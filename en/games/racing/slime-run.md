## About

Sime Run is a fun action game where you control a Slime sliding quickly across the arena to color your territory. Competing directly with other Slimes, you need to move skillfully and occupy as much colored space as possible to win. Fast-paced, simple yet dramatic rules, Sime Run offers exciting and entertaining competitions.
