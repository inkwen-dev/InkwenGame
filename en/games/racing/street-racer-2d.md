## How to play

PC Controls
A / left arrow key = reverse
D / right arrow key = accelerate
W / up arrow key = gear up
S / down arrow key = gear down
R = restart
P = pause
Shift = turbo
Mobile Controls
Touch the in-game buttons on the screen to play the game.

## About

Street Racer 2 is a driving drag-racing game where your goal is to win races, upgrade, and buy new cars. This game offers an exhilarating mix of play modes, including drag racing, off-road challenges, and arcade-style fun. Each mode delivers a distinct experience, whether chasing high-speed thrills, conquering rugged terrain, or enjoying adrenaline-packed track action.
