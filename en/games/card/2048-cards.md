## About

2048 Cards is an addicting card game based on the 2048 mechanism.2048 You need to stack cards in columns with numerical values, they must add up to 2048 to remove them. The aim of the game is to get all of the cards to disappear by adding them up correctly. The hard part is that once you place a card you cannot remove it so make sure that you think quickly and plan accordingly. You have a set number of discards available per game so use them sparingly or you will find yourself stuck with no moves left. Good luck!
