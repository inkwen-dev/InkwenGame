## About

Beetle Solitaire is a solitaire game where the objective is to order all the cards in descending runs from King down to Ace in the same suit. Once a run has been completed, for example King of clubs down to Ace of clubs, then the whole run will be removed from the stack. Once all the stacks are completely empty the game has been won.
