## About

Memory Match is a free online puzzle game for boys played on PuzzleGame. It combines the traditional card memory game with the matching game. These cards are hidden when matching, so you need to remember them and then select the same card to merge. Mobile, Tablet, and Desktop are playable. Challenge yourself!
