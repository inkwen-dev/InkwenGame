## About

Spider Solitaire is a card game that uses two decks of cards. The more cards, the more exciting the solitaire! You will really need to use your concentration to beat this puzzle game. This version of solitaire is different because it does not involve placing cards into foundation slots. Instead, stack the cards in the tableau in descending order to spin a spider web-like pattern. There is no need to sort by suit. This card game is challenging because it is easy to run out of moves. If you run out of moves, click the stock to add another row of cards to the stacks. Eliminate all the stacks to beat the game!
