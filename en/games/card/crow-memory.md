## About

CROW MEMORY is a crow-themed memory matching game featuring 8 unique characters and 16 cards in total. When the game starts, the cards are shuffled using the Fisher-Yates algorithm to ensure a random distribution. The timer starts on the players first click, and each correctly matched pair adds one point to the players score. After completing a game, simply click &ldquo;Start/Restart&rdquo; to shuffle the cards again and begin a new round.
