## About

Fruit Memory Extravaganza is a vibrant and juicy card-based memory game that challenges your brain and sharpens your recall skills! Flip cards one by one to find matching fruit pairs &mdash; from bananas to berries &mdash; all within a limited time. With 6 increasingly tricky levels, each round gets faster and more challenging, testing how quickly and accurately you can match the fruity duos. Can you conquer the fruit frenzy before the clock runs out? Key Features: Flip-and-match fruit cards in a race against time Boosts memory and concentration skills Time-limited challenges across all levels Colorful fruit-themed visuals
