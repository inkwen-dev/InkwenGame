## About

Casino Memory Cards is a game that challenges the memory of the position of 2 cards the same. When you flip true you will be rewarded with money, when you flip wrong you will be deducted until the money runs out, the game ends. Note that each level will have different difficulty and different completion time, if time runs out without flipping all the cards you will lose. Wish you have fun.
