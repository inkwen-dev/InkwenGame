## About

Shortcut Run is a parkour game as well as a new arcade game. In the game, you need to collect wooden blocks on the platform. These wooden blocks allow you to build a road faster than others on the water. The more blocks, the more coins you will get. These coins can be used to exchange for different cartoon character skins. At the same time, running on the water can increase your speed. Are you ready? You will race with others. If you want to win the game, running on the water will speed you up, but it also will cost the bricks. So you need to collect them.
