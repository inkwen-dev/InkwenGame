Mouse control to swipe

## About

The main principle is pretty simple &ndash; you are controlling a small ball that is always moving forward. On your way, there are a few obstacles that you need to get through. There&rsquo;s a small problem however, because you can only touch obstacles that are the same color as your ball. If you touch an obstacle with a different color, the game ends and you need to start from the beginning.
