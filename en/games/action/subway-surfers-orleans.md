## About

Control in the game on the computer is carried out using the arrows, space - to activate the skate. The object of the game is for the hero to run as far as possible, overcoming obstacles and dodging oncoming trains. If the player collides with something, then the inspector catches up with him and the game ends. During the escape, you need to collect gold coins and various bonuses, thanks to which new game possibilities open up.
