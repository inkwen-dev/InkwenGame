## About

Stickman Slope is a running game set in the streets of a city. To be successful, you have to avoid the obstacles that come your way. There are helpful power-ups and special abilities to help you progress in Stickman Slope. The game contains 8 stickman characters. This 3D running game can be played as a casual game. It is a game that can be played on both pc and mobile devices.
