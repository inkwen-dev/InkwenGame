## About

This game with the wonderful piglet called Piggy Run. The task in this game is with the little pig to run as far as possible. Object is to collect diamonds to shoot down the poisonous mushrooms that are an obstacle in this game. For a while the pig will get wings and you can fly. You heave help by use the parachute by pressing the X button when you are up. You shoot by pressing the Z button. Have fun!
