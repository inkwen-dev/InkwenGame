## About

Geometry Stack 2048 Run is a fun and smart online running and puzzle game. You have to slide the screen and move a block through other blocks. The blocks can combine if they have the same number. For example, two 2 blocks can make a 4 block. Two 4 blocks can make an 8 block, and so on. You have to create bigger numbers before the finish line. Can you reach the number 2048? Test yourself and see!
