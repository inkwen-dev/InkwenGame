## About

In this amazing 3D running game Run Run 3D Challenge, you need to act as a little boy and pass through many dangerous places. Click on the right side of the screen to jump, click the left side of the screen to slide, you need to react fast to avoid those roadblocks, dangerous monsters and collect stars. There are 6 levels now and we will create more levels if you like this game, join the adventure and show your game talent in this game Run Run 3D Challenge!
