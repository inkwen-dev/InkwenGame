## How to play

Use the “?” button in the editor to read the help section.

Use the editor to create your own levels. You can also copy and modify levels you like by using the “Remix” button. Once your level is ready, publish it so other players can play it.

## About

Create your own levels and play levels made by other players!

Build your own obby courses, come up with challenges, and share them with other players! In this editor, you can create unique levels, customize obstacles, add logic, and program object behavior.

Use the flexible editor to build simple parkour maps, complex puzzles, mini-games, traps, moving platforms, and levels with custom rules. Customize objects, add events, experiment with mechanics, and turn your ideas into full game worlds.

Game features:

* Create obby courses and parkour levels
* Object, obstacle, and platform editor
* Logic and element behavior settings
* Programming of in-game events
* Levels of different difficulty
* Ability to invent your own rules and challenges
* Suitable for beginners and experienced creators

Build, test, improve, and create obby levels that other players will want to beat!
