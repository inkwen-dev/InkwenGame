## About

In this game there are two balls of different colors in the top part of the game screen which move horizontally, the same is in the down part of screen. Between them there is a ball that moves vertically. The object of the game is to control the balls in the top and down part and to touch only the balls of the same color. The middle ball changes color and therefore the balls that are positioned horizontally should be rotated. As you play the game the speed of the ball will increase.
