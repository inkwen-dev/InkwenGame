## About

Kitty Maze is filled with Fun and enjoyment. &lsquo;Kitty Maze&rsquo; is an engaging and interesting game full of fun.It will test your gaming skill to overcome the hurdle and complete the level. Main object of this game is to pass the cat from one point to another.During crossover the path is blocked by wood log.The player has to shift the wood log and make the way to pass the cat.If you not able to shift the wood log ,you will not be able to complete the level. Features of this game: High Quality graphics Game size is minimal Super simple controls Interesting quests.
