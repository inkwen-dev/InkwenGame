## About

You will think a lot and have a lot of fun while playing the Lipuzz game. A great game to exercise memory. The aim of the game is to collect liquids of the same color in a container by transferring the liquids in the containers to each other. The most important rule in the game is that the container you want to pour the liquid into must either be empty or the other container must have the same color liquid. If you can't pass the level in the game, you can get another container from the top menu.
