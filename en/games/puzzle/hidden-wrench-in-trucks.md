## About

This is hidden objects game with trucks. This game offers you six levels to play. Start with the first level and find the ten hidden wrench for the given playing time. If you succeed in that you will move to the next level. Each next level you play will reduce the playing time by 10 seconds. Try to pass all the levels and win in this game. Hidden object games are always interesting and fun to play.
