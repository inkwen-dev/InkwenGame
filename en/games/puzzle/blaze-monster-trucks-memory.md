## About

This is memory game with Monster Trucks machines. Click on the cards to turn around and see which monster machine image will appear. Memorize the pictures and hit 2 of them to make them disappear. Guess all the cards before time runs out. The game will start with fewer cards and as you progress through the game the cards will increase. So at some point you will have a bunch of fields to guess. An interesting memory game with a monster trucks machines.
