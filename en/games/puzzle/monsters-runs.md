## About

Monsters Run is a game in which you have to control a small monster to pass as far as possible to a destination without being destroyed. You should avoid spikes and saws on the bottom and top of the screen. You need to move the monster to move it up or down the track depending on where the obstacles are. So avoid all obstacles, collect stars and try to get the best score. If your monster is hurt you need to start the game again from the beginning.
