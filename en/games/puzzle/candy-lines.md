## About

Candy Lines is a game where you have to arrange the candies in a line to make them disappear. This game is played like chess. You need to have space to move the candies to where you want it to be. There should be three candies in a horizontal vertical or diagonal row for the candies to disappear. Candies will always appear in a new place so you need to arrange them well so that you do not get trapped and can not make a row of candies.
