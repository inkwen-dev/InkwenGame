## About

Squid Game Jigsaw is a fantastic jigsaw puzzle game with the theme of the squid games. Drag and drop the pieces to their exact locations. In this game you have a total of 12 squid game themed images. You need to start from the first image and to unlock the next one. You have three modes for each image: Easy mode with 25(5x5) pieces, medium mode with 49(7x7) pieces, and hard mode with 100(10x10) pieces.
