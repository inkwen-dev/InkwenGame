## About

A fun Halloween themed "Collapse/Unexpected" type game. Clear the board of all the tiles by clicking 2 or more matching tiles that are adjacent to each other vertically or horizontally. The boards start out with tiles that are more than one tile deep. When the last tile in a stack is removed the tiles above it will drop down. If matches are made when the tiles drop down, you will get another Magic Pumpkin. Magic Pumpkins are used to destroy tiles when no matches are available.
