## About

Match 3 RPG Puzzle is a new puzzle game. Help our hero attack all the monsters in each level. This is an attractive game, attracting many players. There are so many levels to play, you have to connect 3 items of the same type. There are 5 different items and 4 boots, you can buy boots by using coins in the game.
