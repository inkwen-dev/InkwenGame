## About

Move The Pin 2 is an easy and simple game for boys for free, but carefully the trap. All balls must enter the cup, you need to pull out the pins correctly to achieve the goal. Some balls are colorless, they need to touch other colored balls to get the color before entering the cup. So you must think first before pulling the pin. Each level fulfills designs, you can challenge yourself!
