## About

Klara Memory is brain memory game where you need to memorize all images and when they hide you need to find them as you remember fastest as you can. Try to pass all levels and to test your memory skills. How you go up thru the levels the time will increase the speed, so it will be more difficulty for playing. If time is finish you will start from beginning of the game.
