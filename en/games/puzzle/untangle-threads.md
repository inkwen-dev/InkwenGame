"Untangle Threads" — a beautiful puzzle game where you drag nodes so that no thread crosses another.

## How to play

1. Drag the nodes (glowing spheres) with your finger or mouse
2. Position them so that no thread crosses another
3. Red threads = crossing detected, green = all clear
4. Fewer moves = more stars (up to 3)

## About

"Untangle Threads" — a beautiful puzzle game where you drag nodes so that no thread crosses another.

6 unique worlds, each with its own mechanic:
- Neon — classic puzzles to warm up
- Nature — new threads appear as you solve
- Space — some nodes are locked in place
- Ocean — nodes drift with the current
- Crystals — limited number of moves
- Steampunk — linked nodes move as mirror images
