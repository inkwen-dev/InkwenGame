## How to play

Use mouse to click or touch screen to play this game

## About

Collapse blocks by clicking on horizontal or vertical groups of 3 or more same colored blocks. Each collapse will add to your score with larger collapses giving more points. The Projection Box indicates how many points a collapse will give. Use logic to create bigger groups while keeping the blocks from reaching the top. Use power ups to remove more blocks.
