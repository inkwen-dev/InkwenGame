## About

Garfield Memory Time is a puzzle game in which you have to match two images of each kind. To turn the image just click on it and then try to look for the pair. Once you see where the picture, trying to remember, because it will help these matches. You only need the mouse or tap on the screen to fulfill your objective. If you manage to match two images of the same kind you get a certain number of points. Concentrate on the game and try to make as good result as possible. Now, start playing the Garfield Memory Time and have fun!
