## About

This is a casual game in which there is a red object in the center of the screen that You must try to hit it to the blue object with the Smaller number than itself and earn points, in the start screen. You need to be careful not to hit to the blue object with Bigger number. Gradually, the speed of the game is increased and makes you confused. Heave Fun!
