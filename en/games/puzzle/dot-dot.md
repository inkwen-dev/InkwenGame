## About

This is puzzle reflexive game with dots. There is two kinds of dots. Red one and yellow. The dots with same color need to be paired. If you pair dots with different color the game will over. The dots will come from the top of the game. Click on the screen to spread the red dots if necessary. Try to make more points as you can. The commands for this game are simple, just tap on the screen.
