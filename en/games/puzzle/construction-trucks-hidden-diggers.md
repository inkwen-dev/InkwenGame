## About

Construction Trucks Hidden Diggers is a hidden object game. This game has six levels and in each of them there are small diggers. There are 10 diggers in each picture and you need to find them all for the allotted time. At each subsequent level the playing time decreases. Try to pass all levels within the given time to play.
