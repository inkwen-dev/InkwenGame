## About

Halo Run is a fast-paced reflex game set on an endless circular track where survival depends on perfect timing. Run endlessly around the halo and leap over incoming obstacles before they collide with you&mdash;one mistake and the run is over. The challenge intensifies as speed increases and obstacles appear closer together, pushing your reaction time to the limit. Every jump must be precise, every move calculated. Simple controls make it easy to play, but mastering the rhythm takes skill and focus.
