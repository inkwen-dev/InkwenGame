## About

Fun Hidden Objects is a free online skill and hidden object game. In this game you have 6 levels where you have fields that list which objects you need to find. The time is limited so be fast and find all hidden objects before time runs out. Clicking in the wrong place several times reduces the time by an additional 5 seconds. So, if you are ready start the game and have fun!
