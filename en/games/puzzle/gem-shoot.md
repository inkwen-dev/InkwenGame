## About

Link any 3 gems together. "Gem Shoot" is special type of match 3 game. Unlike others match 3 game, you cannot more the gem. There is a gem on the bottom, you can select one of the path the shoot out the gem. Any 3 or more gem linked together the gems will be destroyed. More than 3 gems link together, it will form a new type special gem. "Gem Shoot" is combination game of match 3 and bubble shoot. It will provide you an other type of experience.
