## About

Welcome to our latest game Neon Strike. In this game you have two squares one of which is red and the other is blue. Horizontal line is given which for some time changes color from red to blue and vice versa. The task in the game is to touch the squares of the horizontal line with the appropriate color. If the square is red then the line should also be red. With each touch square you get one point. Make as many points as possible.
