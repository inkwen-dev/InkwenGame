## About

In each game the player starts with 3 hp. Each time a Tower block is dropped, the player drops 1 hp; The game is over when hp is finished. The player is rewarded with 25 points for each successful stacked block (Success). If a block is placed perfect on the previous one, the player is rewarded with 50 points instead. Consecutive Perfects earn an additional 25 points.
