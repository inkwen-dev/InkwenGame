## About

Welcome to our latest game Fun Neon Strike. In the game you have two squares one is red and the other is blue. Horizontal line is given which for some time changes color from red to blue and opposite. Gold in the game is to touch the squares of the horizontal line with the appropriate color. With each touch square you get one point. Make as many points as possible.
