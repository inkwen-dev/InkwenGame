## About

Merge Bubble Number is a simple and addictive number merge puzzle game. You will control a board of checkers, each with a bubble with a number in it. You need to connect as many bubbles as possible so that bubbles of the same number merge together. The goal of the game is to merge as many bubbles as possible before there are no bubbles that can be synthesized, and finally reach a high score.
