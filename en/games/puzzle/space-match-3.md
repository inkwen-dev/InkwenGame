## About

Space Match 3 is a matching game where you need to collect a certain number that is given to you on the screen by some of the blocks. You need to do all this with a certain number of moves. If four or more identical blocks are paired you will get extra moves. Your moves will shift to the next task so it is good to increase them when you have the opportunity. Tap on the blocks to play this game. Match the blocks with minimum moves and win at this interesting puzzle matching game.
