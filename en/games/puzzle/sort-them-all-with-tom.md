Sort Them All is fun addictive hyper casual game.Sort Them in to matching bins.I this game you have to sort all different colors ball into their matching bins.Choose the color which ball do you want to pick. This an interesting arcade and matching puzzle game that is made from 3D game models. There are many blocks with cups order staying at the pipes on the desk. Use the sucking vaccum to collect the blocks with the same color and release them in the bins, once you done with one color you can select another color to sort and complete all the blocks. Complete all levels and have fun.
