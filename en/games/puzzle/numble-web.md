## About

In this exciting puzzle game, you must use your deductive skills to guess a 4-digit number before the bomb explodes! With 10 chances to guess, you must rely on the clues provided after each attempt - green dots represent correct numbers in the correct place, while yellow dots show the number of correct digits in the wrong place. Can you crack the code and save the day?
