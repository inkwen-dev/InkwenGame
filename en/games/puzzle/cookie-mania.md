## About

Discover this classic game which combines the best of Mahjong and Match 3 features and challenges. Set in a beautiful and uplifting environment, the goal of the game is very straightforward: connect similar candies and clear the entire board before time's up. What seems like an easy game at first will challenge you immensely as you advance further. You will need to anticipate every single move and make sure you can clear the ever more complex boards.
