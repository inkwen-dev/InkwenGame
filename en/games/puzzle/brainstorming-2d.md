## About

Brainstorming 2D is a puzzle game. In each slider puzzle, you will see a grid with colored grid edges with squares inside these borders. The squares are the same color as the grid edges. The number of colors may vary. Each slider puzzle aims to get rid of all blocks locked within the edges of the grid.
