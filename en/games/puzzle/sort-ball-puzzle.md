## About

Sort all 3d balls with the same color into one tube. Sort Balls 3D color sort puzzle is a fun and addictive puzzle game! Try to sort the colored balls in the tubes until all balls with the same color stay in the same tube. It's a challenging yet super fun brain puzzle with easy to play controls. HOW TO PLAY? * Tap any tube to move the ball lying on top of the tube to another tube. * Stack all the balls of similar color into a single tube. * Try to not get stuck. But don’t worry, you can restart the level at any time.
