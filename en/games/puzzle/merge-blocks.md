## About

Merge Blocks is an addictive puzzle game combining 2048 and match-3 mechanics. Drag blocks onto a 5x5 board, match 3 or more identical blocks to merge them into higher forms. Create chain reactions for massive combos! Features: - 8 levels of block evolution - 3 power-ups: Undo, Bomb, 2x Score - 3 themes: Light, Dark, Zen - Relaxing procedural music - Cloud save &amp; offline play How to play: 1. DRAG blocks from the bottom panel onto the board 2. MATCH 3+ identical adjacent blocks to merge 3. PLAN ahead and create chain reactions 4. SCORE based on block level and combo Perfect for fans of 2048, Threes, and match-3 games!
