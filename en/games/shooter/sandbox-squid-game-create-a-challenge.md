## About

Sandbox Squid Game - Create a Challenge &mdash; a game inspired by Squid Game. The game genre is a sandbox. Therefore, you can freely build whatever you want. The main task is to build a test that players will pass. You can help them, hinder them, or even kill them. When players pass the test, you get money. The game has: more than 5 maps, 4 blocks for construction, more than 5 players, 4 skins for the guard.
