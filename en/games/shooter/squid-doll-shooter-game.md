## About

Squid Doll Shooter Game is an arcade game where you have to break the blocks with the help of a yellow doll robot. Each block in each level has a number that indicates how many times the block must be hit by the doll robot to break. This game has 30 fun and interesting levels. Enjoy and have fun!!!
