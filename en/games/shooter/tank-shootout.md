## About

Tank shootout is an interesting skill based shooting game. Destroy all the targets to complete a level. Use mouse or touch input, to set the speed and direction of bullet to chase the target successfully. You will get limited number of bullets for each level so use them wisely to win it. You can take the help of power panel to see the current power and last shot’s power. Mini map shows the position of target, the location where the previous shot reached etc.
