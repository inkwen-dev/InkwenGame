## About

Kids Build House is an educational game. In this game, you can help small animals build houses that suit them. You can help monkeys build a banana tree house in the style of a rainforest, help penguins build a white igloo, help bunnies build a greenhouse for growing carrots, and use tree trunks to build a wooden house for little bears.
