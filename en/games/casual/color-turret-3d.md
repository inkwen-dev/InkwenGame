## About

Color Turret 3d! Only the best crashers will be able to destroy all towers in this 3D physics game. Try to let all towers collapse with the number of given balls. But you will only destroy the shapes with the same color as your ball. Use the powerful earthquake or shotgun power-ups, to create huge chain reactions, which will lead to the destruction of the towers. Beautiful designed levels and shapes will await you, so don’t waste any second and become the greatest tower crasher of ‘em all!
