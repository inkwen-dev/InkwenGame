## About

Image Box is an engaging and challenging puzzle game designed to test your spatial awareness and problem-solving skills. The game divides a complete image into a grid, which can be 2x2, 3x3, 4x4, or 5x5 blocks. Each block can be clicked to rotate it 90 degrees counterclockwise. The players goal is to rotate the blocks in such a way that the original image is reconstructed. Image Box is perfect for puzzle enthusiasts looking for a fun and mentally stimulating game. Whether you prefer a solo challenge or competitive play, this game offers something for everyone.
