## About

Spooky Vending Machine is an amazing game that helps your child to learn math by playing! Choose among three vending machines: one with toys, one with sweet treats, and one with food; each item inside the vending machines has a price you have a set of coins at your disposal to insert the right sum you can see on the display, If you’re right, the vending machine will release the item, if you’re wrong you’ll receive an error message.
