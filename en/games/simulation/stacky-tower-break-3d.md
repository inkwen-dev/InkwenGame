## About

Welcome to the most addictive and exciting ball game you have ever played. 3D Ball Stack Tower is a free propeller simulation game in which you can drive through platforms while avoiding black obstacles. On single tap on the screen, it makes the simple fireball into a super Stack ball. Then this Super 3D Ball Stack Tower crashes into the Multiple color rings 3D Ball Stack Tower. You have to find the correct color wheel, so that it crashes all these wheels and reach the end point to complete the level.
