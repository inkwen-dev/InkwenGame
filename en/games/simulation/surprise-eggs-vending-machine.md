## About

Surprise Eggs Vending Machine is a really fun game. Each item inside the vending machine has a price; you have a set of coins at your disposal to insert the right sum you can see on the display. If you’re right, the vending machine will release the item, if you’re wrong you’ll receive an error message. Uncover the surprises and collect all the items.
