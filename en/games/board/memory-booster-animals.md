Use mouse or touch pad to play this game

## About

Memory Booster Animal is a fun and challenging memory game with 2 phases. In the first phase you'll need to pick a certain amount of random cards. As you pick the cards they will be turned over revealing a picture of an animal. You'll need to remember the animal and the order in which you chose it as in the second phase, after all the cards are shuffled and revealed, you'll need to pick them out in order. In each level you will get some hints and lives. You will get more bonus score if you make fewer mistakes or you use fewer hints.
