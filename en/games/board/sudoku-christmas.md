## About

This is a classic sudoku game. You can select any one of three grids(4x4, 6x6 or 9x9) and can set difficulty level. The objective is to fill a selected grid with Christmas items so that each column, each row, and each of the respective sub grids that compose the grid contain all of the items without repeating anyone.
