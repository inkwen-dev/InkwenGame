## About

Link Me To The Factory is a creative puzzle game where your task is to connect the square blocks according to the rules to complete the system and activate the factory. Each level presents a new structure with the square block positions arranged in a challenging way. You need to observe carefully, calculate a reasonable connection path, and arrange the blocks so that they are all fully connected. If you make just one mistake, the entire system will break, and you will have to start over!
