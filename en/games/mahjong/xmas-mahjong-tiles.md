## About

Xmas Mahjong Tiles is the classic tile-matching game with christmas theme. Match the pairs of the same tiles to clear them. You can select only those pairs which have either left or right side open. You need to clear all the tiles before the time runs out, then play as fast as possible. Hints and Shuffles buttons can help you. Spread some holiday cheer with this cool games.
