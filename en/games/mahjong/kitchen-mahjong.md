## About

Simplified classic Mahjong game with Girls theme. You can eliminate pair of similar items. You can select only those pairs which have either left or right side open. Hints can help you. Try out the classic Mahjong game. Make connections between the matching tiles while you fight to keep up with the clock. Can you clear the board before time runs out? Saved time will be awarded as bonus.
