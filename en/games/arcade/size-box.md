## About

Size Box is a puzzle game with boxes. The goal of the game is to put the box on the box spot. But the spot where the box need to be always is with different size, and the box is always smaller than the spot. You need to tap and hold on the screen and box will grow. Release when you thing that the box is big enough. The box need to be exactly as the box spot, if the box is smaller or bigger the game will end and you need to star from the beginning.
