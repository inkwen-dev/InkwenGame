## How to play

Tap or click to flip cards

## About

The game is very simple, you will still use your natural memory ability to complete it by opening pairs of cards with the same animals. You will win the game if you don’t open all the cards correctly and there is still time limit. If the time ends and you don’t open all the cards, the game is over. Completing each level you will be rewarded with coins and coins you can buy help features of the system. Enjoy!
