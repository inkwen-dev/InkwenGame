## About

Help Santa to escape from dark forest prison! Santa Drop is a 60 levels of fun physics puzzle game! all boxes except the grass must be removed where the prison is standing. Simply click or tap on the boxes or blocks to destroy them; carefully use the set blocks in what ever way you can to get the Santa Drop safely into the grass. Solve this fun physics game and help Santa to escape from prison!
