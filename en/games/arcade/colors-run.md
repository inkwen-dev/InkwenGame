## About

Colors Run is a arcade puzzle game suitable for all ages and perfect for families to enjoy. The goal of this game is to catch the coming colored balls with the ring who is located on the bottom of the game screen. You need to match the color of the ring with coming balls. For that you have buttons with different colors. Click on the colored button to change the color of the ring with that color. Be fast and try to destroy more balls as you can.
