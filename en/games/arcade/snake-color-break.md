## About

Snake Color Break is a snake puzzle game. There will be five targets on the roll. You need to control the snake and to pass in target that is with same color as the snake circles. Between targets will have borders in different colors. When you pass the border the snake will change color and you need to go to the target that is with same color. If you don jot match the target with the snake the game will over. It is interesting and addictive kids game. Try to play longer as you can.
