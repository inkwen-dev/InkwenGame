## About

Space Diamond Miner is a casual arcade game inspired by classic Gold Miner&ndash;style mechanics, set in a colorful space diamond mining universe. Players control an astronaut and use a hook to collect valuable diamonds hidden underground on alien planets. Each level has a time limit, encouraging precise timing and smart target selection. Collected diamonds can be spent on upgrades such as hook speed, hook size, extra time, and diamond value, creating a simple yet rewarding progression system.
