## About

Jail Drop is a 60 levels of fun physics puzzle game! all boxes except the grass must be removed where the prison is standing. Simply click or tap on the boxes or blocks to destroy them. Carefully use the set blocks in what ever way you can to get the prisoner safely into the grass. You can reset each level if you made a wrong move. Solve this fun physics game and enjoy!
