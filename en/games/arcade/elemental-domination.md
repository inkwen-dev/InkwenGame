## About

With 145 levels, Elemental Domination is a puzzle game where you, as an alchemist, must unify the elements. Set in a mystical world of alchemy, each level presents a grid filled with different elemental blocks, such as fire, water, earth, and air. Your goal is to transform all the blocks into a single grid element by strategically touching blocks to spread the active element. With increasingly challenging levels, youll need sharp thinking and precise moves to dominate the elements and achieve true alchemical mastery. Can you bring balance to all?
