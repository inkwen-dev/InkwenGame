## About

Aquatic Blocks is a classic block collapse game where you need to eliminate all the blocks in a level. You can remove a group of similar blocks which are adjacent linearly. If you try to remove a single block 200 points will be deducted from your score. Number of block types and level target will be increased gradually. Check how far you can go in this game?
