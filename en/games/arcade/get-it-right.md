## About

The code from the ball! Can you figure it out? Blind guessing requires adding the color and position of the ball. After each position is placed, the answer for each position will be given. Green is completely correct, red is completely wrong, and yellow has the wrong color position. Please guess the correct answer in a finite number of times given!
