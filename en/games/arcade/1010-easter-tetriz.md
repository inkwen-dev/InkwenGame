## About

1010 Easter Tetriz is a very interesting block puzzle game. In this game you need to pick and drop the set of blocks on the board. After dropping the set, if a horizontal or vertical line of 10 blocks is formed, the blocks will be removed from the board. The more number of blocks you remove at once, more score you will get. Don’t let the board crowded with the blocks. You can play till you are able to fit the existing block sets .
