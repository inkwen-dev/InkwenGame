## About

The Galaxy Bricks Breaker Online Game is a great way to pass the time. It is a game that requires quick reflexes and decision making. The object of the game is to clear all the bricks from the screen. This can be accomplished by matching three or more bricks of the same color. The game gets progressively more difficult as more bricks are added to the screen.
