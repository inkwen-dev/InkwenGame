## About

This is a casual game in which there are four operations that are calculations from zero or more input values to an output value, in the start screen. You need to be careful that select correct operation. Gradually, the speed of the game is increased to make you confused. This game is very interesting. Use the mouse click or touch to select the appropriate operator.
