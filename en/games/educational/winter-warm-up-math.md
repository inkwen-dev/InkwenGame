## About

Winter Math Warm-up is a math puzzle game. In this game you need to find the values of some winter items by solving given equations. Operations in the problems consist of addition, subtraction, multiplication and division. Once you find the values of items, use these values to find the answer of a simple Math question. Occasionally you can use hints using the button in the left panel!
