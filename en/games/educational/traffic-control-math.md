## About

This is a traffic control game where you control the flow of traffic by starting the traffic in a lane by clicking an option which shows the correct answer asked in the question. There are four sets of Arithmetic problems; each is connected to a traffic light signal. If you tap correct option for the asked question, it will make its signal green and rest all signals will be red. In each level you have to control the traffic for a limited time. Try to solve as many questions as you can, while avoiding the traffic congestion. If you tap the wrong option, you will lose the level. Game will be tougher gradually as you progress the levels.
