Use mouse or touch the screen

## About

One of the best ways to teach something to children is using some kind of game. This memory game is aimed to teach children the English alphabets using a memory game. This game has 4 modes: Learning, Easy, Normal and Hard. In learning, you will see all alphabets and you can choose each one to hear its pronunciation. In other modes, you can play a memory game and you have to match all cards to finish the level.
