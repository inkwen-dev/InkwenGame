## About

Block Escape is a relaxing yet challenging 3D puzzle game where your goal is to clear all the colorful blocks from the screen. Each block has an arrow pointing in a specific direction. When you tap a block, it will fly off in that direction&mdash;but only if its path is clear! Features: Satisfying and relaxing 3D puzzle mechanics Colorful, high-contrast visual design Endless brain-teasing levels Smooth camera rotation to explore every angle
