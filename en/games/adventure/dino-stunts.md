## About

Dino Stunts is a game in which you have to guide the dino through various adventures. He needs to jump on a cactus or bend over an eagle. Try to go as far as you can. But as time goes on the game gets faster. At some point it is so fast that you have to be very skilled to be able to pass all obstacles without colliding with them. So try what will be your best time.
