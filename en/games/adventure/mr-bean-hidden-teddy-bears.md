## About

Mr. Bean Hidden Teddy Bears is a free online skill and hidden object game. Find out the hidden Teddy Bear in the specified images. Each level has 10 hidden Teddy Bears. There are 8 levels in total. The time is limited so be fast and find all hidden objects before time runs out. Clicking in the wrong place several times reduces the time by an additional 5 seconds. So, if you are ready start the game and have fun!
