## About

Thanksgiving Episode3 is another point and click escape game developed by 8BGames/Games 2Mad. In this escape game, you need to find a Thanksgiving Turkey to escape from this forest. Each episode you will get an object to find the turkey. Already you have collected two objects. So, you need to find the Thanksgiving object by finding useful objects, hints and solving puzzles to find the thanksgiving turkey. Good luck and have fun!
