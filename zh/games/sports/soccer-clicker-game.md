# 足球点击游戏

踏上球场！在这场比赛中，你只需点击屏幕或鼠标来射门得分！追踪你的每秒进球数和总进球数，努力主宰赛场。比赛时间为45秒，每隔几秒你会获得时间奖励以提升你的分数。你能成为终极射手吗？这是一款简单又有趣的游戏——非常适合足球迷！
