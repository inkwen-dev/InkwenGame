# 柔韧跑 3D

<a href="https://inkwengame.com/zh/games/flex-run-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flex-run-3d/cover.jpg)

《柔韧跑 3D》是一款由3D卡通模型和家具构成的瑜伽模拟街机游戏。你的目标是通过实时改变姿势和位置，避开所有家具障碍物，成功抵达终点墙。游戏中有单个女孩和两个女孩的角色，你的拖拽操作将使角色做出不同的动作。抵达终点墙后，你仍可调整姿势，以贴合迎面而来的紫色墙壁上的数字圆圈。祝你好运，尽情享受六种皮肤带来的乐趣！

## 怎么玩

点击并拖动以改变位置
