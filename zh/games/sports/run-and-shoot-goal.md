# 奔跑与射门：进球！

<a href="https://inkwengame.com/zh/games/run-and-shoot-goal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/run-and-shoot-goal/cover.jpg)

奔跑时不要撞到障碍物或对方球员。尽可能多地收集蓝色能量，并更用力地击打足球。然后控制球，尝试突破守门员。你可以成功进球并进入下一关！根据你收集的能量，球的弹跳高度会增加，守门员扑救的概率会降低。如果你想，可以在中场休息时更换角色。撞击球杆会损失1点能量；撞击障碍物会损失10点能量。

## 怎么玩

玩家移动 - 左箭头键向左移动 - 右箭头键向右移动 - 空格键跳跃 球的移动 - 左右箭头键 - 如果你能进球，就可通关
