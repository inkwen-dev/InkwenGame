# BloxingFederation

<a href="https://inkwengame.com/zh/games/bloxingfederation" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bloxingfederation/cover.jpg)

一款主要由方块构成的拳击游戏，你将把对手打得遍体鳞伤，并尽全力赢得比赛。可以体验单人对电脑或双人对战等多种模式。此外，观看电脑对电脑模式也十分有趣。

## 怎么玩

玩家1和玩家2 W 或 上 - 前进 S 或 下 - 后退 A 或 左 - 向左看 D 或 右 - 向右看 G 或 1 - 出拳 H 或 2 - 格挡
