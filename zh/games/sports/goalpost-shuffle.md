# 球门 Shuffle

<a href="https://inkwengame.com/zh/games/goalpost-shuffle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/goalpost-shuffle/cover.jpg)

Goalpost Shuffle 是一款游戏，玩家需要在规定时间内将每个足球送入正确的球门，且不能发生碰撞或其他问题。通过点击足球，然后点击正对足球的目标球门，足球会沿直线移动。尽情享受吧！

## 怎么玩

先点击足球，再点击正对足球的目标球门
