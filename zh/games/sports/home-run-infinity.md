# 全垒打无限

<a href="https://inkwengame.com/zh/games/home-run-infinity" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/home-run-infinity/cover.jpg)

在这款无尽的街机棒球挑战中，把握挥棒时机，将球击得尽可能远。每次击球都能获得金币，解锁 25 支威力递增的球棒，探索 10 个各具特色的球场，并在 Playgama 排行榜上争夺最远击球纪录。

## 怎么玩

点击或轻触游戏区域，或按空格键，即可停止移动的计时标记并挥棒。瞄准绿色区域可获得强力击球。红色和橙色小区域可提供罕见的击球距离倍增。每击中一米可获得一枚金币，然后用金币解锁并装备新的球棒和场景。
