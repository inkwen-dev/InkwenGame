# 直线篮球

<a href="https://inkwengame.com/zh/games/linear-basketball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/linear-basketball/cover.jpg)

在这个游戏中，你需要画一条线，让球沿着这条线移动到篮筐并得分。有时会有多个球和多个篮筐，因此你需要将两个球都放入篮筐中。注意，有时会出现炸弹，你需要避开或阻挡它们。

## 怎么玩

点击屏幕开始游戏
