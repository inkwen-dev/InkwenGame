DESKTOP 方向键或A D 移动 空格键 拳击 Z 键 踢击 X 键 超级踢击 V 键 格挡 C 或 上键 闪避 S 或 下键 暂停 P 或 Esc MOBILE 屏幕上的方向键移动 A 拳击 B 踢击 D 超级踢击 X 格挡 闪避技巧 在格挡或闪避后0.35秒内进行反击可造成双倍伤害
