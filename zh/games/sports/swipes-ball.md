# 滑动球

<a href="https://inkwengame.com/zh/games/swipes-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/swipes-ball/cover.jpg)

这款游戏的目标是将球滑入篮筐。每次投篮成功时，都会得到一个篮筐。有时球会从篮筐弹开，或者你完全错过了篮筐，那么你的分数就会丢失。当你获得分数后，可以更换球，用另一种类型的球进行游戏。

## 怎么玩

使用鼠标或在屏幕上拖动来玩这个游戏
