# 肌肉点击器：健身房游戏

《肌肉点击器》让你体验通过在健身房努力锻炼，将一个瘦弱的人变成强壮肌肉男的过程。在这个游戏中，你需要训练并参与竞争以赚取金钱。但事情并不容易，因为持续锻炼会使你的耐力逐渐耗尽。当资金充足时，你可以购买更多设备，帮助你增肌、赚钱和积累经验。随着经验的增加，你还能提升力量和耐力。快来加入乐趣，成为肌肉打造高手吧！

## 怎么玩

点击角色，他就会开始训练。你点击得越快，举起哑铃、做引体向上和杠铃深蹲就越轻松。在固定自行车上训练时，保持点击即可持续锻炼。
