# 搞笑排球

<a href="https://inkwengame.com/zh/games/funny-volleyball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/funny-volleyball/cover.jpg)

这是一款轻松且充满动感的体育街机游戏，主题是排球。控制你的角色，跳跃，击打排球，并在电脑对手得分之前达到所需的分数。游戏包含不同的角色、球类、奖励以及逐步升级的进度。比赛时间很短，你可以在几分钟内完成一局，也可以玩得更久以解锁新物品并提升成绩。简单的物理机制、清晰的规则和明亮的3D视觉效果，让你轻松享受短暂的游戏时光。

## 怎么玩

使用移动按钮来控制角色在球场上移动，跳跃以击打高球，并在恰当的时机击球。尝试将球打到对方场地，使其无法回击。注意观察比分和球的位置
