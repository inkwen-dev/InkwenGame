# KickAround Live

<a href="https://inkwengame.com/zh/games/kickaround-live" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kickaround-live/cover.jpg)

KickAround Live 是一款基于技巧的多人足球游戏。运球、传球、用头或挑球射门得分。每场比赛可有 1 到 8 名玩家！

## 怎么玩

移动 WASD 或方向键 快速冲刺 空格键 Ctrl Shift 传球 抢断 头球 左键 挑球 切换球员 右键 抢断或跳跃 中键 滚轮缩放 切换聊天标签
