# 篮球模拟器 3D

<a href="https://inkwengame.com/zh/games/basketball-simulator-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/basketball-simulator-3d/cover.jpg)

篮球模拟器 3D 是一款体育模拟游戏，你可以通过从不同距离投篮来证明自己的篮球技巧。首先选择你最喜欢的球队，然后在时间耗尽前尽可能多地投篮。投进越多，得分越高，让你为自己取得的高分感到自豪。

## 怎么玩

使用 WASD 或方向键移动，鼠标进行投篮，按左键（LMB）确定投篮力度，按 P 键暂停游戏
