# 足球目标

<a href="https://inkwengame.com/zh/games/soccer-target" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soccer-target/cover.jpg)

你的任务是用足球准确射中目标并获得分数。你只有三次射击机会，如果错过目标，游戏难度会随着得分增加而提升，并会出现一些障碍物。尽情享受吧！
