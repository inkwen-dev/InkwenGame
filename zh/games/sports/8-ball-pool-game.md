# 8球台球游戏

<a href="https://inkwengame.com/zh/games/8-ball-pool-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/8-ball-pool-game/cover.jpg)

8球台球游戏是一款斯诺克游戏，你需要用白球击打其他球并将其打入洞中。注意白球，它必须留在台面上。如果你把白球打进洞里，游戏就会结束。你能否将所有球都打进洞里？无需按顺序击球，只需将球全部打入洞中即可。

## 怎么玩

使用鼠标瞄准并击球
