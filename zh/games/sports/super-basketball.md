# 超级篮球

<a href="https://inkwengame.com/zh/games/super-basketball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/super-basketball/cover.jpg)

《超级篮球》是一款快节奏的街机体育游戏，以激烈的篮球对抗和精彩的扣篮为核心。抢到球，突破对手，抢在对方之前得分。比赛时间短，场地色彩缤纷，球员和篮球均可解锁，还有震撼的慢动作回放，让每一局都充满活力，轻松上手。

## 怎么玩

目标：在比赛结束前获得比对方球队更高的分数。控球后，向高亮显示的篮筐移动，躲避或突破防守队员，到达篮筐完成扣篮。赢得比赛即可获得金币，解锁新球员、篮球和球场，并挑战更强大的对手。

操作方式：

- 鼠标：按住鼠标左键并拖动以控制球员移动方向。松开鼠标即可停止移动。点击界面按钮选择模式和升级。

- 触控：在游戏区域内按住并拖动即可移动球员。松开手指即可停止移动。点击界面按钮选择模式和升级。
