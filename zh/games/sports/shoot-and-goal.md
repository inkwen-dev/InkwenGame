# 射击与进球

<a href="https://inkwengame.com/zh/games/shoot-and-goal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shoot-and-goal/cover.jpg)

这是一款徽章游戏，两名由玩家控制的选手与另外两名由UI自动控制的选手相互对战。率先在对手之前达到5个进球的一方获胜。

## 怎么玩

您通过从您的球员位置拖动鼠标来移动您的球员至目标位置。您决定的力量大小取决于您将手指远离球员的位置，距离越远，所需力量越大以到达目标。
