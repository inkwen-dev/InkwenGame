# 线性篮球

<a href="https://inkwengame.com/zh/games/the-linear-basketball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-linear-basketball/cover.jpg)

这是一款休闲游戏，在开始界面中，你需要通过画出正确的线条，将篮球投入篮筐来得分。随着游戏进行，篮球的数量和投篮次数会不断增加，你需要格外小心，不要把炸弹投入篮筐。游戏速度会逐渐加快，让你感到困惑。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
