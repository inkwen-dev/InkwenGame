# 超级简单的足球

<a href="https://inkwengame.com/zh/games/super-simple-soccer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/super-simple-soccer/cover.jpg)

正如其名，超级简单的足球是一款清新且易于上手的足球游戏。在这个游戏中，你只需要在90秒倒计时结束前攻入比对方更多的进球即可获胜。你需要连续赢得五场比赛才能举起世界杯奖杯。特色：• 清新简单的玩法 • 自定义你的球队名称和颜色 • 拦截、带球、跳跃和射门 • 音效

## 怎么玩

- 使用方向键上下左右移动 - 按下 Z 键跳跃 - 按下 X 键铲球冲刺 - 按下 C 键射门
