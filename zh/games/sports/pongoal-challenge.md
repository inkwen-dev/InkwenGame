# PonGoal 挑战

<a href="https://inkwengame.com/zh/games/pongoal-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pongoal-challenge/cover.jpg)

PonGoal 挑战目前是乒乓球游戏的最先进版本，在游戏菜单中，您可以将球更改为菜单中提供的任意一种，选择卡片以改变敌方机器人的难度级别，可以选择游戏回合时长为1到10分钟，还可以选择球的飞行速度和旋转！

## 怎么玩

使用鼠标或轻触屏幕
