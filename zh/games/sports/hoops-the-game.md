# HOOPS 游戏

<a href="https://inkwengame.com/zh/games/hoops-the-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hoops-the-game/cover.jpg)

HOOPS 是一款游戏，你需要将球从一个篮筐投到另一个篮筐，且不能让它掉落。直接投球——不碰到篮筐——会获得额外分数。你还可以收集硬币来定制你的球。

## 怎么玩

轻触球并向下拖动以瞄准，然后松开以发射
