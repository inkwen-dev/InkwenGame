# 足球反弹

<a href="https://inkwengame.com/zh/games/soccer-rebound" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soccer-rebound/cover.jpg)

足球反弹是一款在弹球台上演的足球游戏。你控制自己球门前方的两个挡板，而你的玩具队友则自行跑动：他们追球、传球并自行射门。确保球不进入你的球门，利用侧边挡板反弹绕过守门员，将球弹起传给你的组织核心完成第一时间射门，从第4阶段开始使用弯球射门，让下一次击打绕过防守球员。

## 怎么玩

桌面端 左箭头或A键 控制左挡板 右箭头或D键 控制右挡板 上箭头 W键或空格键 从第4阶段起使用弯球射门 然后击打 Esc键或P键 暂停 M键 开关音效 移动设备及平板设备 按住左侧和右侧按钮进行击打 点击弯球按钮后再击打
