# 踢球游戏

<a href="https://inkwengame.com/zh/games/kick-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kick-game/cover.jpg)

踢球是一款单人游戏，玩家扮演一名渴望提升技能的足球运动员。在充满障碍物（从垃圾桶到消防栓）的小巷中进行训练时，意识、速度和射门精准度将大有帮助。不要撞碎窗户！当球打破窗户时，分数会被扣除，但当球随后击中墙壁时，分数会增加。目标是尽可能长时间地保持总分高于零。

## 怎么玩

触摸屏或鼠标或键盘
