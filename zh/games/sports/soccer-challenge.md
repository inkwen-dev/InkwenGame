# 足球挑战

<a href="https://inkwengame.com/zh/games/soccer-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soccer-challenge/cover.jpg)

在这些被称为足球挑战的脑力谜题中提升你的传球技巧。点击你想要传球给的队友（穿黄色球衣的人），但确保你和接球者之间没有对手（穿红色球衣的人），否则他将会截断球。尽量用最少的传球次数射门，以获得更高的分数。完成全部30个关卡即可赢得游戏。
