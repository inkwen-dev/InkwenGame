# 网球冲刺

<a href="https://inkwengame.com/zh/games/tennis-dash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tennis-dash/cover.jpg)

网球冲刺是一款快速又有趣的游戏，一只可爱的猫像职业选手一样打网球！网球从不同方向飞来，你的任务是左右移动猫咪来击球。动作要快——如果错过三次球，游戏就结束了！游戏上手简单，但真正精通却很难。努力打破自己的最高分，让连续击球不断进行下去吧！

## 怎么玩

桌面 点击并拖动左或右 移动猫咪熊 移动设备 点按并拖动左或右 移动猫咪熊
