# 指甲挑战

<a href="https://inkwengame.com/zh/games/nail-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nail-challenge/cover.jpg)

这一次挑战从一块木头、一颗钉子和一把锤子开始。组建属于你自己的队伍，开始将钉子钉入木头中！你应该在对手队伍之前完成钉钉子。不要错过金色钉子的机会，以获得更多的力量。商店里会有各种角色等待着你。确保你组建出最强的队伍。在关卡之间，你将进行一些额外关卡，尝试用你的锤子和钉子尽可能多地砸碎木头，并尽可能多地获得额外游戏金币！

## 怎么玩

玩家1 空格键 玩家2 向下箭头键
