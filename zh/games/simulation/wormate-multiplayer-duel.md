# Wormate 多人对战

<a href="https://inkwengame.com/zh/games/wormate-multiplayer-duel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wormate-multiplayer-duel/cover.jpg)

Wormate 多人对战是经典的贪吃蛇游戏，但加入了新皮肤。选择你的新蠕虫皮肤，点击开始，立即进入蠕虫战斗。与其他玩家对战，吃糖果来变得更大。如果你的头部碰到其他玩家，你就会爆炸，然后游戏结束。但如果其他玩家撞到你，他们就会死亡，而你可以吃掉他们留下的糖果残渣！一起来玩得开心吧！

## 怎么玩

鼠标或操纵杆控制你的蠕虫
