# 桥梁建造者

<a href="https://inkwengame.com/zh/games/bridge-builder" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bridge-builder/cover.jpg)

成为一名设计工程师，你需要随机应变，灵活应对各种任务。运用不同的材料建造能够支撑车辆重量的结构。

## 怎么玩

桌面端操作：拖动鼠标左键 = 建造桥梁

空格键 = 开始模拟

Z 键 = 撤销

双击鼠标左键 = 移除桥梁部件

移动端操作：

使用触摸屏和屏幕按键

## 介绍

成为一名设计工程师，你需要随机应变，灵活应对各种任务。运用不同的材料建造能够支撑车辆重量的结构。

游戏特色：

- 出色的物理引擎——逼真的模拟体验

- 四个不同场景的挑战关卡

- 需要运用思维和逻辑的挑战性谜题

- 内置提示系统，助你提升技能
