# 医院快跑

<a href="https://inkwengame.com/zh/games/hospital-hustle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hospital-hustle/cover.jpg)

《医院快跑》是一款超级有趣的管理游戏。通过接收病人并使用不同的机器为他们治疗来照顾所有病人。顺便说一下，你需要为机器运送资源，以确保机器正常运行。你还可以雇佣医生、工人、接待员，并升级员工的技能和能力。你头顶上有一个幸福度条，需要保持在最高水平。

## 怎么玩
