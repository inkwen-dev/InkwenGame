# 零钱：收银员模拟器

<a href="https://inkwengame.com/zh/games/loose-change-cashier-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/loose-change-cashier-simulator/cover.jpg)

一款轻松的硬币分类益智游戏，你需要按年份和面值排列硬币。规划好每一步，高效地清空棋盘，遇到困难时使用道具，并在每次游戏中刷新你的最高分。

## 怎么玩

拖动硬币将其移动到空位。按年份和面值对硬币进行排序，清除棋盘上已完成的硬币组，并尽可能多地保留步数和道具。
