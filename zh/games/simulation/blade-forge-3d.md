# 刀匠3D

<a href="https://inkwengame.com/zh/games/blade-forge-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blade-forge-3d/cover.jpg)

踏入《刀匠3D》的炽热熔炉，这是一款终极3D模拟休闲游戏。你将成为传奇铁匠，从零开始打造史诗武器。在匹配对手后，选择自己的模具，亲手打造属于自己的剑。通过在火焰中锻造刀刃来淬炼长剑。完成后，用这把剑与对手进行对决测试。精心打磨以提升你的伤害值。
