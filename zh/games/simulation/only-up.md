# Only Up!

<a href="https://inkwengame.com/zh/games/only-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/only-up/cover.jpg)

Only Up! 是一款令人兴奋的街机游戏，你需要克服障碍并征服高度。受到热门游戏的启发，你的任务是引导角色通过一个充满各种障碍的垂直迷宫。你必须反应迅速，准确跳跃，并灵巧地攀爬，以避免撞上障碍物并坠落。随着你在各个关卡中的推进，你会遇到越来越高的难度和新的挑战，例如移动平台和旋转障碍物。

## 怎么玩

PC 移动 - WASD 跳跃 - 空格键 暂停 - P 重新开始 - R 移动端 横屏操作通过屏幕上的虚拟摇杆进行
