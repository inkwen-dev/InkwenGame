# 忍者钓鱼

<a href="https://inkwengame.com/zh/games/ninja-fishing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ninja-fishing/cover.jpg)

忍者钓鱼是一款你需要将游来的鱼切成两半的游戏。选择模式进行游戏并注意观察鱼。它们会飞过你的屏幕，你需要将所有鱼都切开，如果有些鱼掉落，你将会失去一条生命。游戏中还有炸弹，你需要避开它们。

## 怎么玩

在屏幕上移动来玩这个游戏
