# 战争坦克世界

<a href="https://inkwengame.com/zh/games/world-of-wartanks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/world-of-wartanks/cover.jpg)

引人入胜的坦克动作游戏。选择你的坦克，完成任务并摧毁敌人。游戏包含多种任务、生存模式以及5v5对战。对军事题材感兴趣的每个人都会觉得这款游戏非常有趣！游戏中新增了多种坦克，可通过星星获得。升级坦克并完成任务。完成任务即可获得星星！第1个任务 = 1颗星 第12个任务 = 12颗星 5v5对战 = 10颗星

## 怎么玩

游戏目标是完成任务目标，摧毁敌方坦克。射击时，将瞄准镜对准坦克并右键点击。当目标被锁定时，瞄准镜会变为红色，当瞄准镜中出现红色圆圈时即可开火
