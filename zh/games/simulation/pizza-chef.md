# 披萨厨师

<a href="https://inkwengame.com/zh/games/pizza-chef" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pizza-chef/cover.jpg)

披萨厨师是一款非常独特的烹饪游戏。在这款游戏中，你将扮演一名披萨厨师，体验制作披萨的详细过程。你可以选择制作水果披萨或肉披萨。按照指示操作，你就能做出最美味的披萨。披萨烤好后，别忘了将其切成片，并喂给顾客。你将从顾客那里获得金钱。

## 怎么玩
