# 自由职业者模拟器

<a href="https://inkwengame.com/zh/games/freelancersim" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/freelancersim/cover.jpg)

你是否曾想过在家工作并赚钱？是的，今天我们就通过在家工作来自由职业并赚取金钱。我们可以靠打字输入所需文字，或者在电脑上引爆病毒来赚钱。我们可以用赚到的钱购买家居用品或为自己提供食物。如果你饿死了，一切将从头开始。

## 怎么玩

使用WASD键左右移动，也可使用移动端控制按钮
