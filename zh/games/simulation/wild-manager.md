# 野生经理

<a href="https://inkwengame.com/zh/games/wild-manager" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wild-manager/cover.jpg)

在《野生动物园经理》中，建造并管理你自己的色彩缤纷的3D动物园。漫步园中，建造动物栖息地，照顾动物，升级道路和设施，将小型动物园发展成为一个繁荣的野生动物目的地。

## 怎么玩

使用 WASD 键或方向键移动饲养员。在移动设备上，使用屏幕摇杆或点击屏幕进行移动。前往高亮区域建造和升级栖息地、收取收入、照顾动物并完成公园项目。完成所有升级即可达到 100% 公园完成度。

## 介绍
