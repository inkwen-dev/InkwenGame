# 木工

<a href="https://inkwengame.com/zh/games/woodcraft" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/woodcraft/cover.jpg)

木工是一款模拟游戏，让你掌握木工艺术！切割出所需的木块，喷漆制作属于你自己的独特作品。将你的作品卖给出价最高的人，购买酷炫的新磨床、电钻和喷枪！

## 怎么玩

在电脑上玩木工时，使用鼠标进行操作；在手机或平板上则使用点击操作
