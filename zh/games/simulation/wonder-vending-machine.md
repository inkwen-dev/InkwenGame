# 奇妙自动售货机

<a href="https://inkwengame.com/zh/games/wonder-vending-machine" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wonder-vending-machine/cover.jpg)

这款模拟游戏简单又非常有趣！在三种自动售货机中进行选择：一种售卖玩具，一种售卖甜点，还有一种售卖食物。每台自动售货机内的物品都有标价；你有一组硬币可供使用，需要投入与显示屏上显示金额相符的正确金额。如果正确，自动售货机就会吐出商品；如果错误，你会收到一条错误提示。收集所有物品后，你可以再次查看它们。

## 怎么玩

使用鼠标进行操作
