# 飞机模拟器 岛屿旅行

<a href="https://inkwengame.com/zh/games/airplane-simulator-island-travel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/airplane-simulator-island-travel/cover.jpg)

飞机模拟器：岛屿旅行是由CoolMathGamesKids.com团队开发的一款飞机模拟游戏。驾驶你的飞机，探索不同的美丽岛屿。有3种不同的飞机可供解锁，通过收集金币即可获得。这款游戏共有10个精彩关卡，等你来挑战。

## 怎么玩

使用方向键或ASWD键进行起飞、降落、左转和右转操作；使用鼠标滚轮控制飞机上下倾斜
