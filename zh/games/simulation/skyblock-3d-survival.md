# Skyblock 3D：生存

<a href="https://inkwengame.com/zh/games/skyblock-3d-survival" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skyblock-3d-survival/cover.jpg)

在3D世界中，踏上漂浮岛屿的独特生存冒险之旅，每个岛屿都蕴藏着丰富的资源。探索生机勃勃的景色，与怪物战斗以提升实力，并与村民交易获取实用物品。建造种植园，饲养动物，确保食物和资源的稳定供应。天空中遍布岛屿，每个岛屿都隐藏着秘密和挑战。在这个精彩纷呈的世界中生存、建造、战斗，并最终走向繁荣！

## 怎么玩

电脑端：

- 移动：W、A、S、D

- 跳跃：空格键

- 破坏方块：按住鼠标左键

- 放置方块：鼠标右键 / F

- 打开物品栏：E

- 暂停：Tab

- 帮助：J

- 丢弃：Q（Shift+Q 丢弃满格物品）

移动设备端：

- 移动：左摇杆

- 跳跃：箭头图标按钮

- 破坏方块：按住剑图标按钮

- 堆叠方块：按住叉号图标按钮

- 打开物品栏：屏幕中央的橙色按钮

- 暂停：屏幕右上角的紫色按钮
