# 车库老板

<a href="https://inkwengame.com/zh/games/garage-boss" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/garage-boss/cover.jpg)

《车库老板》是一款放置类大亨游戏，你将在一个互联的世界中，把一个小型维修车间发展成集车库、超市和加油站于一体的综合性商业帝国。雇佣工人，升级所有设施，看着你的迷你帝国自动运转，而你只需点击屏幕、走动、扩张即可。

## 怎么玩

在电脑上用 WASD 键移动，或者点击屏幕任意位置启动摇杆，摇杆会跟随你的手指移动。点击车辆进行修理，走到工人面前领取他们的工资，打开电话菜单雇佣员工，购买升级项目来扩建你的车库、超市和加油站。
