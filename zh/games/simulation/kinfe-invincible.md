# Kinfe 无敌

<a href="https://inkwengame.com/zh/games/kinfe-invincible" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kinfe-invincible/cover.jpg)

这是一款简单又有趣的休闲游戏，游戏中像真正的厨师一样切蔬菜，按住屏幕挥动厨房刀具，每一关都有不同的蔬菜，完成清除目标即可。游戏有点像水果忍者，难度不大，但仍需极快的手速，玩家需要做的就是控制手中的厨房刀，在传送带上将所有蔬菜切成薄片，非常解压。

## 怎么玩

虽然屏幕上蔬菜会快速移动，但无需持续按住屏幕。游戏考验反应力，除了砧板上的食材外，还会出现障碍物，如果切错会损失时间
