# 狼模拟器3D

<a href="https://inkwengame.com/zh/games/wolf-simulator-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wolf-simulator-3d/cover.jpg)

狼是速度非常快且力量强大的动物。在这个模拟器中，你将扮演一只狼。你需要猎捕动物并照顾自己的家庭。创建属于你的狼，踏上冒险之旅。猎捕动物，组建家庭，提升你的狼以及家庭成员的能力。完成各种任务，变得更强。了解成为一只狼意味着什么！

## 怎么玩

按 W A S D 键控制狼的移动 鼠标点击 - 射击 空格键 - 跳跃
