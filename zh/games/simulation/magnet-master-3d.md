# 磁力大师 3D

<a href="https://inkwengame.com/zh/games/magnet-master-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magnet-master-3d/cover.jpg)

掌控一个强大的工业磁铁，清理院子！收集金属废料，将其运送到出售区域，将每一批货物变成现金。升级你的磁铁的功率、范围、容量和价值，以举起更重的物体并获得更大的奖励。解锁新区域，发现有价值的废料，并不断改进你的机器，直到没有任何东西太重无法收集！

## 怎么玩

桌面 使用 WASD 或方向键移动磁铁 收集金属废料并将其带到出售区域 移动和收集废料 手机 使用虚拟摇杆移动并收集废料 提示 出售货物后升级 功率 范围 容量 和 价值 提高功率以举起更重的物体
