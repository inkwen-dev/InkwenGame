# 鱼趣盛宴

<a href="https://inkwengame.com/zh/games/fishy-feast" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishy-feast/cover.jpg)

《鱼趣盛宴》是一款快节奏的水下生存游戏，你将操控一条卡通鱼在五彩斑斓的海洋世界中冒险。规则简单却极具吸引力——吃比自己小的鱼来成长，避开比自己大的鱼，否则游戏结束！从一条微小的鱼开始，你的目标是攀登食物链顶端，尽可能长大，并在被更大的生物一口吞下之前，创下最高得分纪录。

## 怎么玩

鼠标移动你的鱼会跟随光标触摸拖动在移动设备上，点击并拖动以移动W A S D上下左右移动方向键与WASD相同空格键或Esc键暂停/继续游戏
