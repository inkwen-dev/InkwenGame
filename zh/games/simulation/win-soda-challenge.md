# 赢得汽水挑战

<a href="https://inkwengame.com/zh/games/win-soda-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/win-soda-challenge/cover.jpg)

一款充满乐趣的休闲益智游戏。玩家需要灵活操作汽水罐，将迷宫中的方块涂色。不同颜色的方块会产生不同的化学反应，汽水罐提供了大量任务来挑战你，尤其考验你的反应速度和手速，整个操作使用起来并不困难。

## 怎么玩

用鼠标点击相邻的管道连接处进行修复，管道接通后汽水汇集在一起即可饮用
