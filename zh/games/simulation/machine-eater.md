# 机器吞噬者

<a href="https://inkwengame.com/zh/games/machine-eater" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/machine-eater/cover.jpg)

利用收集到的资源建造方块，扩建你的飞船，并在雷达上锁定敌人之前，在建造的方块上策略性地放置具有不同功能的建筑。运用你的策略技巧消灭雷达上探测到的敌人。从敌人身上收集的建筑将丰富你的策略。

## 怎么玩

操作方式

使用 WASD / 方向键 / 鼠标移动角色。
