# 爆米花 爆

<a href="https://inkwengame.com/zh/games/popcorn-pop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/popcorn-pop/cover.jpg)

这是一款基于制作爆米花的游戏，具有简单的机制、轻松的控制、商店和关卡。游戏简单易上手，控制条来爆开玉米，将其变成爆米花以填满袋子。通过获得分数来解锁小玉米的新皮肤，通过升级来解锁新条。已解锁的皮肤会带来新的加成，新条则拥有特殊能力。通过获得金色硬币，还可以购买新的爆米花袋。

## 怎么玩

点击或触摸以移动
