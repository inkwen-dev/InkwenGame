# 钓鱼方块

<a href="https://inkwengame.com/zh/games/fishing-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishing-blocks/cover.jpg)

《钓鱼方块》是一款令人上瘾的方块消除益智游戏，你将拥有一块移除方块。你可以通过点击或轻触屏幕来移动移除方块。当移除方块与相同的鱼形方块匹配时，整行方块将会被删除。请勿让方块触及上方边界，否则游戏结束。随着方块快速向上移动，持续消除行。你可以使用减速道具，减缓方块的移动速度。

## 怎么玩

使用鼠标或触控板移动移除方块，并将其与相同的鱼形方块匹配，这将移除整行
