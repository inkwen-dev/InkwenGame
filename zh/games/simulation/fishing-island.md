# 渔岛

<a href="https://inkwengame.com/zh/games/fishing-island" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishing-island/cover.jpg)

将一座小码头改造成一座巨型自动化渔港！在码头尽头垂钓，将渔获运到市场摊位，看着顾客排起长队。开辟从海中升起的新陆地，雇佣渔民、伐木工和搬运工，运营传送带、熏肉房和寿司店，并将海滩烧烤店发展成一家拥有厨师的温馨咖啡馆。完成船舶订单，收集16种鱼类和金鱼，航行于四座岛屿之间——从温暖的海湾到冰冷的港湾…

## 怎么玩

在屏幕上任意位置拖动即可行走（或使用 WASD/方向键）。站在码头尽头的鱼圈上钓鱼，将渔获放在摊位（绿色箭头区域），并从蓝色箭头区域拾取物品。从桌子上收集金币，并站在价格区域建造站点、雇佣工人并开垦新土地。前往装备商店升级你的篮子、靴子和鱼竿。实现整个岛屿的自动化，即可航行至下一个岛屿。“菜单”按钮显示岛屿统计数据和设置。
