# 制作甜甜圈 - 烹饪游戏

<a href="https://inkwengame.com/zh/games/make-donut-cooking-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/make-donut-cooking-game/cover.jpg)

为孩子们制作最美味的甜甜圈！你需要揉面团。然后使用模具在面团上切出各种形状。你可以同时制作不同形状的甜甜圈。油炸完面团后，给甜甜圈加上果酱、糖和巧克力。甜甜圈完成后，选择你最喜欢的盒子，装饰它来包装甜甜圈。尽情享受吧！
