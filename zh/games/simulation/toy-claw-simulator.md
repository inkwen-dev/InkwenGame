# 玩具抓取模拟器

<a href="https://inkwengame.com/zh/games/toy-claw-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/toy-claw-simulator/cover.jpg)

玩具抓取模拟器是一款有趣且令人上瘾的街机游戏，你将操控一个虚拟的抓娃娃机，收集各种可爱的玩具！仔细瞄准并把握时机，用机械爪抓住毛绒玩具、动作人偶和惊喜收藏品。当你积攒了足够的玩具后，前往工厂将它们出售以换取闪亮的硬币！用赚到的钱运行机器，使用吊臂解锁更多玩具。这是一款融合了技巧、策略与奖励性进展的迷人游戏！

## 怎么玩

桌面端 使用WASD或方向键移动吊臂 空格键抓取玩具 移动端 用手指触摸并滑动以移动吊臂 点击红色按钮抓取玩具
