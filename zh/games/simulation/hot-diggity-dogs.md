# 热狗

<a href="https://inkwengame.com/zh/games/hot-diggity-dogs" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hot-diggity-dogs/cover.jpg)

一款轻松愉快的烹饪游戏，讲述你在公园里经营一辆热狗餐车的故事。你可以烤香肠或煮香肠，把面包拖进餐车，然后挤上番茄酱、芥末酱和其他配料，游戏采用真实的物理引擎。每个顾客都有自己的小秘密口味：发挥你的创造力，了解每个常客的喜好和厌恶，创造属于你自己的独家配方，并随着餐车的生意越做越大，不断装饰你的餐车。

## 怎么玩

将面包卷拖入纸船，然后将香肠拖到烤架上（底部变成金黄色时点击翻面）或拖入沸腾的锅中。将烤好的香肠拖到面包卷上，然后拿起酱料瓶沿着热狗涂抹，并撒上或放上配料。向上滑动热狗（或点击绿色箭头）即可在窗口为顾客服务。制作顾客要求的，或给他们一些惊喜：他们会根据自己的口味做出反应。每次轮班都能赚取金币和星星，然后在商店购买食材、升级和货车装饰。支持鼠标和触摸操作。
