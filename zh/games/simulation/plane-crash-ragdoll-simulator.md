# 飞机坠毁布娃娃模拟器

<a href="https://inkwengame.com/zh/games/plane-crash-ragdoll-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/plane-crash-ragdoll-simulator/cover.jpg)

《飞机坠毁布娃娃模拟器》是一款3D飞机游戏，你将扮演一位无畏的飞行员。你的任务是在敌人的猛烈攻击下生存下来。游戏看似简单，却能让你肾上腺素飙升，体验向敌人发射火箭弹、穿梭于险象环生的天空的刺激快感。你可以操控各种飞机和直升机，解锁并自定义独特的涂装。你的目标是成功抵达终点，但要小心，一旦坠地，你的飞机就会爆炸！

## 怎么玩

按住操纵杆启动引擎，拖动即可控制飞机。节省燃料，摧毁敌人，赚取金币来升级你的飞机。
