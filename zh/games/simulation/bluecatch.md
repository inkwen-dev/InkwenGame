# BlueCatch

<a href="https://inkwengame.com/zh/games/bluecatch" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bluecatch/cover.jpg)

BlueCatch 是一款游戏，玩家扮演一只猫去钓鱼，需要从海里捕捉鱼类或珍贵物品。一旦你捕获到东西，它就会飞向空中，你需要点击/触摸它来获得分数。尽情享受吧！

## 怎么玩

点击以捕捉珍贵物品，并通过拖动来引导锚点。当物品在空中时点击它以获得分数
