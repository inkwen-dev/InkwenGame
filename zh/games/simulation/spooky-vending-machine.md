# 幽灵自动售货机

<a href="https://inkwengame.com/zh/games/spooky-vending-machine" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spooky-vending-machine/cover.jpg)

幽灵自动售货机是一款精彩的游戏，通过游戏帮助您的孩子学习数学！在三个自动售货机中进行选择：一个售卖玩具，一个售卖甜点，一个售卖食物；每个自动售货机内的物品都有价格，您有一组硬币可供使用，将正确的金额插入，您可以在屏幕上看到金额，如果正确，自动售货机就会释放物品，如果错误，您将收到一条错误消息。

## 怎么玩

只需点击触摸即可开始游戏
