# 建造者

<a href="https://inkwengame.com/zh/games/constructor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/constructor/cover.jpg)

城市建造是一款类似模拟城市的都市建设游戏。玩家扮演游戏城镇管理者，打造属于自己的独特城市。游戏中包含众多精彩独特的建筑内容以及生动居民的反馈生产系统。城市能否建得更好？快来体验吧

## 怎么玩

以下技能可供使用：收入加速、工人等。点击加速可加快工人等速度。点击工人可增加处理人员
