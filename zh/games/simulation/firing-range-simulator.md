# 射击场模拟器

<a href="https://inkwengame.com/zh/games/firing-range-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/firing-range-simulator/cover.jpg)

你有没有想过只是随意走动并射击东西？现在你可以做到了！在这个模拟游戏中，你身处射击场，将从一把手枪开始。你可以在地图上自由移动，并有目标可供射击。在墙上可以拾取新的酷炫武器，如霰弹枪、M16、狙击枪和榴弹发射器。试试它们，尽情享受乐趣吧！

## 怎么玩

WASD - 移动 鼠标 - 看周围 左键 - 射击 右键 - 瞄准 Q - 切换武器 F - 聚焦缩放 空格键 - 跳跃 左Shift键长按 - 快跑 Tab - 菜单
