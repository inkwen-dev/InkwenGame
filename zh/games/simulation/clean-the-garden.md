# 清理花园

<a href="https://inkwengame.com/zh/games/clean-the-garden" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/clean-the-garden/cover.jpg)

逐一清理落叶覆盖的土地。收集落叶，将它们运送到堆肥箱，兑换成金币，然后用赚来的金币提升移动速度、增加负重能力，并购买更强大的工具。

## 怎么玩

- 键盘：使用 WASD 或方向键移动，空格键跳跃，E 键互动，B 键开启升级，H 键高亮显示剩余树叶，1-4 选择工具，Q 键切换工具，Tab 键暂停，Esc 键关闭已打开的菜单或继续游戏。

- 鼠标：移动或拖动鼠标环顾四周，按住鼠标左键使用当前工具，使用鼠标滚轮切换工具。

- 触控：使用左摇杆移动，向右滑动查看四周，使用屏幕上的按钮收集树叶或互动、高亮显示剩余树叶、跳跃、切换工具、开启升级以及暂停游戏。

## 介绍

逐一清理落叶覆盖的土地。收集落叶，将它们运送到堆肥箱，兑换成金币，然后用赚来的金币提升移动速度、增加负重能力，并购买更强大的工具。

游戏开始时你只能徒手清理，随着前花园、后院、果园和公园区域的大门一一开启，你将解锁耙子、干草叉和吹叶机等工具。完成目标，在工具站升级每种工具，清理每个区域，并可选择保留或重置升级后的游戏进度。
