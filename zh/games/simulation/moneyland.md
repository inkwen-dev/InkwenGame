# Moneyland

<a href="https://inkwengame.com/zh/games/moneyland" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/moneyland/cover.jpg)

Moneyland 是一个充满无限金钱和一些建筑的岛屿。你的目标是收集足够的金钱，以解锁并完成房屋和车辆的建造。岛上的所有人都在等待你完成建筑工程。保持冷静，继续收集更多金钱！
