# 鬣狗模拟器3D

<a href="https://inkwengame.com/zh/games/hyena-simulator-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hyena-simulator-3d/cover.jpg)

《鬣狗模拟器3D》是一款动物模拟游戏，玩家将扮演一只鬣狗，在10个不同任务中完成各种挑战，难度会逐渐增加。下一个任务的指示将由一只模拟执行任务的鬣狗给出。准备好攻击你的敌人并击败他们，以获得更多的分数。

## 怎么玩

WASD 或方向键 - 移动 用数字键 1、2 和 3 或 Shift 键切换鬣狗的速度 左键鼠标 - 攻击你的敌人
