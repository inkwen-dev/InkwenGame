# K-游戏挑战

<a href="https://inkwengame.com/zh/games/k-games-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/k-games-challenge/cover.jpg)

K Games Challenge 用于重演著名电影《鱿鱼游戏》中的游戏。在3D游戏引擎下，您可以与AI对手一起玩绿灯红灯、蜂蜜糖、拔河、弹珠、踏石过河以及SP游戏。采用街机玩法规则和操作方式，您可以在有限时间内轻松赢得所有游戏。例如弹珠游戏，您需要在六次机会内将弹珠投入洞中。您只能在绿色区域完成关卡。祝您好运！
