# 挑战热辣椒3D

<a href="https://inkwengame.com/zh/games/challenge-hot-chili-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/challenge-hot-chili-3d/cover.jpg)

这是一款以吃辣椒为主题的休闲游戏。在游戏中，玩家将体验到选择类休闲游戏，以及模拟体验类游戏和有趣的解压跑酷游戏等多种游戏类型。通过各种方式，关卡中的角色将持续食用世界上最刺激的辣椒，获得极致的辣味体验。

## 怎么玩

游戏操作非常简单，玩家只需使用鼠标从所有食物中选择辣椒即可。逼真的游戏场景为玩家带来沉浸式的乐趣。此外，角色吃辣椒后的反馈也十分生动
