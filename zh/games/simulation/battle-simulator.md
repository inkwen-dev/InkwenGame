# 战斗模拟器

<a href="https://inkwengame.com/zh/games/battle-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/battle-simulator/cover.jpg)

你需要组建一支军队以击败敌方部队。你可以从三种不同类型的士兵中进行选择，并需要在地图上战略性地部署它们以取得胜利。

## 怎么玩

使用 WASD 键或方向键移动相机，右键鼠标拖动以旋转相机，鼠标滚轮缩放
