# 机场安检3D

<a href="https://inkwengame.com/zh/games/airport-security-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/airport-security-3d/cover.jpg)

《机场安检3D》是一款采用3D卡通模型的机场安检模拟游戏。你的任务是逮捕持有假身份证明和武器的罪犯，同时放行普通民众。在柜台处，你需要核对乘客姓名及其对应的身份证件。在安检口，你必须检查他们的行李，找出携带武器的罪犯。最后，你可以对罪犯进行审问。
