# 废品场主人

<a href="https://inkwengame.com/zh/games/junkyard-keeper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/junkyard-keeper/cover.jpg)

进入《废品场主人》，你将成为一家废品场的老板。利用回收物品创造令人惊叹的新机械装置。这是一款创意模拟游戏，你需要通过收集废弃车辆和零件来组装新的机械设备。在废品场中驾驶车辆，收集旧零件，并将它们运回你的基地。
