# 完美舌头

<a href="https://inkwengame.com/zh/games/perfect-tongue" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/perfect-tongue/cover.jpg)

完美舌头是一款休闲减压游戏。在游戏中，你需要用你的长舌头吃更多食物，但不要吃危险道具。你需要避开这些危险道具，以确保能够快速完成进食，游戏中还有多条道路供你使用。
