# 飞机飞行模拟器

<a href="https://inkwengame.com/zh/games/airplane-flying-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/airplane-flying-simulator/cover.jpg)

飞行模拟3D是一款全新的3D飞机模拟游戏，成为飞行员并驾驶你的商用飞机到达目的地。引导并操控你的飞机通过所有航点，确保你前往正确的目的地，经过所有航点并在时间限制内降落在目的地机场，以获得更多的飞行员徽章。

## 怎么玩

使用鼠标和方向键进行飞行
