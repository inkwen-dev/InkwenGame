# 猴子商店游戏

<a href="https://inkwengame.com/zh/games/monkey-mart-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monkey-mart-game/cover.jpg)

猴子商店是由TinyDobbins制作的一款休闲/管理类游戏。你将控制一只可爱的猴子角色，它刚刚开了一家超市。种植水果，从一个站台移动到另一个站台，为摊位摆放香蕉或玉米等商品，或者更多。顾客会来取走商品，并在收银台等待你。你可以升级你的角色，解锁新的工作台，甚至招募其他员工来帮你管理商店！

## 怎么玩

移动 - WASD 或方向键
