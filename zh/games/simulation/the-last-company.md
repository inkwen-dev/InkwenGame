# 最后的公司

<a href="https://inkwengame.com/zh/games/the-last-company" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-last-company/cover.jpg)

《最后的公司》是一款3D奇幻策略角色扮演游戏，玩家需要招募英雄，组建队伍，并努力生存下去。在村庄中做好准备，选择下一场战斗，然后观看你的决策在自动战斗中如何展开。金币稀缺，敌人愈发危险，阵亡的英雄将永远消失。

## 怎么玩

鼠标左键：选择建筑、英雄、装备和菜单选项。

在村庄或角色预览中点击并拖动：旋转视角。

在村庄或角色预览中滚动鼠标滚轮：放大或缩小。

战斗前：将英雄头像拖到 3x3 网格上，或点击头像后点击一个方格。

战斗中：使用屏幕上的按钮暂停、继续或更改战斗速度。

Esc 键：关闭菜单或从建筑返回村庄。

战斗是自动进行的。您只需在战斗前准备并部署您的英雄；无需手动移动或攻击。
