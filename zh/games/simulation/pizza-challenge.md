# 披萨挑战

<a href="https://inkwengame.com/zh/games/pizza-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pizza-challenge/cover.jpg)

喜欢披萨又不想分享的人，你们在吗？尝试在朋友之前按顺序抢到送到你桌上的各种披萨片。你应该将披萨片正中间握住才能抓取。谁先抢到每张披萨的5片，谁就赢得比赛。你可以和朋友或电脑进行这场较量。战斗开始吧。

## 怎么玩

玩家1：W 键；玩家2：上箭头键；此外，你也可以在触控设备上玩这个游戏
