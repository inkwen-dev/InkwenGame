# 剩余螺丝

<a href="https://inkwengame.com/zh/games/leftover-screw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/leftover-screw/cover.jpg)

一款组装平板家具的益智游戏。五十个关卡，每个关卡都是一件家具，从凳子到双层床，每件家具都以零件堆的形式出现。零件通过孔洞的交汇处进行组装，因此可能会装错。每个螺丝都是一个计时按钮：指针停在绿色区域，否则面板会裂开。星星可以解锁三个带有独特机制的奖励零件。

## 怎么玩

将零件拖到另一个零件上，并在绿色幽灵出现时松开。使用零件旁边的按钮或键盘上的 R 和 F 键旋转零件。当指针指向绿色区域时，点击即可拧紧螺丝。红色区域表示面板破裂。安装所有零件即可完成组装。
