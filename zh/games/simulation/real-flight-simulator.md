# 真实飞行模拟器

<a href="https://inkwengame.com/zh/games/real-flight-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/real-flight-simulator/cover.jpg)

真实飞行模拟器是一款拥有3D模型的飞机驾驶模拟游戏。在6个关卡中，你可以学习如何驾驶飞机，包括启动、转向和降落。所有复杂的仪表盘都已简化，便于玩家学习。你驾驶的飞机越昂贵，就能享受更好的加速性能，包括动力、速度、解决方案和刹车。祝你在天空中好运！

## 怎么玩

鼠标点击或轻触开始游戏
