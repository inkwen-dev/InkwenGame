# 吹叶机大亨

<a href="https://inkwengame.com/zh/games/leaf-blower-tycoon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/leaf-blower-tycoon/cover.jpg)

将杂乱的秋日花园变成生意兴隆的落叶清理基地。用吹风机将五彩缤纷的落叶吹到收集篷布上，把装满落叶的袋子搬到卡车上，然后用赚来的钱购买更强劲的吹风机、更大的袋子和更得力的工人。清理七个不同的区域，完成任务，解锁新设备，并以永久奖励开启新的一季。享受令人满意的 3D 落叶物理效果和色彩鲜艳的卡通场景，按照自己的节奏畅玩。

## 怎么玩

桌面端：使用 WASD 键或方向键移动。移动端：在花园中拖动即可使用悬浮摇杆移动。移动时，吹风机会自动工作。将落叶推到蓝色防水布上，收集袋子并送到销售点。站在升级垫和助手垫上可以提升你的生意。清理一片区域即可解锁下一个地点。打开设置可以切换声音、音乐或鼠标移动选项。可选视频提供额外奖励；所有区域均可畅玩，无需广告或购买。
