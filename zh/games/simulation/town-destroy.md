# 城镇摧毁

<a href="https://inkwengame.com/zh/games/town-destroy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/town-destroy/cover.jpg)

城镇摧毁是一款难度较高的游戏，适合有耐心的人游玩。在游戏中，你需要非常小心地摧毁房屋，以免碎片掉落平台

## 怎么玩

在屏幕上选择所需威力的炸弹，然后用鼠标点击目标位置谨慎引爆房屋，同时可使用鼠标旋转摄像机
