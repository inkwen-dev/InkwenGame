# Tiny Fishing

<a href="https://inkwengame.com/zh/games/tiny-fishing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tiny-fishing/cover.jpg)

点击旋转器来设定你的抛投距离。然后点击并拖动以左右滑动鱼钩，捕捉一些鱼。当你的钓线到达水面时，你将获得所有捕获鱼类的现金！在每次抛投之间用这些钱升级你的技能并获取新的鱼钩。提示：即使你离开游戏，仍然会持续赚取现金！
