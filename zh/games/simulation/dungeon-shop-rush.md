# 地牢商店速攻

战士、法师、盗贼以及其他九种英雄在你的柜台前排起了长队，每个人都行色匆匆。在他们失去耐心之前，将合适的剑、药水或卷轴拖到每位英雄手中，让他们连成连击以获得更高的小费，并在发光的附魔台上为商品附魔以获得双倍报酬。

## 怎么玩

将物品从货架拖到下单的英雄身上，或者点击物品再点击英雄。标有“已附魔”的订单需要先使用附魔台：将普通物品放在附魔台上，稍等片刻，然后将发光的物品拖到英雄身上。点击空物品即可补充。连续为英雄服务可以提升连击数并开启连击宝箱。达到当班金币目标的一半即可过关，达到全部目标即可获得三星评价。在班次之间，可以使用金币购买升级和商品。

操作方式：鼠标或触摸（拖放或点击）。按 Esc 键暂停班次。

## 介绍

战士、法师、盗贼以及其他九种英雄在你的柜台前排起了长队，每个人都行色匆匆。在他们失去耐心之前，将合适的剑、药水或卷轴拖到每位英雄手中，让他们连成连击以获得更高的小费，并在发光的附魔台上为商品附魔以获得双倍报酬。

在轮班间隙，选择一个改变规则的合约，用18种商品填满你的货架，获得新商品的授权，并用你的金币升级：更友好的柜台、更大的货架、更快的补货速度以及更划算的定价标签。用新的墙壁、柜台、灯光和装饰翻新你的商店，充实你的英雄、商品和遗物收藏，并完成每日、每周和公会任务。

随着你的声望提升，轮班会越来越繁忙，而声望永无止境地增长。攀登“最佳轮班”排行榜，向世人展示谁才是地牢中最棒的商店老板！
