# 字母厨房

<a href="https://inkwengame.com/zh/games/alphabet-kitchen" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/alphabet-kitchen/cover.jpg)

通过在厨房里制作字母饼干并装饰它们，厨师艾尔莫帮助孩子们学习元音。通过将字母组合起来形成单词，芝麻街的朋友们帮助你的孩子‘烘焙’出美味的三字母和四字母单词饼干。
