# 闲置塔楼建造者

<a href="https://inkwengame.com/zh/games/idle-tower-builder" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/idle-tower-builder/cover.jpg)

你负责建造世界上最高的塔楼。收集或生产必要的资源，实现你的目标！通过在采石场开采资源并加工成砖块来建造塔楼。每一层塔楼都需要更多的砖块，因此要明智地升级你的生产设施。为了将砖块运送到塔楼的更高楼层，你需要一台起重机。你可以用木板建造起重机，而木板则可以在锯木厂用木材制作。

## 怎么玩

按住鼠标按钮以启动设施，定期在市场出售资源以获取升级资金
