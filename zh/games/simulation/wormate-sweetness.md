# Wormate Sweetness

<a href="https://inkwengame.com/zh/games/wormate-sweetness" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wormate-sweetness/cover.jpg)

Wormate Sweetness 是经典的贪吃蛇游戏，但加入了新皮肤。选择你的新蠕虫皮肤，点击开始，立即进入蠕虫对决。与其他玩家对战，吃糖果让自己变得更大。如果你的头部碰到其他玩家，你将爆炸，游戏结束。但如果其他玩家撞到你，他们就会死亡，你可以吃掉他们留下的糖果！一起来玩吧！
