# Fishing.io

<a href="https://inkwengame.com/zh/games/fishing-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishing-io/cover.jpg)

在这个有趣且易于上手的游戏中，你将成为史上第一位抵达海洋底部的渔夫。收集鱼类和宝藏，购买渔网升级，以到达更深的水域。寻找被困在海中的更多角色，并尝试填满你的奖杯室。体验这一切，尽享精美的艺术风格。

## 怎么玩

尽可能多地捕捉鱼和宝藏，升级你的渔网以捕获更多鱼，提高它们的价格，并深入更深处。寻找更多被困在海洋中的角色，填满你的奖杯室
