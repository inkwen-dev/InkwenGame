# 厨房分类

<a href="https://inkwengame.com/zh/games/kitchen-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kitchen-sorting/cover.jpg)

厨房分类使用了众所周知的球类和水类分类游戏机制。在您舒适的厨房里，将烹饪食材分类放入玻璃罐中。分类完成后，将它们倒入锅中烹制美食。

## 怎么玩

点击罐子以从顶部选取一个或多个相同类型的食材；点击另一个罐子以将它们倒入。
只能将食材倒入相同类型食材的顶部或空罐中。
您也可以通过从源罐滑动到目标罐的方式来操作，而无需点击。
