# 混合果汁

<a href="https://inkwengame.com/zh/games/mixed-juice" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mixed-juice/cover.jpg)

最新版的混合水果果汁大师新鲜爽口。你可以用手指完成各种操作，享受指尖的乐趣，非常有趣。玩家在这里将拥有自己的工具，制作出不同口味的水果汁。

## 怎么玩

用手挤压水果到榨汁机中，注意不要伸得太远，否则容易受伤。足够的水果混合并榨汁后，可以制作出不同颜色和口味的果茶
