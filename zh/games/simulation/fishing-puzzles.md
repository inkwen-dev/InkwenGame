# 钓鱼谜题

<a href="https://inkwengame.com/zh/games/fishing-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishing-puzzles/cover.jpg)

这是一款棋盘益智游戏，你需要移除棋盘上的所有鱼。点击同一行或同一列中两个相同的鱼，将会捕获这两个鱼之间的所有鱼，包括它们本身。共有24个挑战。

## 怎么玩

使用鼠标或触摸板来玩这个游戏
