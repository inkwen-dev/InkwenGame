# 跳跃堆叠方块3D

<a href="https://inkwengame.com/zh/games/jump-stacky-cube-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jump-stacky-cube-3d/cover.jpg)

这是一款供你游玩的方块跳跃街机游戏。拥有3D方块和平台，你需要在赛道上收集与你的方块数量相同的方块，才能到达终点平台。黑色平台会减少你当前的一个方块。只有当你收集完所有方块并跳到终点平台时，才能赢得对应关卡！

## 怎么玩

拖动以移动
