# 身体下落

<a href="https://inkwengame.com/zh/games/body-drop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/body-drop/cover.jpg)

身体下落是一款充满刺激的游戏，拥有真实的物理效果和出色的三维图形，在游戏中你需要通过从不同结构上掉落玩偶来测试其身体的强度！

## 怎么玩

你需要将球体发射到玩偶身上，以对其造成最大程度的伤害。操作通过鼠标进行。左键点击发射球体，右键 - 摄像机旋转，鼠标滚轮 - 摄像机缩放
