在《WildBlocks》中，打造属于你自己的微型生活世界。这是一款温馨的体素冒险游戏，带你探索、建造，最终建成一个属于自己的家园。

## 怎么玩

选择“新世界”开启冒险之旅，或选择“建造家园”使用无限材料进行创作。在“生存”模式下，完成初始任务，收集木材和其他资源，然后打开背包和配方书制作工具和实用物品。建造庇护所、种植作物、准备食物，探索并改善你的家园。瞄准物品即可使用，并将你常用的工具放在快捷栏中。

桌面：使用 WASD 键移动，使用鼠标环顾四周。按空格键跳跃，Shift 键冲刺，Ctrl 或 C 键蹲伏。按住鼠标左键砍伐、挖掘或攻击。使用鼠标右键放置方块或使用你手中的物品。按 F 键互动，E 键打开背包和配方书，J 键打开日志，M 键打开地图，Esc 键打开暂停菜单。使用 1-9 键或鼠标滚轮选择快捷栏物品。出现提示时，点击游戏画面以捕获鼠标。

手机或平板电脑：将设备横屏。使用左摇杆移动，拖动屏幕右侧环顾四周。点击屏幕即可使用选中的物品，按住屏幕可破坏方块。使用屏幕按钮进行跳跃、放置、互动和打开背包。点击快捷栏槽位选择物品。游戏内的“玩法指南”会解释触摸控制和各种模式。

建造家园：按 B 键打开目录，选择材料或物品，然后使用建造工具放置和塑造你的家园。R 键旋转，X 键选择移除工具，Ctrl+Z / Ctrl+Y 撤销和重做。在触摸设备上，使用工具抽屉和屏幕操作。打开“玩法指南”查看完整的建造指南。

结束游戏后，使用“保存并退出到菜单”。选择“继续”或选择一个已保存的世界即可返回。多人游戏需要网络连接；创建或加入房间并与好友分享房间代码。

桌面控制参考

| 操作 | 默认控制 |

| --- | --- |

| 移动/视角 | WASD / 鼠标 |

| 跳跃/冲刺/蹲伏 |空格键 / Shift / Ctrl 或 C |

| 砍伐、挖掘、破坏或攻击 | 按住鼠标左键 |

| 放置方块或使用手中物品 | 鼠标右键 |

| 与物体和生物互动 | F |

| 背包和配方书 | E |

| 选择快捷栏物品 | 1-9 或鼠标滚轮 |

| 日志/地图 | J / M |

| 第一人称/第三人称视角 | V |

| 自由光标/返回鼠标视角 | 反引号 |

| 暂停菜单 | Esc |

以上为默认按键绑定。玩家可在“设置”→“控制”中更改支持的按键绑定。“建造家园”和“死亡竞赛”模式在游戏内指南中也有特定模式的按键绑定。

## 介绍

在《WildBlocks》中，打造属于你自己的微型生活世界。这是一款温馨的体素冒险游戏，带你探索、建造，最终建成一个属于自己的家园。

漫步于草地、森林、河流、洞穴和远古遗迹之间。砍伐树木，收集资源，制作工具，种植作物，烹饪食物，结识与你共享世界的生物。建造庇护所，布置你的家，并在发现新地点和完成任务的过程中不断完善你的家园。选择“和平”难度，享受更轻松的冒险，或者挑战荒野的艰险。

想要专注于创造？“建造家园”模式为你提供无限的建筑材料和专属工具，用于建造墙壁、房间、屋顶、家具、花园等等。漫步于你的作品之间，保存蓝图，不断打造你的梦想家园。

独自探索，邀请好友一起建造，或尝试多人对战。保存你的世界，随时返回继续你的冒险。你的下一个发现就在不远处！
