# 独家新闻帝国

![cover](https://img.inkwengame.com/games/scoop-empire/cover.jpg)

经营你自己的冰淇淋店，把它发展成一个冰淇淋帝国！服务顾客，赚取现金，解锁新房间，招募员工，研发新口味，并在得来速窗口为顾客提供服务。开设一家路边咖啡馆，收集漂浮的强化道具，例如速度鞋、现金磁铁和涡轮机，并与旅行商人和供应商见面，获得惊喜优惠。穿越从阳光小镇到游乐园的五个世界，每个世界都有其独特的菜单，并攀登全球排行榜！

## 怎么玩

目标：打造最大的冰淇淋帝国，解锁全部 5 个世界。

使用 WASD/方向键移动，或在屏幕上拖动（移动设备）。

1. 从机器中拿起冰淇淋，放到柜台上。

2. 站在收银台为顾客服务，然后收取现金。

3. 站在价格方块上解锁机器、桌子、房间和员工。

4. 清理脏桌子，并将垃圾或多余的物品扔进垃圾桶。

5. 走到漂浮的能量道具上获得限时加速，并前往门口的商人处和免下车通道旁的供应商处获取特价优惠。

6. 解锁“下一个地点”前往新世界。

使用鼠标滚轮/捏合手势缩放。点击奖杯按钮查看排行榜。
