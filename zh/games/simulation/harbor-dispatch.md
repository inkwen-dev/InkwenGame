# 港口快讯

<a href="https://inkwengame.com/zh/games/harbor-dispatch" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/harbor-dispatch/cover.jpg)

在色彩缤纷的直升机救援游戏《港口调度》中操控你的直升机。飞越沿海公路和岛屿水域，营救被困人员，并将他们安全送往医院。升级你的直升机，搭载更多乘客，飞行速度更快。你每五分钟的轮班能救出多少人？

## 怎么玩

使用 WASD 或方向键飞行，按住鼠标左键前往目的地，或在触摸屏上拖动鼠标。松开鼠标即可刹车。在救援圈内降落接应被困人员，然后按 H 键降落将他们送达目的地。前往加油站加油，前往维修站购买升级。在轮班结束前尽可能多地营救被困人员！
