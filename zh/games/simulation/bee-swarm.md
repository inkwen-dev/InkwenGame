# 蜂群

<a href="https://inkwengame.com/zh/games/bee-swarm" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bee-swarm/cover.jpg)

在这款迷人的 3D 模拟放置街机游戏中，化身忙碌的蜜蜂，翱翔天际！探索生机勃勃的体素草地，从盛开的花朵中采集五彩缤纷的花粉，然后返回蜂巢酿造金黄色的蜂蜜。

## 怎么玩

提升蜜蜂的飞行速度和载货量。雇佣勤劳的助手蜜蜂来自动采集花粉，壮大你的蜂群。

桌面端：WASD / 方向键 / 按住鼠标左键 — 飞行 / 移动

移动端/触控：虚拟摇杆
