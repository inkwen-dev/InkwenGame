# 恐怖自动售货机

<a href="https://inkwengame.com/zh/games/scary-vending-machine" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scary-vending-machine/cover.jpg)

恐怖自动售货机是一款精彩的游戏，通过游戏帮助您的孩子学习数学！在三种自动售货机中进行选择：一种是玩具，一种是甜点，还有一种是食物；每台自动售货机内的物品都有价格，您会有一组硬币可供使用，将正确的金额插入机器，您可以在显示屏上看到金额。如果正确，自动售货机就会释放物品；如果错误，您将收到一条错误消息。

## 怎么玩

只需使用鼠标即可游玩
