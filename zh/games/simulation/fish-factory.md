# 鱼类加工厂

《鱼工厂》是一款温馨的3D鱼类养殖模拟经营游戏，背景设定在一个精致的体素世界中。探索一座广阔的生机勃勃的岛屿，解锁五个各具特色的垂钓区域。收集100种鱼类：每次捕获的鱼都取决于地点、时间、鱼竿和渔具。

## 怎么玩

在电脑上，使用 WASD 键移动。使用鼠标滚轮或 + 和 - 键缩放视角。走到水边，按下空格键，瞄准一个可用的钓点并确认抛竿。收线时，当进度条进入高亮区域时点击。多次精准命中即可将鱼放入鱼笼。

在移动设备上，使用圆形摇杆移动渔夫，点击钓鱼按钮，然后用手指选择抛竿位置。使用 + 和 - 键调整视角。

将渔获物带到接收站旁的明亮圆圈内。鱼会自动放置在传送带上，处理后即可获得金币。商店出售鱼竿、渔具、服装、工坊、新的钓鱼区域、灯笼和其他升级道具。观看教程，学习从抛竿到首次升级鱼竿的完整流程。广告为可选内容，仅提供额外奖励。

## 介绍

《鱼工厂》是一款温馨的3D鱼类养殖模拟经营游戏，背景设定在一个精致的体素世界中。探索一座广阔的生机勃勃的岛屿，解锁五个各具特色的垂钓区域。收集100种鱼类：每次捕获的鱼都取决于地点、时间、鱼竿和渔具。

选择精准的抛竿点，击中移动的目标，并将捕获的鱼带到收货站。建造传送带，升级工作坊，开设属于你自己的鲜鱼店。游客会前来购买鱼类，渔网操作员会收集渔获，偶尔还有一只钓鱼鹦鹉会带来额外的鱼。

昼夜交替，灯笼亮起，夜行生物出现在水中，体素动物在岛上漫步。按照自己的节奏发展，将一个小码头变成一个盈利的渔村。
