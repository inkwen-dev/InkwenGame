# 侏罗纪挖掘大亨

<a href="https://inkwengame.com/zh/games/jurassic-digging-tycoon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jurassic-digging-tycoon/cover.jpg)

游戏的目标是挖掘古代遗骸，清除污垢，并组装完整的骨架。闯过所有关卡，为博物馆提供丰富的恐龙骨架藏品。

## 怎么玩

操作方式：

移动设备：点击并滑动屏幕进行互动。

桌面设备：使用 WASD 键或鼠标左键移动。

其他功能：

- 探索各种挖掘地点，寻找稀有化石。

- 修复并打磨骨骼，提升其价值。

- 设计博物馆展品，吸引更多游客。

- 随着游戏进程，扩建博物馆并解锁新工具。
