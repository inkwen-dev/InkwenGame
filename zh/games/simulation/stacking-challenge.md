# 堆叠挑战

<a href="https://inkwengame.com/zh/games/stacking-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stacking-challenge/cover.jpg)

堆叠挑战是一款有趣的堆叠建造游戏。这款游戏玩法简单但富有挑战性。你会看到一些移动的钩子正携带方块移动，这些方块会左右来回移动。当看到钩子正好位于堆叠上方时，点击或轻触即可。钩子会放下方块，从而扩展堆叠。如果所有方块都成功放置在堆叠中，你将获得分数和额外奖励分。每轮游戏时长为3分钟，你可以随时重复游玩多次。

## 怎么玩

使用鼠标点击或触摸来玩游戏
