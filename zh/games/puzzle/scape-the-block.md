# 逃离方块

<a href="https://inkwengame.com/zh/games/scape-the-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scape-the-block/cover.jpg)

逃离方块是一款平台游戏，你需要在平台上移动，避开下落的方块，同时收集钻石以获得游戏分数。注意方块，跳到它们上面并穿过它们，争取在这个游戏中取得最佳成绩。

## 怎么玩

点击屏幕开始游戏
