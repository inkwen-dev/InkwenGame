# 小丑拼图

<a href="https://inkwengame.com/zh/games/trolls-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/trolls-puzzle/cover.jpg)

小丑是体型虽小但非常好奇和爱探究的生物，对周围的一切事物和人物都充满兴趣。特别是对图片（常常是他们自己的形象）以及这些图片是如何被拆分成许多部分感到着迷。之后，这些小人喜欢把图片重新拼合完整并欣赏它们。我们有4张拼图图片需要一块块地拼起来。帮助这些小丑找出这些图片里到底有什么和谁！

## 怎么玩

拖动图片碎片以组成完整的图片
