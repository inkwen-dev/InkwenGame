# 点点救援

<a href="https://inkwengame.com/zh/games/dot-rescue" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dot-rescue/cover.jpg)

在《点点救援》这款游戏中，你需要控制小球。游戏的目标是尽可能长时间地让小球存活。小球会在圆形区域内移动，而护盾则位于圆的一半位置。护盾会旋转，因此你需要避开护盾。你只有半个圆形区域可以操作。

## 怎么玩

点击屏幕以改变小球的位置
