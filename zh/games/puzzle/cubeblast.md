# CubeBlast

<a href="https://inkwengame.com/zh/games/cubeblast" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cubeblast/cover.jpg)

相同颜色的两个或多个相邻方块可以点击消除。点击的相邻方块越多，生成的特殊方块就越多。点击特殊方块会产生强大的力量。消除关卡中所需的方块即可获胜。快来试试吧。
