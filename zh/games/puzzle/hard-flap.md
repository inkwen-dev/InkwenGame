# 硬翻转

<a href="https://inkwengame.com/zh/games/hard-flap" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hard-flap/cover.jpg)

你控制一个在地面上弹跳的球。但你的路上有很多不同的障碍物，你必须在它们之间跳跃，并且绝对不能碰到它们。这个游戏比看起来要困难，因为障碍物通常以不同的速度移动，而且你一次只能连续跳跃6次，因此你必须完美地把握跳跃时机。
