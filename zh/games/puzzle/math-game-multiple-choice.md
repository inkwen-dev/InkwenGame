# 数学选择题游戏

<a href="https://inkwengame.com/zh/games/math-game-multiple-choice" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-game-multiple-choice/cover.jpg)

这款游戏机制简单，但玩起来比你想象的要难！你会看到一个简单的算式（初等算术），并在有限时间内选择正确的答案（有四个选项）。每答对一题，你将获得一分，最终得分取决于正确回答的数量。如果选择错误答案或时间用完，你将失败！

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
