# 愚蠢的鸡

<a href="https://inkwengame.com/zh/games/stupid-chicken" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stupid-chicken/cover.jpg)

在这个游戏中，你需要喂鸡以获得一个鸡蛋。点击屏幕，让小鸡啄食由小农夫提供的食物。你也可以吃掉靠近你的昆虫。当鸡吃完后，它就能下蛋了。在规定时间内尽可能多地下蛋。游戏结束后，你可以用鸡蛋换取更多游戏时间。通过这种方式，你可以增加游戏时间并推进游戏进度。
