# 堆叠圣诞老人

<a href="https://inkwengame.com/zh/games/stack-christmas-santa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-christmas-santa/cover.jpg)

这是一款有趣的圣诞节游戏，主角是圣诞老人。你需要将三个相同的圣诞老人匹配在一起，使它们消失。可以水平或垂直匹配。你会堆起一列圣诞老人，因此需要决定先摧毁哪一个圣诞老人。聪明地玩，享受乐趣。获得分数，尽可能长时间地玩下去。当你到达游戏顶端时，游戏结束。
