# UFO Arkanoid Deluxe

<a href="https://inkwengame.com/zh/games/ufo-arkanoid-deluxe" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ufo-arkanoid-deluxe/cover.jpg)

这是基于流行的 Arkanoid 游戏。你需要使用挡板控制弹跳的球。挡板可以通过鼠标移动。将有无穷无尽的飞碟向你袭来。你需要摧毁它们全部。

## 怎么玩

使用鼠标或触摸来控制挡板。通过挡板反弹球以击中飞碟。清除屏幕上所有的飞碟
