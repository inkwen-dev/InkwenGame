# 颜色交换

<a href="https://inkwengame.com/zh/games/color-exchange" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-exchange/cover.jpg)

尝试在上升过程中尽可能高地跳跃，同时在途中切换颜色。不要碰到错误的颜色，否则你的球会四分五裂，游戏结束。准确把握跳跃时机，顺利通过每一关卡进入下一关。玩得开心！

## 怎么玩

使用鼠标或触摸屏幕
