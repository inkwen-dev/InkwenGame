# 形状游戏

<a href="https://inkwengame.com/zh/games/shape-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shape-game/cover.jpg)

将从上方落下的形状匹配到圆圈中。通过双击移动顶部的圆圈行。拖动或滑动以更改圆圈的顺序。如果您的形状被阻挡了10次，您就输了。

## 怎么玩

在电脑上用鼠标点击并放下，在手机上用触摸和滑动
