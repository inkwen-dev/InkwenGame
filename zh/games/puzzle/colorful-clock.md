# 彩色时钟

<a href="https://inkwengame.com/zh/games/colorful-clock" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colorful-clock/cover.jpg)

时钟移动得非常快，而且方式非常奇怪！你只需要在正确的时间点击屏幕，使时钟指针的颜色与周围的圆圈颜色匹配即可。看起来可能很简单，但随着你不断进步，时钟会越来越快，并且每次成功匹配后，颜色和方向都会改变。如果你没有在正确的时间点击，或者匹配了错误的颜色，就会失败。集中注意力，尽可能多地获得分数吧！

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
