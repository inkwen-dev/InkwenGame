# 瓷砖层

<a href="https://inkwengame.com/zh/games/tiles-layer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tiles-layer/cover.jpg)

在《瓷砖层》游戏中体验趣味又富有策略的谜题挑战！使用鼠标引导你的路径，边移动边逐步创建瓷砖。每一步都在构建你的行进路线，因此请谨慎规划。当你到达终点时，放下第一块瓷砖以触发连锁反应——如果所有瓷砖都能完美地一直落到终点，你就赢了！但如果有任何一块瓷砖未能落下，该关卡即失败。

## 怎么玩

移动鼠标 — 控制方向并创建路径
到达终点 — 完成路径
点击释放 — 放下第一块瓷砖并启动连锁反应
