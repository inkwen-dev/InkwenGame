# 跳跃的彩色点

<a href="https://inkwengame.com/zh/games/jumping-dot-colors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jumping-dot-colors/cover.jpg)

在这个游戏中，你需要控制这个小点或球。通过点击或触摸屏幕，球会被悬在空中。你需要穿过尽可能多的不同颜色的障碍物。在每个障碍物前，小点会改变颜色，而颜色必须与小点以及它应该通过的障碍物部分相匹配。

## 怎么玩

点击屏幕开始游戏
