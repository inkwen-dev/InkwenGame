# 六边形堆叠排序

六边形堆叠排序是一款有趣且引人入胜的益智游戏，将考验你的大脑！目标很简单，但挑战却令人兴奋。你需要匹配并堆叠相同颜色的六边形方块。你可以移动方块，但要小心不要陷入困境。只有相同颜色的方块才能堆叠在一起。
