# 堆栈排序

<a href="https://inkwengame.com/zh/games/stack-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-sorting/cover.jpg)

欢迎来到堆栈排序！你的任务是通过点击堆栈来整理彩色圆柱体。将最上面的圆柱体移动到空堆栈，或顶部圆柱体相同的堆栈。在拥有大量堆栈和充足时间的简单模式中畅玩，或挑战自己在堆栈较少的困难模式中。在规定时间内完成所有关卡，即可取得胜利！

## 怎么玩

使用鼠标或触控板通过点击堆栈来整理彩色圆柱体
