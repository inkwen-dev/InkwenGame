# 水果消除3

<a href="https://inkwengame.com/zh/games/fruit-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-match-3/cover.jpg)

水果消除3是一款以水果为主题的消除游戏。在每一关中，你需要清除脏污的方格。将三个或更多相同类型的水果连成一行或一列，它们就会消失。你不能交换被锁定的水果。如果你用特定形状匹配三个或更多水果，将会获得特殊符号，例如炸弹符号、碎裂符号、闪光符号和时间符号。在规定时间内清除所有脏污方格即可完成关卡。
