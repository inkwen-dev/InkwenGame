# 春季瓷砖大师

<a href="https://inkwengame.com/zh/games/spring-tile-master" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spring-tile-master/cover.jpg)

欢迎来到《春季瓷砖大师》！沉浸于春天的缤纷世界，通过匹配装饰有盛开花朵、多彩树叶和可爱昆虫的瓷砖来体验乐趣。从棋盘上抽取瓷砖，组成三张一组的组合。你的堆叠最多可保留9张瓷砖，并可在需要时进行洗牌。收集所有瓷砖以解锁新关卡。享受迷人的春日冒险，成为终极的春季瓷砖大师！

## 怎么玩

使用鼠标选择瓷砖，或通过点击选择
