# 找出一组

<a href="https://inkwengame.com/zh/games/find-the-set" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-the-set/cover.jpg)

目标很简单：将三张牌匹配，要么所有属性都相同（背面颜色、多边形颜色和多边形形状），要么所有属性都不同。玩家必须制定策略，仔细观察并分析每张牌的属性，以做出正确的组合。

## 怎么玩

鼠标点击或触摸
