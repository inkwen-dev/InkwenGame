# 宝石怪兽

<a href="https://inkwengame.com/zh/games/jewel-monsters" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jewel-monsters/cover.jpg)

穿越森林，击败隐藏在树木中的怪物！将三个或更多相同颜色的宝石与怪物匹配以攻击它。匹配足够的宝石以消灭怪物并顺利通过。如果动作不够快，怪物就会攻击你！但别担心，有办法恢复自身健康。匹配四个或更多的宝石，会在其中一个宝石中出现爱心奖励。收集它以恢复部分生命值。

## 怎么玩

拖动一个宝石，与相邻的宝石交换位置，形成三个或更多相同颜色的宝石连线。用相同颜色的宝石组合攻击怪物
