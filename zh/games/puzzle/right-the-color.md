# 纠正颜色

<a href="https://inkwengame.com/zh/games/right-the-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/right-the-color/cover.jpg)

纠正颜色，这是一款你可以在空闲时间享受的2D休闲游戏。要在游戏中获得分数，你需要旋转方块并使其与正确的颜色碰撞。尽情享受吧！

## 怎么玩

在电脑上，只需按住鼠标左键来旋转方块；在移动设备上，只需触摸并按住屏幕任意位置
