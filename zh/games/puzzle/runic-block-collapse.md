# 符文方块坍塌

<a href="https://inkwengame.com/zh/games/runic-block-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/runic-block-collapse/cover.jpg)

欢迎来到符文方块坍塌！点击任意方块，即可引发连锁反应，清除相连的方块。消除一个方块需花费250分。消除两个或更多方块可获得积分，组越大，每块得分越高。达到目标分数即可晋级。若失败，请重新开始。尽情享受无尽乐趣！
