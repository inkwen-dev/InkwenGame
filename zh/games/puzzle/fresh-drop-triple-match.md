# 新鲜出炉：三重匹配

<a href="https://inkwengame.com/zh/games/fresh-drop-triple-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fresh-drop-triple-match/cover.jpg)

《新鲜速递：三重匹配》是一款色彩缤纷的3D益智游戏，玩家需要收集相同的新鲜产品，组成三个一组的组合，并在时间耗尽前消除所有物品。精心设计的关卡引入了新的障碍、道具和令人愉悦的特效，同时保持了游戏的快速性和易上手性。游戏进度会自动保存，因此玩家可以在电脑或移动设备上继续游戏。

## 怎么玩

点击或轻触可用商品即可将其放入托盘。在托盘中匹配三个相同的商品即可消除它们。在计时器结束前消除所有商品，并避免填满托盘的所有格子。遇到困难时，可以使用道具。操作方式：桌面端使用鼠标左键；触控设备端点击。
