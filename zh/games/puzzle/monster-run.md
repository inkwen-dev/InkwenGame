# 怪物跑酷

<a href="https://inkwengame.com/zh/games/monster-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-run/cover.jpg)

怪物跑酷是一款简单的点击跳跃收集跑酷游戏。非常容易上手！你必须避开从屏幕左侧或右侧出现的障碍物和锯齿，并努力收集尽可能多的星星，以便在关卡结束时解锁不同的怪物。尽情享受乐趣吧！

## 怎么玩

使用鼠标或在屏幕上简单点击
