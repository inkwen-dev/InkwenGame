# 割草

<a href="https://inkwengame.com/zh/games/cutting-grass" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cutting-grass/cover.jpg)

割草是一款免费的在线休闲益智游戏，专为男孩设计，可在PuzzleGame上玩。游戏玩法流畅且极具吸引力。你只需控制刀片来割除地上的杂草。整个割草过程非常减压，还能为你带来视觉享受。不同的割草关卡等待你去解锁。可在手机、平板或台式机上畅玩！
