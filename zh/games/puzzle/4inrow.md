# 4inROW

<a href="https://inkwengame.com/zh/games/4inrow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/4inrow/cover.jpg)

4inROW 是一款令人上瘾的策略游戏，你将与一位智能的人工智能对手展开较量，争夺在一行中连接四个彩色圆盘的胜利——无论是水平、垂直还是对角线方向。在这个经典的连四棋概念的数字版本中，你将轮流将你的棋子放入一个 6x7 的网格，而人工智能则会战略性地规划其反制走法。

## 怎么玩

使用鼠标左键或右键移动，点击左键下落
