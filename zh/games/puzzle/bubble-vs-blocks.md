# 气泡对方块

<a href="https://inkwengame.com/zh/games/bubble-vs-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-vs-blocks/cover.jpg)

连接数字气泡以摧毁数字方块。每个方块上都有一个数字，你需要连接一些数字气泡，使它们的总和等于方块上的数字。持续游戏，直到数字方块占据所有四个位置。

## 怎么玩

拖动指针点击那些加起来等于即将出现方块上数字的球
