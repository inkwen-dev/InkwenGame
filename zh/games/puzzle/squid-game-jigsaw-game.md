# 鱿鱼游戏拼图游戏

<a href="https://inkwengame.com/zh/games/squid-game-jigsaw-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-game-jigsaw-game/cover.jpg)

鱿鱼游戏拼图是一款以鱿鱼游戏为主题的精彩拼图游戏。将碎片拖放到它们的精确位置。在这个游戏中，你共有12张鱿鱼游戏主题的图片。你需要从第一张图片开始，解锁下一张。每张图片有三种模式：简单模式有25块（5x5），中等模式有49块（7x7），困难模式有100块（10x10）。

## 怎么玩

使用鼠标或轻触屏幕
