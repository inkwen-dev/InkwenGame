# 排序游戏挑战

<a href="https://inkwengame.com/zh/games/sort-games-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sort-games-challenge/cover.jpg)

排序游戏挑战是一款解谜游戏。在这里，你可以挑战自我，并从多种模式中选择，不限于一种。你的目标是在有限时间内完成任务以通过关卡。不要小看这款游戏，它仍然非常难以通关。快来挑战吧！

## 怎么玩

在电脑上，点击鼠标进行选择；在手机和平板上，用手指轻触屏幕进行选择
