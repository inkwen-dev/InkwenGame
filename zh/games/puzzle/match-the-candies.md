# 匹配糖果

<a href="https://inkwengame.com/zh/games/match-the-candies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-the-candies/cover.jpg)

将糖果方块从左右两侧或上下两侧推入棋盘，以形成三个或更多相同的方块组合。要完成一个关卡，需消除所有类型的方块，使棋盘变为空白。本游戏共有30个具有挑战性的关卡。

## 怎么玩

使用鼠标或任何指点设备来玩此游戏
