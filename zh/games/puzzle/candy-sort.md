# 糖果排序

<a href="https://inkwengame.com/zh/games/candy-sort" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/candy-sort/cover.jpg)

糖果排序是一款色彩缤纷的排序谜题游戏，你需要在试管之间移动糖果，并按颜色分组。只能将糖果放入空试管或相同颜色的糖果上。与时间赛跑，需要帮助时，观看一段奖励广告，可额外获得一个试管或无限时间暂停计时器。

## 怎么玩

使用鼠标或触控板在试管之间移动糖果。将糖果放入空试管，或放在同色糖果之上
