# 怪物卡车配对

<a href="https://inkwengame.com/zh/games/monster-trucks-pair" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-trucks-pair/cover.jpg)

怪物卡车配对是一款以怪物卡车为主题的记忆游戏。配对两张相同的怪物卡车卡片即可消除。每一关都有时间限制，必须在时间结束前完成所有卡片的配对。努力记住所有车辆的位置，并点击正确的配对。通过所有关卡，赢得这款儿童记忆游戏！

## 怎么玩

点击屏幕开始游戏
