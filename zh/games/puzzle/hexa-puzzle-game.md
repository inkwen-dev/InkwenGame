# 六边形拼图游戏

<a href="https://inkwengame.com/zh/games/hexa-puzzle-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hexa-puzzle-game/cover.jpg)

Hexa 是一款益智游戏，非常上瘾且有趣。游戏的目标是连接线条，以获得帮助图片中显示的形状。游戏开始时，点击 ? 或帮助按钮，查看该关卡的六边形拼图应呈现的样子。有些关卡比其他关卡更难，所以不要放弃。点击方块并移动它们以改变位置。

## 怎么玩

使用鼠标或点击方块来玩游戏
