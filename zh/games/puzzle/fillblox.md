# 填充块

<a href="https://inkwengame.com/zh/games/fillblox" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fillblox/cover.jpg)

这是一款引人入胜的逻辑益智游戏，你的目标是用各种形状填满游戏区域。游戏提供多种不同形状的方块——将它们拖放到合适的位置，确保每个格子都被填满。听起来很简单？但随着关卡的推进，游戏区域会越来越大，方块的数量也会越来越多，形状也会越来越复杂。

## 怎么玩

将右侧面板中的一个形状拖到游戏区域。

调整形状的位置，使其覆盖所有空白单元格。

填满游戏区域内的所有单元格即可完成关卡。

形状无法旋转或翻转——请为每个形状找到正确的位置。

## 介绍

这是一款引人入胜的逻辑益智游戏，你的目标是用各种形状填满游戏区域。游戏提供多种不同形状的方块——将它们拖放到合适的位置，确保每个格子都被填满。听起来很简单？但随着关卡的推进，游戏区域会越来越大，方块的数量也会越来越多，形状也会越来越复杂。
