# 水排序谜题 - 颜色分类游戏

![cover](https://img.inkwengame.com/games/water-sort-puzzle-color-sorting-game/cover.jpg)

水排序谜题是一款有趣又上瘾的益智游戏！尝试将玻璃杯中的彩色水流排序，直到每个玻璃杯中都只有同一种颜色。这是一款富有挑战性又令人放松的游戏，有助于锻炼你的大脑！

## 怎么玩

操作说明 点击任意玻璃杯，将水倒入另一个玻璃杯 规则为：只有当水的颜色相同且目标玻璃杯有足够空间时才能倒水 尽量不要陷入困境——但不用担心，你随时可以重来
