# 霓虹路径

<a href="https://inkwengame.com/zh/games/neon-path" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/neon-path/cover.jpg)

一个小小的霓虹球开始了他的世界之旅。在这款名为《霓虹路径》的游戏中，你将帮助他完成这场激动人心的冒险。你的角色将沿着特定路线移动。道路会有许多弯道和各种投影。你必须控制他的动作，以避免碰到障碍物。为此，点击屏幕可以改变他的移动轨迹。如果你在路上遇到发光的点，就需要用你的英雄触碰它们，从而获得额外分数。

## 怎么玩

使用鼠标操作游戏，或轻触屏幕
