# 像素流动

<a href="https://inkwengame.com/zh/games/pixel-flow-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-flow-3/cover.jpg)

一款快节奏的游戏，考验反应能力和行动顺序。炮台会向与其颜色匹配的像素方块开火，击碎它们并逐个清除棋盘。要通关关卡，你需要掌控射击的节奏，避免传送带过载，并建立连击。上手简单，但极具吸引力：点击 → 流动 → 像素飞溅。

## 怎么玩

点击将炮台送入传送带 炮台会向与其颜色匹配的像素开火 完成一个完整循环后，它会移动到空闲槽位 槽位有限，请注意顺序 在正确的时机射击以清除棋盘
