# 颜色升级

<a href="https://inkwengame.com/zh/games/color-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-up/cover.jpg)

在游戏过程中控制小球。会出现不同颜色的横向砖块。小球会在这些砖块上弹跳。当你穿过光束时，小球会改变颜色，并获得与光束相同颜色。之后，小球只能在与小球颜色相同的砖块上弹跳。努力达到更远的距离，尽可能多地获得分数。

## 怎么玩

点击并滑动屏幕来控制小球
