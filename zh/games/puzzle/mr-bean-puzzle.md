# 憨豆先生拼图

<a href="https://inkwengame.com/zh/games/mr-bean-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mr-bean-puzzle/cover.jpg)

在这个游戏中，你有16个包含憨豆先生图片的拼图。通过移动来拼合这些碎片，将它们放置到正确的位置。可以通过拖动来改变碎片的位置。完成一个关卡后，进入下一个关卡。每个关卡都有时间限制，你需要在规定时间内完成。
