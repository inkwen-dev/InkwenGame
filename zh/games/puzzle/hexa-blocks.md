# 六边形方块

<a href="https://inkwengame.com/zh/games/hexa-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hexa-blocks/cover.jpg)

Hexa Blocks 是一款 HTML5 风格的俄罗斯方块解谜游戏，简单而令人上瘾。本游戏包含两种模式：关卡模式：你的任务是在用完移动次数前达到目标分数，然后解锁下一关。关卡越高，难度越大。无尽模式：尽可能填满网格线，争取高分！

## 怎么玩

填满水平或垂直方向的网格线后，该行或列中的方块将被消除
