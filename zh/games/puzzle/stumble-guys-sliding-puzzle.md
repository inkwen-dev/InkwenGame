# Stumble Guys 滑动拼图

<a href="https://inkwengame.com/zh/games/stumble-guys-sliding-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stumble-guys-sliding-puzzle/cover.jpg)

欢迎来到名为 Stumble Guys 滑动拼图的游戏！在这个游戏中，你将面对12个来自 Stumble Guys 的图片拼图。通过移动拼图块来完成它们。拖动拼图块到另一个位置以进行交换。完成一个关卡后，进入下一个关卡。每个关卡都有时间限制，你需要在规定时间内完成。

## 怎么玩

使用鼠标或触摸屏幕
