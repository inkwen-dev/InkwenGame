# 太空消消乐

<a href="https://inkwengame.com/zh/games/space-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-match-3/cover.jpg)

太空消消乐是一款匹配游戏，你需要通过屏幕上的提示收集指定数量的方块。你必须在限定的步数内完成任务。如果四个或更多相同的方块连在一起，你将获得额外步数。你的步数会自动进入下一关，因此在有机会时尽量增加步数。点击方块即可开始游戏。用最少的步数匹配方块，赢得这款有趣的益智匹配游戏！

## 怎么玩

点击屏幕开始游戏
