# 冬季记忆

<a href="https://inkwengame.com/zh/games/winter-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/winter-memory/cover.jpg)

欢迎来到新游戏《冬季记忆》。任务是记住并打开相同的配对。在第一关，只有两对。但在第十关时，会有二十对。起初，所有图片会打开几秒钟，以便你可以记住它们的位置。然后它们会翻转到背面，你需要重新打开它们，删除《冬季记忆》中的配对。

## 怎么玩

使用鼠标或触摸屏幕
