# Wordle 2.0

<a href="https://inkwengame.com/zh/games/wordle-2-0" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wordle-2-0/cover.jpg)

Wordle 2.0 是一款基于单词的解谜类浏览器游戏，作为原始 NYT-Wordle 游戏的增强版衍生作品。它允许玩家在多种语言中进行游戏，单词长度从 3 到 5 个字母不等，并提供可选提示以帮助玩家做出更佳猜测。无论你是新手还是高手，Wordle 2.0 都将是提升词汇量的终极挑战！

## 怎么玩

键盘和触摸
