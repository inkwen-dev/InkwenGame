# 收获切割大师

<a href="https://inkwengame.com/zh/games/harvest-cut-master" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/harvest-cut-master/cover.jpg)

收获切割大师是一款有趣的益智游戏，共有55个关卡。在每个关卡中，你需要收割田地里的作物。为了能够收割不同的作物，你需要升级你的车辆。你也可以通过购买新的农业车辆来实现这一目标。不要忘记在收获后用赚到的钱去访问「升级」部分。

## 怎么玩

使用 W A S D 或 方向键 或 鼠标 移动
