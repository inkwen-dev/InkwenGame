# 爱心方块坍塌

<a href="https://inkwengame.com/zh/games/hearts-blocks-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hearts-blocks-collapse/cover.jpg)

在这个充满爱心的趣味游戏中，点击方块将其移除。移除水平或垂直方向上相连且颜色相同的爱心。提前规划，尽可能多地清除每一关的爱心。利用投影框中的信息查看每次移除的价值。达到或超过每关的目标金额即可进入下一关。即使未达到目标金额也没关系，您可以随时重新尝试该关。

## 怎么玩

通过点击至少有一个同色爱心在水平或垂直方向相邻的爱心来移除它们
