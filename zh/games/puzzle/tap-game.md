# 点击游戏

<a href="https://inkwengame.com/zh/games/tap-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tap-game/cover.jpg)

点击游戏是一款匹配拼图游戏，你需要点击两个相同方块的角落处的空白方块。随后这些方块会消失。空白方块会迅速填满，你必须尽快找到角落，因为整个棋盘会很快被方块填满。尽可能长时间地玩下去，直到棋盘被方块完全填满。

## 怎么玩

点击屏幕来玩这个游戏
