# 圣诞匹配豪华版

<a href="https://inkwengame.com/zh/games/xmas-match-deluxe" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/xmas-match-deluxe/cover.jpg)

交换相邻的礼物，以形成一行或一列三个相同的礼物。要完成关卡，您需要在有限的回合内收集指定数量的礼物。收集超过5个礼物即可获得一个法术（强化道具），它会显示在屏幕右侧。通过拖放将法术施加到目标上。点击"提示"和"双倍"法术即可施放。点击旁边了解有关法术的更多信息。
