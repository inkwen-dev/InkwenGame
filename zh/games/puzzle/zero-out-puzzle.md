# 零出谜题

<a href="https://inkwengame.com/zh/games/zero-out-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zero-out-puzzle/cover.png)

用零出谜题挑战你的大脑，这是一款策略性算术游戏，你需要将数字变为零，同时影响相邻方块。随着关卡变得越来越复杂，仔细规划每一步，以高效清除棋盘，并在这场引人入胜的数字冒险中取得最高分。
