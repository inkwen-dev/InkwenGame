# 不稳定的方块

<a href="https://inkwengame.com/zh/games/unstable-squares" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/unstable-squares/cover.jpg)

这款益智游戏的目标是将白色小球从屏幕顶部和底部的两点之间移动。左右两侧有很多不稳定的方块，它们会无规律地四处移动。因此，请在不与方块发生碰撞的情况下，将白色小球移动到目标点。尽可能多地完成移动以获得分数。如果碰到任何方块，游戏就会结束。点击屏幕来控制小球。小球会上下移动，你可以控制移动的长短。

## 怎么玩
