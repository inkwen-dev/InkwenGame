# 奔跑的男人

<a href="https://inkwengame.com/zh/games/run-man" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/run-man/cover.jpg)

奔跑的男人是一款体育游戏。控制这个运动员，尽可能长时间地游玩而不犯错。你需要跑步，并避开路径左侧或右侧的障碍物，跳过横跨整个路径的障碍物。随着游戏时间的延长，障碍物出现的速度会加快。因此，请尽量跑得更久。当你犯下三次错误时，游戏就会结束。

## 怎么玩

使用左、右箭头键移动，空格键跳跃，或点击游戏屏幕上的游戏图标
