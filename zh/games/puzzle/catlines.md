# CatLines

<a href="https://inkwengame.com/zh/games/catlines" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/catlines/cover.jpg)

专为儿童设计的简单五连消游戏，旨在提升逻辑思维能力。将五个或更多同色猫咪排成一条直线（水平、垂直或对角线），即可从棋盘上消除。你能创造出多少条连线？

## 怎么玩

将五个或更多同色猫咪在水平、垂直或对角线上连成一线即可消除。每消除一条线得50分，交叉的连线得分翻倍。使用鼠标或点击屏幕进行游戏
