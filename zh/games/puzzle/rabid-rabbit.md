# 狂暴的兔子

<a href="https://inkwengame.com/zh/games/rabid-rabbit" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rabid-rabbit/cover.jpg)

《狂暴的兔子》是一款有趣的儿童游戏，你需要在实验室中控制一只兔子。点击屏幕可让兔子上下移动，你需要收集所有的胡萝卜。避开实验室中的毒素和实验物品。如果你碰到它们，兔子就会发疯，游戏也就结束了
