# 绳索绘制

<a href="https://inkwengame.com/zh/games/rope-draw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rope-draw/cover.jpg)

绳索绘制是一款解谜游戏，您需要推动绳索以形成新的排列。您的目标是复制上方出现的排列。如有需要，有一个提示按钮，会向您展示最初的几步。游戏中有120个不同的关卡，以及在通关第40关后解锁的‘趣味’模式，在该模式中，您可以随意插入新绳索或推动它们。

## 怎么玩

触摸绳索以进行新的排列
