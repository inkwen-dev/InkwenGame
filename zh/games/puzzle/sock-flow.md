# 袜子流动

<a href="https://inkwengame.com/zh/games/sock-flow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sock-flow/cover.jpg)

Sock Flow 是一款令人放松且有趣的益智游戏，包含 50 个烧脑关卡，能够提升你的逻辑思维和解决问题的能力。从一个彩色圆点拉伸你的袜子，直到到达第二个彩色圆点。
