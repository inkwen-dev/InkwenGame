# 合并小镇！

<a href="https://inkwengame.com/zh/games/merge-town" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-town/cover.jpg)

你是否曾梦想过成为市长？是否曾梦想过经营一座城镇，开发土地，并见证一座大都市的崛起？那么就不要犹豫了，快来体验Gram Games最新推出的《合并小镇！》。游戏的核心概念非常简单——你拥有一块土地，你的任务就是将它变成一座城镇。时不时地，你会获得一栋房子。每栋房子都可以与其他相同类型的房屋合并，形成更大的住宅。

## 怎么玩

点击开始游戏，点击合并。房屋越大，你赚得越多。赚得越多，就能购买越多的房子，从而更快地推动时间发展
