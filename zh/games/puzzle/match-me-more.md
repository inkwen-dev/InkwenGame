# 匹配更多

<a href="https://inkwengame.com/zh/games/match-me-more" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-me-more/cover.jpg)

匹配更多是一款拼图游戏，玩家需要将外观相似的物体进行匹配。匹配颜色、匹配形状、匹配数字。拥有众多挑战和多个关卡。全部匹配并解决所有谜题吧 :)

## 怎么玩

鼠标 - 左键点击物体，再左键点击箭头按钮 或 - 左键点击并滑动物体 鼠标和键盘 - 左键点击并按箭头键 或 - 左键点击并按WASD 触摸屏 - 滑动物体
