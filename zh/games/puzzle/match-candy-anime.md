# 匹配糖果 - 动漫

<a href="https://inkwengame.com/zh/games/match-candy-anime" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-candy-anime/cover.jpg)

匹配三个或更多方块以获得分数。匹配的方块越多，得分越高。尽可能多地得分。每一关的时间都会更短。

## 怎么玩

点击一个方块并拖动到其他相似的方块上以形成组合。完成组合后释放鼠标按钮，使方块被消除，并有新的方块从上方落下
