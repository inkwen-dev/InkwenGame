# 蛇块

<a href="https://inkwengame.com/zh/games/snake-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-blocks/cover.jpg)

蛇块是一款2D益智游戏，你将控制由方块组成的蛇。游戏的目标是通过在障碍物之间移动你的蛇并收集道具，到达每一关的终点。游戏包含多种关卡，每关都有独特的挑战。有些关卡需要你穿越狭窄的空间，而另一些则需要你使用道具来解决谜题。

## 怎么玩

桌面端 使用右键按钮移动 移动端 点击屏幕移动 控制和指示器 屏幕左上角有暂停按钮 分数和关卡信息显示在屏幕中间上方
