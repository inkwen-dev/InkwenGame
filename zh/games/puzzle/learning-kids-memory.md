# 学习儿童记忆

<a href="https://inkwengame.com/zh/games/learning-kids-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/learning-kids-memory/cover.jpg)

这是一个专为学习儿童设计的记忆游戏。游戏中有学习儿童的图片，他们很开心，想要学习。配对两张相同的图片，并在时间结束前完成关卡。您也可以通过这个游戏来学习。

## 怎么玩

使用鼠标点击卡片，或在手机上玩游戏时用手指点击
