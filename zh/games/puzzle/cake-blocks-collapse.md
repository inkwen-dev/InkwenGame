# 蛋糕方块消消乐

<a href="https://inkwengame.com/zh/games/cake-blocks-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cake-blocks-collapse/cover.jpg)

通过点击水平或垂直相连的同色方块组来消除方块。每次消除都会获得分数，消除的方块组越大，得分越高。底部的状态栏会显示任意选中方块组的预估分数。游戏包含多种道具，带来激动人心且富有挑战性的玩法。
