# 自卸卡车记忆

<a href="https://inkwengame.com/zh/games/dump-trucks-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dump-trucks-memory/cover.jpg)

自卸卡车记忆是一款拼图记忆游戏，你需要点击卡片进行翻转，找到两张相同的自卸卡车图片。然后这些图片会消失。在时间结束前猜出所有图片。通过所有关卡，测试你的记忆力。
