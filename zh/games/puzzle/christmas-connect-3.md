# 圣诞三连

<a href="https://inkwengame.com/zh/games/christmas-connect-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-connect-3/cover.jpg)

使用触摸或鼠标连接相似物品。将三个或更多水平、垂直或对角相邻的物品组成一组，使其方块颜色变为红色。使所有方块都变为红色以完成关卡。完成全部24个关卡即可赢得此游戏。

## 怎么玩
