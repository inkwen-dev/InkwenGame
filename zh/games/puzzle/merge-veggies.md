# 合并蔬菜

<a href="https://inkwengame.com/zh/games/merge-veggies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-veggies/cover.jpg)

合并蔬菜是一款超级上瘾的蔬菜合并游戏！你的任务是点击两个或更多相同的蔬菜，将它们升级为更大的蔬菜。努力获得更高的分数，并尝试达到南瓜。南瓜是最终的蔬菜，祝你好运

## 怎么玩
