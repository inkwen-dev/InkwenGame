# Choli 攀登

<a href="https://inkwengame.com/zh/games/choli-climb" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/choli-climb/cover.jpg)

你需要帮助 Choly 攀登高山并到达顶峰。但途中有很多地方可能会让你跌落，因此你必须非常小心。跳上平台，通过跳跃越过洞口来避免坠落。你拥有普通跳跃和双重跳跃，应该明智地使用它们以继续前进。游戏中还有时间限制，如果你耗尽时间，游戏将会失败。因此，你必须收集沿途找到的时钟来增加剩余时间，从而能够攀爬得更高。
