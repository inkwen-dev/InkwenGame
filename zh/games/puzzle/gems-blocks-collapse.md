# 宝石方块消消乐

<a href="https://inkwengame.com/zh/games/gems-blocks-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gems-blocks-collapse/cover.jpg)

通过点击水平或垂直相连的同色方块组来消除方块。每次消除都会获得分数，消除的方块组越大，得分越高。在拥有炸弹之前，你可以随时消除任意单个方块。

## 怎么玩

使用鼠标或触摸
