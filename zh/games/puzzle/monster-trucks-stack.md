# 怪物卡车堆叠

<a href="https://inkwengame.com/zh/games/monster-trucks-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-trucks-stack/cover.jpg)

在这个匹配卡车游戏中，控制并堆叠不同的怪物卡车。游戏的目标是将相同类型的怪物卡车水平或垂直排列成一行，以摧毁它们并获得分数。尽量不要让卡车碰到游戏屏幕的顶部，否则游戏将会结束。匹配三个或更多相同的怪物卡车来玩这个游戏。最好垂直匹配它们。

## 怎么玩

点击屏幕您想放置怪物卡车的位置
