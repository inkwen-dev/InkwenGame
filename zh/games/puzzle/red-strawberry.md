# 红草莓

<a href="https://inkwengame.com/zh/games/red-strawberry" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/red-strawberry/cover.jpg)

在这个游戏中，你扮演一颗草莓，需要正确掌握时机，以便在开始屏幕的跳跃中跳过障碍物。游戏屏幕顶部有一个跳跃条，游戏时请注意它。通过任何障碍物即可得分，否则游戏失败。祝你玩得愉快！
