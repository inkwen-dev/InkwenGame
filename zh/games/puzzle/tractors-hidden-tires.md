# 拖拉机隐藏的轮胎

<a href="https://inkwengame.com/zh/games/tractors-hidden-tires" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tractors-hidden-tires/cover.jpg)

拖拉机隐藏的轮胎是一款寻物解谜游戏。这款游戏共有六个关卡，你需要在图片中找到隐藏的轮胎。每张图片中有十个隐藏的轮胎。第一关你有80秒的时间找到全部10个隐藏物品。只有通过当前关卡，才能解锁下一关。接下来每一关的游戏时间比前一关减少五秒。因此，在最后一关你将只有55秒的时间找到所有隐藏的轮胎。

## 怎么玩

点击屏幕开始游戏
