# 自卸卡车三消

<a href="https://inkwengame.com/zh/games/dump-trucks-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dump-trucks-match-3/cover.jpg)

自卸卡车三消是一款以自卸卡车为主题的消除游戏。移动卡车，使相同卡车在一行中达到三个或更多，即可摧毁它们并获得分数以及时间计量器上的额外时间。你需要快速行动，摧毁更多的卡车以获取更高的分数和更长的游戏时间，从而进入下一关。随着关卡提升，游戏难度也会增加。快来开始游戏，享受乐趣吧。
