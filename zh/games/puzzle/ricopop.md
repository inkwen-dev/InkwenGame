# RICOPOP

<a href="https://inkwengame.com/zh/games/ricopop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ricopop/cover.jpg)

RICOPOP 是一款霓虹弹跳街机解谜游戏。瞄准一次发射，利用墙壁反弹，以最少的射击次数击碎所有水晶。制造连锁反应，充能脉冲，在十个章节的五十个关卡中追逐三颗星。解锁六种球体风格，并可在十四种语言之间切换。

## 怎么玩

用鼠标或手指拖动来瞄准，然后释放以发射。球体会自动返回。利用墙壁反弹从不同角度击中水晶。按 Escape 键或暂停按钮可暂停游戏。使用加速按钮可加快发射速度。
