# 扣篮跳跃

<a href="https://inkwengame.com/zh/games/dunk-jumps" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dunk-jumps/cover.jpg)

扣篮跳跃是另一款球类游戏，你需要在布满尖刺的墙上带球跳跃。球会在墙的左侧和右侧跳跃。两侧都有尖刺，你需要精准地跳过或避开尖刺。如果碰到尖刺，球就会爆炸，游戏结束。游戏中还有星星需要收集以获得额外分数。但要小心，有时星星位于尖刺下方，这会摧毁你的球

## 怎么玩

点击屏幕开始游戏
