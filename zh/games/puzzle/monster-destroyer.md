# 怪物摧毁者

<a href="https://inkwengame.com/zh/games/monster-destroyer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-destroyer/cover.jpg)

这是一款你需要摧毁方块（木头、金属和爆炸性方块）以帮助怪物到达另一个怪物的游戏。这款游戏包含多个关卡，每个关卡你都需要仔细思考如何抵达另一个怪物。
