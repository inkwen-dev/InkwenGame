# 旋转

<a href="https://inkwengame.com/zh/games/rotate" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rotate/cover.jpg)

在这个游戏中，你可以选择玩圆形、三角形、正方形或六边形。它们内部都有尖刺，还有一个小球需要你控制以避免与尖刺碰撞。选择一个你想玩的形状，向左或向右旋转以避开尖刺，同时收集出现的钻石和其他成就，例如球体保护、额外生命等。

## 怎么玩

点击屏幕来玩这个游戏
