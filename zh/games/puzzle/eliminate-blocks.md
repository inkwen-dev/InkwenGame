# 消除方块

<a href="https://inkwengame.com/zh/games/eliminate-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/eliminate-blocks/cover.jpg)

在你面前的关卡中会出现由彩色方块组成的图片。棕色的炮台方块放置在四周，每个只能发射一次。你的任务是击碎所有方块。这是一系列重要的射击顺序。仔细观察位置，注意炮台的位置，并确定哪一个将首先开始射击。请注意，未来会出现新的方块。不要触碰它们，它们带有黑色骷髅标志，在《消除方块》中如此。

## 怎么玩

使用鼠标或触摸屏幕
