# 水色排序谜题

<a href="https://inkwengame.com/zh/games/water-sort-color-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/water-sort-color-puzzle/cover.jpg)

水色排序谜题游戏是一款有趣的颜色搭配游戏。将不同颜色分类到不同的瓶子中，并尝试将相同颜色的液体收集到同一个瓶子中。一旦你成功分离所有颜色，就能通过关卡。你可以使用获得的金币来更换试管或背景。
