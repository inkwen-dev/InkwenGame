# 瑞克和莫蒂拼图

<a href="https://inkwengame.com/zh/games/rick-and-morty-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rick-and-morty-jigsaw/cover.jpg)

瑞克和莫蒂是儿童卡通中的热门角色。这次他们出现在拼图游戏中。这款游戏包含五张瑞克和莫蒂角色的图片。选择一张图片开始游戏。你可以选择25片、49片或100片的拼图模式。将打乱的拼图块放置到正确位置，还原出瑞克和莫蒂的图像。选择你喜欢的模式，享受这款拼图游戏吧。
