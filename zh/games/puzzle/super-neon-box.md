# 超级霓虹方块

<a href="https://inkwengame.com/zh/games/super-neon-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/super-neon-box/cover.jpg)

超级霓虹是一款智力游戏。用鼠标点击以改变方块的颜色，并收集正确颜色的物体。你可以点击蓝色方块将其变为红色。从上方开始的方块初始速度较慢，随后逐渐加速。你需要将相同颜色的方块组合在一起。争取获得最高分。玩得开心。
