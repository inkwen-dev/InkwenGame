# 拯救怪物

<a href="https://inkwengame.com/zh/games/save-the-monster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-monster/cover.jpg)

《拯救怪物》是一款解谜类游戏，你需要在棋盘上移动怪物，收集硬币并避开想要摧毁你的火箭。怪物可以在格子间移动，因此你需要找到最佳路径来收集硬币。当你收集到十枚硬币后，怪物会投下炸弹，可以摧毁部分火箭。尽可能长时间地游玩，避开火箭并收集硬币。

## 怎么玩

在屏幕上滑动以玩此游戏
