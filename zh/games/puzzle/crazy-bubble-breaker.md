# 疯狂泡泡消除

<a href="https://inkwengame.com/zh/games/crazy-bubble-breaker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-bubble-breaker/cover.jpg)

疯狂泡泡消除是一款有趣且富有挑战性的2D泡泡射击物理谜题游戏。你需要用下落的球来摧毁所有泡泡。你可以通过瞄准线来调整泡泡的位置，然后松开手指释放球。你还可以让球在墙壁上反弹，用一个球击中更多的泡泡。你能成功消除它们吗？数十个关卡等待着你来挑战！运用你的智慧，尽量用最少的球完成所有关卡！

## 怎么玩

在电脑和手机上，点击并按住设置球，松开手指释放球
