# 拉火箭

<a href="https://inkwengame.com/zh/games/pull-the-rocket" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pull-the-rocket/cover.jpg)

拉火箭是一款街机游戏。你需要将所有球掉入桶中，并确保所有球都上色。如果你想改变球的颜色，就释放中间的烟花。用彩色球给白色球涂上它们最喜欢的颜色！小心炸弹！

## 怎么玩
