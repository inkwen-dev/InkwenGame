# 鸟类瓷砖三连

<a href="https://inkwengame.com/zh/games/bird-tile-trio" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bird-tile-trio/cover.jpg)

每只鸟都有其完美的三连组合——你能找到所有的吗？匹配三个相同的鸟类瓷砖，揭示隐藏的图层，并清除精美设计的拼图板。解锁成就，获得高分，并在充满生动鸟类艺术的轻松瓷砖匹配冒险中挑战你的大脑。

## 怎么玩

使用鼠标或触控板选择开放的瓷砖，匹配三个相同的鸟类瓷砖，清空所有瓷砖以完成关卡
