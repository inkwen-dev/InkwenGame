# 瓢虫消消乐

<a href="https://inkwengame.com/zh/games/ladybug-match3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ladybug-match3/cover.jpg)

将瓢虫从左向右移动，并通过上下移动来改变它们的颜色。这款有趣的遊戲可以在任何設備上進行：智慧手機、平板電腦和個人電腦。不要害怕，點擊這個令人上癮的遊戲，通過排列三個或更多相同顏色的瓢蟲，盡快將它們從屏幕上消除。

## 怎么玩

使用滑鼠或點擊螢幕
