# 大块要跳

<a href="https://inkwengame.com/zh/games/big-must-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/big-must-jump/cover.jpg)

两个方块进入屏幕并相互靠近。你只需触摸屏幕的任意一侧来跳过另一个方块。但请注意，只有大的方块能成功跳过小的方块。因此，你必须迅速决定点击屏幕的哪一侧，并准确把握跳跃时机，以避免撞上另一个方块。

## 怎么玩

使用鼠标玩游戏，或点击屏幕
