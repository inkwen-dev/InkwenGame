# 滑动方块

<a href="https://inkwengame.com/zh/games/sliding-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sliding-blocks/cover.jpg)

帮助你的橙色方块到达指定位置。向正确的方向移动方块，它们会一直移动直到碰到障碍物或墙壁。你可以在新的方向上开始新的移动。祝你游戏愉快！

## 怎么玩

使用箭头键移动玩家
