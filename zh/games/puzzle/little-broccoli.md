# 小花椰菜

<a href="https://inkwengame.com/zh/games/little-broccoli" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/little-broccoli/cover.jpg)

在这个蔬菜拼图游戏中，你的任务是安全地将花椰菜运送到终点。途中有很多障碍物，你需要避开它们。花椰菜可以在平台的两侧移动。用鼠标左键点击来玩这个游戏。
