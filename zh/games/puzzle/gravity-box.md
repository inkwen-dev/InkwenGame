# 重力方块

![cover](https://img.inkwengame.com/games/gravity-box/cover.jpg)

重力方块是一款令人兴奋的在线物理游戏，你将通过操控重力来控制一个方块，穿越充满挑战的关卡。你的目标是通过在正确时机翻转重力，让方块一步步走上楼梯。避开障碍物，精准把握移动时机，确保在不掉落的情况下抵达顶端！虽然操作简单，但机制极具挑战性，重力方块将考验你的精准度和反应能力。你能否掌握重力，引导方块取得胜利？
