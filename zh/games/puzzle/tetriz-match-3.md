# 糖果三消

<a href="https://inkwengame.com/zh/games/tetriz-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tetriz-match-3/cover.jpg)

将下落的糖果组进行移动和旋转，使它们在棋盘的任意位置形成水平、垂直或对角线方向的相同糖果连线。使用左右键进行移动，上键进行旋转。不要让棋盘上方行被填满。
