# 合并西瓜

<a href="https://inkwengame.com/zh/games/merge-watermelon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-watermelon/cover.jpg)

合并西瓜是一款益智游戏。在游戏中，你需要将两个相同的水果合并成更高级的水果。水果会不断落入场景中。你需要控制它们下落的方向和时机，合成水果，直到场景中的水果无法再放置为止。来吧！

## 怎么玩

用鼠标拖放组合
