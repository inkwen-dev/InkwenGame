# 像素方块3D

<a href="https://inkwengame.com/zh/games/pixel-block-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-block-3d/cover.jpg)

像素方块3D是一款令人放松的在线游戏，适合所有年龄段的人。在这款游戏中，你只需用鼠标控制方块的方向，触碰所有的像素点。注意图案中的空隙，否则你的方块会掉落并结束游戏。游戏中有多个不同难度的关卡等待挑战。快来享受游戏吧！

## 怎么玩

如果你在电脑上玩，请点击鼠标来移动方块；如果你在手机上玩，请点击按钮来移动
