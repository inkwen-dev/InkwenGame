# 算术连线

<a href="https://inkwengame.com/zh/games/arithmetic-lines" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arithmetic-lines/cover.jpg)

算术连线是一款有趣的数学游戏，你需要找到正确的数学符号来回答给出的问题。你需要点击屏幕，将线条移动到相应的字符上。避免错误的答案。
