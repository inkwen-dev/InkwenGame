# 万圣节配对

<a href="https://inkwengame.com/zh/games/halloween-matching" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-matching/cover.jpg)

在时间耗尽前，匹配三个或更多相同的万圣节角色，使它们爆炸。如果匹配四个或更多相同的万圣节角色，您将获得额外时间。在一行或一列中匹配四个相同的角色可获得炸弹。在一行或一列中匹配五个相同的角色可获得一个变化的角色，它会摧毁所有相同的角色，并为每个爆炸的角色提供额外时间。如果您幸运的话，您将在棋盘上获得额外时间。
