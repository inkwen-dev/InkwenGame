# 糖果链匹配

<a href="https://inkwengame.com/zh/games/candy-chain-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/candy-chain-match/cover.jpg)

使用触摸或鼠标连接相似的物品。将三个或更多水平、垂直或对角相邻的物品组成一组，以移除方块上的网。解除所有方块上的网以完成关卡。完成全部36个关卡即可赢得游戏。
