# 彩色圆圈

<a href="https://inkwengame.com/zh/games/colored-circle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colored-circle/cover.jpg)

一个球在圆圈内弹跳，你需要确保它持续这样弹跳！请注意，只有当球碰到与自身颜色相同的圆圈部分时才会反弹。圆圈的四个部分有四种不同的颜色，球的颜色也会随机变为这四种颜色之一。因此，你必须迅速旋转圆圈，以免球触碰到不同颜色的边！

## 怎么玩

使用鼠标操作游戏，或点击屏幕
