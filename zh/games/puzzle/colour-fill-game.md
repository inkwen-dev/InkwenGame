# 颜色填充游戏

<a href="https://inkwengame.com/zh/games/colour-fill-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colour-fill-game/cover.jpg)

在屏幕上滑动，立方体会随着你的手指移动，并用它的颜色填充所在的位置，你需要避开障碍物，并填满所有空白区域才能获胜。必须避免立方体触碰到自己的轨迹。障碍物和墙壁的位置是随机生成的。

## 怎么玩

鼠标控制
