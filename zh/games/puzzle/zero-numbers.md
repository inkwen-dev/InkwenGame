# 零数字

<a href="https://inkwengame.com/zh/games/zero-numbers" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zero-numbers/cover.jpg)

“零数字”是一款逻辑谜题游戏。目标是通过创建相同的数字来消除所有方块。规则：一个方块只能移动到相邻的方块上。如果它们的数字相同，则两个方块都会被消除；否则，它们的数字会相加。做出正确的求和与消除操作，清除游戏区域并解锁下一个挑战！

触摸和鼠标控制
