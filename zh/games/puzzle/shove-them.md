# 推他们

<a href="https://inkwengame.com/zh/games/shove-them" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shove-them/cover.jpg)

推他们是一款有趣且令人上瘾的超休闲游戏。滑动以旋转，点击打开扫帚并把人群从建筑物中扔出去，尽情享受乐趣

## 怎么玩

使用 WASD 或方向键移动，按空格键打开扫帚
