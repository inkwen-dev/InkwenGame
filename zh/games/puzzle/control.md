# 控制

<a href="https://inkwengame.com/zh/games/control" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/control/cover.jpg)

控制是一款休闲类益智游戏，或称砖块游戏，你需要防止球掉落。你需要左右控制挡板来接住球，同时也要注意从挡板下方落下的球必须保持居中，不能掉落。

## 怎么玩

点击屏幕左侧或右侧来玩这个游戏
