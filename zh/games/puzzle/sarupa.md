# SARUPA

<a href="https://inkwengame.com/zh/games/sarupa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sarupa/cover.jpg)

这是一款三消益智游戏，你需要将三个相同颜色的猴子排成一列，使它们消失。随着游戏进行，你会不断消除从树上掉落的猴子。随着关卡提升，下落猴子的种类增多，难度也随之增加。在困难模式中，两个猴子会同时落下，但你可以享受更长的连击乐趣。

## 怎么玩

点击猴子可交换左右位置，将三个相同颜色的猴子垂直对齐以消除它们。当消除猴子时，屏幕右侧的进度条会逐渐累积，当达到最大值时，旋转按钮将会激活
