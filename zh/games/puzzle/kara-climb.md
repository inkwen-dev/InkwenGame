# 卡拉攀爬

<a href="https://inkwengame.com/zh/games/kara-climb" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kara-climb/cover.jpg)

你应该帮助卡拉攀登这座山并到达顶峰。但有很多地方可能会让你跌落，所以你必须非常小心。你所需要做的就是跳到石头（平台）上，并通过跳跃越过洞口来避免坠落。你有普通跳跃和双重跳跃，应该明智地使用它们来前进。此外还有一个时间限制，如果你耗尽时间，游戏就会失败。
