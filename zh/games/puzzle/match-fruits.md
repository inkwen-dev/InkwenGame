# 匹配水果

<a href="https://inkwengame.com/zh/games/match-fruits" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-fruits/cover.jpg)

匹配水果是一款有趣的三消游戏，包含72个关卡（持续更新中）。在时间耗尽前，交换并匹配三个或更多相同类型的水果，获得分数和特殊水果。赢取分数，与朋友以及全球其他玩家在世界排行榜上一较高下。
