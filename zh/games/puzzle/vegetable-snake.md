# 蔬菜蛇

<a href="https://inkwengame.com/zh/games/vegetable-snake" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/vegetable-snake/cover.jpg)

在遥远奇妙的世界里，生活着只吃植物的蛇类。在游戏《蔬菜蛇》中，你将融入其中，并帮助一只小蛇成长。她需要在各种地点爬行，留意散落在地上的蔬菜。你的蛇必须吸收这些蔬菜，从而不断长大并增强力量。为此，使用方向键或触摸屏幕来控制它的移动，引导它找到蔬菜。

## 怎么玩
