# 数字合并冲突

<a href="https://inkwengame.com/zh/games/nummerge-clash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nummerge-clash/cover.jpg)

这是一款动态数字益智游戏，你需要连接相邻的同值卡牌。点击卡牌即可将其与所有相邻的同值卡牌合并，提升其数值，并为上方落下的新卡牌腾出空间。消耗能量进行策略性操作：交换相邻卡牌或移除障碍物。乍看之下简单，但这款游戏机制蕴含着丰富的策略性：你需要规划每一步，适应不断变化的棋盘，并在有限的条件下冲击高分。

## 怎么玩

成为数字组合大师！

你的主要目标是获得最高分并尽可能长时间地生存下去。连接相邻的同值卡牌，提升它们的数值，并为新卡牌腾出空间。当没有可移动的卡牌且能量不足以进行战术操作时，游戏结束。制定你的策略，关注即将出现的卡牌队列，并运用战术操作来避免陷入僵局！

操作方式：

桌面端操作：

左键点击卡牌：将卡牌与所有相邻的同值卡牌合并。

长按卡牌：查看卡牌描述和属性。

交换按钮：激活交换模式，交换两张相邻卡牌。

销毁按钮：消耗能量移除选定的卡牌。

卡牌队列旁的“+”按钮：打开商店，使用金币购买卡牌。

移动端操作：

点击卡牌：将卡牌与所有相邻的同值卡牌合并。

长按卡牌：查看卡牌描述和属性。

能量面板：选择交换或销毁模式。

销毁按钮：消耗能量移除选定的卡牌。卡片队列附近的“+”按钮：打开商店，用金币购买卡片。
