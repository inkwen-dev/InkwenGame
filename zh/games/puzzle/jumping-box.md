# 跳跃方块

<a href="https://inkwengame.com/zh/games/jumping-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jumping-box/cover.jpg)

在这个益智跳跃游戏中，方块必须到达红色旗帜才能进入下一关。同时，你可以通过发射球来移动方块。这些球会撞击墙壁并推动方块到你想要的位置。一开始不会太容易，但当你掌握了移动原理后，乐趣就开始了。

## 怎么玩

使用鼠标操作游戏或轻触屏幕
