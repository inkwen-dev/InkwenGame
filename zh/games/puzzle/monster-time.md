# 怪物时间

<a href="https://inkwengame.com/zh/games/monster-time" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-time/cover.jpg)

一款以怪物为主题的趣味益智游戏，风格类似《连线》，你需要将怪物两两连接。时间有限。每完成一次连接，你将获得积分，积分决定你在排行榜上的位置。
