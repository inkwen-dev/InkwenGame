# 花园配对儿童版

<a href="https://inkwengame.com/zh/games/garden-match-kids" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/garden-match-kids/cover.jpg)

花园配对儿童版——是一款专为儿童设计的蔬菜配对游戏，玩起来非常有趣。你需要将相同类型的蔬菜进行配对，这样就能顺利通过关卡。游戏包含10个简单关卡，让孩子们轻松上手 :)

## 怎么玩

将相同类型的蔬菜进行配对并清除关卡。共有10个关卡
