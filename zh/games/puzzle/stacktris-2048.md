# Stacktris 2048

Stacktris 2048 将俄罗斯方块的策略性堆叠与 2048 的满足感十足的数字合并相结合。在动态的三维空间中穿梭，将相同的数字方块组合起来，朝着标志性的 2048 方块迈进。没有时间限制，尽情规划你的空间与数字策略，在这款令人上瘾的益智对决中展现智慧。
