# 线条障碍

<a href="https://inkwengame.com/zh/games/line-barriers" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/line-barriers/cover.jpg)

Line Barriers 是一款带有球和障碍物的游戏。你需要让球通过到另一边。穿过障碍物。当障碍物透明时你可以通过，但如果它们是实心的，你可能会撞上球。因此，请点击屏幕来减缓球速，安全地通过到另一边并收集分数。尽可能多地通过，并获得最高分。如果你撞上障碍物，游戏就会结束。所以你只有一次机会取得高分。

## 怎么玩

点击屏幕来玩这个游戏
