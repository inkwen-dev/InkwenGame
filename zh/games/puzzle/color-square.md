# 彩色方块

<a href="https://inkwengame.com/zh/games/color-square" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-square/cover.jpg)

彩色方块是一款触摸游戏，你需要在屏幕上点击以改变方块的颜色。主方块必须与进入大方块的较小方块颜色相同。如果颜色不同，方块将会碰撞并导致游戏结束。

## 怎么玩
