# 快速球游戏

<a href="https://inkwengame.com/zh/games/fast-ball-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fast-ball-game/cover.jpg)

快速球是一款你需要击打并用光束控制球的游戏。它是一种砖块消除类游戏。在这里，你需要努力让球不从光束上掉落，并击中那个大的白球。这就是这款游戏的目标：在不让自己的球从光束上掉下来的情况下，尽可能多地摧毁白色球。当你击中白球时，她会消失，新的白球会在新位置出现。

## 怎么玩

使用鼠标来控制光束
