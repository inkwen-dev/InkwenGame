# 圣诞收藏

<a href="https://inkwengame.com/zh/games/christmas-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-collection/cover.jpg)

在这个HTML5游戏中收集圣诞物品。按下任意一个圣诞物品开始游戏。现在用鼠标或指尖在相邻的相同物品上移动（水平、垂直或对角线方向）。至少选择3个物品。松开鼠标按钮以完成匹配。每6个物品会获得一个奖励。超过7个物品将获得时间奖励。在规定时间内收集目标圣诞物品，否则游戏失败。你能玩到的最高级别是多少？
