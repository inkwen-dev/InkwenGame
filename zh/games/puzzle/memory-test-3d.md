![cover](https://img.inkwengame.com/games/memory-test-3d/cover.jpg)

你身处一个迷宫中，需要找到通往按钮的路径。你只能查看地图5秒钟，这取决于你的记忆力和大脑能力。

## 怎么玩

使用 WASD 移动，鼠标控制视角，按 Esc 返回主菜单。如果你忘记了地图或迷失方向，可以使用此功能。
