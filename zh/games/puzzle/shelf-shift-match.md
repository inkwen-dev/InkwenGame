# 货架移动匹配

<a href="https://inkwengame.com/zh/games/shelf-shift-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shelf-shift-match/cover.jpg)

在《货架移动匹配》中测试你的策略和速度！移动货架上的物品，组成三个一组的完美匹配，从而清除障碍，揭示隐藏的阴影物品。但要小心——错误的移动可能会堵塞货架，导致无法再移动，最终游戏结束！如果卡住了，可以使用洗牌按钮打乱局面，寻找新的匹配组合。
