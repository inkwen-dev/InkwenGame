# StickyConnect

<a href="https://inkwengame.com/zh/games/stickyconnect" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickyconnect/cover.jpg)

StickyConnect 是一款受到围棋启发的策略游戏，带来新颖而富有创意的游戏体验。你的任务是通过聪明的走法连接并占领棋盘上的区域。每一步都需要仔细计算，以扩展你的控制范围并阻挡对手。上手简单但策略深度十足，StickyConnect 提供了一种引人入胜且令人着迷的智力体验。
