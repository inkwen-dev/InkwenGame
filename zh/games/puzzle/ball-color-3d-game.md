# 球色3D游戏

![cover](https://img.inkwengame.com/games/ball-color-3d-game/cover.jpg)

Ball Color3D中的物体由各种几何形状组成，包括常见的球体、立方体和菱形体，以及各种不规则的3D形状。通过触摸屏幕调整角度，将小球射向对应3D形状的部分，并将小球颜色涂在射击目标周围。绚丽的色彩和无限关卡将为您展现游戏的魅力！
