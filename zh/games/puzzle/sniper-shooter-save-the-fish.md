# 狙击手 - 拯救鱼

<a href="https://inkwengame.com/zh/games/sniper-shooter-save-the-fish" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sniper-shooter-save-the-fish/cover.jpg)

这款游戏是一款基于物理引擎的益智游戏，重新定义了泡泡射击游戏类型。游戏围绕一个旋转的六边形结构展开，每个关卡都考验玩家适应不断变化的角度、运动和重力。游戏采用海洋主题的视觉风格，讲述了一只螃蟹拯救小丑鱼的轻松故事，将策略、物理和沉浸式设计巧妙融合，带来耳目一新的游戏体验。

## 怎么玩

瞄准并向六边形结构发射泡泡。撞击可能会触发旋转，实时改变泡泡的方向和运动轨迹。利用时机、角度和结构移动来清除泡泡并完成关卡目标。
