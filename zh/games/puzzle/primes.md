# 质数

<a href="https://inkwengame.com/zh/games/primes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/primes/cover.jpg)

质数是一款游戏中，有两种球分别印有数字7或9。需要将它们分别收集到装有质数编号球或非质数编号球的碗中，通过鼠标按住并释放来交换两个碗。尽情享受吧 :)

## 怎么玩

按住并释放鼠标以在蓝色球和红色球的碗之间交换
