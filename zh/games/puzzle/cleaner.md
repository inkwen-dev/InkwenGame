# 清洁器

<a href="https://inkwengame.com/zh/games/cleaner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cleaner/cover.jpg)

在这个包含50个关卡的游戏中，你需要点击网格中的一个格子，使其及其上下左右四个相邻格子（垂直和水平方向）也发生改变。你必须让整个网格变得干净！

## 怎么玩

在屏幕上触摸以更改网格中的格子
