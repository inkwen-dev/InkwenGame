# 怪物配对

<a href="https://inkwengame.com/zh/games/monsters-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monsters-match/cover.jpg)

怪物配对是一款简单的酷炫游戏，要求根据怪物主题找到卡片配对！记住卡片上所有酷炫又搞笑的怪物，按照目标匹配两对或三对。玩完整个游戏并赢得胜利。
