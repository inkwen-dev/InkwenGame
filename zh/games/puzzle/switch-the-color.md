# 切换颜色

<a href="https://inkwengame.com/zh/games/switch-the-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/switch-the-color/cover.jpg)

颜色切换是一款游戏，你需要让球穿过不同颜色的障碍物。障碍物可以是圆形或十字形的障碍物。游戏中会有一段不同颜色的区域，球只能在与球本身颜色相同的区域移动。点击屏幕来控制球，尝试找到通过障碍物的最佳路径并收集星星。尽可能长时间地游玩，并收集更多的星星。

## 怎么玩

点击屏幕来玩这个游戏
