# X 气泡套装

![cover](https://img.inkwengame.com/games/x-bubble-sets/cover.jpg)

有趣的彩色气泡。点击它们！在游戏 X-Bubble Sets 中，你需要发射气泡并落入相同颜色的堆中。消除所有气泡，获得分数并完成关卡。

## 怎么玩

瞄准并点击以向按压方向发射气泡。如果它们进入同色气泡堆且数量达到三个或更多，这些气泡就会爆炸。悬挂在空中的气泡也会爆炸
