# 超级跑车拼图

<a href="https://inkwengame.com/zh/games/supercars-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/supercars-jigsaw/cover.jpg)

在这个游戏中，你将获得一些超级跑车的图像，图片被切割成许多小块。你还会得到这些碎片的布局。你只需要将正确的碎片放到正确的位置，就能以同样的方式还原出完整的图像。

## 怎么玩

使用鼠标或轻触屏幕
