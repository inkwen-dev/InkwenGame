# 彩色纱线分类

<a href="https://inkwengame.com/zh/games/color-yarn-sort" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-yarn-sort/cover.jpg)

彩色纱线分类是一款有趣且令人放松的拼图游戏，你需要将五颜六色的纱线线轴放入对应的桶中。挑战在于：你放置桶的空间有限，必须仔细思考该移动哪个桶。每种颜色的纱线都必须放入对应颜色的桶中，但你只能将桶移动到可用的位置——容错空间为零！

## 怎么玩

目标是将纱线与其对应的彩色桶匹配。你一次只能移动一个桶，每个桶占据一个空间。如果放置错误，你将失去一个空间。一旦所有空间都被填满，你就输了。
