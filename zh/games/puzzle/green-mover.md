# 绿色移动者

<a href="https://inkwengame.com/zh/games/green-mover" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/green-mover/cover.jpg)

绿色移动者是一款包含40个关卡的游戏，您需要控制绿色球体，目标是收集关卡中的所有星星。移动球体时，它只会停在与固体碰撞时。找出最佳路径！

## 怎么玩

触摸屏幕进行移动
