# 炸球

<a href="https://inkwengame.com/zh/games/blast-the-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blast-the-ball/cover.jpg)

这是一款结合速度与技巧的趣味游戏。你的目标是通过射击引爆设定在100个不同关卡中的球。使用10种不同的武器和4种奖励来提升你的策略。获得高分，登上排行榜顶端！

## 怎么玩

使用 A 和 D 键或 LEFT 和 RIGHT 箭头键或左键点击进行移动
