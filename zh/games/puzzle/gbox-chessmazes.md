# GBox 棋盘迷宫

<a href="https://inkwengame.com/zh/games/gbox-chessmazes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gbox-chessmazes/cover.jpg)

将国王的消息传递到城堡，通过不同颜色的棋子之间传递。这并不是一场与对手对弈的国际象棋游戏。游戏的目标是解开迷宫，帮助国王到达城堡。

## 怎么玩

可移动的位置会高亮显示，请选择您认为正确的选项。通过按照国际象棋规则，从一个棋子移动到另一个相反颜色的棋子，构建通往城堡的路径。如果卡住了，请点击游戏板顶部的重置按钮
