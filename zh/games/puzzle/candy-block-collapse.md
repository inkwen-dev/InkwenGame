# 糖果方块坍塌

<a href="https://inkwengame.com/zh/games/candy-block-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/candy-block-collapse/cover.jpg)

通过连接两个或更多相同的糖果来坍塌糖果方块。一次坍塌六个或更多的糖果可获得炸弹。连接的糖果越多，获得的分数越高。

## 怎么玩

使用鼠标来玩这款HTML5糖果方块游戏
