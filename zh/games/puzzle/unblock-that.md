# 解封那个

<a href="https://inkwengame.com/zh/games/unblock-that" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/unblock-that/cover.jpg)

解封那个是一款简单又令人上瘾的益智游戏。目标是通过滑动其他方块，将红色方块从棋盘中移出。尽量用最少的步数完成。游戏包含四种难度，从初级到专家级。解封那个可以帮助你训练大脑，让你每天保持思维敏捷。

## 怎么玩

尽可能少地使用移动步骤，将红色方块移出。你可以移动所有木块
