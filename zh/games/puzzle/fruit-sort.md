# 水果分类

<a href="https://inkwengame.com/zh/games/fruit-sort" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-sort/cover.jpg)

你喜欢吃什么口味的糖果棒？快来加入水果分类谜题，制作专属于你的糖果棒，满足你的口味！移动水果，三个或更多相同的水果可以组合并升级，最终目标是达到山楂。如果水果超过叉子的最大限制，你将失败。你能成功制作出山楂糖果棒吗？相信自己！尽情享受乐趣吧！

## 怎么玩

鼠标或点击操作
