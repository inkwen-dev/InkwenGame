# 管道匹配

<a href="https://inkwengame.com/zh/games/pipe-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pipe-match/cover.jpg)

管道匹配是一款旋转卡片游戏，目标是将所有管道连接到终点。点击管道可顺时针旋转它。模糊显示的管道未连接，带有深灰色背景的管道无法移动。要撤销上一步操作，请点击旋转箭头按钮。要重新开始整个谜题，请点击圆形中的箭头。

## 怎么玩

鼠标点击或触摸
