# 魔法匹配滑块

<a href="https://inkwengame.com/zh/games/magical-match-slider" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magical-match-slider/cover.jpg)

水平或垂直滑动一排魔法物品，以形成三个或更多相同物品的水平或垂直匹配。使用鼠标或指尖滑动行，并收集所需物品以完成关卡。尝试一下，看看在这个限时游戏中你能完成多少个关卡。

## 怎么玩
