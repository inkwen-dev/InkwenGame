# 减法：鸟的图像揭开

<a href="https://inkwengame.com/zh/games/subtraction-bird-image-uncover" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/subtraction-bird-image-uncover/cover.jpg)

在这个游戏中，一张鸟的图片被隐藏在减法表达式方块之下。玩家需要将正确的数字气泡拖放到匹配的方块上，以解决这些表达式。每解决一个表达式，鸟的图片就会逐渐显现出来。目标是通过正确完成所有数学问题，完全揭示这张图片。

## 怎么玩

使用鼠标或触控板，将正确的数字气泡拖放到匹配的方块上以解决表达式
