# 太空火箭

<a href="https://inkwengame.com/zh/games/space-rocket" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-rocket/cover.jpg)

太空火箭是一款游戏，你需要从一个星球前往另一个星球。在其他星球上发现外星生命分析后，团队开始被一个奇怪的黑色气泡追击，其目的就是通过从一个星球转移到另一个星球来逃脱，同时不丢失收集到的样本。点击屏幕开始游戏。当你与另一个星球处于同一方向时，点击屏幕即可切换到另一个星球。

## 怎么玩
