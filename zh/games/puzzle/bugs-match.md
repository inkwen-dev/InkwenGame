# 虫虫配对

<a href="https://inkwengame.com/zh/games/bugs-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bugs-match/cover.jpg)

这是一款消除三连游戏，你需要将三个相同的昆虫匹配在一起以消灭它们。在游戏中，你可以随意移动昆虫。重要的是，它们必须在水平或垂直方向上连续排列三个相同。目标是防止昆虫到达屏幕顶部。一旦到达，游戏结束。随着游戏进行，在特定时间段内昆虫的移动速度会加快。这时你需要更快地行动，并消灭更多的昆虫。

## 怎么玩

使用鼠标移动昆虫
