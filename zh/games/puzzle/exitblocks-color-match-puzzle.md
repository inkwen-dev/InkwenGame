# ExitBlocks：颜色匹配拼图

<a href="https://inkwengame.com/zh/games/exitblocks-color-match-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/exitblocks-color-match-puzzle/cover.jpg)

《ExitBlocks：颜色匹配拼图》是一款色彩缤纷的休闲益智游戏，目标是清除拥挤的方块。玩家需要将不同形状的方块滑动到与其颜色匹配的门中，避开障碍物，并在时间耗尽前完成所有布局。紧凑的关卡、流畅的操作和实用的道具，让每一关都充满挑战，但也需要玩家动脑筋。

## 怎么玩

目标：在倒计时结束前，清除棋盘上所有同色方块。

玩法：

- 在电脑上，用鼠标点击并拖动方块。在移动设备上，用一根手指触摸并拖动方块。

- 将每个方块移动到相同颜色的门上。匹配成功的方块会离开棋盘。

- 规划好你的移动，避免方块互相阻挡或困住。

- 如果遇到困难的布局，可以使用道具来辅助。

- 清除所有方块即可赢得关卡并解锁下一个谜题。

主要操作：电脑端：点击鼠标左键并拖动；移动设备端：触摸并拖动。
