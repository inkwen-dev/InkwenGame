# 圣诞瓷砖

<a href="https://inkwengame.com/zh/games/christmas-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-tiles/cover.jpg)

通过连接三个或更多相邻的相同物品来清除圣诞瓷砖板。获得魔法雪花，当无法形成匹配时可用来消除瓷砖。

## 怎么玩

点击瓷砖组以移除
