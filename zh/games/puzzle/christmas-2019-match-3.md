# 2019 圣诞三消

<a href="https://inkwengame.com/zh/games/christmas-2019-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-2019-match-3/cover.jpg)

2019 圣诞三消是一款包含 16 个关卡的优秀三消游戏。在每个关卡中，你需要清除脏格子。将三个或更多相同类型的圣诞符号排成一行或一列，它们就会消失。你不能交换被锁定的符号。如果你用特定形状匹配三个或更多符号，将会获得特殊符号，例如炸弹符号、粉碎符号、闪光符号和时间符号。在规定时间内清除所有脏格子以完成关卡。
