# 滑动方块

<a href="https://inkwengame.com/zh/games/slide-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slide-blocks/cover.jpg)

滑动方块益智游戏是一款休闲益智游戏。拖动形状，将其滑动并放置在完美位置以消除线条。用形状填满线条时会获得酷炫效果。逐行清除以收集分数。

## 怎么玩

使用鼠标左右滑动方块
