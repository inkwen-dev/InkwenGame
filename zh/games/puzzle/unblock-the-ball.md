# 解救小球

<a href="https://inkwengame.com/zh/games/unblock-the-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/unblock-the-ball/cover.jpg)

《解救小球》是一款简单而令人上瘾的益智游戏。游戏中有各种由不同材料制成的管道。玩家只能移动木制管道，使所有管道平滑连接，从而让小球能够被推到终点。在到达目的地的过程中，还可以收集星星，星星越多越好。快来加入我们吧！
