# 方块坍塌挑战

<a href="https://inkwengame.com/zh/games/block-collapse-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-collapse-challenge/cover.jpg)

通过点击水平或垂直相连的同色方块组来坍塌方块。每次坍塌都会获得分数，坍塌的方块组越大，得分越高。底部的状态栏会显示任何已选方块组的预估分数。你可以运用策略来创建更大的方块组。进度会自动保存，因此可以反复游玩以获得更高的分数。请勿让棋盘被方块填满，以保持游戏继续进行。

## 怎么玩

使用鼠标或触控板来玩此游戏
