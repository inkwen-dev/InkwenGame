# Arrower

<a href="https://inkwengame.com/zh/games/arrower" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrower/cover.jpg)

Arrower 是一款极简且令人放松的益智游戏。目标是将所有黄色箭头移动到黄色方框中。您可以通过触摸箭头来实现，它们会朝所指方向（上、左、右或下）移动。此外，您还会发现各种特殊方块，帮助箭头找到正确的路径。尽情享受吧！
