# Splash Colors

<a href="https://inkwengame.com/zh/games/splash-colors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/splash-colors/cover.jpg)

Splash Color 是一款酷炫的游戏，你需要用彩色球击破透明气泡。屏幕上端会落下带有不同颜色线条的透明气泡，你必须用相同颜色的球来击破它们。你有 3 次失误机会，失误次数用尽游戏结束，祝你玩得愉快。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
