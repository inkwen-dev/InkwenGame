# 环

<a href="https://inkwengame.com/zh/games/ring" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ring/cover.jpg)

Ring Game 是一款解谜游戏，你需要控制环。环不能碰到线。线位于环的中间，你需要将环穿过线而不碰到它。线会断裂，且并不总是一条直线。因此你需要小心，尽量不要碰到线。如果你碰到了线，游戏就结束了。

## 怎么玩

轻触屏幕来控制环
