# 甜蜜匹配

<a href="https://inkwengame.com/zh/games/sweet-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweet-match/cover.jpg)

欢迎来到甜蜜匹配益智游戏！滑动以匹配三个或更多相同的糖果，消除它们，并持续匹配直到完成任务，解锁下一关。探索25个挑战关卡，并尝试全部通关！祝你好运！
