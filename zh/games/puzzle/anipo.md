# Anipo

<a href="https://inkwengame.com/zh/games/anipo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/anipo/cover.jpg)

Anipo 是一款轻量但富有挑战性的解谜游戏，你将操控一个具有独特颜色的角色，在地图上的陆地块之间移动。每走一步，你都会在经过的陆地块上留下颜色痕迹，你的任务是计算出一条逻辑路线，将整个区域涂满颜色并完成关卡。关卡设计多样，要求每一步都具备逻辑思维和操作技巧。Anipo 提供了一种适合所有年龄段的放松体验。
