# 移动图钉

<a href="https://inkwengame.com/zh/games/move-the-pin" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/move-the-pin/cover.jpg)

移动图钉是一款有趣的物理游戏——在这个游戏中，你需要推动图钉，帮助彩色小球收集灰色小球，使它们也变成彩色，然后进入透明的烧瓶。游戏共有30个不同的关卡，尽情享受吧。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
