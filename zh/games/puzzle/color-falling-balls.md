# 颜色下落的球

<a href="https://inkwengame.com/zh/games/color-falling-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-falling-balls/cover.jpg)

当两个球接触时，它们的颜色必须相同。如果球的颜色不同，游戏就会结束。球会快速且从四面八方落下，因此你需要迅速反应，并及时改变大球的颜色。点击屏幕可改变大球的颜色。

## 怎么玩

使用鼠标或点击屏幕来玩这个游戏
