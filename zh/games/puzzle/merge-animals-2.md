# 合并动物

<a href="https://inkwengame.com/zh/games/merge-animals-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-animals-2/cover.jpg)

合并动物是一款小型塔防游戏，你需要与不同的动物互动，以阻止试图夺取它们王国的入侵者。当你的预算允许时，点击“随机宠物”按钮来获取构成你防御的不同动物。相同数字的动物可以合并，从而增强它们的战斗力。你还可以通过商店升级每只动物，这强烈建议你使用，以取得胜利！
