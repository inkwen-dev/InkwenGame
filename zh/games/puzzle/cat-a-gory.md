# 猫-类

<a href="https://inkwengame.com/zh/games/cat-a-gory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cat-a-gory/cover.jpg)

猫-类是一款脑洞大开的单词解谜游戏，让你欲罢不能。游戏开始时，你有8只可爱的猫咪绑着C4炸弹！在游戏过程中，你需要猜字母。每猜错一个字母，就会有一只可怜的小猫爆炸！每解开一个谜题，你就能找回2只猫咪。当你的猫咪全部用完时，游戏结束。

## 怎么玩

使用鼠标或轻触屏幕进行游戏
