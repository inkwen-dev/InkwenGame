# 表情符号记忆：找到一对

<a href="https://inkwengame.com/zh/games/emoji-memory-find-a-pair" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/emoji-memory-find-a-pair/cover.jpg)

你需要翻开牌面，尝试找到两张相同的牌。

## 怎么玩

用鼠标或手指点击触摸屏上任意一张翻开的牌即可将其翻开。

当玩家翻开两张牌后，如果这两张牌相同，则算玩家成功翻开一对牌。如果两张牌不同，则翻回原位。

之后，您可以继续翻开后续的牌。

## 介绍

你需要翻开牌面，尝试找到两张相同的牌。

如果翻开两张不同的牌，它们会自动翻回正面，给玩家一些时间记住它们。

当玩家翻开游戏区域内所有相同的牌时，即可完成关卡。

游戏还包含两种额外的模式，你可以与其他玩家竞争，创造新的纪录：一种是限时纪录，另一种是最少步数纪录。
