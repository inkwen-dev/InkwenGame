# 甜蜜世界

<a href="https://inkwengame.com/zh/games/sweet-worlds" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweet-worlds/cover.jpg)

你所需要做的就是匹配相同颜色的糖果。只能相邻或对角相邻，点击你想匹配的糖果并画线连接相同的糖果，然后你的糖果就会爆炸，爆炸时获得分数，你能得到最高分吗？你可以用鼠标来玩。尽情享受吧。
