# 钻石任务

<a href="https://inkwengame.com/zh/games/diamonds-misiion" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/diamonds-misiion/cover.jpg)

当点击鼠标左键或右键时，钻石开始下落，你需要将正在下落的珠宝与下方相同类型的珠宝进行匹配。你匹配的钻石越多，它们下落的速度就越快。尽情享受吧！
