# 精准跳跃

<a href="https://inkwengame.com/zh/games/exact-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/exact-jump/cover.jpg)

正如游戏名称所示，在这款游戏中你需要非常精确。你需要将球准确地放入目标中。点击屏幕以移动跳跃到目标位置。每次将球放入目标后，目标的位置都会改变。尽可能多地准确命中目标，直到游戏结束。你可以犯三次错误，之后游戏就会结束。
