# 表情符号合并狂潮

<a href="https://inkwengame.com/zh/games/emoji-merge-madness" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/emoji-merge-madness/cover.jpg)

合并相同的表情符号，将其进化成疯狂的新形态！在6条独特的进化链中发现全部30个表情符号：快乐、酷炫、火焰、爱情、诡异和大脑。点击两个相邻的相同表情符号以合并它们并解锁下一阶段。你能进化到多远？特色：复古像素艺术风格，每条进化链包含5个阶段，发现追踪器，连击得分系统，以及令人上瘾的“再试一次合并”玩法。简单易学…

## 怎么玩

鼠标点击或轻触以选择并合并表情符号 点击一个表情符号，然后点击一个相邻的相同表情符号以合并它们 当无可用移动时，使用洗牌按钮
