# 2019 圣诞节系列

<a href="https://inkwengame.com/zh/games/christmas-collection-2019" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-collection-2019/cover.jpg)

收集圣诞礼物，让圣诞老人能把它们发送给乖巧的小男孩和小女孩。点击任意礼物开始游戏。现在用鼠标或指尖在相邻的相同圣诞礼物上移动（水平、垂直或对角线方向）。至少选择3个礼物。松开鼠标按钮完成匹配。每第6个礼物会提供奖励。超过7个礼物将获得时间奖励。在规定时间内收集完所需礼物，否则游戏失败。
