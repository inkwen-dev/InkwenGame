# 果冻爆炸

<a href="https://inkwengame.com/zh/games/jelly-boom" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jelly-boom/cover.jpg)

果冻爆炸是一款画面精美的益智游戏。通过点击糖果来完成关卡，但点击次数有限，需谨慎计算。游戏中有四种类型的糖果，当被触碰或被其他糖果击中时，它们会生长并爆裂。部分关卡还包含额外元素——冰块、鞭炮和炸弹，这些道具有助于摧毁所有甜食。

## 怎么玩

使用鼠标或点击屏幕
