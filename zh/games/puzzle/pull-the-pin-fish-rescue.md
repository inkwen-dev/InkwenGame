# 拔掉插销鱼救援

![cover](https://img.inkwengame.com/games/pull-the-pin-fish-rescue/cover.jpg)

拔掉插销：鱼救援！是一款轻松上瘾的益智游戏，包含许多有趣的谜题。游戏中会出现多个隔间，它们被隔板分隔开来。在一个隔间里你会看到一条鱼，而在另一个隔间里则有水。你需要仔细观察所有细节，然后拔掉插销。这样就能打开隔板，让水流向鱼。

## 怎么玩
