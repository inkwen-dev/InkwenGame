# 爱心消消乐

![cover](https://img.inkwengame.com/games/hearts-match-3/cover.jpg)

交换相邻的方块，以形成三个相同方块的水平或垂直行。要完成一个关卡，你需要将棋盘上所有方块的颜色变为指定颜色。收集超过5个方块即可获得一个法术（增强道具），它会显示在屏幕右侧。通过拖拽并将法术放置在目标方块上施放。点击“提示”和“超能”法术即可施放。
