# 找到南瓜

<a href="https://inkwengame.com/zh/games/find-the-pumpkin" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-the-pumpkin/cover.jpg)

这个游戏的目标是找出南瓜藏在哪里！享受游戏吧。你会玩得很开心！

## 怎么玩

点击藏有南瓜的帽子以获得分数。如果你选错了帽子，就会被困住。每次击中都可获得分数
