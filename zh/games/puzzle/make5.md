# MAKE5

<a href="https://inkwengame.com/zh/games/make5" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/make5/cover.jpg)

将三个相同数字和颜色的方块相邻放置，以水平、垂直或两者兼有的方式合并它们。你还可以在将方块放置到网格之前旋转它们！方块的数值会从1增加到5。方块数值越高，获得的分数就越多。你能做到吗？

## 怎么玩

使用鼠标或轻触来移动和旋转方块
