# 宝石交汇

<a href="https://inkwengame.com/zh/games/gems-junction" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gems-junction/cover.jpg)

通过射击一个相同的宝石来阻止宝石部队前进。游戏有两种模式：在初级模式中，一组两个宝石可以被消除；而在专家模式中，你需要至少三个宝石才能消除。收集所有星星以赢得游戏。一颗宝石掉落将扣除四条生命中的一条。享受这款游戏中精彩的能力升级。
