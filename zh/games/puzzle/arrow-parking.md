# 箭头停车

<a href="https://inkwengame.com/zh/games/arrow-parking" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrow-parking/cover.jpg)

《箭头停车》是一款轻松的益智游戏，挑战玩家的预判能力。玩家需要放置箭头方块来规划最佳路线，引导汽车驶入车库，并解决难度不断提升的停车谜题。

## 怎么玩

桌面端操作：

- 鼠标：将箭头方块拖放到棋盘上。

移动端操作：

- 触摸：将箭头方块拖放到棋盘上。
