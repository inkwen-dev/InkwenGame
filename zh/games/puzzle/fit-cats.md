# 健身猫咪

<a href="https://inkwengame.com/zh/games/fit-cats" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fit-cats/cover.jpg)

猫咪喜欢盒子！将不同大小的猫咪发射进盒子里。如果两个相同大小的猫咪相互接触，它们会合并成一个更大的猫咪。在游戏中，你还可以使用鼠标将任意猫咪从盒子里驱逐出去。此外，偶尔还能捕捉到老鼠，获得这个机会。尝试解锁所有猫咪。

## 怎么玩

点击盒子内的任意位置以发射猫咪。相同大小的猫咪会合并成更大的猫咪。使用鼠标可将猫咪从盒子中删除。
