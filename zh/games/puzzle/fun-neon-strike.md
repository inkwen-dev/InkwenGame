# 趣味霓虹打击

<a href="https://inkwengame.com/zh/games/fun-neon-strike" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fun-neon-strike/cover.jpg)

欢迎来到我们的最新游戏《趣味霓虹打击》。在游戏中，你有两个方块，一个是红色的，另一个是蓝色的。一条水平线会不定时地在红色和蓝色之间切换颜色。游戏的目标是用相应颜色的方块触碰水平线。每次成功触碰，你将获得一分。尽可能多地得分吧！

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
