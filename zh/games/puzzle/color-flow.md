# 色彩流动

<a href="https://inkwengame.com/zh/games/color-flow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-flow/cover.jpg)

这款游戏玩法非常简单但极具挑战性。你将从右上角的方块开始，需要将其颜色与周围方块匹配。为此，你需要从屏幕底部选择一个周围方块的颜色。总共有6种颜色，你的最终目标是在22步或更少的步骤内让所有方块颜色相同。

## 怎么玩

使用鼠标操作游戏，或点击屏幕
