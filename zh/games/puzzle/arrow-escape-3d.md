# 箭矢逃脱3D

<a href="https://inkwengame.com/zh/games/arrow-escape-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrow-escape-3d/cover.jpg)

《箭矢逃脱3D》是一款轻松的3D益智游戏，游戏场景设定在一个立方体表面。点击彩色箭矢，让它滑出立方体——但只有当路径畅通无阻时，箭矢才能逃脱。旋转立方体，找到所有箭矢，按正确顺序清除障碍物，最终清空整个立方体。1000个关卡，每个关卡都短小精悍，趣味十足，等你来挑战。

## 怎么玩

- 拖动方块任意位置即可旋转方块，查看全部六个面。

- 点击箭头即可使其沿指向方向滑出。

- 箭头只有在路径上没有任何障碍物时才能滑出——请先清除障碍物。

- 清除所有箭头即可通关。注意你的生命值——被阻挡的点击会消耗一点生命值！
