# 数学火柴

<a href="https://inkwengame.com/zh/games/math-matchsticks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-matchsticks/cover.jpg)

数学火柴是一款规则简单但趣味十足且富有挑战性的逻辑谜题游戏，适合所有年龄段的玩家。玩家需要根据给定的数学问题，通过移动火柴来改变数字或符号，使等式成立。游戏共有100个关卡，随着关卡提升，难度逐渐增加，需要玩家投入更多的思考与耐心。这款逻辑与计算类游戏能够锻炼玩家的智力和数学能力。

## 怎么玩

这些数学等式大多不正确。你的挑战是，在每个谜题中恰好移动一根火柴，使等式成立。有些谜题可能存在多种解法。
