# 给可爱猫咪的牛奶

<a href="https://inkwengame.com/zh/games/milk-for-cute-cat" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/milk-for-cute-cat/cover.jpg)

游戏《给猫咪的牛奶》的目标是用牛奶喂食各种猫咪。有一只坐着的猫，上方一定高度处挂着一个装有牛奶的袋子，袋子像钟摆一样左右摆动。你需要判断最佳时机，在牛奶袋正好位于猫咪上方时剪断绳子。如果猫咪吃饱了，你将获得分数。尽情享受吧。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
