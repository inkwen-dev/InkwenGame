# 弹跳球跳跃

<a href="https://inkwengame.com/zh/games/bounce-ball-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bounce-ball-jump/cover.jpg)

弹跳球跳跃是一款以球为主题的解谜游戏。控制球在楼梯上移动和跳跃。楼梯上有尖刺和其他障碍物，你需要避开它们。但也有需要收集的道具，这些道具将在游戏中帮助你。你可以组装一个护盾，暂时保护你免受尖刺伤害。还有一个棍子，可以将你前方的所有障碍物推开。

## 怎么玩

点击屏幕来控制球
