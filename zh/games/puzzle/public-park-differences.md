# 公共公园差异

<a href="https://inkwengame.com/zh/games/public-park-differences" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/public-park-differences/cover.jpg)

这是一款找不同类型的拼图游戏，玩家必须在两张几乎相同的图片中找出至少5处差异。使用鼠标或触摸板点击差异处。
