# 扫雷

<a href="https://inkwengame.com/zh/games/minesweeper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minesweeper/cover.jpg)

扫雷是一款单人解谜类视频游戏。游戏的目标是在不引爆任何隐藏的‘地雷’或炸弹的情况下，清除一个包含隐藏地雷的矩形棋盘，借助每个方格周围地雷数量的提示来完成。

## 怎么玩
