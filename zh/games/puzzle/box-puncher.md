# 拳击箱

<a href="https://inkwengame.com/zh/games/box-puncher" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/box-puncher/cover.jpg)

在这个游戏中，你是一名拳击手，需要击打箱子来获得分数。但这是一个限时游戏，你需要避开障碍物。当障碍物出现时，你需要换边，并从另一边击打箱子。尽可能多地得分，并享受游戏的乐趣。

## 怎么玩
