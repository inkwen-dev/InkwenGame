# 甜蜜糖果

<a href="https://inkwengame.com/zh/games/sweety-candy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweety-candy/cover.jpg)

你的任务是至少组合三个美味的甜点，使它们消失。持续匹配直到达成目标以推进关卡！确保每关获得三颗星，以解锁通往更多关卡的大门。如果你匹配超过三个相同颜色的糖果，将获得强力道具，帮助你迅速达成关卡目标。每天回来领取礼物。

## 怎么玩
