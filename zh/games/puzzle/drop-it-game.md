# Drop It 游戲

<a href="https://inkwengame.com/zh/games/drop-it-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drop-it-game/cover.jpg)

Drop It 是一款寶石消除益智遊戲。它會水平移動寶石，填滿一行寶石，並消除高分。消除一行即可得分。如果消除了多行，則可獲得更高分數。如果玩家的寶石到達頂部，遊戲結束。這款遊戲既有趣又具策略性。玩家需要觀察、判斷、移動，最終達到一列或多列。

## 怎么玩

使用滑鼠或點擊操作
