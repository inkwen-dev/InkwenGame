# 建造你的机器人

<a href="https://inkwengame.com/zh/games/build-your-robot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/build-your-robot/cover.jpg)

当你能在电脑或手机上轻松完成机器人制作时，谁还需要一个大型工厂呢！在这个游戏中，你可以使用现有的零件轻松快速地创造出你心目中的机器人！你还可以保存你发明的图片（屏幕顶部的相机按钮），并展示给你的朋友！
