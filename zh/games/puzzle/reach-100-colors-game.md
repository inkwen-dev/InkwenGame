# 达到100：颜色游戏

<a href="https://inkwengame.com/zh/games/reach-100-colors-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/reach-100-colors-game/cover.jpg)

达到100是一款关于谜题和思考的游戏，您必须将数字组合起来，创造出总和为100的结果。您可以水平或垂直滑动不同的形状和数字，并将数字相加。当您达到100的总和时，该形状会冻结，不能再使用。将所有形状组合起来，以完成关卡。挑战您的大脑，在六十个不同关卡中找到解决方案。关卡难度会逐渐增加。
