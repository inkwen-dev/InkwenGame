# 锁

<a href="https://inkwengame.com/zh/games/lock" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lock/cover.jpg)

锁是一款点击谜题游戏，当橙色堆叠在黄色球上时，你需要及时点击。黄色球会在圆周上旋转。球会移动到圆周的左侧或右侧。当球和棍子对齐时，请在正确的时间点击屏幕。在这个游戏中取得最高分并享受乐趣。
