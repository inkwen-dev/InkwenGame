# 垃圾分类

<a href="https://inkwengame.com/zh/games/trash-sort" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/trash-sort/cover.jpg)

你扮演一名垃圾分类员，正确分类每一个瓶子、罐子、纸屑或食物垃圾，都能帮助自然环境恢复生机。

## 怎么玩

点击并拖拽物品到对应的垃圾桶中。

每个垃圾桶都有一个符号或颜色，代表一种垃圾类型（例如，瓶子代表玻璃，树叶代表有机垃圾）。

## 介绍

你扮演一名垃圾分类员，正确分类每一个瓶子、罐子、纸屑或食物垃圾，都能帮助自然环境恢复生机。

随着你回收的垃圾越来越多，场景也会逐渐从污染严重、灰暗无光的状态，变得干净、色彩缤纷，再次充满快乐的动物。

游戏玩法简单，但看着环境因你的行动而恢复生机，却能带来极大的满足感。
