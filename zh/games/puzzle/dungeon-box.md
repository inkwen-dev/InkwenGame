# 地牢盒子

<a href="https://inkwengame.com/zh/games/dungeon-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dungeon-box/cover.jpg)

你必须阻止那个可怜的球逃离地牢。地牢的三面被墙挡住，底面是空的，但你可以通过点击或触摸在底面召唤一道墙。请注意，这道墙只持续一瞬间，你需要精准的时机。球会在地牢中移动，当它到达底部时，你必须及时召唤墙来阻挡它，使其留在房间内。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
