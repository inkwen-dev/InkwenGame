# 方块匹配 3D

《方块匹配3D》是一款轻松又益智的3D益智游戏，你需要一块一块地拆解一个巨大的方块立方体。每个方块都带有可爱的图标——甜甜圈、动物、表情符号、音乐等等。

## 怎么玩

- 点击任何开口的方块即可拾取——埋在地下的方块暂时无法拾取。

- 如果方块的图标与顶部的某个目标标记匹配，它会直接飞向该目标。

- 任何其他方块都会进入底部的存储栏。如果存储栏溢出，则游戏结束——所以不要囤积方块！

- 完成一个目标标记后，下一个类别会滑入；该类别的已存储方块会自动飞向存储栏。

- 在计时器结束前清除所有类别即可赢得关卡。

- 卡关了？使用道具：提示可以找到匹配的方块，魔法棒可以立即收集一个方块，洗牌可以重新排列图标，撤销可以返回你放置的最后一个方块。

## 介绍

《方块匹配3D》是一款轻松又益智的3D益智游戏，你需要一块一块地拆解一个巨大的方块立方体。每个方块都带有可爱的图标——甜甜圈、动物、表情符号、音乐等等。

将方块匹配到当前类别的目标上，深入探索方块的结构，并在时间耗尽前消除整个立方体。游戏上手简单，精通却需要技巧：谨慎点击，因为底部的方块槽很快就会填满。

数十个关卡、丰富多彩的图标以及提示、洗牌、魔棒和撤销等实用道具，让你畅玩数小时！
