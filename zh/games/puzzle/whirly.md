# 旋转风车

<a href="https://inkwengame.com/zh/games/whirly" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/whirly/cover.jpg)

Whirly 是一款游戏，其中带有四个彩色区域的风车会旋转，同时有四个彩色的袋子下落，这些袋子应落在风车相同颜色的区域上。一旦错过，游戏即结束。这款游戏为孩子们设计得更加简单易玩，尽情享受乐趣吧 :)
