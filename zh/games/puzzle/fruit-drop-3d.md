# 水果下落3D

<a href="https://inkwengame.com/zh/games/fruit-drop-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-drop-3d/cover.jpg)

《水果下落3D》是一款色彩缤纷、基于物理引擎的水果合并益智游戏。将水果投入容器，合并相同的水果，创造出更大更有价值的水果，并尽可能地建造最大的水果。精心计划每一次下落，巧妙利用物理引擎，努力打破自己的最高分，同时还要避免容器溢出。

## 怎么玩

用鼠标或手指左右移动水果，然后点击或轻触即可放置。两个相同的水果接触后会合并成一个更大的水果，并为你赢得分数。不断合并水果，创造出更大的水果，从而提高你的分数。如果水果堆积过高并到达容器顶部，游戏结束。
