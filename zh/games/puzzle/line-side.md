# 线侧

<a href="https://inkwengame.com/zh/games/line-side" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/line-side/cover.jpg)

线侧是一款反应解谜游戏。你的任务是控制圆形避开方块。为此，你需要改变线条，前往线的左侧或右侧。点击屏幕可切换圆形所在侧。你需要及时切换，既不能太快也不能太慢，否则会撞上方块。创造属于自己的分数，尽情享受游戏乐趣。

## 怎么玩

点击屏幕开始游戏
