# 合并数字

<a href="https://inkwengame.com/zh/games/merge-number" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-number/cover.jpg)

合并数字是一款免费的在线益智游戏，专为男孩设计，可在PuzzleGame上玩。你只需在有限的网格中合并数字，形成更大的数字。记住，你还受到接触数字次数的限制，以完成关卡。这极具挑战性，考验你的策略，努力获得最高分吧！支持在手机、平板和电脑上游玩。尽情享受乐趣！
