# 消灭病毒

<a href="https://inkwengame.com/zh/games/killing-the-virus" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/killing-the-virus/cover.jpg)

通过连接两个或更多相同的病毒来消除病毒。消除六个或更多的病毒可获得炸弹。连接的病毒越多，得分越高。
