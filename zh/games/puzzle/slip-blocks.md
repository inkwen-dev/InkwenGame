# 滑块

<a href="https://inkwengame.com/zh/games/slip-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slip-blocks/cover.jpg)

滑块是一款适合儿童的有趣益智游戏。你是一个特定颜色的立方体，只能在与你的立方体颜色相同的点所构成的路径上移动。通过控制键，你需要指示你的角色将要移动的路线。到达终点后，你的角色将进入传送门并被传送到游戏的下一关。

## 怎么玩

使用鼠标操作游戏，或点击屏幕
