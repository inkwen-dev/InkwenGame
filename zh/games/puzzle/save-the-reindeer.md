# 拯救驯鹿

<a href="https://inkwengame.com/zh/games/save-the-reindeer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-reindeer/cover.jpg)

找到15个圣诞节物品，并通过走过它们来收集。然后去见雪人，他会让你穿过冰屋到达另一边。接着你只有60秒的时间在冬雪中找到那只迷路的小驯鹿，否则你会被冻住。每局游戏中，驯鹿的位置都会不同。有时他很容易找到，有时则不然。祝你好运，圣诞快乐。

## 怎么玩

使用方向键移动角色，或在移动设备上使用屏幕上的箭头按钮
