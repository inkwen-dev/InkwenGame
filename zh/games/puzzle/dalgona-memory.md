# Dalgona Memory

<a href="https://inkwengame.com/zh/games/dalgona-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dalgona-memory/cover.jpg)

这是一款以Dalgona糖果图案为主题的记忆游戏，包含八种不同的形状：星星、笑脸、六边形、圆形等。您可以选择2到8对进行匹配游戏。

## 怎么玩

点击糖果以揭开它们，配对相同图案
