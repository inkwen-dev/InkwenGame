# 冰淇淋记忆

<a href="https://inkwengame.com/zh/games/ice-cream-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ice-cream-memory/cover.jpg)

冰淇淋记忆是一款独特又有趣的益智游戏。通过这款游戏，你可以了解并提升自己的记忆力。游戏玩法非常简单：你需要根据屏幕上显示的冰淇淋图片来制作冰淇淋，而图片只会显示几秒钟，之后你需要根据之前看到的图片来制作冰淇淋。此外，制作冰淇淋还有时间限制。如果你制作的冰淇淋与之前显示的图片不一致，那么你制作的冰淇淋就会被扔进垃圾桶。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
