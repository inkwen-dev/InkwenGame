# 推箱子游戏

<a href="https://inkwengame.com/zh/games/push-the-box-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/push-the-box-game/cover.jpg)

地图上会有明确标记的点，将箱子推到这些点上，直到所有点都被填满即可通过关卡。随着新关卡的增加，游戏难度会持续提升。有可能走错一步而导致无法通过关卡！

## 怎么玩

点击地图上的位置来移动角色，直到所有标记的位置都被填满
