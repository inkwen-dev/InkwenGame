# 草收割者

<a href="https://inkwengame.com/zh/games/grass-reaper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/grass-reaper/cover.jpg)

草收割者是一款休闲小游戏，只需控制收割者并为每一关收集指定数量的草即可。初始状态下，你的收割者无法一次性收集所有草，因此你需要先收集并出售草，然后用获得的金币升级收割者，从而更快地通过关卡！

## 怎么玩

滑动以移动
