# 青绿色方块

<a href="https://inkwengame.com/zh/games/turquoise-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/turquoise-blocks/cover.jpg)

青绿色方块是一款游戏，你需要将方块拖动到网格中，填满行或列以得分。你始终有三个方块可以使用。即使没有空间放置方块也不会输，唯一的限制是时间（金色条）。你可以收集并使用硬币来获得道具（翻转和旋转网格、拖动并放置固定方块、将方块向下排列以及删除方块）

## 怎么玩

在屏幕上点击以移动方块
