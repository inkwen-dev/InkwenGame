# 心盒 - 物理谜题游戏

<a href="https://inkwengame.com/zh/games/heart-box-physics-puzzles-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/heart-box-physics-puzzles-game/cover.jpg)

让机器人通过教授鼠的全部实验谜题房间，从而脱离充电器！利用20种物理道具的特性来完成所有谜题：测试方块、保龄球、弹簧蹦床、炸药、可移动平台、传送带、风扇、气动管道、激光、传送门、动态锯、开关按钮等！

## 怎么玩

使用鼠标或触摸来与物体互动。完成关卡并解锁所有有趣的卡通内容。不想完成关卡？那就自己创建关卡吧。
