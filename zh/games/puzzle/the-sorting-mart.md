# 排序商店

<a href="https://inkwengame.com/zh/games/the-sorting-mart" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-sorting-mart/cover.jpg)

《排序商店》是一款商店整理益智游戏，让你体验在商店购物的乐趣。将物品在货架间重新排列，使同一货架上出现三个相同的物品，即可清除该货架，让上方的货架随之下降。清空整个堆栈后，相邻的货架会移动，务必在时间耗尽前持续匹配。如果卡住了，可以使用洗牌按钮打乱货架，更容易找到匹配项。随着关卡难度提升，挑战你的整理技巧吧！

## 怎么玩

使用鼠标或触控板拖动物品在货架间移动。在货架上排列三个相同的物品以清除它们，使上方的货架掉落。完全清空一个堆栈后，相邻的货架会移动。在时间耗尽前收集所有物品
