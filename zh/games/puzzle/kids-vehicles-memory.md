# 儿童车辆记忆

<a href="https://inkwengame.com/zh/games/kids-vehicles-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kids-vehicles-memory/cover.jpg)

儿童车辆记忆是一款游戏，你需要在短时间内记住图片中儿童车辆的位置。之后你需要从之前的图片中找到对应的图片。每通过一关，你用于猜测所有图片的时间就会减少。因此，请集中注意力，并在关卡开始前仔细记住图片的位置。

## 怎么玩
