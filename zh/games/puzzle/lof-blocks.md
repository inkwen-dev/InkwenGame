# Lof Blocks

<a href="https://inkwengame.com/zh/games/lof-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lof-blocks/cover.jpg)

通过触摸或点击来收集相似的方块组。如果只收集单个方块，将扣除200分。收集所有方块以完成关卡。如果你组成更大的组，将会获得道具。
