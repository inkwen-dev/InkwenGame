# MergeMaster

<a href="https://inkwengame.com/zh/games/mergemaster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mergemaster/cover.jpg)

一款以匹配和消除为核心的休闲手机游戏。游戏采用鲜艳的色彩，视觉风格充满海滩元素。背景音乐和音效让人联想到在海滩上悠闲漫步，营造出一种放松的海滩漫步氛围，让玩家沉浸于听觉体验之中。

## 怎么玩

鼠标点击进行游戏 玩家需通过点击主游戏棋盘上相邻的相同数字，将它们合并以消除，并生成一个数值翻倍的新数字
