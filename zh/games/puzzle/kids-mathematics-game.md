# 儿童数学游戏

<a href="https://inkwengame.com/zh/games/kids-mathematics-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kids-mathematics-game/cover.jpg)

你有120秒时间完成尽可能多的算式。在每个算式中，基本的算术运算缺失，你需要根据数字和答案选择正确的运算符来完成算式。当你的120秒结束时，你的得分将根据正确和错误的答案数量计算。所以要迅速行动，尽最大努力正确回答尽可能多的问题。

## 怎么玩

使用鼠标操作游戏或点击屏幕
