# Pop It 对战 旋转盘

<a href="https://inkwengame.com/zh/games/pop-it-vs-spinner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pop-it-vs-spinner/cover.jpg)

通过一次匹配至少两个相同的方块，尝试在三个关卡中移除所有的 PopIt。当没有可匹配的方块时，使用旋转盘模式生成新的方块并清理整个关卡。

## 怎么玩

使用鼠标或手指来消除匹配的配对
