# 三消谜题对决

<a href="https://inkwengame.com/zh/games/3-match-puzzle-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/3-match-puzzle-battle/cover.jpg)

消除三个谜题以攻击敌人并推进关卡。共有四种类型的谜题：恢复、攻击、防御和金币，因此请根据你的体力和敌人的强度来制定策略以消除谜题。如果产生连击，可以对敌人造成巨大伤害。获得金币后，升级玩家等级并推进关卡。
