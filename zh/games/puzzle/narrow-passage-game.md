# 狭窄通道游戏

![cover](https://img.inkwengame.com/games/narrow-passage-game/cover.jpg)

在狭窄通道游戏中，你的任务是带着球通过所有狭窄的通道以及路上的所有障碍物。障碍物会旋转，你需要在有机会时通过。尽可能多地通过形状而不发生碰撞。
