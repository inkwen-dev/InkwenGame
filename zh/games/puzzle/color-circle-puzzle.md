# 颜色圆圈谜题

<a href="https://inkwengame.com/zh/games/color-circle-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-circle-puzzle/cover.jpg)

这款游戏与井字棋非常相似，但不同之处在于，您可以在一个格子中放置多个圆圈。您可以将不同大小的圆圈放入同一个格子中。目标是匹配相同颜色的圆圈。您可以在水平或垂直行中，或对角线上进行匹配。在游戏屏幕底部，您会看到下一个要放置的圆圈。因此，您可以进行组合以获得更高的分数。这是一款令人上瘾的逻辑游戏，您可以一直玩下去…

## 怎么玩

点击屏幕即可开始游戏
