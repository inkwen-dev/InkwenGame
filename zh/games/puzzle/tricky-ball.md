# 棘手的球

<a href="https://inkwengame.com/zh/games/tricky-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tricky-ball/cover.jpg)

棘手的球是一款全新的令人满足的益智游戏。将球从一个杯子移动到另一个杯子，以到达棘手的杯子。但要小心，因为在到达棘手的杯子之前如果球掉落，你就会失败。如何玩：用鼠标左右拖动，将球从一个杯子移到另一个杯子，并将球落入棘手的杯子中
