# 逃离迷宫

<a href="https://inkwengame.com/zh/games/exit-the-maze" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/exit-the-maze/cover.jpg)

屏幕上将呈现一个三维的迷宫图像。你的角色位于某个位置，同时你也会看到迷宫的出口。你需要将球移动到出口处。为此，你需要使用键盘按键来在空间中朝所需方向旋转整个迷宫。一旦球到达迷宫出口，你将获得分数，并进入游戏的下一关。

## 怎么玩

使用左、右箭头键或触摸屏幕
