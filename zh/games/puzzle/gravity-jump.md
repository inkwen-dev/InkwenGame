# 重力跳跃

<a href="https://inkwengame.com/zh/games/gravity-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gravity-jump/cover.jpg)

重力跳跃是另一款点击重力游戏。你需要点击屏幕，让球跳跃以避开障碍物和方块。方块会左右移动，还可以旋转，这会使通过更加困难。但你可以无限次尝试通过关卡。

## 怎么玩

点击屏幕开始游戏
