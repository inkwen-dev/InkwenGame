# 果冻方块

<a href="https://inkwengame.com/zh/games/jelly-cubes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jelly-cubes/cover.jpg)

在棋盘上选择并放置果冻方块组合。你可以通过点击来旋转方块组合。将三个相同颜色的果冻连在一起即可得分并消除果冻。游戏没有时间限制，仅受棋盘空位数量限制，因此请谨慎下棋。组成更大的匹配组合可获得更高分数。
