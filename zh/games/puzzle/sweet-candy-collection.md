# 甜蜜糖果收藏

<a href="https://inkwengame.com/zh/games/sweet-candy-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweet-candy-collection/cover.jpg)

在这个游戏中收集甜蜜的糖果。点击任意糖果开始。现在用鼠标或指尖在相邻的相同糖果上移动（水平、垂直或对角线方向）。至少选择3颗糖果。松开鼠标按钮以完成匹配。每第6颗糖果会带来奖励。超过7颗糖果将获得时间奖励。在规定时间内收集指定的糖果，否则游戏失败。
