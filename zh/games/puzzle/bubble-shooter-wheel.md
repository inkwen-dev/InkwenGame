# 泡泡射击轮盘

<a href="https://inkwengame.com/zh/games/bubble-shooter-wheel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-shooter-wheel/cover.jpg)

这是一款特殊的泡泡射击游戏，其中你会遇到一个旋转的泡泡轮盘。要完成游戏，你需要收集轮盘上的所有泡泡。将泡泡射向轮盘，使至少三个相同颜色的泡泡连在一起。你的分数会随着时间减少，因此越早完成游戏，就能保留越多分数。
