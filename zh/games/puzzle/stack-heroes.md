# 堆叠英雄

<a href="https://inkwengame.com/zh/games/stack-heroes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-heroes/cover.jpg)

这是一款拥有飞行英雄的游戏。将英雄堆叠成一行或三行以消灭它们。这是一款略有不同的消除3游戏。将下一个英雄放置在正确的位置，形成一排三个相同的英雄。小心不要让英雄堆到游戏顶部，否则游戏结束。点击屏幕即可将英雄放置在该位置。你能达到最高分吗？
