# CrossPath

<a href="https://inkwengame.com/zh/games/crosspath" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crosspath/cover.jpg)

CrossPath 是一款 HTML5 解谜游戏。在这款解谜游戏中，你需要拖动钻石，在拼图板的可用空间中画出一条线。每个钻石上都有一个数字，你可以从该钻石出发画出与数字相同次数的线条。有些地方有障碍物，你不能将线条拖过这些障碍物。随着关卡的推进，拼图板会变得越来越难。如果你画线的方式错误，可以撤销你的操作。

## 怎么玩

鼠标点击或轻触即可游玩。这款游戏支持移动设备，可在浏览器和手机上运行
