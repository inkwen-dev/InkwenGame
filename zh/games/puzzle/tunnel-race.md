# 隧道竞速

<a href="https://inkwengame.com/zh/games/tunnel-race" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tunnel-race/cover.jpg)

隧道竞速是一款游戏，你需要控制圆形角色通过隧道。避开道路上的光束和其他障碍物。小心谨慎，避免在道路尽头撞上。如果你碰到白色线条，游戏就会结束。所以请保持在道路上，收集球体并避开障碍物。听起来很简单，但实际上并不容易。

## 怎么玩

使用鼠标控制玩家，或在移动设备屏幕上滑动
