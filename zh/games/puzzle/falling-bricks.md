# 下落的砖块

<a href="https://inkwengame.com/zh/games/falling-bricks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/falling-bricks/cover.jpg)

在这款新奇刺激的游戏《下落的砖块》中，你可以测试自己的反应速度和敏捷性。游戏场地上会有一个黑色方块位于下方。你可以使用控制键将其向右或向左移动。从上方，不同速度的方块会落下，方块之间会有空隙供你通过。你需要让自己的方块穿过这些空隙。坚持得越久，得分就越高。
