# 形态变换跑

<a href="https://inkwengame.com/zh/games/shape-shift-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shape-shift-run/cover.jpg)

《形态变换跑》是一款有趣的在线游戏，使用手指控制图形变换形状。你手中的图形具有不同的弹性，可以通过手指点击改变成不同形状。你需要根据前方的障碍物及时调整形状，通过将图形变为匹配的形态轻松通过关卡。所有果冻形状都需要在极短时间内完成。快来挑战吧！

## 怎么玩

鼠标或轻触操作
