# 几乎无限

<a href="https://inkwengame.com/zh/games/almost-infinite" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/almost-infinite/cover.jpg)

《几乎无限》是一款轻松休闲的建造和探索游戏。游戏开始时，你将拥有四种元素（火、水、土、风），并将它们组合成新的元素。火和水可以合成蒸汽，再过几步，你就能创造出火山、巨龙、星系和微波炉。游戏中有超过 23,000 种物品等你发现。每种组合都是固定的，所以相同的组合总是会产生相同的结果，但总有新的东西等待你去发现…

## 怎么玩

将物品栏中的卡牌拖放到桌面上，然后将一张卡牌放到另一张卡牌上进行组合。如果组合成功，你将获得一张新卡牌；任何你之前未找到的卡牌都会进入你的物品栏。有些组合无法组合，所以请尝试其他组合。使用搜索功能查找卡牌，并按发现时间或深度对物品栏进行排序。“遗物”筛选器会显示你收集到的最终形态。“撤销”功能可以撤销你上一步操作，“清空桌面”功能可以整理桌面。遇到难题？点击“提示”并观看一段简短的广告，即可看到一个你尚未尝试过的组合，它可以组合出新的卡牌。操作方式：鼠标或触摸，拖放。

## 介绍

《几乎无限》是一款轻松休闲的建造和探索游戏。游戏开始时，你将拥有四种元素（火、水、土、风），并将它们组合成新的元素。火和水可以合成蒸汽，再过几步，你就能创造出火山、巨龙、星系和微波炉。游戏中有超过 23,000 种物品等你发现。每种组合都是固定的，所以相同的组合总是会产生相同的结果，但总有新的东西等待你去发现。有些发现是遗物：无法再进行任何组合的最终形态。尽可能地收集它们吧！游戏支持离线游玩，会自动保存你的游戏进度，并且可以在桌面或移动设备的任何浏览器中畅玩。
