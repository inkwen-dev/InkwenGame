# 桥上动物救援

<a href="https://inkwengame.com/zh/games/bridge-go-animal-rescue" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bridge-go-animal-rescue/cover.jpg)

桥上动物救援是一款适合儿童的趣味在线游戏，通过点击屏幕开始建造桥梁。根据游戏角色与下一步之间的距离，控制触摸屏幕的时间长短。触摸时间越长，桥梁就越长。当游戏角色安全到达下一步时即可得分。途中还需拯救小动物，让它们帮助你提升分数！
