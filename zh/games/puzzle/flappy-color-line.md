# 彩色小鸟

<a href="https://inkwengame.com/zh/games/flappy-color-line" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flappy-color-line/cover.jpg)

彩色小鸟是一款非常有趣且好玩的游戏，供你尽情体验。你的目标是让那个小彩点尽可能走得远，这意味着你需要穿过所有颜色的线条，但你只能穿过与小球颜色相同的线条。祝你好运，玩得开心！
