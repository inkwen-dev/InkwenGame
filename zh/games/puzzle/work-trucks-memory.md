# 工作卡车记忆

<a href="https://inkwengame.com/zh/games/work-trucks-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/work-trucks-memory/cover.jpg)

这是一款带有工作卡车的记忆游戏。点击卡片，它们会翻转。匹配两张相同的卡片即可消除。这款游戏有时间限制，但当你成功匹配卡片时，会获得额外时间。测试你的大脑，记住所有卡片，如果你想要赢得这个游戏。

## 怎么玩

使用鼠标玩此游戏，或点击卡片
