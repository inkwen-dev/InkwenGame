# 拼图

<a href="https://inkwengame.com/zh/games/puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/puzzles/cover.jpg)

拼图是一款专为年幼儿童设计的有趣益智游戏。游戏中，各种可爱的图案被放置在棋盘中央。包括可爱的动物、汽车、小鸟、三角形、矩形、星星等等。游戏的目标是将这些可爱的图案拖动到两侧的正确空白处。尽情享受这款可爱的拼图游戏吧。

## 怎么玩
