# 方块爆破狂热

<a href="https://inkwengame.com/zh/games/block-blast-mania" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-blast-mania/cover.jpg)

在《方块爆破狂热》中，你的任务很简单：尝试在游戏板上放置各种形状的彩色方块，使其形成完整的行。填满的行或列（没有空隙）会从棋盘上消失，为新的方块腾出空间。一次性消除的行越多，获得的分数就越高。

## 怎么玩

将方块从底部拖到网格上即可放置。方块不能旋转，但可以随意放置，顺序不限。填满列或行即可消除方块并获得分数。

## 介绍

在《方块爆破狂热》中，你的任务很简单：尝试在游戏板上放置各种形状的彩色方块，使其形成完整的行。填满的行或列（没有空隙）会从棋盘上消失，为新的方块腾出空间。一次性消除的行越多，获得的分数就越高。

游戏有两种模式。在经典模式下，游戏会一直进行，直到棋盘上没有空间放置三种形状中的任何一种为止。在关卡模式下，你需要完成诸如收集小猪之类的目标。

道具可以帮助你顺利通关。
