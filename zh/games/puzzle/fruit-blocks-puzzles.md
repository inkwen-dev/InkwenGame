# 水果方块谜题

<a href="https://inkwengame.com/zh/games/fruit-blocks-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-blocks-puzzles/cover.jpg)

水果方块谜题是一款方块消除游戏。点击两个或更多相同的水果方块以消除它们。要完成一关，您需要消除棋盘上的所有方块。消除方块时要谨慎，因为每个方块至少需要一个相同的相邻方块！

## 怎么玩

使用鼠标或触摸板来玩此游戏
