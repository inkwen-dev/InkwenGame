# 方块滑动游戏

<a href="https://inkwengame.com/zh/games/block-slider-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-slider-game/cover.jpg)

当你开始游戏并进入主界面时，在一个8X10的棋盘上，有2-3行方块会随机从底部升起。你每次只能水平移动一个方块，并且要移动的方块旁边必须有空位。

## 怎么玩

如果你不小心移动错误，可以点击返回按钮回到上一步
