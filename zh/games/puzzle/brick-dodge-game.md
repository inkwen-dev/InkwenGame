# 砖块躲避游戏

<a href="https://inkwengame.com/zh/games/brick-dodge-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/brick-dodge-game/cover.jpg)

砖块躲避不同于传统的砖块击打游戏。这是一款简单的砖块游戏，你需要在不碰到砖墙的情况下让砖块穿过砖块之间的空隙。砖块来得很快，而空隙的位置也在不断变化，因此这款游戏既充满挑战又非常有趣，是一款解谜游戏。

## 怎么玩

使用鼠标控制砖块
