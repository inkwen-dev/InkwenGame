# 小型弓箭手游戏

<a href="https://inkwengame.com/zh/games/small-archer-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/small-archer-game/cover.jpg)

小型弓箭手是一款休闲益智射击游戏。你需要点击空白区域，然后瞄准目标进行射箭，目标可能在移动，大小不同，也可能放置在不同的距离上。这便是整个游戏的难度所在。你有信心获得三星评价吗？快来试试吧！别忘了与朋友分享你的优异成绩，让他们也来挑战一下！祝你玩得愉快！

## 怎么玩

在桌面端使用鼠标，在移动设备上使用触摸操作
