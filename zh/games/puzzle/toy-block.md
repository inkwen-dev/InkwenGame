# 玩具方块

<a href="https://inkwengame.com/zh/games/toy-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/toy-block/cover.jpg)

玩具方块是一款简单而富有挑战性的方形游戏。匹配相同颜色的方块并摧毁盒子以达标。没有时间限制，你唯一受限的是移动次数。来吧，击打这些卡通方块！你所需要做的就是移除匹配的方块，让新方块从顶部掉落。匹配或更多相邻方块即可完成任务，获得高分，并达成目标。
