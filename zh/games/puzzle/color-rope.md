# 彩色绳子

<a href="https://inkwengame.com/zh/games/color-rope" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-rope/cover.jpg)

这里有一个新的彩色绳子游戏，包含色彩谜题。滚动以连接相同颜色的绳子，避开障碍物，匹配它们的绳子。

## 怎么玩

拖动彩色绳子到终点，避免与其他绳子交叉
