# 疯狂怪物方块

![cover](https://img.inkwengame.com/games/crazy-monster-blocks/cover.jpg)

欢迎来到我们最新推出的合并数字游戏《疯狂怪物方块》。你需要合并两个数字相同的方块。数字范围为1到9。当你达到数字9时，整行方块将被释放。屏幕底部会显示下一个建议的怪物方块数字。游戏可通过鼠标点击或触摸屏幕进行。尽情享受并玩得开心！！！
