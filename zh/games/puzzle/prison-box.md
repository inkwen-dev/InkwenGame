# 监狱盒子

<a href="https://inkwengame.com/zh/games/prison-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/prison-box/cover.jpg)

在监狱盒子中，你的任务是让球待在监狱里。当球到达笼子底部时，总是点击屏幕以关闭出口。尽量让球在盒子里停留更长时间，并享受乐趣
