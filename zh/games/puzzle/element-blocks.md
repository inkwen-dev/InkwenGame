# 元素方块

![cover](https://img.inkwengame.com/games/element-blocks/cover.jpg)

方块拼图，也称为1010，是一款简单的HTML5拼图游戏。将方块拖入网格棋盘，直到棋盘的垂直或水平线被完全填满，然后被填满的方块将被移除，并确保剩余方块仍有可行的移动方式。

## 怎么玩

使用鼠标或轻触屏幕
