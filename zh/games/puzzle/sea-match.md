# 海之匹配

<a href="https://inkwengame.com/zh/games/sea-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sea-match/cover.jpg)

海之匹配是一款富有挑战性的消除三消益智游戏。将三个或更多相同的鱼水平或对角线连接起来。匹配的鱼越多，得分越高！注意时间限制。如果未能在规定时间内收集足够的格子，将无法通过关卡。完成任务越快，获得的星星越多！如果你遇到困难，可以随时使用特殊道具来帮助你。

## 怎么玩

点击交换方块并连成三排
