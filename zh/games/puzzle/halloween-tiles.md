# 万圣节方块

<a href="https://inkwengame.com/zh/games/halloween-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-tiles/cover.jpg)

一款有趣的万圣节主题「坍塌/意外」类型游戏。通过点击两个或更多相邻的相同方块（上下或左右相邻）来清除棋盘上的所有方块。游戏开始时，方块堆叠深度超过一层。当某堆最下方的方块被移除后，上方的方块会下落。如果在方块下落过程中形成匹配，你将获得一个魔法南瓜。魔法南瓜可在无法形成匹配时用于消除方块。

## 怎么玩

使用鼠标或触摸操作
