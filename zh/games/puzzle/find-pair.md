# 找配对

<a href="https://inkwengame.com/zh/games/find-pair" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-pair/cover.jpg)

这个游戏的目标是找到相同的物品进行匹配。当选择两个相同的物品时，它们将从棋盘上移除。尽可能多地匹配所有物品，直到没有可配对的物品为止，同时还有时间限制，使游戏更具挑战性。

## 怎么玩
