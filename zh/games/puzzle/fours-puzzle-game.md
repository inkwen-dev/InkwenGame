# 四格拼图游戏

<a href="https://inkwengame.com/zh/games/fours-puzzle-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fours-puzzle-game/cover.jpg)

你需要将由不同颜色方块组成的随机形状放置在一个矩形区域内。每当有四个或更多相同颜色的相邻方块时，它们就会被消除，你将在灰色区域中腾出空间。此外，每消除一个方块，你都会获得相应的分数。

## 怎么玩

电脑鼠标控制 智能手机 平板触控操作
