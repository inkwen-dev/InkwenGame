# 合并泡泡数字

<a href="https://inkwengame.com/zh/games/merge-bubble-number" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-bubble-number/cover.jpg)

合并泡泡数字是一款简单又上瘾的数字合并益智游戏。你将控制一个棋盘，每个棋子上都有一个带有数字的气泡。你需要尽可能多地连接气泡，使相同数字的气泡合并在一起。游戏的目标是在无法再合成任何气泡之前，尽可能多地合并气泡，并最终获得高分。

## 怎么玩

1 使用鼠标拖动，也可以在移动设备上轻触屏幕进行操作。2 游戏需要你灵活运用数学思维和策略，合理安排每一步。3 你需要预测合并后的数字，并选择合适的方案。
