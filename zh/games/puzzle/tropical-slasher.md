# 热带切水果

<a href="https://inkwengame.com/zh/games/tropical-slasher" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tropical-slasher/cover.jpg)

在这款游戏中，你的任务是切掉所有的水果，同时不要让它们逃走。刀必须挂在旁边的树上。你要避开炸弹，因为一旦碰到炸弹，游戏就会结束。你的时间有限，尽可能多地收集分数。祝你好运。

## 怎么玩
