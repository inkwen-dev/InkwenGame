# 大理石连线

<a href="https://inkwengame.com/zh/games/marble-lines" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/marble-lines/cover.jpg)

在棋盘被填满之前，尝试消除大理石的连线！每次移动后会有3个新大理石出现，你可以将1个大理石移动到新位置。用相同颜色的5个或更多大理石连成一条线即可消除它们。连线可以是水平、垂直或对角线方向的。

## 怎么玩

左键点击大理石进行移动，再点击新位置即可。BackSpace 或 Ctrl Z 撤销上一步操作。F7 切换音效开关
