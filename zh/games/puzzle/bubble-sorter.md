# 冒泡排序器

<a href="https://inkwengame.com/zh/games/bubble-sorter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-sorter/cover.jpg)

冒泡排序是一款解谜类排序游戏。游戏的目标是按照颜色对气泡球进行排序。将气泡放入试管中，并按颜色进行分类。每个试管中只能放置相同颜色的气泡。对所有不同颜色的气泡都完成分类后即可通过关卡。在排序过程中，你还可以使用额外的试管来临时存放气泡。

## 怎么玩

点击气泡即可开始游戏
