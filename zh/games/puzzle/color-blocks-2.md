# 彩色方块 2

<a href="https://inkwengame.com/zh/games/color-blocks-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-blocks-2/cover.jpg)

彩色方块是一款有趣的益智色彩游戏。有一些已填充的方块和空方块。点击已填充的方块，它们会发射一支箭，将空方块涂色。但你需要将所有方块都涂色，并确保与图片一致。

## 怎么玩

点击触摸已填充的方块，以发射一支箭，将空方块涂色
