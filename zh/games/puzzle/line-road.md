# 线路路

<a href="https://inkwengame.com/zh/games/line-road" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/line-road/cover.jpg)

游戏的目标是让绿色球体击中同色的传送门。但首先你必须穿过白色的迷宫。球开始循环滚动，撞击篱笆后完全失去导航能力。帮助角色到达终点，你需要尝试并展现技巧。碰撞次数严格受限，如果超过限制，旅程将结束。尽情享受乐趣！
