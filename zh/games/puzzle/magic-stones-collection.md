# 魔法石收集

<a href="https://inkwengame.com/zh/games/magic-stones-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magic-stones-collection/cover.jpg)

在这个HTML5游戏中收集魔法石。点击任意一块魔法石开始游戏。现在用鼠标或指尖在相邻的相同魔法石上移动（水平、垂直或对角线方向）。至少选择3块魔法石。松开鼠标按钮以使它们匹配。每第6块石头会给予奖励。超过7块石头将获得时间奖励。在规定时间内收集目标魔法石，否则游戏失败。你能玩到的最大关卡是多少？
