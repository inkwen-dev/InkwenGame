# 加法：鸟的图像揭示

<a href="https://inkwengame.com/zh/games/addition-bird-image-uncover" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/addition-bird-image-uncover/cover.jpg)

在这个游戏中，一张鸟的图片被隐藏在加法表达式瓷砖之下。玩家必须将正确的数字气泡拖放到匹配的瓷砖上以解决表达式。每解决一个表达式，鸟的图片就会逐渐显现。目标是通过正确完成所有数学问题来完全揭示这张图片。

## 怎么玩

使用鼠标或触控板将正确的数字气泡拖放到匹配的瓷砖上以解决表达式
