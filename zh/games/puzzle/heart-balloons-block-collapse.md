# 心形气球方块坍塌

<a href="https://inkwengame.com/zh/games/heart-balloons-block-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/heart-balloons-block-collapse/cover.jpg)

通过点击水平或垂直方向上三个或更多相同颜色的方块来使它们坍塌。每次坍塌都会增加您的得分，更大的坍塌会获得更多的分数。投影框显示了此次坍塌将获得多少分。运用逻辑创造更大的组合，同时防止方块到达顶部。使用道具移除更多方块。
