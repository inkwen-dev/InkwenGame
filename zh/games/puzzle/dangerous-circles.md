# 危险的圆圈

<a href="https://inkwengame.com/zh/games/dangerous-circles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dangerous-circles/cover.jpg)

围绕圆圈旋转并躲避尖刺！这些尖刺会出现在圆圈内部或外部，你需要改变你的轨道来躲避它们。每完成一次完整的圆圈旋转就算一分。玩游戏时别忘了收集宝石，以在商店解锁新角色！
