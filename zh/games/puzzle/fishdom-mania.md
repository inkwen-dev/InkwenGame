# 鱼dom狂想

<a href="https://inkwengame.com/zh/games/fishdom-mania" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fishdom-mania/cover.jpg)

在《鱼dom狂想》中，你将进入一个充满活力的水下世界，解决各种谜题任务。加入可爱的鱼类，挑战令人兴奋的关卡。核心玩法是经典的数字谜题。选择关卡模式或自由模式，并解锁新的鱼类品种。在关卡模式中，画线来吃掉比你小的鱼。
