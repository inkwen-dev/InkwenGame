# 颜色分类

<a href="https://inkwengame.com/zh/games/color-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-sorting/cover.jpg)

颜色排序是一款完全由颜色构成的谜题——并非水排序，也无需倾倒任何东西。每个棋盘都是由连续的渐变色块切割并打乱而成。固定的方块不会移动，而角块则负责固定渐变色块，因此每个方块都有其唯一的位置——你需要阅读棋盘，而不是猜测。

## 怎么玩

桌面和移动设备：拖动一个方块到另一个方块上即可交换它们，或者点击（单击）一个方块，然后再点击第二个方块。

固定的方块不会移动——它们负责固定渐变效果。

撤销操作会撤销一次交换，重置操作会将方块重新洗牌，提示操作会执行一次最优交换，新谜题会生成一个全新的棋盘。

目标：将洗牌后的渐变效果重新排列，直到颜色均匀地分布在整个棋盘上。标准是完成此目标所需的最少交换次数，没有时间限制。

## 介绍

颜色排序是一款完全由颜色构成的谜题——并非水排序，也无需倾倒任何东西。每个棋盘都是由连续的渐变色块切割并打乱而成。固定的方块不会移动，而角块则负责固定渐变色块，因此每个方块都有其唯一的位置——你需要阅读棋盘，而不是猜测。

将一个方块拖到另一个方块上进行交换，或者点击一个方块，然后再点击第二个。标准分是完成棋盘所需的最少交换次数，它是通过计算而非估算得出的，因此它是一个你可以实际超越的目标，而不是一个分数。你可以选择简单、中等或困难模式，对应 5×4、7×5 和 9×6 的棋盘，使用始终是最优交换的提示，并记录每个难度下的个人最佳成绩和平均成绩。

颜色由 OKLab 生成，因此渐变色块中的等距步长看起来也相等。只有在移除红色和绿色后棋盘仍然清晰可读时，才会显示棋盘。设置中的色盲调色板选项可以进一步提高这一门槛。
