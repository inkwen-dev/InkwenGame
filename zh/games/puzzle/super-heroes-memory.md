# 超级英雄记忆

<a href="https://inkwengame.com/zh/games/super-heroes-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/super-heroes-memory/cover.jpg)

超级英雄记忆是一款专为儿童设计的记忆游戏，包含所有受欢迎的超级英雄。在关卡开始时，你可以看到所有印有超级英雄的卡片。之后，卡片会翻转，你需要通过记忆来猜测卡片的位置。匹配两张相同的卡片，它们就会消失。

## 怎么玩

点击屏幕即可开始游戏
