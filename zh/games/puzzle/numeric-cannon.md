# 数字大炮

<a href="https://inkwengame.com/zh/games/numeric-cannon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/numeric-cannon/cover.jpg)

数字大炮是一款有趣的遊戲，你可拖動大炮移動並射擊數字方塊。途中收集各種能力提升，例如速度、雙重射擊、更高傷害的子彈等。每破壞一個方塊，根據其數字獲得分數。看看你能走多遠！？
