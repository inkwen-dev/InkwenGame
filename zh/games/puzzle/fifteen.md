# Fifteen

<a href="https://inkwengame.com/zh/games/fifteen" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fifteen/cover.png)

潜入神秘的十五谜题世界，通过策略性地移动方块，将混乱的网格变得有序。选择不同的网格尺寸，每次都能体验独特的挑战。谨慎规划，因为每一步都可能开启新的路径，也可能导致无法解决的谜题。非常适合磨练你的解决问题的能力。
