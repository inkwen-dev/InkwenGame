# 拯救狗狗免受蜜蜂攻击

<a href="https://inkwengame.com/zh/games/save-dogs-from-bee" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-dogs-from-bee/cover.jpg)

拯救狗狗是一款休闲益智游戏。你用手指在屏幕上画线，创建墙壁来保护狗狗免受蜂巢中蜜蜂的攻击。在蜜蜂攻击期间，你需要用涂色的墙保护狗狗10秒钟，坚持住，你就能赢得游戏。动脑筋拯救狗狗吧。
