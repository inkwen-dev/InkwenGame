# 饥饿的蜗牛

<a href="https://inkwengame.com/zh/games/hungry-snail" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hungry-snail/cover.jpg)

**饥饿的蜗牛**是一款有趣的逻辑解谜游戏，你将帮助一只可爱的小蜗牛找到回家的路。移动地面砖块，创造完美的路径，避开棘手的障碍物，并尽可能多地收集星星。每一关都会引入更具挑战性的谜题，考验你的逻辑、策略和解决问题的能力。精心规划每一步，收集所有星星，安全地引导这只饥饿的蜗牛回家！
