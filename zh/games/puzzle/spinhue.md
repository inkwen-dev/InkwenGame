# SpinHue

<a href="https://inkwengame.com/zh/games/spinhue" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spinhue/cover.jpg)

SpinHue 是一款游戏，其中带有四个彩色区域的圆圈会旋转，同时有四个彩色的袋子下落，这些袋子应落在圆圈相同颜色的区域上。一旦错过，游戏结束。保持专注，尽情享受乐趣！

## 怎么玩

轻触点击以旋转圆圈
