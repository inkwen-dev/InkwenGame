# 数学儿童游戏

<a href="https://inkwengame.com/zh/games/arithmetic-kids-games" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arithmetic-kids-games/cover.jpg)

数学儿童游戏是一款可以展示你数学知识的游戏。在这个数学游戏中，你需要加、减、乘、除来得到正确结果。尽量在规定时间内以最少的错误答案取得最佳成绩。点击你认为与屏幕上显示的答案相对应的符号来玩这个游戏。

## 怎么玩

点击屏幕开始游戏
