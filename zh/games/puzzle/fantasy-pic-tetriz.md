# 幻想拼图俄罗斯方块

<a href="https://inkwengame.com/zh/games/fantasy-pic-tetriz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fantasy-pic-tetriz/cover.jpg)

这是一款简单却有趣的拼图俄罗斯方块游戏。在游戏中，你需要将图片碎片放置到正确的位置，以组成完整的图片。点击碎片，将其移动到正确位置后放下。完成8个激动人心的关卡即可赢得游戏。

## 怎么玩

使用鼠标或触摸板来玩这个游戏
