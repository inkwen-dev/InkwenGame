# 刀刃合并

<a href="https://inkwengame.com/zh/games/blade-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blade-merge/cover.jpg)

刀刃合并是一款融合了合并策略与激烈刀刃对决的刺激游戏。通过组合你的刀刃，锻造更强大的武器，在充满动作的对决中击败敌方机器人。这些旋转的锋利刀刃是你的终极工具，可以切开敌人、降低他们的生命值，并在征服关卡的过程中保护自己，展开这场史诗般的对决。

## 怎么玩
