# 画冲浪者游戏

<a href="https://inkwengame.com/zh/games/draw-surfer-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/draw-surfer-game/cover.jpg)

画冲浪者是一款专为男孩设计的免费休闲在线绘画游戏。你需要用手指完成路线绘制，让角色持续冲浪。途中会有许多障碍物，你需要具备一定的创造力和快速反应能力，才能让小人轻松避开障碍，到达目的地。小心！不要让他从你的视线中消失！

## 怎么玩

鼠标或点击操作
