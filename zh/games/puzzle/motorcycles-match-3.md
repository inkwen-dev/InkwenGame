# 摩托车消除3

<a href="https://inkwengame.com/zh/games/motorcycles-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/motorcycles-match-3/cover.jpg)

摩托车消除3是一款你需要匹配三个或更多相同摩托车的游戏。摩托车可以水平或垂直方向进行匹配。这将为你赢得分数，并为你的游戏时间增加秒数。你获得的分数越多，游戏时间就越长。所以要小心并迅速行动，尽可能长时间地玩下去。

## 怎么玩

使用鼠标拖动摩托车排成一行
