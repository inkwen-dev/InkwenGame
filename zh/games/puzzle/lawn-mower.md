# 割草机

<a href="https://inkwengame.com/zh/games/lawn-mower" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lawn-mower/cover.jpg)

借助割草机，你需要割完草坪上的所有草。草坪的每个区域只能访问一次。

## 怎么玩

点击割草机水平或垂直方向上的未占用区域以割草；若要将割草机移回，请点击已割过的区域
