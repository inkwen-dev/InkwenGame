# 怪物奔跑

<a href="https://inkwengame.com/zh/games/monsters-runs" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monsters-runs/cover.jpg)

怪物奔跑是一款游戏，你需要控制一个小怪物尽可能远地到达目的地，同时避免被摧毁。你需要避开屏幕上下方的尖刺和锯齿状障碍物。根据障碍物的位置，你需要移动怪物在轨道上上下移动。因此，请避开所有障碍物，收集星星，并努力获得最高分数。如果怪物受伤，你需要从头开始重新游戏。

## 怎么玩

点击屏幕即可开始游戏
