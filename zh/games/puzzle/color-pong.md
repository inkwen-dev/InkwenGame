# 颜色弹球

<a href="https://inkwengame.com/zh/games/color-pong" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-pong/cover.jpg)

在这个游戏中，你应该尽最大努力尽可能长时间地击打小球。但请注意，你必须用相同颜色的圆圈击打小球！小球的颜色会随机变化，你必须迅速反应并快速切换圆圈，以便用相同颜色的圆圈击中小球。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
