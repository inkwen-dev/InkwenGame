# 丰收狂想

<a href="https://inkwengame.com/zh/games/harvest-mania" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/harvest-mania/cover.jpg)

丰收狂想是一款极具上瘾性的方块消除游戏。在游戏中，你将拥有一块移除方块，可以通过点击或轻触屏幕向左或向右移动。如果移除方块位于与其相同的方块上，它将消除整行。随着方块快速向终点移动，持续消除它们。如果方块触及屏幕的左上角，游戏即告结束。

## 怎么玩

使用鼠标或触摸板来玩此游戏
