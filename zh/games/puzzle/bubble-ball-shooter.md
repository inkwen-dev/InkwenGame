# 泡泡球射击

<a href="https://inkwengame.com/zh/games/bubble-ball-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-ball-shooter/cover.jpg)

泡泡球是一款无时间限制的泡泡消除策略游戏，具有经典界面和街机特效音效。玩家使用箭头发射器来消除三个或更多相同颜色的泡泡，以获得分数和特殊礼物。玩家通过连续消除大型匹配泡泡群来获得最高分数。当玩家用一个泡泡群消除非匹配泡泡的雪崩时，可获得十倍于标准分数的奖励；当完全清空场地时，得分翻倍。
