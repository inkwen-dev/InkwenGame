# Tidydeck：整理谜题

<a href="https://inkwengame.com/zh/games/tidydeck-sort-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tidydeck-sort-puzzle/cover.jpg)

Tidydeck 是一款平静、无失败的排序谜题。将每张物品卡拖到与其类别匹配的分类牌堆上，清空整个棋盘。将棘手的卡片放在架子上；当一个牌堆填满时就会关闭。没有计时器，也不会失败——只有把所有东西归位后的宁静满足感。

## 怎么玩

从场地上拖动一张卡片到与其类别匹配的牌堆上；将暂时无法放置的卡片放在架子上；清空所有卡片即可完成当前关卡
