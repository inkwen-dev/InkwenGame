# 快乐的卡车

<a href="https://inkwengame.com/zh/games/happy-trucks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-trucks/cover.jpg)

快乐的卡车是一款填满谜题游戏。你的任务是用液体填满卡车。在全部30个关卡中完成此任务。每个关卡都有不同的卡车，因此你需要估算液体能装多少。你既不能装得太满，也不能只装一半。如果评估出错，你将重新开始该关卡。一款非常有趣的遊戲，你会乐在其中。
