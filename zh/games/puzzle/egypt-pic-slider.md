# 埃及拼图滑块

<a href="https://inkwengame.com/zh/games/egypt-pic-slider" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/egypt-pic-slider/cover.jpg)

将古埃及图片的碎片在方块间移动，将其排列成正确的顺序。触摸或点击一个方块，可将其移至相邻的空白位置。每过一秒就会扣分，因此请聪明地完成游戏以最大限度地节省分数。
