# 下落并合并方块

<a href="https://inkwengame.com/zh/games/drop-n-merge-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drop-n-merge-blocks/cover.jpg)

下落并合并数字是一款类似于2048的新类型游戏。只需下落一个方块，它就会自动与附近的相同数字合并。如果你足够出色，还能引发连锁反应。你能合并多少个方块？在失败前能获得多高的分数？
