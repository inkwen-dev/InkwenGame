# 车厢拼图

<a href="https://inkwengame.com/zh/games/wagons-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wagons-jigsaw/cover.jpg)

车厢拼图是一款包含车厢图片的游戏。你需要选择一张图片进行游戏。选择你想要玩的模式，有三种模式：简单、中等或困难。将碎片拖动到正确位置，以还原出带有车厢的图像。这款游戏没有时间限制，你可以随时开始游玩，并在空闲时间享受乐趣。

## 怎么玩

使用鼠标或手指拖动碎片
