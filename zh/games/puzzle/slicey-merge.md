# Slicey Merge

<a href="https://inkwengame.com/zh/games/slicey-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slicey-merge/cover.jpg)

Slicey Merge 是一款有趣的水果合并游戏，你只需掉落并匹配相同的水果，让它们合成为更大的水果。随着游戏进行，观察水果如何切分、合并并不断成长！努力合成最大的水果，打破你的最高得分纪录吧！

## 怎么玩

点击或轻触以掉落水果，匹配两个相同的水果即可合并成更大的一个
