# 拼图游戏

<a href="https://inkwengame.com/zh/games/tile-puzzle-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tile-puzzle-game/cover.jpg)

拼图游戏是一款引人入胜且视觉效果出色的基于方块的拼图游戏，考验您的空间推理和解决问题的能力。游戏开始时，一个编号方块的网格被打乱，并留有一个空白空间。您的目标是通过将方块滑入空白空间，重新排列方块以达到正确的数字顺序。内置计时器和步数计数器，您需要快速思考并制定策略，在时间耗尽前解决谜题。
