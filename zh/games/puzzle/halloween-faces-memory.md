# 万圣节脸庞记忆

<a href="https://inkwengame.com/zh/games/halloween-faces-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-faces-memory/cover.jpg)

展示你的视觉万圣节记忆有多好。任务是记住并成对打开相同的恐怖脸庞。在第一关，只有两对。但在第十关时，会有二十对。起初，所有图片会打开几秒钟，以便你记住它们的位置。然后它们会翻转到背面，你需要重新打开它们，删除万圣节脸庞记忆中的配对。
