# 水果系统

<a href="https://inkwengame.com/zh/games/fruits-system" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-system/cover.jpg)

水果系统是一款游戏，您首先需要绘制一条通往榨汁机的路径，以获取需要倒入彩色玻璃杯中的果汁。在途中，您还会遇到会冻结的平台以及会偷走果汁的洞穴。

## 怎么玩
