# 拼图冲刺

<a href="https://inkwengame.com/zh/games/puzzle-dash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/puzzle-dash/cover.jpg)

拼图冲刺是一款拼图泡泡射击游戏，但在这个游戏中，巫师发射的不是泡泡，而是糖果。左右移动巫师，将饼干射向你想要的位置。击中两个或更多相同的饼干即可将其摧毁。在糖果到达终点前摧毁所有糖果。

## 怎么玩

使用鼠标操作此游戏，或点击屏幕
