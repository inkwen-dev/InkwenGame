# 机器人废料场竞技场

<a href="https://inkwengame.com/zh/games/robot-scrapyard-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/robot-scrapyard-arena/cover.jpg)

《机器人废料场竞技场》是一款3D俯视角机器人射击游戏。玩家需要从废料场中回收零件，将它们合并成更强大的部件，然后组装到自己的机器人上，并努力在10波敌人和两个巨型Boss的围攻下生存下来。每一波敌人都会掉落零件。两个相同的零件可以合并成一个更高阶的零件，从Mk I到传奇的Mk V及更高阶…

## 怎么玩

挺过每一波敌人，击败两位首领。收集敌人和箱子掉落的部件，然后打开工坊，将一个部件拖到另一个相同的部件上，即可将它们合并成更高阶的部件。装备你最强的部件，继续战斗！

桌面：

WASD 或方向键：移动

鼠标：瞄准

鼠标左键/右键：左臂/右臂射击

空格键或 Shift 键：冲刺

Q 键：超速模式

Tab 键：工坊

回车键：提前开始下一波敌人

Esc 键：暂停

移动：

左手拇指：移动（拖动到屏幕左侧任意位置）

手臂自动瞄准和射击

冲刺和超速模式按钮位于屏幕右侧

## 介绍

《机器人废料场竞技场》是一款3D俯视角机器人射击游戏。玩家需要从废料场中回收零件，将它们合并成更强大的部件，然后组装到自己的机器人上，并努力在10波敌人和两个巨型Boss的围攻下生存下来。每一波敌人都会掉落零件。两个相同的零件可以合并成一个更高阶的零件，从Mk I到传奇的Mk V及更高阶。玩家可以在五个零件槽位（两条手臂、核心、头部和腿部）中组合15种不同类型的零件，打造自己的专属机器人。
