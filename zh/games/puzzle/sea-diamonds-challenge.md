# 海洋钻石挑战

<a href="https://inkwengame.com/zh/games/sea-diamonds-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sea-diamonds-challenge/cover.jpg)

对于喜爱宝石或钻石类游戏的玩家，这款游戏提供了有趣的娱乐体验。观察屏幕上的钻石，尝试找出最大颜色相同的组合。点击三个或更多相同颜色的钻石组合。越来越多的钻石将被显示出来。在时间结束前获得最高分。

## 怎么玩

尝试匹配相同颜色的钻石以获得高分 尽量清除所有方块以获得更多奖励 炸毁钻石组合以提升法力 你可以使用这些法力来激活特殊能力，帮助你清除屏幕上的钻石
