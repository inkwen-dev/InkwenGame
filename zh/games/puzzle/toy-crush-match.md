# 玩具粉碎匹配

<a href="https://inkwengame.com/zh/games/toy-crush-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/toy-crush-match/cover.jpg)

将两个或更多相邻的方块组合成相同颜色，使它们消失。一次消除的方块组合越多，得分越高。在这个挑战模式中，消除每种颜色的一定数量方块即可完成关卡。
