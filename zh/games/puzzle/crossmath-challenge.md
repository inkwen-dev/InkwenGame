# Crossmath 挑战

<a href="https://inkwengame.com/zh/games/crossmath-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crossmath-challenge/cover.jpg)

CrossMath 是一款快速的数字谜题游戏，你需将方块拖入类似填字游戏的网格中，完成横向和纵向的数学等式。上手简单，但精通却颇具挑战。

## 怎么玩

点击或轻触底部托盘中的方块，然后点击网格中的空格以放置它。你也可以直接将方块拖到格子中。点击撤销可移除上一次的放置，点击洗牌可重新排列你的托盘，点击提示可自动填充一个格子（使用次数有限）
