# 圣诞梦

<a href="https://inkwengame.com/zh/games/santa-dream" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/santa-dream/cover.jpg)

圣诞梦是一款欢乐的小圣诞老人游戏，他需要你的帮助。你需要引导圣诞老人完成旅程，为所有孩子收集礼物。避开圣诞老人路上的所有障碍物，并尽可能多地收集礼物。特别注意那些可怕的巨眼，一旦碰到游戏就会结束。一切就靠你了。节日的幸福将取决于你和你的圣诞老人。

## 怎么玩

滑动屏幕来玩游戏
