# 砖块挑战

<a href="https://inkwengame.com/zh/games/brick-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/brick-challenge/cover.jpg)

砖块挑战是一款有趣的益智游戏，你需要将相同颜色的砖块相邻排列以获得分数。快速观察，明智选择你的行动，并创造出大型组合以获得最高分。每一关都带来新的挑战，有助于训练你的思维能力，并提供引人入胜的娱乐体验。
