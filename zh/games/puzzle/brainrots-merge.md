# 脑腐合并

<a href="https://inkwengame.com/zh/games/brainrots-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/brainrots-merge/cover.jpg)

一款引人入胜的合并点击式自动战斗游戏。

## 怎么玩

- 点击角色即可获得货币

- 将相同的角色拖放到一起即可解锁新角色

- 受到攻击时，选择要派出的角色参战

## 介绍

一款引人入胜的合并点击式自动战斗游戏。

合并角色即可获得新角色，定期与其他玩家对战，并解锁所有脑洞大开的关卡！
