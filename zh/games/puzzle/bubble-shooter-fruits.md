# 泡泡射击水果

<a href="https://inkwengame.com/zh/games/bubble-shooter-fruits" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-shooter-fruits/cover.jpg)

这是一款经典的泡泡射击游戏，包含36个具有挑战性的关卡。在每个关卡中，你将面临不同的挑战。要完成一个关卡，必须消除屏幕上的所有水果。当你射出的水果与三个或更多同类型的水果组合在一起时，这些水果就会被消除。你必须在规定时间内完成关卡。越早完成关卡，得分越高。
