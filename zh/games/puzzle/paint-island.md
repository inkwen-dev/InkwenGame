# 绘画岛

<a href="https://inkwengame.com/zh/games/paint-island" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/paint-island/cover.jpg)

《绘画岛》是一款注重用画笔经过胶囊来涂色的超休闲游戏。在游戏中，玩家需要将所有胶囊涂色。游戏的目标是涂完所有的胶囊。这款游戏适合所有年龄段的玩家，并可在网页平台上进行游玩。游戏通过吸引人的图形和有趣的机制，旨在给玩家留下持久的印象。

## 怎么玩

--------- 左键点击 ------- 每次按下鼠标左键，角色的一只手臂会固定，另一只手臂则开始为周围的胶囊涂色
