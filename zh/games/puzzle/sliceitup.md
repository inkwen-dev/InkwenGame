# SliceItUp

<a href="https://inkwengame.com/zh/games/sliceitup" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sliceitup/cover.jpg)

玩家将面对一组由不同精灵表示的切片。通过旋转和放置这些切片到指定的槽位中，玩家可以收集并匹配它们。每个槽位可以容纳不同形状和大小的切片。玩家通过战略性地用匹配的切片填满槽位来获得分数。随着游戏进程推进，难度逐渐增加，新的回合会带来不同类型的切片和角度，需要放入槽位中。

## 怎么玩

点击收藏中的项目可让玩家查看并可能解锁新的切片
