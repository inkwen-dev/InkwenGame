# Pin Circle

<a href="https://inkwengame.com/zh/games/pin-circle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pin-circle/cover.jpg)

这个游戏界面很简单，中间有一个旋转的轮盘，底部有一堆球（箭头），玩家需要一个接一个地将球发射到旋转轮盘上，但必须避免碰到其他球。随着游戏进行，球的数量会越来越多，最多达到100个球，轮盘可能旋转得越来越快或越来越慢，游戏难度也随之增加。如果你成功发射完所有球，你将获胜，屏幕颜色变为绿色；否则屏幕颜色变为红色。

## 怎么玩

非常简单，只需使用空格键
