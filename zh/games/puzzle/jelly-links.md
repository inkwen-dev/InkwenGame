# 果冻链接

<a href="https://inkwengame.com/zh/games/jelly-links" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jelly-links/cover.jpg)

一款色彩鲜艳的数独游戏。每一行、每一列、每一条连接线都必须恰好包含每个数字一次。游戏包含 1000 个谜题，从轻松的 4x4 热身题到真正考验脑力的 12x12 谜题，外加一个 500 关的沙盒模式。没有时间限制，没有生命值——只有你和你的逻辑思维。

## 怎么玩

用数字 1 到 N 填满每一行、每一列以及每一条连接的线，每个数字只能使用一次。

- 点击珠子即可更改其数字。再次点击即可循环。

- 带有金色圆环的珠子可以更改。其余珠子是固定的线索。

- 线条是游戏的亮点——由线条连接的珠子会形成一个独立的组，就像行或列一样。

- 双指捏合即可放大较大的棋盘。（在电脑上：将鼠标滚轮悬停在空白区域。）

- 卡住了？提示 (HINT) 会帮你填入一颗珠子。重置 (RESET) 会清除你输入的所有内容，并保留线索。

三种游戏模式

- 教程 — 3 个短棋盘，教你线条规则。

- 普通模式 — 1000 个关卡。棋盘从 4x4 逐渐增大到 12x12，线索也会随着关卡的推进而减少。

- 沙盒模式 — 500 个开放棋盘，每个棋盘只有一个线索。没有提示，只有线条结构。
