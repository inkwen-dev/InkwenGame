# 滑动

<a href="https://inkwengame.com/zh/games/slip" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slip/cover.jpg)

滑动是一款解谜游戏，你需要控制在轨道上左右移动的球。蓝色和橙色方块会向蓝球靠近。你应该避开橙色方块，但要收集蓝色方块。取得最佳成绩，尽可能多地收集方块。如果你碰到橙色方块，游戏就结束了。你的方块是蓝色的，所以请收集它们。

## 怎么玩

点击屏幕即可开始游戏
