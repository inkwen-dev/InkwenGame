# 圣诞记忆配对

<a href="https://inkwengame.com/zh/games/christmas-memory-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-memory-match/cover.jpg)

圣诞记忆配对是一款简单的经典棋盘游戏，具有圣诞节主题，可以帮助并挑战你的记忆力。在计时器每秒减少的情况下，尽可能获得最高分数。

## 怎么玩

点击或触摸方块以翻转打开，然后打开另一个关闭的方块。如果两个翻开的方块匹配，它们将从屏幕上移除，得分将增加
