# 心形爆破

<a href="https://inkwengame.com/zh/games/hearts-popping" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hearts-popping/cover.jpg)

点击所有在指尖弹珠器上的气泡以完成关卡。只有当心形闪烁时才能点击对应的气泡，越早点击目标气泡，得分越高。如果心形闪烁时未能点击该气泡，你的分数将减少50分。错误地点击气泡将导致分数减少100分。
