# 蛇之乱斗：融合竞技场

<a href="https://inkwengame.com/zh/games/snake-brawl-merge-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-brawl-merge-arena/cover.jpg)

滑入竞技场，打造最强大的融合蛇！每个蛇节都有一个数字——吞噬相同数字的能量球，像玩2048游戏一样将它们融合，提升能量。咬断小蛇，夺取它们的蛇节；躲避大蛇；在时间耗尽前击败加冕的Boss。然后在“强力粉碎”奖励关卡中疯狂点击，打破倍增墙，赢取金币。升级力量、速度和磁力，解锁8款蛇皮！

## 怎么玩

在屏幕上任意位置拖动即可控制蛇的移动。吞食与蛇身节数相同的能量球，即可合并节数并变得更强。攻击节数小于蛇头的蛇，避开节数更大的蛇（绿色圆环表示安全，红色圆环表示危险）。在倒计时结束前击败目标数量的蛇或首领，然后在“强力粉碎”模式下快速点击即可获得额外金币。
