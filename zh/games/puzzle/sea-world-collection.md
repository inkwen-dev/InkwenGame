# 海洋世界收藏

<a href="https://inkwengame.com/zh/games/sea-world-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sea-world-collection/cover.jpg)

在这个HTML5游戏中收集海洋世界物品。点击任意海洋物品开始游戏。现在用鼠标或指尖在相同且相邻的物品上移动（水平、垂直或对角线方向）。至少选择3个物品。松开鼠标按钮以完成匹配。每第6个物品将获得奖励。超过7个物品将获得时间奖励。在规定时间内收集目标海洋物品，否则游戏失败。你能玩到的最大关卡是多少？
