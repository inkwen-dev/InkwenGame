# 合并野兽

<a href="https://inkwengame.com/zh/games/merge-beasts" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-beasts/cover.jpg)

《合并怪兽》是一款色彩缤纷的合并益智游戏，玩家需要合并相同的生物，发现更强大的怪兽。规划你的每一步，管理棋盘上的空间，努力达成每个关卡的目标。简单的拖放操作让你在电脑或移动设备上都能轻松上手，每一次合并都会让你离下一个发现更近一步。

## 怎么玩

将一只野兽拖到另一只同类型的野兽身上，即可将它们合并成更强大的生物。不断合并相同的野兽以达到关卡目标，并在棋盘上留出空间进行下一步操作。在电脑上，按住鼠标左键并拖动，然后松开。在移动设备上，用一根手指触摸并拖动。使用屏幕上的按钮可以暂停游戏、切换音效以及访问可用奖励。
