# 醉鹤

<a href="https://inkwengame.com/zh/games/drunken-crane" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drunken-crane/cover.jpg)

这是一款动作解谜游戏，你需要用起重机把一个喝醉的叔叔运送到长椅上。通过屏幕右侧的按钮来操作起重机左右移动、向下移动以及释放。你可以像玩抓娃娃机一样享受其中的乐趣。游戏共有38个关卡，让你玩得不厌其烦。除了长椅之外，还有让叔叔骑在大象上的关卡。也会出现利用弹簧床反作用力的关卡。如果你以三颗星的成绩通关全部38个关卡…

## 怎么玩

侧边按钮使起重机横向移动，下方按钮使其向下移动，停止按钮则停止运行并打开机械臂，松开叔叔，将其放置在长椅或垫子上。如果释放叔叔时高度过高，他将会滚落，

## 介绍

这是一款动作解谜游戏，你需要用起重机把一个喝醉的叔叔运送到长椅上。通过屏幕右侧的按钮来操作起重机左右移动、向下移动以及释放。你可以像玩抓娃娃机一样享受其中的乐趣。游戏共有38个关卡，让你玩得不厌其烦。除了长椅之外，还有让叔叔骑在大象上的关卡。也会出现利用弹簧床反作用力的关卡。如果你以三颗星的成绩通关全部38个关卡，隐藏关卡将会出现，请务必挑战一下。
