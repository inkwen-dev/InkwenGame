# 消灭病毒

<a href="https://inkwengame.com/zh/games/kill-virus" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kill-virus/cover.jpg)

在这个HTML5游戏中，连接病毒以消灭它们。点击任意一个病毒开始游戏。现在用鼠标或指尖在相邻的相同病毒上移动（水平、垂直或对角线方向）。至少选择3个病毒。松开鼠标按钮以使它们匹配。每第6个病毒会带来奖励。超过7个病毒将给予你时间奖励。在规定时间内消灭指定病毒，否则游戏失败。你能玩到的最大关卡是多少？
