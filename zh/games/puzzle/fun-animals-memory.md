# 趣味动物记忆

<a href="https://inkwengame.com/zh/games/fun-animals-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fun-animals-memory/cover.jpg)

展示你视觉记忆能力的强弱。任务是记住并随后成对打开相同的动物。在第一关，只有两对。但在第十关时，会有二十对。中间会逐渐增加卡片数量，以避免给你造成压力。起初，所有图片会打开几秒钟，以便你记住它们的位置。然后它们会翻到背面，你需要重新打开它们，在《趣味动物记忆》中消除配对。

## 怎么玩

使用鼠标或触摸屏幕
