# 图块排序：颜色列

<a href="https://inkwengame.com/zh/games/tile-sort-color-columns" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tile-sort-color-columns/cover.jpg)

这是一款引人入胜的逻辑游戏，色彩缤纷的方块组成了你的挑战。你的目标是将方块排列成一列，使每一列都包含同一种颜色的方块。选择一列，在顶部添加一个方块，然后取走底部的方块作为下一步操作。要解开每个谜题，你需要仔细思考每个方块的放置位置。

## 怎么玩

屏幕底部的方块就是你需要放置的方块。选择一列：方块会添加到该列的顶部，而该列底部的方块将成为你下一步移动的方块。

在列之间移动方块，直到每列都只有一种颜色的方块。提前计划：你从底部拿走的方块决定了你的下一步移动。

有些关卡会引入隐藏方块和其他机制。如果你一时找不到解决方案，可以尝试不同的移动顺序。游戏没有时间限制，你也不会失败。

按照自己的节奏游戏，寻找巧妙的解决方案，将每种颜色的方块排列成一列！
