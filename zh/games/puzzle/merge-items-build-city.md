# 合并物品建造城市

<a href="https://inkwengame.com/zh/games/merge-items-build-city" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-items-build-city/cover.jpg)

一款关于建造城市的游戏。为城市居民建造简朴的房屋和街道，让市民生活幸福美满。

## 怎么玩

- 使用鼠标在电脑屏幕上操作，或在智能手机屏幕上用手指点击；

- 点击建筑物即可开始建造；

- 选择任务 - 使用鼠标或手指点击屏幕；

- 连接物体时，需要拖动并连接相同的物体。

- 连接石头即可获得砖块；

- 连接树木即可获得木板；

- 这是一款建造城市的游戏，连接物体即可建造；

- 建造医院和幼儿园；

- 开设商店和银行；

- 每栋建筑都能产生收入。增加利润，变得富有；

- 完成任务和挑战即可增加收入；

- 要建造一座建筑物，需要完成所有任务；

- 建造楼梯、窗户和墙壁。
