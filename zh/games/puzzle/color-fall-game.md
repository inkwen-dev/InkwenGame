# 色彩坠落游戏

<a href="https://inkwengame.com/zh/games/color-fall-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-fall-game/cover.jpg)

通过移动可以上下左右滑动的挡板，将正确的颜色填入卡车中。移动颜色并仔细规划它们通往卡车的路径。注意黑色，它会摧毁接触到的任何东西，你将不得不重新开始该关卡！
