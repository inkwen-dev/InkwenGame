# 拯救矿工

我们的矿工神秘地喜欢往上走，甚至连他自己都不知道原因！不幸的是，他在攀爬时经常遇到危险情况，你必须帮助他安全地到达地面。因此，你必须帮助游戏中的矿工角色通过拾取他脚下的箱子来抵达地面。
