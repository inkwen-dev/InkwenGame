# 圆环旋转

<a href="https://inkwengame.com/zh/games/circle-rotate" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/circle-rotate/cover.jpg)

圆环旋转是一款益智游戏，你需要旋转一个带有小开口的圆环。白色小球必须通过这个开口到达圆环中心。开口很窄，你需要精确调整位置，让白球顺利通过。你可以犯几次错误，但要小心，尽量让更多的小球通过开口。使用左、右箭头键或点击屏幕来旋转圆环。

## 怎么玩

点击屏幕开始游戏
