# 恐怖面孔拼图

<a href="https://inkwengame.com/zh/games/scary-faces-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scary-faces-jigsaw/cover.jpg)

这里有很多恐怖的面孔。在这个游戏中，你共有12个拼图。你需要从第一个开始，解锁下一个图像。每张图片有三种模式：简单模式（25块）、中等模式（49块）和困难模式（100块）。尽情享受吧！
