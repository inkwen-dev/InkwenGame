# 形状链匹配

<a href="https://inkwengame.com/zh/games/shapes-chain-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shapes-chain-match/cover.jpg)

使用触摸屏或鼠标连接相似的形状。将三个或更多水平、垂直或对角相邻的星星组成一组，使其方块颜色变为蓝色。使所有方块都变为蓝色即可完成关卡。完成全部24个关卡即可赢得游戏。

## 怎么玩
