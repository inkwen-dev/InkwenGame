# 色彩方块填充

<a href="https://inkwengame.com/zh/games/colour-box-fill" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colour-box-fill/cover.jpg)

在屏幕上滑动，方块会随着你的手指移动，并用它的颜色填满所在位置，你需要避开障碍物，填满所有空白区域以获胜。必须避免方块触碰到自己的轨迹。障碍物和墙壁的位置是随机生成的。
