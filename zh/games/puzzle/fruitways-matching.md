# 水果连线

<a href="https://inkwengame.com/zh/games/fruitways-matching" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruitways-matching/cover.jpg)

将水果移动到空白格子中，以形成水平或垂直的三个相同水果的行。使用尽可能少的步数以获得更高分数。要移动水果，请先点击水果，然后点击任意空白格子。如果水果与其目的地之间有通路，它就会移动到新位置。在分数降至0之前完成关卡。您可以使用特殊能力，如炸弹和额外分数，以更快地匹配水果。

## 怎么玩

使用鼠标或触摸板来玩此游戏
