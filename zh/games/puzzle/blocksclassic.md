# BlocksClassic

<a href="https://inkwengame.com/zh/games/blocksclassic" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocksclassic/cover.jpg)

Blocks Classic 是一款消除两个相同方块的益智游戏，你需要清除棋盘上的所有方块。游戏包含三种模式：经典模式、强力模式（上方会掉落更多方块）以及禅意模式（无尽方块消除）。

## 怎么玩

点击两个或更多相同颜色的方块
