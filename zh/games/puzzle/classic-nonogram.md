# 经典数图

<a href="https://inkwengame.com/zh/games/classic-nonogram" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/classic-nonogram/cover.jpg)

如果你喜欢玩数独，那么你一定会爱上这款数图谜题游戏！你的目标是确定哪些方格需要涂色，哪些方格应保持空白。行和列中的数字会给你提示，但要小心：你只有三条生命！

## 怎么玩

最上方的行和最左边的列决定了某列或某行中填充方块的数量。点击或轻触一个方格以进行填充
