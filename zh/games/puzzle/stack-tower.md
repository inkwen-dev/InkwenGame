# 堆叠塔

<a href="https://inkwengame.com/zh/games/stack-tower" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-tower/cover.jpg)

堆叠塔是一款适合全家人的趣味游戏。在不破坏塔楼的情况下，完美地建造高耸的塔楼。通过将不同大小的形状层层叠加，最终建成一座完美的建筑以完成每一关卡。

## 怎么玩

鼠标瞄准，点击以放下方块 触摸并拖动以瞄准，松开以放下方块
