# 合并到 AGI

<a href="https://inkwengame.com/zh/games/merge-to-agi" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-to-agi/cover.jpg)

一款轻松的合并益智游戏，讲述的是一家车库人工智能创业公司的故事。你需要整合硬件、代码、数据和咖啡，打造更强大的设备，满足一群滑稽顾客的订单，并将你的实验室发展成为横跨十个区域的通用人工智能帝国，同时还要与八个竞争对手在排行榜上一较高下。

## 怎么玩

点击生成器即可制作物品。将两个相同的物品拖到一起，即可合并成更高阶的物品。将顾客需要的物品交给他们，即可获得金币和经验值，然后在帝国中使用金币建造项目并解锁新的区域。支持鼠标和触摸操作。
