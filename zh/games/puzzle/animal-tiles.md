# 动物方块

<a href="https://inkwengame.com/zh/games/animal-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-tiles/cover.jpg)

动物方块游戏要求您匹配三个相同元素的方块，当所有方块都被匹配时即可通过关卡。这与麻将或其他方块益智游戏不同。Tile Master Match 包含大量关卡，难度逐渐增加。
