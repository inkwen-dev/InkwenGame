# 揭示动物

<a href="https://inkwengame.com/zh/games/reveal-the-animal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/reveal-the-animal/cover.jpg)

揭示动物是一款有趣且富有教育意义的数学游戏，玩家需要选择相加等于1的分数。当玩家正确解答分数方程时，会逐渐揭开隐藏的动物。游戏包含多种动物和难度级别，适合所有年龄段的玩家。
