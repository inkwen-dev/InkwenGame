# 点点

<a href="https://inkwengame.com/zh/games/dot-dot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dot-dot/cover.jpg)

这是一款带有反射机制的点点益智游戏。游戏中有两种点：红色和黄色。相同颜色的点需要配对。如果将不同颜色的点配对，游戏就会结束。点会从游戏上方出现。如有必要，点击屏幕来分散红色的点。尽可能多地得分。这款游戏的操作非常简单，只需点击屏幕即可。

## 怎么玩

点击屏幕开始游戏
