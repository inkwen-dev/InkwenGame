# 泡泡宠物射击

<a href="https://inkwengame.com/zh/games/bubble-pets-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bubble-pets-shooter/cover.jpg)

泡泡宠物射击是一款街机游戏，你可以在其中引爆色彩缤纷的泡泡。通过投掷相同颜色的泡泡，使三个或更多相同颜色的泡泡连在一起即可消除。一次射击消灭的泡泡越多，获得的分数就越高。如果你未能组成组合，游戏场地将向下移动一行。游戏的主要目标是尽可能多地得分并清除关卡！

## 怎么玩

拖动或使用鼠标左键来瞄准并发射泡泡
