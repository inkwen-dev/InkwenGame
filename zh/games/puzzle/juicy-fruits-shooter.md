# 多汁水果射击

<a href="https://inkwengame.com/zh/games/juicy-fruits-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/juicy-fruits-shooter/cover.jpg)

多汁水果射击是一款令人愉悦的泡泡射击游戏，为经典类型带来了果味新意。玩家手持色彩缤纷的水果大炮，展开一场多汁冒险，射击并匹配水果泡泡。目标是通过战略性地瞄准和发射水果，形成三个或更多相同水果的组合，从而清除屏幕。不要让水果触碰到底线，争取高分！尽情享受吧！
