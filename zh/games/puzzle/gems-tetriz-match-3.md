# 宝石方块消消乐

<a href="https://inkwengame.com/zh/games/gems-tetriz-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gems-tetriz-match-3/cover.jpg)

使用左、右和下键移动宝石。使用上键打乱宝石。也可以点击或触摸按钮来执行相同操作。目标是将方块组合成一条直线的宝石图案（水平、垂直或对角线）。达到目标分数即可完成关卡。

## 怎么玩

左、右、下键或按钮移动宝石组；上键或旋转按钮打乱方块
