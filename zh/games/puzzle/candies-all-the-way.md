# 糖果一路

<a href="https://inkwengame.com/zh/games/candies-all-the-way" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/candies-all-the-way/cover.jpg)

水平或垂直滑动一排糖果，以形成三个或更多相同的糖果的水平或垂直行。使用鼠标或指尖滑动行。尝试一下，看看在这个限时游戏中你能完成多少关卡。
