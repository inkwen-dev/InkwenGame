# 合并美人鱼

<a href="https://inkwengame.com/zh/games/merge-mermaids" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-mermaids/cover.jpg)

在尝试匹配三个或更多相同鱼类以合并它们时，将鱼放置到棋盘上。在这个独特的2048风格游戏中，尽可能长时间地持续合并鱼类。提前思考，然后放置你的鱼，尽量保持棋盘有更多空位。一旦你无法再移动，游戏结束，你的分数将被添加到Lagged排行榜中。如何玩：点击或轻触鱼来将它们放到棋盘上。
