# 颜色圆圈

<a href="https://inkwengame.com/zh/games/color-circle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-circle/cover.jpg)

颜色圆圈是一款有趣的技巧类游戏，考验你的反应力和专注力。在游戏中，你控制一个多彩的旋转圆圈，同时观察时钟指针持续旋转。当指针指向与你所控制圆圈颜色相匹配的位置时，你需要在正确的时间点击。只要稍有延迟或点击了错误的颜色，你就必须重新开始。随着速度加快和颜色不断变化，颜色圆圈带来了一种简单却极具上瘾性的体验！

## 怎么玩

使用鼠标进行游戏
