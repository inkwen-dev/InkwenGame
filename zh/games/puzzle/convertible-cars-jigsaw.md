# 敞篷车拼图

<a href="https://inkwengame.com/zh/games/convertible-cars-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/convertible-cars-jigsaw/cover.jpg)

敞篷车拼图是一款游戏，你需要将碎片放置在正确的位置，以还原出敞篷车的图像。这是一款包含十二张图片的拼图游戏，你需要完成所有图片才能通关。选择你想玩的模式。你可以选择简单、中等或困难模式。如果你想玩更多碎片，请选择困难模式，你将面对100块碎片。通过拖动碎片到正确位置来玩游戏。

## 怎么玩

使用鼠标拖放，或用手指来玩这个游戏
