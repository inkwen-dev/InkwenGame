# 俄罗斯方块3D

<a href="https://inkwengame.com/zh/games/tetris-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tetris-3d/cover.jpg)

你从屏幕顶部落下方块。你可以左右移动方块，还可以旋转和镜像它们。你需要将方块组合成完整的行以消除该行。如果你确定位置，可以让方块下落得更快。并收集分数。
