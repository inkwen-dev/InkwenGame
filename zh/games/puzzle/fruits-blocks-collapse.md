# 水果方块消消

<a href="https://inkwengame.com/zh/games/fruits-blocks-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-blocks-collapse/cover.jpg)

通过点击或触摸来收集所有的水果切片。如果你收集到两个或更多切片，你将获得分数。如果在一次操作中收集超过7个切片，你将获得一个道具（炸弹、箭头或魔法切片）。如果你点击单个切片，你的分数将被扣除200分。请参考投影框中的信息，了解每次收集的得分价值。达到或超过每关的目标分数，并清除棋盘上的所有切片，即可进入下一关。
