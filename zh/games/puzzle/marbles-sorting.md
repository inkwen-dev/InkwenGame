# 弹珠排序

<a href="https://inkwengame.com/zh/games/marbles-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/marbles-sorting/cover.jpg)

弹珠排序是一款出色的脑力益智游戏，有助于锻炼你的思维。尝试将不同颜色的弹珠放入试管中，直到相同颜色的弹珠都集中在同一个试管里。这款游戏有助于缓解压力，让你的大脑焕然一新。

## 怎么玩

使用鼠标或触控板将一个弹珠从一个试管移动到另一个试管。尽可能快地完成所有弹珠的排序
