# 圣诞方块消消

<a href="https://inkwengame.com/zh/games/christmas-blocks-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-blocks-collapse/cover.jpg)

通过连接两个或更多相同的方块来消除圣诞方块。一次消除六个或更多的方块可获得炸弹。连接的方块越多，得分越高。
