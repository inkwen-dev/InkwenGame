# 蔬菜收集

<a href="https://inkwengame.com/zh/games/vegetables-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/vegetables-collection/cover.jpg)

在这个HTML5游戏中收集蔬菜。点击任意一个蔬菜开始游戏。现在用鼠标或指尖在相同且相邻的物品上移动（水平、垂直或对角线方向）。至少选择3个物品。松开鼠标按钮以使它们匹配。每第6个物品会给予奖励。超过7个物品会获得时间奖励。在规定时间内收集目标蔬菜，否则游戏失败。你能玩到的最大关卡是多少？
