# 躲避球

<a href="https://inkwengame.com/zh/games/dodging-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dodging-ball/cover.jpg)

躲避球是一款复杂的球类游戏。你需要在横梁上保持球的平衡，同时避开飞来的箱子。这款游戏并不容易玩。你需要集中注意力于球，但与此同时也要留意飞来的箱子。尽量长时间地玩下去，不要让球从横梁上掉落，也不要与任何箱子相撞。

## 怎么玩

点击屏幕以保持平衡，或使用左右箭头键
