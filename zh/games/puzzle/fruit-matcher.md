# 水果匹配

<a href="https://inkwengame.com/zh/games/fruit-matcher" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-matcher/cover.jpg)

交换水果，使三个或更多相同的水果在水平或垂直方向上相邻。持续匹配，直到解锁并清除所有方块。使用道具来加快进程。

## 怎么玩

使用鼠标或触控板来玩这款游戏
