# 踢彩色球

<a href="https://inkwengame.com/zh/games/kick-colored-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kick-colored-balls/cover.jpg)

这款游戏的目标是踢彩色球。游戏区域的两侧将会有球。左侧是黄色球，右侧是蓝色球。点击左侧或右侧，球就会击打。屏幕中间会移动一条由黄色和蓝色球组成的线。你需要用侧边的球来摧毁迎面而来的球。但黄色球只能摧毁黄色球，蓝色球只能摧毁蓝色球。如果击打错误，你将会失败。

## 怎么玩

点击屏幕开始游戏
