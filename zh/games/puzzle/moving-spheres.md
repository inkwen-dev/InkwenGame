# 移动球体

<a href="https://inkwengame.com/zh/games/moving-spheres" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/moving-spheres/cover.jpg)

移动球体是一款带有球体的益智游戏。游戏的目标是用球体抓住环。环不能与游戏边界碰撞，也不能掉落到地面。因此，你必须用球体或大圆圈来控制它。移动球体以缓冲撞击。努力取得好成绩。你可以掉落环三次，之后游戏结束。

## 怎么玩

触摸并点击屏幕以移动球体
