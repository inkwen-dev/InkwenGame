# 合并枪械

<a href="https://inkwengame.com/zh/games/merge-guns" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/merge-guns/cover.jpg)

《Merge Guns》是一款基于单一网格的塔防合并游戏。玩家可以用金币购买武器，将相同等级的武器拖拽合并成更强大的武器，并抵御从右侧涌来的外星入侵者。游戏包含八个武器等级、持续升级系统、首领关卡、成就系统、英语和俄语本地化，以及不断更新的关卡进度，让每一次防御都成为全新的布局挑战。

## 怎么玩

点击或轻触“购买枪械”即可添加武器。选择或拖动枪械即可移动、交换、回收或将其与同等级的枪械合并。按下“开始战斗”按钮即可开始；枪械会自动开火。阻止敌人越过警戒线，使用空袭对抗大量敌人，并在战斗间隙使用获得的核心和回收物进行永久升级。
