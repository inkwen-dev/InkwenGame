# 数学游戏3D

<a href="https://inkwengame.com/zh/games/math-game-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-game-3d/cover.jpg)

数学游戏3D 是一款有趣且富有教育意义的 HTML5 解谜游戏，挑战你的数学技能。将数字方块拖动到正确的数学表达式上以解决每个方程。每答对一次，就会移除一个灰色方块，逐渐揭示下方隐藏的图片。享受色彩丰富的图形、流畅的游戏体验、轻松的音乐以及响应灵敏的控制，这是一款适合所有年龄段的学习冒险游戏。

## 怎么玩
