# 释放礼品盒

<a href="https://inkwengame.com/zh/games/release-the-gift-boxes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/release-the-gift-boxes/cover.jpg)

在这个游戏中，你需要堆叠礼品。触摸钳子夹着的礼品以释放它，并将其落在其他礼品上。尽量让礼品不要相互压倒，也不要掉落到地板上。找准时机并居中释放礼品。争取获得最高分，建造最高的礼品塔。点击屏幕开始玩这款名为释放礼品盒的游戏。
