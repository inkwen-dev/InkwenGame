# 漫画数学辅导

<a href="https://inkwengame.com/zh/games/manga-math-tutor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/manga-math-tutor/cover.jpg)

漫画数学辅导是一款益智游戏，挑战你进行一些数学计算。目标是让你在轻松愉快的方式下，提高并加快心算能力。

## 怎么玩

在棋盘上方，你会看到我们需要你解决的计算题目。然后你需要通过点击棋盘上的数字，按所需顺序选择数字来完成运算。完成运算越快，得分就越高。
