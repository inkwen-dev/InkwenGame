# 怪物合并

<a href="https://inkwengame.com/zh/games/monsters-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monsters-merge/cover.jpg)

有一位普通的农夫，但在一个不幸的日子里，怪物袭击了他的农场，毁掉了全部的收成。但他没有灰心，他抓住了这些怪物，创建了自己的怪物农场。通过出售门票让游客观看每一只怪物，他决心再次成为一位成功的农夫。

## 怎么玩

通过点击屏幕鼠标或手指来控制一切。连接相同的怪物，从传送门购买或等待怪物，购买升级并解锁所有怪物
