# 水果大师三消

<a href="https://inkwengame.com/zh/games/fruits-master-match-3" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-master-match-3/cover.jpg)

在这个HTML5游戏中收集水果物品。按下任意复活节物品开始游戏。现在用鼠标或手指在相邻的相同物品上移动（水平、垂直或对角线方向）。至少选择3个物品。松开鼠标按钮以完成匹配。每第6个物品会给予奖励。超过7个物品将获得时间奖励。在规定时间内收集目标水果物品，否则游戏失败。你能玩到的最大关卡是多少？

## 怎么玩

用手指滑动并连接水果
