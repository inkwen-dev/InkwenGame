# 六边形拼图

<a href="https://inkwengame.com/zh/games/hex-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hex-puzzle/cover.jpg)

六边形拼图是一款需要匹配物品的游戏。你需要将提供的物品拖动到棋盘上，并将它们排列成四个或更多相同颜色的物品相连。这些相同颜色的物品可以在任意位置，水平、垂直或对角线方向相连。在没有空间放置新物品之前，尽可能多地得分。

## 怎么玩

使用鼠标拖动物品
