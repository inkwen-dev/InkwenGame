# 缺失的数字气泡

<a href="https://inkwengame.com/zh/games/missing-num-bubbles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/missing-num-bubbles/cover.jpg)

这是一款有趣的数字游戏，适合儿童。在本游戏中有三种模式：找出所问数字之前的数字、找出所问数字之后的数字，以及找出两个给定数字之间的数字。查看左侧面板中的给定数字，并从右侧方框中选择正确的数字气泡。

## 怎么玩

使用鼠标或触摸板来玩此游戏
