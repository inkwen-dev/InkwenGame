# 六边形糖果爆裂

<a href="https://inkwengame.com/zh/games/hex-candy-crackle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hex-candy-crackle/cover.jpg)

通过射击一个相似的糖果来阻止糖果部队前进。游戏有两种模式：在初级模式中，一组两个糖果可以被消除；而在专家模式中，你需要至少三个糖果才能消除。收集所有星星即可赢得游戏。一颗糖果掉落会损失四分之一条生命。
