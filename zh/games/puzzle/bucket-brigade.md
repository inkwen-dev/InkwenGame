## 怎么玩

键盘和鼠标控制

1 - 选择救护车

2 - 选择起重机

3 - 选择自卸车

W / S - 驾驶

Q / E - 旋转起重机驾驶室

鼠标上/下 - 移动起重机臂

鼠标左键 - 收起起重机爪

鼠标右键 - 打开起重机爪

Esc - 暂停/返回

手柄控制

RT / R2 - 前进

LT / L2 - 后退/刹车

LB / L1 - 向左旋转起重机驾驶室

RB / R1 - 向右旋转起重机驾驶室

左摇杆上/下 - 移动起重机臂

A / 十字键 - 收起起重机爪/确认

B / 圆圈键 - 返回/取消/暂停

X / 方块键 - 切换车辆

## 介绍

救生桶大作战

《救生桶大作战》是一款轻松愉快的玩具主题益智游戏，你将带领一支救援队穿越阳光明媚的海滩。

孩子们把玩具和沙堡都留在了沙滩上，你需要在夏日的酷暑融化你的塑料小车之前，把沙滩清理干净。
