# 匹配宝石

<a href="https://inkwengame.com/zh/games/match-jewels" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-jewels/cover.jpg)

匹配所有颜色相同的宝石。为了使游戏更有趣，尝试匹配4个或5个宝石，这将帮助你完成关卡。交换并匹配3个或更多相同类型的宝石，以获得更高分数。
