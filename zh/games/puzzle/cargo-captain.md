# 货物船长

<a href="https://inkwengame.com/zh/games/cargo-captain" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cargo-captain/cover.jpg)

《货物船长》是一款基于物理的解谜冒险游戏，帮助船长堆放货箱并清除行以获得分数。战略性地放置起重机掉落的集装箱，并管理不断增长的堆叠！体验五个独特关卡的挑战：从阳光明媚的港口到暴风雨夜、雪白的冬天，甚至丛林河流。使用特殊道具如炸弹和冷冻物品来克服困难局面，冲击高分。你准备好成为终极货物船长了吗？

## 怎么玩

移动 使用方向键或A D键移动船长 推动 只需走向一个货箱即可将其推入空隙 移动端 使用屏幕上的触摸按钮进行移动和互动 目标 用货箱填满一整行以清除该行并得分
