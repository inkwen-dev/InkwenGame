# 平衡堆叠

<a href="https://inkwengame.com/zh/games/balance-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/balance-stack/cover.jpg)

玩家需要一个接一个地堆叠形状，确保它们不会倒塌。当所有形状都堆叠完毕后，会启动一个短暂的计时器，以确保堆叠结构的稳定性。如果其中任何一个部件掉落，游戏结束，玩家可以重新尝试该关卡。包含多种形状：立方体、三角形、圆柱体、球体和矩形。游戏将随机播放这些形状，使挑战性更高，乐趣更足，最高可达第50关。
