# 隐藏物品 冬日问候

<a href="https://inkwengame.com/zh/games/hidden-objects-hello-winter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hidden-objects-hello-winter/cover.jpg)

漫步在冬日风景中，享受一段美好的时光。在时间耗尽前找到屏幕上所有的物品。16个被物品填满的雪景关卡等待你来清理。你能达成目标吗？只有一种方法可以知道。

## 怎么玩

左侧屏幕显示需要寻找的物品列表。在时间耗尽前在场景中找到它们。如果遇到困难，请点击提示按钮。使用放大镜按钮可放大场景，在此模式下还可以拖动屏幕查看不同区域。
