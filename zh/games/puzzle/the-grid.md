# 网格

<a href="https://inkwengame.com/zh/games/the-grid" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-grid/cover.jpg)

《网格》是一款快节奏的益智游戏，玩家需要重复网格中显示的图案。玩家只有几秒钟的时间来重复正确的图案，才能继续前进。随着进度推进，挑战会变得越来越困难，有些甚至需要改变你的视角。在时间耗尽前尽可能多地得分，然后再次尝试击败你的最高分，或登上排行榜顶端。该网格游戏也支持移动设备，仅需点击/轻触操作。

## 怎么玩

鼠标点击 触摸 轻触
