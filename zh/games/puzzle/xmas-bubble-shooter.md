# 圣诞泡泡射击

<a href="https://inkwengame.com/zh/games/xmas-bubble-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/xmas-bubble-shooter/cover.jpg)

这是一款具有圣诞节主题的经典泡泡射击游戏，包含36个富有挑战性的关卡。在每个关卡中，你将面临不同的挑战。要完成一个关卡，必须消除屏幕上所有的灯光。当你发射的光球与三个或更多相同颜色的光球组合时，这些光球就会被消除。你必须在规定时间内完成关卡。越早完成关卡，得分越高。
