# 会说话的蔬菜：表情包合并

<a href="https://inkwengame.com/zh/games/talking-veggies-meme-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/talking-veggies-meme-merge/cover.jpg)

欢迎来到《会说话的蔬菜：表情包合并》！在这款令人上瘾的物理益智游戏中，尽情投放并合并各种搞笑的会说话的蔬菜吧！合并两个相同的蔬菜，就能创造出一个更大的蔬菜，最终还能挑战传说中的西瓜Boss！赚取金币，购买各种疯狂的升级道具来强化你的罐子，还能打开扭蛋盒，解锁拥有强大增益效果的稀有表情包皮肤…

## 怎么玩

电脑端：左键点击罐子上方任意位置即可放置蔬菜。手机端：点击屏幕任意位置即可放置蔬菜。

目标：放置并合并相同的蔬菜，使其进化成更大的蔬菜。不断合并蔬菜即可得分，但要小心——如果蔬菜溢出罐子，游戏就结束了！在商店中使用获得的金币进行升级，并使用水晶打开宝箱。
