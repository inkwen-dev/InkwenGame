# Bug Hunter

<a href="https://inkwengame.com/zh/games/bugs-hunter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bugs-hunter/cover.jpg)

Bugs Hunter 是一种泡泡射击游戏。但这一次，蜘蛛需要抓住朝他靠近的虫子。蜘蛛会掉落蛛网，从而捕捉虫子。你必须用这种方式捕捉所有虫子，因为它们想要攻击你。如果三个虫子到达蜘蛛线，游戏就会结束。虫子会从不同方向出现，并以不同的速度移动。因此，你必须小心谨慎，并向各个方向射击。

## 怎么玩

点击屏幕上的游戏图标来玩游戏，或使用方向键和空格键进行射击
