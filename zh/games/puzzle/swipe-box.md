# 滑动盒子

<a href="https://inkwengame.com/zh/games/swipe-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/swipe-box/cover.jpg)

滑动盒子是一款富有挑战性和趣味性的益智游戏，玩家需要运用逻辑思维和策略，将方块通过各种障碍物移动到目标区域。游戏采用简洁而充满未来感的视觉风格，让玩家沉浸于金属质感的挑战与烧脑关卡之中。

## 怎么玩

目标
目标是通过滑动方块在网格中移动，使其到达目标区域。
控制
向任意方向（上、下、左、右）滑动以移动方块。
避开障碍物
注意那些会阻挡你的障碍物。
