# 著名公主记忆

<a href="https://inkwengame.com/zh/games/famous-princesses-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/famous-princesses-memory/cover.jpg)

著名公主记忆是一款独特而有趣的益智游戏。通过这款游戏，你可以了解并提升自己的记忆力。游戏玩法非常简单：你需要根据屏幕上显示的图片制作冰淇淋，图片只会显示几秒钟，之后你需要根据之前显示的图片来制作冰淇淋。如果你制作的冰淇淋与之前显示的图片不一致，那么你制作的冰淇淋就会被扔进垃圾桶。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
