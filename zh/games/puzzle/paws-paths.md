# 爪印与小径

<a href="https://inkwengame.com/zh/games/paws-paths" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/paws-paths/cover.jpg)

在 50 个色彩缤纷的益智关卡中，连接相同的猫、熊和兔子，完成你的目标。在步数用完之前，构建长链来发射有用的爪子，打破冰面，并找到绕过金属方块的道路。

## 怎么玩

用鼠标点击并拖动，或用手指拖动，跨越相邻的相同动物。松开鼠标即可收集连锁动物，并让新的动物落下。在步数限制内到达棋盘上方的目标。一旦形成连锁，四个或更多动物即可发射额外的爪子。清除编号冰块旁边的动物即可打破冰块；金属方块会留在原地。使用“撤销”功能重新考虑下一步操作，或使用“提示”功能寻求帮助。
