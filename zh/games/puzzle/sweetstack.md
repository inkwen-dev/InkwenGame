# SweetStack

<a href="https://inkwengame.com/zh/games/sweetstack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweetstack/cover.jpg)

SweetStack 是一款非常甜美有趣的游戏！合并两个或更多相似且较小的果冻，以创建新的果冻，这就是规则。持续合并相同类型的果冻，让您的得分越来越高。不断添加果冻，直到您越过横杆并填满空间。

## 怎么玩

顶部的控制条决定了下一个果冻将落下的位置。合并果冻，获得更高的分数
