# 时间控制

<a href="https://inkwengame.com/zh/games/time-control" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/time-control/cover.jpg)

时间控制是一款益智游戏，你需要控制红色小球。她将从一个点垂直移动到另一个点。当小球碰到点时，你将获得分数。但方块会围绕小球的路径旋转，因此你需要避开它们。为此，你需要控制小球的速度。点击或轻触屏幕可减慢小球的移动，使其恢复正常移动。只有这样你才能避免与方块碰撞。如果你撞上方块，游戏就会结束。所以尽量多得分…

## 怎么玩

轻触屏幕即可开始游戏

## 介绍

时间控制是一款益智游戏，你需要控制红色小球。她将从一个点垂直移动到另一个点。当小球碰到点时，你将获得分数。但方块会围绕小球的路径旋转，因此你需要避开它们。为此，你需要控制小球的速度。点击或轻触屏幕可减慢小球的移动，使其恢复正常移动。只有这样你才能避免与方块碰撞。如果你撞上方块，游戏就会结束。所以尽量多得分，并成功控制小球。
