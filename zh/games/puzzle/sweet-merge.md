# 甜蜜合并

<a href="https://inkwengame.com/zh/games/sweet-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweet-merge/cover.jpg)

你喜欢合并游戏吗？点击或轻触以释放糖果，合并相同的糖果，直到得到最大的糖果。尝试困难模式，从最大的糖果开始，不断合并，直到得到那个小小的蓝色糖果。祝你好运！

## 怎么玩
