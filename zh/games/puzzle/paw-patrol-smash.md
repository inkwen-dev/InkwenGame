# 汪汪队立大功 摧毁

<a href="https://inkwengame.com/zh/games/paw-patrol-smash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/paw-patrol-smash/cover.jpg)

用汪汪队的成员摧毁所有气球并获得分数。但你不能摧毁斯凯。如果你摧毁了斯凯，就会失去一条生命。如果你失去3条生命，或者三次摧毁斯凯，游戏就结束了。因此，有时汪汪队会行动迅速，你需要小心应对。
