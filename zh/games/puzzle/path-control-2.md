# 路径控制

<a href="https://inkwengame.com/zh/games/path-control-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/path-control-2/cover.jpg)

游戏的目标是将静止的球击入篮筐。通过鼠标点击物体，可使其左右移动并改变位置。这样你就可以让球朝你想要的方向移动。当球进入篮筐时，你将获得分数并进入下一关。祝你玩得愉快。

## 怎么玩

使用鼠标操作游戏或在屏幕上轻触
