# 连接协会

<a href="https://inkwengame.com/zh/games/connect-associations" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/connect-associations/cover.jpg)

一组词语隐藏着许多有意义的关联。找出四个主题相同的词语，并逐步将它们合并成一个词组。正确的匹配会揭示词类，而后面的关卡会引入新的词组和冰雪障碍。

## 怎么玩

1. 找出两个主题相同的单词。

2. 点击第一个单词，然后点击第二个单词，或者将一个单词拖到另一个单词上。

3. 继续添加相关单词，直到四个单词全部匹配。

4. 每次正确合并单词都会破坏冰块。使用单词前，请先解冻冰块。

5. 揭开所有类别即可完成关卡。

错误的单词组合会消耗一次尝试机会。如果遇到困难，可以重新排列单词或使用提示。

## 介绍

一组词语隐藏着许多有意义的关联。找出四个主题相同的词语，并逐步将它们合并成一个词组。正确的匹配会揭示词类，而后面的关卡会引入新的词组和冰雪障碍。

轻松的节奏让你有时间思考每一步。当遇到特别棘手的关联时，提示可以帮助你继续解题。完成关卡，赢取金币，见证你的整体进步。
