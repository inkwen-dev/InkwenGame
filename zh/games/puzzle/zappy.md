# Zappy

![cover](https://img.inkwengame.com/games/zappy/cover.jpg)

Zappy 是一款有趣的 2D 解谜冒险游戏，你将操控一个聪明的机器人，执行将一个神秘箱子送达目的地的任务。穿越复杂的障碍，避开危险陷阱，智胜敌人，并解决具有挑战性的谜题以完成每一关。运用策略和精准的操作来保护箱子并抵达目标。游戏玩法引人入胜，关卡创意十足，操作流畅，为解谜游戏爱好者带来一场激动人心的冒险体验。

## 怎么玩

移动 WASD 或 上下左右 键 拾取/放下物品 空格键 或 E
