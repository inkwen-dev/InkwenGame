# 圣诞记忆配对

<a href="https://inkwengame.com/zh/games/xmas-memory-matching" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/xmas-memory-matching/cover.jpg)

这是一款带有圣诞节元素的记忆游戏。游戏共有30个关卡，你需要通过所有关卡才能完成游戏。但在某些关卡中，时间被缩短，你必须快速反应并加快节奏，以在规定时间内完成关卡。你可以重置当前关卡，并从你离开的地方继续进行游戏。

## 怎么玩

点击屏幕开始游戏
