# 大泡泡

<a href="https://inkwengame.com/zh/games/big-bubbles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/big-bubbles/cover.jpg)

大泡泡是一款关于吸收较小泡泡同时避免被更大泡泡吸收的游戏。当你吸收泡泡时，你会变大，由于游戏是无尽模式，你可以从皮米尺度成长为万亿光年大小。每5级有一个检查点，如果你失败，将从该检查点重新开始。游戏支持使用键盘、鼠标、触摸屏，甚至如果浏览器支持，也可以使用游戏手柄进行操作。
