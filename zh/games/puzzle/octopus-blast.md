# 章鱼爆炸

<a href="https://inkwengame.com/zh/games/octopus-blast" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/octopus-blast/cover.jpg)

在这个解谜游戏中，你必须引爆元素以触发连锁反应，从而消除它们。你需要消除所有元素才能完成关卡并进入下一关。你需要完成400个关卡才能通关游戏。在每个关卡中，你可以收集星星。尽可能快速地完成关卡，以获得最多的星星。你能否用三颗星完成所有关卡？这就是你的挑战。

## 怎么玩

每次点击章鱼，它都会变大。当完全充满时，章鱼会爆炸，并将墨汁扩散到邻近的章鱼，使其生长，从而引发连锁反应。要聪明，要迅速，全部炸掉
