# 颜色方块

<a href="https://inkwengame.com/zh/games/color-cell" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-cell/cover.jpg)

颜色方块是一款带有彩色方块的益智游戏。这款游戏的目标是创建四个颜色相同的方块以将其消除。屏幕上出现的方块需要放置在棋盘上，并尝试匹配方块的颜色。您可以将方块向任何方向移动，以便正确地打破和排列它们。只要棋盘上有空位，就可以继续玩游戏。争取最佳成绩并享受乐趣。使用鼠标来玩此游戏，如果您在移动设备上玩，则可以使用手指操作。
