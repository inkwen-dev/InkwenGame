# 滚动橙子

<a href="https://inkwengame.com/zh/games/roll-orange" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roll-orange/cover.jpg)

这款游戏的主角是一颗被困在箱子和平台顶部的橙子！他害怕高处，因此你必须通过移除这些箱子和平台来帮助他到达地面。但要小心，随着游戏进程推进，一些危险物品会出现，比如炸弹和仙人掌，如果你碰到它们，就会失去一条生命！游戏开始时你有5条生命，如果全部失去，游戏就结束了。随着游戏进展，你可能会根据得分获得额外的生命。

## 怎么玩

使用鼠标操作游戏或点击屏幕
