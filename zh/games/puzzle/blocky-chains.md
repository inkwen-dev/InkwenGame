# 方块链条

<a href="https://inkwengame.com/zh/games/blocky-chains" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocky-chains/cover.jpg)

使用触控板或鼠标连接相似的糖果。将3个或更多水平、垂直或对角相邻的糖果组成一组，使它们的方块颜色变为蓝色。将所有方块变为蓝色即可完成该关卡。完成全部24个关卡即可赢得游戏。

## 怎么玩
