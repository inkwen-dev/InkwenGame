# 直升机跳跃

<a href="https://inkwengame.com/zh/games/heli-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/heli-jump/cover.jpg)

直升机跳跃是一款游戏，你需要控制直升机安全地起飞并降落在下一个地点。你需要快速且精准。在游戏结束前，你有三次出错的机会。你可以更改直升机的颜色。找出你的幸运色，并尝试在这个飞行游戏中尽可能走得更远。按住屏幕可给直升机提供飞行力量。如果力量太强，它会撞上障碍物；但如果力量太弱，它会掉入深渊。找到合适的时机，安全飞行。
