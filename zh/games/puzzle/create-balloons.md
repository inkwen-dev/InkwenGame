# 创建气球

<a href="https://inkwengame.com/zh/games/create-balloons" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/create-balloons/cover.jpg)

在游戏《创建气球》中，你将来到一家生产球类的工厂后方，最近这里发明了一种新的生产方式——一台特殊机器。它操作简单，仅由一个普通的小小水桶组成。点击它，球就会无限量地出现。你的任务是填满现有的容器，但不能超过其容量上限。当顶部的虚线从白色变为绿色时即为成功。

## 怎么玩

在桌面端使用鼠标，或在移动设备上使用触摸按钮
