# 森林瓷砖

<a href="https://inkwengame.com/zh/games/forest-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/forest-tiles/cover.jpg)

9乘9的游戏场地上有若干枚硬币。需要将方块放置在游戏场上，以完全拼成一条垂直或水平的线。金币可用于重置不需要的方块，并在失败时继续游戏。

## 怎么玩

游戏场左侧会出现三个方块，必须将其放置在游戏场上，以拼成一条水平或旋转的线
