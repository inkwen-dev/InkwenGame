# 复活节彩蛋收集

<a href="https://inkwengame.com/zh/games/easter-eggs-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/easter-eggs-collection/cover.jpg)

在这个HTML5游戏中收集复活节彩蛋。点击任意彩蛋开始游戏。现在用鼠标或指尖在相邻的相同彩蛋上移动（水平、垂直或对角线方向）。至少选择3个彩蛋。松开鼠标按钮以使它们匹配。每第6个彩蛋会给予奖励。超过7个彩蛋将获得时间奖励。在规定时间内收集指定的彩蛋，否则游戏失败。你能玩到的最高等级是多少？
