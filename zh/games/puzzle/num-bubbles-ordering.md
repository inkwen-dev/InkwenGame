# 数字气泡排序

<a href="https://inkwengame.com/zh/games/num-bubbles-ordering" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/num-bubbles-ordering/cover.jpg)

触摸或点击数字气泡，按正确的顺序。选择错误的气泡会从你的分数中扣除50分，而选择正确的气泡则会为你的分数增加100分。在时间耗尽前完成关卡可获得时间奖励。
