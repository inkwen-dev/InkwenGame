# 圣诞方块挑战

<a href="https://inkwengame.com/zh/games/christmas-block-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-block-challenge/cover.jpg)

圣诞方块挑战：在10x10的网格上战略性地放置节日方块，完成一整行或一整列的10个方块，以收集其中所有的圣诞收藏品。目标是收集棋盘上所有的收藏品。你能否成为终极假日方块策略大师，揭开所有的节日惊喜？

## 怎么玩
