# 收获商店分类

<a href="https://inkwengame.com/zh/games/harvest-store-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/harvest-store-sorting/cover.jpg)

收获商店分类是一款设定在田园世界中的益智游戏，你需要将收获的水果分类摆放至货架上。将相同类型的水果放在一起，直到每个货架上只有一种水果。游戏趣味十足且引人入胜，每一关都拥有不同形状的货架以及数量各异的货架。运用你的分类技巧，在有限的空间内整齐地整理货架。如果遇到困难，还可以使用工具帮助你更轻松地通过关卡。

## 怎么玩

点击一个水果后，将其移动到相同类型水果的货架上或空货架上，然后再次点击以放置。当所有货架上的水果一致时，即可进入下一关
