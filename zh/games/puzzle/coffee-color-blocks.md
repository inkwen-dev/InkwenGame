# 咖啡色块

<a href="https://inkwengame.com/zh/games/coffee-color-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coffee-color-blocks/cover.jpg)

《咖啡色块》是一款画面明亮、轻松愉快的益智游戏。游戏中，你需要移动彩色方块，引导它们到达对应颜色的门。每次连接成功，方块内部的杯子就会被填满——你的目标是在不阻挡路径的情况下填满整个图案。

## 怎么玩

移动方块。点击并滑动方块，将它们移动到相同颜色的门前。

匹配颜色。方块只有到达匹配颜色的门前才能填充——填充门内的凹槽。

填充整个形状。填充图形的每个部分即可完成关卡。

避免死路。提前思考——有些方块如果移动不当，可能会阻挡其他方块。

不断进步，解锁新机制。每个关卡都会引入新的形状、颜色和谜题等你来解。
