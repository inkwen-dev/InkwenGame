# 夏洛克小矮人拼图

<a href="https://inkwengame.com/zh/games/sherlock-gnomes-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sherlock-gnomes-jigsaw/cover.jpg)

有趣的拼图游戏，你可以选择五张图片中的一张来尝试完成拼图。选择你想放置正确位置的拼图块数量，以获得夏洛克小矮人的图像。你可以使用25、49或100块拼图进行游戏。
