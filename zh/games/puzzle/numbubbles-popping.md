# 数字泡泡爆破

<a href="https://inkwengame.com/zh/games/numbubbles-popping" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/numbubbles-popping/cover.jpg)

数字泡泡爆破是一款逻辑数学游戏。开始时，只需指向一个数字泡泡，设定箭头方向，然后将数字泡泡射向另一个。如果两个数字泡泡上的数字不同，它们将会合并，生成的新数字泡泡将包含两个数字的总和。如果两个数字泡泡上的数字相同，则两个数字泡泡都会被消除。你的目标是消除所有数字泡泡，因此在合并或消除一对之前，请仔细思考。

## 怎么玩

使用鼠标或触摸板来玩此游戏
