# 拾取与放置匹配

<a href="https://inkwengame.com/zh/games/pick-and-drop-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pick-and-drop-match/cover.jpg)

通过组成三连相似礼物来收集礼物。你可以通过将传送带前端的礼物拖动并放置到另一条传送带上，来形成这些行。在礼物到达传送带末端之前，持续这样做。尽可能多地完成匹配，以打破你的记录。
