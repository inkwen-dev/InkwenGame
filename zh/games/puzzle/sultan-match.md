# 苏丹匹配

<a href="https://inkwengame.com/zh/games/sultan-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sultan-match/cover.jpg)

苏丹匹配是一款经典的配对游戏，你需要连接三个或更多相同的物体来得分。要进入下一关，你需要获得一定的分数。注意时间，努力获取分数以通过关卡。尝试通过全部十二个关卡，享受这款游戏的乐趣。
