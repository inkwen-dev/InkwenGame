# 地铁狂飙单词方块

<a href="https://inkwengame.com/zh/games/subway-surfers-word-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/subway-surfers-word-blocks/cover.jpg)

组合单词是一件轻而易举的事情。你只需要鼠标就能完成这项任务。只需点击并按住单词的第一个字母，然后拖动到最后一个字母。当你这样做时，方块会变成蓝色。当整个单词被高亮显示后，就可以释放点击了。
