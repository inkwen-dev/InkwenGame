# 1010 鱼块

<a href="https://inkwengame.com/zh/games/1010-fish-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/1010-fish-blocks/cover.jpg)

选择并放置鱼块组合，以完成垂直和水平行。一旦完成，整行将被移除。你不受时间限制，只受棋盘上空位的限制，因此要谨慎移动。游戏简单易上手，只需选择一组方块并将其拖到棋盘上即可。当你放置完三组方块后，系统会再给你三组新的方块。一次完成多行可获得更高分数。
