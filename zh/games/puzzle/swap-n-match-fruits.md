# 交换匹配水果

<a href="https://inkwengame.com/zh/games/swap-n-match-fruits" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/swap-n-match-fruits/cover.jpg)

交换相邻的水果方块，以形成一行或一列三个相同的水果方块。要完成一个关卡，你需要将棋盘上所有方块的颜色变为绿色。

## 怎么玩

使用鼠标或触摸操作此游戏
