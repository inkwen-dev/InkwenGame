# 赛车拼图

<a href="https://inkwengame.com/zh/games/race-cars-jigsaw" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/race-cars-jigsaw/cover.jpg)

这是一款以赛车为主题的拼图游戏。你可以玩12个关卡。开始游戏时，在第一关选择你想要的游戏模式。有三种模式：简单模式（25块）、中等模式（49块）或困难模式（100块）。完成第一关后即可进入下一关。你能解开全部12关吗？使用鼠标拖动拼图块到正确位置。玩游戏时没有时间限制。
