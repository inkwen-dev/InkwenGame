# 动物收藏

<a href="https://inkwengame.com/zh/games/animals-collection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animals-collection/cover.jpg)

在这个游戏中收集动物。点击任意一个动物开始。现在移动鼠标或手指尖，选择相邻且相同的动物（水平、垂直或对角线方向）。至少选择3个动物。松开鼠标按钮以完成匹配。每第6个动物会获得奖励。超过7个动物会获得时间奖励。在规定时间内收集指定的动物，否则游戏失败。

## 怎么玩
