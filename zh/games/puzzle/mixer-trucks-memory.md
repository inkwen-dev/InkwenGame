# 搅拌车记忆

<a href="https://inkwengame.com/zh/games/mixer-trucks-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mixer-trucks-memory/cover.jpg)

搅拌车记忆是一款游戏，你可以一边测试记忆力一边享受乐趣。每张卡片背后都有一辆不同的搅拌车。记住卡片内部的图片，点击两张相同的卡片将其消除。与时间赛跑，击中所有卡片。努力通过所有关卡。

## 怎么玩

轻触屏幕上的卡片来玩这个游戏
