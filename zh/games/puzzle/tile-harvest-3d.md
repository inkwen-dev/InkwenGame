# Tile Harvest 3D

<a href="https://inkwengame.com/zh/games/tile-harvest-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tile-harvest-3d/cover.jpg)

《Tile Harvest 3D》是一款融合了趣味十足的3D方块消除益智游戏。通过收集匹配的方块组合并进行强力合并，清除堆积如山的彩色3D方块。游戏拥有无限关卡、不断升级的挑战难度，以及一系列关键道具助你渡过难关，每一关都充满新鲜感，让你绞尽脑汁。

## 怎么玩

你的目标：清除 3D 棋盘上的所有方块，即可赢得关卡。

1. 选择匹配的方块

点击 3D 方块堆上任意一个可点击的方块。当你点击 3 个相同类型的方块时，它们会被收集并送入你的传送带——屏幕底部的一排槽位。

2. 注意你的传送带

传送带存放着你收集的方块。当传送带上同时出现 3 个相同的方块时，它们会自动合并成一个全新的、更高等级的方块——清空这些槽位，腾出空间放置更多方块。

3. 旋转和缩放棋盘

方块以 3D 形式堆叠。滑动屏幕旋转棋盘，即可显示下方隐藏的方块。捏合屏幕即可放大或缩小。在正确的时间显示正确的方块是顺利合并的关键。

4. 注意空间

如果你的传送带被无法合并的方块填满，你就无法继续游戏——关卡失败。提前思考，规划你的选择，让传送带上的牌源源不断地涌出。

5. 明智地使用道具

四种道具助你摆脱困境：

🔄 回旋镖 — 将传送带上的最后一张牌送回牌桌。

🌀 旋风 — 重新洗牌，让牌桌焕然一新。

🔍 放大镜 — 高亮显示一组三个相同的牌。

🔨 锤子 — 击碎并移除牌桌上的一张牌。
