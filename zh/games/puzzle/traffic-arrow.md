# 交通箭头

<a href="https://inkwengame.com/zh/games/traffic-arrow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/traffic-arrow/cover.jpg)

交通箭头是一款游戏，你需要控制蓝色箭头穿过其他箭头。避开带有箭头的灰色球，并尽可能长时间地生存下去。点击屏幕以移动球体。点击你希望蓝色箭头前往的位置。注意观察其他球体，它们会从四面八方出现。交通非常繁忙，你需要找到最佳位置来越过球体。

## 怎么玩

点击屏幕即可开始游戏
