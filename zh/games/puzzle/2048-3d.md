# 2048 3D

<a href="https://inkwengame.com/zh/games/2048-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/2048-3d/cover.jpg)

2048 3D 是一款单人滑动方块拼图游戏。游戏的目标是在网格上滑动带有数字的方块，将它们合并以创建一个数字为 2048 的方块，但达到目标后仍可继续游戏，创造出更大数字的方块。目的是让相同数字的方块相互碰撞，将两个方块上的数字相乘，最终得到数字 2048。两个相同数字的方块碰撞后会合并为它们的和。
