# 方块爆破

<a href="https://inkwengame.com/zh/games/block-blaster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-blaster/cover.jpg)

方块爆破是一款融合了网格立方体游戏挑战与经典方块谜题趣味性的益智游戏。通过越来越复杂的关卡锻炼你的大脑，不断磨练技能并提升你的智商分数。潜入纯粹的解谜乐趣世界，让方块匹配的冒险就此开启！

## 怎么玩

将立方体方块拖放到8x8网格中。用方块填满行或列以消除它们。当没有剩余方块时，游戏结束。方块不能旋转，这使得游戏更具挑战性和不确定性
