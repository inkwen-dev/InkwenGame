# 堆叠潮汐

<a href="https://inkwengame.com/zh/games/stack-tide" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-tide/cover.jpg)

堆叠潮汐是一款基于物理的堆叠游戏，每一块积木都至关重要。投放并旋转漂浮的形状，建造你能搭建的最高塔楼，并在不断上涨的潮水中保持领先。错过的积木会落入水中，海水上涨得更快，一次失误的放置就可能让一切更接近终结。简单易上手的操作和无限重玩的价值，使每一次游戏都成为平衡、时机与压力之间的紧张较量。

## 怎么玩

桌面端 使用鼠标拖动或使用 A D 键以及左右箭头键移动 按下 Q E 键或上下箭头键旋转 按空格键或回车键放下 移动设备 点击并拖动以移动方块
