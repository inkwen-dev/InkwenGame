# Lof Tetriz

<a href="https://inkwengame.com/zh/games/lof-tetriz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lof-tetriz/cover.jpg)

经典的下落方块俄罗斯方块游戏，你需要通过填满方块来完成一行，从而消除方块。

## 怎么玩

使用左右方向键和向下键移动方块，使用上方向键旋转方块。或者你可以点击或轻触按钮来执行相同操作。你的目标是将方块拼合，形成一整行。
