# 对角线游戏

<a href="https://inkwengame.com/zh/games/diagonal-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/diagonal-game/cover.jpg)

对角线是一款受控的解谜游戏，游戏的目标是控制子弹避开方块和其他可能摧毁子弹的火箭。但你需要记住，子弹只能沿对角线移动。虽然控制起来很困难，但从另一方面来说，它既有趣又好玩。当你掌握技巧后，游戏就会变得简单。收集路上的蓝色球体，尽可能长时间地游玩，避免碰撞或被火箭击中。

## 怎么玩

点击屏幕即可开始游戏
