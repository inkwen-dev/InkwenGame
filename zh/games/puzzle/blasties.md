# Blasties

<a href="https://inkwengame.com/zh/games/blasties" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blasties/cover.jpg)

Blasties 是一款以糖果为主题的游戏中，你从地面发射糖果，它们会在布满糖果的天空中形成相同糖果的连锁反应。3个或更多相同的糖果相连将提升你的得分。尽情享受吧 :)

## 怎么玩

形成相同糖果的连锁
