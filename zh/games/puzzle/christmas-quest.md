# 圣诞大冒险

<a href="https://inkwengame.com/zh/games/christmas-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-quest/cover.jpg)

圣诞大冒险是一款独特的消除三消游戏。将物品移动到空白格子中，以形成横向或纵向的三个相同物品的组合。尽可能少地使用移动次数以获得更高分数。只需点击物品，再点击想要移动到的位置即可移动。如果物品与其目的地之间有畅通路径，它就会移动到新位置。除了组成三个相同的物品组合外，如果你提前完成游戏，还将获得额外时间奖励。
