# 推土机攀爬

<a href="https://inkwengame.com/zh/games/bulldozer-climb" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bulldozer-climb/cover.jpg)

推土机攀爬是一款跳跃平台游戏，你需要跳过山丘并收集时钟以获得额外时间。尽量在时间耗尽前通过更多的山丘。使用鼠标操作此游戏，或使用键盘上的左右箭头键进行一次或两次跳跃。
