# 表情符号合并

<a href="https://inkwengame.com/zh/games/emoji-merge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/emoji-merge/cover.jpg)

表情符号合并是一款引人入胜且令人上瘾的益智游戏，玩家需要向下投放并合并相同的表情符号以创造新的表情符号。目标是战略性地合并匹配的表情符号，发现独特的组合，并获得高分。

## 怎么玩

点击以从上方投放表情符号。合并相同的表情符号以创建新组合并得分。使用“移除最小项目”按钮清除舞台上微小的表情符号实例。开启一段无法停止的乐趣之旅
