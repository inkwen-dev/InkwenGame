# Snakefalls

<a href="https://inkwengame.com/zh/games/snakefalls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snakefalls/cover.jpg)

Snake falls 是一款非常有趣的益智游戏，拥有美丽的鸟头和蛇身，以及独特的移动机制。不要掉到尖锐的物体上，吃更多的水果来变得更大更美丽，并通过美丽而富有挑战性的关卡。支持PC和HTML5的按钮控制，以及移动端的按钮控制，通过滑动自动开启触摸控制。

## 怎么玩

鼠标或点击操作
