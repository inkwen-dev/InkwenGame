# 僵尸防御GO

<a href="https://inkwengame.com/zh/games/zombie-defense-go" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-defense-go/cover.jpg)

僵尸已经入侵了庭院，使用武器射击所有僵尸来保护农夫的房子。完成每个任务后，你可以获得奖励。通过射击所有僵尸来防守你的房子，并通过购买武器来选择你的装备。通过击杀僵尸赚取金钱，然后用这些金钱购买武器或升级你的屏障。完成每个任务后，你可以获得奖励。

## 怎么玩

使用方向键或鼠标左键进行射击
