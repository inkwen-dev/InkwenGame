# 甜甜圈猫

<a href="https://inkwengame.com/zh/games/donutcats" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/donutcats/cover.jpg)

放置弹簧，帮助这些有趣的甜甜圈猫进入舒适的礼品盒。使用喷气背包、传送门和巨大的风扇。尽可能多地收集硬币，并解锁新的猫咪和甜甜圈。

## 怎么玩

点击弹簧以激活它们。甜甜圈猫不能碰到尖锐的物体，否则会死亡
