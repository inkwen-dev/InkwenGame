# 匹配形状

<a href="https://inkwengame.com/zh/games/match-the-shapes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-the-shapes/cover.jpg)

在这个游戏中，你需要将进入屏幕的形状与对应的形状进行匹配。触摸屏幕的左侧和右侧以更换形状，并匹配进入屏幕的形状。如果你在电脑上玩游戏，可以使用箭头键。如果用错误的形状撞击了进入的形状，游戏将会结束。

## 怎么玩

使用鼠标来玩这个游戏
