# 箭头消失

<a href="https://inkwengame.com/zh/games/arrows-disappear" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrows-disappear/cover.jpg)

你将面对一叠不断增长的3D方块，每个方块都显示着不同的箭头方向。游戏的核心在于快速决策——点击向上箭头的方块，在方块塔倒塌前将其消除。它的独特之处在于：简洁的3D画面，令人满意的物理效果，不断提升的速度和复杂度，简单的单指操作，以及随着方块塔越堆越高、速度越快而产生的紧张刺激的“再来一关”的感觉！

## 怎么玩

你的主要目标是快速点击并消除所有带有向上箭头 (↑) 的方块，同时避开其他方向的方块 (↓ ← →)。在塔楼过高倒塌之前，尽可能快地消除方块。点击速度越快、越准确，得分就越高！

PC 操作：

鼠标：直接点击带有向上箭头 (↑) 的方块即可消除它们。

移动设备操作：

触摸屏：点击带有向上箭头 (↑) 的方块即可消除它们。
