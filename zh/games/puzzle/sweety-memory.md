# Sweety Memory

![cover](https://img.inkwengame.com/games/sweety-memory/cover.jpg)

Sweety Memory 是一款有趣的拼图游戏。在时间耗尽前匹配所有相同的卡片。共有 4 个难度等级，第一个最简单，最后一个最难。通过快速找到相同的卡片来获得最多的分数。尽情享受！

## 怎么玩
