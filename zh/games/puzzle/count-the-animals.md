# 数动物

<a href="https://inkwengame.com/zh/games/count-the-animals" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/count-the-animals/cover.jpg)

在这个游戏中，你需要数出图片中的动物。点击图片中显示的动物，并尝试找出同一物种的所有动物。如果有时有些动物遗漏了，你可以点击帮助按钮。请注意，你只能点击五次帮助按钮。开始游戏并享受乐趣。在玩乐中学习动物知识。
