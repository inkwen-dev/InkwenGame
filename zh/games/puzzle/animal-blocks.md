# 动物积木

<a href="https://inkwengame.com/zh/games/animal-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-blocks/cover.jpg)

《动物方块》巧妙融合了方块益智玩法和可爱的动物主题画面，是一款轻松愉快的游戏。游戏旨在提供休闲娱乐体验，色彩缤纷，轻松惬意，非常适合快速游戏或放松身心。

## 怎么玩

- 匹配三个或更多动物即可得分，连续匹配可获得倍数倍增得分。

- 动物主题：方块采用可爱的动物造型，为经典的方块益智游戏增添了视觉吸引力。

- 得分与难度：匹配三个或更多方块即可得分，得分越高，游戏难度越大。
