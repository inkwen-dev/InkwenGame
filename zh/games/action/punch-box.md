# 拳击箱

![cover](https://img.inkwengame.com/games/punch-box/cover.jpg)

你是一名拳击手，但钱很少，无法负担健身房的训练费用，因此你只能通过击打箱子来训练！你需要点击屏幕的两侧进行出拳，摧毁箱子。请注意避开一些箱子上的尖锐木片，否则你会被击倒！另外，请记住游戏有时间限制，你需要击打箱子来获得额外时间。所以尽可能快速地出拳，争取更高的分数！
