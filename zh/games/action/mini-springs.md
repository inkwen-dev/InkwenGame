# 迷你弹簧

<a href="https://inkwengame.com/zh/games/mini-springs" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-springs/cover.jpg)

迷你弹簧是一款复古风格的平台游戏，您将操控一个无法跳跃的小圆球角色；利用关卡中遍布的弹簧来躲避障碍物和敌人，抵达终点并完成所有关卡！

## 怎么玩

移动端 - 触摸右侧以向右移动 - 触摸左侧以向左移动 桌面端 - 使用 A/D 或方向键移动
