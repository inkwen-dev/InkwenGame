# 奔跑的圣诞老人

<a href="https://inkwengame.com/zh/games/running-santa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/running-santa/cover.jpg)

圣诞老人需要在这个游戏中通过所有关卡，并为全世界的孩子收集礼物。你的任务是帮助圣诞老人完成所有任务，并安全抵达终点。跳过障碍物，避开岩石和其他可能伤害圣诞老人的物体。跳上弹簧床以实现更长的跳跃。穿过平台，收集所有礼物。通过所有关卡，尽情享受乐趣。
