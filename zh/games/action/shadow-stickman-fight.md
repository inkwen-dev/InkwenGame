# 影子火柴人战斗

<a href="https://inkwengame.com/zh/games/shadow-stickman-fight" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shadow-stickman-fight/cover.jpg)

影子火柴人战斗是一款精彩刺激的2D忍者生存街机游戏。你需要用火柴人忍者抵御无穷无尽的敌人进攻。每次通过一个关卡测试，你就会获得考官的帽子和武器。你可以使用灵魂来交易物品或获取礼物。你需要跟随白色圆点并击中敌人。必须在敌人处于你的攻击距离时准确把握攻击时机。你还可以进入军械库，选择不同的装备，比如头盔和武器。

## 怎么玩

在PC上 A键向左移动 D键向右移动 在手机上 滑动或点击
