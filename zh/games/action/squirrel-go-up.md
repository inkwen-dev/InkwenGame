# 松鼠往上走

<a href="https://inkwengame.com/zh/games/squirrel-go-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squirrel-go-up/cover.jpg)

使用鼠标或按回车键开始游戏。使用键盘控制可爱的松鼠向上移动，避开障碍物并在平台上跳跃。不要让石头碰到你，一边向上前进一边收集榛子以获得更高分数。在这个简单易学、令人上瘾的游戏中尽情享受乐趣吧！

## 怎么玩

PC 上使用 W A S D 或方向键移动，按回车键开始游戏；手机上使用触摸操作
