# 木棍人对僵尸我的世界

<a href="https://inkwengame.com/zh/games/stickman-vs-zombies-minecraft" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickman-vs-zombies-minecraft/cover.jpg)

木棍人对僵尸我的世界是一款动作冒险平台游戏，你可以扮演勇敢的木棍忍者。当你扮演木棍英雄时，消灭所有狡猾的僵尸，并在每个被消灭的僵尸身上收集硬币，以解锁新皮肤。在地图上移动并寻找所有僵尸，以免它们发现你并追捕你或向你的位置射击。不要让任何一个僵尸存活，不要停止移动，否则所有僵尸都会试图抓住你。

## 怎么玩

操作说明 在每一关中搜索并消灭所有狡猾的僵尸，以确保自己存活并进入下一关。WASD键用于移动和跳跃，空格键和鼠标点击用于攻击，盾牌。触摸设备请使用游戏按钮
