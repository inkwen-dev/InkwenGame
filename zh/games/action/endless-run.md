# 无尽奔跑

<a href="https://inkwengame.com/zh/games/endless-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/endless-run/cover.jpg)

享受这款令人上瘾的无尽奔跑游戏中充满数字丛林和障碍物的乐趣。收集尽可能多的硬币。留意跑步途中出现的酷炫磁铁和惊喜。在一款高度刺激且不可预测的物理游戏中，速度越快，乐趣越多。高跳或滑下，避开或驶向，随心所欲，但务必远离障碍物。

## 怎么玩

向左或向右滑动屏幕以左右移动，向上滑动以跳跃。也可使用方向键左右移动，按空格键跳跃
