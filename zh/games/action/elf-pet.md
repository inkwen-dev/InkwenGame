# 精灵宠物

<a href="https://inkwengame.com/zh/games/elf-pet" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/elf-pet/cover.jpg)

这是一款以精灵战斗为主题的休闲对战游戏。玩家可以自由选择自己喜爱的精灵参与战斗。丰富的福利系统可通过每日签到获取大量资源，用于提升自己的精灵。累计签到还有VIP礼包赠送。丰富多样的玩法模式可供全面体验，收集不同的仙子，完成全图鉴成就。

## 怎么玩

键盘控制方向，W键前进，S键后退，A键左移，D键右移
