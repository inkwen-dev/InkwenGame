# 垂直重力

<a href="https://inkwengame.com/zh/games/vertical-gravity" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/vertical-gravity/cover.jpg)

垂直重力是一款平台游戏，你通过改变重力来跳跃过缝隙。当你走在平台上时，需要移动到对面的平台，你会使用方向键完成这一操作，因此必须跟随平台移动并小心谨慎。

## 怎么玩

上箭头 上升重力 下箭头 降低重力
