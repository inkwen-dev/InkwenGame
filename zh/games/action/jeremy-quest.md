# 杰里米冒险

<a href="https://inkwengame.com/zh/games/jeremy-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jeremy-quest/cover.jpg)

杰里米冒险是一款2D平台游戏，你需要收集所有的红宝石，同时避开怪物、火焰和尖刺，抵达绿色旗帜以进入下一关。游戏中共有8个关卡，随着进度推进难度会逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行双跳
