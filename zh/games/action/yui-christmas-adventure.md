# Yui 圣诞冒险

<a href="https://inkwengame.com/zh/games/yui-christmas-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/yui-christmas-adventure/cover.jpg)

Yui 圣诞冒险是一款2D圣诞主题的平台游戏，你将扮演一位名叫Yui的动漫女孩，需要收集所有糖果，同时避开雪怪、地面锯子、尖刺，并抵达蓝色旗帜以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
