# 角斗士之战

<a href="https://inkwengame.com/zh/games/gladiator-kampf" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gladiator-kampf/cover.jpg)

欢迎来到竞技场！在这个3D模拟游戏中参与古老的角斗士战斗。拿起你的武器和盔甲，像真正的战士一样昂首步入竞技场。愿诸神庇佑于你！• 2张奇幻的竞技场地图 • 真实的角斗士模拟器 • 提供5种武器，包括一面盾牌

## 怎么玩

使用WASD移动 鼠标左键进行攻击 使用左键点击进行重击 左键点击切换为奔跑 攻击时使用重击 C键蹲下 Q键跳跃 空格键进行冲刺
