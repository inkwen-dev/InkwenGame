## 怎么玩

收集脑腐 → 制作 → 建立帝国！

你的主要目标是寻找最稀有的脑腐。找到它们，制作它们，并用它们来发展你的基地！

💻 电脑：

• WASD — 移动

• E — 与物体互动

• G — 退出脑腐游戏

• F — 启用/禁用光标

移动设备：

• 使用界面上的屏幕按钮。

## 介绍

🚨警告：海啸来袭！🚨

在《海啸逃生：脑腐逃生》中体验速度与激情！这里没有时间思考。

你的任务很简单：

- 逃离巨浪。

- 沿途搜刮酷炫的脑腐物品。

- 建立你的幸存者帝国。

你背包里的脑腐物品越多，你的逃生之路就越平坦。你能成功逃脱，成为传奇吗？点击“立即开始游戏”！🌊🏃‍♂️💨
