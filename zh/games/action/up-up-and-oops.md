# 向上，向上，哎呀！

在这款快节奏的3D街机动作游戏中，攀爬漂浮的路径。阅读路径，选择正确的方向，并在方块崩塌前移动。在经典模式中挑战难度不断提升的关卡，在无尽模式中冲击最高分，或在在线竞速模式中与最多六名玩家一较高下。赢取星星，解锁新角色、方块和称号，并在历史排行榜上与其他玩家一较高下。

## 怎么玩

沿着浮空路径攀爬，选择下一个方块对应的正确操作。如果路径笔直向前，则向前跳跃。如果路径转弯，则按下路径转弯方向的按钮。在能量槽耗尽前做出选择。

在经典模式中，清除所有台阶即可解锁下一关。每个关卡都会变得更长、更难，你的下一轮挑战将从你上次通关的关卡之后开始。即使失败，到达新的台阶也能获得奖励，观看广告还能使本次挑战获得的奖励翻倍。

在无尽模式中，尽可能攀爬到更高处，冲击新的最高分。经典模式和无尽模式都提供三条命。三条命用完后，你可以使用一次复活机会。

在在线竞速模式中，与 2-6 名玩家进行两分钟的比赛。到达比其他玩家更高的台阶即可领先他们到达终点。坠落会将你送回最近的检查点，检查点每 20 步设置一个。

桌面控制：

W 或 ↑：向上移动。

S 或 ↓：向下移动。

A 或 ←：向左移动。

D 或 →：向右移动。

空格键：向前跳跃。

移动端操作：

上、下、左、右方向键：朝所选屏幕方向移动。

跳跃键：朝角色面向的方向向前跳跃。
