# Touba 2

<a href="https://inkwengame.com/zh/games/touba-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/touba-2/cover.jpg)

Touba 2 是一款 2D 平台游戏，你需要收集谷物碗，同时避开敌对的鸟类、尖刺，并抵达鸟巢以进入下一关。共有 8 个关卡可供挑战，难度会随着关卡推进逐渐增加。这是原版《Touba》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
