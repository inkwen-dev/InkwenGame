# 摆锤

<a href="https://inkwengame.com/zh/games/pendula" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pendula/cover.jpg)

摆锤是一款冒险游戏，玩家需要通过摆动环境来完成关卡，同时避开敌人和陷阱，包括刀刃、食人鱼和水。但你只能抓住金属物体。游戏中还有一些有趣的内容，比如跳跃垫和大炮，可以帮助你完成关卡。

## 怎么玩

鼠标左键点击或触摸并按住以朝指定方向延伸并抓住金属杆；想要松开时释放点击。当你在大炮内部时，点击并拖动以调整大炮的角度和威力
