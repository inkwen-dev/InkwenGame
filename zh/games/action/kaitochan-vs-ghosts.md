# Kaitochan 对战幽灵

<a href="https://inkwengame.com/zh/games/kaitochan-vs-ghosts" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kaitochan-vs-ghosts/cover.jpg)

《Kaitochan 对战幽灵》是一款2D万圣节主题的平台游戏，你需要收集黄色球体，同时避开南瓜敌人、火焰、尖刺和飞行的幽灵，抵达出口门以进入下一关。只有在每一关中收集完所有黄色球体后，出口门才会解锁。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
