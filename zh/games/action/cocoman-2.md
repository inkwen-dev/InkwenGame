# Cocoman 2

<a href="https://inkwengame.com/zh/games/cocoman-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cocoman-2/cover.jpg)

Cocoman 2 是一款 2D 可爱的小型平台游戏，你需要收集椰奶瓶作为能量来源，同时避开敌人、飞行怪物及其子弹、旋转刀片、巨型刀片和尖刺，抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。这是原版《Cocoman》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
