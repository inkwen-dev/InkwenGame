# 土豆

<a href="https://inkwengame.com/zh/games/aloo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/aloo/cover.jpg)

土豆是一款2D平台游戏，你将扮演主角土豆人阿鲁，任务是收集能量饮料瓶，同时避开锯子、巨型刀片、尖刺和球形怪物。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
