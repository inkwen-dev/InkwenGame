# Haruz

<a href="https://inkwengame.com/zh/games/haruz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/haruz/cover.jpg)

Haruz 是一款 2D 简单平台游戏，你需要收集银币，同时避开各种飞行机器人、尖刺，并进入魔法洞穴以进入下一关。游戏中共有 8 个关卡，难度随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
