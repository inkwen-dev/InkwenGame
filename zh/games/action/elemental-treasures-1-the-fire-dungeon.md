# 元素宝藏1：火焰地牢

<a href="https://inkwengame.com/zh/games/elemental-treasures-1-the-fire-dungeon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/elemental-treasures-1-the-fire-dungeon/cover.jpg)

元素宝藏系列游戏将带你探索地牢。《元素宝藏1：火焰地牢》是该系列的第一部作品，你将在其中探索一个火焰地牢（真的吗？）。本游戏的目标是找到钥匙打开大门。每一关都有不同的挑战。你还可以收集一些金币和水晶。选择你的冒险者，让我们开始探索吧！

## 怎么玩

键盘方向键控制角色移动，上箭头让角色跳跃，空格键使用特殊能力（当你获得护身符时可用）
