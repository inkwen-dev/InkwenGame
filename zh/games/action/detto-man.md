# 迪托曼

<a href="https://inkwengame.com/zh/games/detto-man" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/detto-man/cover.jpg)

迪托曼是一款2D可爱的小型平台游戏，你需要收集橙子（水果），同时避开敌人、飞行生物、尖刺和巨型刀刃，抵达出口门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上方向键可进行二段跳
