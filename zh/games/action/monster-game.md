# 怪物游戏

<a href="https://inkwengame.com/zh/games/monster-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-game/cover.jpg)

怪物游戏是一款令人兴奋的动作游戏，玩家将在动态地图中奔跑，收集独特的零件来打造自己的终极怪物。当你的怪物完成之后，带它进入战场，与其他怪物展开史诗般的对决，证明谁才是最强王者！

## 怎么玩

鼠标点击或轻触开始游戏
