# Mashup Hero

<a href="https://inkwengame.com/zh/games/mashup-hero" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mashup-hero/cover.jpg)

Mashup Hero 是一款快节奏的机甲跑酷游戏，你将在冲刺至终点线的过程中组装机器人。滑动以避开陷阱，然后释放强大的冲击波，在最终竞技场中碾压对手。通过获得核心来升级速度、护甲和力量，解锁新皮肤，并完成越来越复杂的关卡。简单的一指操作，短小精悍的关卡，震撼的打击感。

## 怎么玩
