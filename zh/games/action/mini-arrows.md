# 迷你箭头

<a href="https://inkwengame.com/zh/games/mini-arrows" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-arrows/cover.jpg)

迷你箭头是一款复古风格的平台游戏，您将引导一个 blob 角色到达终点；通过开启或关闭关卡中的箭头方块来改变角色的方向和动作，巧妙地使用箭头移动角色。游戏包含 27 个关卡、速通模式、复古风格图形以及令人上瘾的音乐。

## 怎么玩

桌面端 - X 键或左键点击以切换箭头状态 移动端 - 触摸以切换箭头状态
