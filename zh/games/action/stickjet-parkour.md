# StickJet 拓荒

<a href="https://inkwengame.com/zh/games/stickjet-parkour" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickjet-parkour/cover.jpg)

你和你的朋友必须首先在棍子人世界中生存下来，而且必须非常小心。使用背后的喷气背包飞得更高并生存下去。注意障碍物，它们可能会杀死你。旋转的轮子，你不应该离开关卡范围，任何地方都可能致死。收集金币，否则你将无法完成关卡。

## 怎么玩

按下任意键或触摸屏幕开始游戏；在移动设备上使用移动控制飞行，按住不放；在PC上按住W键或上箭头键飞行；收集3枚金币以到达旗帜
