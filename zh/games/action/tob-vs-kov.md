# Tob vs Kov

![cover](https://img.inkwengame.com/games/tob-vs-kov/cover.jpg)

Tob vs Kov 是一款 2D 科幻主题的平台游戏，玩家扮演机器人 Tob，需要在避开敌方机器人、锯子的同时收集红色球体，并抵达出口门。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
