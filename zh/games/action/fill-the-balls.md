# 填满小球

<a href="https://inkwengame.com/zh/games/fill-the-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fill-the-balls/cover.jpg)

在《填满小球》中，你需要帮助炸毁了炸弹的圣诞老人将小球填入碗中。你可以通过点击或轻触屏幕任意位置来调整把手，从而将小球放入碗中。调整好手臂后，按下“准备”按钮，将小球送入碗中。尝试用100多个关卡解决整个谜题。

## 怎么玩
