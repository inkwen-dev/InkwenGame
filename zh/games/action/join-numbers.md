# 合并数字

<a href="https://inkwengame.com/zh/games/join-numbers" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/join-numbers/cover.jpg)

合并数字是一款受欢迎的益智游戏。你的数学能力如何？这款游戏需要你通过不同数字的门。你将从一个数字开始，移动这个数字，控制它穿过前方道路上的数字门，你所控制的数字必须大于数字门的数值，才能成功到达终点。现在尽你所能解锁更多关卡吧！

## 怎么玩
