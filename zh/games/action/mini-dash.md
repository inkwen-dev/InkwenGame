# 迷你冲刺

<a href="https://inkwengame.com/zh/games/mini-dash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-dash/cover.jpg)

迷你冲刺是一款复古风格的平台游戏，你将操控一个小小的Blob角色；利用他的空中冲刺技能躲避障碍物并收集关卡中的硬币！此外，你还可挑战速度通关模式来检验自己的技巧。

## 怎么玩

桌面端 -X 左键 或 右键 跳跃 -X 或 左键 在空中冲刺向左 -C 或 右键 在空中冲刺向右 移动端 -触摸左侧或右侧跳跃 -在空中触摸左侧冲刺向左 -在空中触摸右侧冲刺向右
