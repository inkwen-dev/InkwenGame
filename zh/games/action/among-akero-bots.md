# 在阿克罗机器人之间

<a href="https://inkwengame.com/zh/games/among-akero-bots" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/among-akero-bots/cover.jpg)

《在阿克罗机器人之间》是一款2D科幻主题的平台游戏，你将扮演阿克罗机器人，需要收集红色魔法宝石，同时避开敌方机器人、飞行机器人及其子弹、旋转激光、尖刺，并抵达出口门以进入下一关。游戏中共有8个关卡，随着进程难度逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W键或上箭头键可进行二段跳
