# 冬日之战

<a href="https://inkwengame.com/zh/games/winter-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/winter-battle/cover.jpg)

完美的冬季来临了！加入圣诞老人和格林奇在雪下的战斗吧！收集所有从天而降的礼物盒，但要记住，有些礼物盒非常危险。收集礼物盒会让你变大；当然，如果你收集错了礼物盒，你的体型就会缩小。在时间耗尽之前获得最高分，即可赢得游戏。

## 怎么玩

*您可以使用 WASD 和方向键移动。

*玩家可以使用向下方向键或 S 键互相推搡。

*游戏结束时得分最高的玩家获胜。
