# 波波歌手

<a href="https://inkwengame.com/zh/games/popo-singer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/popo-singer/cover.jpg)

波波歌手是一款2D平台游戏，你将扮演一位热爱音乐的波波。你的任务是收集吉他，同时避开敌人、尖刺和飞行怪物，抵达魔法洞穴。游戏中共有8个关卡，随着进度推进难度逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上方向键可进行二段跳
