# 杰卡冲刺2

<a href="https://inkwengame.com/zh/games/jeka-dash-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jeka-dash-2/cover.jpg)

在这个动态游戏中，你需要躲避各种障碍物并到达终点线。主角始终向前移动，拥有不同形状和不同特性的角色——一个人、一架飞机、一个圆盘、一个球。游戏具有出色的图形、音乐和不同的场景。随着关卡的推进，难度逐渐增加，需要良好的反应力、记忆力和耐心才能通过，如果无法通过所有关卡，请不要灰心。

## 怎么玩

左键、W键或上方向键，或在手机上按住屏幕顶部；右键、S键或下方向键，或在手机上按住屏幕底部
