# 字母跑酷

<a href="https://inkwengame.com/zh/games/alphabet-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/alphabet-run/cover.jpg)

欢迎来到《字母跑酷3D》，这是一款精彩绝伦的游戏！你扮演字母A，任务是收集尽可能多的字母以击败蓝色怪物。选择与你的角色相同颜色的字母，可以让你的字母数量翻倍。尽情享受吧！

## 怎么玩

点击或鼠标点击开始游戏
