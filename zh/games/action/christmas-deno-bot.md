# 圣诞 Deno 机器人

<a href="https://inkwengame.com/zh/games/christmas-deno-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-deno-bot/cover.jpg)

圣诞 Deno 机器人是一款以圣诞节为背景的2D科幻主题平台游戏，玩家扮演名为 Deno 的机器人，需要收集燃料容器，同时避开敌对机器人、飞行机器人、巨大刀片、锯子，并抵达出口门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
