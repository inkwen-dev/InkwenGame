# 迷你方块决斗

<a href="https://inkwengame.com/zh/games/minicraft-duello" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minicraft-duello/cover.jpg)

迷你方块决斗是一款双人TNT游戏，你的任务是引爆你的朋友并成为唯一的幸存者。在两张不同的地图中与朋友对战，制定策略并引爆你的TNT。

## 怎么玩

支持移动设备操作。玩家1：WASD - 移动，R - 投掷TNT。玩家2：方向键 - 移动，P - 投掷TNT
