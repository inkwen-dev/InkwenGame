# Labubu 和朋友们 2人游戏

<a href="https://inkwengame.com/zh/games/labubu-and-friends-2player" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/labubu-and-friends-2player/cover.jpg)

Labubu 和他的朋友需要在夏天逃离这座岛屿！你们在冒险时要非常小心，沿途收集所有的金色蛤蜊。当然，先收集那些金色蛤蜊——然后到达巨大的礼物盒！两个可爱的 Labubu 朋友都必须抵达礼物盒，因为里面藏着他们最喜欢的东西。但要当心——路上充满了危险和障碍！

## 怎么玩

使用 WASD 和方向键移动，收集所有金色蛤蜊并抵达礼物盒。支持移动设备和 PC 游玩
