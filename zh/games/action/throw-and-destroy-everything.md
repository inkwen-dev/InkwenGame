# 投掷并摧毁一切

<a href="https://inkwengame.com/zh/games/throw-and-destroy-everything" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/throw-and-destroy-everything/cover.jpg)

将一波波的机器人分解成零件，这些机器人会扔出所有能抓到的东西，绝不让敌人逃脱。你可以投掷被摧毁的机器人的任何零件。

## 怎么玩

WASD - 移动 用鼠标拾起并投掷破损机器人的零件，此操作在启动慢动作时同样有效
