# Locoman 2

<a href="https://inkwengame.com/zh/games/locoman-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/locoman-2/cover.jpg)

Locoman 2 是一款简单的 2D 平台游戏，你需要收集银色钥匙，同时避开敌人、飞行生物、尖刺，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进度逐渐增加。这是原始 Locoman 系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
