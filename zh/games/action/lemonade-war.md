# 柠檬大战

<a href="https://inkwengame.com/zh/games/lemonade-war" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lemonade-war/cover.jpg)

你想采摘柠檬并赢得比赛吗？收集柠檬来击败你的朋友。你必须帮助蓝色和红色玩家赢得柠檬赛跑。从地图中央的树上摘取柠檬，并将它们带到柠檬摊。收集最多柠檬的人将赢得比赛。快速收集柠檬并赢得游戏。水位正在缓慢上升，你唯一的希望就是尽可能快地收集柠檬。

## 怎么玩

按WASD键移动红色玩家 按方向键移动蓝色玩家 从树上收集柠檬并带到柠檬摊以获得分数
