# 救援逃脱

<a href="https://inkwengame.com/zh/games/resuce-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/resuce-escape/cover.jpg)

救援逃脱是一款动作解谜游戏，你将操控小人角色，从布满陷阱的监狱中逃脱。你的任务是引导所有角色避开危险障碍，并安全地聚集在逃生点，打开出路。每一关都带来新的挑战——尖刺陷阱、移动障碍、狭窄路径以及无数其他危险，要求你灵活操作并精确计算每一步。只要有一个小人被困，整个团队就无法逃脱！
