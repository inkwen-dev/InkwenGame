# Leafino

<a href="https://inkwengame.com/zh/games/leafino" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/leafino/cover.jpg)

Leafino 是一款 2D 平台游戏，你将扮演一片叶子，需要在不惜一切代价避开火焰球敌人的情况下收集光球。共有 8 个关卡可供挑战，随着关卡推进难度逐渐增加。

## 怎么玩

使用 WASD 或方向键进行移动，连续按两次 W 键或上箭头键可进行二段跳
