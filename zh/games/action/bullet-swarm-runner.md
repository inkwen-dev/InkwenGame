# 子弹风暴跑者

<a href="https://inkwengame.com/zh/games/bullet-swarm-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bullet-swarm-runner/cover.jpg)

子弹风暴跑者是一款快节奏的3D无尽跑酷游戏，你需要躲避致命障碍，并用你的子弹风暴击败巨大的Boss。左右转向以避开旋转的剑、挥动的锤子、扫过的激光和旋转的尖刺柱。使用你的金币升级起始子弹数量和收益倍数，然后在商店中解锁新的子弹皮肤。坚持到底，抵达Boss处，将所有子弹倾泻而出以取得胜利。

## 怎么玩

PC 方向左键 方向右键 以操控 移动端 左右滑动以操控
