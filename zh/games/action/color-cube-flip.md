# 颜色方块翻转

<a href="https://inkwengame.com/zh/games/color-cube-flip" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-cube-flip/cover.jpg)

这是一款带有方块的平台游戏。你需要在平台上移动方块。方块的每一面都涂有不同的颜色，而平台的颜色也与方块上的颜色相对应。游戏的目标是通过平台移动方块，同时使方块的颜色与平台的颜色匹配。因此，在跳跃到平台上时，你必须旋转方块。

## 怎么玩

点击屏幕上显示的颜色来玩这个游戏
