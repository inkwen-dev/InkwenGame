# 迷你方块

<a href="https://inkwengame.com/zh/games/mini-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-blocks/cover.jpg)

您控制一个小型的 blob 角色，拥有开启或关闭关卡中元素的能力。明智地使用这种能力，以到达下一阶段的目标！您还可以在速通模式中测试自己的技能。《迷你方块》采用复古风格制作，灵感源自8位时代的经典游戏。

## 怎么玩

桌面端 - 上箭头或左键点击以跳跃 - 空格键或右键点击以开启/关闭元素 移动端 - 触摸右侧以跳跃 - 触摸左侧以开启/关闭元素
