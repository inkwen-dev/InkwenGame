# Voltier

<a href="https://inkwengame.com/zh/games/voltier" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/voltier/cover.jpg)

Voltier 是一款 2D 平台游戏，你需要收集被偷走的电力箱，同时避开敌人、尖刺、水体、旋转刀片，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上方向键可进行二段跳
