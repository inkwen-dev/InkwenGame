# 星际小鸡

<a href="https://inkwengame.com/zh/games/astro-chickens" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/astro-chickens/cover.jpg)

驾驶飞船穿越10个独特的环境，击退无尽波次的外星小鸡，防止它们接近你。摧毁敌人以获得金币，在波次中收集强化道具，并释放飞船的特殊技能以求生存。每第五波都会迎来一场Boss战斗。没有终点线——只有更高的分数。飞船技能 每艘飞船都拥有独特的特殊能力，通过按空格键（桌面端）或右键触发。技能具有冷却时间，会随时间自动充能。

## 怎么玩

如何游玩 打开大厅 从各自的网格中选择一个环境和一艘飞船 在设置中选择难度等级 正常 困难 或 绝望 按下开始任务 在准备画面中按空格键或点击画布以开始 移动飞船
