# 彩色砖块大战

<a href="https://inkwengame.com/zh/games/color-brick-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-brick-battle/cover.jpg)

彩色砖块大战是一款快速且令人上瘾的砖块消除游戏，颜色是取得胜利的关键。控制球拍，反弹小球，并通过匹配颜色来摧毁砖块。小球初始为白色，但当它触碰到球拍的彩色一侧时，会改变颜色。只有相同颜色的砖块才能被摧毁，因此精准和位置至关重要。在经典街机体验中加入缤纷色彩，测试你的反应速度与策略。

## 怎么玩

触摸屏或使用 A D 键移动球拍
