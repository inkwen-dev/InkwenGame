# 飞行橙子

<a href="https://inkwengame.com/zh/games/flying-orange" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flying-orange/cover.jpg)

飞行橙子是一款平台游戏，你将控制一个小橙子，借助喷气背包逃离太空的危险。收集燃料，避开沿途的陷阱和敌人。

## 怎么玩

左箭头键向左移动 右箭头键 - 向右移动 Z键 跳跃 X键 使用喷气背包 你可以在游戏菜单中修改控制设置
