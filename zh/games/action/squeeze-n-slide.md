# 挤压滑行

<a href="https://inkwengame.com/zh/games/squeeze-n-slide" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squeeze-n-slide/cover.jpg)

控制一颗果冻滑过色彩缤纷的障碍赛道。改变果冻的形状以穿过障碍门，收集水晶和水果，解锁新的皮肤，获得更多乐趣。

## 怎么玩

用手指或鼠标上下拖动来改变果冻的形状，使其能够通过每个关卡。随着速度加快，反应要快，并沿途捕捉水果。
