# 数学之门

<a href="https://inkwengame.com/zh/games/math-gates" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-gates/cover.jpg)

在这款游戏中，你的任务是在短时间内找出被告诉的数学问题的答案，并将正确的答案通过你前进时出现在面前的门。你将在屏幕底部看到数学运算。要通过面前的门，你必须穿过带有正确答案的门。如果你穿过错误答案的门，游戏将以某种方式结束。当你成功穿过带有正确答案的门时，你就获胜了。

## 怎么玩

左右移动 - 滑动鼠标
