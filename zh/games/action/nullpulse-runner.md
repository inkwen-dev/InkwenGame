# Nullpulse Runner

<a href="https://inkwengame.com/zh/games/nullpulse-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nullpulse-runner/cover.jpg)

NullPulse Runner 是一款快节奏的休闲街机游戏，你将控制一个发光的能量球，在未来感十足的霓虹世界中穿梭。以完美的时机跳跃，躲避危险障碍，尽可能长时间生存，打破自己的最高分纪录。凭借简单的单指操作、无尽玩法、流畅动画、移动端支持以及令人上瘾的反应式挑战，每一次奔跑都是对技巧的新考验。

## 怎么玩

桌面端：空格键 - 跳跃；开始/重新开始；左键鼠标 - 跳跃；Esc 键 - 暂停/继续；M 键 - 静音/取消静音；移动端：轻触屏幕 - 跳跃
