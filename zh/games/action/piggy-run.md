# 小猪跑

<a href="https://inkwengame.com/zh/games/piggy-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/piggy-run/cover.jpg)

这款名为小猪跑的游戏中，有一个可爱的猪宝宝。游戏的任务是让这只小猪尽可能地跑得更远。目标是收集钻石，用来击落阻碍游戏进程的有毒蘑菇。一段时间后，小猪会获得翅膀，可以飞翔。当你在空中时，按X键可以使用降落伞。按Z键进行射击。祝你玩得愉快！
