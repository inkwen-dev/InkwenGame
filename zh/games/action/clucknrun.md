# CluckNRun

<a href="https://inkwengame.com/zh/games/clucknrun" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/clucknrun/cover.jpg)

在《CluckNRun》中，踏上一段激动人心的乡村之旅，你的任务是将走失的鸡群送回农场家园！穿越充满活力的农田景观，沿途收集丰富的鸡群和必需的汽油。但要小心——路途中散落着桶，随时可能让你的旅程中断！

## 怎么玩

使用 A 和 D 键进行流畅的左右移动，或直接用鼠标控制方向，轻松享受游戏体验
