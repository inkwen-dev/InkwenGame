# Brikzo

<a href="https://inkwengame.com/zh/games/brikzo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/brikzo/cover.jpg)

Brikzo 是一款游戏中，沙块会不断出现，摔跤手用他的手臂或腿击打并打破这些沙块。你只有有限的机会错过沙块，一旦错过，游戏就结束。得分高一点 :)

## 怎么玩

点击沙块的一侧来击打它们
