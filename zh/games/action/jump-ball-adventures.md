# 跳球冒险

<a href="https://inkwengame.com/zh/games/jump-ball-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jump-ball-adventures/cover.jpg)

在这个游戏中，你的任务是控制小球通过不同的平台。跳上去并收集星星。避开尖刺，否则你将不得不重新开始这一关。这款游戏共有40个关卡，每一关都是一次新的冒险。通过所有关卡，享受游戏的乐趣。你可以更换小球的不同造型。选择你最喜欢的小球，开始游戏。
