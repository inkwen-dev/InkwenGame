# 像素工艺动物学校

<a href="https://inkwengame.com/zh/games/pixelcraft-animal-school" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixelcraft-animal-school/cover.jpg)

为了在这个世界生存，你必须避开危险的动物。在一个寒冷的冬日，你需要到达传送门。你可以独自一人或与朋友一起，在雪覆盖的森林中收集黄金。收集所有黄金，并在不死亡的情况下抵达关卡终点的传送门。收集黄金后可以购买不同的服装。熊、狼、野猪和其他可怕的动物会追捕你，所以不要停下——不要回头地奔跑。

## 怎么玩

亚历克斯 按WASD键移动和跳跃 斯蒂夫 按方向键移动和跳跃 移动设备控制可用 收集黄金并安全到达传送门
