# 小小探险家

<a href="https://inkwengame.com/zh/games/tiny-explorer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tiny-explorer/cover.jpg)

小小探险家是一款复古街机平台游戏，你需要帮助一位小探险家在古老神庙中寻找史诗级宝藏的旅程！探索全部27个关卡，并在速通模式中测试你的技巧！

## 怎么玩

桌面端 - A D 或 左右箭头键 移动 - W I 或 上箭头键 跳跃 - 空格键 U C 或 O 使用鞭子 - 游戏内控制
