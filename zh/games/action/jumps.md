# 跳跃

<a href="https://inkwengame.com/zh/games/jumps" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jumps/cover.jpg)

跳跃是一款带有跳跃元素的儿童平台游戏。在这款游戏中，你需要控制一个跳跃方块。跳过小型障碍墙并旋转星星。跳过尖刺，并在墙壁出现前及时跳跃。一些星星会上下移动，你需要判断何时可以跳过它们，何时可以从它们下方通过。如果墙壁较高，你可以进行双跳。当面前有更大的障碍物时，请每次都进行双跳。

## 怎么玩

点击屏幕以开始游戏
