# 陈氏机器人之间

<a href="https://inkwengame.com/zh/games/among-chen-bots" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/among-chen-bots/cover.jpg)

《陈氏机器人之间》是一款2D科幻主题的平台游戏，你需要收集蓝色能量箱，同时避开敌方机器人、尖刺、巨型刀刃和飞行机器人，抵达出口门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上箭头键可进行二段跳
