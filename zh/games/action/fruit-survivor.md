# 水果幸存者

<a href="https://inkwengame.com/zh/games/fruit-survivor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-survivor/cover.jpg)

水果幸存者是一款酷炫且令人兴奋的3D卡通生存街机游戏。你扮演一名园丁，遭到水果怪物的攻击。你需要奋力突围，并使用不同的武器摧毁它们。我建议先选择搅拌机并将其升级到最高级别。它能有效应对许多强大的敌人。你也可以尝试不同的武器组合，挑战更难的关卡。尽情狩猎水果怪物吧！

## 怎么玩

在电脑和移动设备上，按住并拖动移动，点击按钮选择，升级武器
