# 绅士的 quest

<a href="https://inkwengame.com/zh/games/gentlemans-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gentlemans-quest/cover.jpg)

《绅士的 quest》是一款2D平台游戏，你需要在收集能量饮料的同时抵达你的办公室。务必避开锯子和劫匪。游戏中共有8个关卡，随着任务推进，难度会逐渐增加。

## 怎么玩

使用WASD或方向键进行移动；连续按两次W或上方向键可进行二段跳
