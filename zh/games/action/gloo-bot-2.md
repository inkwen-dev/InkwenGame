# Gloo Bot 2

<a href="https://inkwengame.com/zh/games/gloo-bot-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gloo-bot-2/cover.jpg)

Gloo Bot 2 是一款 2D 科幻主题的平台游戏，你将扮演一名机器人，需要收集所有电池单元，同时避开敌对机器人、飞行机器人、子弹、尖刺，并抵达你的机器人房屋以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐提升。这是原版《Gloo Bot》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
