# Rinos Quest

<a href="https://inkwengame.com/zh/games/rinos-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rinos-quest/cover.jpg)

Rinos Quest 是一款 2D 平台游戏，你需要收集银色钥匙，同时避开尖刺、锯子和尖刺怪物敌人，并打开出口门。游戏中共有 8 个关卡，随着你不断推进，难度会逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上方向键可进行二段跳
