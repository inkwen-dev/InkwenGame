# 画笔冲刺

<a href="https://inkwengame.com/zh/games/draw-pen-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/draw-pen-rush/cover.jpg)

画笔冲刺是一款有趣又刺激的跑酷游戏。玩家控制一个机器人参加跑酷比赛，避开障碍物并收集各种零件来增强能力，最终变成巨大的机器人。游戏采用竖屏模式，让玩家能够更清楚地看到前方赛道，提前准备躲避陷阱。帮助机器人击败终极大脑。

## 怎么玩

向左或向右滑动以避开障碍物，并拾取零件变身成小机器人
