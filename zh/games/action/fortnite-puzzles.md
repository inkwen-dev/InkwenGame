# 堡垒之夜拼图

<a href="https://inkwengame.com/zh/games/fortnite-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fortnite-puzzles/cover.jpg)

欢迎来到名为《堡垒之夜拼图》的游戏！在这个游戏中，你有12个来自《堡垒之夜》的拼图。通过移动拼图块的位置来完成它们。拖动拼图块到另一个位置以进行更换。完成一个关卡后，进入下一个关卡。每个关卡都有时间限制，你需要在规定时间内完成。

## 怎么玩

使用鼠标或触摸屏幕
