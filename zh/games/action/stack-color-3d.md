# 堆叠颜色3D

<a href="https://inkwengame.com/zh/games/stack-color-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-color-3d/cover.jpg)

在《堆叠颜色3D》游戏中，尽可能多地运输砖块。每一关都会展示一个新的场景，有一个不同颜色的人物。注意运输相同颜色的砖块，避免不同颜色的砖块。你只需触碰砖块，它们就会自动堆叠，享受《堆叠颜色3D》的乐趣。
