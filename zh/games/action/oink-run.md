# Oink Run

<a href="https://inkwengame.com/zh/games/oink-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/oink-run/cover.jpg)

欢迎来到我们的游戏，游戏中有一位可爱的猪宝宝叫 Oink Run。在这个游戏中，任务是让这只小猪尽可能地跑得更远。你需要收集钻石来击落那些有毒的蘑菇，它们是游戏中的障碍物。一段时间后，小猪会获得翅膀，你可以飞翔。你还可以通过按下 X 键在空中使用降落伞。按 Z 键进行射击。祝你玩得愉快！

## 怎么玩

使用鼠标或空格键跳跃，Z 键射击，X 键使用降落伞
