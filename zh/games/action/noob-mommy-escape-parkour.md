# 新手妈妈逃脱跑酷

<a href="https://inkwengame.com/zh/games/noob-mommy-escape-parkour" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noob-mommy-escape-parkour/cover.jpg)

新手妈妈逃脱跑酷是一款Minecraft风格的跑酷游戏，你需要跳跃过方块，同时努力逃离妈妈和黄色宝宝。尽量不要被长腿怪物抓住，也不要掉进岩浆。尽快抵达传送门，登上排行榜顶端，证明你是新手还是高手。

## 怎么玩

- WASD或方向键移动 - 空格键跳跃 - 按C键切换摄像机模式 - 点击进行拳击
