# JoJo 跑酷

<a href="https://inkwengame.com/zh/games/jojo-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jojo-run/cover.jpg)

JoJo 跑酷是一款跑酷风格的游戏。拥有非常美丽多彩的图形，你会玩得非常开心。收集金币和钻石来获得分数并升级关卡。消灭蜗牛，打破挡在你面前的墙壁。通关所有关卡，积累最多的金币和分数。祝你好运，玩得愉快！

## 怎么玩
