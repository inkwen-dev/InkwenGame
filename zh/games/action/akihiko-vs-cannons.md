# 明彦对炮台

<a href="https://inkwengame.com/zh/games/akihiko-vs-cannons" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/akihiko-vs-cannons/cover.jpg)

明彦对炮台是一款2D平台游戏，你将扮演名叫明彦的男子，需要收集金币条，同时避开炮台机器人、子弹、尖刺、飞行炮台机器人，并抵达黄色旗帜以进入下一关。共有8个关卡可供挑战，难度会随着进程逐渐增加。游戏开始时你有6条生命。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
