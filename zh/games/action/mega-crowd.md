# 巨 crowd

<a href="https://inkwengame.com/zh/games/mega-crowd" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mega-crowd/cover.jpg)

巨 crowd 是一款快节奏的 3D 人群奔跑游戏，你将壮大你的队伍，躲避陷阱，选择最佳的数学门，向终点冲刺。扩大你的队伍，避开危险障碍，与敌对团体战斗，击败强大的首领，并在每轮结束时建造最高的真人阶梯。你的队伍越大，爬得越高，获得的金币越多。解锁新的外观皮肤，提升你的分数，掌握越来越困难的关卡，看看你的队伍能走多远！

## 怎么玩

鼠标触摸 —— 按住并左右拖动以控制人群，松开以停止转向。点击按钮使用菜单和商店
