# 怪物向上

<a href="https://inkwengame.com/zh/games/monster-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-up/cover.jpg)

怪物向上是一款点击基础游戏，玩法极具吸引力。点击以跳跃到平台，并在每个平台上保持平衡以收集星星。每收集一颗星星，就能看到新的主题、新角色和新背景。可爱的图形和精彩的游戏体验，让怪物向上既适合儿童也适合成人。
