# 僵尸基地

<a href="https://inkwengame.com/zh/games/zombie-base" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-base/cover.jpg)

僵尸基地是一款设计类游戏，包含多个关卡等待你来挑战。你需要收集金币来强化武器和弹药，以通过关卡。

## 怎么玩

通过手指鼠标控制角色进行角色设计。在射击过程中，可以持续躲避怪物的攻击，并消灭所有怪物以通过关卡
