# Blacko Ball

<a href="https://inkwengame.com/zh/games/blacko-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blacko-ball/cover.jpg)

Blacko Ball 是一款 2D 奇怪的小型平台游戏，你将扮演一个黑色球体，需要收集小红球，同时避开敌人、尖刺，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；使用 W 键或上方向键进行二段跳
