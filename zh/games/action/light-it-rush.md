# 点亮冲刺

<a href="https://inkwengame.com/zh/games/light-it-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/light-it-rush/cover.jpg)

摆动、跳跃、翻滚和滑行，让你的小人身体从一个霓虹色形状滑到另一个，让它们发光并点亮世界。对于像你这样小小的 Stickman 翻转大师来说，外面的世界一片黑暗，是时候点亮它，让色彩闪耀了。

## 怎么玩

鼠标点击或轻触开始游戏

## 介绍

摆动、跳跃、翻滚和滑行，让你的小人身体从一个霓虹色形状滑到另一个，让它们发光并点亮世界。对于像你这样小小的 Stickman 翻转大师来说，外面的世界一片黑暗，是时候点亮它，让色彩闪耀了。
