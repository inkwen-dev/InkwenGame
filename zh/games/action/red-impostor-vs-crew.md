# 红色冒名者对船员

<a href="https://inkwengame.com/zh/games/red-impostor-vs-crew" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/red-impostor-vs-crew/cover.jpg)

红色冒名者对船员是一款有趣且引人入胜的动作游戏。你的任务很简单：在宇宙飞船上消灭所有活着的船员。让无人幸存。当你在不被发现的情况下杀光所有人时，关卡即完成。小心船员们，他们可能会发现你就是冒名者

## 怎么玩

按住并拖动以在飞船中移动，击杀船员并破坏物品
