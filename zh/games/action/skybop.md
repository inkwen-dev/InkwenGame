# Skybop

<a href="https://inkwengame.com/zh/games/skybop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skybop/cover.jpg)

Skybop 是一款设定在黑洞环境中的游戏，其中物体必须保持在黑洞内部并不断往返穿梭。游戏中会提供一个挡板，用于将物体推回黑洞内，你需要小心注意物体的移动。尽情享受游戏吧 :0

## 怎么玩

随时准备好挡板以阻止玩家物体
