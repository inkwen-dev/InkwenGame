# 斧头城堡

<a href="https://inkwengame.com/zh/games/axe-castle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/axe-castle/cover.jpg)

通过在移动平台上用斧头投掷击中对手来得分，先获得5分的一方获胜

## 怎么玩

游戏包含双人模式和单人模式。在双人模式下，通过按住P2的上键和P1的W键进行射击

## 介绍
