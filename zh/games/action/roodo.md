# Roodo

<a href="https://inkwengame.com/zh/games/roodo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roodo/cover.jpg)

Roodo 是一款科幻主题的 2D 平台游戏，你需要收集钥匙，同时避开绿色的敌方机器人、尖刺和地面锯子，抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行双重跳跃
