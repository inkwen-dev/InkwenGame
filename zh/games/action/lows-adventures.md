# Lows Adventures

<a href="https://inkwengame.com/zh/games/lows-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lows-adventures/cover.jpg)

这是一款包含32个关卡的平台游戏。你将在每个关卡中引导Low展开冒险，主要目标是收集三枚硬币（有些硬币可能被隐藏），以解锁奖杯并进入下一关。

## 怎么玩

键盘WASD和触摸屏
