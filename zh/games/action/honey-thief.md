# 蜂蜜窃贼

<a href="https://inkwengame.com/zh/games/honey-thief" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/honey-thief/cover.jpg)

熊想要一些蜂蜜。所以你需要投掷回旋镖击中蜜蜂并获取蜂蜜。只要你击中蜜蜂，回旋镖总会回到你手中。但如果你错过了蜜蜂，你将失去一条生命。如果你击中了鸟，游戏就会结束。
