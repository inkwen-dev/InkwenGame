# 疯狂重力 - 宇航员游戏

<a href="https://inkwengame.com/zh/games/crazy-gravity-astronaut-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-gravity-astronaut-game/cover.jpg)

《疯狂重力》是一款平台/休闲游戏，玩家需要操控宇航员在未知星球上克服各种挑战。通关所有关卡并收集所有能量物品，修复你的火箭，返回家园。在游戏中，你必须躲避电击机器和尖刺，并探索交替的重力机制来推进关卡。游戏画面色彩丰富，卡通风格，非常美观。总共包含15个关卡，随着玩家逐关推进，难度逐渐增加。

## 怎么玩

向右移动 D  向左移动 A  跳跃 W  在移动设备上使用触摸按钮
