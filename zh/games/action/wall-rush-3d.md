# 墙冲3D

<a href="https://inkwengame.com/zh/games/wall-rush-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wall-rush-3d/cover.jpg)

像风一样奔跑，与世界上最优秀的跑者一较高下。从高楼纵身跃下，翻越高墙。只有第一个获胜者才能登上胜利的巅峰。

## 怎么玩

- 左右滑动控制角色移动。

- 避开障碍物和危险的缝隙。

- 保持在赛道上。你可以跳上屋顶，沿着墙边奔跑，但不要掉下去。

- 奔跑时收集金币。

- 率先到达终点线，击败对手。
