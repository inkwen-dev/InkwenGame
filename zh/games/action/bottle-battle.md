# 瓶子大战

<a href="https://inkwengame.com/zh/games/bottle-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bottle-battle/cover.jpg)

这是一款解谜游戏，游戏提供不同容量的水壶，根据游戏关卡提示，每个水壶需要不同的量，达到提示所需的量即可通关

## 怎么玩

游戏的主要操作是点击水瓶，将水倒入另一个水瓶
