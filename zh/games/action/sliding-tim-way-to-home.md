# 滑行蒂姆：回家之路

<a href="https://inkwengame.com/zh/games/sliding-tim-way-to-home" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sliding-tim-way-to-home/cover.jpg)

一款基于完成艰难路径的冒险游戏。你扮演英雄蒂姆，他离家很远，需要帮助才能返回。但前方的道路并不容易，一路上你需要克服各种不同的障碍，你将穿越泥泞、沙漠，甚至滚烫的熔岩。保持节奏至关重要，稍有不慎就会滑倒，或在关键时刻减速。乍看之下，这似乎是一个简单的任务，但每走一步，都会迎来不可预测的新路线，可能瞬间导致失败。

## 怎么玩

按空格键让玩家开始奔跑，需要时松开以停止奔跑。你也可以使用左键代替空格键
