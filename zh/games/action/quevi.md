# Quevi

<a href="https://inkwengame.com/zh/games/quevi" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/quevi/cover.jpg)

Quevi 是一款 2D 科幻主题的平台游戏，你需要收集所有的金属球，同时避开敌方机器人、飞行机器人及其子弹、旋转激光、巨型刀刃，并抵达出口门以进入下一关。共有 8 个关卡，难度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动，按 W 键或上箭头键两次实现二段跳
