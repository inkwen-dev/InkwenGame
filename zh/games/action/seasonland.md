# Seasonland

<a href="https://inkwengame.com/zh/games/seasonland" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/seasonland/cover.jpg)

SeasonLand 是一款经典的 2D 像素艺术平台游戏。请帮助兔机器人完成他的旅程，找到出路，但要小心，一路上有许多邪恶的怪物和致命的陷阱等着你。

## 怎么玩

使用键盘移动，按向下箭头键下落，按 Z 键跳跃并射击。移动端请使用屏幕上的控制按钮
