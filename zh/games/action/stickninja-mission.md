# StickNinja 任务

![cover](https://img.inkwengame.com/games/stickninja-mission/cover.jpg)

进入一个快节奏的2D平台冒险，每一关都充满危险！控制你的忍者，击败路径上的怪物，收集钥匙，并打开神秘的门以继续你的任务。在平台上跳跃，避开致命陷阱，对抗危险敌人，并通过具有挑战性的关卡找到正确的道路。提升你的技能，掌握攻击技巧，生存下来每一次遭遇。你能否击败所有怪物，找到所有钥匙，并完成 StickNinja 任务？

## 怎么玩

使用 WASD 键移动 双跳功能可用 使用鼠标攻击敌人 移动设备上提供触摸控制
