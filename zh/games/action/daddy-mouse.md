# 爸爸老鼠

<a href="https://inkwengame.com/zh/games/daddy-mouse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/daddy-mouse/cover.jpg)

在这个色彩缤纷的2D平台冒险游戏中，帮助一只勇敢的老鼠收集奶酪并返回家中与家人团聚。探索森林、冰山、火山地带、开阔海域以及危险的城堡。跳跃避开陷阱，发现隐藏路径，收集金色星星，并击败强大的Boss。在桌面端使用键盘操作，在移动端使用屏幕触控操作。

## 怎么玩

桌面端 使用 A D 或左右箭头键移动，空格键、W 键或上箭头键跳跃（按住可跳得更高），E 键或 X 键进行互动或攻击，F 键在有武器时发射。Shift 键或 J 键在解锁后冲刺。移动端 使用屏幕上的方向键移动和跳跃，E 键进行互动
