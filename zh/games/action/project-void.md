# Project VOID

<a href="https://inkwengame.com/zh/games/project-void" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/project-void/cover.jpg)

Project VOID 是一款快节奏的科幻类随机生成生存游戏，背景设定在一个神秘的外星世界。对抗一波又一波的敌对无人机，尽可能长时间地生存下去，收集虚空头骨，并在每波之间升级你的能力。随着波次推进，敌人会变得更强大，出现频率也更高。你能坚持多久？

## 怎么玩

桌面端 使用 WASD 或方向键 移动 右键攻击 移动端 虚拟摇杆 移动 触摸攻击
