# Humi Bot 2

<a href="https://inkwengame.com/zh/games/humi-bot-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/humi-bot-2/cover.jpg)

Humi Bot 2 是一款 2D 科幻主题的平台游戏，你需要收集黄色光球，同时避开尖刺、锯子、敌方机器人、飞行机器人，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度随着进程逐渐增加。这是原版《Humi Bot》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
