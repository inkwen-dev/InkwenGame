# 狂奔进化

<a href="https://inkwengame.com/zh/games/stampede-evolution" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stampede-evolution/cover.jpg)

这是一款3D自然平台游戏，你将带领一群不断壮大的动物。在营地里行走，升级进化，从松鼠一路成长为狮子，然后在精心打造的各种生物群落（鲜花盛开的草地、秋日的森林、雨后的沼泽、冰封的河流、夜幕下的森林）中奔跑跳跃，同时让你的动物群向捕食者投掷食物。驶入有利的入口，壮大你的动物群，选择升级道具，击败强大的首领…

## 怎么玩

桌面端：使用 WASD 或方向键（或鼠标左键拖动）移动，空格键或鼠标右键跳跃，P 键暂停。移动端：左手拇指为摇杆，点击“跳跃”键或屏幕右侧即可跳跃。你的兽群会自动向捕食者投掷食物。驶入绿色大门即可壮大你的兽群，避开红色大门；驶入蓝色木板即可获得升级道具；尽可能多地带领动物到达终点拱门。在营地内走动即可升级，然后进化成更强大的动物。在“狂奔”模式中，你将独自向前奔跑：躲避墙壁和水障碍，尽可能跑得更远。

## 介绍

这是一款3D自然平台游戏，你将带领一群不断壮大的动物。在营地里行走，升级进化，从松鼠一路成长为狮子，然后在精心打造的各种生物群落（鲜花盛开的草地、秋日的森林、雨后的沼泽、冰封的河流、夜幕下的森林）中奔跑跳跃，同时让你的动物群向捕食者投掷食物。驶入有利的入口，壮大你的动物群，选择升级道具，击败强大的首领，并在每个关卡中获得三星评价。或者试试“狂奔”模式：一个不断加速、愈发狂野的无尽自动奔跑模式。
