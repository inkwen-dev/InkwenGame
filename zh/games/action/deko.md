# Deko

<a href="https://inkwengame.com/zh/games/deko" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/deko/cover.jpg)

Deko 是一款 2D 平台游戏，你需要在避开敌人、尖刺和锯齿的同时收集冰淇淋，并抵达粉红色的旗帜。游戏中共有 8 个关卡，随着进度难度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；使用 W 键或上方向键进行二段跳
