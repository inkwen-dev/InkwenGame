# Obby 币收集

<a href="https://inkwengame.com/zh/games/obby-coin-collect" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/obby-coin-collect/cover.jpg)

在这个冒险中，Obby 和他的朋友 Bacon 需要竞争并获胜。等待他们的跑酷挑战非常艰难，障碍物从各个方向袭来，试图将他们击倒。选择成为 Bacon 或 Obby，努力在这个冒险中生存下来。小心气球和旋转的草捆。此外，游戏中还能拥有一个独特的飞行宠物。

## 怎么玩

黄色玩家使用 WASD 键移动，灰色玩家使用方向键移动，收集所有硬币
