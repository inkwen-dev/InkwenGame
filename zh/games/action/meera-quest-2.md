# Meera Quest 2

<a href="https://inkwengame.com/zh/games/meera-quest-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/meera-quest-2/cover.jpg)

Meera Quest 2 是一款 2D 动漫风格的平台游戏，玩家将扮演一位可爱的动漫女孩 Meera，需要收集钥匙以逃离怪物世界，同时避开怪物、飞行恶魔及其子弹、熔岩、火焰和尖刺，抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐提升。这是原版《Meera Quest》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
