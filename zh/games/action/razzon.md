# Razzon

<a href="https://inkwengame.com/zh/games/razzon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/razzon/cover.jpg)

Razzon 是一款 2D 简单平台游戏，你需要收集骰子，同时避开尖刺、锯齿和敌人，抵达红色旗帜。共有 8 个关卡可供挑战，随着进度推进，难度会逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；使用 W 键或上箭头键进行二段跳
