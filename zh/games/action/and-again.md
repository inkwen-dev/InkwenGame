# 再次

<a href="https://inkwengame.com/zh/games/and-again" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/and-again/cover.jpg)

与新网络游戏《再次》的主角一同，你将踏上一段穿越绘画世界寻找宝藏与冒险的旅程。你的英雄所在的位置将显示在你面前的屏幕上。通过控制他的行动，你将在该区域中移动。克服各种障碍和陷阱，你需要帮助英雄找到特殊的魔法钉子。借助这些钉子，他将能够激活通往下一关卡的传送门。
