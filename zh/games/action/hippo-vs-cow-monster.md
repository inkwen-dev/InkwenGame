# 河马对牛怪

<a href="https://inkwengame.com/zh/games/hippo-vs-cow-monster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hippo-vs-cow-monster/cover.jpg)

《河马对牛怪》是一款2D可爱的小型平台游戏，你需要收集所有的西瓜，同时避开牛怪、锯子、尖刺，并抵达红色旗帜以进入下一关。游戏中共有8个关卡，随着游戏进行难度会逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上箭头键可进行二段跳
