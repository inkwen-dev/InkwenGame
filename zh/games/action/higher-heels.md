# 更高的高跟鞋

<a href="https://inkwengame.com/zh/games/higher-heels" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/higher-heels/cover.jpg)

你的高跟鞋越高，就越容易从墙壁中逃脱。每一关都有不同的障碍等待着你！有些轨道需要你张开双腿滑行。

## 怎么玩

按住并左右拖动以收集高跟鞋并提升你的高度，避开障碍物以通过当前关卡
