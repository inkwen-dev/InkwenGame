# 崛起僵尸

<a href="https://inkwengame.com/zh/games/rise-zombies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rise-zombies/cover.jpg)

**崛起僵尸** 是一款紧张刺激的僵尸生存游戏，背景设定在一个危险的末日城市。对抗无穷无尽的僵尸浪潮，从击败的敌人中收集金币，并升级你的战斗技能、速度和防御力。随着亡灵越来越强大且数量越来越多，运用聪明的策略和快速的反应来求生。探索废墟城市，击败每一个僵尸，变得更强，为生存而战！

## 怎么玩

使用 WASD 或方向键移动，Z 或 J 键出拳，X 或 K 键踢击
