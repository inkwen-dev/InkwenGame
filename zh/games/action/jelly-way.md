# 果冻之路

![cover](https://img.inkwengame.com/games/jelly-way/cover.jpg)

果冻之路是一款出色的平台类HTML5游戏。果冻在晴朗的一天迷失了。你需要帮助他逃离那里。你需要在关卡中收集3把钥匙并找到出路。你需要通过6个关卡。使用方向键控制果冻，注意观察敌人并找到避开它们的方法。祝你好运，尽情享受！
