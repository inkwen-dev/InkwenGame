# 僵尸日

<a href="https://inkwengame.com/zh/games/zombie-day" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-day/cover.jpg)

僵尸日是一款僵尸游戏。玩家将扮演一名警官，通过击倒僵尸来获取资源，并升级各种基地设备。功能：1. 玩家可以射击僵尸；2. 游戏中的武器包括无人机、地雷以及多种枪械；3. 击败Boss后可挑战更高难度。

## 怎么玩

电脑：您可以通过鼠标点击屏幕来控制主角的移动。手机：您可以通过手指点击屏幕来控制主角的移动。
