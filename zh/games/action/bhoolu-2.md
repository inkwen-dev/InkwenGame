# Bhoolu 2

<a href="https://inkwengame.com/zh/games/bhoolu-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bhoolu-2/cover.jpg)

Bhoolu 2 是一款 2D 平台游戏，你需要收集所有的糖果，同时避开敌人、锯子、尖刺，并抵达通往下一关的魔法洞穴。游戏中共有 8 个关卡，随着进度推进难度逐渐增加。这是经典系列 Bhoolu 的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
