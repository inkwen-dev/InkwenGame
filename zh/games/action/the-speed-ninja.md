# 速度忍者

<a href="https://inkwengame.com/zh/games/the-speed-ninja" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-speed-ninja/cover.jpg)

在这款令人兴奋的跑酷游戏中，扮演来自日出之地的勇猛战士，测试你的反应能力，完成多次跳跃赛。当敌军逼近时，一名年轻的忍者正从屋顶跃至屋顶。他的目标是敲响锣鼓，提前警告村庄的各个区域，以防敌人进攻。你的任务是抵达每一关终点的锣鼓。

## 怎么玩

- 点击屏幕右侧或按上箭头键跳跃，可进行二段跳 - 点击屏幕左侧或按右箭头键投掷手里剑 - 向下滑动或按下箭头键让忍者落地
