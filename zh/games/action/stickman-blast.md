# Stickman Blast

![cover](https://img.inkwengame.com/games/stickman-blast/cover.jpg)

合并相同的木人，解锁强大的战士和法师！带领你的小队自动战斗，对抗巨大的鸡、牛头怪和成群的恶魔。释放爆炸性技能，击溃敌人，在剧情模式和无尽模式中称霸。简单的合并机制和混乱的战斗让游戏易于上手——消灭敌人，成为终极木人英雄！

## 怎么玩

合并并部署 拖动相同的木人进行合并，生成更强大的单位，然后部署它们进行自动战斗。点击左侧的技能图标以激活强力攻击，清除一波又一波的敌人。重启并无尽 使用
