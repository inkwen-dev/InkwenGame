# 画笔奔跑

<a href="https://inkwengame.com/zh/games/draw-brush-running" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/draw-brush-running/cover.jpg)

在游戏中，你可以自由掌控自己的彩色画笔，顺利完成自己的挑战。根据你遇到的不同障碍，需要合理规划不同的游戏路线。游戏中可能会遇到建筑物、黑洞等不同考验，需顺利解决这些问题。

## 怎么玩

你的路线可以自由弯曲，但必须时刻注意这些障碍物。游戏中的所有路线障碍都是突然出现的，可能随时出现在前方。你的彩色画笔还可以解锁新的颜色皮肤，让游戏更加丰富多彩
