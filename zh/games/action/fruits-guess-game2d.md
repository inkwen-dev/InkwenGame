# 水果猜谜游戏2D

<a href="https://inkwengame.com/zh/games/fruits-guess-game2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-guess-game2d/cover.jpg)

在这个游戏中，玩家需要收集指定的物品，并在完成游戏后得知自己所猜测的水果名称。这款游戏有助于快速思考。游戏中共有10个关卡，每通过一个关卡，都会展示新的水果名称。

## 怎么玩

WSAD 和 左右方向键 - 玩家移动 空格键 - 玩家跳跃
