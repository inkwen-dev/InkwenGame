# 查基天空跳跃

<a href="https://inkwengame.com/zh/games/chaki-sky-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chaki-sky-jump/cover.jpg)

这一次，查基在天空中的平台上跳跃。帮助他跳过所有平台而不掉落。点击屏幕向左或向右移动。有时一些平台会水平移动，因此你需要等待它们到达合适位置再跳跃上去。
