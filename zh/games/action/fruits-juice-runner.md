# 水果果汁跑者

<a href="https://inkwengame.com/zh/games/fruits-juice-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-juice-runner/cover.jpg)

在移动玻璃杯的过程中收集所有水果和金币，将带来更多的游戏乐趣。游戏玩法非常简单，且更有趣！1. 请用手指在屏幕上左右滑动来移动玻璃杯 2. 收集相同颜色的水果，避开不同颜色的水果 3. 如果玻璃杯的大小恢复到初始状态，则本关失败 4. 如果收集到更多相同颜色的水果，可以在关卡结束时与他人分享果汁。

## 怎么玩

鼠标点击或轻触屏幕开始游戏
