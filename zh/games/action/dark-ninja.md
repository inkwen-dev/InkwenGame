# 暗影忍者

<a href="https://inkwengame.com/zh/games/dark-ninja" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dark-ninja/cover.jpg)

暗影忍者是一位需要穿越岩石村庄并消灭红色忍者——他最惧怕的敌人！奔跑、跳跃、使用降落伞、开启隐身、滑行（冲刺）、投掷手里剑，并使用特殊技能击杀敌人，尽可能快速地穿越村庄！收集尽可能多的忍者金币以获得分数，同时收集能量药水以增加能量条。

## 怎么玩

使用方向键移动；在移动设备上，点击屏幕上的A键投掷手里剑
