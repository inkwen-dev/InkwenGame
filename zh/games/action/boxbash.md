# BoxBash

<a href="https://inkwengame.com/zh/games/boxbash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boxbash/cover.jpg)

BoxBash 是一款游戏，玩家需要击打沙箱以提高分数，同时要避开带有致命火花的箱子，通过跳到箱子堆的另一侧来躲避。持续摧毁箱子，分数就会不断上升。尽情享受吧！

## 怎么玩

避开火花的一侧，并快速击打箱子
