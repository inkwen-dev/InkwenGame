# 橡果机器人

<a href="https://inkwengame.com/zh/games/acorn-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/acorn-bot/cover.jpg)

橡果机器人是一款2D平台游戏，你需要收集所有的冰淇淋蛋筒，同时避开敌方机器人、尖刺、地面锯片和旋转激光，抵达出口门以进入下一关。游戏中共有8个关卡，随着进度难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
