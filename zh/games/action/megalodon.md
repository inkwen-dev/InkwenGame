# 巨齿鲨

<a href="https://inkwengame.com/zh/games/megalodon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/megalodon/cover.jpg)

这是一款小型的吞食类鲨鱼游戏。在这里，玩家控制自己的鲨鱼，不断完成吞食任务。会有许多渔船等待你去攻击。每次攻击成功，你都会获得分数。但你必须确保渔船被击沉后，有人会落水。你必须吃掉这个人。这样得分会更高。这是一款节奏紧凑的战斗游戏，非常刺激和有趣。
