# 跳跃方块

<a href="https://inkwengame.com/zh/games/jumping-obby" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jumping-obby/cover.jpg)

控制一个方块在充满平台和障碍物的世界中跳跃。点击屏幕让方块跃起，避开障碍物，达到更高的高度。随着游戏进程，难度逐渐增加，速度更快，关卡也更加复杂。在《跳跃方块》中，你能跳得多高？

## 怎么玩

点击屏幕向前跳跃，尽量不要掉下去。你只能向前移动。努力取得高分
