# 米奇奔跑冒险游戏

<a href="https://inkwengame.com/zh/games/mickey-run-adventure-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mickey-run-adventure-game/cover.jpg)

欢迎来到伟大的王国工艺！勇敢的米奇，准备好跑、跳、冲刺和疾驰穿越王国吧。在这个工艺游戏中，你将扮演一名跑者，需要在无尽跑酷游戏中奔跑并收集金币。你需要非常小心，因为路上会有许多老鼠挡路。你需要利用你的工艺米奇和反应力来避开它们并持续奔跑。游戏中还会出现道具，你可以收集它们来帮助你在工艺游戏中前进。

## 怎么玩

上箭头 - 跳跃 左箭头 - 向左移动 右箭头 - 向右移动 下箭头 - 滑行
