# 矿工守护者

<a href="https://inkwengame.com/zh/games/mine-keeper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mine-keeper/cover.jpg)

《矿工守护者》是一款模拟游戏，你将扮演一位矮人领主，创建属于你的伟大王国。建造自己的城镇，并照顾你的国家。采集水果并出售以提供人民的食物。为居民提供更好的住所，建设新的设施，或把资金用于组建由矮人组成的军队。深入挖掘矿井以获取珍贵的石头和宝石。别忘了带上你的部队，因为矿井里有怪物！随着你的王国声名远扬…

## 怎么玩

PC 操作 使用 WASD 方向键，左键拖动以移动。移动设备操作 使用游戏内虚拟摇杆来移动。

## 介绍

《矿工守护者》是一款模拟游戏，你将扮演一位矮人领主，创建属于你的伟大王国。建造自己的城镇，并照顾你的国家。采集水果并出售以提供人民的食物。为居民提供更好的住所，建设新的设施，或把资金用于组建由矮人组成的军队。深入挖掘矿井以获取珍贵的石头和宝石。别忘了带上你的部队，因为矿井里有怪物！随着你的王国声名远扬，会有更多人前来定居和工作，你也可以雇佣农民和士兵。为城市建造新的设施。
