# Darios 的任务

<a href="https://inkwengame.com/zh/games/darios-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/darios-quest/cover.jpg)

Darios 的任务是一款 2D 平台游戏，你需要收集所有的冰淇淋棒，同时避开怪物、尖刺和锯齿，到达你的女朋友身边以进入下一关。游戏中共有 8 个关卡，随着进程难度逐渐增加。你能否为你女朋友收集到所有的冰淇淋棒？

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
