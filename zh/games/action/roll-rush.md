# 滚动冲锋

<a href="https://inkwengame.com/zh/games/roll-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roll-rush/cover.jpg)

一款快节奏的滚球游戏，你需要躲避障碍物并收集金币来进一步升级你的球，努力滚得越远越好！

## 怎么玩

操控一颗滚动的球，在布满平台、障碍物、缝隙和危险陷阱的赛道上飞驰。保持路线，快速反应，并保持速度，尽可能地跑得更远。

沿途收集金币，发现新的球体皮肤，并冲击你的最高分。你跑得越远，赛道就越快，难度也越高。

继续滚动，别掉下去。你能跑多远？

操作方式

移动端：

左右拖动即可控制球的方向。

桌面端：

左右移动鼠标即可控制球的方向。

目标：

保持在赛道上，避开障碍物，收集金币，并尽可能长时间地坚持下去。
