# BLOCKINS

<a href="https://inkwengame.com/zh/games/blockins" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockins/cover.jpg)

在《BLOCKINS》中，运用你的解谜技巧，堆叠类似俄罗斯方块的方块，抵达传送门。不同形状的方块，只需用一个方块抵达传送门即可通关。移动方块，跳跃于平台之间，堆叠并旋转以克服障碍。发现各种富有创意且令人满足的谜题，若遇到困难，别犹豫使用提示功能。

## 怎么玩

移动 - WASD 或 方向键 切换 - X 或 空格键 返回 - B 或 ESC 重启 - R
