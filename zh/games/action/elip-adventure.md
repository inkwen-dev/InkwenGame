# 椭圆冒险

<a href="https://inkwengame.com/zh/games/elip-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/elip-adventure/cover.jpg)

描述 在《椭圆冒险》中，你将扮演一个椭圆，展开一场惊险刺激的探险之旅，穿越充满危险的地图，寻找能够解锁椭圆之屋的星星。每一关都有不同的挑战，众多障碍物和敌人会阻碍你的前进。无论你是选择巧妙规避还是正面迎击这些敌人，都需要做出战略抉择，从而带来动态的游戏体验。

## 怎么玩

- WASD 移动 - 鼠标右键或 X 键 跳跃 - 空格键或 Z 键 墙面行走
