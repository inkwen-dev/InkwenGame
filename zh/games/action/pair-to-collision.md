# 配对碰撞

<a href="https://inkwengame.com/zh/games/pair-to-collision" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pair-to-collision/cover.jpg)

这是一款3D碰撞游戏。游戏非常放松和解压。你可以点击球体上两个相同的物体来消除它们。当球体上的所有物体都被消除后，你就可以通过关卡了。玩家在游玩时会感到非常有成就感。快来试试吧，我觉得你会喜欢的。

## 怎么玩

点击球体上两个相同的物体以消除它们，并消除球体上的所有物体以通过关卡
