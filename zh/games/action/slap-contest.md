# 掌掴对决

<a href="https://inkwengame.com/zh/games/slap-contest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slap-contest/cover.jpg)

欢迎来到掌掴对决游戏。向左和向右移动，并双击以掌掴你的对手。获得3次掌掴即可进入下一关。你可以选择双人模式，与朋友和家人一起玩。尽情享受

## 怎么玩

使用方向键移动，连续点击右方向键两次进行掌掴
