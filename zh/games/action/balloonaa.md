# 气球男孩

<a href="https://inkwengame.com/zh/games/balloonaa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/balloonaa/cover.jpg)

气球男孩是一款2D小平台游戏，你将扮演一个气球男孩，需要收集氦气罐，同时避开敌对气球、图钉、尖刺和地面锯齿，抵达出口门以进入下一关。共有8个关卡可供挑战，随着关卡推进难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
