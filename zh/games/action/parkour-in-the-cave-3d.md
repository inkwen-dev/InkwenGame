# 洞穴中的跑酷 3D

<a href="https://inkwengame.com/zh/games/parkour-in-the-cave-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/parkour-in-the-cave-3d/cover.jpg)

这款游戏采用《我的世界》的风格。洞穴中有安全的高处和熔岩形状的地板。运用你所有的跑酷技巧来完成所有关卡。每一关都比前一关难得多。

## 怎么玩

要完成关卡，你需要进入洞穴另一端的传送门。PC操作：WASD - 移动，空格键 - 跳跃。手机操作：虚拟摇杆 - 移动，跳跃按钮
