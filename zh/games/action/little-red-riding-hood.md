# 小红帽

<a href="https://inkwengame.com/zh/games/little-red-riding-hood" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/little-red-riding-hood/cover.jpg)

你能帮助小红帽打败那只坏狼吗？这是一款平台游戏。你需要跳跃前进，避开坑洞和敌人。途中可以收集水果，并用它们作为武器击败蛇，最终打败那只坏狼。

## 怎么玩

A D 或左、右箭头键移动，W 或上箭头键跳跃，空格键射击
