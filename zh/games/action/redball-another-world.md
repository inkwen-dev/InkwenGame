# Redball - 另一个世界

<a href="https://inkwengame.com/zh/games/redball-another-world" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/redball-another-world/cover.jpg)

一款引人入胜的3D街机游戏，讲述了一个红球的故事。你需要克服障碍并击败对手，才能到达关卡的终点。你的最佳成绩将被记录在排行榜中。游戏共有15个关卡（3个世界）

## 怎么玩

游戏的主要目标是抵达关卡终点。PC操作：WASD移动，空格键跳跃；移动设备操作：左摇杆移动，右按钮跳跃
