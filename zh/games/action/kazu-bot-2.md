# Kazu Bot 2

<a href="https://inkwengame.com/zh/games/kazu-bot-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kazu-bot-2/cover.jpg)

Kazu Bot 2 是一款 2D 科幻主题的平台游戏，你需要收集所有包含与科技相关机密信息的平板，同时避开敌方机器人、飞行机器人及其子弹、尖刺、旋转锯片，并抵达出口门以进入下一关。共有 8 个关卡可供挑战，随着游戏进程难度逐渐增加。这是原版《Kazu Bot》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
