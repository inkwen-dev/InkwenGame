# 直升机对战

<a href="https://inkwengame.com/zh/games/helifight" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/helifight/cover.jpg)

两架微型像素直升机正在互相搏斗。其中一架蓝色或红色的直升机由你控制，另一架则由你的朋友控制。通过收集空中出现的火箭符号来发射火箭攻击敌方直升机。率先完成五次射击的一方将赢得比赛。

## 怎么玩

在移动设备上通过触摸操作，在键盘设备上通过W键和上箭头键进行控制
