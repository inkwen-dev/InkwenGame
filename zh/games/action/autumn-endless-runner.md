# 秋日无尽跑酷

<a href="https://inkwengame.com/zh/games/autumn-endless-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/autumn-endless-runner/cover.jpg)

你外出到一片树林中欣赏美丽的秋日景色，但随后一个诡异的南瓜幽灵开始追你。沿着小路奔跑以逃离南瓜幽灵。点击游戏屏幕来跳过遇到的障碍物和动物。千万别让南瓜幽灵抓到你！

## 怎么玩

点击游戏屏幕跳跃 双击实现双重跳跃 避开所有障碍物和动物
