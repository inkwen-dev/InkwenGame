# 忍者障碍公园

<a href="https://inkwengame.com/zh/games/ninja-obby-parkours" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ninja-obby-parkours/cover.jpg)

一款快节奏的跑酷游戏，支持单人和双人模式。你的目标很简单：不断前进，尽可能长时间地生存下去，不要掉下平台。你一开始有3条生命——全部失去，游戏结束。你可以独自挑战来测试自己的技巧，也可以在双人模式中组队，进行一场有趣又充满竞争的比赛，看看谁能够走得更远。

## 怎么玩

单人模式时使用WASD键和空格键；按两次空格键可进行二段跳。双人模式时，第一玩家使用WASD和空格键，第二玩家使用方向键控制，按L键跳跃，连续按两次L键可进行二段跳
