# 枪战节

<a href="https://inkwengame.com/zh/games/gun-fest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gun-fest/cover.jpg)

你认识多少把枪？《枪战节》是一款枪支收集类街机游戏。有许多小人劫匪正在从银行抢劫钱财。我们需要你消灭尽可能多的坏人，并通过收集到的枪支摧毁他们的车辆。游戏中有三种编号墙壁：蓝色墙壁会增加你当前拥有的枪支数量；红色墙壁会减少你当前的枪支数量，甚至直接导致失败；橙色墙壁则会提供随机数字。祝你好运，完成所有关卡！
