# Triman

<a href="https://inkwengame.com/zh/games/triman" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/triman/cover.jpg)

Triman 是一款 2D 简单平台游戏，你需要收集金色钥匙并到达出口门。共有 8 个关卡可供游玩，难度会随着关卡推进而增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
