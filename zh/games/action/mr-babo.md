# Mr Babo

<a href="https://inkwengame.com/zh/games/mr-babo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mr-babo/cover.jpg)

Mr Babo 是一款 2D 简单的平台游戏，你需要收集金色钥匙以解锁金门，同时避开敌人、尖刺和锯子。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；使用 W 键或上方向键进行二段跳
