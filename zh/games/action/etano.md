# 乙烷

<a href="https://inkwengame.com/zh/games/etano" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/etano/cover.jpg)

乙烷是一款2D平台游戏，你需要收集所有历史性的金色装饰品，同时避开所有敌人、尖刺、火焰，并抵达出口门以进入下一关。共有8个关卡可供游玩，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上方向键可进行二段跳
