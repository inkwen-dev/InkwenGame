# 剑士冒险

![cover](https://img.inkwengame.com/games/swordsman-adventure/cover.jpg)

剑士冒险是一款紧张刺激的冒险游戏，你在战场上自由挥舞你的剑来完成一系列任务。在这个角色扮演游戏中，你控制你的士兵攻击不同血量的敌人。每完成一个任务后，你会获得奖励，可以用来提升你的攻击力或装备新武器。
