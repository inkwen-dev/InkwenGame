# Skibidi Blocks

<a href="https://inkwengame.com/zh/games/skibidi-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skibidi-blocks/cover.jpg)

Skibidi Blocks 游戏是一款快节奏且充满挑战的积木跑酷游戏，将考验你的反应能力和战略思维。在一系列障碍物中堆叠积木，同时沿途收集 Poo。积木会自动向前移动，因此你必须仔细规划跳跃和移动，以避免从屏幕上掉落。

## 怎么玩

桌面 使用左键点击或键盘上的上箭头键进行跳跃 移动设备 点击屏幕进行跳跃
