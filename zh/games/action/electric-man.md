# 电人

<a href="https://inkwengame.com/zh/games/electric-man" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/electric-man/cover.jpg)

电人是一款精彩的Stickman格斗Flash游戏，你必须使用各种不同的拳击和踢击组合来对抗一系列对手。进入游戏前，你可以选择你的Stickman的名字和颜色，以及难度等级（简单、普通或专业）。选定角色后，你可以完成一个教程，了解基本的游戏机制和招式组合。
