# 迷你跳跃

<a href="https://inkwengame.com/zh/games/mini-jumps" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-jumps/cover.jpg)

迷你跳跃是一款游戏，你控制一个小小的橙色粘液，它唯一的能力就是跳跃。利用关卡中的平台帮助粘液到达目标。你还可以在速通模式中测试你的跳跃技巧！

## 怎么玩

桌面端 - 按 X 键或左键点击以跳跃 移动端 - 触摸以跳跃
