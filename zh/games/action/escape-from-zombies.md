# 逃离僵尸

<a href="https://inkwengame.com/zh/games/escape-from-zombies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/escape-from-zombies/cover.jpg)

你是僵尸末日的幸存者，被困在一座建筑物里，汽车坏了，成群的僵尸正在草坪上攻击你。但等等，你找到了足够的工具来修理汽车，从而逃离僵尸的围攻。你准备好了吗？你一边努力修理汽车，一边还要抵御成群僵尸的进攻。每个部分都需要掷骰子决定成功与否。任何存活下来的僵尸都会攻击掩体。当你成功击杀10个僵尸后，将获得一个强化道具。

## 怎么玩

你有4个行动骰子，可以分配到游戏的3个部分：草坪掩体、汽车维修。如果你在草坪上放置骰子并获得3或以上的点数，就能对僵尸进行一次射击；如果你在掩体上放置骰子并获得3或以上的点数，就能获得1点掩体生命值；若获得5或以上点数，则可获得额外效果。
