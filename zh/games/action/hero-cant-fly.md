# 英雄不会飞

<a href="https://inkwengame.com/zh/games/hero-cant-fly" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hero-cant-fly/cover.jpg)

这位英雄不会飞，你需要帮助他跳过台阶，并且始终注意飞行的箱子，以免被砸中。

## 怎么玩

点击屏幕帮助英雄跳得更高，松开手指让英雄正常移动，以避开飞行的箱子或移动到其他砖块上
