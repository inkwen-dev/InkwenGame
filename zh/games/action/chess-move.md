# 国际象棋走法

<a href="https://inkwengame.com/zh/games/chess-move" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chess-move/cover.jpg)

在这个有趣的类似国际象棋的解谜游戏中，每一关都要抓住红方国王。棋子的移动方式如同国际象棋，但你无需懂得下国际象棋即可完成全部24个关卡。如果遇到困难，只需点击每关屏幕底部的「攻略」按钮。

## 怎么玩

点击你的蓝色棋子以查看其可移动的位置，然后点击其中一个高亮位置来移动它
