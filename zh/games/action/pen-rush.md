# 笔速冲

<a href="https://inkwengame.com/zh/games/pen-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pen-rush/cover.jpg)

笔速冲是一款有趣的街机游戏。你见过奔跑的笔吗？这里就是。滑动屏幕让笔在桌面上移动。收集其他笔。注意避开书本、笔筒和其他障碍物。到达终点时，你收集到的额外笔将会被放进书里。
