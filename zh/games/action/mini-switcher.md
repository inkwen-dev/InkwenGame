# 迷你切换器

<a href="https://inkwengame.com/zh/games/mini-switcher" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-switcher/cover.jpg)

切换重力，引导一个小球角色到达目标，穿越30个关卡，面对各种色彩缤纷、行为各异的敌人和障碍。你还可以在速度挑战模式中测试自己的能力。《迷你切换器》采用复古风格制作，旨在带来一段简短而放松的游戏体验。

## 怎么玩

桌面端 - 按 X 键、空格键或左键点击以切换重力；移动端 - 触摸屏幕以切换重力
