# 奔跑的字母

跑起来，让我们一起跑字母君。这是一款特别独特的手机酷跑游戏。玩家在游戏中操控字母进行趣味闯关。不同的游戏关卡需要玩家解锁，收集更多字母，最终赢得转盘奖励的机会。卡通风格的游戏场景和清新的小跑道，当不同字母形态面对障碍时，通过关卡的速度也各不相同，这要求玩家灵活操作。

1 游戏场景采用卡通风格，众多游戏关卡，玩家可以在这里体验有趣的酷跑乐趣 2 在跑道上收集其他字母，收集成功后可获得转盘奖励，并赢得更多道具 3 类别
