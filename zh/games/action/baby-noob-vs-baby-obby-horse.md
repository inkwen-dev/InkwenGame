# 宝宝新手 vs 宝宝奥比马

<a href="https://inkwengame.com/zh/games/baby-noob-vs-baby-obby-horse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/baby-noob-vs-baby-obby-horse/cover.jpg)

两个宝宝兄弟需要在森林中找到一把钥匙和一个箱子。帮助宝宝兄弟找到钥匙，找到钥匙后，用钥匙打开箱子。森林里有可怕的动物，所以你必须非常小心。为了击败森林中的动物，你应该扔瓶子。瓶子是一种非常强大的武器，所以不要犹豫使用它。收集森林中的棒棒糖。宝宝们喜欢棒棒糖，所以别忘了收集它们。

## 怎么玩

使用WASD和方向键移动 按P键投掷瓶子 有12个不同的挑战关卡 双跳功能已开启
