# Rexo

<a href="https://inkwengame.com/zh/games/rexo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rexo/cover.jpg)

Rexo 是一款 2D 平台游戏，你将扮演一个立方体，目标是在每一关中收集所有宝石，然后进入下一关，同时避开尖刺和敌人。一旦你收集完所有宝石，红色旗帜就会变成绿色，你就可以继续前往下一关。游戏中共有 8 个关卡，难度会随着关卡推进而逐渐增加。

## 怎么玩

使用方向键控制立方体的移动。按两次上方向键可进行双跳。如果你使用的是移动设备，可以使用屏幕上的虚拟摇杆按钮来操作游戏
