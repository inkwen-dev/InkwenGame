# Dandys World 马拉松

<a href="https://inkwengame.com/zh/games/dandys-world-marathon" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dandys-world-marathon/cover.jpg)

你将扮演来自 Dandys World 的心爱角色，帮助他们收集散布在奇异关卡中的神秘黑色水滴。

## 怎么玩

点击屏幕使角色跳跃或转向。收集所有水滴以完成关卡。避开障碍物——深渊不会沉睡。发现新角色。
