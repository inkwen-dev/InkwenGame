# MCBros 像素工艺

<a href="https://inkwengame.com/zh/games/mcbros-pixelcraft" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mcbros-pixelcraft/cover.jpg)

在史蒂夫和亚历克斯的冒险中，你需要帮助他们。他们必须收集所有的钻石。在收集钻石时要非常小心。洞穴内外都有许多带刺的障碍物。别忘了，洞穴里有怪物，它们非常危险。要消灭怪物，就跳到它们身上把它们压扁。这样，你就可以击败所有怪物，并到达关卡尽头的传送门。务必小心，确保两位玩家都能安全抵达传送门。

## 怎么玩

使用WASD和方向键移动，双跳已启用。收集所有硬币，找到钥匙和宝箱
