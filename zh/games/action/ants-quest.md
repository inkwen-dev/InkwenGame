# 蚂蚁大冒险

《蚂蚁大冒险》是一款2D平台游戏，你需要收集糖块，避开敌对蚂蚁、飞蚁、尖刺，并抵达红色旗帜以进入下一关。游戏中共有8个关卡，难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上方向键可进行二段跳
