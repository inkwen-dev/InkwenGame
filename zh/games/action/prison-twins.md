# 监狱双胞胎

<a href="https://inkwengame.com/zh/games/prison-twins" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/prison-twins/cover.jpg)

两名兄弟需要逃离监狱，帮助他们！兄弟俩在监狱里非常无聊。监狱里有许多需要解决的谜题式按钮。每个按钮会激活一个不同的平台。移动平台并找到你需要的三把金钥匙。找到金钥匙后，与你的兄弟一起逃离监狱。记住，其中一人可以破坏门，而另一人则可以通过狭窄的隧道和雪地。

## 怎么玩

使用WASD键和方向键移动。游戏中启用了双重跳跃功能。胖兄弟可以破坏门，瘦兄弟可以通过狭窄的缝隙
