# Bhoolu

Bhoolu 是一款 2D 平台游戏，你需要收集所有糖果，同时避开尖刺、锯子和敌人，抵达魔法洞穴以进入下一关。共有 8 个关卡可供挑战，难度会随着游戏进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；使用 W 键或上方向键进行二段跳
