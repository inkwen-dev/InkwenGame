# 鱿鱼监狱游戏

<a href="https://inkwengame.com/zh/games/squid-prison-games" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-prison-games/cover.jpg)

欢迎来到鱿鱼监狱游戏。共有10个关卡需要生存。通过通关关卡赚取金钱，并为你的角色购买道具。从3名角色中选择一位，与20名渴望逃脱的囚犯竞争。祝你好运！

## 怎么玩

使用鼠标移动角色，或使用方向键或WASD键
