# 迷你推

<a href="https://inkwengame.com/zh/games/mini-push" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-push/cover.jpg)

迷你推是一款复古风格的街机游戏，你需要帮助一个圆球到达目标，通过开启或关闭挡路的方块，并让他避开敌人。这款游戏受到一些NES风格游戏的启发，但拥有简单的操作和对所有人友好的难度。它还为追求更高挑战的玩家提供了速通模式。

## 怎么玩

桌面端 - X 键、空格键或左键点击以切换方块状态；移动端 - 触摸以切换方块状态
