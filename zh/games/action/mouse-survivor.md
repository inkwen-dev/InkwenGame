## 怎么玩

如何玩《鼠标幸存者》？

键盘操作

W / 上方向键 / 空格键：跳跃

A / 左方向键：向左

D / 右方向键：向右

手机端：滑动屏幕

🐭 与勇敢的鼠标一起奔跑、跳跃、探索无限分割的世界！🧀

在这款激动人心的 2D 无尽跑酷游戏中，与我们无畏的鼠标英雄一起踏上史诗般的旅程！

🏃 无尽的奔跑冒险：

引导你的鼠标穿梭于一个充满不断变化的方块的动态世界。小心那些透明度较低的方块；一触即伤！躲避、跳跃、滑行，一路闯过无尽的挑战。

🐍 遭遇狡猾的蛇：

小心爬行的蛇！蛇会试图阻碍你的前进。向右、向左或向上滑动屏幕，做出大胆的动作，逃脱它们的魔爪。你能智胜这些蛇形敌人吗？

🧀 奶酪收集与升级：

沿途收集美味的奶酪，增加你的奶酪数量。用辛苦赚来的奶酪解锁新的地块类型。多种地块各具特色，挑战不断，打造专属你的跑步体验！

祝你好运……
