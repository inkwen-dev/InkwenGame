# 圣诞跑酷挑战

<a href="https://inkwengame.com/zh/games/santa-run-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/santa-run-challenge/cover.jpg)

在游戏《圣诞跑酷挑战》中，你将帮助勇敢的圣诞老人完成他的使命。你的英雄将手提袋子在城市街道上奔跑。当各种障碍物和怪物挡在前方时，你需要点击屏幕让角色跳跃。这样，他就能跳过怪物，继续前行。你还可以用袋子击打怪物，将其击倒。

## 怎么玩

在桌面端使用鼠标，或在移动设备上使用触摸按钮
