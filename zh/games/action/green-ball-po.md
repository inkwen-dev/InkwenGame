# 绿色球波

<a href="https://inkwengame.com/zh/games/green-ball-po" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/green-ball-po/cover.jpg)

绿色球波是一款2D平台游戏，你需要收集金色钥匙以解锁大门，同时避开尖刺和敌人。游戏中共有8个关卡，随着进度难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
