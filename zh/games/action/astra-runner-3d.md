# 星尘跑者3D

![cover](https://img.inkwengame.com/games/astra-runner-3d/cover.jpg)

在充满色彩的世界中弹跳前行，穿越移动平台、棘手的间隙和无尽的挑战！通过简单的点击或轻触操作控制一个球体——跃过障碍物，精准把握时机，争取最高分数。

## 怎么玩

使用方向键或屏幕按钮移动角色，收集硬币并避开障碍物。失败后游戏将重新开始。努力获得最高分。控制方式：方向键 / 触屏按钮 —— 移动角色；空格键 / 轻触 —— 跳跃或触发
