# Mew Cat 2

<a href="https://inkwengame.com/zh/games/mew-cat-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mew-cat-2/cover.jpg)

Mew Cat 2 是一款 2D 平台游戏，你需要收集猫粮碗，同时避开敌对的猫咪、飞行机器人、尖刺和锯子，并抵达绿色旗帜以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。这是原始《Mew Cat》游戏系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
