# 色彩 3D   突破障碍

<a href="https://inkwengame.com/zh/games/color-3d-bump-it-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-3d-bump-it-up/cover.jpg)

基本原理非常简单——你控制一个始终向前移动的小球。在前进的路上，会遇到一些障碍物，你需要通过它们。不过有个小问题：你只能触碰与你的小球颜色相同的障碍物。如果碰到不同颜色的障碍物，游戏就会结束，你需要从头开始。

## 怎么玩

鼠标操作进行滑动
