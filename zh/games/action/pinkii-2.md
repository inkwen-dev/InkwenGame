# Pinkii 2

<a href="https://inkwengame.com/zh/games/pinkii-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pinkii-2/cover.jpg)

Pinkii 2 是一款简单的 2D 平台游戏，你需要收集黄色花朵，同时避开包括飞行怪物在内的敌人，并抵达粉色旗帜以进入下一关。这是原始 Pinkii 系列的续作，新增了更多敌人。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动，使用 W 键或上箭头键进行二段跳
