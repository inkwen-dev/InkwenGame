# StickMan Parkour 2

<a href="https://inkwengame.com/zh/games/stickman-parkour-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickman-parkour-2/cover.jpg)

这是另一版本的 Stickman Parkour 游戏。你的任务是奔跑和跳跃，到达门口以解锁下一关。小心不要从边缘掉下去，并尽量避开障碍物。冒险开始吧！

## 怎么玩

使用 A 和 D 键左右移动，W 键跳跃和攀爬，S 和 D 或 A 键滚动，也可以使用方向键
