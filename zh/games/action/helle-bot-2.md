# Helle Bot 2

<a href="https://inkwengame.com/zh/games/helle-bot-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/helle-bot-2/cover.jpg)

Helle Bot 2 是一款 2D 科幻主题的平台游戏，您将扮演一名机器人，需要收集珍贵的红色宝石，同时避开绿色和紫色的敌方机器人、飞行机器人及其子弹、火焰、旋转刀片和尖刺，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。这是原版《Helle Bot》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；按两次 W 键或上箭头键可进行二段跳
