# 快速数学

<a href="https://inkwengame.com/zh/games/quick-maths" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/quick-maths/cover.jpg)

《快速数学》是一款街机跑酷游戏，你的大脑就是控制器。在包含加减乘除的20个关卡中，你需要解数学题来清除障碍。完成全部20个关卡即可解锁无尽模式，挑战高分。

## 怎么玩

在计时器归零前解决每个数学题。点击或轻触答案，或按 1、2 或 3。答对即可清除障碍。错误会扣除星星，但不会导致关卡结束：完成关卡可得一颗星，错误不超过两次可得两颗星，没有错误且快速答对足够多的题目可得三颗星。通关第 20 关即可解锁“无尽模式”，在该模式下，一次碰撞即结束游戏。按 Enter 键或空格键开始和继续游戏。
