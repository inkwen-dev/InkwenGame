# FatRabbit

<a href="https://inkwengame.com/zh/games/fatrabbit" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fatrabbit/cover.jpg)

忘记那些减肥饮食，让这只可爱的兔子在这场甜点、蛋糕和饼干的盛宴中变得越来越胖吧，这些美食会纷纷落在你身上。解锁礼物，获得金币以探索更多新领域，同时还能获得一些实用的增益效果，让你移动更加轻松，同时通过跳跃来避开陷阱。

## 怎么玩

上键 - 跳跃 2次上键 - 双重跳跃 左键 - 向左移动 右键 - 向右移动 E键 - 降低水果和蛋糕的速度 R键 - 减少过重
