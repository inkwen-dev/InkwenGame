# 监狱大门

<a href="https://inkwengame.com/zh/games/prison-gates" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/prison-gates/cover.jpg)

《监狱大门》是一款忍者风格的跑酷游戏，你需要在奔跑过程中穿过门洞，同时避开罪犯。你的任务是在你面前出现的两个门中选择正确的那一个通过。这两个门中，一个会是打开的，另一个则是关闭的。如果你尝试穿过关闭的门，罪犯就会抓住你，游戏结束。当你成功穿过正确的门时，追赶你的罪犯将无法抓住你，从而取得胜利。

## 怎么玩

PC 使用左右方向键移动  移动设备 使用手指左右滑动操作
