# 怪物制造者

<a href="https://inkwengame.com/zh/games/monster-maker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-maker/cover.jpg)

- 点击生成以创建一个随机怪物。 - 输入一个种子，或留空以获得随机结果 - 点击截图以拍摄你的怪物图片作为壁纸（添加你的名字并分享截图！！）[仅限Windows版本] - 点击多色复选框，如果你希望随机化怪物的颜色 - 点击背景以选择其他背景
