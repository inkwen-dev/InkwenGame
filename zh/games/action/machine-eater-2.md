# 机械吞噬者

<a href="https://inkwengame.com/zh/games/machine-eater-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/machine-eater-2/cover.jpg)

利用你收集的资源创建方块，扩展你的飞船，并在你创建的方块上战略性地放置具有不同功能的结构，然后在雷达上选择你的敌人。运用你的策略技能来消灭雷达上探测到的敌人。从敌人那里收集的结构将为你的策略增添深度。

## 怎么玩

控制方式 使用 WASD 方向键和鼠标移动角色
