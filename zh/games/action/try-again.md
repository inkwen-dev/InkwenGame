# 再试一次

<a href="https://inkwengame.com/zh/games/try-again" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/try-again/cover.jpg)

《再试一次》是一款充满挑战的物理平台游戏。滚动你的小球穿越70个会反抗的关卡：会消失的地板、等待完美时机的陷阱，以及每次尝试时行为都不同的关卡。每一次死亡都会让你学到一些东西。记住陷阱的位置，找到安全的时机，抵达传送门。每10个关卡后，新的区域和新的Boss关卡等待着你，同时解锁新的小球颜色。不断死亡，不断学习…

## 怎么玩

键盘方向键或A D键滚动，W键或空格键跳跃，Esc键或P键暂停，触摸操作时按住左键滚动，点击右键跳跃
