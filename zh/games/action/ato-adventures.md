# Ato 冒险

<a href="https://inkwengame.com/zh/games/ato-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ato-adventures/cover.jpg)

Ato 冒险是一款2D简单平台游戏，你的任务是收集玫瑰，以解锁出口门。你需要避开陷阱和敌人，才能到达通往下一级的出口门。游戏中共有8个关卡，随着进度推进难度会逐渐增加。

## 怎么玩

使用方向键或WASD键进行移动，连续按两次W键或上箭头键可进行二段跳
