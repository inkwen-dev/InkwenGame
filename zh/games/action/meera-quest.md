# Meera Quest

<a href="https://inkwengame.com/zh/games/meera-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/meera-quest/cover.jpg)

Meera Quest 是一款 2D 动漫主题的平台游戏，你将扮演一位可爱的动漫女孩 Meera，需要收集钥匙以逃离怪物世界，同时避开怪物、熔岩、火焰和尖刺，抵达出口门以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
