# 部落战争

<a href="https://inkwengame.com/zh/games/tribal-wars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tribal-wars/cover.jpg)

这是一款个人与恐龙共同作战的游戏，获胜后可获得金币，金币可用于购买人员和恐龙，同等级的人员可以合并成更高等级的人员，战斗力会变得更强大，同等级的恐龙也可以合成更高等级的恐龙，相应的战斗力也会提升，战斗前还可以摆放不同的阵型，赶快开始战争吧

## 怎么玩

游戏开始前，触摸屏幕拖动角色和恐龙可移动位置，将它们放置在想要的位置，拖动相同的角色和相同的恐龙可合并成更高等级的角色
