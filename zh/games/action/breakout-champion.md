# 突破冠军

<a href="https://inkwengame.com/zh/games/breakout-champion" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/breakout-champion/cover.jpg)

突破冠军是一款经典的突破游戏。一排排砖块正朝你逼近。你的目标是通过反复将球击打到挡板上，使其反弹并摧毁所有砖块，以免一排砖块触及你的边界。摧毁所有砖块即可完成一个关卡。每个关卡必须在5分钟内完成。使用鼠标或指尖操作挡板。
