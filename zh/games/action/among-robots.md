# 机器人之间

<a href="https://inkwengame.com/zh/games/among-robots" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/among-robots/cover.jpg)

《机器人之间》是一款2D平台游戏，你需要收集钥匙卡以解锁门并进入下一关。你必须避开敌对机器人、尖刺和锯子。共有8个关卡可供挑战，随着游戏进程难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
