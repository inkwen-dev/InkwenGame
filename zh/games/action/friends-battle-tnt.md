# 好友大战 TNT

<a href="https://inkwengame.com/zh/games/friends-battle-tnt" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/friends-battle-tnt/cover.jpg)

你准备好和朋友一起迎接一场激烈的挑战了吗？你应该与朋友竞争。现在正是和朋友比赛的好时机。谁最快收集到飞行的 TNT，谁就获胜。共有两支队伍，红色和蓝色。收集到最多 TNT 的队伍获胜。第一个收集到 20 个 TNT 的人获胜。你必须在朋友之前收集它们。抓住空中飞舞的 TNT。

## 怎么玩

红色玩家使用 WASD 键移动，蓝色玩家使用方向键移动。收集 TNT 并将其带入箱子
