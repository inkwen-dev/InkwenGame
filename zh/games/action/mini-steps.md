# 迷你步

<a href="https://inkwengame.com/zh/games/mini-steps" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-steps/cover.jpg)

迷你步是一款复古风格的平台解谜游戏，你将操控一个小型凝胶角色，以小步跳跃的方式前进；你需要明智地移动这个凝胶角色，收集四处散落的所有硬币。

## 怎么玩

桌面端 - 使用 WAD 或方向键进行跳跃 移动端 - 游戏内控制
