# 一分钟

<a href="https://inkwengame.com/zh/games/one-minute" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/one-minute/cover.jpg)

尝试在1分钟内击败强大的士兵来赢得游戏。用你的主角在不到1分钟的时间内对抗强大的士兵，并运用策略。最后，专注于赢得游戏。

## 怎么玩

WASD 移动 Q 切换剑 左键点击 攻击
