# 无限直线跑酷游戏

<a href="https://inkwengame.com/zh/games/infinite-line-runner-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/infinite-line-runner-game/cover.jpg)

无限直线跑酷游戏是一款快节奏且令人上瘾的跑酷游戏，考验你的反应力、专注力和时机把握。在这款游戏中，玩家控制一个角色沿着基于线条的路径不断奔跑，路径中充满了障碍物、弯道以及逐渐加快的速度。目标很简单：尽可能长时间地奔跑，避开障碍物，并取得最高分数。

## 怎么玩
