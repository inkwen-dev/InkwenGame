# Retoena

<a href="https://inkwengame.com/zh/games/retoena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/retoena/cover.jpg)

Retoena 是一款 2D 科幻主题的平台游戏，你将扮演一名类人女孩，需要收集蓝色能量方块，同时避开敌方机器人、尖刺、锯齿，并抵达基地以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
