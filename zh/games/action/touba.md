# Touba

<a href="https://inkwengame.com/zh/games/touba" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/touba/cover.jpg)

Touba 是一款 2D 平台游戏，你将扮演一只黄色小鸟，需要收集谷物碗，避开敌对小鸟、尖刺，并抵达鸟巢以进入下一关。共有 8 个关卡，难度逐步增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
