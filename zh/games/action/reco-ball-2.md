# Reco Ball 2

<a href="https://inkwengame.com/zh/games/reco-ball-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/reco-ball-2/cover.jpg)

Reco Ball 2 是一款 2D 的可爱小平台游戏，你将扮演一个球，需要收集所有的铜币，同时避开敌人球、飞行敌人球、旋转刀片、尖刺，并抵达黄色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。这是原版《Reco Ball》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
