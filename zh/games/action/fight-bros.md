# 战斗兄弟

<a href="https://inkwengame.com/zh/games/fight-bros" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fight-bros/cover.jpg)

你以前用弹弓扔过石头吗？用弹弓射击并击败你的朋友。这是一款支持两名玩家的游戏。与朋友互相战斗。你有3条生命。3次生命耗尽即告失败。战斗以取得胜利为目标。游戏包含3种不同的地图。超级能力会从天而降。获取宝箱并获得你的力量。用鱼、橙子和星星击败对手。

## 怎么玩

玩家1可以使用WASD键移动，使用S键射击。玩家2可以使用方向键移动，使用向下方向键射击。支持移动端游玩
