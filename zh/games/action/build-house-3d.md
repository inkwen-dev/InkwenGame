# 建造3D房屋

![cover](https://img.inkwengame.com/games/build-house-3d/cover.jpg)

这是一款放置类游戏，游戏中玩家的房子被陨石摧毁，因此需要雇佣工人、提高效率等方式挖掘出自己的房子，游戏界面干净简洁。用户还可以感受到采矿过程中金钱数量不断增加的快感。

## 怎么玩

这款游戏操作简单，只需点击自己认为需要的物品以加速或雇佣工人，让玩家在游戏中更贴近建设过程。
