# 球落

<a href="https://inkwengame.com/zh/games/ball-fall" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ball-fall/cover.jpg)

球落是一款富有挑战性的平台游戏。游戏的目标是从高处投掷彩色球，通过不同的平台得分。在平台之间跳跃，防止球掉落。如果球多次掉出目标区域，游戏结束。祝你玩得愉快。

## 怎么玩

使用鼠标操作游戏，或点击屏幕
