# Cano Bunny

<a href="https://inkwengame.com/zh/games/cano-bunny" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cano-bunny/cover.jpg)

Cano Bunny 是一款 2D 平台游戏，你将扮演一只可爱的兔子，需要收集所有胡萝卜，同时避开乌龟怪物、旋转刀片、尖刺，并抵达黄色旗帜以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
