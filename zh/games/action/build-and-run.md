# 构建和运行

![cover](https://img.inkwengame.com/games/build-and-run/cover.jpg)

《建造与奔跑》是一款刺激的街机游戏，你将在其中穿梭、建造并最终取得胜利！无需下载或注册，即可在各种设备上立即畅玩。在关卡中竞速，建造坡道，并使用各种武器击败敌人。用时尚装备定制你的角色，并在两种模式下享受无穷乐趣！

## 怎么玩

搭建关卡中缺失的部分。

PC/台式机

按 Q 键搭建平台

按 W 键搭建斜坡

按 E 键搭建斜坡

按 R 键使用武器

移动设备

使用屏幕上的按钮
