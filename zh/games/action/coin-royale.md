# 硬币王座

<a href="https://inkwengame.com/zh/games/coin-royale" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coin-royale/cover.jpg)

在《硬币王座》游戏中收集所有散落的硬币并开始赚钱。你可以通过一些数学运算来增加你的金钱。在除法和减法中，你的金钱会减少；而在乘法和加法中，你的金钱会增加。你需要注意一些折扣和税款。途中会出现一些障碍。你应该通过快速进行数学运算来获得最佳收益。你可以用赚到的硬币在市场购买新的硬币角色。尽情享受吧！

## 怎么玩

使用鼠标或触摸板来玩此游戏，也可以在桌面端使用W A S D键或方向键
