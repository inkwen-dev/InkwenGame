# 基科冒险

<a href="https://inkwengame.com/zh/games/kiko-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kiko-adventure/cover.jpg)

Kiko Adventure 是一款基于 HTML5 的冒险平台游戏，如果你喜欢平台游戏，就不要错过这款。由于操作简单，上手容易。在精心设计的关卡中展开旅程，尝试找到所有的水果和瓶子，跳跃并击败危险的敌人。

## 怎么玩

如何游玩 - 按住左右按钮来移动 - 点击跳跃按钮进行跳跃 - 收集关卡中的所有水果 - 收集3个瓶子以开启下一关 - 通过跳跃击败敌人
