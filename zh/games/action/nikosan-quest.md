# Nikosan 任务

<a href="https://inkwengame.com/zh/games/nikosan-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nikosan-quest/cover.jpg)

Nikosan 任务是一款2D平台游戏，你将扮演一位名叫 Nikosan 的动漫女孩，需要收集所有黄色方块，同时避开怪物、尖刺、旋转刀片，并抵达黄色旗帜以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动。连续按两次 W 键或上箭头键可进行二段跳
