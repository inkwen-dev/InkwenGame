# 忍者棍人

<a href="https://inkwengame.com/zh/games/stickman-attack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickman-attack/cover.jpg)

一波又一波的棍人向你涌来，试图耗尽你的意志，等待你犯下第一个错误。作为被选中的棍人，你应该无意识地用功夫将他们打倒。没人知道为什么你是被选中的，也没人知道为什么这些傻瓜会冲向你，只为了在敏感部位挨上一拳。点击白色圆圈来消灭敌人，获得灵魂，并购买新武器。
