# 丛林吉姆

<a href="https://inkwengame.com/zh/games/jungle-jim" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jungle-jim/cover.jpg)

享受这款有趣的全新2D平台游戏。丛林吉姆需要你全部的跳跃和奔跑技巧，才能到达每一关终点的宝箱。途中，打破方块，收集水果和硬币以提升你的分数，同时避开敌人、尖刺和会爆炸的方块。请注意，大蘑菇可以当作蹦床使用。共有7个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

按左或右箭头键移动，按上箭头键跳跃。在桌面端也可以使用WAD键或手柄操作。通过触摸或点击播放按钮开始游戏。在桌面端还可以按D键或手柄上的START键启动游戏。
