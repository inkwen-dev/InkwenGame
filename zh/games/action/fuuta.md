# Fuuta

<a href="https://inkwengame.com/zh/games/fuuta" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fuuta/cover.jpg)

Fuuta 是一款 2D 平台游戏，你需要收集所有口红，同时避开单眼敌对怪物、飞行怪物、钉子，并抵达黄色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
