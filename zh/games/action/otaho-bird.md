# 奥塔霍鸟

<a href="https://inkwengame.com/zh/games/otaho-bird" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/otaho-bird/cover.jpg)

奥塔霍鸟是一款2D平台游戏，你将扮演一只小鸟，需要收集所有面包片，同时避开敌对鸟类、旋转刀片和火焰，抵达出口巢穴以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W键或上箭头键可进行二段跳
