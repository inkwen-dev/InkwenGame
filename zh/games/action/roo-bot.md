# Roo Bot

<a href="https://inkwengame.com/zh/games/roo-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roo-bot/cover.jpg)

Roo Bot 是一款 2D 科幻主题的平台游戏，你需要收集红色能量饮料试管，同时避开敌方机器人、锯子和尖刺，抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
