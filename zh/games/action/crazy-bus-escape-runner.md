# 疯狂巴士逃脱跑酷

<a href="https://inkwengame.com/zh/games/crazy-bus-escape-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-bus-escape-runner/cover.jpg)

在《疯狂巴士逃脱跑酷》中，带领一群无畏的群众穿越混乱的城市道路。滑动或使用键盘躲避危险障碍，招募新跑者，幸存于残酷陷阱，并共同抵达终点。完成五个难度逐渐增加的关卡，保护你的团队，证明你能在每一场狂乱的赛道中活下来。

## 怎么玩

点击或轻触开始 按住并左右拖动以在触摸设备上操控 桌面端使用 A D 键或左右箭头键 招募跑者、避开陷阱、确保领头者存活并抵达终点 选择“下一关”继续，或失败后选择“重新开始”
