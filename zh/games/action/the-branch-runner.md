# 分支奔跑者

<a href="https://inkwengame.com/zh/games/the-branch-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-branch-runner/cover.jpg)

你擅长无尽跑酷类游戏吗？现在有机会玩一款有趣的跑酷游戏，采用3D像素方块风格。你需要通过旋转平台轨道来帮助角色向前奔跑，并避开障碍方块。商店里有许多漂亮的皮肤，只要收集足够的金币，就可以解锁并使用它们！

## 怎么玩

点击屏幕左侧使平台向左旋转，点击屏幕右侧使平台向右旋转
