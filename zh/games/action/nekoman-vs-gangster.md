# 猫人对黑帮

<a href="https://inkwengame.com/zh/games/nekoman-vs-gangster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nekoman-vs-gangster/cover.jpg)

《猫人对黑帮》是一款2D平台游戏，玩家扮演一只猫咪，需要在避开黑帮、锯子的同时收集所有银色钥匙，并抵达出口门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
