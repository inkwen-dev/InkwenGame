# 熊追逐

<a href="https://inkwengame.com/zh/games/bear-chase" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bear-chase/cover.jpg)

在这个平台游戏中，你的任务是通过跳跃在平台上收集礼物以获得分数。但突然间，从你的影子中出现了更多的熊，它们会追着你，你需要避开它们。黑色的熊会追捕你。
