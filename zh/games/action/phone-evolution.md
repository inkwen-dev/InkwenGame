# 手机进化

<a href="https://inkwengame.com/zh/games/phone-evolution" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/phone-evolution/cover.jpg)

这是一款带有3D卡通手机模型和平台轨道的收集进化模拟街机游戏。只要你保持手机比1980年代更现代，到达终点墙时就能完成关卡。蓝色墙壁会将你的手机升级到不同的时间跨度。红色墙壁会将你的手机降级为更老的类型。你是否想在这个游戏中将手机升级到终极类型？

## 怎么玩
