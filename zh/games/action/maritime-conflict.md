# 海上冲突

<a href="https://inkwengame.com/zh/games/maritime-conflict" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/maritime-conflict/cover.jpg)

海上冲突是一款快节奏的海军战略游戏，每一发子弹都至关重要。扫描海洋，预测对手的行动，并发动精准攻击，击沉对方整个舰队。每场对战都是一场紧张刺激的回合制智谋、策略与运气的较量。非常适合喜爱经典战舰风格玩法且追求简洁现代视觉呈现的玩家。

## 怎么玩

在PC上使用鼠标点击网格选择目标并发射炮弹；在移动设备或平板上使用触摸屏轻触单元格进行攻击，击沉敌方船只。
