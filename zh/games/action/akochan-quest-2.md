# Akochan Quest 2

<a href="https://inkwengame.com/zh/games/akochan-quest-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/akochan-quest-2/cover.jpg)

Akochan Quest 2 是一款 2D 动漫风格的平台游戏，你将扮演一名名叫 Akochan 的女孩，需要收集所有的项链，同时避开僵尸、飞舞的心形怪物、旋转刀片、尖刺，并抵达黄色旗帜以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。这是原版《Akochan Quest》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
