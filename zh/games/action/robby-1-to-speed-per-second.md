# 罗比速度+1

<a href="https://inkwengame.com/zh/games/robby-1-to-speed-per-second" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/robby-1-to-speed-per-second/cover.jpg)

在这个游戏中，你的速度每秒都在提升，没有速度上限。成为最快的玩家，以闪电般的速度通过各项挑战。

## 怎么玩

电脑操作：

● WASD - 移动

● 鼠标 - 视角

● 空格键 - 跳跃

● Tab 或 Esc 键 - 启用/禁用光标

手机操作：

● 使用游戏界面

● 任意移动 - 视角

## 介绍

在这个游戏中，你的速度每秒都在提升，没有速度上限。成为最快的玩家，以闪电般的速度通过各项挑战。

游戏共有四个场景，每个场景都有其独特的挑战。

解锁宠物，努力让它们齐聚一堂。

你可以在商店购买角色饰品。
