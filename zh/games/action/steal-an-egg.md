# 偷一个蛋

<a href="https://inkwengame.com/zh/games/steal-an-egg" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/steal-an-egg/cover.jpg)

《偷一个蛋》将经典的偷脑残循环翻转为一场孵化鸡蛋的经济竞赛。支持单人或双人模式，从中央传送带购买神秘蛋，将其运回基地，等待它们孵化成随机的脑残角色！你的阵容越强大，金币生成速度就越快，也就越早能买得起最稀有的蛋。

## 怎么玩

玩家1 移动 W A S D 跳跃 空格键 购买或偷取 E 按击 F 或左键鼠标 快跑 左移位键
玩家2 移动 方向键 跳跃 L 购买或偷取 O 按击 K 快跑 J
