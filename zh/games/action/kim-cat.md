# 金猫

<a href="https://inkwengame.com/zh/games/kim-cat" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kim-cat/cover.jpg)

金猫是一款2D平台游戏，你需要收集并吃掉饼干，同时避开尖刺和敌人，最终到达红色旗帜。游戏中共有8个关卡，随着进度推进难度会逐渐增加。

## 怎么玩

使用WASD或方向键进行移动；连续按两次W键或上箭头键可进行双重跳跃
