# 可爱的熊

<a href="https://inkwengame.com/zh/games/lovely-bear" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lovely-bear/cover.jpg)

这是一款动作跳跃游戏。一只可爱的小考拉宝宝想要去天堂。此时，玩家需要帮助考拉。通过左右移动来抓住弹簧板，使它跳得更高。在左右移动时，要注意不要移动太多，以免让考拉掉下去。如果掉下去了，游戏就结束了。诀窍是左右小范围移动。你可以点击屏幕，然后考拉就会跳起来。孩子们喜欢玩这种动作冒险类游戏。不要错过哦。

## 怎么玩
