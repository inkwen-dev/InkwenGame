# Tenno

Tenno 是一款 2D 平台游戏，你将扮演一名名叫 Tenno 的员工，需要收集被办公室对手偷走的重要文件。在收集文件的过程中，你必须避开敌对的对手、锯齿和尖刺，并抵达办公室门口以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动。连续按两次 W 键或上箭头键可进行二段跳
