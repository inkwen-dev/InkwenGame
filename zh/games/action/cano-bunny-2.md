# Cano Bunny 2

Cano Bunny 2 是一款 2D 平台游戏，你将扮演一只可爱的兔子，需要收集所有胡萝卜，同时避开乌龟怪物及其子弹、旋转刀片、尖刺，并抵达黄色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。这是原版《Cano Bunny》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
