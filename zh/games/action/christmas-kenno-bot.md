# 圣诞肯诺机器人

<a href="https://inkwengame.com/zh/games/christmas-kenno-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-kenno-bot/cover.jpg)

圣诞肯诺机器人是一款2D圣诞主题的平台游戏，你将扮演一个机器人，需要收集绿色礼品盒，同时避开敌对机器人、飞行机器人、它们的子弹、锯子、尖刺，并抵达爱斯基摩人的门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上箭头键可进行二段跳
