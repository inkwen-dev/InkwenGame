# StickJump

<a href="https://inkwengame.com/zh/games/stickjump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickjump/cover.jpg)

StickJump 是一款高速反应游戏，你控制一个 stick figure 在无尽的圆形跑道上奔跑。但不要掉以轻心——障碍物会不断且完全出乎意料地出现，始终试图阻挡你的路径！你的任务非常简单：在正确时机跳跃，精准闪避，并尽可能长时间地奔跑。生存时间越长，速度就越快，挑战也越艰难，让每一刻都充满刺激感。

## 怎么玩

- 使用 W 或上箭头键改变方向 - 按住 S 或下箭头键进行冲刺
