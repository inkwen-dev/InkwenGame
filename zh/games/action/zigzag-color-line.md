# ZigZag 彩色线条

<a href="https://inkwengame.com/zh/games/zigzag-color-line" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zigzag-color-line/cover.jpg)

来回走动，避开与你的线条颜色不同的方块。收集相同颜色的方块以获得分数，同时努力取得高分。尝试两种不同的模式，看看哪种对你来说更容易。在这个有趣的在线街机游戏中，不断 zigzag，直到登上 Lagged 排行榜首位。
