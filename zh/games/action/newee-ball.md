# Newee Ball

<a href="https://inkwengame.com/zh/games/newee-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/newee-ball/cover.jpg)

Newee Ball 是一款 2D 平台游戏，你将扮演一个球，需要在避开敌方球、尖刺、旋转刀片的同时收集棒棒糖，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
