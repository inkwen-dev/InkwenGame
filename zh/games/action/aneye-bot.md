# Aneye Bot

<a href="https://inkwengame.com/zh/games/aneye-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/aneye-bot/cover.jpg)

Aneye Bot 是一款 2D 科幻主题的平台游戏，你将扮演一个带眼睛的机器人，任务是收集所有冰淇淋，同时避开三眼敌方机器人、尖刺和锯齿，最终抵达自己的家。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
