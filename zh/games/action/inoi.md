# Inoi

<a href="https://inkwengame.com/zh/games/inoi" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/inoi/cover.jpg)

Inoi 是一款 2D 平台游戏，你需要在沙漠区域收集水容器，同时避开仙人掌敌人。收集所有水容器并抵达红色旗帜，即可进入下一关。共有 8 个关卡可供挑战，难度适中。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按下 W 键或上箭头键两次可进行二段跳
