# 兔子奔跑冒险

<a href="https://inkwengame.com/zh/games/rabbit-run-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rabbit-run-adventure/cover.jpg)

这是一款可爱的兔子主题的街机冒险游戏。你的任务是帮助兔子跨越平台上的所有障碍，安全抵达终点线。尝试通过所有关卡并赢得游戏。你需要跳过各种形状、动物生物和刀片，或者在某些障碍物下方通过。每关你有三条生命。如果失去一条生命，就必须从游戏开始处重新开始。

## 怎么玩

使用鼠标来玩此游戏，或在移动设备上点击屏幕上的图标进行操作
