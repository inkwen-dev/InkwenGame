# 涂鸦猫

<a href="https://inkwengame.com/zh/games/doodle-cats" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/doodle-cats/cover.jpg)

引导你的涂鸦猫在无尽的平台、道具和敌人世界中不断向上！跳跃、二段跳，并躲避蝙蝠、蜜蜂和幽灵，同时收集硬币以在商店中解锁新的猫咪皮肤、尾迹和升级。在一次游戏中收集3个奖励物品即可触发奖励关卡，在紧张刺激的飞行环节中赚取更多硬币。挑战你的最高分！

## 怎么玩

点击或轻触以跳跃 再次点击或轻触空中可进行二段跳
