# Utoo

<a href="https://inkwengame.com/zh/games/utoo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/utoo/cover.jpg)

Utoo 是一款 2D 平台游戏，你需要收集蓝色方块，同时避开敌人、锯齿和尖刺，抵达出口门。游戏中共有 8 个关卡，难度适中。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
