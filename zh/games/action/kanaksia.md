# Kanaksia

<a href="https://inkwengame.com/zh/games/kanaksia" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kanaksia/cover.jpg)

Kanaksia 是一款 2D 平台游戏，你需要收集所有草莓，同时避开敌人、尖刺、巨型刀片，并抵达红色旗帜以进入下一关。共有 8 个关卡可供游玩，随着进度难度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
