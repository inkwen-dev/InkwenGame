# Stick Runner

<a href="https://inkwengame.com/zh/games/stick-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stick-runner/cover.jpg)

Stick Runner 是一款有趣的在线游戏。游戏中只有一条赛道，不同大小和长度的障碍物会随机出现。小人需要使用底部的两个按钮来跳跃或蹲下以避开障碍物！当然，蹲下的时间是有限制的。当红色进度条消失时，小人将站起来。请注意这一点！

## 怎么玩

使用空格键跳跃，使用方向键滑动
