# 灯泡女友

<a href="https://inkwengame.com/zh/games/the-bulb-girlfriend" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-bulb-girlfriend/cover.jpg)

《灯泡女友》是一款2D平台游戏，你需要收集能量药水瓶，避开红色敌人灯泡、旋转刀片和锯子，抵达粉色女友灯泡以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
