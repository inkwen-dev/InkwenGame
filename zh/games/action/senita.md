# Senita

<a href="https://inkwengame.com/zh/games/senita" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/senita/cover.jpg)

Senita 是一款 2D 平台游戏，你将扮演一位女孩，需要收集所有的巧克力棒，同时避开敌对怪物、飞行生物、尖刺、地面锯片，并抵达粉色旗帜以进入下一关。共有 8 个关卡可供游玩，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
