# 太空跑酷

<a href="https://inkwengame.com/zh/games/space-obby" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-obby/cover.jpg)

一款轻松有趣的太空平台游戏。加入其他勇敢的宇航员，探索一座损毁空间站的各个角落，利用你可靠的喷气背包在漂浮的残骸中穿梭。游戏包含六个可解锁角色和散落在四个大型关卡中的可收集电池——你是否有能力到达终点？

## 怎么玩

目标：探索空间站残骸，收集能量电池以开启通往新关卡的大门并解锁角色。

鼠标和键盘操作：

移动：WASD 或方向键

跳跃：空格键

喷气背包：空中按住空格键

镜头旋转：移动鼠标

镜头缩放：滚轮

设置菜单：P 键

移动设备触控操作：

移动：触摸并拖动屏幕左侧的虚拟摇杆

跳跃：点击屏幕右侧的跳跃按钮

喷气背包：按住屏幕右侧的跳跃按钮

镜头旋转：在屏幕任意位置滑动

镜头缩放：在屏幕任意位置捏合
