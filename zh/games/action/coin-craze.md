# 硬币狂热

<a href="https://inkwengame.com/zh/games/coin-craze" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coin-craze/cover.jpg)

硬币狂热是一款冒险角色扮演游戏，你需要控制一个正在收集硬币的男孩。男孩站在一个移动的平台上，当平台移动到另一个平台上方时，你需要点击或轻触以让他跳上去。如果你错过了下一个平台，平台下方的尖刺将结束男孩的旅程。随着游戏进程推进，你将发现各种神奇物品，帮助你收集越来越多的硬币。
