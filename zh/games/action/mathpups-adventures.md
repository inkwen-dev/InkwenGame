# MathPups Adventures

![cover](https://img.inkwengame.com/games/mathpups-adventures/cover.jpg)

MathPup 今天已经完成数学学习，但仍然饿着肚子想吃狗骨头。帮助 MathPup 收集关卡中的所有狗骨头。之后，MathPup 需要拿到奖杯才能完成每一关。共有 32 关供 MathPup 完成。在每关中拿到奖杯即可完成该关。MathPup 必须先收集完关卡中的所有狗骨头，奖杯才会出现。如果某关卡卡住了…

## 怎么玩

使用 WASD 或方向键移动。在触屏设备上，请使用屏幕上的方向键进行移动

## 介绍

MathPup 今天已经完成数学学习，但仍然饿着肚子想吃狗骨头。帮助 MathPup 收集关卡中的所有狗骨头。之后，MathPup 需要拿到奖杯才能完成每一关。共有 32 关供 MathPup 完成。在每关中拿到奖杯即可完成该关。MathPup 必须先收集完关卡中的所有狗骨头，奖杯才会出现。如果某关卡卡住了，只需点击主菜单上的视频按钮，观看通关视频。
