## 怎么玩

桌面版

WASD/方向键 = 移动角色

鼠标右键（按住并拖动）= 旋转视角

空格键 = 跳跃

鼠标左键 = 攻击

Q = 丢弃脑腐

E = 吸收脑腐

R = 返回基地

Z = 重生

P = 设置

Tab = 慢动作模式

移动版

左摇杆 = 移动角色

向右滑动屏幕 = 旋转视角

跳跃键 = 跳跃

攻击键 = 攻击

丢弃键 = 丢弃脑腐

吸收键 = 吸收脑腐

## 介绍

《奔跑跳跃收集脑腐》是一款快节奏游戏，你的目标是收集脑腐梗图来提升实力。

在平台上跳跃收集脑腐梗图，带回基地强化自身。升级后可以跳得更高，挑战更具难度的区域。
