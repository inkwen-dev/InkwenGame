# 坦克之星战斗竞技场

<a href="https://inkwengame.com/zh/games/tank-stars-battle-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tank-stars-battle-arena/cover.jpg)

坦克之星 - 战斗竞技场是一款采用2D模型的坦克设计策略游戏。在14个关卡中，我们需要你建造坦克以击败所有敌方坦克。只要击败敌方驾驶员，就能赢得战斗。当你获得足够的钻石时，可以在商店打开宝箱获取坦克部件。你最多可以保存3个坦克设计项目。别忘了调整不同部件的位置，它们具有不同的功能。
