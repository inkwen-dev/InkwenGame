# 触摸与跳跃

<a href="https://inkwengame.com/zh/games/touch-and-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/touch-and-jump/cover.jpg)

这是一款你需要点击屏幕来让球在移动的方块平台上弹跳的游戏，这些方块可能会吃掉球。因此你需要小心谨慎，在恰当的时机跳跃，以避开可能摧毁球的方块。球和方块会在平台上左右移动，使游戏更具挑战性。
