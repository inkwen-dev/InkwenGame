# 夜影弓箭

<a href="https://inkwengame.com/zh/games/nightshade-archary" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nightshade-archary/cover.jpg)

探索《夜影弓箭》的弓箭动作世界，体验流畅的模拟与游戏玩法。注意障碍物的存在。在游戏过程中，你只能跳跃到你的箭矢上以到达更高的方块。每一关都有不同的敌人需要应对。你可以用箭矢攻击并摧毁敌人。如果你的身体碰到敌人，你将死亡。本游戏的主要目标是找到‘钥匙’。你需要找到钥匙并收集它，以打开位于关卡末尾的门，从而完成该关卡。

## 怎么玩

如何操作 Android 点击屏幕左侧的左箭头键向左移动；点击屏幕左侧紧邻左箭头键的右箭头键向右移动；点击屏幕右侧的跳跃键进行跳跃
