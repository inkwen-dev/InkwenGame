# 棍子弓箭手对决

<a href="https://inkwengame.com/zh/games/stick-archers-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stick-archers-battle/cover.jpg)

棍子弓箭手对决是一款有趣的1-2人弓箭挑战游戏。通过适应不断变化的环境和物理规则，尝试精准地向对手射出箭矢。在释放箭之前，请预测正确的角度和距离，让箭能够命中你的朋友。你可以以「单人模式」、「双人模式」和「死亡竞赛模式」进行游戏。率先达到5分的一方将赢得比赛。

## 怎么玩

蓝色玩家：W键 或 点击按钮；红色玩家：上箭头键 或 Tab键
