# MiniBattles - 2 3 4 5 6人游戏

<a href="https://inkwengame.com/zh/games/minibattles-2-3-4-5-6-player-games" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minibattles-2-3-4-5-6-player-games/cover.jpg)

众多迷你游戏可供挑战你的朋友，听起来难以置信，但确实存在！最多可支持6名玩家同时参与“全员对战”模式，每场对决中始终只有一名胜利者。通过这款惊人的游戏，你可以与朋友组织锦标赛，因为计分器会显示谁赢得的比赛最多。游戏中包含多种游戏类型，其中包括足球、汽车、战争坦克、相扑、弓箭手、维京人、宇宙飞船等更多内容。

## 怎么玩

单键游戏 玩家1 按 C 键 玩家2 按 N 键 玩家3 按 P 键 玩家4 按 Q 键 玩家5 按 左键 玩家6 按 右键
