# 阿杜冒险

<a href="https://inkwengame.com/zh/games/adou-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/adou-adventure/cover.jpg)

阿杜冒险是一款2D平台游戏，你需要收集宝石，同时避开敌人、旋转刀片和尖刺，抵达出口门以进入下一关。共有8个关卡可供挑战，难度会随着关卡推进而逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上方向键可进行二段跳
