# 梯形2

<a href="https://inkwengame.com/zh/games/trapezio-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/trapezio-2/cover.jpg)

梯形2 是一款 2D 的可爱小平台游戏，你需要收集银币，同时避开敌人、飞行机器人、尖刺和锯子，并到达红色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着关卡推进而逐渐增加。这是原版《梯形》系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
