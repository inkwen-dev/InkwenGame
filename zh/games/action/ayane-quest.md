# あやねクエスト

<a href="https://inkwengame.com/zh/games/ayane-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ayane-quest/cover.jpg)

あやねクエストは、2Dアニメ風のプラットフォームゲームです。あなたはアニメ風の女の子として、モンスター、スパイク、火炎を避けながらすべての魔法の花を集めて、次のレベルに進むための出口のドアに到達する必要があります。全8つのレベルがあり、進行するにつれて難易度が上がります。

## 怎么玩

プレイヤーの移動にはWASDキーまたは矢印キーを使用してください。Wキーまたは上矢印キーを2回押すことでダブルジャンプができます
