## 怎么玩

克服重重障碍，以最快的速度到达终点。第一关包含教程，随着游戏的进行，您将逐步了解一些游戏机制。

直线前进时速度最快。

🖥️ PC 控制：

• A / 🡸 — 向左移动 / 贴墙跑（按住）

• D / 🡺 — 向右移动 / 贴墙跑（按住）

• 空格键 — 跳跃 / 蹬墙

• Shift — 滑行（滑行时仍可左右转向）

• R — 重新开始

📱 手机控制：

点击屏幕任意位置即可调出虚拟摇杆。在摇杆区域内移动并按住手指即可执行以下操作：

• 中心 — 待机（无操作）

• 顶部区域 — 跳跃

• 左侧区域 — 向左移动/贴墙跑（贴墙按住）

• 右侧区域 — 向右移动/贴墙跑（贴墙按住）

• 底部中心 — 滑行

• 左下角 — 滑行 + 向左移动

• 右下角 — 滑行 + 向右移动

您可以在“选项”菜单中调整摇杆大小。
