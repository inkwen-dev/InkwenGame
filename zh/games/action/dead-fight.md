# 死亡对决

<a href="https://inkwengame.com/zh/games/dead-fight" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dead-fight/cover.jpg)

蓝队和红队的战士们在神秘的竞技场中相互对抗。挑战在于摧毁对方队伍的能量石，或击杀对方队伍的玩家。如果你能入侵对手的电脑，就能获得额外力量来击碎特殊石头。你必须在竞技场中快速移动并压制对手。死亡对决支持单人和双人模式，尽情享受吧。

## 怎么玩

游戏控制 红队 移动 AWD 切换角色 TAB 入侵电脑 CTRL 攻击 空格键 蓝队 移动 方向键 切换角色 攻击 NUM0 入侵电脑 NUM1
