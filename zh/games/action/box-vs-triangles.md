# 方块对三角形

<a href="https://inkwengame.com/zh/games/box-vs-triangles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/box-vs-triangles/cover.jpg)

点击右侧或左侧以击中三角形。尽可能多地击碎三角形。你的方块可以获得特殊奖励，帮助你击碎更多三角形。你能击碎多少个三角形？真的吗？我不认为能达到这个分数……这款游戏非常容易上手，但要获得高分却非常困难。
