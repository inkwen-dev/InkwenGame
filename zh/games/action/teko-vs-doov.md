# Teko 对 Doov

<a href="https://inkwengame.com/zh/games/teko-vs-doov" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/teko-vs-doov/cover.jpg)

Teko 对 Doov 是一款 2D 科幻主题的平台游戏，你需要收集银色钥匙，避开敌方机器人、飞行机器人、锯子、地面锯子和尖刺，抵达出口门以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
