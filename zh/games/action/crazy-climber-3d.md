# 疯狂攀爬3D

<a href="https://inkwengame.com/zh/games/crazy-climber-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-climber-3d/cover.jpg)

《疯狂攀爬3D》是一款3D休闲游戏，你需要通过避开障碍物来抵达终点线。游戏玩法非常简单：通过左右移动来避开障碍物，并收集地面上的台阶碎片。你需要将收集到的台阶碎片拼接起来，以跨越大型障碍物。在前进的过程中，你还需要尽可能多地收集黄色钻石，以便购买新角色并继续你的进度。这款游戏包含无限多关卡，也可在移动设备上进行游玩。

## 怎么玩

PC端：向右移动 D键 或 右箭头键；向左移动 A键 或 左箭头键；攀爬 空格键；移动端：向右移动 向右滑动；向左移动 向左滑动；攀爬 点击黑色区域
