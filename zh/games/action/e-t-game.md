# E.T. 游戲

<a href="https://inkwengame.com/zh/games/e-t-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/e-t-game/cover.jpg)

E.T. 遊戲是一款非常有趣且富有挑戰性的2D側滾動遊戲，風格類似於《超級瑪利歐》、《大金剛》和《索尼克》等熱門遊戲。遊戲包含10個關卡，將考驗你完成它的能力。完成所有關卡，幫助E.T. 找到回家的路！遊戲設計色彩豐富且美觀！

## 怎么玩

桌面版 W - 跳躍 A - 向左移動 D - 向右移動 空格鍵 - 激光射擊 移動設備 觸控螢幕按鈕
