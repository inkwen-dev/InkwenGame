# 菜鸟与高手怪物学校

<a href="https://inkwengame.com/zh/games/noob-and-pro-monster-school" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noob-and-pro-monster-school/cover.jpg)

在我们的冒险中，有一个不断追捕你的学校怪物。有时它是一个绿色的怪物，有时又是一个黑色的怪物。你需要逃离学校怪物。学校怪物想要吃掉你。和菜鸟与高手一起逃离学校怪物。在逃跑时，永远、永远不要回头。逃离怪物，收集沿途找到的所有钻石，并到达关卡尽头的传送门。

## 怎么玩

菜鸟 按WASD键移动和跳跃  高手 按方向键移动和跳跃 移动端控制可用
