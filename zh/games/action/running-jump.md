# 奔跑跳跃

<a href="https://inkwengame.com/zh/games/running-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/running-jump/cover.jpg)

奔跑跳跃是一款你需要在平台上跳跃的游戏。你的敌人在平台上巡逻。你只能在跳过他们时才能摧毁他们。你必须快速且谨慎。从底部会升起一个带有尖刺的平台，会伤害你，游戏也会结束。尝试在尖刺到达你之前跳上更多的平台并摧毁更多的敌人。

## 怎么玩

点击屏幕开始游戏
