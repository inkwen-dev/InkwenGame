# 镜像巫师

![cover](https://img.inkwengame.com/games/mirror-wizard/cover.jpg)

镜像巫师是一款复古风格的平台解谜游戏，玩家控制一名拥有瞬移至关卡另一侧能力的巫师。你需要帮助巫师跳跃、避开障碍，并运用魔法翻转位置来完成关卡。

## 怎么玩

桌面端 - 移动 A D 或方向键 - 跳跃 W 上箭头 X 或 I - 瞬移 空格键 U C 或 O 移动端 - 游戏内操作
