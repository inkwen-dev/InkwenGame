# 疯狂重力

<a href="https://inkwengame.com/zh/games/crazy-gravity" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-gravity/cover.jpg)

《疯狂重力》是一款平台休闲游戏，玩家需要操控宇航员克服未知星球上的各种挑战。通关所有关卡并收集所有能量物品，修复你的火箭返回家园。在游戏中，你必须躲避电击机器和尖刺，并探索交替变化的重力来推进关卡。游戏画面色彩丰富，卡通风格，非常精美。总共有15个关卡，随着玩家逐级推进，难度会逐渐增加。

## 怎么玩

在桌面端使用鼠标，在移动设备上使用触摸按钮
