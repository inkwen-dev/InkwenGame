# 动物世界

<a href="https://inkwengame.com/zh/games/animal-world" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-world/cover.jpg)

一个开放世界的沙盒游戏，你可以捕捉和驯服脑萝卜、帕尔蒙斯以及可爱的宠物！建造你的家园，收集资源，并在夜晚怪物的威胁下生存。探索一个广阔的世界，体验昼夜循环，制作武器、护甲和药品，在宝箱或敌人身上找到战利品。驯服生物来帮助你采集资源，并开启无尽的冒险！

## 怎么玩

WASD — 移动；Q — 滚动闪避攻击；左键鼠标 — 攻击；右键鼠标 — 瞄准；鼠标中键 — 缩放；空格键 — 跳跃；Shift — 快跑；E — 互动（例如拾取物品）；1 2 3 a
