# 果冻菲利

<a href="https://inkwengame.com/zh/games/jelly-phil" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jelly-phil/cover.jpg)

果冻菲利是一款2D可爱的平台游戏，你将扮演果冻人，需要收集粉红色果冻，同时避开果冻敌人、锯子，并抵达出口门以进入下一关。游戏中共有8个关卡，随着游戏进行难度会逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上箭头键可进行二段跳
