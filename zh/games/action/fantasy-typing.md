# 幻想打字

<a href="https://inkwengame.com/zh/games/fantasy-typing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fantasy-typing/cover.jpg)

幻想打字将你带入一个魔法世界，在这里，你的打字速度和精准度就是你的武器。探索广阔的幻想领域，与神话生物战斗，并通过快速准确地输入单词来挑战史诗级的Boss。提升你的打字能力，解锁秘密，成为这场激动人心的打字游戏中的英雄。

## 怎么玩

鼠标触摸输入用于界面选择，键盘用于输入文本
