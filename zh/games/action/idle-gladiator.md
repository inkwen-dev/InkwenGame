# Idle Gladiator

<a href="https://inkwengame.com/zh/games/idle-gladiator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/idle-gladiator/cover.jpg)

击败所有敌人并成为胜利者！连接三个或更多相同类型的元素，如果连接的元素匹配，您将获得额外金币；如果元素类型与敌人的目标元素相同，玩家将攻击敌人。游戏中有六个不同的地点，每个地点有五个关卡。您可以使用通关后获得的游戏金币升级您的英雄，并解锁新英雄。您还可以使用宝石购买特殊道具。
