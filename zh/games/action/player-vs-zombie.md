# 玩家对僵尸

<a href="https://inkwengame.com/zh/games/player-vs-zombie" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/player-vs-zombie/cover.jpg)

一名角色在两张地图上使用不同的武器。对抗士兵的10个关卡和对抗僵尸的10个关卡。关卡会逐步开放，难度逐渐增加。通过关卡后会获得金钱，用这些金钱可以购买急救包和手榴弹。你可以在游戏设置中购买手榴弹和急救包。

## 怎么玩

WASD - 移动 E - 使用急救包 Tab - 选择武器 C - 蹲下 Esc - 暂停游戏 R - 重新装填武器 空格键 - 跳跃 G - 使用手榴弹 K - 抛弃武器 左Shift - 快跑
