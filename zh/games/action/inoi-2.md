# Inoi 2

<a href="https://inkwengame.com/zh/games/inoi-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/inoi-2/cover.jpg)

Inoi 2 是一款 2D 简单的平台游戏，你需要避开不同大小的绿色、黄色和红色仙人掌，抵达红色旗帜。在抵达红色旗帜之前，你必须收集所有水容器才能进入下一关。游戏中共有 8 个关卡，随着进程难度逐渐增加。这是原版 Inoi 游戏的续作。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上方向键可进行二段跳
