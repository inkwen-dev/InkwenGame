# 迷你硬币

<a href="https://inkwengame.com/zh/games/mini-coins" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-coins/cover.jpg)

迷你硬币是一款街机游戏，你需要通过跳跃、墙跳、躲避障碍物和敌人来收集关卡中的所有硬币，控制一个小小的 blob 角色。准备好迎接高速通关模式吧！

## 怎么玩

移动设备 - 触摸以跳跃  桌面端 - 按 C 键或左键点击以跳跃
