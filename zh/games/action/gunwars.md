# 枪战

<a href="https://inkwengame.com/zh/games/gunwars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gunwars/cover.jpg)

枪已出鞘，你准备好和朋友一决高下吗？拿起你的武器，开始射击吧。你需要与朋友对抗。选择红色或蓝色玩家，用你的枪射击。击败你的朋友。击中次数最多的一方获胜。空中会飘过一些掉落的气球，找到它们并更换你的武器。记住，每种武器都有其独特的特性，因此每种武器都很强大。

## 怎么玩

红色玩家使用WASD键移动，蓝色玩家使用方向键移动，被击中20次的一方输掉
