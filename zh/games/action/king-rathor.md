# 国王拉索尔

<a href="https://inkwengame.com/zh/games/king-rathor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/king-rathor/cover.jpg)

国王拉索尔是一款2D平台游戏，你将扮演一位国王，必须拯救被敌军士兵俘虏的王后。你需要收集装饰品，同时避开敌军士兵、锯子和尖刺，并将王后从危险中解救出来。游戏中共有8个关卡，随着进度推进难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
