# Tronbot

<a href="https://inkwengame.com/zh/games/tronbot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tronbot/cover.jpg)

Tronbot 是一款 2D 平台游戏，你需要收集电池单元以解锁电力驱动的安全门。游戏中共有 8 个关卡，随着进度推进难度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
