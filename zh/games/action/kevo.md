# Kevo

<a href="https://inkwengame.com/zh/games/kevo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kevo/cover.jpg)

Kevo 是一款 2D 平台游戏，你需要收集钥匙以解锁门，同时避开锯齿、尖刺和敌人。共有 8 个关卡可供挑战，随着进度推进难度会逐渐增加。

## 怎么玩

使用 WASD 或方向键进行移动，连续按两次 W 键或上箭头键可进行二段跳
