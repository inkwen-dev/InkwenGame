# Tuu Bot 2

<a href="https://inkwengame.com/zh/games/tuu-bot-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tuu-bot-2/cover.jpg)

Tuu Bot 2 是一款 2D 科幻主题的平台游戏，你需要收集电池，同时避开敌方机器人、飞行机器人、尖刺、巨型刀刃，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
