# SMod：后台沙盒

<a href="https://inkwengame.com/zh/games/smod-sandbox-in-backrooms" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/smod-sandbox-in-backrooms/cover.jpg)

SMod：Backrooms 沙盒是一款基于沙盒和 Backrooms 的模组式游戏。它是一款实时模拟器，包含敌人生成和关卡挑战。在游戏中，你可以使用传送枪生成敌人、完成任务并搜寻武器。

## 怎么玩

你的任务是尽可能多地消灭怪物😎！积累积分，登上排行榜榜首🏆！尽情享受游戏乐趣😉！

电脑端：

鼠标左键：射击。

Tab键：打开怪物刷新面板。

WASD键：移动角色。

鼠标移动：控制视角。

空格键：飞行和跳跃。

手机端：

左摇杆：移动。

屏幕右侧的跳跃按钮：飞行和跳跃。

屏幕右侧：控制视角。

方框图标：打开怪物刷新面板。

枪图标：射击。
