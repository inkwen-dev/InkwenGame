# 铸铁剑

<a href="https://inkwengame.com/zh/games/cast-iron-sword" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cast-iron-sword/cover.jpg)

这是一款可以完全缓解你日常生活压力的休闲游戏。在游戏中，你可以使用不同形状的磨石打磨剑的原型，根据每一关给出的轨迹按压你的魔法石，使其去除多余材料，让剑呈现出正确的形状。每一次去除都必须按照规定的轨迹进行，否则挑战将失败。

## 怎么玩

根据每一关给出的轨迹按压你的魔法石，使其去除多余的材料，让剑呈现出正确的形状
