# 音符

<a href="https://inkwengame.com/zh/games/music-note" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/music-note/cover.jpg)

扮演音符在平台上跳跃。每次弹跳都会散播色彩，为黑白世界带来生机。

## 怎么玩

点击屏幕或按空格键跳跃，到达终点（钢琴部分）即可获胜。

按 R 键重新开始。

## 介绍
