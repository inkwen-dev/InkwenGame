# HissHop

<a href="https://inkwengame.com/zh/games/hisshop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hisshop/cover.jpg)

HissHope 是一款危险的蛇类游戏。LOL！它们从不会咬你。你只需要点击它们从洞里钻出来的时候，用锤子砸中它们。挑战在于它们出现得非常快，你不能让超过3条蛇溜走而不砸中。

## 怎么玩

点击或轻触以锤击砸中它们
