# Riko 对 Tako

<a href="https://inkwengame.com/zh/games/riko-vs-tako" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/riko-vs-tako/cover.jpg)

《Riko 对 Tako》是一款2D科幻主题的平台游戏，你需要在避开敌方机器人、飞行机器人及其子弹、尖刺、巨型刀刃的同时，收集巧克力球糖果，并抵达终点的环形洞口以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
