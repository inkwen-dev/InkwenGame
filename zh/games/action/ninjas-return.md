# 忍者归来

<a href="https://inkwengame.com/zh/games/ninjas-return" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ninjas-return/cover.jpg)

帮助我们的忍者英雄从邪恶的黑暗忍者手中救出他心爱的妻子！要推进游戏，你必须探索森林，并在每一关中恰好收集3颗粉红色星星。集齐所有星星后，终点处会开启一道魔法传送门，使整个区域飘落樱花花瓣。进入传送门即可进入下一阶段。完成你的旅程，救出最终关卡等待着你的妻子！

## 怎么玩

操作 左右箭头键 向左或向右移动 上箭头键 跳跃越过障碍物 A键 挥动你的剑攻击敌人 S键 投掷你的锁链
