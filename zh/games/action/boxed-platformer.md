# 盒中平台游戏

<a href="https://inkwengame.com/zh/games/boxed-platformer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boxed-platformer/cover.jpg)

盒中平台游戏是一款儿童平台游戏。作为玩家，你的任务是控制小角色收集所有的星星。从一个平台跳到另一个平台并收集星星。障碍物会突然出现在游戏屏幕上，你需要避开它们，因为它们可能会伤害你。你有三条生命来玩游戏。通过关卡，享受乐趣。

## 怎么玩

点击屏幕即可开始游戏
