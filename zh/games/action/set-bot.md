# 设置机器人

<a href="https://inkwengame.com/zh/games/set-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/set-bot/cover.jpg)

设置机器人是一款2D科幻主题的平台游戏，你将扮演一个机器人，需要收集红色科技球，同时避开敌方机器人、飞行机器人、尖刺和巨型刀刃，抵达出口门以进入下一关。共有8个关卡可供挑战，随着进程难度逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W键或上箭头键可进行二段跳
