# 计数与弹跳

<a href="https://inkwengame.com/zh/games/count-and-bounce" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/count-and-bounce/cover.jpg)

计数与弹跳是一款球类益智游戏。它会引导小球前进。松开手后，小球将继续向前移动。你需要转动方块，防止小球掉落。一些方块上会有计算题目，你需要根据手中小球的数量选择最佳的方块进行弹跳。尽情享受吧！

## 怎么玩

在电脑上 滑动以旋转并左右引导 在手机和平板上 触摸屏幕并向左或向右拖动
