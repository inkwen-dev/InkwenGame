# 方程拍打

<a href="https://inkwengame.com/zh/games/equation-flapping" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/equation-flapping/cover.jpg)

这款游戏结合了技巧和数学推理。点击屏幕使小鸟飞得更高，穿过树木，避免与它们碰撞，但你必须根据显示的数学乘法选择正确的数字。
