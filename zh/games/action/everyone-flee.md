# 所有人逃离

<a href="https://inkwengame.com/zh/games/everyone-flee" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/everyone-flee/cover.jpg)

你必须确保每个人都能成功逃离！但要注意，你的操作会作用于所有人。以一种所有人都能安全抵达门口的方式移动所有玩家。如果有一人无法到达，那么所有人都将失败，请务必留意这一点。

## 怎么玩

使用WASD键移动，避开障碍物。你也可以使用方向键进行移动
