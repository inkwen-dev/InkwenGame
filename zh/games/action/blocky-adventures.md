# Blocky Adventures

<a href="https://inkwengame.com/zh/games/blocky-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocky-adventures/cover.jpg)

Blocky Adventures 是一款快速的平台游戏，每一次跳跃都至关重要。引导你的小方块英雄穿越五个截然不同的世界中的50个关卡，从冰冻洞穴到炽热火山，还有为最勇敢玩家准备的秘密超大关卡。收集能量光球，避开巡逻和飞行的敌人，并在竞速模式中与时间赛跑。你能否征服全部50个关卡并揭开秘密世界的面纱？

## 怎么玩

键盘 - 移动 使用方向键或 A D - 跳跃 空格键、W 键或上箭头 - 冲刺 X 键或 Shift 键 - 双重跳跃 在空中再次按下跳跃键 - 墙壁跳跃 沿墙壁滑下后跳跃以攀爬  手机 触屏按钮 左右移动、跳跃和冲刺 游戏手柄
