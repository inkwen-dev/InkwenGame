# 迷你方块生存战

<a href="https://inkwengame.com/zh/games/minicraft-bedwars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minicraft-bedwars/cover.jpg)

在生存战模式中，保护好自己的床并摧毁朋友的床怎么样？选择红色或蓝色队伍。尽快收集金币，并用收集到的金币购买炮弹来装填你的炮台。从炮台发射炮弹击中朋友的床。你可以收集自己和朋友的金币。集齐所有金币并购买炮弹。记住，如果射击失误，你将耗尽炮弹而输掉游戏。你必须非常小心。

## 怎么玩

红色玩家使用WASD键移动，蓝色玩家使用方向键移动，按下向下箭头键和S键来发射和购买炮台
