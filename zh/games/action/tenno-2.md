# Tenno 2

<a href="https://inkwengame.com/zh/games/tenno-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tenno-2/cover.jpg)

Tenno 2 是一款 2D 平台游戏，你将扮演一名名叫 Tenno 的员工，需要收集被办公室对手偷走的重要文件。在收集文件的过程中，你必须避开敌对的对手、飞行机器人、锯子、尖刺，并抵达办公室门口以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。这是原版 "Tenno" 系列的第二部作品。

## 怎么玩

使用 WASD 或方向键控制玩家移动；按两次 W 键或上箭头键可进行二段跳
