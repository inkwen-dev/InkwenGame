# 幽灵森林跑酷

<a href="https://inkwengame.com/zh/games/spooky-forest-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spooky-forest-run/cover.jpg)

你去森林里散步，但突然一个可怕的骷髅开始追你。在森林中奔跑以逃离骷髅。点击屏幕来跳过障碍物和其他角色。如果骷髅抓住你，游戏就结束了！

## 怎么玩

鼠标点击或轻触屏幕进行游戏 双击可二段跳
