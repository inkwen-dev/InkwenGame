# 剑与混乱

<a href="https://inkwengame.com/zh/games/blade-and-bedlam" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blade-and-bedlam/cover.jpg)

剑与混乱是一款紧张刺激的俯视角近战游戏，以基于物理的剑术为核心。使用你的剑进行格挡、闪避和攻击敌人。随着关卡推进，面对越来越具挑战性的对手。在求生之旅中，通过强大的道具和独特的技能强化你的骑士。你能否击败所有的首领波次？

## 怎么玩

使用WASD键移动，用鼠标右键挥砍剑。按Shift键进行闪避翻滚，左键释放武器特殊技能
