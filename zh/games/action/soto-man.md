# Soto Man

<a href="https://inkwengame.com/zh/games/soto-man" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soto-man/cover.jpg)

Soto Man 是一款 2D 简单平台游戏，你将扮演超级英雄 Soto Man，需要收集被偷走的红色宝石，同时避开敌人、机器人、尖刺，并抵达通往下一关的魔法洞穴。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
