# 猎人史蒂夫

<a href="https://inkwengame.com/zh/games/hunter-steve" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hunter-steve/cover.jpg)

猎人史蒂文需要追捕所有的怪物。拿起你的武器，追捕所有怪物。小心，有些怪物更强，更难杀死。但当然，你可以购买更强大的武器来消灭它们。去商店，获得更强大的武器，然后追捕所有怪物。

## 怎么玩

使用WASD键移动，使用鼠标左键射击。消灭所有僵尸并完成任务
