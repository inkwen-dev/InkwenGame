# 相扑派对

<a href="https://inkwengame.com/zh/games/sumo-party" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sumo-party/cover.jpg)

想来点有趣的相扑摔跤游戏吗？在这款游戏中，你可以体验单人模式或双人模式，享受令人惊叹的3D图形和传统的相扑摔跤音效。你将使用 "W, A, S, D" 和 "方向键" 来控制相扑选手。如果按一次按钮，你的选手会朝该方向移动；如果快速连续按两次，你的选手将在该方向执行特定动作。
