# 好友对决 刀剑出鞘

<a href="https://inkwengame.com/zh/games/friends-battle-swords-drawn" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/friends-battle-swords-drawn/cover.jpg)

在《好友对决》系列的第三集里，刀剑已经出鞘，战争即将开始。战斗打响；磨利你的剑，你需要一把锋利的刀刃。与你的朋友一起，谁夺得旗帜次数最多，谁就获胜。获胜者必须在旗帜处停留20秒。别忘了，你有一把剑，还需要设置自己的旗帜。在设置旗帜时，你必须抵达敌方的旗帜位置。用剑杀死你的朋友并夺取旗帜。

## 怎么玩

红色玩家使用WASD键移动 蓝色玩家使用方向键移动 在旗帜处停留20秒 你可以按S键和向下箭头键来击杀敌人
