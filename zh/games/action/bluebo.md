# Bluebo

![cover](https://img.inkwengame.com/games/bluebo/cover.jpg)

Bluebo 是一款 2D 平台游戏，你需要收集所有宝石，避开敌人和尖刺，并抵达终点旗帜。共有 8 个关卡可供游玩。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
