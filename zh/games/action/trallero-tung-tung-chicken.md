# Trallero Tung Tung 鸡

<a href="https://inkwengame.com/zh/games/trallero-tung-tung-chicken" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/trallero-tung-tung-chicken/cover.jpg)

你进入农民的世界了吗？你需要抓住鸡。抓住所有的鸡并赢得游戏。第一个收集到10只鸡的人获胜。选择一位农民角色，Trallero 或 Tung Sahur，与你的朋友比赛来取胜。你可以通过跳跃来打破木箱。连续跳三次以打破箱子并抓到鸡。在你的朋友之前收集所有鸡。尽快把鸡带回鸡舍。

## 怎么玩

使用 WASD 和方向键移动。第一个收集到10只鸡并带回鸡舍的玩家获胜。连续跳三次以打破木箱并获得鸡。可在移动设备和 PC 上游玩
