# 心星

<a href="https://inkwengame.com/zh/games/heart-stars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/heart-stars/cover.jpg)

心星是由Adventure Islands开发的一款解谜游戏。改变你周围的环境吧！在心星中，你可以控制两个角色，通过操作与他们各自颜色相关联的游戏物体，使他们在每一关到达终点区域。在女孩和男孩之间切换，谨慎移动并改变房间布局。通过团队合作，征服每一关！

## 怎么玩

移动 - WASD 或 方向键 切换角色 - C 跳跃 - X
