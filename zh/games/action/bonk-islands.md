# 邦克群岛

![cover](https://img.inkwengame.com/games/bonk-islands/cover.jpg)

一路爆破、弹跳、碰撞，最终赢得胜利！《Bonk Islands》是一款色彩缤纷的物理战斗游戏，四位个性鲜明的战士将在漂浮于不断上涨的熔岩之上的岛屿上展开激战。发射火箭，摧毁可破坏的地形，用奇特的武器将对手击飞。稳住阵脚，躲避危险，成为最后的幸存者。每场战斗后都能获得金币，用滑稽的帽子、服装和配饰来装扮你的角色。

## 怎么玩

选择武器，然后向后拖动并松开瞄准。按下“开始”键即可发动攻击！

使用“跳跃”键并拖动，即可在开火前进行跳跃（可选）。部分武器需要您在地图上选择位置，而非直接瞄准。

将对手击落岛屿，同时注意避开熔岩。看着地形崩塌，熔岩升腾——最终的幸存者获胜！
