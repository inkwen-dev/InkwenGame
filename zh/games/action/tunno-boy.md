# 隧道男孩

<a href="https://inkwengame.com/zh/games/tunno-boy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tunno-boy/cover.jpg)

隧道男孩是一款2D可爱的小小平台游戏，你需要收集所有的蓝色魔法球，避开敌人、飞行怪物、尖刺，并到达出口门以进入下一关。共有8个关卡可供游玩，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制玩家移动；连续按两次W或上箭头键可进行二段跳
