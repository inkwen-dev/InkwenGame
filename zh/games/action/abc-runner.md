# ABC 跑者

<a href="https://inkwengame.com/zh/games/abc-runner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/abc-runner/cover.jpg)

ABC 跑者是一款结合打字的竞速游戏。当你输入正确答案时，就可以通过，继续跑向下一个跑步段落。开始游戏时，随机选择26个字母中的任意一个作为第一个字母，你需要组合问题，回答的答案必须是答案的第一个字母。你准备好了吗？

## 怎么玩

打字或点击开始游戏
