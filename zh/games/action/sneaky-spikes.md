# 狡猾的尖刺

<a href="https://inkwengame.com/zh/games/sneaky-spikes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sneaky-spikes/cover.jpg)

《狡猾的尖刺》是一款在笔记本纸上绘制的恶搞平台游戏。地板会下落，尖刺会弹出，门会咬人，而一个讽刺的旁白会在每次死亡时进行评论。完成一页后，你所有的死亡瞬间重播，组成一场死亡游行。共60个关卡，可收集星星，还有速通计时器。如何游玩：奔跑并跳跃，到达每一页尽头的门。做好意外的准备：留意陷阱，从每次死亡中学习，然后再次尝试。

## 怎么玩

桌面端使用方向键或A D移动，空格键、W键或上方向键跳跃，P键暂停。移动端使用屏幕上的方向键和跳跃按钮
