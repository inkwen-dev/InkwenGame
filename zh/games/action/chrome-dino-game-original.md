Chrome 恐龙游戏是一款无尽的横版跑酷游戏：跳跃和下蹲躲避仙人掌和翼龙，冲击高分，并在游戏崩溃后通过奖励广告获得额外生命。忠实还原 Chrome 霸王龙的经典玩法。

## 怎么玩

按空格键、上方向键或轻点屏幕即可跳跃。向下方向键可以躲避飞行中的翼龙。在速度不断提升的过程中尽可能长时间地生存下去。坠落后，观看奖励广告可获得一条额外生命，然后按空格键或轻点屏幕即可再次奔跑。
