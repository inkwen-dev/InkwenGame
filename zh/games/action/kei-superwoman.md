# Kei 超级女英雄

<a href="https://inkwengame.com/zh/games/kei-superwoman" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kei-superwoman/cover.jpg)

Kei 超级女英雄是一款2D平台游戏，你将扮演Kei，这位超级女英雄，需要为被关在安全门后的平民收集汉堡。你必须在避开尖刺、锯子、地面锯子、敌人的情况下收集所有汉堡，并到达安全出口门以进入下一关。共有8个关卡可供挑战，随着关卡推进难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
