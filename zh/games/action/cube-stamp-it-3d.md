# 立方体印章 3D

<a href="https://inkwengame.com/zh/games/cube-stamp-it-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cube-stamp-it-3d/cover.jpg)

这是一款供你游玩的立方体跳跃街机游戏。拥有3D立方体和平台，你需要在赛道上收集与你的立方体数量相同的立方体，到达终点平台。黑色平台会减少你当前的一个立方体。只有当你收集完所有立方体并跳上终点平台时，才能赢得对应关卡！

## 怎么玩

拖动以移动立方体
