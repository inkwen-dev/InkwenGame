# Stickman Picker Master

<a href="https://inkwengame.com/zh/games/stickman-picker-master" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickman-picker-master/cover.jpg)

Stickman Picker Master 是一款 stickman 跑酷游戏，你在海面上方的赛道上高速前进，尝试收集相同颜色的球。如果你收集到相同颜色的球，你的 stickman 角色会变大；但如果你收集到不同颜色的球，你的 stickman 角色会变小。

## 怎么玩

PC 左右移动 滑动鼠标 移动设备 左右移动 滑动手指
