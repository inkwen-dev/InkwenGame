# 猎人之弓游戏

<a href="https://inkwengame.com/zh/games/archer-huntsman-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/archer-huntsman-game/cover.jpg)

猎人之弓是一款有趣的对战街机游戏。你可以选择跑酷狩猎模式或无尽突破模式。在跑酷狩猎模式中，你需要在时间限制内凭借技巧生存到最后。在无尽模式中，你需要保护国王，如果国王死亡，你也会失败。你可以使用通关奖励来解锁新角色和技能。尽情享受吧！
