# Kaido

<a href="https://inkwengame.com/zh/games/kaido" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kaido/cover.jpg)

Kaido 是一款 2D 的可爱小平台游戏，你需要收集所有的橙色冰淇淋棒，同时避开戴着帽子、旋转刀片、尖刺的敌人，并抵达粉色旗帜以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
