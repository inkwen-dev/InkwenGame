# 椰子人

<a href="https://inkwengame.com/zh/games/cocoman" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cocoman/cover.jpg)

椰子人是一款2D萌系小平台游戏，你需要收集椰奶瓶作为能量来源，同时避开敌人、旋转刀片、巨型刀片、尖刺，并抵达出口门以进入下一关。共有8个关卡可供挑战，难度会随着进程逐渐提升。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
