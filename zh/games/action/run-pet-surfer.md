# 跑宠物冲浪者

<a href="https://inkwengame.com/zh/games/run-pet-surfer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/run-pet-surfer/cover.jpg)

宠物跑者是一款无尽奔跑类手机游戏。通过建造来解锁更多宠物角色。与你的宠物一起奔跑和跳跃，避开道路上的障碍物。收集各种物品，如硬币、分数、弹性鞋、喷气背包、磁铁和加速包。随着速度加快，快速切换可获得更多硬币和分数。通过游戏内进度可解锁多种服装，玩家还可以收集特定物品。
