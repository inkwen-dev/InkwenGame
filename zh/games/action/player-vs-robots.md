# 玩家对机器人

<a href="https://inkwengame.com/zh/games/player-vs-robots" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/player-vs-robots/cover.jpg)

玩家对机器人是一款第一人称射击游戏。拯救世界免受机器人的侵害。游戏包含三种难度模式，每种模式有10个关卡。你可以购买急救包和武器。在设置中，你可以开启/关闭音效，调整鼠标灵敏度。

## 怎么玩

移动- 方向键或WASD 跳跃 - 空格键 射击 - 左键瞄准 - 右键 暂停 - Tab 键 快跑 - Shift WASD 急救包 - F
