# Slope Cyber

<a href="https://inkwengame.com/zh/games/slope-cyber" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slope-cyber/cover.jpg)

Slope Cyber 是一款在赛博游戏类型中的无尽斜坡游戏。你必须在赛博城市中控制一个斜坡球。球在移动，你需要有出色的反应能力来操控它。

## 怎么玩

PC 按 A D 或左右箭头键来左右转向 移动端 用手指滑动
