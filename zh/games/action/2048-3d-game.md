# 2048 3D 游戏

<a href="https://inkwengame.com/zh/games/2048-3d-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/2048-3d-game/cover.jpg)

2048 3D 是一款有趣的跑酷游戏，游戏中有小小的数字球。控制你的球很简单，只需滑动即可操控，当遇到相同数字的球时，它们会合并成一个更高数字的球。注意道路上的障碍物，它们会使你的球变小！合并的数字越大，得分越高。尽情享受吧！

## 怎么玩

鼠标点击或轻触开始游戏
