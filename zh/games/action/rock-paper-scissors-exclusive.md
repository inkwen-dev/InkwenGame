## 怎么玩

P1 使用 A S D 键，P2 使用左、下和右方向键 -------------------------------- A 是 P1 的石头，S 是 P1 的纸，D 是 P1 的剪刀 --------------------------------- 左方向键是 P2 的石头，下方向键是 P2 的纸
