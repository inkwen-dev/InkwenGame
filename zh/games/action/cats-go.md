# 猫咪出发！

![cover](https://img.inkwengame.com/games/cats-go/cover.jpg)

《猫咪快跑！》是一款障碍赛类游戏。游戏中，你将扮演一只猫咪，穿越地图，最终到达鱼儿所在的位置。这款硬核平台游戏将挑战你的极限，你能通关吗？猫咪们正等着你，勇往直前！

## 怎么玩

游戏的目标是到达鱼的所在位置！

在手机和电脑上，你需要按下屏幕上的按钮才能跳跃。
