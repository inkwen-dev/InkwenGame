# 光明节

<a href="https://inkwengame.com/zh/games/hanuka" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hanuka/cover.jpg)

《光明节》是一款2D平台游戏，玩家扮演一位可爱又擅长运动的女孩，需要收集所有红色球体，同时避开敌人、尖刺、飞行生物、旋转刀片，并抵达出口门以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
