# 胖肯

<a href="https://inkwengame.com/zh/games/fatty-ken" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fatty-ken/cover.jpg)

胖肯是一款2D平台游戏，你需要收集哑铃，避开敌人、地面锯子、尖刺，并抵达终点旗以进入下一关。共有8个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W或上箭头键可进行二段跳
