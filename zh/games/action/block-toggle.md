# 方块切换

<a href="https://inkwengame.com/zh/games/block-toggle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-toggle/cover.jpg)

方块切换是一款解谜平台游戏，你需要开启或关闭方块以到达出口传送门。

## 怎么玩

菜单选择 Enter 或空格键 移动 WASD 或方向键 切换方块 123 或鼠标左右键 重置 R 返回 Esc 或 B
