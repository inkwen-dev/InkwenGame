# 像素战斗向上

<a href="https://inkwengame.com/zh/games/pixel-battle-upward" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-battle-upward/cover.jpg)

在这个冒险中，我们必须避开熔岩，并把敌人推入熔岩中。你准备好和朋友一起玩这个有趣的躲避熔岩游戏了吗？谁掉进熔岩里谁就输。为了不掉进熔岩，你必须躲避你的朋友。逃离你的朋友，或者把他们推入熔岩。小心从天而降的火箭。这些火箭会杀死你。在120秒内，掉进熔岩或死亡次数最多的玩家输掉比赛。和朋友一起玩，努力击败他们。

## 怎么玩

按 S 键或向下箭头键来推动或撞击。120秒内得分最高的玩家获胜。使用 WASD 键或方向键移动
