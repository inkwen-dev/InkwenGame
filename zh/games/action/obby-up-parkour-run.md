# Obby Up：跑酷跑

<a href="https://inkwengame.com/zh/games/obby-up-parkour-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/obby-up-parkour-run/cover.jpg)

《Obby Up：跑酷奔跑》是一款色彩缤纷的3D平台冒险游戏，融合了体型变化元素。奔跑跳跃，穿越高耸的障碍赛道；缩小身形挤过狭窄空间；变大身形挑战更大的障碍。抵达检查点，收集金币，发现支线挑战，并用服装和宠物装扮你的跑酷角色。选择你的路线，把握每次跳跃的时机，看看你能爬多高！

## 怎么玩

通过穿越平台和避开陷阱，到达障碍赛道的顶端。激活检查点以保存进度，并根据路线需要使用大小滑块来缩小或放大。沿途收集金币并探索支线挑战。如果掉落，请返回检查点并重新尝试。观看奖励视频可解锁额外的道具、宠物和服装。

桌面版操作

- WASD 或方向键：移动。

- 空格键：跳跃；当可用时，在空中再次按下空格键可进行二段跳。

- 点击并拖动视角区域：环顾四周。

- 拖动大小滑块：缩小或放大。

- E 键或屏幕上的锤子按钮：装备锤子后进行攻击。

- Esc 键：暂停或继续游戏。

- 使用屏幕上的按钮激活道具和打开设置。

移动版操作

- 拖动左摇杆移动。

- 滑动视角区域环顾四周。

- 点击跳跃或锤子按钮执行当前操作。

- 拖动大小滑块缩小或放大。

- 使用设置按钮控制音乐和音效。

横屏模式下播放。购买项目为可选项目，仅在平台支持时提供。
