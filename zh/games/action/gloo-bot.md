# Gloo Bot

<a href="https://inkwengame.com/zh/games/gloo-bot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gloo-bot/cover.jpg)

Gloo Bot 是一款 2D 科幻主题的平台游戏，你将扮演一个机器人，需要收集所有电池单元，同时避开敌方机器人、飞行机器人、尖刺，并抵达你的机器人之家以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
