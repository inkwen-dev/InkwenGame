# Soosiz

<a href="https://inkwengame.com/zh/games/soosiz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soosiz/cover.jpg)

在这个游戏中，你控制角色在围绕你的世界中移动。当你在地形上移动时，角色会通过重力紧贴地面——利用这一点优势从一个平台移动到下一个平台。这是一款有趣的探索冒险游戏，尽情享受吧！

## 怎么玩

左键 向左移动 右键 向右移动 空格键 跳跃 或使用触摸控制来无需键盘游玩
