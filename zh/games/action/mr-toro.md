# 托罗先生

<a href="https://inkwengame.com/zh/games/mr-toro" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mr-toro/cover.jpg)

《托罗先生》是一款2D平台游戏，你需要在躲避敌人、尖刺和锯齿的同时收集金钱，并抵达红色旗帜以进入下一关。游戏中共有8个关卡，随着进度推进难度逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上方向键可进行二段跳
