# 鸡尾酒奔跑

<a href="https://inkwengame.com/zh/games/cocktail-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cocktail-run/cover.jpg)

《鸡尾酒奔跑》是一款为快速街机乐趣打造的2D像素平台游戏。奔跑、跳跃并躲避危险的尖刺或射击植物，安全抵达终点。沿途收集硬币，在商店解锁独特的角色皮肤，并领取每日奖励。完全优化适用于PC和移动设备。

## 怎么玩

PC 使用 A D 键或左右箭头键移动，空格键 W 或上箭头键跳跃；移动设备 使用屏幕上的触摸按钮进行移动和跳跃
