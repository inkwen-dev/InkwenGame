## 怎么玩

单人游戏操作：

WASD — 移动

J — 攻击

K — 特殊技

后 + K — 第二特殊技

S + J — 上勾拳

长按 S — 防御

双人游戏（同一台电脑）操作：

玩家 1：WASD + F（攻击），G（特殊技）

玩家 2：IJKL + :（冒号）（攻击），"（引号）（特殊技）

连击：

在合适的时机按下攻击键即可继续连击。跳到敌人身后攻击——这将触发空中攻击。

战术：

合理分配体力，及时防御，并使用破防技来摆脱连击。赢得胜利即可获得金币，解锁新的斗士！
