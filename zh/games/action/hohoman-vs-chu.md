# Hohoman 对决 Chu

<a href="https://inkwengame.com/zh/games/hohoman-vs-chu" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hohoman-vs-chu/cover.jpg)

Hohoman 对决 Chu 是一款 2D 可爱的小型平台游戏，你需要收集所有苹果，同时避开敌人、尖刺、地面锯片，并抵达出口门以进入下一关。游戏中共有 8 个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
