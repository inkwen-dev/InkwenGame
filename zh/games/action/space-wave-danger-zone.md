# 太空波：危险区域

<a href="https://inkwengame.com/zh/games/space-wave-danger-zone" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-wave-danger-zone/cover.jpg)

你的星系遭到攻击，作为勇敢的战士，你跳上飞船以抵御敌人的进攻，为整个世界带来和平。- 你需要击败8个各不相同的特殊敌人，它们拥有各自的能力，有的会射击，有的会从你背后靠近 - 每10波会出现一个独特的首领 - 如果你厌倦了飞船的外壳，可以更换它，其颜色和形状均可不同，并且具有不同的稀有度

## 怎么玩

使用 WASD 或方向键控制飞船转向，使用鼠标购买升级

## 介绍

你的星系遭到攻击，作为勇敢的战士，你跳上飞船以抵御敌人的进攻，为整个世界带来和平。- 你需要击败8个各不相同的特殊敌人，它们拥有各自的能力，有的会射击，有的会从你背后靠近 - 每10波会出现一个独特的首领 - 如果你厌倦了飞船的外壳，可以更换它，其颜色和形状均可不同，并且具有不同的稀有度
