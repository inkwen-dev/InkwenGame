# 滑板冒险

<a href="https://inkwengame.com/zh/games/skateboard-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skateboard-adventures/cover.jpg)

用你的滑板奔跑，避开想要杀死你的剑。点击屏幕来跳跃并躲过剑。有两把剑，分别来自上方和下方。你最多可以在空中跳跃六次，因此需要小心，并注意剑的位置。
