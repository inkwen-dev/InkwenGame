# Nanychan 对战幽灵

<a href="https://inkwengame.com/zh/games/nanychan-vs-ghosts" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nanychan-vs-ghosts/cover.jpg)

Nanychan 对战幽灵是一款2D万圣节主题的平台游戏，你需要收集红色球体，同时避开南瓜、幽灵、尖刺和火焰，抵达出口门以进入下一关。共有8个关卡可供挑战，随着关卡推进，难度逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
