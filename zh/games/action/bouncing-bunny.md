# 弹跳兔子

<a href="https://inkwengame.com/zh/games/bouncing-bunny" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bouncing-bunny/cover.jpg)

这只跳跃的兔子饿了。它需要在平台之间跳跃以到达胡萝卜。有时它必须穿过会破碎的玻璃表面，无法长时间停留在上面。引导兔子安全地通过各个关卡，抵达它的胡萝卜。
