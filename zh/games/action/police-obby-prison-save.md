# 警察障碍赛监狱救援

在这个冒险中，你伪装成一名警察，正在从监狱中营救你的朋友们。找到所有朋友，并将他们送入直升机。你需要从监狱中救出你的朋友。确保你的朋友们进入直升机后，再逃离守卫的追捕。你需要逃离监狱。要成功逃脱，必须到达汽车并进入车内。

## 怎么玩

使用WASD键移动。营救3位朋友并收集所有的铁条。安全抵达关卡终点的汽车
