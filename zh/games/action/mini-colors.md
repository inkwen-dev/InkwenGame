# 迷你色彩

<a href="https://inkwengame.com/zh/games/mini-colors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-colors/cover.jpg)

迷你色彩是一款解谜游戏，你需要开启或关闭彩色平台，以到达你心爱的人；游戏灵感来自一些复古游戏，具有极简风格。游戏包含36个关卡，每个关卡都有不同的谜题，以及竞速模式。

## 怎么玩

桌面端 - 按 X 键、空格键或左键点击以切换重力；移动端 - 触摸屏幕以切换重力
