# Retoena 2

<a href="https://inkwengame.com/zh/games/retoena-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/retoena-2/cover.jpg)

Retoena 2 是一款 2D 科幻主题的平台游戏，玩家扮演一名类人女孩，需要收集蓝色能量方块，同时避开红色和绿色的敌方机器人、飞行机器人、子弹、尖刺和锯齿，并抵达基地以进入下一关。游戏中共有 8 个关卡，难度随着进程逐渐增加。这是原版《Retoena》系列的第二部作品

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
