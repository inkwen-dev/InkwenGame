# 跳跃爆炸房间

<a href="https://inkwengame.com/zh/games/jump-boom-room" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jump-boom-room/cover.jpg)

在这个游戏中，你的任务是收集钻石，但会遇到一些障碍物。你需要避开炸弹，在炸弹爆炸前跳开并躲藏。尽可能多地收集钻石，你还可以解锁拥有双跳能力的玩家，这样就能更容易地拿到更高的钻石并获得额外分数。
