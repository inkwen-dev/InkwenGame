# 失落的鸡

<a href="https://inkwengame.com/zh/games/the-lost-chicken" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-lost-chicken/cover.jpg)

《失落的鸡》是一款3D街机游戏，玩家需在旋转的螺旋平台间撞击、碰撞和弹跳，以抵达终点。听起来简单吗？你可别想太多！！你的小鸡像砖块一样撞碎五彩斑斓的树木，阻挡它的下落，但一旦撞上树木，游戏就结束了！你的小鸡会四分五裂，你必须重新开始坠落过程。
