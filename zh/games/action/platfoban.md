# Platfoban

<a href="https://inkwengame.com/zh/games/platfoban" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/platfoban/cover.jpg)

你需要收集每一关的所有硬币。游戏中有两种模式：平台模式，你可以跑和跳；以及推箱子模式，你可以移动箱子、硬币等。在推箱子模式下，宝箱中的怪物会醒来，攻击并追击主角。在平台模式下，宝箱处于睡眠状态，可以作为平台使用。

## 怎么玩

wasd - 移动 空格键 - 闲置 q 或 shift - 切换模式
