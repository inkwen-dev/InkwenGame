# Splatcha!

<a href="https://inkwengame.com/zh/games/splatcha" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/splatcha/cover.jpg)

SPLATCHA! 是一场快速、充满活力的领土涂鸦对决。两个圆滚滚的对手，一个竞技场，90秒内覆盖最多地面者获胜！模式：双人本地对战、单人对战电脑（3种难度）、街机塔模式。在5个独特的竞技场中战斗，收集道具，打开金色宝箱并存活下来。保证有彩带！

## 怎么玩

操作方式 玩家1 使用 WASD 移动 middot 按住以自动涂色 middot 空格键冲刺 玩家2 使用方向键 middot 0 键或回车键冲刺 支持手柄 移动端请横屏触摸操作 P 键暂停 middot 音效
