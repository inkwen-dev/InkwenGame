# 防御植物

<a href="https://inkwengame.com/zh/games/defense-plants" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/defense-plants/cover.jpg)

在《防御植物》这款策略塔防游戏中，用强大的植物抵御一波又一波危险怪物的进攻。选择你的植物，谨慎放置，收集资源，解锁升级，并在越来越具挑战性的关卡中生存下来。

## 怎么玩

在桌面端使用鼠标，在移动端使用触摸操作。选择一种植物后，点击或轻触战场来放置它。使用屏幕上的按钮来管理植物、道具、升级以及暂停游戏
