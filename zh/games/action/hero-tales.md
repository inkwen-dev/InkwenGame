# 英雄传说

<a href="https://inkwengame.com/zh/games/hero-tales" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hero-tales/cover.jpg)

一个充满怪物和壮丽景色的幻想世界正等待着你。化身一位魅力非凡且英勇无畏的角色，他决心拯救自己的生命并铲除敌人。但要小心，每杀死一个敌人，你的生命值都会减少。如何在生命值与攻击之间取得平衡，完全取决于你。你可以通过香蕉来恢复生命！沿途还会找到心形物品和小苹果。

## 怎么玩

你的角色会自动奔跑，你只需给他指引方向以收集物品并恢复生命。当到达终点线时，即完成当前关卡。
