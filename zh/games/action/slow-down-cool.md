# 慢下来冷静

<a href="https://inkwengame.com/zh/games/slow-down-cool" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slow-down-cool/cover.jpg)

这是一款有趣的行走游戏。玩家在游戏中扮演不同的角色，迎接各种行走挑战，玩法类似于跳跃，根据点击时间来行走，步伐必须计算得准确，否则就会失败。在游戏中，玩家需要具备良好的平衡能力，才能成功抵达终点。

## 怎么玩

玩家可以通过点击选择界面右侧的按钮进入游戏界面。玩家的左右腿分别显示在界面的左侧和下方，玩家需要控制其移动
