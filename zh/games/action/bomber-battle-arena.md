# 炸弹战斗竞技场

<a href="https://inkwengame.com/zh/games/bomber-battle-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bomber-battle-arena/cover.jpg)

炸弹战斗竞技场是一款令人兴奋的3D收集游戏，让你扮演一名手持炸弹的角色。你的目标是战略性地引爆炸弹，清除各种绿色植物和树桩，收集金色钥匙，并抵达宝箱以进入下一关。请注意炸弹的爆炸范围，避免与沿途的其他怪物接触。准备好迎接一场充满爆炸动作的10个挑战关卡的激烈冒险吧！

## 怎么玩

WASD控制四个方向移动，空格键放置炸弹
