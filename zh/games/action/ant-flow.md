# 蚂蚁流

<a href="https://inkwengame.com/zh/games/ant-flow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ant-flow/cover.jpg)

介绍蚂蚁流，这是一款轻松的解谜游戏，你的创造力将占据主导地位。用手指绘制线条，构建路径，引导勤劳的蚂蚁找到食物。你的任务是帮助这些勤勉的蚂蚁将收获运回巢穴。解决谜题，避开障碍，赢得胜利。这款游戏是你展示智慧、征服前方挑战的机会。
