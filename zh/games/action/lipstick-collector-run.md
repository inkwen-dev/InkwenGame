# 口红收藏家跑酷

![cover](https://img.inkwengame.com/games/lipstick-collector-run/cover.jpg)

口红收藏家跑酷是一款经典的竖版街机游戏，采用单按钮控制。你的任务是收集所有口红部件，同时躲避障碍物并赚取金钱。完成8次缠绕即可解锁标记关卡。用金钱绘制8种不同颜色。拥有8只手可提升口红收集效率，赚取额外现金。收集的口红越多，赚的钱就越多！

## 怎么玩

向左或向右滑动移动
