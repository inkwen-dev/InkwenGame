# 妮娜冒险

<a href="https://inkwengame.com/zh/games/nina-adventures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nina-adventures/cover.jpg)

《妮娜冒险》是一款2D小平台游戏，你将扮演一位可爱的女孩，需要收集所有的巧克力冰淇淋棒，同时避开怪物、地面锯齿和尖刺，抵达红色旗帜以进入下一关。游戏中共有8个关卡，难度会随着进程逐渐增加。

## 怎么玩

使用WASD或方向键控制角色移动；连续按两次W键或上箭头键可进行二段跳
