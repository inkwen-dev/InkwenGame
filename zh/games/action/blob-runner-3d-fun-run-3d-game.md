# Blob Runner 3D - 趣味跑酷3D游戏

Blob Runner 3D 是一款有趣的躲避类街机游戏，采用3D液态人角色的游戏美术动画制作。在每一关的赛道上，通过收集小 blobs 来让自己的身体变大，直至到达终点线。当你碰到障碍物时，不得不失去自己的一部分。尽力控制损伤，完成所有关卡！
