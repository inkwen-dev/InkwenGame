# 暗影锻造

<a href="https://inkwengame.com/zh/games/shadow-forge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shadow-forge/cover.jpg)

《暗影熔炉》是一款融合了黑暗奇幻元素的塔防与动作角色扮演游戏。玩家将扮演锻造大师英雄，建造并升级10座独具特色的防御塔——躲避攻击、施放4种技能，在8张地图、20波关卡中击溃一波又一波的暗影生物，更有史诗级首领等你挑战。升级即可解锁强大的增益效果。

## 怎么玩

桌面端：WASD/方向键移动，鼠标瞄准和施放技能（Q/E/R/T），点击防御塔再点击地图格子进行建造。移动端：左摇杆移动，点击技能键施放技能，点击防御塔图标再点击地图格子进行建造。尽早开始攻击波次可获得额外金币——别让敌人到达锻造厂！
