# 像素征服

<a href="https://inkwengame.com/zh/games/pixel-conquest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-conquest/cover.jpg)

《像素征服》是一款节奏明快、令人欲罢不能的策略游戏，你将与电脑对手展开激烈的领土争夺战。绘制路径圈地，将其据为己有，你的城市也会在边界内自动扩张。

## 怎么玩

目标：目标是占领尽可能多的领土，并成为地图上最后的幸存者。

操作：

桌面端：使用方向键控制角色移动。

如何占领领土：

从你的彩色领土向外移动，画出一条路径。

返回你领土的任意位置即可完成一个循环。你圈出的区域将被占领并变为你的颜色。

淘汰：

撞到外墙或对手的领土将被淘汰。

城市建设与得分：

随着你的领土扩张，房屋和摩天大楼等建筑将自动建造，并随时间推移为你积累分数。

占领敌方领土、摧毁他们的建筑以及淘汰对手也能提升你的分数。

强化道具：

地图上偶尔会出现强化道具。移动到它们上方即可获得特殊能力，该能力会在限定时间内生效。

速度：移动速度翻倍。

护盾：可承受一次致命碰撞。

幽灵：穿过敌人的踪迹而不被消灭。

炸弹：立即占领你周围的一大片圆形区域。
