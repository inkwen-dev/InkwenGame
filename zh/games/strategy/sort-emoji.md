# 排序表情符号

<a href="https://inkwengame.com/zh/games/sort-emoji" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sort-emoji/cover.jpg)

这款轻松的表情符号排序谜题游戏既有趣又具挑战性，为谜题玩法带来了全新的突破。将表情符号分类放入玻璃瓶中，使每个瓶子中的表情符号都相同。通过将所有相同类型的表情符号分别放入独立的玻璃罐中，您将轻松获胜。

## 怎么玩

您只能将表情符号移动到空的玻璃瓶中，或移动到与之类型相同的表情符号所在的瓶子中
