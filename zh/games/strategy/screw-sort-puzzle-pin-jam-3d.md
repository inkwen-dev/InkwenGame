# 螺丝排序谜题钉 jam 3D

<a href="https://inkwengame.com/zh/games/screw-sort-puzzle-pin-jam-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/screw-sort-puzzle-pin-jam-3d/cover.jpg)

想要一个有趣又莫名放松的3D拼图吗？在《ScrewSortPuzzle:PinJam3D》中，你将拆除每一个螺丝，整理五彩缤纷的钉子，并将它们匹配到正确的槽位，而不会造成卡住！你需要持续匹配正确颜色的螺丝，并将它们放入对应颜色的盒子中。旋转棋盘，找出可以安全先松开的螺丝。你还可以体验拆螺丝模式。
