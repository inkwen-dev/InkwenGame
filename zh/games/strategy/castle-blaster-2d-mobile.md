# 城堡爆破者 2D！（移动版）

扮演国王最伟大的士兵，保卫你的国王和他的城堡，抵御他最大的弓箭敌人！由于之前战斗造成的损伤，敌方国王的城堡正逐渐被摧毁。这使得他开始攻击比以往更弱小的王国，以掠夺他们的黄金并击败他们，从而维持自己庞大的城堡。你国王的珍贵城堡花了19年才建成，而你配备了地球上最强大的未来武器。不要让国王失望！

## 怎么玩

点击屏幕左上角的三个武器图标来切换，它们各自有不同的用途和优势。重机枪是你的主要武器，应用来远距离撕裂子弹。用弓箭阻止蓝色子弹靠近。
