# 皇冠卫队

<a href="https://inkwengame.com/zh/games/crown-guard" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crown-guard/cover.jpg)

《皇冠卫队》是一款动作塔防游戏，你将扮演一位国王，保卫自己的城堡免受敌军侵袭。收集金币，建造并升级防御塔，招募骑士，释放强大的皇家突袭。征服横跨10个不同生物群落的100张地图，解锁新的防御设施，并通过永久升级强化你的国王。

## 怎么玩

使用 WASD 键、方向键或按住并拖动鼠标或手指移动。停止移动即可自动射击。收集掉落的金币，然后站在标记的建筑地块上建造或升级防御工事。按空格键或点击攻击按钮攻击附近的敌人。在五波敌人的围攻下保护你的城堡，即可解锁下一张地图。每波敌人过后选择奖励，并在暂停菜单中使用皇冠购买永久升级。
