# 砖块与方块

![cover](https://img.inkwengame.com/games/bricks-blocks/cover.jpg)

《砖块与方块》是一款有趣且令人上瘾的超休闲策略益智游戏。将这些砖块方块拖入空格中，清除网格中的行和列。在这个具有挑战性的益智游戏中，你能走多远？尝试为所有这些砖块方块找到足够的位置，同时形成行以使它们消失。一旦你没有更多空间，游戏就结束了。
