# 经典俄罗斯方块

<a href="https://inkwengame.com/zh/games/classic-tetrix" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/classic-tetrix/cover.jpg)

玩家通过移动不同形状的方块（四连方块）来完成横线，这些方块会从上方落下。完成的横线会消失并为玩家获得分数，玩家可以继续填充腾出的空间。当游戏区域被填满时，游戏结束。玩家延迟这一结果的时间越长，得分就越高。

## 怎么玩

使用左或右方向键设置位置，上和下方向键旋转方块
