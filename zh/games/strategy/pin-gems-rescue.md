# Pin Gems Rescue

<a href="https://inkwengame.com/zh/games/pin-gems-rescue" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pin-gems-rescue/cover.jpg)

欢迎来到 Pin Gems Rescue，在这款游戏中，你需要拔掉钉子，帮助怪物抢夺宝藏或黄金，并解救他脱离阻碍。拔钉子时要小心，运用你的头脑，避免让宝藏掉进熔岩或水中。同时不要让其他怪物摧毁你的英雄。祝你好运！

## 怎么玩

点击或轻触以拔出钉子
