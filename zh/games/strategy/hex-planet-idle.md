# 六边形星球闲置

<a href="https://inkwengame.com/zh/games/hex-planet-idle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hex-planet-idle/cover.jpg)

六边形星球闲置是一款结合了RPG冒险和生存闲置元素的3D游戏。你可以操控一个棍子人战士，通过收集资源并解锁新区域来探索整个宇宙。当你踏上白色光亮区域时，会得知下一个区域的资源需求。靠近任何物品即可自动收集。如果我是你，我会因为丰富的资源而解锁所有区域。
