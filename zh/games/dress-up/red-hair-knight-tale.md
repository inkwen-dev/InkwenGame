# 红发骑士传说

<a href="https://inkwengame.com/zh/games/red-hair-knight-tale" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/red-hair-knight-tale/cover.jpg)

红发骑士传说是一款酷炫且史诗般的2D中世纪剑客冒险游戏。你必须消灭怪物，并到达每一关的棕色旗帜。你还可以收集金币来提升总分。它们在这个游戏中没有实际用途，但你可以从宝箱或怪物尸体中找到它们。你需要跳两次才能到达更高的平台，并在怪物杀死你之前跑到终点旗帜！

## 怎么玩

在PC上，AD键或左右箭头键移动，空格键跳跃，J键攻击；在移动设备上，点击屏幕上的按钮
