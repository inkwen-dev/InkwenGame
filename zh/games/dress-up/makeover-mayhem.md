# 改造大乱斗

<a href="https://inkwengame.com/zh/games/makeover-mayhem" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/makeover-mayhem/cover.jpg)

一场正面交锋的ASMR清洁对决。你和你的对手比赛，看谁能最快地将五件脏兮兮的物品擦洗得光亮如新——刮擦、喷洒、擦洗、刮水，逐一完成，并在对手之前（或在4分钟计时器结束之前）完成所有五件物品。

## 怎么玩

玩法介绍

清除污垢 — 拖动鼠标在脏污物品上擦拭污垢，露出下方干净的一层。

使用合适的工具 — 每个关卡都会按顺序解锁新的工具：刮刀 → 泡沫喷雾 → 刷子 → 刮水器。

完成每个关卡 — 清除足够的污垢（约 90% 的脏污区域）后，关卡会自动结束；下一个工具将会解锁。

清洁全部五件物品 — 在一场比赛中，完成所有五件物品的每个关卡：地毯、运动鞋、奖杯、茶壶和手表。

击败对手 — 在对手之前清洁全部五件物品即可获胜。如果时间耗尽，则完成清洁的物品更多（或总进度更快）的玩家获胜。
