# 幽灵链接

<a href="https://inkwengame.com/zh/games/spooky-links" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spooky-links/cover.jpg)

幽灵链接是一款轻松的万圣节主题游戏，你需要连接匹配的幽灵瓷砖。点击一张瓷砖，然后点击其对应的匹配项。如果它们之间的路径转弯不超过两次，这些瓷砖就会被清除。每清除一张瓷砖，就会腾出更多空间来连接其他瓷砖。享受众多充满万圣节惊喜的乐趣关卡！

## 怎么玩

点击或轻触一张幽灵瓷砖，然后找到并选择其匹配的瓷砖。如果它们之间的路径转弯不超过两次，它们将被清除。清空所有瓷砖以完成该关卡。使用鼠标或触摸板进行游戏
