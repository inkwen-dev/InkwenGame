# 鱼的连接

<a href="https://inkwengame.com/zh/games/fish-connections" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fish-connections/cover.jpg)

这是一款经典益智游戏，灵感来自流行的麻将消除游戏。你需要消除出现在棋盘上的所有方块。你可以将相同的方块连接起来以同时消除它们，每次连接最多只能有2个拐弯。游戏中共有24个具有挑战性的关卡。在时间限制内完成关卡可获得额外奖励。
