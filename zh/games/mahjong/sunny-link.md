# 阳光链接

<a href="https://inkwengame.com/zh/games/sunny-link" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sunny-link/cover.jpg)

阳光链接是一款简单有趣的益智游戏，玩家需要匹配带有夏日图标的小方块。目标是连接两个相同的方块。如果可以通过三条或更少的直线将方块连接起来，就可以进行连接。游戏中有众多关卡可供体验。随着游戏进行，您将听到海浪的声音。这是一款非常适合在阳光下放松和娱乐的游戏！

## 怎么玩
