# 水果漂浮连接

<a href="https://inkwengame.com/zh/games/fruits-float-connect" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruits-float-connect/cover.jpg)

用一条路径连接两个相同的水果，路径上的转角不超过两个90度。通过移除所有相同水果的配对来清空棋盘。注意，某些关卡中，水果方块可以漂浮（向下、向上、向左、向右、向中心或分裂）。本游戏共有27个具有挑战性的关卡。在时间限制内完成关卡可获得额外奖励。
