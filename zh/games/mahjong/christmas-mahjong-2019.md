# 2019 圣诞麻将

<a href="https://inkwengame.com/zh/games/christmas-mahjong-2019" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-mahjong-2019/cover.jpg)

将两张相同的圣诞麻将牌组合在一起以从棋盘上移除它们。你只能使用自由的牌。一张自由的牌未被其他石头覆盖，并且至少有一侧（左或右）是开放的。在这个麻将游戏中，你有 25 个关卡可以挑战。你可以多次玩这款麻将游戏（每次挑战都不同）。
