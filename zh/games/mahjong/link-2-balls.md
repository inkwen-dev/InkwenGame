# 连接两个球

<a href="https://inkwengame.com/zh/games/link-2-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/link-2-balls/cover.jpg)

你喜欢Onet拼图游戏吗？那么！Link 2 Ball是一款令人惊叹的Onet连接拼图游戏，采用球形图形。点击连接两个相同的球以消除它们，并持续连接，直到清空棋盘以解锁下一关。当你找不到或无法连接球时，可使用提示和洗牌按钮。清除一关后可获得提示和洗牌机会。尽情享受吧！

## 怎么玩
