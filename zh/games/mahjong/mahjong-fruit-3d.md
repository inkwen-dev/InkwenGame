# 麻将水果 3D

<a href="https://inkwengame.com/zh/games/mahjong-fruit-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mahjong-fruit-3d/cover.jpg)

屏幕上将呈现一个三维图像，立方体的各个面上会显示各种水果图案。你需要仔细观察所有内容，找到完全相同的水果，并点击它们以突出显示其所在的立方体。完成此操作后，你会看到这些物体从游戏场中消失。通过这样做，你将获得分数，并进行下一步操作。在游戏《麻将水果 3D》中，你的任务是在最短时间内并以最少的步数，彻底清除所有立方体。
