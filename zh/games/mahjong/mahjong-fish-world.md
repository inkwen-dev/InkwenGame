# 麻将鱼世界

<a href="https://inkwengame.com/zh/games/mahjong-fish-world" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mahjong-fish-world/cover.jpg)

麻将鱼世界是一款充满挑战且有趣的水下跑酷游戏。玩家控制一条鱼，在一系列关卡中游动，通过匹配麻将牌来从棋盘上消除它们。随着玩家的进展，他们会遇到各种障碍，包括鲨鱼、水母和珊瑚礁。玩家必须运用技巧避开这些障碍，并尽可能多地收集星星。游戏包含多种关卡，每种关卡都有其独特的挑战。玩家还可以与朋友竞争最高得分。
