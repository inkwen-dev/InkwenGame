# 快乐复活节链接

<a href="https://inkwengame.com/zh/games/happy-easter-links" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-easter-links/cover.jpg)

用一条路径连接两个相同的复活节物品，路径最多包含两个90度角。通过移除所有相同复活节物品的配对来清空棋盘。请注意，在某些关卡中，物品方块可以浮动（向下、向上、向左、向右、向中心或分裂）。本游戏共有27个具有挑战性的关卡。在时间限制内完成关卡可获得额外奖励。
