# 工作坊工具连接

<a href="https://inkwengame.com/zh/games/workshop-tools-link" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/workshop-tools-link/cover.jpg)

工作坊工具连接是一款方块连接游戏。你需要连接两个相同工具的方块。两个匹配工具之间的连接线只能有两个转弯。在与时间赛跑的过程中，完成相同工具之间的连接。你能在时间耗尽前清空棋盘吗？

## 怎么玩

使用鼠标或触控板连接两个相同的工具方块。两个匹配工具之间的连接线只能有两个转弯
