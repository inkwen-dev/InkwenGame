# 圣诞浮游连接

<a href="https://inkwengame.com/zh/games/xmas-float-connect" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/xmas-float-connect/cover.jpg)

用一条路径连接两个相同的圣诞物品，路径最多只能有两个90度角。通过移除所有相同圣诞物品的配对来清空棋盘。注意，在某些关卡中，物品瓷砖可以浮动（向下、向上、向左、向右、向中心或分裂）。游戏中共有27个具有挑战性的关卡。在时间限制内完成关卡可获得额外奖励。
