# 麻将缩放

<a href="https://inkwengame.com/zh/games/mahjong-resize" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mahjong-resize/cover.jpg)

你需要找到并匹配具有相同动物图案的牌。与普通麻将不同，这款游戏的牌具有不同的形状和大小。可以将不同大小的牌相互组合，关键在于它们上面必须有相同的动物图案。

## 怎么玩

找到具有相同动物的牌以清除整个游戏区域，并解救出被囚禁的40只动物。你可以使用提示功能，并重新洗牌游戏区域中的牌。
