# Finnie 逃脱

Finnie 逃脱是一款激动人心的水下解谜冒险游戏，你将引导一条小鱼穿越神秘的海洋迷宫。沿着网格状路径移动，避开危险的敌人，与环境互动，并使用特殊能力来生存。每一关都会引入新的障碍和更具挑战性的难题，考验你的逻辑、策略和时机把握。找到最安全的路径，帮助 Finnie 脱离深海！
