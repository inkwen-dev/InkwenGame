# 颜色切换球

<a href="https://inkwengame.com/zh/games/color-switch-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-switch-ball/cover.jpg)

轻触屏幕，小心地控制小球穿过障碍物。小球只能通过与其颜色相同的障碍物。不要穿过错误颜色的障碍物，否则你将不得不重新开始。注意，小球的颜色可能会随机改变。

## 怎么玩
