# 囚犯逃亡

<a href="https://inkwengame.com/zh/games/prisoners-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/prisoners-run/cover.jpg)

这是一座残酷的监狱，狱警毫不留情。你扮演一名身手不凡的囚犯，可以砸开牢门、智胜狱警、解救其他囚犯，并一路杀出一条血路，最终逃出生天。

## 怎么玩

游戏目标：找到钥匙并到达出口电梯，进入下一关。沿途营救并护送其他囚犯重获自由。电脑端操作：方向键或WASD键。移动端操作：虚拟摇杆：拖动即可向各个方向移动。
