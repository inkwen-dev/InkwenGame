# 咬住子弹

<a href="https://inkwengame.com/zh/games/byte-the-bullet" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/byte-the-bullet/cover.jpg)

咬住子弹是一款基于弹幕的射击游戏，你和你的敌人装备了护甲生物，这些虚拟程序不仅能保护使用者免受真实伤害，还能提供被动效果。在这款游戏中，你扮演一名由公司派遣的廉价机器人，前往一座被铁轨覆盖的废弃矿井，清除轨道上的神秘赛博格怪物，以便进一步提取资源。你别无选择，必须完成任务——要么为了生存…

## 怎么玩

除了移动和射击外，你还可以召唤一个护盾，通过在一条铁轨上停留短暂时间，然后跳到另一条铁轨来阻挡所有伤害；同时，你可以通过按下Shift+Insert键或在设置中启用自动奔跑来加速前进。
