# 滑索山谷

<a href="https://inkwengame.com/zh/games/zipline-valley" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zipline-valley/cover.jpg)

为了救出等待在危险山谷起点的朋友，用鼠标画一条线，到达另一端后，点击左键让乘客滑上滑索。按住鼠标的时间越长，滑索的乘客就越多。为了避开危险，你可以绕过障碍物画线，就像绳索一样移动线条。游戏机制基于甩动绳索。
