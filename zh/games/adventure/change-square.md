# 改变方块

<a href="https://inkwengame.com/zh/games/change-square" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/change-square/cover.jpg)

改变方块是一款解谜游戏，球会触碰到方块。就这么简单。但球和方块必须是同一种颜色。因此你必须点击屏幕来改变方块的颜色，使其与球的颜色相同。如果球和方块在接触时颜色不同，游戏就会结束。

## 怎么玩

点击屏幕开始游戏
