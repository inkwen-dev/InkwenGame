# 蘑菇王国之战

<a href="https://inkwengame.com/zh/games/mushroom-fight-for-the-kingdom" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mushroom-fight-for-the-kingdom/cover.jpg)

《蘑菇王国之战》是一款激动人心且策略性十足的移动端游戏，玩家将踏上一段惊险刺激的旅程，保卫并扩展自己的魔法蘑菇王国。游戏设定在一个充满活力与奇幻色彩的世界中，玩家将扮演一名勇敢的蘑菇战士，与成群的敌人战斗，征服领土，并建立一个强大的王国。

## 怎么玩

左移动按钮 向左移动你的蘑菇角色 右移动按钮 向右移动你的蘑菇角色 跳跃上按钮 使你的蘑菇角色跳跃 长按按钮以跳得更高 暂停按钮 暂停游戏并打开暂停菜单
