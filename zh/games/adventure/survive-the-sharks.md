# 生存于鲨鱼之间

<a href="https://inkwengame.com/zh/games/survive-the-sharks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/survive-the-sharks/cover.jpg)

你当时正在船上，不小心掉进了海里。不幸的是，没有人注意到，船把你留在了茫茫大海中央。水中潜伏着鲨鱼，你别无选择，只能努力游向陆地以求生存，因为附近似乎没有任何船只。每次游戏开始时，陆地会出现随机位置，你要尽力避开鲨鱼。海洋中还有无害的鱼类，它们不会对你造成伤害。祝你好运！
