# 万圣节恐怖

<a href="https://inkwengame.com/zh/games/halloween-horror" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-horror/cover.jpg)

恐怖万圣节是一款休闲游戏，你只需吃巧克力，通过吃巧克力来获得分数。需要小心不要吃有毒的药水瓶。黄金规则是不让三块巧克力掉到地面，否则你将失败。游戏速度会逐渐加快。尽情享受吧！
