# 寻宝

<a href="https://inkwengame.com/zh/games/search-for-treasure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/search-for-treasure/cover.jpg)

你被雇佣为潜水员，前往海底收集7件物品，并找到能打开沉在海床的宝箱的骨架钥匙。当你找到全部8件物品并获得宝藏后，就需要找到船只。小心一些海洋生物很危险，别耗尽氧气。祝你好运。
