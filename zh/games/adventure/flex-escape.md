# 柔韧逃脱

<a href="https://inkwengame.com/zh/games/flex-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flex-escape/cover.jpg)

Flex Escape 3D 是一款有趣的遊戲，你需要伸展和彈性來避開障礙物。與傳統跑酷不同，你將停留在一塊墊子上，利用你的柔韌性來閃避被扔向你的家具和家用電器。通過簡單地左右移動控制，你可以順利通過各種挑戰。收集寶石可以解鎖新物品，讓遊戲更加刺激。目標是在保持專注和靈活的同時，成功到達終點，且不碰到任何障礙物。
