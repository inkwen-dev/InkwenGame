# Claritas 地城爬行者 RPG 演示版

![cover](https://img.inkwengame.com/games/claritas-dungeon-crawler-rpg-demo/cover.jpg)

Claritas 是一款 2D 回合制地城爬行角色扮演游戏，专注于策略性玩法。游戏没有剧情或故事，挑战玩家探索队伍构建、技能融合以及战术战斗。从多样化的英雄阵容中进行选择，每位英雄拥有四种独特技能，并创造出强大的协同效应，以征服每一次遭遇战。

## 怎么玩

桌面控制 - 确认 Z - 取消 X - 移动 方向键 移动设备控制 - 确认 点按 - 取消 滑动或两指点按 - 移动 点按
