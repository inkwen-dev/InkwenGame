# 后室出口

<a href="https://inkwengame.com/zh/games/backroom-exit" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/backroom-exit/cover.jpg)

你准备好面对后室的诡异空旷了吗？在《后室出口》这款紧张的第一人称逃脱游戏中，你被困在一个令人不安的黄色墙壁与无尽走廊的世界中。你的唯一目标就是找到出口，但这绝非易事。探索阴森的环境，搜寻隐藏物品，并收集线索以揭开围绕你的谜团。你需要运用智慧解决巧妙的谜题，组合物品，并发现如何打开通往自由的大门，否则氛围将完全吞噬你。

## 怎么玩

使用WASD或方向键移动，使用鼠标旋转视角，左键点击进行互动，鼠标滚轮切换背包物品。通过TouchScript，你可以使用虚拟摇杆移动，点击手部按钮进行互动，滑动选择背包物品
