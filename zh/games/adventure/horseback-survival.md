# 骑马求生

<a href="https://inkwengame.com/zh/games/horseback-survival" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/horseback-survival/cover.jpg)

在《骑马求生》中开启一段生存之旅，你扮演的主角佐汉与你的马匹巴达尔有着不可分割的联系。你们同一天出生，当一场神秘事件使你陷入昏迷时，这种独特纽带便成为你的生命线。在被僵尸占领的世界中穿行，使用近战和远程攻击进行激烈战斗，通过保持隐蔽来智胜亡灵，并通过策略性的奔跑和跳跃克服障碍。

## 怎么玩

移动端：虚拟摇杆控制移动，跳跃按钮用于跳跃；桌面端：A、D键移动，空格键跳跃，Shift键跑步；常见操作：点击屏幕左侧进行近战攻击，按住并拖动屏幕左侧进行瞄准，松开后释放
