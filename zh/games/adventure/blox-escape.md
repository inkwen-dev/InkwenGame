# Blox Escape

<a href="https://inkwengame.com/zh/games/blox-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blox-escape/cover.jpg)

这是一款逻辑谜题游戏，你需要从框架中逃脱。它是一种滑动类游戏。你需要移动方块，为带有星星的方块开辟一条路径。你有无限的时间来完成这个目标。只需滑动箱子，找到最佳的逃脱方式，让带星星的方块成功离开。游戏共有25个关卡，每个关卡都各不相同，其中一些关卡非常具有挑战性。

## 怎么玩

使用鼠标或点击屏幕来玩这个游戏
