# 不熟悉的物体

<a href="https://inkwengame.com/zh/games/unfamiliar-object" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/unfamiliar-object/cover.jpg)

《陌生物品》是一款第一人称视角的办公室恐怖侦查游戏，玩家需要找出那件格格不入的物品。阅读游戏规则，探索寂静的夜班走廊，拍摄真正的异常物品，并在程序变得敌对之前通过传真提交证据。每个班次都会将普通的办公物品扭曲成某种诡异的存在。

## 怎么玩

检查办公室走廊，找出不属于这里的物品。点击进入鼠标视角，使用WASD键或方向键移动，移动鼠标环顾四周。按空格键升起或降下检查摄像头。摄像头升起后，对准轮廓线内的物品，点击鼠标左键拍照。将证据带到正确标记的传真机，点击鼠标左键提交，并在时间耗尽前完成。不要报告错误的物品，不要重新进入已拍照的房间，并遵守不断变化的规则，才能顺利完成所有轮班。
