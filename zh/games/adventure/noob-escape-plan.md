# 菜鸟：逃脱计划

菜鸟被抓住并囚禁在地下监狱中。为了成功逃脱，你需要制定一个精确的计划。通过地下洞穴和墓穴，让菜鸟避开危险陷阱和狡猾敌人，找到逃离这座监狱的方法。在通往自由的路上，菜鸟将面对25个简单关卡和25个困难关卡，骷髅、僵尸、末影人、陷阱、激光等障碍将不断干扰。通往自由的道路绝不会轻松。
