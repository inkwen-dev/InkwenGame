# 兄弟：游戏

<a href="https://inkwengame.com/zh/games/brothers-the-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/brothers-the-game/cover.jpg)

这是一款关于两个兄弟的遊戲，他们的披薩被偷了。他们必须克服重重障碍和谜题才能找回披萨，而只有你能控制他们。但你一次只能控制一个兄弟。你必须利用这些限制来解决谜题。

## 怎么玩

这真的很具有挑战性，我非常喜欢音乐，但控制确实非常困难
