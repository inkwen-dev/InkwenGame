# 云跃

![cover](https://img.inkwengame.com/games/cloud-hopper/cover.jpg)

云跃是一款趣味十足、节奏快速的街机游戏，你将引导一个下落的emoji穿越充满移动云朵的天空。点击屏幕可倾斜云朵以控制下降方向，通过弹跳不断向下前进并收集硬币。红色障碍物不仅会减缓你的速度，还能被战略性地利用来降低过快的动量。不要偏离边缘太远，否则你会坠落。保持平衡，迅速反应，看看你能走多远。

## 怎么玩

一个emoji持续从云层中下落。点击屏幕可向一个方向倾斜云朵，再次点击则向相反方向倾斜。沿途收集硬币。利用或避开红色障碍物来控制速度。尽可能走得更远，以获得高分。
