# 魔法之地

<a href="https://inkwengame.com/zh/games/magic-land" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magic-land/cover.jpg)

魔法之地是一款无尽游戏，你将扮演一名巫师，收集南瓜的同时避开所有障碍物。每收集一个南瓜，你的分数就会增加。如果你与障碍物相撞，你将从绳子上掉落。

## 怎么玩

操作 桌面端 点击鼠标左键移动角色 移动端 点击屏幕移动角色 操作和指示 分数显示在屏幕的正上方
