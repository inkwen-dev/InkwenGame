# 孢子卫士

<a href="https://inkwengame.com/zh/games/spore-guard" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spore-guard/cover.jpg)

保护活孢子核心免受一波又一波的微生物攻击。核心会自动开火，你需要点击优先目标、收集生物质、解锁变异，并在不断升级的酸液、护盾、坦克、快速移动、粘液和首领级敌人的攻击下生存下来。

## 怎么玩

点击敌人即可集中孢子攻击。点击发光的生物质即可收集。能量槽充满后使用防御爆发，或在电脑上按空格键。在数波敌人中生存下来，选择变异形态，在游戏间隙获得永久升级，并保护核心以获得最高分。
