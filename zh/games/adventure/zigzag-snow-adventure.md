# 之字形雪地探险

<a href="https://inkwengame.com/zh/games/zigzag-snow-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zigzag-snow-adventure/cover.jpg)

控制一个弹力十足的红色小球，让它从雪山上滚落！躲避树木、岩石和其他障碍物，尽可能长时间地生存下去。速度越快，难度越大！

## 怎么玩

🎮 操作方式：

PC（键盘）：

按 A 键或左箭头键向左移动。

按 D 键或右箭头键向右移动。

移动设备（触摸屏）：

向左滑动向左移动。

向右滑动向右移动。
