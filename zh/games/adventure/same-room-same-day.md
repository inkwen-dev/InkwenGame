# 同一房间，同一天

![cover](https://img.inkwengame.com/games/same-room-same-day/cover.jpg)

体验《同一天同室》带来的惊悚心理恐怖。扮演罗莎琳，探索一座充满怪物的恐怖建筑。面对严峻的挑战，收集关键物资，直面内心深处的恐惧，揭开秘密，在令人毛骨悚然的数字世界中寻求平静。

## 怎么玩

需要完整支持游戏手柄

控制方式：

移动：WASD

环顾四周：鼠标

射击：鼠标左键

瞄准：鼠标右键

装弹：R

手电筒：F

跳跃：空格键

互动：E

冲刺：Shift
