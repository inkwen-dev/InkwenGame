# 像素英雄幸存者

<a href="https://inkwengame.com/zh/games/pixel-hero-survivor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-hero-survivor/cover.jpg)

《像素英雄：幸存者》是一款生存类游戏，你必须在无尽的怪物浪潮中生存下来。从三个各具特色的英雄中选择一位，在每波攻击后选择强大的升级，并使用你英雄独特的专属技能来击败成群的怪物！

## 怎么玩

操作方式：

PC玩家：使用WASD键或鼠标在屏幕上控制你的英雄。

移动玩家：使用屏幕上的虚拟摇杆进行触控操作。

技能：点击技能图标释放角色技能。
