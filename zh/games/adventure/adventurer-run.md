# 冒险者跑

![cover](https://img.inkwengame.com/games/adventurer-run/cover.jpg)

拖动你的角色移动。你的武器会自动射击。避开怪物的攻击或撞到树木等物体。随着时间推移，当你跑得越远，就会获得武器升级或解锁新武器。收集金币并解锁新角色。消灭敌对怪物，取得最高分数。
