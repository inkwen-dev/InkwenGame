# 水果忍者刀切切乐游戏

<a href="https://inkwengame.com/zh/games/fruit-ninja-cutter-slice-fun-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-ninja-cutter-slice-fun-game/cover.jpg)

水果切割游戏是一款全新的街机游戏，融合了角色扮演游戏的玩法，在游戏中你将切水果、得分并躲避炸弹。你能切多少次这些水果？拔出你的刀刃，像忍者一样开始砍切所有移动的东西，别忘了斩杀特殊水果以获得额外奖励。加入你 fellow 忍者们的行列，踏上成为水果大师的征程！尝试击败他们的分数，成为终极大师。

## 怎么玩

切水果，不要碰到炸弹
