# 解开毛线

<a href="https://inkwengame.com/zh/games/yarn-untangle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/yarn-untangle/cover.jpg)

解开毛线是一款解谜游戏，你将使用你信赖的小猫来解开毛线球。只需选择毛线并拖动，将其从缠结的混乱中解放出来。注意连接线的颜色。红色表示缠结，粉色表示正在解开，黄色表示已成功解开。

## 怎么玩

在电脑上玩《解开毛线》时，通过鼠标进行操作；在手机或平板上则通过滑动操作
