# MR BLOCK

<a href="https://inkwengame.com/zh/games/mr-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mr-block/cover.jpg)

你开始游戏时是一个蓝色方块。你在一根线上移动。你会尝试尽可能远地移动，而不会碰到红色方块。使用空格键或Shift键上下跳跃，使用方向键或W/S键分别上下移动。

## 怎么玩

使用空格键或Shift键跳跃，使用方向键或W/S键分别上下移动
