# 螺旋球下落

<a href="https://inkwengame.com/zh/games/helix-ball-drop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/helix-ball-drop/cover.jpg)

点击屏幕开始螺旋球下落，避开障碍物。螺旋球下落游戏拥有疯狂的球跳和非常上瘾的游戏玩法。跳跃并完成螺旋迷宫和关卡。操作简单，只需左右滑动手指即可旋转螺旋并让球跳跃。尝试避开颜色异常的螺旋部分，让球顺利通过。通过多个开口同时前进可获得更高分数。如果通过三个或更多开口，你将降落在一个有纹理的平台区域，该平台会破裂。

## 怎么玩

无限滑落球跳，但要小心，你已不再是小孩了。避开深坑和障碍物，躲避向你射击的物体
