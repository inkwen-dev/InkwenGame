# 逃脱系列

<a href="https://inkwengame.com/zh/games/the-escape-series" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-escape-series/cover.jpg)

《逃脱系列》是一款引人入胜的游戏，考验你的智力和分析能力。探索精心设计的场景，寻找线索和物品，助你逃脱。每个空间都设有独特的谜题和谜语，确保在移动设备和电脑平台上都能获得沉浸式的游戏体验。

## 怎么玩

使用鼠标选择并与物体互动，破解密码，运用逻辑思维和解谜技巧找到逃出房间的方法。
