# 拯救动物王国

<a href="https://inkwengame.com/zh/games/save-the-animal-kingdom" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-animal-kingdom/cover.jpg)

"拯救动物王国" 是一款点击游戏，玩家控制一个动物角色，试图逃离被熔岩填满的世界。通过点击屏幕的左侧或右侧，角色会从一片叶子跳到另一片叶子，利用植物作为避让下方危险熔岩的方法。目标是引导角色安全抵达，拯救动物王国。

## 怎么玩

使用左、右方向键以及点击屏幕的左右两侧来移动动物
