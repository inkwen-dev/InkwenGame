# 方块方块

<a href="https://inkwengame.com/zh/games/block-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-block/cover.jpg)

方块逃脱是一款极具挑战性的解谜游戏，你需要将红色方块向右滑动，直到它完全移出棋盘！通过上下左右移动其他方块，为红色方块腾出通道，使其能够脱离谜题。

## 怎么玩

完成足够的关卡并赢得金币。金币可用于显示提示，帮助你解决那些难以攻克的关卡
