# 海洋水管工

<a href="https://inkwengame.com/zh/games/sea-plumber" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sea-plumber/cover.jpg)

潜入海洋，成为极限水管工。在这款解谜游戏中挑战你的大脑：修复深海中的管道，成为水管冠军。当初设想建造一个巨大的管道系统将海水排出，这似乎是个好主意，直到压力导致整个系统崩溃！现在一切都乱成一团，你必须通过在两个仍保持完好的点之间建立连接来解决这个问题。

## 怎么玩

触摸并点击管道以旋转它们，然后将水流引导至正确的管道
