# 礼物蛇

<a href="https://inkwengame.com/zh/games/gifts-snake" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gifts-snake/cover.jpg)

用移动的蛇收集礼物，不要让蛇撞到自己的身体。你有三种控制方式。默认的是相对控制。如果蛇水平移动，你需要触摸蛇上方或下方的屏幕，使它向上或向下移动。如果蛇垂直移动，你需要触摸蛇右侧或左侧的屏幕，使它向相应方向移动。

## 怎么玩

使用鼠标和键盘进行游戏
