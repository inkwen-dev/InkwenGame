# 大理石螺旋

<a href="https://inkwengame.com/zh/games/marble-spiral" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/marble-spiral/cover.jpg)

瞄准相同颜色的球并击碎相同颜色的球。你的目标是匹配三个或更多相同颜色的大理石以摧毁它们并获得分数。防止大理石到达终点，否则你会失去一条生命。
