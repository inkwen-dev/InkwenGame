# SuperCowboyRun

Super Cowboy Run 是一款引人入胜且美丽的游戏，你必须收集金币、生命值、弹药，并击杀怪物，尽可能走得更远！操作简单：按向上箭头跳跃，按空格键射击，或在移动设备上触摸屏幕进行射击。
