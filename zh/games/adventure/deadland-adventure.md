# Deadland Adventure

<a href="https://inkwengame.com/zh/games/deadland-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/deadland-adventure/cover.png)

Deadland Adventure 将玩家带入一个充满僵尸的世界，拥有直观的控制和紧张刺激的平台玩法。使用你的枪械和近战技能，探索秘密路径，收集资源，并征服遍布亡灵敌人的多样化关卡。在冒险中寻找隐藏的宝藏，同时战略性地管理生命值和弹药以求生存。
