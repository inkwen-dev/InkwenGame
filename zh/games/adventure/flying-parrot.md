# 飞翔的鹦鹉

<a href="https://inkwengame.com/zh/games/flying-parrot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flying-parrot/cover.jpg)

飞翔的鹦鹉是一款无尽飞行游戏，在这款游戏中，你需要帮助鹦鹉避开障碍物，并从平台上收集硬币。这款游戏采用了非常出色的图形效果，适合所有6岁以上年龄段的玩家，是专为所有玩家设计的独特无尽游戏，当鹦鹉掉落时，游戏结束，你需要重新开始游戏。

## 怎么玩
