# 螃蟹与鱼

<a href="https://inkwengame.com/zh/games/crab-fish" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crab-fish/cover.jpg)

《螃蟹与鱼》是一款技巧类游戏，你通过消除方块来释放鱼类，并逐渐向下移动平台。只需触碰鱼笼，即可让可怜的动物重获自由。巧妙地消除方块以保持平衡，切勿从平台上掉落！与朋友分享《螃蟹与鱼》，在不断下潜的过程中超越他们的最高分。海里有无数条鱼，它们都指望你来拯救它们！

## 怎么玩

用手指或鼠标点击方块，以向下移动平台
