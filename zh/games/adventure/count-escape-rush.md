# 计数逃脱冲刺

<a href="https://inkwengame.com/zh/games/count-escape-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/count-escape-rush/cover.jpg)

计数逃脱冲刺是一款类似3D像素人奔跑街机游戏。与传统的奔跑街机游戏不同，你的角色将向后奔跑并射击追击的敌人。拥有3D像素人士兵，你需要收集更多的成员和武器，以对抗即将来袭的红色敌人，直到抵达终点线。任何障碍物都会减少你的成员数量，或直接导致你失败。不要忘记穿过绿色数字墙壁，并收集武器以增强火力。
