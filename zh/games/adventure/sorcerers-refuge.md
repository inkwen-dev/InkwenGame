## 怎么玩

桌面版

WASD = 移动

Q = 打开日记

H = 提示

C = 商店

TAB = 背包

F = 治疗

1/2/3/4 = 技能

E 或鼠标左键 = 使用战斗魔法

移动版

从屏幕右侧滑动 = 旋转角色

左侧虚拟摇杆 = 移动

点击屏幕中央图标 = 与物品互动

点击菜单按钮 = 菜单导航

## 介绍

你醒来发现自己身处一间陌生的客厅。这里没有门，只有墙后传来的低语和黑暗的眼神。欢迎来到巫师的藏身处，一场融合了魔法、谜题和任务的黑暗冒险。

在这个迷雾重重、危机四伏的地方，你将遭遇：

等待着你的：

神秘的走廊、隐蔽的房间和突如其来的陷阱

冰、火、变形和真知术的魔法

神秘的生物、恶魔，以及一个心怀鬼胎的古怪小丑

扣人心弦的对话、意想不到的结局，以及影响剧情走向的选择

战斗、谜题，以及与强大力量缔结的古老契约

你被一位奴役了四个恶魔的巫师困住了。你能否逃脱，还是会成为他收藏的又一个灵魂？
