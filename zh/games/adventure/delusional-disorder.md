# 妄想症

<a href="https://inkwengame.com/zh/games/delusional-disorder" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/delusional-disorder/cover.jpg)

妄想症是一款小型游戏，你扮演一个被困在不真实梦境中的孩子，努力设法逃脱。游戏不会告诉你该做什么，你需要自己去发现。

## 怎么玩

使用WASD或方向键移动，使用E键与物体互动，使用ESC键暂停游戏，使用空格键攻击敌人
