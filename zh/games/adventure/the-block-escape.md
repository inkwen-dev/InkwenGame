# 方块逃脱

<a href="https://inkwengame.com/zh/games/the-block-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-block-escape/cover.jpg)

方块逃脱是一款令人放松 yet 具有挑战性的3D益智游戏，你的目标是清除屏幕上的所有彩色方块。每个方块都有一个指向特定方向的箭头。当你点击一个方块时，它会朝该方向飞出——但前提是其路径必须畅通！特色：令人满足且放松的3D益智机制；色彩丰富、高对比度的视觉设计；无尽的脑力挑战关卡；流畅的摄像机旋转，可从各个角度探索游戏。

## 怎么玩

左键点击 点击选择并移除一个方块 点击并拖动 滑动 旋转3D谜题以查看不同角度
