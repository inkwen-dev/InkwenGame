在屏幕上，您将看到一个游戏区域，卡片会放置在上面。您可以在一次操作中翻转两张卡片。仔细观察卡片上的图案，并记住它们的位置。一旦找到两张相同的图片，请点击卡片数据并同时打开它们。这样，您就可以将它们从游戏区域移除，并获得相应的分数。
