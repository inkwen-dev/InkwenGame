# 猫滚动

<a href="https://inkwengame.com/zh/games/cat-rolling" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cat-rolling/cover.jpg)

猫滚动是一款益智游戏，你需要操控一只滚动的猫。控制猫咪跳跃越过障碍物，并跳起来捕捉星星。点击镜像物体以创建猫的路径。当你收集到钥匙后，就可以打开通往下一关的门了。

## 怎么玩

点击屏幕开始游戏
