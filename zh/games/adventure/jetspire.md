# Jetspire

<a href="https://inkwengame.com/zh/games/jetspire" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jetspire/cover.jpg)

Jetspire 是一款快节奏的街机游戏，你将操控一名配备喷气背包的跑者，向上穿越无尽的垂直挑战。在攀登过程中穿过不断开合的移动门框，每通过一个屏幕即可获得一分。随着你不断上升，门框的移动速度也会加快，考验你的时机把握和反应能力。保持专注，快速反应，看看你能攀爬多高。

## 怎么玩

点击以激活喷气背包并向上移动，松开点击则停止推进并让角色下落。通过交替按住和释放来控制高度。撞到门框或时机失误将结束游戏
