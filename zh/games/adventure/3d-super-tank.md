# 3D 超级坦克

<a href="https://inkwengame.com/zh/games/3d-super-tank" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/3d-super-tank/cover.jpg)

在这款休闲动作游戏中，你的目标是保卫你的基地，并摧毁所有敌方坦克及其建筑。挑战30多个关卡，尝试击败所有其他基地

## 怎么玩

PC上使用键盘方向键移动，空格键射击；移动端使用屏幕上的方向键移动和射击
