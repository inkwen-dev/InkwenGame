# SantaCraft

<a href="https://inkwengame.com/zh/games/santacraft" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/santacraft/cover.jpg)

SantaCraft 是一款第三人称射击游戏，你必须在僵尸的围攻中生存下来，并尝试抵达传送门。在一个广阔的方块世界中享受激烈的枪战。你是唯一幸存的人，任务是尽快建造传送门，并使用各种武器射击所有逼近的僵尸。在《我的世界》的世界中消灭僵尸！你必须保持警觉，准备好武器以抵御邪恶的僵尸。

## 怎么玩

WASD 移动，左键射击，右键瞄准，空格键跳跃，左移键跑步
