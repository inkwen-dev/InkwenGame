# 蠕虫路径

<a href="https://inkwengame.com/zh/games/worm-path" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/worm-path/cover.jpg)

蠕虫路径是一款富有挑战性的逻辑谜题游戏，你需要引导一只聪明的蠕虫穿越复杂的迷宫以到达出口。在方块间移动，推动障碍物，避开陷阱，并仔细规划每一步，以免被困住。每一关都会引入新的布局和越来越困难的谜题，考验你的策略和解决问题的能力。找到最佳路径，克服所有障碍，帮助蠕虫逃脱！

## 怎么玩

A S D W 或方向键进行操作
