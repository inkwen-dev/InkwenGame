# 硬币猎人远征

<a href="https://inkwengame.com/zh/games/coin-hunters-odyssey" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coin-hunters-odyssey/cover.jpg)

《硬币猎人远征》是一款令人兴奋的冒险游戏，玩家需要在每一关收集九枚硬币，并用它们打开通往下一房间的门。游戏中共有13个关卡等待探索，玩家必须运用智慧和解谜技巧来穿越每个房间并推进到下一关。途中，玩家将遇到各种障碍和挑战，包括复杂的迷宫、上锁的门以及隐藏的陷阱。你能否收集全部硬币，并成功通关全部13个关卡…

## 怎么玩

1- 收集九枚硬币并拉动杠杆，打开通往下一关的门 2- 注意观察隐藏区域，硬币可能藏在那里 3- 在每关的结尾拉动杠杆，打开通往下一关的门 4- 克服迷宫等障碍
