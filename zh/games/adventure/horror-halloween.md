# 恐怖万圣节

<a href="https://inkwengame.com/zh/games/horror-halloween" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/horror-halloween/cover.jpg)

恐怖万圣节是一款你需要收集所有出现糖果的游戏。尽量多抓取饼干之间的糖果，同时始终避开藏在饼干之间的炸弹。如果炸弹击中你，游戏就结束了。如果你错过了三次饼干，游戏也会结束。
