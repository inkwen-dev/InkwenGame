# 僵尸对战士

<a href="https://inkwengame.com/zh/games/zombie-vs-warriors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-vs-warriors/cover.jpg)

这是一款动作/冒险三消游戏，包含60个独特关卡和敌人。但在这其中，你将控制两位强大而勇敢的英雄，需要你的帮助来对抗怪物！你所匹配的方块将决定会发生什么。剑会令骑士攻击，锤子会让维京人攻击，药瓶可以恢复部分损失的生命值，盾牌在完全充能后可抵挡敌人的攻击。你有三次行动机会，然后轮到对手行动，如此循环往复。
