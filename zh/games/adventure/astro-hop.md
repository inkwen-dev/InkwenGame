# 星际跳跃

<a href="https://inkwengame.com/zh/games/astro-hop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/astro-hop/cover.jpg)

星际跳跃是一款刺激的太空主题跳跃游戏，玩家控制一名勇敢的宇航员在浩瀚的太空中跃过平台。你的目标是避开障碍物，并通过抵达最高平台来收集分数。游戏拥有令人惊叹的太空背景和色彩缤纷的平台，玩家必须仔细把握跳跃时机，避免被快速移动的危险击中。这是一款引人入胜的街机体验，考验你的反应力和策略能力，助你追求最佳得分！

## 怎么玩

轻触屏幕 让你的宇航员跳向下一个平台 轻触重新开始按钮 游戏结束画面后重新开始游戏 最佳分数 显示你的最高分，每次游戏结束后都会保存并显示
