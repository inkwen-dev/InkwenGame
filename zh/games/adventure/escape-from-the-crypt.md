# 逃离地穴

<a href="https://inkwengame.com/zh/games/escape-from-the-crypt" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/escape-from-the-crypt/cover.jpg)

在亡灵法师抓住你之前，逐个房间地逃出地穴！他们行动比你快，但他们不会避开障碍物：想办法把他们引入死胡同！

## 怎么玩

在电脑上，使用方向键移动角色。按退格键撤销移动，按 H 键获取提示。在移动设备上，使用屏幕上的方向键和屏幕按钮！
