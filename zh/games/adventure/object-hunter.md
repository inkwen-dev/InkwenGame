# 物品猎人

<a href="https://inkwengame.com/zh/games/object-hunter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/object-hunter/cover.jpg)

物品猎人是一款令人兴奋且极具上瘾性的在线游戏。精美的视觉效果将你沉浸在一个设计精美、细节丰富的环境中，充满各种巧妙隐藏的物品。你的主要目标是在有限时间内，通过变成物体来隐藏或在游戏场景中找出这些巧妙隐藏的物品。一人将成为追捕者，其余人则需躲藏！让我们深入探索物品猎人的迷人世界，发现它为何值得你投入时间！

## 怎么玩

1 拖动以移动并躲避追捕者，或成为追捕者去寻找躲藏者 2 在限时模式中挑战自己，与时间赛跑，找出所有隐藏物品 3 锻炼你的观察力，你将获得满足感
