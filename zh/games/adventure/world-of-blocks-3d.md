# 方块世界 3D

<a href="https://inkwengame.com/zh/games/world-of-blocks-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/world-of-blocks-3d/cover.jpg)

你喜欢建造类游戏吗？《方块世界 3D》将你带入一个完全开放且庞大的创作世界。在这个世界中，你可以使用数十种物品/矿石来设计出你所能想象的大部分事物，并在属于自己的世界中采取行动。例如，先进行设计，然后使用飞行模式飞越你的独特设计！这款精彩的模拟游戏可能会让你上瘾。每次游戏都有可能创造出一个截然不同的世界。
