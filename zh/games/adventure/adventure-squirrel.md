# 冒险松鼠

<a href="https://inkwengame.com/zh/games/adventure-squirrel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/adventure-squirrel/cover.jpg)

在游戏中，你将扮演一只松鼠，前往陌生的国度，与怪物战斗，克服障碍，并收集所有水果以完成关卡。每一关你将有三条生命，尝试运用你的敏捷和快速的手速来完成游戏。游戏共设计了20个关卡，专为移动设备和PC优化。
