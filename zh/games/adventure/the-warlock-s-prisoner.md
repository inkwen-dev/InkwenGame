## 怎么玩

在移动设备上：

- 角色旋转 - 从屏幕右侧向内滑动；

- 角色移动 - 使用左侧的虚拟摇杆；

- 与物品互动 - 点击屏幕中央的图标；

- 菜单导航 - 点击按钮。

在电脑上：

- 角色旋转 - 使用鼠标移动；

- 角色移动 - 使用 WASD 键；

- 与物品互动 - 使用 E 键或鼠标左键；

- 提示 - 使用 H 键；

- 打开物品栏 - 使用 TAB 键。

## 介绍

《术士的囚徒》是一款融合了恐怖、生存和解谜元素的黑暗冒险游戏。

你醒来发现自己被囚禁在一位神秘术士的巢穴深处。四周充斥着黑暗、陷阱和成群的僵尸。为了逃脱，你必须探索危险的走廊，搜寻物品，收集线索，解开谜题，并为生存而战。

你能否活着逃离巢穴？还是将永远沦为黑暗的囚徒？

- 探索与解谜

- 与亡灵的战斗

- 神秘的镜子

- 氛围、紧张感和故事
