# BlockGunner

<a href="https://inkwengame.com/zh/games/blockgunner" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockgunner/cover.jpg)

BlockGunner 是一款可在网页上进行的 HTML5 战争游戏，支持两名玩家对战。与朋友一起在三种不同的地图和三种不同的武器中展开战斗。记住，胜利者才是最终的赢家。

## 怎么玩

WASD R 和方向键 O 移动触控操作
