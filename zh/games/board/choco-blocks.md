# 巧克力方块

<a href="https://inkwengame.com/zh/games/choco-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/choco-blocks/cover.jpg)

进入巧克力方块的迷人世界，这是一款令人垂涎的益智冒险游戏，策略与甜蜜完美结合！在这个引人入胜的游戏里，你的任务是选择并放置方块以完成行。但有一个甜蜜的转折：特殊巧克力方块隐藏在行中，等待被收集。你的任务是战略性地排列方块，并在时间耗尽前收集棋盘上所有指定的巧克力方块。

## 怎么玩

玩巧克力方块时，请使用鼠标点击并拖动方块至合适位置。在触摸设备上，只需轻触并滑动方块以按需排列
