# 动物乱序

<a href="https://inkwengame.com/zh/games/animals-jumble" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animals-jumble/cover.jpg)

使用给定的字母找出动物名称，然后在屏幕上点击该动物。每一关将有5个打乱的单词。这款图片文字谜题游戏共有10个具有挑战性的关卡。

## 怎么玩

使用鼠标或触摸屏点击所要求的动物
