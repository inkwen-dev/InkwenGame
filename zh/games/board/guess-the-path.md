# 猜路径

<a href="https://inkwengame.com/zh/games/guess-the-path" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/guess-the-path/cover.jpg)

猜路径是一款专为最聪明的你设计的解谜游戏。是的，最初的关卡相当简单，你会觉得自己在玩儿童游戏……但事实并非如此，试试更难的关卡吧……你会发现这款游戏并不适合所有人……或者说，并不适合所有大脑。因此，你必须将所有的方块连接起来，并完全填满网格。这看起来很简单，但随着网格尺寸的增大，难度会显著提升。

## 怎么玩

游戏规则非常简单：你必须用1到X之间的数字填满网格。这些数字在网格中必须按顺序排列，也就是说，例如数字2所在的方块必须紧邻数字1所在的方块，而数字3所在的方块必须紧邻数字2所在的方块
