# 漫画板谜题

<a href="https://inkwengame.com/zh/games/comic-board-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/comic-board-puzzles/cover.jpg)

这是一款限时游戏，玩家需要在两张看起来完全相同的棋盘中找出一个不同之处。一旦找到两块板之间的差异，两块板将刷新以生成新的差异。在规定时间内找出尽可能多的不同之处，以获得更高的分数。

## 怎么玩

使用鼠标或触摸板来玩此游戏
