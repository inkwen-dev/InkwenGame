# 金色甲虫时间

<a href="https://inkwengame.com/zh/games/golden-beetle-time" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/golden-beetle-time/cover.jpg)

在这个有趣且需要读时钟的游戏里，你需要引导甲虫前往包含需要四舍五入的数字的方块。计算出该数字应四舍五入到哪个数，并让甲虫前往包含该数字的盒子。如果前往了错误数字的盒子或从边缘掉落，甲虫将损失1条生命（总共3条）

## 怎么玩

使用鼠标或触摸屏幕来引导甲虫
