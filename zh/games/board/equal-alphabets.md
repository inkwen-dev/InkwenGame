# 相同字母

<a href="https://inkwengame.com/zh/games/equal-alphabets" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/equal-alphabets/cover.jpg)

一种有趣的练习图片识别和字母表的方法。通过点击或触摸一个图像并将其拖动到匹配的图像上，来配对名称以相同字母开头的物体图片。在2分钟内完成一个关卡可获得奖励。正确匹配得500分，错误匹配扣100分。完成全部12个关卡即可赢得游戏。

## 怎么玩

使用鼠标或触控操作此游戏
