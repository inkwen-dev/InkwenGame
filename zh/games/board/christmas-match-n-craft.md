# 圣诞配对与制作

<a href="https://inkwengame.com/zh/games/christmas-match-n-craft" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-match-n-craft/cover.jpg)

《圣诞配对与制作》是一款有趣的益智游戏。在本游戏中，你需要将物品移动到空白格子中，以形成一行或一列五个或更多相同的物品。每组五个或更多物品将会合并并制作出下一级别的物品。如果你的移动未能制作出新物品，则会在棋盘上添加两个新的额外物品。你可以通过战略性地合并，完全消除低级别物品。你需要制作第40个物品才能赢得此游戏。

## 怎么玩

使用鼠标或触控板来玩此游戏
