# 国际象棋皇家

<a href="https://inkwengame.com/zh/games/chess-royale" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chess-royale/cover.jpg)

一款非标准的国际象棋游戏，游戏中的国王拥有魔法力量。玩家需要击败敌方国王，通过结合棋步和魔法能力来制定制胜策略。

## 怎么玩

魔法能力分为三种：

- 创造新棋子；

- 创造新障碍物；

- 将一个棋子变成另一个棋子。

要使用魔法能力，请将卡牌拖到空白格子上（如果是创造新棋子或创造新障碍物），或拖到棋子上（如果是改变棋子）。
