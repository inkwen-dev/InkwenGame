# 10x10 拼图

<a href="https://inkwengame.com/zh/games/10x10-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/10x10-puzzle/cover.jpg)

经典 10x10 拼图游戏的重生版本，但加入了一些新元素！通过在行和列中放置方块来清除它们，但请注意那些被冻结的格子，必须清除两次才会消失。闪电会前来救援！如果你在同一行收集到两颗闪电，该行将立即被清除。每次同时清除一行，得分倍数就会增加，因此巧妙地组合填满行以获得高分！
