# 像素管道

<a href="https://inkwengame.com/zh/games/pixel-pipes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-pipes/cover.jpg)

像素管道是一款逻辑游戏，你需要让管道连接起来，将水从一个点输送到另一个点。只需轻触管道即可旋转它们。随着游戏进行，你会解锁更多关卡，总共60个关卡！

## 怎么玩

轻触管道以旋转它们
