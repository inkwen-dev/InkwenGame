# 动物单词搜索

<a href="https://inkwengame.com/zh/games/animals-word-search" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animals-word-search/cover.jpg)

这是一款有趣的单词搜索游戏。首先查看左侧面板，找到需要在棋盘中搜索的动物名称列表。现在在棋盘中寻找完全相同的单词。当你在方块的直线（水平、垂直或对角线，任何方向）上找到该单词时，点击显示单词首字母的方块，并一直移动到单词末尾的字母为止。
