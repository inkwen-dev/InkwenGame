# 寻找独特的圣诞树

<a href="https://inkwengame.com/zh/games/find-unique-xmas-tree" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-unique-xmas-tree/cover.jpg)

这是一款棋盘谜题游戏，你需要点击那棵独特的圣诞树。棋盘上所有的树都有配对，但有一棵是唯一的。所以在时间耗尽前找出那棵独特的树吧。

## 怎么玩
