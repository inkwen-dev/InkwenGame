# 1 Block Puzzles

<a href="https://inkwengame.com/zh/games/1-block-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/1-block-puzzles/cover.jpg)

这是一款具有挑战性的益智游戏。这款游戏的玩法非常简单。你需要让方块跳过其他方块，这样就能从棋盘上消除一个方块。要完成一关，必须消除所有方块，仅剩最后一个跳跃的方块。完成全部24个关卡即可赢得游戏。

## 怎么玩

使用鼠标或触摸板来玩这个游戏
