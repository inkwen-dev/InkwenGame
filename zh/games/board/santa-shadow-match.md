# 圣诞影子匹配

<a href="https://inkwengame.com/zh/games/santa-shadow-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/santa-shadow-match/cover.jpg)

圣诞影子匹配是一款适合儿童的有趣且富有教育意义的影子匹配游戏。查看右侧的图形，点击它会产生的影子。点击正确的影子将获得500分，而点击错误的影子则会从你的得分中扣除100分。

## 怎么玩

使用任何指向设备指出正确的影子
