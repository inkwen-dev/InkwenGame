# 流动狂热

<a href="https://inkwengame.com/zh/games/flow-mania" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flow-mania/cover.jpg)

一款简单却令人上瘾的益智游戏，你需要用管道连接成对的彩色点。你必须在所有配对之间建立流动，并且用管道完全覆盖整个棋盘。这可不是一件容易的事，因为管道不能交叉或重叠。三组共75个关卡等你来挑战！

## 怎么玩

用管道连接相同颜色的点，形成流动；你还必须用管道填满整个棋盘才能通关；禁止管道交叉或重叠
