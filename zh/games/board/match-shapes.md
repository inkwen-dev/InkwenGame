# 匹配形状

<a href="https://inkwengame.com/zh/games/match-shapes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-shapes/cover.jpg)

将形状方块滑动到另一个具有相同形状的方块上，以消除两者。尽可能少地移动来完成此操作。消除一个方块可获得100分，但如果一个方块被滑动超过一次，每次移动将扣除10分。消除所有方块以完成关卡。本游戏共有24个具有挑战性的关卡。

## 怎么玩
