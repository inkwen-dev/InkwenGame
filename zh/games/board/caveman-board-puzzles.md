# 穴居人拼图游戏

<a href="https://inkwengame.com/zh/games/caveman-board-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/caveman-board-puzzles/cover.jpg)

这是一款限时游戏，玩家需要在两张看起来完全相同的、充满穴居人的棋盘中找出一个不同之处。一旦找到差异，两个棋盘将刷新以生成新的差异。在规定时间内找出尽可能多的差异以获得更高分数。

## 怎么玩

使用鼠标或触控板来玩此游戏
