# 极速追捕阿恩

<a href="https://inkwengame.com/zh/games/hot-pursuit-ayn" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hot-pursuit-ayn/cover.jpg)

这款游戏的目标是逃脱警车的追捕。警车会试图撞击你的车辆，并试图将"HP"值降为0。当"HP"值为0时，你就会被捕，追逐游戏结束。你将被10辆愤怒的警车追击。利用你惊人的驾驶技巧摆脱警车。不要让警车撞到你。在广阔的"自由驾驶"区域中，有一些地方可以进行"特技"或"漂移"。

## 怎么玩

移动 方向键 - WASD 氮气 N 摄像机 C 手刹 空格键
