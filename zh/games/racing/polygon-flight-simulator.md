# 多边形飞行模拟器

<a href="https://inkwengame.com/zh/games/polygon-flight-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/polygon-flight-simulator/cover.jpg)

在这个飞机模拟器中像专业人士一样飞行；你可以流畅地从一个机场导航到另一个机场。操作简单——按下W键，拖动鼠标，看着你的飞机升空。在前往下一个目的地机场的途中，巧妙地通过空中检查点。凭借直观的操作，这款模拟器提供了沉浸式的飞行体验。无论你是新手还是专家，无缝的界面都能确保你在虚拟天空中享受愉快的旅程…

## 怎么玩

WASD 移动飞机 鼠标拖动 上升 鼠标前推 下降 鼠标左右移动飞机 TAB 菜单
