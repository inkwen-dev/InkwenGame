# 驾驶员

<a href="https://inkwengame.com/zh/games/driver" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/driver/cover.jpg)

驾驶员拥有各种汽车和摩托车可供驾驶；可以自由地从他人那里夺取车辆。

## 怎么玩

WASD或方向键控制车辆 空格键手刹 C键切换视角 Shift键加速 R键重置场景 F键上下车 Page Up Down键切换手动挡档位 Tab键暂停
