# 画桥谜题：大脑游戏

<a href="https://inkwengame.com/zh/games/draw-bridge-puzzle-brain-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/draw-bridge-puzzle-brain-game/cover.jpg)

画桥谜题 - 画图游戏是一款令人兴奋且富有挑战性的大脑游戏，将考验你的解决问题能力。在这个桥梁建造冒险中，你需要绘制道路，让汽车安全地穿越障碍物并到达目的地。准备好踏上一段激动人心的桥梁建设和解谜之旅，通过绘制道路来拯救被困的汽车！

## 怎么玩

- 触摸屏幕开始绘图 - 按住并拖动以绘制你想要的形状 - 完成后松开手指，汽车将开始运行
