# 金钱追逐者 奔跑游戏

<a href="https://inkwengame.com/zh/games/money-chaser-parkour-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/money-chaser-parkour-game/cover.jpg)

无尽地追逐/奔跑以收集硬币（金钱）。努力避开陷阱，并*踢开路上的所有敌人/竞争对手*。*你可以使用滑行技能踢开前方的敌人*。当你有足够的金钱后，就可以挑战Boss战斗。硬币（金钱子弹）的数量是击败Boss的唯一武器，越多越好。记住，没有金钱就没有生命……继续奔跑吧 :)

## 怎么玩

键盘操作：空格键 rarr 跳跃，A键 rarr 滑行或射击；在Boss战斗中使用。触屏手机操作：点击屏幕右侧 rarr 跳跃，点击屏幕左侧 rarr 滑行或射击；在Boss战斗中使用
