# 船只竞速

<a href="https://inkwengame.com/zh/games/boats-race" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boats-race/cover.jpg)

船只竞速是一款以船只为主题的街机竞速游戏。你将驾驶自己的船只与其他船只排成一列进行比赛。努力超越它们，但途中会有障碍物，你需要避开它们。如果撞上障碍物，速度会减慢。当你因障碍物而碰撞三次后，游戏将会结束。
