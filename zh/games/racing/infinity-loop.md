# 无限循环

<a href="https://inkwengame.com/zh/games/infinity-loop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/infinity-loop/cover.jpg)

尝试思考如何将所有线条连接成一个封闭的形状。当你成功完成一个回路时，最终的电路会亮起，让你退后仔细观察。此外，还有数十种精心设计的形状等待你去发现！你准备好放松身心，释放所有压力了吗？

## 怎么玩

连接所有形状以形成一个封闭的回路 旋转形状 - 左键鼠标
