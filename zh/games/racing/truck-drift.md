# 卡车漂移

<a href="https://inkwengame.com/zh/games/truck-drift" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/truck-drift/cover.jpg)

卡车漂移是一款你需要用你的卡车完成一些漂移的游戏。游戏开始时，你可以选择卡车的行驶速度。我们的建议是先从给定的90英里每小时的速度开始，如果你愿意，可以在游戏过程中 later 增加速度。尽量在撞车前通过尽可能多的圈数。

## 怎么玩
