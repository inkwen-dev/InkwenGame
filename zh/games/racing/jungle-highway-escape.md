# 丛林高速公路逃脱

<a href="https://inkwengame.com/zh/games/jungle-highway-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jungle-highway-escape/cover.jpg)

这是一款简单的汽车驾驶游戏，你需要拯救在错误轨道（一侧）上行驶的汽车。使用方向键或键盘上的‘W、A、S、D’键控制汽车。你也可以使用鼠标或触摸屏幕来操控汽车。收集硬币以获得分数。

## 怎么玩
