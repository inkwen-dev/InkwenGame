# 悬浮竞速

![cover](https://img.inkwengame.com/games/hover-racer/cover.jpg)

Hover Racer 是一款有趣的反重力竞速游戏。特性：- 可选择的悬浮飞船及升级系统 - 3 张地图 - 完成每关后获得奖励的系统 - 武器系统

## 怎么玩

使用 WASD 或方向键控制悬浮飞船，左 Shift 键射击，Esc 键暂停
