# 极速赛车最高速

<a href="https://inkwengame.com/zh/games/fast-car-top-speed" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fast-car-top-speed/cover.jpg)

准备好打破速度纪录吧，体验《极速赛车最高速》。这是一款3D汽车驾驶模拟游戏，你可以与时间赛跑。游戏中包含15辆快速汽车和36条赛道。极速赛车城市特技拥有车辆购买与开发系统。每场比赛结束后，你可以升级或自定义你的汽车，或者购买新车。在比赛时间所剩无几时，别忘了使用氮气加速。

## 怎么玩

移动 方向键 - WASD 氮气 N 相机 C 手刹 SPACE
