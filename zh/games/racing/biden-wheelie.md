# 拜登特技

<a href="https://inkwengame.com/zh/games/biden-wheelie" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/biden-wheelie/cover.jpg)

拜登特技是一款简单的2D游戏，共有10个关卡，玩家需要在驾驶吉普车时保持车辆后轮着地来完成挑战。为了增加难度，每个关卡中都有各种障碍物——有些可以跨越，有些则必须避开。收集的美元会增加总分。祝你玩得开心。

## 怎么玩

右箭头键进行特技 跳跃空格键 移动鼠标在手机上操作
