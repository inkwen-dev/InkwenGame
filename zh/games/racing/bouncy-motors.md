# 弹跳马达

<a href="https://inkwengame.com/zh/games/bouncy-motors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bouncy-motors/cover.jpg)

开着一辆像果冻一样颠簸的车，你得到达终点线。

## 怎么玩

前进：W 或 ↑ 或左摇杆（移动设备）

后退：S 或 ↓ 或左摇杆（移动设备）

逆时针旋转：A 或 ← 或右摇杆（移动设备）

顺时针旋转：D 或 → 或右摇杆（移动设备）

## 介绍

开着一辆像果冻一样颠簸的车，你得到达终点线。

小心红色区域——撞击时车轮会脱落！

在冰面上行驶也要格外小心！
