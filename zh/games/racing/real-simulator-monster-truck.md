# 真实模拟怪兽卡车

<a href="https://inkwengame.com/zh/games/real-simulator-monster-truck" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/real-simulator-monster-truck/cover.jpg)

真实模拟：怪兽卡车是一款3D汽车驾驶游戏，让你驾驶怪兽卡车。游戏中有10辆怪兽卡车和4张自由驾驶地图。本游戏拥有车辆购买与升级系统。还有“竞速”模式可与人工智能对抗，以及“特技”模式可在惊人的道路上驾驶怪兽卡车。“竞速”和“特技”模式各包含12个关卡。多种赛车可供选择，开放世界包含4张地图：森林、沙漠、山地和月球。

## 怎么玩

驾驶 方向键 或 WASD 加速氮气 N 摄像头视角 C
