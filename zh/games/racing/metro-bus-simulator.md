# 地铁巴士模拟器

<a href="https://inkwengame.com/zh/games/metro-bus-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/metro-bus-simulator/cover.jpg)

现在你将在城市和山区的特殊道路上驾驶城市地铁巴士游戏。城市地铁巴士是一款双舱式、8x8轮子的长型地铁巴士，行驶在城市和山区的特殊装饰道路上。搭载乘客，驾驶这款城市地铁客车穿越起伏的区域，并将乘客送到他们期望的目的地。在城市中遇到大量交通时，放慢地铁巴士的速度以避免碰撞。

## 怎么玩

使用 WASD 或方向键进行驾驶，空格键 - 手刹
