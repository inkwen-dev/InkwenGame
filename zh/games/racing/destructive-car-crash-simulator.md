# 破坏性汽车碰撞模拟器

<a href="https://inkwengame.com/zh/games/destructive-car-crash-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/destructive-car-crash-simulator/cover.jpg)

所有车辆都会被撞坏、撞凹甚至损毁！逼真的车辆损坏和变形系统。

## 怎么玩

TAB 键 - 暂停菜单（或 Esc 键）

WASD 键 - 移动

空格键 - 手刹

Shift 键 - 氮气加速

C 键 - 切换视角

R 键 - 重置车辆

K 键 - 恢复车辆

N 键 - 切换车辆

移动设备用户请使用游戏界面

## 介绍

所有车辆都会被撞坏、撞凹甚至损毁！逼真的车辆损坏和变形系统。

安排警匪追逐——撞上警车，它就会开始追捕你。

车辆碰撞测试——观看车辆损毁过程。所有车辆损毁效果都经过逼真模拟。

多种地图和车辆。

大量撞击道具——大炮、弹射器、悍马、压力机等等。
