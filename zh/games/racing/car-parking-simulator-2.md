# 汽车停车模拟器

<a href="https://inkwengame.com/zh/games/car-parking-simulator-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/car-parking-simulator-2/cover.jpg)

你觉得停车很难吗？玩一玩汽车停车模拟器，这是一款精准的模拟驾驶游戏。跟随红色箭头指示，将你的汽车停好，不要撞车或发生碰撞。你是不是停车高手？特色：• 45个挑战关卡 • 不同的障碍物需要通过 • 真实的停车模拟 • 2款酷炫汽车 • 汽车升级与个性化定制

## 怎么玩

WASD 方向键控制前进 C 切换摄像头视角 空格键刹车 Tab Esc 暂停/继续
