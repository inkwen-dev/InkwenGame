# CarHit.io

<a href="https://inkwengame.com/zh/games/carhit-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/carhit-io/cover.jpg)

CarHit.io 是一款 .io 游戏，目标是将其他车辆推下平台。在这款游戏中，你必须努力保护自己，并将对手的车辆赶出竞技场。每将一名对手推出竞技场，你的撞击力就会增强，攻击也更猛烈。

## 怎么玩

向左转 左箭头 向右转 右箭头 你可以按住鼠标左键来转向
