# 疯狂驾驶游戏

<a href="https://inkwengame.com/zh/games/drive-mad-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drive-mad-game/cover.jpg)

《疯狂驾驶》是一款赛车游戏，你将在布满障碍物的赛道上驾驶车辆。目标是完好无损地抵达终点线。你需要平衡车速，以免车辆翻覆。这听起来比实际更难，因为游戏中有许多令人兴奋且富有创意的特技和障碍等待你体验。你是否具备完成《疯狂驾驶》每一关的勇气？

## 怎么玩

前进转向 - W D X 上箭头 右箭头 鼠标点击  后退转向 - S A Z 下箭头 左箭头
