# 爬山

<a href="https://inkwengame.com/zh/games/hill-climbing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hill-climbing/cover.jpg)

爬山是一款爬山游戏，你将驾驶汽车穿越颠簸的道路。控制加速以避免事故。尽可能行驶更远的距离并创造记录。祝你好运

## 怎么玩

在桌面端 - 使用 D 键向右加速，A 键向左加速（相反方向）
在移动端 - 使用图形用户界面按钮来控制你的汽车
