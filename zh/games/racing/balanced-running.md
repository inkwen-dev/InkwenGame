# 平衡奔跑

<a href="https://inkwengame.com/zh/games/balanced-running" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/balanced-running/cover.jpg)

是时候展示你的技巧，让木偶在《平衡行走》游戏中行走了！一开始这可能会有点困难。你需要非常仔细地决定按住按钮的时间长短。如果按得太久，角色会迈出过长的步子，这可能导致失败。试着让步伐保持平衡，把角色带到终点吧！你还可以在双人模式下进行挑战，和朋友一起玩会更有趣！开始吧！

## 怎么玩

玩家1 W  在单人模式下，您也可以使用上箭头键；玩家2 使用上箭头键
