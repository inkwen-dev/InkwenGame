# 我能变身

<a href="https://inkwengame.com/zh/games/i-can-transform" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/i-can-transform/cover.jpg)

《我能变身》是一款2D动作平台游戏。在这款游戏中，你将使用特殊的服装，能够变身为机械物体（汽车、火箭、直升机、摩托车等），以避开障碍物，在关卡中收集漩涡宝石，并击败刺客（那些想要毁灭世界的人）。跨世界模式让你可以穿越众多著名电子游戏的世界，如果你能100%完成活动，将在活动结束时获得奖励。

## 怎么玩

点击屏幕或按空格键执行特殊动作
