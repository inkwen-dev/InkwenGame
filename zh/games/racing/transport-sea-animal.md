# 运输海洋动物

<a href="https://inkwengame.com/zh/games/transport-sea-animal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/transport-sea-animal/cover.jpg)

这是一款极具挑战性的游戏，你需要操控一辆卡车，将巨大的海洋动物从海滩上的一个地点运送到水族馆。展示你驾驶大型卡车在多山道路、多个坡道、急弯以及更多危险情况下的驾驶技巧。

## 怎么玩

WASD - 驾驶 空格键 - 刹车 C - 切换摄像机
