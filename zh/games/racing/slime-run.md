Slime Run 是一款有趣的动作游戏，你将控制一个 Slime 在竞技场中快速滑行，为你的领地涂上颜色。与其他 Slime 直接竞争，你需要灵活移动，并尽可能占据更多的彩色区域以取得胜利。节奏快、规则简单却充满戏剧性，Slime Run 带来激动人心且趣味十足的对决体验。
