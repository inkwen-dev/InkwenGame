# ATV Rush

<a href="https://inkwengame.com/zh/games/atv-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/atv-rush/cover.jpg)

ATV Rush 是一款 ATV 赛车速度游戏，你需要收集硬币并避开障碍物。随着时间推移，车辆速度会加快，因此驾驶难度也会增加。你有 3 条生命。在你的驾驶冒险中努力获得最高分数。

## 怎么玩

点击屏幕进行驾驶，或使用方向键
