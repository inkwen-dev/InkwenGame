# 自由城市驾驶

![cover](https://img.inkwengame.com/games/free-city-drive/cover.jpg)

自由城市驾驶是一款有趣的汽车模拟游戏，拥有多种车辆、汽车改装以及非常出色的都市环境。

## 怎么玩

使用 WASD 控制车辆 按左 Shift 使用氮气加速 按空格键使用手刹 按 Escape 或 Tab 键暂停/取消暂停 按 C 键切换摄像机
