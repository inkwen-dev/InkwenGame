# 火箭特技赛车

<a href="https://inkwengame.com/zh/games/rocket-stunt-cars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rocket-stunt-cars/cover.jpg)

一场漫长的冒险从在巨大沙漠地图上的《火箭特技赛车》游戏开始！这款游戏包含多个目标和有趣的模式。你可以在非常宽广的特技地图上驾驶你的汽车，也可以在城市交通中驾驶，或者在高速公路上驾驶。选择你想驾驶汽车的地方，让乐趣开始吧！你可以使用不同的摄像机模式，如驾驶舱视角和第三人称视角。

## 怎么玩

使用 W A S D 或方向键移动，NOS 加速，刹车 空格键，切换摄像机 C
