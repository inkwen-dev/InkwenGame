# 冒险驾驶游戏

<a href="https://inkwengame.com/zh/games/adventure-drivers-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/adventure-drivers-game/cover.jpg)

冒险驾驶是一款赛车游戏，你需要在其他赛车手之间争取第一名。你准备好开始一场驾驶冒险了吗？登上你的汽车，穿越热带地区，在这款激烈的赛车游戏中夺得第一。击败竞争对手，赢得奖杯，并收集金币和分数以解锁新车和升级。与朋友分享游戏，一起玩以最大化乐趣！

## 怎么玩

翻滚 - A D 或 左右箭头键 发射武器 - Enter 使用氮气加速 - Shift
