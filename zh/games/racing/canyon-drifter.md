# 峡谷漂流者

<a href="https://inkwengame.com/zh/games/canyon-drifter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/canyon-drifter/cover.jpg)

这是一款以高难度赛道和车辆调校为核心的2D摩托车越野游戏。根据泥泞路面和地形选择合适的车辆配置，通过倾斜车身保持平衡，轻松越过陡峭的爬坡和跳跃，并在排行榜上争夺最佳成绩。遇到怎么也过不去的赛道？那就去车库重新调校一下你的摩托车，它就能立刻通关了。

## 怎么玩

键盘：

- 油门 — 上箭头或 W

- 刹车/倒车 — 下箭头或 S

- 后倾（抬起前轮） — 左箭头或 A

- 前倾（降低车头） — 右箭头或 D

- 暂停 — Esc 或 P

- 重启 — R

手机端：

首次触摸屏幕时会出现四个虚拟按钮 — 油门和刹车分别位于右上角和左上角，前倾/后倾按钮位于底部。暂停和重启按钮位于右上角。
