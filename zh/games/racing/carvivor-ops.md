# 汽车幸存者行动

<a href="https://inkwengame.com/zh/games/carvivor-ops" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/carvivor-ops/cover.jpg)

《Carvivor Ops》是一款以汽车为主题的动作游戏，挑战玩家在有限的时间内抵御一波又一波愈发猛烈的警察追击。

## 怎么玩

驾驶武装超跑！

躲避警察追捕，发射火箭弹！升级装备，在无尽的追逐中生存下来，成为终极逃脱大师！

电脑操作：

↑（上箭头，W）：向上移动。

↓（下箭头，S）：向下移动。

←（左箭头，A）：向左移动。

→（右箭头，D）：向右移动。

手机操作：

使用屏幕上的按钮控制车辆！
