# Shipnt.io

<a href="https://inkwengame.com/zh/games/shipnt-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shipnt-io/cover.jpg)

Shipnt.io 是一款适合移动设备的协作物理游戏，你和其他玩家将一起帮助一艘被困在苏伊士运河中的船脱困。游戏的目标是尽快解救当前被困的船只，同时你还要在排行榜上与其他玩家竞争。

## 怎么玩

游戏中的角色会根据物理原理拉动船只。你通过拖拽和拉动角色来移动，但一旦松开，角色总会自动回到船上。如果没有其他玩家在场或他们断开连接，你可以使用两个角色来进一步移动。
