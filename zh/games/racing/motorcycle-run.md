# 摩托车跑

![cover](https://img.inkwengame.com/games/motorcycle-run/cover.jpg)

摩托车竞速游戏。看看你能跑得多快、多远。避开汽车和卡车。

## 怎么玩

使用方向键和A S D M键前进，刹车左右转向。也可以点击底部的按钮来控制摩托车

## 介绍
