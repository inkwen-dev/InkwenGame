# 真实卡车停车

<a href="https://inkwengame.com/zh/games/real-truck-parking" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/real-truck-parking/cover.jpg)

在《真实卡车停车》中，你需要驾驶一辆没有车身的大卡车。任务是沿着用混凝土块和集装箱围起来的指定路径行驶，并到达画在沥青上的矩形区域——这就是停车场。在左上角你会看到一个计时器，它会倒数一秒钟，这意味着你需要在时间结束前完成停车。如果你成功撞到停车场的围栏，就算关卡完成。

## 怎么玩

使用方向键驾驶，或使用设备上的触摸按钮
