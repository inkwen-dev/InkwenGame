# 浪行者

<a href="https://inkwengame.com/zh/games/wave-rider" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wave-rider/cover.jpg)

浪行者是一款免费的在线船类游戏，既具挑战性又充满乐趣。玩家必须驾驭自己的船只穿越波浪并避开障碍物。游戏的目标是在不翻船的情况下抵达终点线。

## 怎么玩

桌面控制：点击鼠标右键以左右移动船只。移动设备：点击屏幕以左右移动船只。控制与指示：分数和关卡显示在屏幕中间上方。
