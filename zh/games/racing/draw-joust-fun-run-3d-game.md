# Draw Joust - 趣味跑酷3D游戏

<a href="https://inkwengame.com/zh/games/draw-joust-fun-run-3d-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/draw-joust-fun-run-3d-game/cover.jpg)

Draw Joust 是一款战斗放松游戏。玩家将在一个非常开阔的场地上驾驶自己的车辆，并携带各种奇妙的武器相互对决。你可以随意改变你的车辆形状，但必须在战斗开始前完成这一操作。武器将随机分配。一开始，斧头、标枪或铁皮都可以在 Draw Joust 中使用，尽情享受乐趣吧！
