# 4X4 越野拉力赛 3D

<a href="https://inkwengame.com/zh/games/4x4-off-road-rally-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/4x4-off-road-rally-3d/cover.jpg)

这是一款越野汽车驾驶模拟游戏，包含四种不同的3D拉力赛车和十个关卡。你需要驾驶车辆，在每个关卡中按时抵达终点灯光区域。如果你掉进河里，游戏将直接结束。保持冷静，稳定驾驶，时间总是足够的！

## 怎么玩

使用 WASD 或方向键移动
