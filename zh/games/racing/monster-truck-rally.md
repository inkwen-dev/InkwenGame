# 怪物卡车拉力赛

<a href="https://inkwengame.com/zh/games/monster-truck-rally" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-truck-rally/cover.jpg)

怪物卡车竞速是一款3D游戏，你将体验到酷炫的怪物卡车、富有挑战性的比赛以及越野赛道。选择你的怪物卡车，享受竞速乐趣，尽情玩耍。特性 • 3种游戏模式 • 多个关卡 • 多种怪物卡车皮肤

## 怎么玩

使用WASD控制怪物卡车，按C键切换摄像机视角
