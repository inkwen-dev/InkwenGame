# 改装汽车特技

<a href="https://inkwengame.com/zh/games/tuning-cars-stunts" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tuning-cars-stunts/cover.jpg)

你可以选择5辆汽车进行娱乐。改装汽车：保险杠、引擎盖、排气管、轮毂、尾翼。汽车升级分为3个阶段，加速性能取决于此。更改颜色：车身、玻璃、烟雾、霓虹灯。更改相机图形效果：4种预设或关闭。更改游戏图形：低、中、高、极致。

## 怎么玩

WASD 或 方向键 - 驾驶 T - 时间变慢 R ESC - 重置场景 Tab - 下一辆车 鼠标滚轮 - 相机距离 Enter - 重置汽车 F - 氮气加速 添加力量 C - 相机视角 I - 信息面板 Q - 音乐 开关
