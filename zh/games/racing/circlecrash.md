# CircleCrash

<a href="https://inkwengame.com/zh/games/circlecrash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/circlecrash/cover.jpg)

控制车辆在环形道路上行驶。在行驶过程中会有其他车辆，避免与其他车辆发生碰撞。行驶过程中会获得金币，可用于解锁新车辆。快来体验吧！
