# 猫的进化

<a href="https://inkwengame.com/zh/games/cat-evolution" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cat-evolution/cover.jpg)

猫的进化是一款有趣的跑酷游戏。你将扮演一只猫，作为肉食动物，收集肉块以更快地进化，而光亮的蔬菜会降低你的等级。别忘了收集钻石，它们可以用于升级！从猫进化成老虎，甚至更进一步，到达终点线征服所有动物！
