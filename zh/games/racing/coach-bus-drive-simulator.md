# 长途巴士驾驶模拟器

<a href="https://inkwengame.com/zh/games/coach-bus-drive-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coach-bus-drive-simulator/cover.jpg)

长途巴士驾驶模拟器是一款经典的3D驾驶模拟游戏。你可以从多个巴士车型中进行选择，并体验三种不同的游戏模式。你需要驾驶巴士来接载乘客。屏幕左上角的地图会显示你前往最近巴士站的路线，你需在那里接载乘客。这是一款逼真的模拟游戏，让你测试自己的驾驶技巧。

## 怎么玩

操作方式 使用WASD或方向键移动 空格键使用手刹 C键切换摄像机视角
