# 巴士订单3D

<a href="https://inkwengame.com/zh/games/bus-order-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bus-order-3d/cover.jpg)

巴士订单3D是一款匹配谜题游戏。有三种游戏模式可供选择。第一种是帮助乘客找到他们的巴士，按颜色分类并送他们去度假！第二种是在空间中放置相同颜色的硬币。第三种是转动螺钉，将木块从板上移除。其可爱的造型和多样的挑战使其成为必玩之作。快来挑战自己，看看你能否完成所有关卡！

## 怎么玩

在电脑上 使用鼠标点击进行游戏 在手机上 触摸屏幕进行游戏
