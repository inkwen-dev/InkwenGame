# 打字冲刺

![cover](https://img.inkwengame.com/games/type-sprint/cover.jpg)

你擅长在键盘或手机上打字吗？《打字冲刺》是一款结合了竞速跑酷和打字放松元素的3D Stickman 游戏。你需要快速打字，为你的角色创造前进的平台，让他在最前面奔跑。我认为在电脑上打字比在手机上更容易。祝你好运，玩得开心！

## 怎么玩

键盘上的字母或在屏幕上点击虚拟键盘
