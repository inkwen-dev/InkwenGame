# 面具进化3D

<a href="https://inkwengame.com/zh/games/mask-evolution-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mask-evolution-3d/cover.jpg)

《面具进化3D》是一款跑酷游戏。通过数字门移动面具，提升面具的价值。你还可以收集装饰品和随从，让你的面具更加艺术化。最后，拍卖你的面具，以高价出售并赚取更多金钱。请注意，小心道路上的障碍物，如尖刺，它们会降低你的面具价值，当面具价值为0时，游戏失败。准备好开启一段激动人心的旅程，打造属于你自己的面具吧！
