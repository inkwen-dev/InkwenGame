# 交通速度赛车

<a href="https://inkwengame.com/zh/games/traffic-speed-racer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/traffic-speed-racer/cover.jpg)

交通速度赛车是一款有趣的驾驶游戏。在充满车辆的道路上驾驶你的汽车。点击道路以换道，避免与其他车辆发生碰撞。除了车辆外，道路上还有许多路障。所以要小心驾驶。你能到达目的地并完成所有关卡吗？尽情享受吧！
