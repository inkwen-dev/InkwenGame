这是一款以赛车为主题的记忆游戏。点击卡片进行翻转，找到两张带有相同赛车的卡片。游戏包含多个关卡，随着游戏进程推进，卡片数量会逐渐增加。最多可使用32张卡片进行游戏。使用鼠标来玩这款游戏。
