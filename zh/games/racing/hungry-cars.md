# 饥饿的汽车

<a href="https://inkwengame.com/zh/games/hungry-cars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hungry-cars/cover.jpg)

你是一辆通过吞噬其他车辆来变得更强大的汽车！每次奔跑都能变得更强，并解锁自定义选项！

## 怎么玩

攻击低等级车辆来吞噬它们，从而提升自身实力。避开高等级车辆，否则会被损坏。

桌面控制：

↑（上箭头）：向上移动。

↓（下箭头）：向下移动。

←（左箭头）：向左移动。

→（右箭头）：向右移动。

移动控制：

屏幕摇杆：拖动摇杆即可向各个方向移动。
