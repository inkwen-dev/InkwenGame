# 城市驾驶者

<a href="https://inkwengame.com/zh/games/stadtfahrer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stadtfahrer/cover.jpg)

特性：• 可驾驶多种汽车和摩托车；• 完全自由，可从他人那里夺取汽车

## 怎么玩

控制 WASD 或方向键 驾驶汽车 空格 手刹 C 键 切换视角 相机切换 汽车充电 R 重置场景 F 上下车 方向键上下调整
