# K-Game 玻璃桥生存

K Game 玻璃桥生存是一款推荐的第三人称跳跃街机游戏，采用3D鱿鱼游戏角色。为了生存并完成当前关卡，您需要在每个关卡中跳跃并越过玻璃桥。您将获得通往终点平台的正确路径。只要记住这些路径并按照顺序跳跃即可。每通过一个关卡，方块数量将会增加。祝你好运，玩得愉快！
