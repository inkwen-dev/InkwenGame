# 极限骑行

<a href="https://inkwengame.com/zh/games/cycle-extreme" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cycle-extreme/cover.jpg)

参与一场山地自行车下坡竞速挑战。你将操控一辆从山间疾驰而下的自行车。小心——赛道非常陡峭，前方有多个障碍物和致命的深坑。小心谨慎，以最快的速度完成20个关卡，争取每关获得3颗星！

## 怎么玩

上或W - 加速 下或S - 刹车 左或A - 向左倾斜 右或D - 向右倾斜
