# 动物变身赛

<a href="https://inkwengame.com/zh/games/animal-transform-race" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-transform-race/cover.jpg)

动物变形赛是一款考验反应能力的趣味游戏，不同类型的动物将在赛场上展开角逐。每种动物都有其独特的优势，在某些赛道上速度飞快，而在另一些赛道上则速度缓慢。你需要做出正确的选择，才能在比赛中脱颖而出。选择动物的速度越快，获得的优势就越多。你可以使用比赛赢得的金币，在市场中解锁新的动物。

## 怎么玩

您可以使用鼠标或触摸控制来切换动物。在双人模式下，您可以使用“A、S、D”和“J、K、L”键作为切换动物的快捷键。
