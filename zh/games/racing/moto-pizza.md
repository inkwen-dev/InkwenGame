# 摩托披萨

<a href="https://inkwengame.com/zh/games/moto-pizza" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/moto-pizza/cover.jpg)

摩托披萨配送的目标非常有趣。你的任务是骑上披萨店的货运自行车，尽快将披萨送达客户，避免迟到。将你的摩托车停在道路上高亮显示的区域。停车后，你需要让披萨配送员下到地面，将披萨送到客户家门口。
