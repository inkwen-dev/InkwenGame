Vemon Run 3D 带来一款有趣的街机跑酷游戏。踏入一个生动的 3D 平台世界。你将化身敏捷的 Vemon，向前冲刺，躲避障碍物，开启一场惊险刺激的跑酷冒险。灵活操控角色左右闪避，以飞快的速度奔跑！持续收集更多宝石来升级你的角色。通过正数编号的门。击败敌人以获得升级，并变身成为超级英雄！
