# 救护车模拟器

<a href="https://inkwengame.com/zh/games/ambulance-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ambulance-simulator/cover.jpg)

救护车模拟器是一款3D游戏，你将扮演一名救护车司机，拯救人类生命。你的任务是将急救人员送达事故地点，接上病人并送往医院，你有一个小地图来指引你在街道上的行进路线。在困难情况下，你需要驾驶直升机前往现场。完成你的工作，拯救人们的生命。

## 怎么玩

使用WASD键控制救护车
