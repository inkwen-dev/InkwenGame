# 鼠标按键

<a href="https://inkwengame.com/zh/games/mouse-key" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mouse-key/cover.jpg)

鼠标按键是一款在游戏中的鼠标控制类游戏，鼠标通过缠绕来运作，当你撞到按键时，鼠标会获得更强的动力前进。你走得越远，得分就越高。尽情享受吧！

## 怎么玩

触摸或点击屏幕上的点，鼠标就会朝那个方向移动
