# 停车场大乱斗

<a href="https://inkwengame.com/zh/games/parking-lot-jam" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/parking-lot-jam/cover.jpg)

深入商业世界，成为自己停车场的经理！让汽车进入并出售停车票给司机，以解锁新的机会。在这个引人入胜的浏览器游戏中，你需要完全管理整个停车场的运作。积累钞票购买新的停车位，提升性能，最终雇佣一名船员为你工作！

## 怎么玩

1 用手指轻触屏幕或按下鼠标左键，出现操纵杆来控制玩家 2 前往入口的栏杆处，放行车辆 3 到黄色自动取款机处领取停车票，然后前往车辆将票交给司机
