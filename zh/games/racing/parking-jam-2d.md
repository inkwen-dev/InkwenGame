# 停车堵塞 2D

<a href="https://inkwengame.com/zh/games/parking-jam-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/parking-jam-2d/cover.jpg)

- 交通堵塞游戏的目标是通过移动其他车辆为白色救护车腾出空间，找到让白色汽车离开的路径。出口是一个激光系统，若未找到钥匙则无法通过。你必须先将白色救护车开到钥匙位置，才能打开激光门。请注意，步数和能量等级有限，需在限制内成功逃离交通堵塞。

## 怎么玩

通过向左、右、上、下四个方向滑动来控制车辆
