# 漂移挑战游戏

<a href="https://inkwengame.com/zh/games/drift-challenge-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drift-challenge-game/cover.jpg)

“漂移挑战”是一款赛车游戏，你需要通过在赛道上漂移来获得分数。尽可能多地在赛道上滑行，以积累大量分数并达到目标分数。你必须在目标时间内完成终点线，超越目标分数以解锁新关卡。一款超级有趣且富有挑战性的赛车游戏！尽情享受吧！

## 怎么玩

左箭头和右箭头 - 左转 右转 上箭头 - 加速 下箭头 - 刹车 空格键 - 进行漂移
