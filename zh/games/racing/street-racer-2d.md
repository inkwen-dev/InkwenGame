# 街头赛车2D

<a href="https://inkwengame.com/zh/games/street-racer-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/street-racer-2d/cover.jpg)

《街头赛车2》是一款以直线加速赛为主题的驾驶游戏，你的目标是赢得比赛、升级车辆并购买新车。这款游戏融合了多种刺激的游戏模式，包括直线加速赛、越野挑战和街机风格的乐趣。每种模式都能带来截然不同的体验，无论是追求高速刺激、征服崎岖地形，还是享受肾上腺素飙升的赛道竞速。

## 怎么玩

PC 控制

A / 左箭头键 = 倒车

D / 右箭头键 = 加速

W / 上箭头键 = 升档

S / 下箭头键 = 降档

R = 重新开始

P = 暂停

Shift = 加速

手机控制

点击屏幕上的游戏内按钮即可开始游戏。
