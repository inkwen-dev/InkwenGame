# 战场卡车模拟器

<a href="https://inkwengame.com/zh/games/battlefield-truck-simulator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/battlefield-truck-simulator/cover.jpg)

这是一款带有3D卡车和坦克的军事运输汽车驾驶模拟游戏。你的目标是在所有关卡中将货物运送到军事基地中标记的绿色位置。25秒绝对足够你完成任务。不要让指挥官失望！

## 怎么玩
