# 六边形汽车

<a href="https://inkwengame.com/zh/games/hexa-cars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hexa-cars/cover.jpg)

六边形汽车游戏是一款有趣的io生存游戏。目标是在不同的地图上坚持到最后，不要掉下去！每张不同的地图都需要不同的技巧。你可以单人或双人游玩六边形汽车游戏。通过收集的金币可以解锁新汽车。尽情享受吧！

## 怎么玩

单人模式：使用方向键移动，空格键跳跃。双人模式：玩家1 使用 W A S D 移动，Q 键跳跃；玩家2 使用方向键移动，空格键跳跃
