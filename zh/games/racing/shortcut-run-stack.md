# 快捷路线堆叠

![cover](https://img.inkwengame.com/games/shortcut-run-stack/cover.jpg)

与对手竞速，尽可能多地拾取沿途的板子进行堆叠！如果你足够聪明，就避开障碍，建造桥梁以走捷径，在其他人之前冲过终点线！作弊从未如此帅气！一款简单易上手、操作高效的休闲游戏。

## 怎么玩

当你建造捷径时，移动速度会加快。减少弯道意味着你将冲刺通过它们。捷径越长，你的速度提升就越明显。
