# 跑或死

<a href="https://inkwengame.com/zh/games/run-or-die" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/run-or-die/cover.jpg)

凭借你能够二段跳的能力，你只剩下几个选择：奔跑或死亡。在战火蹂躏过的地貌中不停前行，看看你的决心能带你走多远。

## 怎么玩

点击屏幕跳跃，再次点击以二段跳，不要撞到墙壁
