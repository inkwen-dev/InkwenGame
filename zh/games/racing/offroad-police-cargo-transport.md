# 越野警察货运运输

<a href="https://inkwengame.com/zh/games/offroad-police-cargo-transport" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/offroad-police-cargo-transport/cover.jpg)

越野警察货运运输是一款不错的越野驾驶游戏，您将在蜿蜒的赛道上驾驶各种车辆，将货物从一个地方运送到另一个地方。城市居民需要食物、医疗用品和其他必需品，而您就是负责在整个城市运送货物的人。

## 怎么玩

方向键 ASWD - 控制车辆移动 Shift键 - 启动直升机升空 ASWD - 控制直升机移动 空格键 - 车辆刹车并下降
