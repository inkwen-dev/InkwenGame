# 超级跑车停车

<a href="https://inkwengame.com/zh/games/supercars-parking" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/supercars-parking/cover.jpg)

超级跑车停车是一款驾驶技巧游戏。驾驶你的兰博基尼，找到停车位。你需要获得3颗星才能看到你的车位位置。在10个不同的多边形区域中，检验你的前向、倒车或平行停车技巧。祝你好运！

## 怎么玩

方向键或触摸控制
