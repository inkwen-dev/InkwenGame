# 特技飞机

你是否曾梦想过驾驶一架经过大幅改装的战争飞机，专门用于纯粹的破坏？在这款充满动作与生存元素的3D飞机竞速游戏中，飞上天空，在激烈的3D环境中展开竞速！驾驶自定义的二战风格飞机，在高风险的比赛中挑战重重关卡、收集强化道具，并体验真实的3D物理效果！终极战争飞机模拟器等你来挑战！

## 怎么玩

- 玩家1使用方向键 上 下 左 右 控制 - 左右转向 上下俯仰 - 加速 X - 刹车 C - 强化道具 空格键 - 摄像机 N - 暂停 P 或 Esc
玩家2移动控制键 - WASD 键 W A S D
你可以自定义按键
