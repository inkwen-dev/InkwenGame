# 越野巴士模拟器 2019

<a href="https://inkwengame.com/zh/games/offroad-bus-simulator-2019" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/offroad-bus-simulator-2019/cover.jpg)

《越野巴士模拟器 2019》是一款有趣的模拟游戏，你可以在危险的高速公路上驾驶巴士。你的任务是从指定上车点接载乘客，并将他们安全送达目的地。务必避免与其他交通车辆发生碰撞。

## 怎么玩

方向键 ASDW - 移动巴士 空格键 - 刹车
