# F1 拼图游戏

<a href="https://inkwengame.com/zh/games/f1-slide-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/f1-slide-puzzle/cover.jpg)

F1 拼图游戏是一款简单的 HTML5 经典拼图游戏。将 F1 图像的碎片在方块间移动，以正确的顺序排列，重新组合成完整的图像。点击或触摸一个方块，将其移至相邻的空白位置。尽情享受吧。
