# 公式特技

<a href="https://inkwengame.com/zh/games/formula-stunts" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/formula-stunts/cover.jpg)

《公式特技》是3D赛车模拟游戏的第二部续作。玩家可以切换四种不同颜色的车辆。一张大型地图上充满了障碍物和可以完成特技的地方。这款游戏适合所有年龄段的玩家。

## 怎么玩

WASD方向键 - 驾驶 C - 切换摄像头 Tab - 切换ATV Enter - 重新开始ATV R Esc - 重置场景 T - 慢动作 F - 修复ATV
