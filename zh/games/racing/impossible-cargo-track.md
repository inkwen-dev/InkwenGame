# 不可能货物轨道

<a href="https://inkwengame.com/zh/games/impossible-cargo-track" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/impossible-cargo-track/cover.jpg)

Impossible Cargo Track 是今年最棒的卡车驾驶游戏，玩家将有机会在这条不可能的赛道上驾驶强大的货运卡车。用户面临的主要问题是转弯，因为卡车体积巨大，转弯成为真正的挑战，需要玩家应对。必须保持卡车的平衡，因为卡车后部装载了各种货物，如果卡车失去平衡，货物和货运物品可能会被损坏。

## 怎么玩

使用 WASD 或方向键来玩这个游戏
