# 果冻跑 2048

<a href="https://inkwengame.com/zh/games/jelly-run-2048" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jelly-run-2048/cover.jpg)

《果冻跑 2048》是一款富有挑战性的休闲益智游戏，将经典的 2048 数字合并玩法与激动人心的跑酷游戏相结合。通过向左或向右滑动来引导你的果冻方块，连接和断开方块。合并方块以获得双倍数字，达到 2048 或更高。当果冻方块与相同数字的方块碰撞时，它们会合并成更大的数字。

## 怎么玩
