# 交通速度赛车

<a href="https://inkwengame.com/zh/games/traffic-speed-racing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/traffic-speed-racing/cover.jpg)

在游戏《交通速度赛车》中，我们将与一位年轻人一起参加充满障碍物的赛车比赛。这些障碍物可能包括地雷、坑洞和其他危险。你将坐在汽车方向盘后，必须以尽可能高的速度在高速公路上飞驰，并在严格规定的时间内完成比赛。所有障碍物都必须以高速通过。道路上还可能出现奖励道具。
