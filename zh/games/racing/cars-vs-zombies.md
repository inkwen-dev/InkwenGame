# 汽车大战僵尸

<a href="https://inkwengame.com/zh/games/cars-vs-zombies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cars-vs-zombies/cover.jpg)

《汽车大战僵尸》是一款街机风格的车辆生存动作游戏。驾驶你的汽车，消灭一波又一波的僵尸，并在竞技场中摧毁各种互动环境。收集资源，在车库中升级你的车辆：提升性能、安装可拆卸装甲、装备加速器。游戏提供多种地图和车辆类型。

## 怎么玩

键盘和鼠标控制（台式机/PC）：

• W / 上箭头 — 加速（油门）

• S / 下箭头 — 刹车和倒车

• A / D 或 左 / 右箭头 — 转向和空中平衡（飞行中倾斜）

• 左Shift / 空格键 — 火箭助推器（氮气加速）

• 鼠标左键 — 发射机载武器

• 鼠标右键 — 触发慢动作

• Esc / P / Tab — 暂停菜单

触控控制（移动设备）：

• 屏幕踏板 — 油门和刹车/倒车

• 左 / 右按钮 — 转向和空中平衡

• 氮气按钮 — 激活助推器
