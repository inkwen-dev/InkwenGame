# 驾驶任务

![cover](https://img.inkwengame.com/games/drive-quest/cover.jpg)

《Drive Quest》是一款开放世界驾驶冒险游戏，道路任你探索。穿梭于城市之间，发现隐藏区域，挑战漂移、特技和速度测试等刺激项目。游戏提供35辆可定制车辆，以及包含港口、高速公路和秘密区域等丰富细节的地图，带来无尽的驾驶乐趣和风格独特的游戏体验。

## 怎么玩

使用 WASD 键或方向键控制车辆行驶

空格键用作手刹

使用 C 键切换视角
