# 战斗竞技场竞速获胜

![cover](https://img.inkwengame.com/games/battle-arena-race-to-win/cover.jpg)

《战斗竞技场竞速》是一款刺激的竞技场游戏，你将加入红队或蓝队，参与激烈的赛车大战。从各种赛车中选择你的座驾，收集并升级它们，称霸竞技场。平衡速度、耐久度和加速性能，才能战胜对手。为你的赛车配备战略道具，不断升级，攀登排行榜，带领你的队伍走向胜利！

## 怎么玩

W / 上箭头键 = 加速

S / 下箭头键 = 后退

A / 左箭头键 = 左转

D / 右箭头键 = 右转

R = 恢复原位

空格键 = 手刹（漂移）

左Shift键 = 氮气加速
