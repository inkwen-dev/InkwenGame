# Buggy Simulator Sandbox 3D

<a href="https://inkwengame.com/zh/games/buggy-simulator-sandbox-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/buggy-simulator-sandbox-3d/cover.jpg)

这是一个模拟真实物理效果的游戏，玩家可以在各种地图上驾驶车辆，观察车辆及其车轮的运行情况。游戏提供多种车辆供玩家选择，玩家可以随时切换并操控任意车辆。探索包含城市和桥梁的地图，飞跃山丘，甚至冲下桥梁。在测试区域，玩家可以摧毁金字塔，评估悬挂系统的性能等等。

## 怎么玩

操作说明：

“WASD” - 驾驶/转向

“空格键” - 手刹

“C” - 切换视角

“Shift” - 氮气加速

“R” - 重置车辆

“N” - 下一辆车

“Tab” - 菜单

其他操作请参考游戏界面。

移动设备用户请使用游戏界面。

游戏目标：尽情享受驾驶乐趣。
