# 拆毁竞技场挑战

<a href="https://inkwengame.com/zh/games/demolition-derby-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/demolition-derby-challenge/cover.jpg)

拆毁竞技场挑战是一款极限游戏，适合喜欢用车进行破坏或毁灭挑战的玩家。游戏任务非常简单：你需要快速驾驶你的汽车避开其他车辆，然后大胆地猛烈撞击其他车辆，使它们从赛道上掉落或掉入漩涡中。不要让其他车辆损坏你，向他们展示你的操控技巧，这是一场生死竞速。

## 怎么玩

使用 WASD 或方向键驾驶，空格键 - 手刹
