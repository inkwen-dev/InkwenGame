# 越野大师挑战

<a href="https://inkwengame.com/zh/games/offroad-masters-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/offroad-masters-challenge/cover.jpg)

你是否想在《越野大师挑战》游戏中，驾驶你的越野卡车穿越大陆、土地和各个国家，开启一段冒险之旅？在这段旅程中，你可以打造自己的越野车辆职业生涯，参与自由的SUV驾驶冒险，甚至在巨大的越野赛车碰撞竞技场中撞毁你的卡车！这些车辆支持改装，例如发动机改装或轮胎改装。你可以选择单人游戏模式，也可以选择双人游戏模式…

## 怎么玩

单人游戏 玩家1 移动 W A S D 或 方向键 移动摄像机 鼠标和左键切换摄像机 C 重新开始 R 打开灯光 F 双人游戏 玩家1 移动 方向键 切换摄像机 C 重置车辆位置
