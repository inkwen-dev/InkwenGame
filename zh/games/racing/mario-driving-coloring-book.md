# 马里奥驾驶涂色书

<a href="https://inkwengame.com/zh/games/mario-driving-coloring-book" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mario-driving-coloring-book/cover.jpg)

在这个与超级马里奥一起的游戏里，你将找到六幅不同的图片，需要尽可能快地为它们上色，以在游戏结束时获得高分。你有24种不同的颜色可供选择。你还可以保存已上色的图像或将其打印出来。尽情享受吧！
