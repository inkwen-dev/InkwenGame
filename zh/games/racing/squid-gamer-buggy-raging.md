# 鱿鱼玩家越野车狂飙

<a href="https://inkwengame.com/zh/games/squid-gamer-buggy-raging" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-gamer-buggy-raging/cover.jpg)

这是一款基础的竞速游戏，你将驾驶一辆越野车在海滨赛道上行驶，并尽可能地跑得更远。然而，你必须避开赛道上的其他越野车和障碍物，否则碰撞会导致失去一颗生命值。如果你失去了全部四颗生命值，你将被淘汰出游戏！你的得分取决于你的表现，所以尽你所能长时间保持在赛道上吧！
