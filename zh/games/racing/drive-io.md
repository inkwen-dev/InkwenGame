# Drive.IO

<a href="https://inkwengame.com/zh/games/drive-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drive-io/cover.jpg)

Drive.IO 是一款智能交通控制游戏，你将负责管理繁忙城市十字路口的车辆！目标是在正确的时间让车辆通过，以避免碰撞。反应迅速、精准且保持警觉——一个失误就可能导致交通灾难！同时控制多辆汽车，测试你的反应能力，并享受充满生机的色彩缤纷的低多边形城市。你能让道路安全多久？

## 怎么玩

使用电脑鼠标来停止汽车
