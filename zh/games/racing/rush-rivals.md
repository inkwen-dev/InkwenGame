# 冲刺对手

<a href="https://inkwengame.com/zh/games/rush-rivals" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rush-rivals/cover.jpg)

在车流中穿梭，收集强力皮卡，超越对手。赢取金币，升级车库，解锁新车，征服不断升级的高速公路竞速赛（支持竖屏和横屏模式）。

## 怎么玩

按住屏幕或鼠标按钮加速，左右拖动控制方向。在键盘上，按住空格键或回车键，然后使用 A/D 键或方向键控制方向。躲避车辆，抢夺皮卡，争夺第一名。
