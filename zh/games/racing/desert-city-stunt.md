# 沙漠城市特技

<a href="https://inkwengame.com/zh/games/desert-city-stunt" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/desert-city-stunt/cover.jpg)

《沙漠城市特技》是一款模拟游戏，让你体验在沙漠城市中驾驶的乐趣。在时间耗尽前尝试完成游戏中的6个不同关卡！每通过一关就会解锁一辆新车，让你在接下来的关卡中更加强大！使用装甲车辆穿越障碍物。你还可以在自由驾驶模式下随意完成一些酷炫特技，无需担心时间限制！

## 怎么玩

玩家1 移动 方向键 氮气 N 回头 B 玩家2 移动 W A S D 氮气 T 回头 C 重生 R
