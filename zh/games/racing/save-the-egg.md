# 拯救鸡蛋

<a href="https://inkwengame.com/zh/games/save-the-egg" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-egg/cover.jpg)

拯救鸡蛋是一款在坡道上驾驶汽车的游戏，车顶上放着一个鸡蛋。只有一个重要的任务：不要让鸡蛋掉下来。小心驾驶，尽可能行驶更远的距离。这并不容易，祝你好运

## 怎么玩

在桌面端 - 使用 A 键或右键、左键来驾驶汽车；在移动端 - 使用图形用户界面按钮来驾驶汽车
