# Pickup Driver

<a href="https://inkwengame.com/zh/games/pickup-driver" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pickup-driver/cover.jpg)

驾驶你的皮卡，完成具有挑战性的停车任务，或只是在美丽的山区随意漫游。

## 怎么玩

- 使用 WASD 或方向键驾驶皮卡 - 按 C 键切换摄像头 - 按空格键使用手刹

## 介绍
