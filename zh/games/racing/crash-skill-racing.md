## 怎么玩

键盘：

WASD / 方向键 = 移动

空格键 = 手刹

N = 氮气加速

B = 启动/停止引擎

Q / E = 左/右转向灯

H = 切换前大灯

G = 危险警告灯（双转向灯）

V = 切换视角

R = 重置车辆

F = 车辆修复

Shift = 升档

Ctrl = 降档

鼠标 = 移动视角

手柄：

左摇杆 = 转向

RT / R2 = 加速

LT / L2 = 刹车

A / X = 氮气加速

X / 方块 = 启动/停止引擎

Y / 三角 = 重置车辆

B / 圆圈 = 手刹

方向键 ← / → = 左/右转向灯

方向键 ↑ = 切换前大灯

方向键 ↓ = 危险警告灯（双转向灯）

RB / R1 = 升档

LB / L1 = 降档

右摇杆 = 移动视角

R3（按下摇杆） = 切换视角
