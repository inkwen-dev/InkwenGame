# 摩托车3D

<a href="https://inkwengame.com/zh/games/motorbike-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/motorbike-3d/cover.jpg)

你想成为著名的摩托车赛车手吗？Shinecool特技摩托车是一款带有新街机游戏元素的驾驶游戏，采用3D艺术风格。你的任务是驾驶一辆越野摩托车到达赛道终点，但这注定是一场非同寻常的比赛，因为你需要与对手竞争，你可以用踢腿和其他动作将他们从摩托车上踢下去。你必须注意避开赛道上的障碍物，同时收集金币。

## 怎么玩

WASD或方向键 - 移动 空格键 - 氮气加速
