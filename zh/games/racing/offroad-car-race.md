# 越野赛车

<a href="https://inkwengame.com/zh/games/offroad-car-race" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/offroad-car-race/cover.jpg)

越野赛车是一款3D游戏，你将在山地赛道上驾驶一些酷炫的跑车进行竞速，这次骑行需要良好的驾驶技巧。特性 • 多个关卡 • 优秀的图形效果

## 怎么玩

使用 WASD 控制车辆，按 C 键切换摄像头，按 Escape 键开启/关闭暂停
