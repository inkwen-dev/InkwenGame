# 可爱的狂热

<a href="https://inkwengame.com/zh/games/lovely-mania" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lovely-mania/cover.jpg)

《可爱的狂热》是一款快速节奏的心形匹配游戏。将你的心形朝向相同颜色的心形发送，它会收集该行中的所有心形。心形行不断向下移动，追逐着你的心形，因此要迅速行动，收集每一行。你的心形颜色会不断变化，所以在发送之前务必检查清楚。你可以持续游玩一局，直到其他心形不再追击你。
