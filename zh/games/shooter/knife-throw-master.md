# 飞刀大师

<a href="https://inkwengame.com/zh/games/knife-throw-master" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/knife-throw-master/cover.jpg)

飞刀大师是一款考验反应力和技巧的趣味游戏，你需要展示你的飞刀投掷技巧！在每个挑战中，你必须将所有的飞刀投进一个旋转的水果板上，并解锁特殊飞刀。你不能击中任何已固定在旋转板上的飞刀。收集糖果以获得更多的生命，或观看广告来收集爱心。尽情享受吧！
