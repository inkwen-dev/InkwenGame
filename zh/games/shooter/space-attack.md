# 太空攻击

<a href="https://inkwengame.com/zh/games/space-attack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-attack/cover.jpg)

在太空战争中，你的任务是尽可能长时间地保护地球免受小行星和小行星的袭击！使用鼠标移动并射击。每关都有一定数量的弹药，击中目标越多，得分越高。在关卡结束时，可以获得额外分数和弹药。游戏还设有奖励：三种类型的飞船，三种类型的激光，以及提升飞船生命值的保护功能。

## 怎么玩

使用鼠标或点击屏幕来玩游戏
