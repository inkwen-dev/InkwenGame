# Roblox世界射击

<a href="https://inkwengame.com/zh/games/roblox-world-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roblox-world-shooter/cover.jpg)

管理你的小角色，见证他在迷你障碍赛战争游戏中永无止境的冲突中前行，这是一款在Roblox环境中设置的动作丰富的3D游戏。拥有超过十个独特且富有挑战性的关卡，这款精彩的游戏触手可及。不断奔跑以避开敌军部队的浪潮，他们一旦看到你就会向你开火，瞄准并射击所有敌人。当你击败敌人时，会获得金币，可用于解锁具有独特能力的额外角色。

## 怎么玩

控制方式 WASD和键盘方向键移动，左键射击，右键瞄准，R键充能，F键互动，Ctrl键奔跑，空格键跳跃
