# 神庙目标

<a href="https://inkwengame.com/zh/games/temple-targets" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/temple-targets/cover.jpg)

神庙目标是一款令人费解的击中目标解谜游戏，考验你的规划能力和精准度。你的任务是引导你的玩家物体穿越充满神秘反射镜的古老神庙房间，计算出完美的路径以击中隐藏的目标。每个反射镜都会使你的轨迹改变90度，因此精心规划是掌握每一关的关键。

## 怎么玩

规划并发射 点击以更改物体的方向
