# 气球爆炸游戏

<a href="https://inkwengame.com/zh/games/pop-the-balloons-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pop-the-balloons-game/cover.jpg)

使用大炮瞄准并射击以炸破气球。这款游戏分为两个部分。第一部分是训练你使用大炮，你需要炸破一系列随机放置的气球。游戏的第二部分你也需要使用大炮，但这次要射击的是热气球，而不是普通气球。第二部分的游戏拥有无限数量的大炮弹药。如果超过5个热气球从你身边飞过，游戏就结束了。

## 怎么玩

触摸游戏屏幕来瞄准和发射大炮。长按游戏屏幕可增加力量。尽可能多地炸破气球。如果你在电脑上玩，请使用鼠标进行瞄准和射击。按住鼠标左键可增强射击力度。
