# 僵尸屋

<a href="https://inkwengame.com/zh/games/the-zombie-house" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-zombie-house/cover.jpg)

保护你的家园免受无尽僵尸浪潮的侵袭！击败僵尸以收集金币和能力掉落。使用金币升级你的角色和房屋。每一关都会让僵尸变得更强大。你能坚持多久？

## 怎么玩

PC 使用 WASD 移动，并点击僵尸以朝该方向射击。移动设备 使用左侧摇杆移动，右侧摇杆瞄准并射击
