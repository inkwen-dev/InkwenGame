# 坠落圆盘

<a href="https://inkwengame.com/zh/games/fall-disk" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fall-disk/cover.jpg)

坠落圆盘是一款射击益智游戏，你需要用屏幕下方的球击中屏幕上方的圆盘。圆盘会左右移动，难以击中。球会缓慢地沿着尖刺下落。如果碰到尖刺，球就会被摧毁。因此你需要在不浪费时间的情况下射击圆盘。每次击中圆盘后，它下次出现时将具有不同的移动方式，让游戏更加有趣。你可以在游戏结束前失去三个球。

## 怎么玩

触摸屏幕以发射球
