# 像素射击谜题

<a href="https://inkwengame.com/zh/games/pixel-shooter-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-shooter-puzzle/cover.jpg)

像素射击谜题是一款色彩缤纷的3D益智游戏，其中每个炮台的选择都至关重要。从队列前端选择炮台，击碎旋转体素模型中的匹配方块。揭开下面的层次，合理规划有限的槽位，并清除200个像素谜题。旋转和缩放以检查每个模型，在需要时使用可选增益。进度保存在当前浏览器中。

## 怎么玩

桌面端：点击炮台，拖动模型以旋转，滚动以缩放；移动端：点击炮台，滑动模型以旋转，双指捏合以缩放。将炮台颜色与暴露的方块匹配，清除模型且不填满你的槽位。
