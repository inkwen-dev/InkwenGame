# 太空射击

<a href="https://inkwengame.com/zh/games/space-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-shooter/cover.jpg)

重新体验街机的刺激，掌控一艘宇宙飞船，在《太空射击》中展现你的飞行技巧，穿越四十个关卡，对抗成群的敌人。你独自一人在驾驶舱内，面对整个敌对外星舰队的攻击。为了生存，你必须在它们抵达并用导弹将你的飞船撕成碎片之前，将它们全部摧毁。

## 怎么玩

拖拽飞船躲避敌方子弹，并消灭所有敌人。飞船会自动射击。这款游戏会迅速考验你的反应速度和局势应对能力，且难度会不断变化。每一关都会比前一关更难。
