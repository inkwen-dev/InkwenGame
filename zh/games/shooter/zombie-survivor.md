# 僵尸幸存者

<a href="https://inkwengame.com/zh/games/zombie-survivor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-survivor/cover.jpg)

《僵尸幸存者》将你带入后末日僵尸爆发的惊心动魄世界。游戏提供紧张刺激的动作体验，你需要在越来越具挑战性的关卡中穿行，每个关卡都充斥着成群结队的丧尸。角色动作流畅且响应迅速，让你轻松闪避来袭威胁并精准射击。随着游戏进程，你将面对各种类型的僵尸，每种都有独特的技能和挑战。这是一场对你生存技巧和精准射击能力的考验。

## 怎么玩

PC 操作：使用 WASD 键移动角色；使用鼠标瞄准和射击。移动设备操作：点击屏幕上的按钮
