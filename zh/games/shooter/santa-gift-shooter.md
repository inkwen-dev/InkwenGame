# 圣诞礼物射击

<a href="https://inkwengame.com/zh/games/santa-gift-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/santa-gift-shooter/cover.jpg)

使用糖果炮台射击每一关的所有礼物。每颗糖果都需要花费金钱，因此在钱用完之前，你需要射中关卡中的所有礼物。射击奖励物品以获得更多金钱或更强力的射击。
