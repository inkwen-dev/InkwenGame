# 点

<a href="https://inkwengame.com/zh/games/point" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/point/cover.jpg)

点是一款解谜射击游戏。滚轮中会有若干个球，其中只有一个红球。你需要用屏幕底部旋转左右的球击中红球。当你认为球正朝向需要击中的红球时，选择合适的时机进行射击。击中后，一排球会出现在其他位置，你需要再次击中。如果连续两次失误，游戏将结束。

## 怎么玩

点击屏幕以射击并开始游戏
