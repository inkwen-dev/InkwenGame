# 鱿鱼枪节

<a href="https://inkwengame.com/zh/games/squid-gun-fest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-gun-fest/cover.jpg)

枪节传奇带来了全新的鱿鱼游戏主题。通过解数学题复制他们的武器，摧毁鱿鱼游戏的员工。作为老板角色，鱿鱼游戏的婴儿角色有时会出现，你需要尽可能多地获得武器来摧毁他。当到达最后一行时，停下并摧毁试图逃离岛屿的卡车。如果你想拥有6种不同的武器，就必须在每关结束时积累你获得的分数。尽情享受吧！
