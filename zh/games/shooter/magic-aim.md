# 魔法瞄准

《魔法瞄准》（Magic Aim）是一款以Q版魔法师为主角的实时街机炮击游戏。你需要观察风向变化，为魔杖充能，然后发射弧形元素炮弹，这些炮弹会在空中分裂，清除丘陵地形上成群的怪物。冲刺寻找更佳的射击角度，升起能量护盾抵挡来袭的攻击，拾取掉落的道具来强化你的下一次射击，然后传送至全新的地图。与传统的回合制炮击游戏不同…

## 怎么玩

在不断升级的怪物浪潮中生存下来，并尽可能获得高分。清除当前关卡中的所有怪物即可传送至下一个更强大的关卡——一旦被击败，你的挑战就会结束。得分取决于击杀数、速度、精准度和技巧（例如分裂攻击和完美格挡）。

瞄准光标方向，并注意风向条——风力会在飞行途中推动你的子弹，并且每隔几秒就会发生变化。按住按钮蓄力，松开按钮发射；子弹在飞行顶点会分裂成扇形，用于控制人群。在敌人子弹即将击中时举起盾牌即可完美格挡（返还法力值并加速）。走动可以重新调整位置，并拾取可以强化你射击的物品。

桌面端操作：

• 瞄准 — 鼠标

• 蓄力射击 — 按住/松开鼠标左键

• 能量护盾 — 鼠标右键或空格键

• 移动 — A / D（或 ← / →）

• 冲刺瞬移 — 双击 ← 或 →

• 切换元素 — 1–4

• 暂停 — Esc

移动端：虚拟摇杆 + 拖动瞄准 + 屏幕射击/护盾按钮。

## 介绍

《魔法瞄准》（Magic Aim）是一款以Q版魔法师为主角的实时街机炮击游戏。你需要观察风向变化，为魔杖充能，然后发射弧形元素炮弹，这些炮弹会在空中分裂，清除丘陵地形上成群的怪物。冲刺寻找更佳的射击角度，升起能量护盾抵挡来袭的攻击，拾取掉落的道具来强化你的下一次射击，然后传送至全新的地图。与传统的回合制炮击游戏不同，每一发炮弹都是实时且快速的——精通的关键在于能够迅速判断炮弹的弧线和风向。四种元素（火、水、雷、土）的飞行轨迹各不相同，因此切换元素会改变你对同一发炮弹的判断。像素风画面，趣味十足，上手简单，非常适合快速畅玩。
