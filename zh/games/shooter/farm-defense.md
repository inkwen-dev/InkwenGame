# 农场防御

<a href="https://inkwengame.com/zh/games/farm-defense" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/farm-defense/cover.jpg)

在一波波奇怪的怪物试图入侵你的农场时生存下来。收集临时道具，如快速射击、爆炸弹药、医疗包和电 Fence。每关结束后，从随机升级中选择，解锁新武器，部署作物喷洒空袭，用陷阱减缓敌人，或使用磁铁吸引道具。继续前进以解锁具有独特风格的新可玩英雄。

## 怎么玩

使用方向键或WASD移动，按空格键转身
