# 棍子对决战斗

<a href="https://inkwengame.com/zh/games/stick-duel-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stick-duel-battle/cover.jpg)

棍子对决战斗是一款有趣又疯狂的忍者棍子对战游戏！你可以在多个地图上使用真实的武器和物理效果进行战斗。每张不同的地图都需要不同的战术。棍子对战对决支持单人和双人模式。率先达到5分的一方获胜游戏。

## 怎么玩

玩家1 方向键 和 L 键 玩家2 WASD 和 F 键
