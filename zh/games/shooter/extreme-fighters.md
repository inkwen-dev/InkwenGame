# 极限格斗

<a href="https://inkwengame.com/zh/games/extreme-fighters" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/extreme-fighters/cover.jpg)

在《极限格斗》中，你将与其它敌人战斗，并通过击杀他们来获得分数。你可以选择自己的角色，共有3个不同的角色可供选择。你将收集生命值、弹药和护盾。可在电脑或移动设备上玩这款游戏。

## 怎么玩

使用方向键操作，空格键跳跃，H键射击，或使用鼠标并在屏幕上轻触
