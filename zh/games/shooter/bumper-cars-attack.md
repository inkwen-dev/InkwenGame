# 碰碰车攻击

<a href="https://inkwengame.com/zh/games/bumper-cars-attack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bumper-cars-attack/cover.jpg)

碰碰车攻击是一款专为儿童设计的汽车射击游戏。控制碰碰车，射击那些在轨道上向你逼近并攻击你的敌人。尽可能多地消灭敌人，并尽可能长时间地游玩。点击屏幕左侧或右侧以移动至该侧，避开可能伤害你的子弹。靠近士兵们，避开子弹，并在每次游戏中争取获得最佳分数。

## 怎么玩

点击屏幕来玩此游戏，或使用左右箭头键
