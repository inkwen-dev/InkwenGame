# 方块枪

<a href="https://inkwengame.com/zh/games/blocky-guns" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocky-guns/cover.jpg)

在这款像素风格的第一人称射击游戏中，收集彩色方块，打造强力武器，一路杀出重围，击败一波又一波的敌人。解锁并使用各种武器类型，包括手枪、机枪、火箭筒和手榴弹。为每场战斗选择合适的武器，升级火力，在危机四伏的关卡中生存下来。

## 怎么玩

击败敌人，收集彩色方块，并用它们来制作新武器。每种武器都需要两种不同颜色的方块，所以在任务中收集足够的材料来解锁更强大的装备。明智地使用你的武器，保持移动，消灭所有敌人即可完成关卡。在电脑上，使用 WASD 键移动，鼠标瞄准，鼠标左键射击。在移动设备上，使用屏幕上的摇杆和按钮来移动、瞄准、切换武器和攻击。
