# 炮弹冲浪者

<a href="https://inkwengame.com/zh/games/cannon-surfer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cannon-surfer/cover.jpg)

炮弹冲浪者是一款有趣的街机游戏。你需要推动一个球形大炮到达终点。避开障碍物。记得要整合坦克，随着坦克的升级，你就能轻松击败老板。如果你无法应对，右边有一个彩虹壳，会帮助你。

## 怎么玩
