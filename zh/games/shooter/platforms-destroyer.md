# 平台摧毁者

<a href="https://inkwengame.com/zh/games/platforms-destroyer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/platforms-destroyer/cover.jpg)

这是一款有趣的儿童游戏《平台摧毁者》，游戏中特殊的加农炮会发射出五颜六色的球。加农炮是一根管道，你可以在命令下让球从管道中落下，攻击下方的平台。但平台会不断上升，因此你的任务是在平台到达加农炮之前将其击碎。同时，你只有有限次数的射击机会，如果球击中尖刺，你将失去三条生命中的一条。尽情享受游戏吧。
