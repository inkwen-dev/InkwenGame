# 特工计划

![cover](https://img.inkwengame.com/games/agent-plan/cover.jpg)

这是一款非常刺激的射击游戏。在游戏中，玩家将控制一个小小的橡胶人去冒险。游戏中有多种武器。玩家将化身特工，进入各种场所执行任务。游戏中的武器子弹有限，在有限条件下完成任务。

## 怎么玩

1 快速完成特工任务 游戏世界无比庞大 每一关都需要玩家灵活操作击败所有对手 2 每场战斗都非常激烈 玩家还可以使用各种武器和装备，拥有更多可能性
