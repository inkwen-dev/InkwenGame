# 微型坦克

<a href="https://inkwengame.com/zh/games/micro-tanks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/micro-tanks/cover.jpg)

您可以在双人模式下与AI或朋友对战微型坦克战争游戏。通过15个独特设计的平台，精准射击摧毁敌方坦克。利用移动墙壁和迷宫关卡中的高级战术，出其不意地击败敌人！专注于在承受最少伤害的情况下摧毁对手，因为15个关卡的总分将决定游戏的胜者。
