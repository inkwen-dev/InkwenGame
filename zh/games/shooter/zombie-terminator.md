# 僵尸终结者

<a href="https://inkwengame.com/zh/games/zombie-terminator" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-terminator/cover.jpg)

《僵尸终结者》是一款紧张刺激的僵尸射击生存游戏，背景设定在一座被不死生物占领的末日城市。你将扮演最后的幸存者之一，装备强大的武器，对抗一波又一波的僵尸。游戏融合了动作射击、生存玩法和策略性移动，带来惊险刺激的战斗和酣畅淋漓的快感。击败敌人，收集奖励，升级武器，在日益危险的僵尸群中生存下来…

## 怎么玩

你的任务是消灭所有僵尸，并生存到每个关卡的最后。小心移动，避免被包围，同时瞄准并射击敌人。击败的僵尸会掉落金币和强化道具，可以提升你的武器和生存能力。随着游戏的进行，更强大的敌人将会出现，所以保持警惕，成为终极僵尸终结者！

PC 操作：

↑（上箭头）：向上移动

↓（下箭头）：向下移动

←（左箭头）：向左移动

→（右箭头）：向右移动

空格键：射击/开火

Shift：加速

移动端操作：

摇杆：拖动即可向任意方向移动

射击键：点击攻击僵尸

加速键：点击可暂时加速
