# 丛林恐龙猎人

<a href="https://inkwengame.com/zh/games/jungle-dino-hunter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jungle-dino-hunter/cover.jpg)

加入《丛林恐龙猎人》，在茂密而危险的环境中猎杀恐龙。开第一枪后，恐龙会变得警觉，并开始嗅探以确定子弹来源。探索狙击模式和突击模式，你将能够四处移动并从各个方向发起攻击。

## 怎么玩

WASD 或方向键 - 移动玩家 按 R - 重新装填枪支 按空格键 - 跳跃 左键点击 - 发射子弹 右键点击 - 放大 缩小 鼠标滚轮 - 在不同枪支之间切换
