# 轰炸突袭

<a href="https://inkwengame.com/zh/games/bombing-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bombing-run/cover.jpg)

你的敌人想要夺取你的土地。但他们不知道你掌控着天空！在这场节奏快速、充满动作的游戏中，通过呼叫空袭来抵御入侵部队，看看你的部队在空中掩护下能坚守防线多久。从天而降倾泻火力，升级你的地面部队，解锁新单位，不惜一切代价，但绝不能让敌人进入你的领地！

## 怎么玩

点击屏幕任意位置以在敌人路径上呼叫空袭。点击屏幕左下角的加号按钮以打开升级菜单
