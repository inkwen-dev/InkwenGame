# 僵尸潮

<a href="https://inkwengame.com/zh/games/zombie-horde" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-horde/cover.jpg)

僵尸潮是一款射击游戏，你将需要消灭不断出现的僵尸。每次击杀都会获得分数，你可以用这些分数购买新武器和新子弹。不要让僵尸碰到你，否则你会死亡；同时要小心，因为随着时间推移，僵尸会变得更强更快速。

## 怎么玩

使用 A S D 和 W 键移动，鼠标瞄准和射击。按 P 键暂停或重新开始游戏
