# 箭矢计数大师

<a href="https://inkwengame.com/zh/games/arrow-count-master" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrow-count-master/cover.jpg)

箭矢计数大师是一款快速且令人满足的跑酷游戏，每一次选择都会改变你的火力。滑动以移动，并在增加、减少、乘以或提升箭矢数量的通道之间进行选择。在避免惩罚和障碍物的同时，尽可能地积累最多的箭矢数量。

## 怎么玩

鼠标点击或点击触摸屏开始游戏
