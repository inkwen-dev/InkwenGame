# 虚空射击

![cover](https://img.inkwengame.com/games/void-shot/cover.jpg)

《虚空射击》是一款单手操作的霓虹街机射击游戏，背景设定在闪耀的宇宙深处。滑动屏幕底部的炮塔——它会自动开火——在无穷无尽的脉冲光环到达你之前将其击破。每五波光环后都会出现一场 Boss 战，每个 Boss 的玩法都各不相同：有的会传送，有的会分裂，有的会召唤小怪…

## 怎么玩

目标：尽可能多地生存下来。摧毁每一波中的所有圆环即可前进；每五波击败一次 Boss。你的最佳成绩将登上排行榜。

操作方式——移动设备：触摸并拖动即可移动炮塔。桌面设备：移动鼠标，或使用方向键/A 和 D；按 Esc 或 P 键暂停游戏。自动射击——只需瞄准即可。

收集从被摧毁的圆环中掉落的物品：金币、爱心（额外生命）和临时强化道具。生命值耗尽？观看广告即可复活一次（每局限一次）。花费金币进行升级，提升伤害、射速、金币获取量，并解锁双重射击。

## 介绍

《虚空射击》是一款单手操作的霓虹街机射击游戏，背景设定在闪耀的宇宙深处。滑动屏幕底部的炮塔——它会自动开火——在无穷无尽的脉冲光环到达你之前将其击破。每五波光环后都会出现一场 Boss 战，每个 Boss 的玩法都各不相同：有的会传送，有的会分裂，有的会召唤小怪。随机出现的波次修正——例如侧风、低重力、涡轮漂移、额外弹跳——会不断改变游戏规则，确保每次游戏体验都独一无二。收集强化道具（冰霜、双倍伤害、速射、护盾），储存金币，并在每次游戏之间永久升级你的炮塔。你能深入虚空多远？
