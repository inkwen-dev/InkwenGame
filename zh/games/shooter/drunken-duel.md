# 醉汉决斗

<a href="https://inkwengame.com/zh/games/drunken-duel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drunken-duel/cover.jpg)

醉汉决斗是一款有趣的西部风格游戏，采用基于物理的一键控制，支持单人和双人模式。游戏中，两个醉酒的布娃娃进行对决。你可以通过随机射击来击中目标，但这样可能会输掉比赛。经过几轮游戏后，掌握游戏的物理机制，就能打出更专业的射击。游戏中的音效和视觉效果让游戏更加有趣。
