# 僵尸袭击

<a href="https://inkwengame.com/zh/games/zombie-attack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-attack/cover.jpg)

僵尸袭击是一款动作游戏，你需要建造防御工事并抵御僵尸的攻击浪潮，升级你的武器和防御设施以击败各种类型的僵尸。

## 怎么玩

使用方向键或WASD键移动，鼠标瞄准并射击，按E键投掷炸药。在移动设备上使用虚拟摇杆
