# 枪与瓶子

<a href="https://inkwengame.com/zh/games/guns-bottles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/guns-bottles/cover.jpg)

枪与瓶子是一款精彩的瓶装射击游戏，你需要射击旋转的瓶子以获得高分。枪支也会在原地旋转，这使得游戏稍微困难一些。点击屏幕以击中瓶子。尝试连续击中三个瓶子以获得5枚硬币。但要避免击中红色瓶子，如果击中它们，游戏就会结束。收集大量硬币以解锁超级枪支。尽你所能射击，尽情享受「枪与瓶子」的乐趣！

## 怎么玩

点击屏幕进行射击
