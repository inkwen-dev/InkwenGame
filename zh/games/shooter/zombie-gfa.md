# 僵尸GFA

<a href="https://inkwengame.com/zh/games/zombie-gfa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-gfa/cover.jpg)

这里发生了一次盛大而奇妙的事故，也被称为GFA，导致该地区的一些有毒废物桶使人们变成了僵尸。通过尽可能长时间地生存，并找到3个有毒废物桶将其摧毁，来阻止僵尸GFA。弹药有限，但你可以在周围找到更多。走过弹药和生命包即可收集它们。

## 怎么玩

键盘方向键控制玩家移动，鼠标点击射击；移动设备：屏幕上的箭头控制移动，点击射击
