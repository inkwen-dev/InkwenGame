# 鱿鱼游戏狙击手

<a href="https://inkwengame.com/zh/games/squid-game-sniper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-game-sniper/cover.jpg)

使用你的狙击枪检测并消灭在绿灯红灯游戏中移动的玩家！瞄准时，务必确保击中正确的玩家。击中正确玩家可获得分数，但若击中错误玩家，分数将减少。在游戏结束时获得最高分，并与朋友一较高下。立即游玩鱿鱼游戏狙击手，开启精彩行动！

## 怎么玩

鼠标锁定解锁 L 狙击枪移动 鼠标缩放 右键射击 左键缩放进退 鼠标滚轮
