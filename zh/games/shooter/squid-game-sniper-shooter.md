# 鱿鱼游戏狙击手射击

掌控你的狙击枪，在红灯绿灯游戏中击倒移动的玩家！在《鱿鱼游戏狙击手射击》中，现在由你来精准击中被淘汰的玩家！当杀手宝宝说红灯时，如果他正在移动，你必须用狙击枪发现并击倒这些移动的玩家。如果你击中了错误的玩家，将会扣除分数。保持警惕，击倒正确的玩家，立即拿起你的枪！

## 怎么玩

鼠标锁定解锁 L 狙击枪移动 鼠标缩放 右键射击 左键缩放进退 鼠标滚轮
