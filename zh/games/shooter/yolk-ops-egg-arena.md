# 蛋黄行动  蛋蛋竞技场

<a href="https://inkwengame.com/zh/games/yolk-ops-egg-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/yolk-ops-egg-arena/cover.jpg)

《蛋黄行动》是一款第一人称竞技场射击游戏，玩家将在八个独特的3D地图上展开蛋类战士的对决。可免费体验自由混战、团队乱斗或蛋王争霸模式，对手为AI机器人。从七种主武器和副武器中选择，使用手雷和竞技场道具补给，争夺最高击杀数。每场比赛的机器人数量会有所不同。支持桌面、游戏手柄和触控操作。仅支持单人模式；不支持在线多人游戏。

## 怎么玩

桌面端：WASD 或方向键移动，鼠标控制视角，左键开火，右键瞄准，空格键跳跃，Shift键冲刺，R键重新装填，G键投掷手雷，数字键1、2切换主武器/副武器，E键或鼠标滚轮切换武器，按住Tab键查看战绩排行榜
