# 机器人冲刺

<a href="https://inkwengame.com/zh/games/robot-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/robot-rush/cover.jpg)

机器人冲刺是一款充满挑战且节奏快速的动作射击游戏。摧毁屏幕上所有的机器人，尽可能获得最高分以进入下一关卡。

## 怎么玩

鼠标点击或轻触屏幕进行游戏。点击敌人进行射击，但不要让敌人接近你
