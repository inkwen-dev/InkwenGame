# 像素突击队

<a href="https://inkwengame.com/zh/games/pixel-commando" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-commando/cover.jpg)

像素突击队是一款充满动作的2D跑动射击游戏，灵感源自经典街机游戏。穿越危险关卡，击败强大的敌人，并面对史诗般的Boss战斗。解锁新关卡，收集硬币，并升级你的技能，征战丛林、雪地、熔岩区域和未来城市。你准备好成为终极突击队员了吗？立即开始游戏，证明你的射击技巧！

## 怎么玩

使用方向键或A D移动，使用空格键或W跳跃，使用J键或鼠标射击敌人，避开敌方子弹，击败所有敌人以通关，收集硬币用于升级，击败Boss以解锁新关卡
