# CircleJump

<a href="https://inkwengame.com/zh/games/circlejump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/circlejump/cover.jpg)

这是一款休闲风格的游戏，等待相同颜色的片段出现后射击并摧毁它。当圆圈的生命值降至零时，圆圈将被摧毁。可以跳跃到新关卡。当子弹用尽时，游戏结束。

## 怎么玩

鼠标或键盘
