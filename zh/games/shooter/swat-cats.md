## 怎么玩

操作说明

W = 前进

A = 左移

S = 后退

D = 右移

Ctrl = 开火

R = 充能

鼠标右键 = 瞄准模式

鼠标左键 = 开火

1 = 切换至普通武器

2 = 切换至手枪

3 = 切换至匕首

4 = 切换至炸弹

5 = 切换至治疗模式

T = 聊天

C = 坐下

空格键 = 跳跃

M = 地图

Tab = 暂停

F = 拾取武器

## 介绍

《SWAT Cats》是一款在线射击游戏，背景设定在一个所有英雄都是战斗猫的世界。准备好体验刺激的战斗了吗？快来加入战斗，戴上头盔，投入战斗吧！

目前你可以从4位猫咪特工中选择。我们有4位战斗猫咪，但我们会不断增加！

选择你的特工：

- 九命下士

- 强爪下士

- 沉默喵中士

- 抓挠队长

你将以下士的身份开始游戏。在之后的在线比赛中，你可以切换到其他角色！

《SWAT Cats》拥有多个舒适且节奏明快的地图，非常适合进行动作和射击。

在线游戏的乐趣在于与朋友一起玩。我们打造了这款多人射击游戏，所以快来组队，一起加入战斗吧！

想和其他玩家聊天吗？游戏内置聊天功能。

《SWAT Cats》是一款跨平台射击游戏！你可以在手机和电脑上畅玩！

选好你的猫，拿起你的枪，冲进战场！
