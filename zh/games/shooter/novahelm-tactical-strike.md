# 新海姆 - 战术打击

<a href="https://inkwengame.com/zh/games/novahelm-tactical-strike" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/novahelm-tactical-strike/cover.jpg)

《Novahelm》是一款快节奏的4v4团队淘汰射击游戏，采用第三人称视角，场景设定在由集装箱和混凝土装卸区构成的迷宫之中。选择你的武器，推进敌方基地，与你的小队一起守住据点。游戏提供六种武器，每种武器都有独特的后坐力、瞄准方式、手雷、冲刺、蹲伏、翻越等动作，以及奖励积极进攻的连杀奖励系统…

## 怎么玩

桌面模式：WASD键移动，鼠标控制视角和瞄准，鼠标左键射击，鼠标右键瞄准。Shift键切换冲刺，Ctrl键切换蹲伏，空格键跳跃并翻越低矮掩体，R键换弹，G键投掷手榴弹。按1到6选择装备栏位，按回车键部署装备。按ESC键松开鼠标。使用右下角的音量按钮静音。

你的四人小队将与四名敌方士兵组成的小队进行战斗，直至达到分数上限。每击杀一名敌人即可获得一分。进行比赛即可解锁狙击步枪、机枪和榴弹发射器。冲锋枪和步枪可通过在装备界面观看奖励广告解锁。打开装备界面的“排名”按钮即可查看共享的生涯击杀数排行榜。

## 介绍

《Novahelm》是一款快节奏的4v4团队淘汰射击游戏，采用第三人称视角，场景设定在由集装箱和混凝土装卸区构成的迷宫之中。选择你的武器，推进敌方基地，与你的小队一起守住据点。游戏提供六种武器，每种武器都有独特的后坐力、瞄准方式、手雷、冲刺、蹲伏、翻越等动作，以及奖励积极进攻的连杀奖励系统。完成比赛即可解锁狙击步枪、机枪和榴弹发射器，或者观看一段简短的广告即可立即解锁冲锋枪和步枪。
