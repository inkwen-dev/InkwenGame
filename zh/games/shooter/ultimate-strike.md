# 终极打击

<a href="https://inkwengame.com/zh/games/ultimate-strike" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ultimate-strike/cover.jpg)

终极打击拥有庞大的武器库，包含二十七种不同的枪械，以及在九个高度详细的地图上进行的激烈多人对战。你将随机获得武器配置并开始游戏，任务是射击所有敌对玩家以取得胜利。

## 怎么玩

WASD - 移动 空格键 - 跳跃 C - 蹲下 左键 - 射击 右键 - 瞄准 R - 换弹 P - 暂停菜单 1 2 3 - 选择武器
