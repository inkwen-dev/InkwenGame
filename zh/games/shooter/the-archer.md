# 弓箭手

<a href="https://inkwengame.com/zh/games/the-archer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-archer/cover.jpg)

弓箭手是一款射击游戏，玩家需要控制弓箭手用箭射中气球。射中气球可以获得分数、额外箭矢和生命值，但不要射击炸弹，否则游戏将结束。当你收集到一定金额的现金后，可以购买更多的箭矢。

## 怎么玩

使用鼠标瞄准并射击
