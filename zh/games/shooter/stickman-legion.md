# Stickman军团

<a href="https://inkwengame.com/zh/games/stickman-legion" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickman-legion/cover.jpg)

带领不断壮大的木偶军队投入战斗！击退一波波敌人，并将他们转化为自己的士兵。升级、选择强化，将你的枪升级为微型机枪、轨道炮或火箭发射器。召唤无人机、炮塔和空袭，提拔你的部队，击败坦克和堡垒等巨大首领。10个关卡，2个岛屿，以及每次游戏之间可永久解锁的升级项。

## 怎么玩

使用WASD或方向键移动，在手机上则通过拖动操作。你的指挥官会自动射击。点击一个升级项以选择它。按Esc或P键暂停
