# 弹珠机

<a href="https://inkwengame.com/zh/games/pinball-machine" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pinball-machine/cover.jpg)

出色的弹珠游戏，目前音效非常逼真。该游戏目前仅支持1名玩家，未来将推出的v2版本支持2名玩家游玩。游戏目标是尽可能多地击中障碍物以提升计分器。必须至少获得15000分才能进入得分排行榜。

## 怎么玩

使用键盘的方向键移动球拍。按空格键开始游戏。
