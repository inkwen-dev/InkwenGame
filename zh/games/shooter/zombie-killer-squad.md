# 僵尸杀手小队

<a href="https://inkwengame.com/zh/games/zombie-killer-squad" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-killer-squad/cover.jpg)

这款游戏将让你组建自己的僵尸猎人小队，彻底清除它们的本土领地。小队中的每位成员都有独特的武器和能力，有人擅长使用散弹枪，有人使用手榴弹发射器，还有人使用狙击步枪。但仅仅组建一支优秀的队伍是不够的，你还需要不断强化队员及其武器。这可以通过消灭怪物和完成任务来实现。
