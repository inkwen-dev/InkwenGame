# 僵尸宝藏冒险

<a href="https://inkwengame.com/zh/games/zombie-treasure-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-treasure-adventure/cover.jpg)

玩最新的动作冒险游戏《僵尸宝藏冒险》。你的目标是收集钥匙打开宝藏。在游戏中，你需要对抗攻击你的僵尸。每消灭一个僵尸，你就能获得一颗星。同时，你还会收集金币，从而获得分数。游戏共有6个有趣的关卡。在最后一个关卡中，你将与最终的僵尸Boss战斗！

## 怎么玩

使用方向键移动，Z和X键用于开枪和使用其他武器
