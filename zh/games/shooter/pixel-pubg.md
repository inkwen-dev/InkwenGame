# 像素PUBG

<a href="https://inkwengame.com/zh/games/pixel-pubg" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-pubg/cover.jpg)

像素PUBG是一款3D射击游戏，你必须从五个不同的角色和两张地图中进行选择。游戏中会有大量武器，找到它们并拾取后开始射击。在这个充满挑战的游戏里证明你的实力，消灭所有对手。尽情享受吧！特性：• 5个可选角色 • 2张地图：大逃杀模式和沙盒模式 • 地图上遍布武器 • 背包系统

## 怎么玩

WASD或方向键移动 左键射击 右键瞄准 F键互动或拾取武器或跳伞 空格键跳跃 左Shift键奔跑 R键重新装填 C键蹲下 Tab键打开背包
