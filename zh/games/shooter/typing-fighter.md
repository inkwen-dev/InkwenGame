# 打字格斗家

<a href="https://inkwengame.com/zh/games/typing-fighter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/typing-fighter/cover.jpg)

在这个游戏中，你将通过输入屏幕上出现的句子来与对手战斗。快速而准确地输入以释放最大威力。你可以不断积累打字能量，同时释放致命技能招式，并受到200多条励志语录和名言的激励。来吧，展示文字的力量！还有踢击！

## 怎么玩

使用您的电脑键盘或触摸键盘输入屏幕上显示的句子
