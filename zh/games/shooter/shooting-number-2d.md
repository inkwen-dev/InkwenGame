# 射击数字2D

<a href="https://inkwengame.com/zh/games/shooting-number-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shooting-number-2d/cover.jpg)

射击并合并数字是一款适合全家人的非常有趣的益智游戏。触摸屏幕底部你想要射击的列来开始游戏。努力匹配大小相同且数字相同的方块。当相同的方块组合在一起时，它们会合并成一个带有多个数字的新方块。

## 怎么玩

使用鼠标或手机触控操作，控制小球方向进行射击
