# 像素力量

<a href="https://inkwengame.com/zh/games/pixel-forces" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-forces/cover.jpg)

像素力量是一款具有挑战性的3D射击在线游戏。你可以从五种不同的多人游戏模式和地图中进行选择，并自定义你的角色。环境结构类似于垂直迷宫，配有弹簧床。你可以创建一个房间来游玩，也可以进入已创建的房间。

## 怎么玩

使用WASD或方向键移动，空格键跳跃，右键瞄准，左键射击，L键在夜间模式下切换手电筒，Esc或Tab键切换暂停
