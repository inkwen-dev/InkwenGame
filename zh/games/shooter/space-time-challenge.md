# 时空挑战

<a href="https://inkwengame.com/zh/games/space-time-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/space-time-challenge/cover.jpg)

在太空中射击其他物体和宇宙飞船。但你可以控制时间。移动玩家飞船来改变时间，如果你停止时间，时间就会停止。这样你就可以避开某些情况，在游戏中更轻松地度过更多时间。

## 怎么玩

使用鼠标控制玩家并进行游戏
