# 侧翼防御

<a href="https://inkwengame.com/zh/games/side-defense" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/side-defense/cover.jpg)

你从两侧使用红色和黄色激光来保护你的飞船。你需要用多色激光摧毁下落的球体——红色球体用红色激光，黄色球体用黄色激光。尽情享受游戏乐趣。
