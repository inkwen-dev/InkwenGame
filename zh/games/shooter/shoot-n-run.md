Shoot N Run 是一款全新的跑酷与体育类超休闲游戏，乐趣无穷。你的目标是收集球并奔跑，将球传给队友，避开障碍物和对手，抵达目的地以获得乐趣。点击并滑动来奔跑，投掷球给队友，并通过避开障碍物和对手到达目的地。尽情享受吧！
