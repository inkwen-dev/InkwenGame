# 坠落的球

<a href="https://inkwengame.com/zh/games/fallen-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fallen-balls/cover.jpg)

触摸屏幕用白球射击。当白球位于黄球上方时，你需要再次触摸屏幕或射击以摧毁黄球。当两个球匹配时，你需要点击屏幕来摧毁它们。在错过目标之前尽可能多地摧毁黄球。取得最高分并享受乐趣。
