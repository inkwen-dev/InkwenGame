# 射击游戏

<a href="https://inkwengame.com/zh/games/shot-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shot-game/cover.jpg)

射击是一款射击类游戏。这款游戏的目标是通过旋转的箭头射击到小圆圈上。由于圆圈很小，所以击中它会更难。当你击中小圆圈时，箭头和圆圈的位置都会移动。每击中一次你就会获得分数。你有三次失误的机会，之后游戏就结束了。

## 怎么玩

使用鼠标瞄准和射击 如果你在移动设备上玩游戏，请点击屏幕
