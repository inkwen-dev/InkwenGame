# Breakout Level Pack

<a href="https://inkwengame.com/zh/games/breakout-level-pack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/breakout-level-pack/cover.jpg)

这是一款经典的弹球游戏，包含不同类型的砖块和具有挑战性的关卡。2倍砖块需要被击中两次，而‘射击砖块’只能通过射击来消除，如果球击中‘射击砖块’，球将会被摧毁。‘额外球砖块’会给你一个额外的球。消除所有砖块以完成关卡。每个关卡必须在5分钟内完成。使用鼠标或指尖操作挡板。
