# Counter Craft Classic

<a href="https://inkwengame.com/zh/games/counter-craft-classic" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/counter-craft-classic/cover.jpg)

Counter Craft Classic 是一款第一人称射击游戏，将方块状的我的世界风格世界与反恐精英式玩法相结合。你的任务是使用丰富的武器库射击所有方块状生物，并在每一关找到出口以推进游戏进程。

## 怎么玩

WASD - 移动 LMB - 射击 RMB - 瞄准 手电筒 空格键 - 跳跃 R - 换弹 G - 投掷手雷 C - 蹲下 Shift - 快跑 鼠标滚轮 - 切换武器
