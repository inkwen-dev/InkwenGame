# 僵尸射击

<a href="https://inkwengame.com/zh/games/zombies-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombies-shooter/cover.jpg)

僵尸射击是一款你需要消灭所有僵尸的游戏。但有许多障碍物，消灭僵尸不会轻松，但会非常有趣且令人上瘾。利用障碍物来反弹子弹，取得良好效果。你的弹药有限，如果在消灭所有僵尸前用完弹药，你将重新开始该关卡。本游戏共有30个关卡。

## 怎么玩

使用鼠标瞄准并射击
