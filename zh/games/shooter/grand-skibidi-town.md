# 大斯基比迪城镇

<a href="https://inkwengame.com/zh/games/grand-skibidi-town" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/grand-skibidi-town/cover.jpg)

大斯基比迪城镇拥有类似GTA的沙盒玩法、可驾驶的车辆以及丰富的武器库，你的任务是摧毁指定数量的斯基比迪马桶，以成功完成每一关并解锁新武器。
