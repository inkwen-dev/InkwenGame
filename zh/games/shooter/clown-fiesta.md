# 小丑嘉年华

<a href="https://inkwengame.com/zh/games/clown-fiesta" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/clown-fiesta/cover.jpg)

《小丑嘉年华》是一款射击游戏：与怪物、首领和其他玩家战斗，寻找武器，并升级你的角色。

## 怎么玩

桌面操作（键盘和鼠标）

移动

- 按 W / A / S / D 键移动。

- 空格键朝移动方向冲刺，静止不动时朝瞄准方向冲刺。

瞄准和攻击

- 移动鼠标使武器瞄准光标。

- 鼠标左键使用当前武器攻击。按住可保持当前武器的射速持续攻击。

- 鼠标右键是辅助攻击：投掷近战武器（棒球棒、流星锤）和使用剑、风暴战戟进行戳刺。不使用枪械。

- 按 F 键投掷手雷，或引爆已在空中的手雷。

武器和拾取物

- 按 1 / 2 选择近战或远程武器栏位。

- 鼠标滚轮在已占用的武器栏位之间循环切换。

- 点击地上的武器即可拾取（在有效范围内）。能量球可通过行走拾取。

技能（学习后）

- Q 键释放反弹，E 键释放护盾，R 键释放加速，C 键释放火焰吐息。

菜单和信息

- U 代表属性升级，I 代表技能升级。只有在点数未使用时才能解锁。

- 长按 Tab 键可显示记分板。

- P 键在单人游戏中暂停。

移动设备（触摸屏，横屏）

移动

- 点击屏幕右半部分的任意位置并拖动即可移动。摇杆会出现在您的拇指下方。

- 左下角的跳跃按钮会朝着摇杆的方向冲刺，静止不动时则会朝着瞄准点的方向冲刺。

瞄准和攻击

- 瞄准和攻击是自动的。武器会自动锁定最近的可见敌人：枪械会向其射击，近战武器会在敌人进入攻击范围后挥舞。如果没有敌人，武器会朝向您移动的方向。

- 点击油桶或蒸汽管道即可攻击它们。点击空地即可取消攻击。

- 跳跃按钮旁边的投掷/戳击按钮是另一种攻击方式。它只会在使用带有投掷功能的武器时出现：棒球棒和流星锤使用投掷功能，剑和风暴战戟使用戳刺功能。

- 跳跃键旁边的投掷手雷按钮可以投掷手雷，或引爆已在飞行中的手雷。

武器和拾取物

- 点击屏幕底部的武器栏即可切换武器。

- 当地面武器进入攻击范围时，跳跃键旁边会出现一个拾取按钮。拾取能量球需要走过去。

法术（技能习得后）

- 每习得一个法术，跳跃键上方就会增加一个按钮：反弹、护盾、加速、火焰吐息。

菜单和信息

- 武器栏右侧的两个“+”按钮可以打开属性升级和技能升级选项。它们仅在点数未使用时才会显示。

- 菜单和暂停按钮位于右上角。

- 将设备竖起来会暂停游戏，直到设备恢复横屏模式。
