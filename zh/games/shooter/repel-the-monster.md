# 驱逐怪物

<a href="https://inkwengame.com/zh/games/repel-the-monster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/repel-the-monster/cover.jpg)

**驱逐怪物** 是一款动作激烈的怪物射击游戏，你将对抗无尽的敌人并摧毁它们的召唤传送门。击败怪物以获得分数，并收集掉落的武器和弹药来增强火力。摧毁每一个传送门以阻止入侵并完成每一关。快速的战斗节奏、简单的操作以及令人上瘾的生存玩法，让你争夺最高分，成为终极怪物猎人！

## 怎么玩

使用 WASD 或方向键移动，按住鼠标左键进行射击
