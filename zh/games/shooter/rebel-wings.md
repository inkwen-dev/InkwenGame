# 叛逆之翼

<a href="https://inkwengame.com/zh/games/rebel-wings" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rebel-wings/cover.jpg)

玩家控制飞船，射击激光攻击敌人，发射追踪导弹并对抗Boss。每一关敌人都不同，更难对付的敌人和更难对付的Boss会逐渐加入。每个Boss都有独特的移动模式。收集如生命值、导弹和炸弹等强化道具，炸弹可清除所有可见敌人以通关。挑战16个已准备好的关卡。收集爆炸敌舰的零件。将收集到的废料作为货币，用来升级自己的飞船。

## 怎么玩

在桌面浏览器上，使用WASD或方向键移动，按X键或Shift键发射导弹。使用鼠标选择关卡，或在机库中选择要购买的飞船部件。在移动浏览器上，有两种方式可选择来移动玩家的飞船。
