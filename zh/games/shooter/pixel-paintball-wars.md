# 像素弹珠大战

<a href="https://inkwengame.com/zh/games/pixel-paintball-wars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-paintball-wars/cover.jpg)

像素弹珠大战是一款快节奏的多人射击游戏，将复古像素图形与弹珠的混乱乐趣相结合。玩家在充满活力的方块状竞技场中展开对决，使用各种弹珠枪和道具来击败对手。

## 怎么玩
