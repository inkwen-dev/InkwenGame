# 波巴爆破

<a href="https://inkwengame.com/zh/games/boba-blast" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boba-blast/cover.jpg)

快节奏的珍珠对决游戏。你和你的对手将各自面对一个旋转的、由五彩缤纷的珍珠组成的巨型球。射击相同颜色的珍珠，即可触发连锁反应，消除它们，逐步削弱珍珠群，率先清空你的球。

## 怎么玩

比对手更快地用你的超级球击碎珍珠。率先消除己方珍珠群即可获胜，或者在双方都用完所有球的情况下，先击碎更多珍珠者获胜。

操作

点击游戏区域任意位置开始瞄准。

拖动调整击球弧线：

上 → 高弧线（吊球）

下 → 平直直线球

左/右 → 调整瞄准方向

松开即可沿着发光的弧线发射。

点击“交换球”按钮，即可将当前击球与旁边的预览球交换。

## 介绍

快节奏的珍珠对决游戏。你和你的对手将各自面对一个旋转的、由五彩缤纷的珍珠组成的巨型球。射击相同颜色的珍珠，即可触发连锁反应，消除它们，逐步削弱珍珠群，率先清空你的球。

比赛体验如同街机游戏般紧张刺激：你需要精准瞄准，合理分配有限的射击次数，并在时间限制内与对手展开较量。如果击中的珍珠颜色错误，它们会反弹而不是消除，因此每一次射击都至关重要。
