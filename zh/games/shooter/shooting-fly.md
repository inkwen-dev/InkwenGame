# 射击苍蝇

<a href="https://inkwengame.com/zh/games/shooting-fly" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shooting-fly/cover.jpg)

射击苍蝇是一款你需要控制一只苍蝇，用子弹击碎障碍物中的箱子的游戏。每个箱子需要不同数量的射击才能摧毁，因此你必须选择射击哪一个箱子才能顺利通过。点击屏幕来控制苍蝇。

## 怎么玩

点击屏幕开始游戏
