# 僵尸跳跃

<a href="https://inkwengame.com/zh/games/zombies-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombies-jump/cover.jpg)

在这个僵尸游戏中，你将身处一个有僵尸的平台上。在平台间跳跃并射击僵尸。收集武器的弹药。如果没有弹药，你需要跳过僵尸才能到达更高的平台。不要与僵尸碰撞，否则你会死亡。尽可能多地杀死僵尸，并达到更高的目标。使用方向键移动角色，空格键射击，或者直接点击屏幕上的图标。

## 怎么玩

点击屏幕上的图标来跳跃和射击
