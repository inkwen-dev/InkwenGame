# 僵尸改革

<a href="https://inkwengame.com/zh/games/zombie-reform" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-reform/cover.jpg)

《僵尸改革》是一款3D僵尸射击生存游戏。这是一款具有等级系统的游戏，每升一级，僵尸的强度都会提升。游戏中共有6种不同的地图，每12级地图会更换一次。每次地图更换前，都会有一场「全boss」战斗。所有僵尸都极其强大，你必须击败它们才能进入新地图。

## 怎么玩

WASD移动 左键射击 右键切换视角 U 火箭筒 R 换弹 C 蹲下 1 2 3 切换武器
