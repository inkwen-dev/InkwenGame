# 死亡竞赛战斗 io

<a href="https://inkwengame.com/zh/games/deathmatch-combat-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/deathmatch-combat-io/cover.jpg)

特色 - 快节奏的3D第一人称射击游戏 - 游戏模式：僵尸生存、街机模式、死亡竞赛、团队死亡竞赛、大逃杀和末日大逃杀 - 可在房间中添加机器人 - 五张地图 - 道具：生命恢复、伤害增强、无限冲刺和护盾 - 11种武器 - 等级系统，用于解锁武器皮肤 - 护甲和面具自定义 - 死亡竞赛和团队死亡竞赛模式中的远距离标记

## 怎么玩

操作 - WASD 或方向键移动 - 左 Shift 键激活快速冲刺 - 空格键跳跃 - R 键重新装弹 - 数字键切换武器 - 左键射击 - 右键瞄准 - Tab 键暂停 - T 键聊天
