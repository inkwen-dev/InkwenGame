# Top Shooter io

<a href="https://inkwengame.com/zh/games/top-shooter-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/top-shooter-io/cover.jpg)

Top Shooter io 是一款像素射击游戏，你将进入一个充满其他玩家的房间，你需要向所有人展示你是一位出色的士兵，并且能够存活到没有敌人还能站立为止。你可以在战斗中使用各种道具，自定义角色外观，并可在两个不同的地图中与机器人对战。尝试两种不同的游戏模式，击败敌人后赢得酷炫奖励，成为史上最强大的士兵。

## 怎么玩

WASD 移动 空格键跳跃 左键射击
