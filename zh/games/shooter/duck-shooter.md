# 鸭子射击

<a href="https://inkwengame.com/zh/games/duck-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/duck-shooter/cover.jpg)

鸭子射击是一款简单的无尽嘉年华风格射击游戏，随着你的得分越来越高，游戏速度会逐渐加快。除了射击黄色鸭子来获得分数外，你还需要避开红色鸭子。如果射击了红色鸭子，游戏会扣除你的分数。如果你在射击下一只鸭子之前花费了太长时间，游戏就会结束！享受游戏吧！
