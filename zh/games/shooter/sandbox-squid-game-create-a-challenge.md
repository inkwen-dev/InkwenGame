# 沙盒鱿鱼游戏 创建挑战

沙盒鱿鱼游戏 - 创建挑战 &mdash; 一款受鱿鱼游戏启发的游戏。游戏类型为沙盒，因此你可以自由地建造任何你想要的东西。主要任务是建造一个玩家需要通过的测试。你可以帮助他们，阻碍他们，甚至杀死他们。当玩家通过测试时，你会获得金钱。游戏包含：超过5张地图、4种建筑方块、超过5名玩家、4种守卫皮肤。

## 怎么玩

左箭头 右箭头 或 AD - 左右移动 上箭头 或 W - 跳跃 Q - 切换方块 S - 放置方块 F - 使用机枪射击 完成测试搭建后，别忘了点击左上角的绿色按钮
