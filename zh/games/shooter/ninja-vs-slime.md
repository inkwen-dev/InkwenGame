# 忍者对史莱姆

<a href="https://inkwengame.com/zh/games/ninja-vs-slime" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ninja-vs-slime/cover.jpg)

忍者对史莱姆是一款休闲游戏，你需要消灭向你逼近的史莱姆。向对手投掷忍者飞镖。飞镖会弹跳在史莱姆身上并产生反弹，让你一次性摧毁多个史莱姆。但史莱姆有更多生命值，有些拥有20、30甚至更多。因此你需要精准投掷，并优先摧毁靠近你的史莱姆，以免被它们摧毁。

## 怎么玩

点击屏幕开始游戏
