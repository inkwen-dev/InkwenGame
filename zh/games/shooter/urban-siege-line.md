# 都市围城线

<a href="https://inkwengame.com/zh/games/urban-siege-line" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/urban-siege-line/cover.jpg)

都市围城线是一款2D动作射击游戏，你将防守一条被摧毁的城市防线，抵御一波又一波的僵尸。在三条路线间移动，射击来袭的敌人，切换武器，呼叫空中支援，部署支援小队，投掷手榴弹，升级你的军械库，并在每一关中生存下来。

## 怎么玩

桌面端 使用上下箭头键切换路线 按 S 键射击 按 1、2 和 3 键切换武器 按 A 键呼叫空中支援 按 D 键部署支援小队 按 F 键投掷手榴弹 按 P 或 ESC 键暂停 移动端 使用屏幕上的按钮
