# Pin It

<a href="https://inkwengame.com/zh/games/pin-it" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pin-it/cover.jpg)

在这个游戏中，你需要将小球钉到旋转的圆环上。但你需要将小球钉到与颜色匹配的位置。将绿色小球钉到圆环的绿色部分，以此类推。大圆环会以不同的速度移动，有时还会出现一些障碍物，你需要避开它们。

## 怎么玩

点击屏幕来移动小球进入圆环
