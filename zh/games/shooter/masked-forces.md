# 蒙面部队

<a href="https://inkwengame.com/zh/games/masked-forces" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/masked-forces/cover.jpg)

如果你喜欢CS:GO或COD，那你来对地方了。《蒙面部队》是一款射击动作游戏，考验你所有的策略和生存技巧。你的任务是消灭所有敌人，在战场环境中生存下来并赢得战斗。特色：• 多人及单人任务 • 武器库和武器商店 • 优秀的图形表现

## 怎么玩

WASD移动 T聊天 R重新装填 P暂停 C蹲下 空格键跳跃 左键点击开火 鼠标滚轮切换武器
