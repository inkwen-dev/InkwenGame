# 冒险挑战游戏

<a href="https://inkwengame.com/zh/games/upit-adventure-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/upit-adventure-game/cover.jpg)

一种2D游戏，每个关卡都有冒险元素，操作简单，如跳跃和行走。玩家需要通过跳跃来越过障碍物，并到达指定地点。

## 怎么玩

按Ctrl键跳跃，按Shift键射击；若想暂停，可按Esc键，再次按Esc键可继续游戏，按Enter键开始游戏
