# 子弹循环

<a href="https://inkwengame.com/zh/games/bullet-loop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bullet-loop/cover.jpg)

《子弹循环》是一款动作射击游戏，每次挑战都能让你变得更强。你的英雄需要抵挡一波又一波的敌人，撤退到掩体后，瞄准头部射击，收集金币来提升伤害、射速和收入。游戏包含10个主题区域，从古埃及和维京峡湾到霓虹闪烁的街道和秘密实验室，应有尽有。遇到困难？升级装备，重新投入战斗，继续前进！

## 怎么玩

按住鼠标左键并拖动即可瞄准。射击和移动自动进行。

空格键或“战斗”键——开始奔跑。

R 键——重新开始。

移动设备：触摸并拖动即可瞄准。点击屏幕按钮开始游戏并购买升级。
