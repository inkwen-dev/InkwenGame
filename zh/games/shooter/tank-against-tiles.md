# 坦克对抗方块

<a href="https://inkwengame.com/zh/games/tank-against-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tank-against-tiles/cover.jpg)

在这个游戏中，你需要摧毁所有来袭的方块。它们是蓝色和粉色的，因此你需要用蓝色或粉色的子弹来摧毁它们。尝试选择正确的子弹颜色，用你的坦克摧毁方块。点击左侧或右侧来切换子弹颜色。
