# 恐怖万圣节射击游戏

<a href="https://inkwengame.com/zh/games/scary-halloween-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scary-halloween-shooter/cover.jpg)

在游戏《恐怖万圣节射击游戏》中，你将需要摧毁所有的万圣节物品。游戏中有各种不同的万圣节物品，你需要用单次射击击中它们，且必须击中完全相同的万圣节图像。当你击中一组完全相同的万圣节图像时，它们就会被摧毁，并获得分数。祝你万圣节快乐，尽情享受吧！
