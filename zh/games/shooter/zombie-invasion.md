# 僵尸入侵

<a href="https://inkwengame.com/zh/games/zombie-invasion" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-invasion/cover.jpg)

《僵尸入侵》是一款第一人称射击游戏，玩家身处一个充满僵尸的地方，可以自由探索周围环境。玩家必须躲避僵尸的攻击或击杀僵尸，尽可能长时间地保持生命。每杀死一个僵尸，你就能获得金钱，然后可以用这些钱购买新的武器和弹药。务必留意你的弹药数量，否则死亡是必然的！你可以选择两张不同的地图：「城市」或「森林」

## 怎么玩

WASD移动 R 换弹 M1 Ctrl 开火 M2 瞄准 L-Shift 跑步
