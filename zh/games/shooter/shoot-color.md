# 射击色彩

<a href="https://inkwengame.com/zh/games/shoot-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/shoot-color/cover.jpg)

在Lagged上玩射击色彩游戏，通过射击颜色来完成每一关的趣味在线街机益智游戏。点击射击你的颜色，然后观察会发生什么。提前思考，然后将所有方块涂色以通过全部50个挑战。你需要完美的时机才能通过这个动作游戏中的所有挑战关卡。每关你只有三次机会。你能让它们在恰到好处的时刻击中彩色目标吗？
