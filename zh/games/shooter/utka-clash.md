# 鸭子对决

<a href="https://inkwengame.com/zh/games/utka-clash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/utka-clash/cover.jpg)

《鸭子对决》是一款第一人称射击游戏，包含锦标赛死亡竞赛模式，你的任务是在地图上寻找散落的武器，射击机器人以获得指定数量的击杀分数，从而晋级到下一关卡。

## 怎么玩

WASD - 移动 左键鼠标 - 射击 右键鼠标 - 瞄准 手电筒 空格键 - 跳跃 R - 换弹 G - 手雷 F - 使用 C - 蹲下
