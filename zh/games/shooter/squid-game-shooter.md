# 鱿鱼游戏射击

<a href="https://inkwengame.com/zh/games/squid-game-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-game-shooter/cover.jpg)

鱿鱼游戏射击是一款3D生存游戏。在不同且危险的关卡中与敌人展开生存之战。使用重型机枪、散弹枪和火箭筒对抗敌人，并利用真实的布娃娃物理效果来躲避攻击。在鱿鱼游戏挑战中，最终只有一人能胜出！

## 怎么玩

WASD移动 左键射击 右键切换视角 U 火箭筒 R 换弹 C 蹲下 1 2 3 切换武器
