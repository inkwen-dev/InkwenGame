# Tethan Arena

<a href="https://inkwengame.com/zh/games/tethan-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tethan-arena/cover.jpg)

Tethan Arena 使用两种不同的代币，玩家可以赚取 THC 和 THG 代币。游戏内的主要货币是 Thetan Coin (THC)，用户通过参与游戏模式和其他各种活动来收集这些代币。一旦玩家获得这些 THC 代币，就可以将其提现到自己的钱包中

## 怎么玩

移动你的角色，击杀你的敌人
