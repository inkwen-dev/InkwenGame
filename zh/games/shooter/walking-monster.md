# 行走的怪物

<a href="https://inkwengame.com/zh/games/walking-monster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/walking-monster/cover.jpg)

在这个射击僵尸游戏中，你将独自一人在战场上，四周都是僵尸。你唯一的伙伴只有手中的枪。你会从四面八方受到攻击。僵尸会向你逼近，从前方和后方同时涌来。你必须在两个方向上都进行防御。但天空中也会带来危险。那里会有僵尸蝙蝠和其他生物袭击你。努力消灭所有敌人，尽可能走得更远。

## 怎么玩

使用鼠标瞄准并射击
