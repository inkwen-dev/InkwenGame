# 部落

<a href="https://inkwengame.com/zh/games/the-horde" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-horde/cover.jpg)

**部落**是一款紧张刺激的动作生存游戏，你必须抵御无穷无尽的敌人。升级你的武器，建造防御工事，并尽可能长时间地生存下去！

## 怎么玩

- 移动 WASD 方向键 虚拟摇杆 点击瞄准 - 射击 自动射击 - 建造 在建造编辑器中
