# 黑手党战争

<a href="https://inkwengame.com/zh/games/mafia-wars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mafia-wars/cover.jpg)

《黑手党战争》是一款动作射击游戏，你将扮演一位牛仔义警，与黑手党的腐败势力作斗争。游戏包含引人入胜、扣人心弦的关卡，以及各种各样的首领战。你必须谨慎使用子弹，因为在关键战斗中，节省子弹至关重要。

## 怎么玩

战斗中，点击角色即可标记射击位置，但请注意子弹需要一些时间才能到达目标。

根据需要切换武器，并在敌人密集时使用自动武器。

别忘了解锁支援设施和强力防御工事；没有它们，你可能无法赢得某些比赛。

桌面端

与游戏界面互动，选择并升级武器。

战斗中，使用鼠标点击即可触发玩家的武器射击。

移动端

与游戏界面互动，选择并升级武器。

战斗中，使用触摸屏触发玩家的武器射击。
