# 疯狂科学家

<a href="https://inkwengame.com/zh/games/mad-scientist" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mad-scientist/cover.jpg)

这是一款非常酷的快节奏游戏，你将扮演一名疯狂的科学家，可以收集全部10种武器，各种用于秘密升级的物品，途中会有各种不同的敌人，以及6个难度和速度各不相同的关卡。尽可能走得更远吧！
