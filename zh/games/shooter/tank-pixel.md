# 坦克像素

<a href="https://inkwengame.com/zh/games/tank-pixel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tank-pixel/cover.jpg)

由单次触摸控制的微型坦克已准备就绪，即将与你的朋友展开对决！通过屏幕触摸来操控微型坦克，长按则会射击。每轮结束后，地图将发生变化，率先获得五分的一方将赢得比赛。你可以通过让子弹从墙壁反弹来误导你的朋友。

## 怎么玩

在桌面端，玩家1使用W键，玩家2使用上箭头键；在移动端，请使用屏幕一侧的触摸操作
