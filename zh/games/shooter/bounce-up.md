# 弹起来！

<a href="https://inkwengame.com/zh/games/bounce-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bounce-up/cover.jpg)

《Bounce Up!》是一款色彩缤纷的街机类roguelite游戏，灵感源自弹珠机和木钉游戏。发射小球，击中木钉，触发强力连击，解锁强大的升级道具，让每一次游戏都变成一场酣畅淋漓的得分和金币盛宴。制定你的专属策略，挑战高分，并发现意想不到的惊喜。

## 怎么玩

将球发射到游戏板上，击中木桩或落入得分槽即可获得金币。使用金币在游戏间隙购买升级道具，优化球的排列，创造更强大的连击。你的目标是在单局游戏中尽可能多地获得分数和金币。

操作方式：移动鼠标并单击鼠标左键或按空格键发射球。在移动设备上，点击游戏主区域即可发射球。按 Esc 键暂停游戏。
