# 虫虫大爆炸

<a href="https://inkwengame.com/zh/games/bugs-blaster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bugs-blaster/cover.jpg)

虫虫大爆炸是一款你扮演昆虫灭绝者的游戏。你需要摧毁那些悬挂在空中并用蛛网攻击你的蜘蛛。你手持一把特殊的喷雾器，可以喷洒毒药。击中蜘蛛并消灭它们，以免被它们杀死。但你也需要小心某些关卡中出现的蛇。不要靠得太近，否则它会抓住你并杀死你。留意屏幕左侧的生命值。通过所有关卡，消灭所有的昆虫和虫子。
