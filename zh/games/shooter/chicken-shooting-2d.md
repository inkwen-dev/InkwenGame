# 鸡射击 2D

<a href="https://inkwengame.com/zh/games/chicken-shooting-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chicken-shooting-2d/cover.jpg)

想射击一些鸡吗？这款游戏将考验你的技巧，通过方向键控制准星并射击飞行的2D鸡，获得分数，成为这款射击鸡游戏中的最佳玩家。当你子弹用尽时，可以按R键重新装填。

## 怎么玩

使用方向键移动准星，空格键射击，R键重新装填
