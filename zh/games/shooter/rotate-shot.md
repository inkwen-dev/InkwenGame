# 旋转射击

<a href="https://inkwengame.com/zh/games/rotate-shot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rotate-shot/cover.jpg)

在这个益智射击游戏中，你需要用紫色球击中圆环。球会旋转，当它到达与圆环匹配的位置时，点击射击并尝试击中圆环。你可以犯三次错误，之后游戏结束。在游戏结束前尽可能多地得分吧。

## 怎么玩

点击屏幕开始游戏
