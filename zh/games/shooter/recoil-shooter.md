# 后坐力射击

<a href="https://inkwengame.com/zh/games/recoil-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/recoil-shooter/cover.jpg)

嘿，你这个射手，射击并消灭怪物，杀光本关的所有怪物。消灭怪物后即可跳过该关卡。新关卡中还有更具挑战性的敌人等待着你。每关都有不同的敌人。共15个不同关卡，15种不同难度。如果你无法从跳跃坡道跳起，就朝地面射击，利用后坐力跳跃。记住，一切都在你手中！注意风向，别被吹走。

## 怎么玩

点击射击或用手指轻触屏幕。你射击的方向与移动方向相反，根据枪口的指向移动
