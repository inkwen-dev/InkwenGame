# 坠落的图形

<a href="https://inkwengame.com/zh/games/fallen-figures" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fallen-figures/cover.jpg)

《坠落的图形》是一款你需要射击向你坠落的图形的游戏。在图形落地前射击并摧毁它们。你有十条生命，或者在游戏结束前最多错过10个图形。你可以获得奖励和成就，因此有时图形会变慢，让你一次性摧毁更多图形。使用直线射击或从左到右射击，以捕捉所有坠落的图形。

## 怎么玩
