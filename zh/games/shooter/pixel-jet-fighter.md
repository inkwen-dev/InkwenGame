# 像素喷气式战斗机

<a href="https://inkwengame.com/zh/games/pixel-jet-fighter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-jet-fighter/cover.jpg)

这是一款射击飞机游戏，你需要摧毁敌方基地。但在那之前，你将遇到大量敌人，包括直升机、飞机和船只。它们都想要摧毁你。所以你孤身一人，先开火摧毁它们。你也可以摧毁敌人的子弹。

## 怎么玩

使用鼠标移动飞机并避开敌方子弹
