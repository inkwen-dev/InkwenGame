# 恐龙猎手

<a href="https://inkwengame.com/zh/games/dino-huntress" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dino-huntress/cover.jpg)

帮助恐龙猎手收集她一路上的所有硬币和蛋。避开敌人，使用你的武器和道具安全抵达终点区域。你可以跳到鸟儿身上来消灭它们，但并非所有敌人都可以被跳跃击败，例如恐龙！游戏中有8个关卡，游戏末尾还有2个大型Boss等待着你。你准备好帮助恐龙猎手踏上她的旅程了吗？

## 怎么玩

按左或右箭头键移动，上箭头键跳跃，空格键射击。在桌面设备上也可以使用WAD键或游戏手柄。在移动设备上请使用屏幕上的按钮。长按跳跃按钮可跳得更高，连续按两次跳跃可进行双跳
