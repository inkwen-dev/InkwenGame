# 士兵之路

<a href="https://inkwengame.com/zh/games/soldier-way" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/soldier-way/cover.jpg)

士兵之路是一款出色的HTML5平台游戏。在丛林中控制士兵，收集钻石和奖章，解锁大门并完成关卡。共6个关卡，4种不同的敌人，使用方向键移动，空格键射击，或使用触摸屏控制移动设备。尽情享受！

## 怎么玩

方向键 触摸屏幕
