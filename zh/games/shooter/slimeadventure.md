# SlimeAdventure

<a href="https://inkwengame.com/zh/games/slimeadventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slimeadventure/cover.jpg)

Slime Adventure 是一款有趣的动作游戏，你将操控一个绿色的黏液进入充满挑战的关卡。你的任务是灵巧地移动，避开危险，并消灭红色黏液以通关。每一关都有独特的布局和难度，需要快速反应和策略思考。快节奏的游戏玩法与鲜艳的视觉效果相结合，为玩家带来激动人心的娱乐体验。

## 怎么玩

- 使用 A D 键或左、右方向键移动 - 空格键跳跃 - 使用鼠标射击
