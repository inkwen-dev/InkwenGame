# 斑点与绵羊

<a href="https://inkwengame.com/zh/games/blobs-and-sheep" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blobs-and-sheep/cover.jpg)

在这个基于技巧的物理射击游戏中，目标是消灭所有斑点同时拯救绵羊。你使用子弹和/或爆炸手榴弹来摧毁斑点，通过摧毁所有斑点或将绵羊传送到安全区域（使用任何可用的传送手榴弹）来拯救绵羊。如果你摧毁了任何绵羊，或者在弹药耗尽后仍有斑点残留，你的最高分将会下降。版本 1.1 修复了错误。

## 怎么玩

首先选择要使用的武器，然后选择投掷或射击武器的方向
