# 快乐复活节游戏

<a href="https://inkwengame.com/zh/games/happy-easter-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-easter-game/cover.jpg)

在这个游戏中，你需要把复活节彩蛋扔进气球篮子里。尽量把尽可能多的彩蛋放进篮子。找准位置，瞄准，然后投掷到篮子中。但篮子里的兔子是个糟糕的飞行员，气球根本不会稳定。它会上下左右摇晃。因此，要把彩蛋扔进篮子会更加困难。但这正是这个游戏的趣味所在。而且，即使你失误了，彩蛋掉到了地上，新的生命也会诞生。小鸡将会从蛋里孵化出来。

## 怎么玩

在屏幕上轻触并滑动来玩这个游戏
