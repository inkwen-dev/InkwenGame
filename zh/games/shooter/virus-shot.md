# 病毒注射

<a href="https://inkwengame.com/zh/games/virus-shot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/virus-shot/cover.jpg)

摧毁围绕在你周围的病毒。在这个游戏中，你有机会做到这一点，但如果你错过三次，游戏就会结束，病毒将获胜。病毒会围绕你移动，而你只有一个旋转的注射器。你需要在正确的时间注射药物以击中病毒。点击屏幕来注射药物。

## 怎么玩

点击屏幕开始游戏
