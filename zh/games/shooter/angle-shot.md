# 角度射击

<a href="https://inkwengame.com/zh/games/angle-shot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/angle-shot/cover.jpg)

在这个游戏中，你需要用小球向大球射击。但这并不简单，因为小球是以一定角度发射的，而不是直线前进。你需要在大球离你较远时进行射击。在游戏结束前，你可以失误五次。努力取得好成绩。找出合适的射击角度并得分。
