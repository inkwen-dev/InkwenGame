# 制作怪物狩猎

<a href="https://inkwengame.com/zh/games/craft-monster-hunting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/craft-monster-hunting/cover.jpg)

制作房间：怪物狩猎是一款3D动作游戏，你将扮演一名英雄，必须追捕邪恶的怪物。游戏设定在一个广阔而美丽的制作世界中，充满了危险与冒险。你需要使用你的枪支射击怪物，并拯救房间中的所有人。怪物会以熟悉的节奏来回移动：咚 咚 咚 是 是，其皮肤呈现怪物的特征。

## 怎么玩

简单却令人上瘾的刺激体验 - 在房间的每个角落寻找并射击所有怪物 - 拿起大量武器，为自己在战斗中争取优势 - 使用按钮和摇杆进行移动、奔跑和跳跃
