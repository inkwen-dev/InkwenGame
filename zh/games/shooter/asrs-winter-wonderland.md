# ASRs 冬日仙境

<a href="https://inkwengame.com/zh/games/asrs-winter-wonderland" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/asrs-winter-wonderland/cover.jpg)

你在冬日里带着宠物驯鹿走进了森林。听说森林里有钻石，所以你一边在森林中寻找这些钻石。不幸的是，森林里有个邪恶的巫师，他施了魔法，把森林里的小精灵甚至雪人变成了危险的生物。他还偷走了你的驯鹿。要解除这个魔法，你必须找到9颗圣诞宝石。一旦你找到它们，也会找回你的驯鹿。

## 怎么玩

使用方向键或屏幕上的箭头移动；在某些关卡中还可以原路返回。找到9颗圣诞宝石并摧毁巫师即可获胜。左键点击或屏幕上轻触来射击；跳到雪人身上以摧毁它们
