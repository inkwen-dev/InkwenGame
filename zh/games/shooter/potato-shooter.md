# 土豆射手

<a href="https://inkwengame.com/zh/games/potato-shooter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/potato-shooter/cover.jpg)

一款Roguelike生存游戏，一个被诅咒的土豆将面对无情的敌人。升级你的武器库，躲避弹幕，寻找能打破游戏平衡的神器。死亡。再试一次。

## 怎么玩

移动

• 使用方向键或 WASD 键移动

• 按空格键冲刺——快速躲避敌人攻击

• 避开敌人的投射物和接触伤害

战斗

• 你装备的武器会自动向附近的敌人开火

• 击败房间内的所有敌人即可解锁出口

• 收集被击败敌人掉落的金币

升级与物品

• 前往基座购买新的武器和神器

• 使用铁砧升级你的武器（提升伤害和攻击速度）

• 收集神器获得特殊的被动技能

• 拾取生命值以恢复生命值

导航

• 通过门在房间之间移动

• 随着深入，房间难度会逐渐增加

• 你只有一条命——击败敌人，努力生存！

快速提示

• 使用冲刺技能快速脱离险境

• 专注于高效击杀敌人，更快获得金币

• 优先升级武器而非购买新武器

• 神器效果可叠加——构建协同效应

• 保持移动以躲避敌人攻击

• 越深入，奖励越丰厚

目标

尽可能长时间地生存下去，并尽可能深入无尽的地牢！
