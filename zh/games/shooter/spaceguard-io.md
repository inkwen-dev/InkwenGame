# SpaceGuard.io

<a href="https://inkwengame.com/zh/games/spaceguard-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spaceguard-io/cover.jpg)

SpaceGuard.io 是一款科幻主题的多人第一人称射击游戏，拥有诸如传送门和跳跃平台等疯狂特色。特色 • 4张手工制作的地图，包含太空环境 • 类似 Quake 的体验 • 角色皮肤 • 两种游戏模式（死亡竞赛、团队死亡竞赛）

## 怎么玩

使用 WASD 或方向键移动，左键射击，右键瞄准，C 键蹲下，R 键重新装弹，空格键跳跃，左 Shift 键奔跑，数字键 1-5 切换武器，Tab 键打开菜单
