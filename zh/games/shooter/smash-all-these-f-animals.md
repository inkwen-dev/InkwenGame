# 砸碎这些该死的动物

<a href="https://inkwengame.com/zh/games/smash-all-these-f-animals" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/smash-all-these-f-animals/cover.jpg)

砸碎这些该死的动物是一款街机游戏，游戏中一队森林动物会从屏幕顶部向底部移动。你只有三条生命值，每一只到达屏幕底部的动物都会让你失去一条。如果你想摆脱它们，只需点击它们即可。你还可以使用可怕的法术，一次击倒多个敌人。

## 怎么玩

每一关都会带来新的敌人，它们的速度会越来越快，行动也越来越不可预测。把这些小混蛋砸成肉泥，重拾你作为混乱与邪恶之王的尊严
