# 怪物改造

<a href="https://inkwengame.com/zh/games/monster-reform" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-reform/cover.jpg)

《怪物改造》是一款3D生存射击游戏。这是一款具有等级系统的游戏，每个等级中怪物都会变得更强大。所有怪物都十分强大，你必须摧毁它们才能进入新的地图。

## 怎么玩

WASD移动 左键射击 右键切换摄像机 U火箭筒 R重新装填 C蹲下 1 2 3 切换武器
