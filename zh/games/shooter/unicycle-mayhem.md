# 独轮车混乱

<a href="https://inkwengame.com/zh/games/unicycle-mayhem" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/unicycle-mayhem/cover.jpg)

独轮车混乱游戏开启了布娃娃木偶战士之间的战斗！这些布娃娃角色正试图在单轮自行车上保持平衡。地面由可破坏的碎片组成，每次射击击中地面时，该部分地板就会消失。你的目标是摧毁对手站立的砖块或地板，使其坠落。率先获得五分者赢得比赛！让独轮车木偶战斗开始吧！

## 怎么玩

单人模式下：使用 A D 或 左右箭头 移动，空格键射击；双人模式下：玩家1 使用 A D 移动，G 键射击；玩家2 使用 左右箭头 移动，L 键射击
