# FlipTheGun

<a href="https://inkwengame.com/zh/games/flipthegun" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flipthegun/cover.jpg)

随着枪械后坐力向上翻转。触摸屏幕会使枪械开火，利用后坐力将枪向上翻转。在翻转过程中，你会获得冲刺和弹药。同时也会获得金币，可用于解锁更强大的枪械。快来体验吧。
