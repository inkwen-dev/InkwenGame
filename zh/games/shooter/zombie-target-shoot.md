# 僵尸靶子射击

<a href="https://inkwengame.com/zh/games/zombie-target-shoot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-target-shoot/cover.jpg)

僵尸靶子射击是一款有趣的嘉年华街机风格射击游戏。目标是尽可能多地射击不同的僵尸靶子，并在仅有的50发子弹中积累尽可能多的分数。如果你直接击中僵尸的眼睛，得分会更高。为了让射击更加有趣，只需一枪击中多个靶子，你的分数就会翻倍！如果击中绿色的僵尸果汁罐，将获得75分。尽情射击，看看在80发子弹内能取得多高的分数吧！

## 怎么玩

使用鼠标瞄准，鼠标左键射击
