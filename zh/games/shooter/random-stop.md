# 随机停止

<a href="https://inkwengame.com/zh/games/random-stop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/random-stop/cover.jpg)

这是一款解谜射击游戏。游戏的目标是用较小的白球击中黄色球。黄色球会随机且毫无预警地移动。每次你击中或错过黄色球后，她都会随机移动到另一个位置。你需要快速射击，因为黄色球会持续移动。在游戏结束前你可以犯三次错误。因此，你需要用三个球取得最佳分数。

## 怎么玩

点击屏幕进行射击
