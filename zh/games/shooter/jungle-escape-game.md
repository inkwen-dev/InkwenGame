# 丛林逃脱游戏

<a href="https://inkwengame.com/zh/games/jungle-escape-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jungle-escape-game/cover.jpg)

一款有趣的动作游戏，你扮演维京人，操控你的龙穿越成群的敌人，到达每一关的终点。每关都有一个大型奖励循环，里面充满了敌人，但你只有一次机会在奖励结束前完成！当你的生命和能量全部耗尽时，游戏结束。每种武器都会为维京人的分数带来不同的加成，因此请务必在每关尝试所有武器！

## 怎么玩

移动端 触摸屏幕上的按钮 电脑端 使用 A W S D 或上下左右箭头移动 攻击 空格键或点击屏幕
