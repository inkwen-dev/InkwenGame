# 僵尸浪潮竞技场

<a href="https://inkwengame.com/zh/games/zombie-wave-arena" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-wave-arena/cover.jpg)

《僵尸浪潮竞技场》是一款快节奏的俯视角街机生存射击游戏。消灭无穷无尽的僵尸群，赚取金币，并将六种武器从手枪升级到传奇的射线枪。面对九种独特的僵尸变异体、十个难度递增的 Boss 和五个轮换的竞技场。拾取道具、投掷手榴弹，在电脑或单指移动设备上生存下来。

## 怎么玩

目标：在竞技场中抵御无尽的僵尸浪潮。击杀僵尸即可获得金币，然后在每波僵尸之间用金币升级武器、购买新枪、护甲和手榴弹。每5波僵尸就会召唤一个强大的首领，其生命值是上一波的两倍——击败首领即可解锁新的僵尸威胁和更丰厚的奖励。竞技场每10波僵尸刷新一次。游戏没有最终关卡：你通过击败自己遇到的最强僵尸波数和获得最高分来“获胜”——达到50波即可征服死亡之王和所有竞技场。

桌面端操作：WASD 或方向键 — 移动 · 鼠标 — 瞄准 · 鼠标左键 — 射击 · 鼠标右键 — 投掷手榴弹 · G — 切换手榴弹 · R — 装弹 · 1-6 或 Q — 切换武器 · P / Esc — 暂停。

移动端操作：左拇指 — 虚拟摇杆移动 · 射击键 — 带自动瞄准的射击 · 屏幕上的按钮用于装弹、切换武器和投掷手榴弹。
