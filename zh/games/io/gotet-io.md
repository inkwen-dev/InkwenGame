# GoTet.io

<a href="https://inkwengame.com/zh/games/gotet-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gotet-io/cover.jpg)

GoTet.io 是一款方块匹配成长游戏。你从一个 2x2 的方块开始，移动地图，撞击方块并将其粘合。目标是在时间结束前填满你的方块。你可以使用法术来帮助自己，并收集游戏内金币购买和装备增强游戏体验的饰品。你能达到最高级别吗？

## 怎么玩

移动 使用 WASD 方向键或鼠标左键 捡起 空格键或双击 放下 M 键或右键 N 旋转 B 键 磁铁 用于排列方块 F 键 发射 烧毁你路径上的方块 引爆 X 键 速度 暂时加速
