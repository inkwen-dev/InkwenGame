# 冠状病毒.io

<a href="https://inkwengame.com/zh/games/corona-virus-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/corona-virus-io/cover.jpg)

你扮演一个救世病毒的角色，被故意注入新冠肺炎患者体内，以对抗冠状病毒并消灭它们。你的目标是成为拥有最大鼻子的病毒。当你的鼻子触碰到并消灭冠状病毒时，你的鼻子会爆炸，并获得一点分数。但如果其他病毒撞到你，你就失败了，游戏结束。

## 怎么玩

用鼠标悬停控制左右上下移动 空格键冲刺 加速
