# 男孩冒险家

<a href="https://inkwengame.com/zh/games/boy-adventurer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boy-adventurer/cover.jpg)

男孩冒险家是一款很棒的平台游戏。你需要在关卡中收集3把钥匙才能完成该关。共有12个关卡等待你完成游戏。跳到僵尸头上将其消灭，避开尖刺，滑行，攀爬墙壁，收集金币。使用魔法药水来保护自己免受炸弹和僵尸的伤害。每个关卡你有6条生命。注意掉落的岩石。双重跳跃对于生存至关重要！享受游戏吧！
