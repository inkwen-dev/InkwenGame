# 昆虫大战

<a href="https://inkwengame.com/zh/games/insect-battle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/insect-battle/cover.jpg)

在伟大的昆虫战斗中，扮演一只小昆虫，在大地图上进行游戏。你可以拾取地上的物品并缓慢成长，也可以吃掉比自己小的昆虫。点击技能可以分裂。小心不要被大昆虫吃掉
