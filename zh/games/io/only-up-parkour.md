# Only Up! 跑酷

<a href="https://inkwengame.com/zh/games/only-up-parkour" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/only-up-parkour/cover.jpg)

Only Up! 是一款令人兴奋的街机游戏，你需要克服障碍并征服高度。受到热门游戏的启发，你的任务是引导角色穿越一个充满各种障碍的垂直迷宫。你必须迅速反应，准确跳跃，并灵巧地攀爬，以避免撞上障碍物和坠落。随着你在各个关卡中的推进，你会遇到越来越大的难度和新的挑战，例如移动平台和旋转障碍物。

## 怎么玩

WASD 移动 空格键 跳跃
