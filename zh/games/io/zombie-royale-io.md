# 僵尸王座 Io

<a href="https://inkwengame.com/zh/games/zombie-royale-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zombie-royale-io/cover.jpg)

僵尸王座 Io 是一款收集生存类街机 IO 游戏。拥有 3D 卡通幸存者，你需要帮助他们拯救更多的幸存者，并尽可能多地射击僵尸。随着时间推移，你会遇到越来越多强大的僵尸。他们会随机出现并追击最后的幸存者。你可以在游戏中召唤更多士兵和炸弹。每轮结束后，你可以使用金币来升级你的幸存者。
