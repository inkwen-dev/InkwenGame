# 情感支持鸭

<a href="https://inkwengame.com/zh/games/emotional-support-duck" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/emotional-support-duck/cover.jpg)

情感支持鸭是一款温馨的生活管理游戏，你需要平衡你的情感能量和你的鸭子的支持能力。面对100多个随机事件，享受舒缓的视觉效果和环境音效，并在任何设备上通过自动保存和高分记录来追踪进度。

## 怎么玩

N 键用于下一个事件，B 键用于挑战Boss，M 键用于切换静音，ESC 键用于退出全屏
