# Leafino 游戏

<a href="https://inkwengame.com/zh/games/leafino-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/leafino-game/cover.jpg)

Leafino 是一款 2D 平台游戏，你将扮演一片叶子，需要在不惜一切代价避开火焰球敌人的情况下收集光球。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。操作方式：使用 WASD 或方向键移动，按两次 "W" 键或上箭头键可进行二段跳。

## 怎么玩

触摸屏或鼠标或键盘
