# 数字蛇

<a href="https://inkwengame.com/zh/games/number-snake" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/number-snake/cover.jpg)

用手指滑动来引导一串球组成的蛇，击碎砖块。通过数字蛇游戏，你可以使用手指来玩这款富有挑战性的游戏。目标是引导球组成的蛇穿过障碍物迷宫，并尽可能多地击碎砖块。有不同难度的关卡，你可以随时切换，总有新的内容可以尝试。获得更多的球，打造史上最长的蛇！这款有趣又具挑战性的游戏上手容易，但要取得高分却很难，所以一定要挑战自我！
