# Birdify

<a href="https://inkwengame.com/zh/games/birdify" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/birdify/cover.jpg)

Birdify 是一款令人上瘾的游戏。拯救小鸟免受移动障碍物的威胁。这款游戏与‘Flappy Bird’类似，但增加了一些新元素。本游戏兼容 Admob。该游戏使用 Construct 2 制作。

## 怎么玩

在电脑或笔记本电脑上玩游戏时，按空格键让小鸟跳跃，或点击鼠标左键让小鸟跳跃。在智能手机或平板电脑上玩游戏时，点击屏幕任意位置让小鸟跳跃。
