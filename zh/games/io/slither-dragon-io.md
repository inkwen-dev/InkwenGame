# Slither Dragon.io

<a href="https://inkwengame.com/zh/games/slither-dragon-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/slither-dragon-io/cover.jpg)

Slither Dragon.io 是一款精彩的游戏。吃掉其他玩家的彩色蛋来让你的龙变大。游戏的目标是让自己的龙滑行得最长。如果你的龙与敌人的身体相撞，就会死亡。

## 怎么玩

点击并按住你的龙，吃掉其他龙以变得更大
