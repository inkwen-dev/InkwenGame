# Oib.io

<a href="https://inkwengame.com/zh/games/oib-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/oib-io/cover.jpg)

Oib.io 是一款微型管理和策略类 io 游戏。生成、集结并分散你的军队，摧毁敌方军队，打造最佳防御或最富战略性的进攻。保护你的女王，成为领导者。加入最强阵营，喂养你的单位以及盟友的单位，或者决定独自统治整个地图。

## 怎么玩

左键点击选择一个单位；左键拖动选择多个单位；左键加 Ctrl 选择或取消选择单位；空格键选择所有单位；右键移动；WASD 或方向键移动摄像机；1 键生成 oibs；2 键合并选中的单位
