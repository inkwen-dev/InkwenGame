# 蛇类游戏

<a href="https://inkwengame.com/zh/games/snake-spiel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-spiel/cover.jpg)

你身处蛇类世界，必须生存下去，并吃掉沿途找到的一切。通过阻挡其他蛇的路径来攻击它们，迫使它们的头部撞上你。然后你可以吃掉它们身体留下的所有东西。祝你好运！令人上瘾的游戏方式，单人游戏模式。

## 怎么玩

使用鼠标进行游戏，空格键用于加速
