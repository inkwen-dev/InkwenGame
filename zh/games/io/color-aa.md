# 颜色AA

<a href="https://inkwengame.com/zh/games/color-aa" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-aa/cover.jpg)

Color AA 是一款简单游戏，你只需点击屏幕即可开始游玩。每次点击屏幕，就会弹出一个钉子并将其固定在中心的大球上。每一轮你需要将一定数量的钉子固定在球上。

## 怎么玩

所有钉子都必须固定在球上，不能有任何钉子相互碰撞，条件看似非常简单，但其实并不像你想的那么容易。随着新颜色的球出现，游戏会变得更加有趣。
