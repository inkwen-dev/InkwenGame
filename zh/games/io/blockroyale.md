# Blockroyale

<a href="https://inkwengame.com/zh/games/blockroyale" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockroyale/cover.jpg)

一款创意建造竞赛游戏。玩家在规定时间内根据主题建造方块，然后投票选出获胜者。

## 怎么玩

使用 W A S D 键移动 1-9 数字键切换方块 在建造阶段，左键放置方块，右键移除方块 在投票阶段，点击投票并使用 1-6 颗星，星星越多得分越高
