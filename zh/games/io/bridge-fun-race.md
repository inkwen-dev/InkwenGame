# 桥趣竞速

<a href="https://inkwengame.com/zh/games/bridge-fun-race" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bridge-fun-race/cover.jpg)

桥趣竞速是一款类似Mr Bean系列的IO对战街机游戏。采用3D可爱角色，你可以与多名AI对手参与不同的淘汰赛。只有前3名玩家才能获胜并进入下一场比赛。在竞速关卡中，你需要收集道具并将障碍物推到终点线。在生存关卡中，你需要滚动并投掷雪球，在有限时间内击中平台上的其他玩家。

## 怎么玩

鼠标点击或轻触开始游戏
