# Ping

<a href="https://inkwengame.com/zh/games/ping" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ping/cover.jpg)

Ping Ping 是一款极简设计的游戏，目标是通过将球从一侧传到另一侧而不触碰障碍物来获得最高分数。随着游戏时间的推移，难度逐渐增加。游戏由 Nau.Minimal 开发。

## 怎么玩

点击屏幕，将球传送到对侧
