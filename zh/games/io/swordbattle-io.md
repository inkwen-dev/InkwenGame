# Swordbattle.io

<a href="https://inkwengame.com/zh/games/swordbattle-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/swordbattle-io/cover.jpg)

Swordbattle.io 是一款多人游戏，玩家使用不同的2D剑相互战斗，并尝试获得金币。你拥有的金币越多，你的角色就越强大！努力成为最强者。升级你的角色，与朋友战斗，并统治这片土地！

## 怎么玩

键盘鼠标默认设置 - 使用 WASD 或方向键移动，点击并指向鼠标来挥剑，按 C 键投掷剑。鼠标模式，你可以在设置中启用此模式 - 点击挥剑，右键投掷，移动鼠标以移动和瞄准。Enter 键 - 与他人聊天
