# 超级跑酷3D游戏

![cover](https://img.inkwengame.com/games/super-runner-3d-game/cover.jpg)

超级跑酷3D是一款3D跑步游戏。掌控你的小人，与人群竞速。你可奔跑、冲刺或从屋顶跃至屋顶！跑过发光的加速垫以获得动力，并完成翻腾和空翻来展示你的风格。每日挑战、道具升级，甚至华丽的配饰等你来用，打造独一无二的小人形象。通过跑酷竞速，将你的跑步游戏提升到新高度！

## 怎么玩

使用 A D 键或左、右方向键移动
