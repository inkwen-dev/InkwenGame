# 雪战 io

<a href="https://inkwengame.com/zh/games/schneekrieg-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/schneekrieg-io/cover.jpg)

我们正处于冬季季节，到处都是雪。我们制作一些巨大的雪球，并在一场疯狂的战争中战斗。你需要收集雪，直到你拥有的雪球比你的敌人更大。然后你可以把它推到边缘。注意冰面，它们会把你冻住。祝你玩得开心！特性：有趣的 io 游戏玩法，出色的图形

## 怎么玩

使用 WASD 键移动，松开按键来投掷雪球
