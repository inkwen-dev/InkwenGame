# Breakout 游戏

<a href="https://inkwengame.com/zh/games/breakout-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/breakout-game/cover.jpg)

Breakout 是基于一个流行概念的游戏；在 Breakout 中，一排砖块排列在屏幕的上三分之一处，目标是通过反复将球从挡板反弹到砖块上来摧毁所有砖块。只需点击开始按钮即可开始游戏，然后左右移动挡板。

## 怎么玩

使用键盘进行操作 左箭头 右箭头
