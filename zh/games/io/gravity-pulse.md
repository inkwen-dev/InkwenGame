# 重力脉冲

<a href="https://inkwengame.com/zh/games/gravity-pulse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gravity-pulse/cover.jpg)

《重力脉冲》是一款极简主义的街机生存游戏，玩家需在小型竞技场中穿梭，权衡风险与回报。游戏围绕着引力场——看不见的力量——展开，这些力量引导玩家行为，创造出流畅感、紧张感以及自发掌握的体验。核心乐趣：在混乱系统中发现不变规律，同时被无形的吸引场微妙引导。玩家目标：尽可能长时间生存并收集分数。

## 怎么玩

移动 WASD 方向键 鼠标 触控 闪避 空格键 左键按钮 暂停 ESC 键按钮
