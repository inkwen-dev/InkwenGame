# Flappy Halloween Run

![cover](https://img.inkwengame.com/games/flappy-halloween-run/cover.jpg)

欢迎来到 Flappy Halloween Run 游戏！玩家需要拯救万圣节球，并在飞行女巫和鸟类之间的空隙中飞行。当玩家触碰到任何障碍物或因重力而坠落时，游戏结束。

## 怎么玩

简单操作：点击并跳跃。点击即可开始游戏，您可以用鼠标点击来跳过障碍物
