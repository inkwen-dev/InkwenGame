# 竞技场愤怒球

<a href="https://inkwengame.com/zh/games/arena-angry-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arena-angry-balls/cover.jpg)

你必须在竞技场中摧毁你的敌人，那里愤怒的脸庞正在互相战斗。你将与8个不同的对手展开一场充满动作的推挤竞赛，而你的敌人会试图把你推出竞技场。如果你离开了竞技场，游戏就结束了，你失败了。

## 怎么玩

向左向右移动 鼠标点击
