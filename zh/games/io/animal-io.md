# Animal.io

<a href="https://inkwengame.com/zh/games/animal-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-io/cover.jpg)

Animal.io 是一款有趣的多人在线游戏。控制你的动物，通过摆动尾巴将其他玩家推出平台。肉可以增加你的体型，汉堡可以延长尾巴的长度，蘑菇则会让你变小但速度更快。消灭敌人，赢得比赛！解锁更多可爱的动物！

## 怎么玩

使用摇杆移动，按 Tab 键摆动尾巴
