# Animal.io 3D

<a href="https://inkwengame.com/zh/games/animal-io-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animal-io-3d/cover.jpg)

Animal.io 是一款有趣的多人在线游戏。控制你的动物，通过摆动尾巴将其他玩家推下平台。肉类可以增加你的体型，汉堡可以延长尾巴的长度，蘑菇会让你变小但速度更快。击杀你的敌人并赢得游戏！解锁更多可爱的动物！
