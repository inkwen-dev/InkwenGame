# 颜色轮游戏

<a href="https://inkwengame.com/zh/games/color-wheel-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-wheel-game/cover.jpg)

疯狂无限颜色轮是一款简单、有趣且令人上瘾的单触点游戏，包含5种不同的颜色轮片，多种颜色主题以及多种主题的指针箭头。当指针颜色与指向的颜色轮片颜色相匹配时，您需要点击屏幕。
