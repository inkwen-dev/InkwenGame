# Dots.io

<a href="https://inkwengame.com/zh/games/dots-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dots-io/cover.jpg)

Dots.io 是一款精彩的点点对战游戏。你将从一个小小的灰色圆点开始。避开更大的圆点，同时尝试吃掉较小的圆点。一旦你变大，就会发现许多可以吃掉的圆点，但要始终小心那些更大的圆点。祝你好运

## 怎么玩

触摸或按住点击并滑动来游玩
