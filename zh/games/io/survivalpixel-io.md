# SurvivalPixel.io

<a href="https://inkwengame.com/zh/games/survivalpixel-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/survivalpixel-io/cover.jpg)

我们需要你在一款热门的生存游戏中发挥作用。帮助战士存活下来，并在每一关中协助他们对抗更强大的怪物。要小心，因为怪物会从四面八方涌来，你需要保持生存。拿起你的剑，消灭所有怪物。击败的怪物将为你提供生命值和力量。不断变强，最终击败Boss怪物。

## 怎么玩

使用WASD键左右移动以进行游戏，移动端也提供控制按钮
