# 难搞的杯子

<a href="https://inkwengame.com/zh/games/tricky-cups" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tricky-cups/cover.jpg)

你是否有能力成为杯子大师？游戏规则很简单：将球从一个杯子移动到另一个杯子，直到它们最终进入目标杯子。说起来容易做起来难！本游戏包含无穷无尽的关卡，设置充满挑战：有时只有一个球，有时有两个球。有时会有障碍物，或滑道帮助你。难度永无止境！
