# Wizard.io

<a href="https://inkwengame.com/zh/games/wizard-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wizard-io/cover.jpg)

Wizard.io 是一款设定在魔法与神秘领域的动作游戏。在充满神秘敌人的迷人竞技场中展开激烈的决斗。释放元素法术和巧妙的咒语，战胜你的对手。探索动态的法术组合，收集魔法水晶，并强化你的巫师基地以获得战略优势。发掘强大的神器，扭转战局于己方有利。

## 怎么玩

按住鼠标左键拖动，使用 WASD 方向键移动角色；使用鼠标左键与游戏内用户界面进行互动
