# Farming.IO

<a href="https://inkwengame.com/zh/games/farming-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/farming-io/cover.jpg)

Farming.IO 是一款 2D 飞行射击游戏，你玩得越久就越享受。这是一款拼图游戏，你需要将至少三个相邻的相同物品连接起来，以获得 500 枚金币。在计时器结束前尽可能多地获取金币，以便购买一些酷炫道具。

## 怎么玩

鼠标点击或轻触屏幕进行游戏
