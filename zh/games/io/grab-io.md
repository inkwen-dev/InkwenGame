# Grab.io

<a href="https://inkwengame.com/zh/games/grab-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/grab-io/cover.jpg)

grab.io 是一款快速的占地类街机游戏，风格类似 paper.io，设定在一个充满饥饿机器人的圆形竞技场中。悄悄离开你的领地，画一个环形路线，然后溜回家中，夺取内部的所有区域。从对手那里抢夺土地，抢夺星星以获得额外分数，并避开所有路径——触碰一次即致命。不断成长超越机器人，登上排行榜，戴上王冠。

## 怎么玩

用鼠标控制方向——你的头部会跟随光标移动。在任意位置拖动以设定方向。离开你的领地，画一个环形路线并返回自己的颜色，以占领其内部区域。触碰任何路径（包括你自己的或敌人的）都会立即结束游戏。
