# PETS.io

<a href="https://inkwengame.com/zh/games/pets-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pets-io/cover.jpg)

这是一款简单易学但难以精通的休闲游戏。你会越来越沉迷于这款游戏。在农场周围吃掉各种各样的农作物，但务必小心不要被农民或其他农场危险困住。你和羊群移动得越多，吃的作物越多，它们的数量就会越多。

## 怎么玩

你可以选择多种不同的宠物，如绵羊、公羊、猫、马、狗，甚至鸭子。解锁新的宠物，并升级你所选择的每只宠物的行为。你可以提升它们的移动速度。
