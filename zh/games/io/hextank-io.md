# HexTank.io

<a href="https://inkwengame.com/zh/games/hextank-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hextank-io/cover.jpg)

HexTank.io 是一款基于 Nimiq 区块链构建的 Web3 即时游戏，支持边玩边赚。游戏场景设定在一个 PVP 科幻对战竞技场。你将操控一辆 HexTank，任务是消灭所有其他玩家，并登上得分排行榜的顶端。HexTank.io 可在所有主流浏览器上运行，包括桌面版和移动版。

## 怎么玩

桌面键盘 WASD 或方向键 控制移动 空格键 射击 游戏手柄 摇杆 手柄摇杆 控制移动 L1 L2 R1 R2 射击 移动触摸控制 方向键 控制移动 红色圆圈 射击
