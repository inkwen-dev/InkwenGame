# 吃鱼IO

<a href="https://inkwengame.com/zh/games/eat-the-fish-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/eat-the-fish-io/cover.jpg)

游戏名称是一款免费的io游戏，你将扮演一条致命且饥饿的鱼，手持锋利的刀刃。加入多人竞技场，与其他鱼类对决，猎杀目标的同时也要避开其他玩家刀刃的尖端。吞噬较小的鱼以获得增益，不断成长，主宰海洋，成为海洋之王。

## 怎么玩

- 用一根手指控制你的鱼，通过从侧面或背后攻击来消灭其他鱼 - 按下右侧按钮可加速并获得优势 - 吞噬其他鱼以恢复法力 - 持续加速
