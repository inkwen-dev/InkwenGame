# 双球

<a href="https://inkwengame.com/zh/games/dual-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dual-balls/cover.jpg)

这是一款简单的休闲游戏，它会以逆时针和顺时针方向旋转，因此有点像无尽跑酷类游戏。如果你点击屏幕左侧，游戏将阻挡左侧并锁定其旋转方向，你将开始一次相当「不自然」的跳跃

## 怎么玩

轻触屏幕两侧进行控制
