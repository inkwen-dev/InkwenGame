# 企鹅大战.io

<a href="https://inkwengame.com/zh/games/penguinbattle-io" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/penguinbattle-io/cover.jpg)

企鹅大战.io 是一款有趣且令人上瘾的超休闲 io 游戏。你控制一只小企鹅，在冰山上进行战斗。你的任务是将其他企鹅推出这片冰山。如果你是最后一个留在冰山上的，你就赢了。这是一场冰上生存对决，最后存活的企鹅获胜。每隔几秒，冰山的一部分就会脱落。

## 怎么玩

使用鼠标移动企鹅
