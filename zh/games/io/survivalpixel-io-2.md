# SurvivalPixel.io

<a href="https://inkwengame.com/zh/games/survivalpixel-io-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/survivalpixel-io-2/cover.png)

SurvivalPixel.io 将你带入充满活力的像素化混乱之中，每一场战斗都在考验你的战略技巧。精准而敏捷地挥舞你的剑，击败一波又一波的怪物以提升你的技能。每一次胜利都让你变得更强大，足以挑战令人畏惧的头目，这一切都发生在一个充满激情与张力的迷人世界中。
