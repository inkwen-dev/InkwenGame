# 我能吃它吗

<a href="https://inkwengame.com/zh/games/can-i-eat-it" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/can-i-eat-it/cover.jpg)

“我能吃它吗？”是一款适合孩子和成年人的趣味游戏。你的任务是判断哪些食物可以吃，哪些不可以。当女孩吃了她本该吃的东西却被你阻止，或者你允许她吃了不该吃的东西时，游戏结束。

## 怎么玩

触摸或点击“是”或“否”按钮来玩游戏
