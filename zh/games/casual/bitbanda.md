# BitBanda

<a href="https://inkwengame.com/zh/games/bitbanda" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bitbanda/cover.jpg)

BitBanda 就是你口袋里的音乐工作室！无需任何乐器技巧：只需轻点音色卡，欢快的乐手们就会登台演奏。所有音色都已预先匹配好节奏和调性，所以演奏出错是不可能的。从第一次轻点开始，你就能创作出一首真正的乐曲！

## 怎么玩

1. 点击底部的音效卡片——乐手们就会登场演奏。任何组合都精彩纷呈！

2. 控制每位乐手：使用滑块调节音量，触发独奏 (🎧) 或静音 (🔉)，并移除不需要的乐手。

3. 调整效果——滤波器、回声和混响——打造你专属的音乐风格。

4. 在场景中填充不同的音效，将它们混合编排，然后点击“曲目”即可聆听完整的作品。

5. 寻找🔮隐藏音效组合——它们可以奖励音符并开启派对模式。

6. 保存你的曲目或将其发布到目录。聆听其他玩家的作品，点赞❤，并制作混音🎭。

7. 赢取音符，解锁新的音乐世界和配件，完成每日挑战，并角逐“每周冠军”的称号！
