# 匕首瞄准

<a href="https://inkwengame.com/zh/games/dagger-aim" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dagger-aim/cover.png)

匕首瞄准考验你的精准度和时机把握，你需要将匕首投向一个旋转的目标。击中目标，闪避金属板，并瞄准苹果以获得额外得分。随着每一关的推进，挑战逐渐加剧，需要更加专注，提升你的反应能力，带来令人兴奋的游戏体验。
