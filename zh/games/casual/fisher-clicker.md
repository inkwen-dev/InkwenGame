# 费舍尔点击器

<a href="https://inkwengame.com/zh/games/fisher-clicker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fisher-clicker/cover.jpg)

点击即可钓鱼。钓鱼并出售，用所得资金升级你的装备。购买鱼竿、浮标、船和渔夫服。在渔夫比赛中拔得头筹，赢得胜利，赚取金币，建造你自己的渔屋。

## 怎么玩

- 点击即可钓鱼；

- 拖动鱼进行连接；

- 拖动鱼进行出售；

- 点击炸药即可使用，一次炸掉多条鱼。
