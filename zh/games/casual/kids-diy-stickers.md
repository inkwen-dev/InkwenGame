# 儿童手工贴纸

<a href="https://inkwengame.com/zh/games/kids-diy-stickers" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kids-diy-stickers/cover.jpg)

儿童手工贴纸是一款休闲游戏。想象一下，用可爱的贴纸制作一张特别的卡片会有多有趣。你有一张透明卡片和各种可爱的贴纸，比如可爱的小狗、小兔子、小牛、美丽的花朵等。你可以从这些贴纸中选择你最喜欢的，贴在透明卡片上。最后，你可以保存并收藏自己制作的卡片。
