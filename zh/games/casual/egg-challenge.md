# 鸡蛋挑战

<a href="https://inkwengame.com/zh/games/egg-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/egg-challenge/cover.jpg)

3、2、1，开始！准备好迎接一场有趣的挑战吧！在这个游戏中，你可以选择1人、2人或3人参与。规则非常简单：按下按钮，把鸡蛋扔进篮子里。在单人模式中，选择一个时间限制，尝试在规定时间内将10个鸡蛋扔进篮子。在2人和3人模式中，通过比所有对手更早将10个鸡蛋扔进篮子来赢得比赛。一场有趣又充满竞争的游戏正等着你！

## 怎么玩

玩家1 W 键 玩家2 J 键 玩家3 上箭头键
