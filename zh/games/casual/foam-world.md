# 泡沫世界

<a href="https://inkwengame.com/zh/games/foam-world" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/foam-world/cover.jpg)

泡沫世界是一款游戏，你需要用五颜六色的球填满瓶子以制造泡沫。你需要使用按钮来引导球朝正确的方向移动，这些按钮会提供不同方向的推力。

## 怎么玩

鼠标点击或轻触开始游戏
