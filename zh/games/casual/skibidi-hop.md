# Skibidi Hop

<a href="https://inkwengame.com/zh/games/skibidi-hop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skibidi-hop/cover.jpg)

这只是一个非常简单的无尽休闲游戏！帮助Skibidi，当你奔跑时尽量避开红色三角形；很简单：你只需跳跃！但你在一颗行星上奔跑，所以你需要尽可能坚持更久，并创造最佳纪录！这款游戏适合所有人，尽情享受吧！
