# MiniMarin

<a href="https://inkwengame.com/zh/games/minimarin" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minimarin/cover.jpg)

MiniMarin 是一款以海洋为背景的游戏，小尼莫鱼需要在其他食肉鱼类的威胁下求生。你需要点击并移动尼莫鱼，确保没有其他动物靠近她。一旦发生碰撞，游戏就结束了！祝你玩得愉快。

## 怎么玩

点击橙色的鱼并移动它，躲避其他海洋生物
