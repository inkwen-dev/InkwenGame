# Fisquarium

<a href="https://inkwengame.com/zh/games/fisquarium" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fisquarium/cover.jpg)

Fisquarium 是一款休闲点击游戏，将点击的乐趣与水族馆的宁静氛围相结合。在这款游戏中，玩家通过点击来获得鱼类，解锁多种物种，通过升级提升产量，发现新的鱼种，收集奖杯，并沉浸于水下奇观的放松世界中。无论你是休闲玩家还是点击游戏爱好者，Fisquarium 都能带来轻松愉快的游戏体验！

## 怎么玩

使用鼠标左键点击鱼以启动鱼类生产。使用鼠标滚轮向上或向下选择升级
