# 恐龙堆叠器

<a href="https://inkwengame.com/zh/games/dino-piler" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dino-piler/cover.jpg)

扮演一只可爱的恐龙来下蛋。建造最高的蛋塔，并与其他玩家竞争。你的任务是将不同颜色的蛋排成一排。

## 怎么玩

要放置一个蛋，需要点击屏幕右侧或按键盘上的右箭头；要移除一个蛋，需要点击屏幕左侧或按键盘上的左箭头。
