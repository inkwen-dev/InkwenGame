# 疯狂球 picker

<a href="https://inkwengame.com/zh/games/crazy-ball-picker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-ball-picker/cover.jpg)

如果你准备好了，试试通过画线将向上弹起的球放进桶里。不要让球掉下来。看看你能收集多少个球，你只能画三条线。

## 怎么玩

移动设备操作 用手指按住屏幕并拖动来画线 电脑操作 按住鼠标左键并拖动来画线
