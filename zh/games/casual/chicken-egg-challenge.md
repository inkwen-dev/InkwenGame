# 鸡肉蛋挑战

<a href="https://inkwengame.com/zh/games/chicken-egg-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chicken-egg-challenge/cover.jpg)

你准备好和朋友一起参加有趣的比赛了吗？在你的朋友把10个鸡蛋放进你的篮子之前，先让你的朋友把篮子装满。第一个装满篮子的人获胜。输掉比赛的玩家必须下注！如果你不想闻朋友的袜子味，不想吃洋葱，或者不想跳鸡舞，那就赶快按按钮吧！祝你玩得开心！

## 怎么玩

单人游戏 J 键 双人游戏 W键 和 上箭头键 三人游戏 W键、J键 和 上箭头键 你可以在手机上玩这个游戏
