# 颜色堆叠

<a href="https://inkwengame.com/zh/games/color-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-stack/cover.jpg)

在"颜色堆叠"游戏中，尽可能多地运送砖块。每一关都会展示一个新场景，有一个不同颜色的人物。请注意运送相同颜色的砖块，避免运送不同颜色的砖块。你只需触摸砖块，它们就会自动堆叠，享受颜色堆叠的乐趣！

## 怎么玩

滑动以移动
