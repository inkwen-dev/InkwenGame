# IDLE: 重力爆发

<a href="https://inkwengame.com/zh/games/idle-gravity-breakout" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/idle-gravity-breakout/cover.jpg)

摧毁作为重力中心的棕色球。通过点击它们，或购买其他球来替你战斗。合并你的球以增强它们的力量，购买升级以赋予它们新能力

## 怎么玩

- 点击棕色敌人以造成伤害 - 赚取金钱以购买新球与你并肩作战 - 赚取宝石以通过升级球来帮助你
