# IDLE：行星突破

<a href="https://inkwengame.com/zh/games/idle-planets-breakout" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/idle-planets-breakout/cover.jpg)

摧毁作为重力中心的怪物行星。通过点击它们来摧毁它们。你可以购买小球来代替点击，让它们为你战斗，而这正是游戏乐趣开始的地方。合并你的小球以增强它们的力量，并购买升级来赋予它们新的能力。购买升级；摧毁以变得更强大；变得更强大以继续摧毁，在这款永无止境且令人上瘾的游戏中不断循环。
