# 方块摧毁者

<a href="https://inkwengame.com/zh/games/block-destroyer" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-destroyer/cover.jpg)

一款你需要通过投掷球来摧毁塔楼的游戏。你需要通过投掷球来摧毁各种建筑，通过关卡后你会获得金币，这些金币可以用来购买新的球

## 怎么玩

点击屏幕投掷球。瞄准以摧毁建筑物，点击屏幕后球将朝你点击的方向飞去
