# 侏罗纪恐龙横冲直撞游戏

扮演一只饥饿的恐龙，踏上狂野的冒险之旅！每个关卡中，你都需要完成一项任务：吃掉动物、摧毁场景道具，吞噬沿途的一切。但要小心：一只巨型恐龙在地图上游荡，伺机猎杀你。一旦被它发现，就会被吃掉，关卡也就失败了！保持隐蔽，巧妙移动，完成任务，解锁下一关。随着关卡的推进，会出现更多巨型恐龙，让每个关卡都更加艰难刺激…

## 怎么玩

WASD键 = 移动玩家

沿X轴移动鼠标（点击并拖动屏幕）= 旋转玩家

屏幕摇杆（左下角）= 移动玩家

吃掉按钮 = 吃掉动物和物品（靠近时也会自动吃掉）

## 介绍

扮演一只饥饿的恐龙，踏上狂野的冒险之旅！每个关卡中，你都需要完成一项任务：吃掉动物、摧毁场景道具，吞噬沿途的一切。但要小心：一只巨型恐龙在地图上游荡，伺机猎杀你。一旦被它发现，就会被吃掉，关卡也就失败了！保持隐蔽，巧妙移动，完成任务，解锁下一关。随着关卡的推进，会出现更多巨型恐龙，让每个关卡都更加艰难刺激。你能否一路生存、吞噬、破坏，最终登上食物链顶端？

游戏特色：

扮演恐龙，完成每个关卡的吞噬任务

摧毁场景道具，吞噬地图上的动物

躲避在每个关卡巡逻的巨型敌方恐龙

随着关卡的推进，敌方恐龙数量增多，关卡难度也会提升

操作简单，支持键盘、鼠标和屏幕虚拟摇杆。
