# 花园求生

<a href="https://inkwengame.com/zh/games/garden-survive" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/garden-survive/cover.jpg)

你必须在由方块构成的花园中，让你的方块角色存活下来。要小心向你逼近的刀片、会砸到你的墙壁以及带刺的木头。如果能抓住偶尔出现在花园中的生命补给，你就能获得额外生命。每通过一关，你将解锁新角色的权限。

## 怎么玩

方向键或 WASD
