# Skibidi 三连跳

<a href="https://inkwengame.com/zh/games/skibidi-triple-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skibidi-triple-jump/cover.jpg)

Skibidi 三连跳游戏，是一款单指点击的跳跃反应类游戏，拥有打造下一个应用商店爆款所需的一切！运用你的技巧和敏捷性，通过跳跃避开障碍物并生存下来。只需轻触屏幕，完成三次跳跃，直到再次触地。避开危险障碍物，否则你的 Skibidi 角色将会爆炸，游戏结束！

## 怎么玩

鼠标点击 或 轻触屏幕，或按空格键进行跳跃
