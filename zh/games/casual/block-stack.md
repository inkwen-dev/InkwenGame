# 方块堆叠

<a href="https://inkwengame.com/zh/games/block-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-stack/cover.jpg)

方块堆叠是一款有趣的堆叠和反应游戏，你需要在方块移动时停止并尽可能地搭建更高的塔。等待下一个方块与建筑物对齐后，点击屏幕将其堆叠起来。如果你在错误的时机点击，导致方块掉落，就必须从头开始。

## 怎么玩
