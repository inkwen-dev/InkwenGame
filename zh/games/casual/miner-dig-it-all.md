# 矿工，挖遍一切

你的钻头只有一罐燃料。看看你能钻多深！

## 怎么玩

• 鼠标：按住鼠标左键钻孔。按住并拖动可铺设炸药线，单击可放置一根炸药。右键单击可提前引爆炸药。

• 触摸屏：点击放置一根炸药，拖动铺设炸药线，按住钻孔。炸药会自动引爆。

• 空格键引爆已放置的炸药。

• 按 Esc 或 Tab 键暂停。

## 介绍

你的钻头只有一罐燃料。看看你能钻多深！

拖动鼠标铺设炸药线，引爆，然后握住钻头，将碎石磨碎。清除这一层后，它会在你脚下坍塌，直接进入更富饶的下一层。回到地面，卖掉矿石，购买更坚硬的钻头、更广的爆破范围和机器人操作组，然后再次下潜。十层之下是熔岩核心：击碎它，整个矿坑就会重新开始，而且会永久富饶！
