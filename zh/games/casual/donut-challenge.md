# 甜甜圈挑战

<a href="https://inkwengame.com/zh/games/donut-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/donut-challenge/cover.jpg)

喜欢甜甜圈又不想分享的人，都在这里吗？在朋友之前抓住各种甜甜圈！你需要抓住旋转盘上中间部分的甜甜圈。第一个在旋转托盘上抓住5个甜甜圈的人赢得游戏。注意盘子上旋转的 - 和 + 分数！这些数字可能会让你得分或失分！你也可以通过点击屏幕来控制游戏。尽情享受吧！

## 怎么玩

玩家1 W 键 玩家2 上箭头 或 触摸
