# Bloxorz：彩色方块滚动

<a href="https://inkwengame.com/zh/games/bloxorz-color-block-roll" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bloxorz-color-block-roll/cover.jpg)

一款以颜色为核心的滚动立方体益智游戏。滚动一个涂有颜色的立方体到达出口，使其落点只能落在与地面接触面颜色相同的方块上。游戏包含 60 个关卡，每个关卡都由颜色匹配的路径组成，平台会旋转、移动甚至瞬移，是对空间思维能力的一次令人满意的考验。

## 怎么玩

移动 — WASD 或方向键

移动（鼠标）— 按住鼠标左键并向某个方向拖动，然后松开

移动（触摸）— 向某个方向滑动

一次移动一步。选择向上、向下、向左或向右移动以到达目标。
