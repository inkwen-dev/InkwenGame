# 在道路上

<a href="https://inkwengame.com/zh/games/in-the-path" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/in-the-path/cover.jpg)

在这个游戏中，你的目标是改变球的方向，使其沿着路径前进而不与墙壁碰撞，并收集宝石以购买更多皮肤并达到最高分数。

## 怎么玩

点击或轻触以改变球的方向，并避开墙壁以免死亡
