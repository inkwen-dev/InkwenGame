# 清洁公主

<a href="https://inkwengame.com/zh/games/cleaning-princess" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cleaning-princess/cover.jpg)

这是一款专为女孩设计的ASMR游戏。如果你喜欢把一切打扫干净，那么这款游戏非常适合你。游戏包含5种模式：耳朵清洁、脚后跟清洁、背部按摩、牙齿清洁和风扇清洁。你可以使用不同的工具来清洁和按摩身体部位。但需要注意的是，每种模式都有倒计时时间，你必须选择正确的工具进行清洁。
