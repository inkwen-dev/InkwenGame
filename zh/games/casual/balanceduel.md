# BalanceDuel

<a href="https://inkwengame.com/zh/games/balanceduel" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/balanceduel/cover.jpg)

Balance Duel 是一款基于平衡元素的趣味格斗游戏，你将手持武器，直接与对手展开充满欢笑的战斗。你的任务不仅是进攻，还要保持自身的平衡，巧妙把握时机，率先击倒对手，同时避免自己失足。每一次碰撞都充满不可预测性，让比赛既紧张又幽默。谁能更好地维持平衡，谁就是最终的胜利者！

## 怎么玩

- 使用 A 键或左箭头键后退 - 使用 D 键或右箭头键前进
