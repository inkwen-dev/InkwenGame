# Treatsy

<a href="https://inkwengame.com/zh/games/treatsy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/treatsy/cover.jpg)

Treatsy 是一款糖果放置游戏，糖果从一个魔法罐中不断涌出，你需要点击它们来增加分数，以免它们碰到边界。一旦它们碰到边界，如果你再点击它们，分数就会下降。挑战性十足又充满乐趣！

## 怎么玩

在糖果碰到边界前点击它们
