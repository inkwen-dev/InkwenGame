# 二进制球

<a href="https://inkwengame.com/zh/games/binary-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/binary-balls/cover.jpg)

二进制球是一款游戏中，有两种类型的球会陆续出现，上面分别写着0或1。你需要将它们收集到装有相同数字球的碗中，而通过鼠标点击并按住再释放来交换碗的位置。尽情享受吧 :)

## 怎么玩

按住鼠标左键或松开以交换碗
