# 机械闲置

![cover](https://img.inkwengame.com/games/maskinery-idle/cover.jpg)

《Maskinery Idle》是一款放置类点击游戏，玩家将探索神秘岛屿，与敌人战斗，并收集赋予独特能力的强大面具。清除每个区域网格上的所有方格即可进入五个关卡。在最终关卡中击败 Boss 即可完成该区域并解锁下一个区域。收集金币购买升级道具，获取能量提升面具等级，并使用重生系统。

## 怎么玩

操作方式

左键点击/轻触 -> 攻击方块、激活面具、按下按钮

就是这么简单——整个游戏只需单击/轻触即可完成。无需键盘。

游戏玩法

1. 点击方块造成相当于你力量值的伤害。被摧毁的方块会掉落金币和能量。

2. 敌人（红色方块）会反击——它们会将伤害反弹给你。如果你的生命值过低，无法承受一次攻击，敌人将被锁定，直到你恢复生命值。

3. Boss 会在第五关出现，它是一个 3x3 的大型方块。先清除覆盖 Boss 的方块，然后击败它即可完成该关卡。

4. 返回村庄（安全区）花费金币升级：最大生命值、生命值回复速度和力量值。
