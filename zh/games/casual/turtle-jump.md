# 乌龟跳跃

<a href="https://inkwengame.com/zh/games/turtle-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/turtle-jump/cover.jpg)

乌龟跳跃是一款非常有趣的休闲游戏，将考验你的技巧。通过点击屏幕，让乌龟尽可能多地攀爬平台，以获得分数并打破自己的记录。注意躲避敌人和尖刺。使用炸弹可以消除屏幕上所有的敌人，你还可以收集护盾和跳跳鞋来保护自己并获得更多分数。游戏设计精美且色彩丰富。
