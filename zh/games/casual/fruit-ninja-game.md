# 水果忍者游戏

<a href="https://inkwengame.com/zh/games/fruit-ninja-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fruit-ninja-game/cover.jpg)

水果忍者是一款街机游戏，你需要通过滑动和切割的方式，切掉各种水果，从梨子和苹果，到椰子和香蕉。通过一次切割多个水果来争取最高分数，并不断积累连击，超越所有人！你还可以通过精准地击中水果获得巨大分数，因此要战略性地进行滑动操作。然而，要小心炸弹！击中任何一个炸弹都会结束你的游戏。经典水果切割滑动冒险，现在就来体验吧！

## 怎么玩

鼠标点击或轻触屏幕开始游戏
