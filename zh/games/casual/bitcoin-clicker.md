# 比特币点击器

<a href="https://inkwengame.com/zh/games/bitcoin-clicker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bitcoin-clicker/cover.jpg)

在这个游戏中，你可以建立自己的挖矿农场！赚取比特币 -> 在动态股票交易所将其兑换为美元 -> 购买更多的显卡、处理器 -> 挖掘更多的比特币。每个部分（rx 和 gtx）最多可添加10张你的显卡。

## 怎么玩

使用鼠标进行游戏
