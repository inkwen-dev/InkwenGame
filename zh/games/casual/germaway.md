# GermAway

<a href="https://inkwengame.com/zh/games/germaway" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/germaway/cover.jpg)

GermAway 是一款快速、简单且高度反应的生存游戏，你的唯一任务非常明确：远离屏幕上的每一个病菌。你控制一个微小的角色，在充满游走、弹跳和不可预测的传染性病菌的环境中移动。这些病菌会滑动、旋转、追击或在竞技场中漂移——只要触碰一次，感染就会传播，游戏也就结束了。

## 怎么玩

移动以确保玩家不触碰病菌
