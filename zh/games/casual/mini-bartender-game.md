# 迷你调酒师游戏

<a href="https://inkwengame.com/zh/games/mini-bartender-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/mini-bartender-game/cover.jpg)

移动调酒师的手，收集尽可能多的酒杯，用它们来调制不同的饮品，用许多洞穴和吸引人的物品进行装饰。请注意，每个关卡中都会遇到一些障碍物，可能会阻止你完全达成目标。网站开发者 <a href='https://kiz10.com/'>https://kiz10.com/</a>

## 怎么玩

操作 使用鼠标在桌面端移动 在移动端点击屏幕并拖动以移动
