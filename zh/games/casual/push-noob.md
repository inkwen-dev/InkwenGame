# 推小丑

<a href="https://inkwengame.com/zh/games/push-noob" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/push-noob/cover.jpg)

推小丑 - 是一款关于跳舞小丑和他的坠落的精彩模拟游戏。加入收集钻石来提升小丑并解锁新地点的行列吧！向小丑投掷雪球，通过他的碰撞获取钻石！解锁新关卡和皮肤！比拼谁获得的钻石更多！- 逼真的3D物理效果 - 小丑的炫酷舞蹈 - 12个关卡 - 12种小丑皮肤

## 怎么玩

PC操作：投掷雪球点击鼠标左键；移动相机按住鼠标右键并旋转；缩放相机滚动鼠标滚轮；手机操作：投掷雪球点击屏幕
