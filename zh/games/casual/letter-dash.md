# 字母冲刺

<a href="https://inkwengame.com/zh/games/letter-dash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/letter-dash/cover.jpg)

在《字母冲刺》中，玩家会看到不断下落的字母，必须迅速在键盘上输入对应的字母以摧毁它们，防止它们到达底部。游戏的目标是准确且快速地输入字母，避免字母堆积至底部。随着游戏进程，下落的字母可能会加快速度或变得更加复杂，从而提高难度。

## 怎么玩

点击键盘上的字母，或在使用PC时按下对应键
