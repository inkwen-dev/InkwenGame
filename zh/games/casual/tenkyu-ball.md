# 天降球

<a href="https://inkwengame.com/zh/games/tenkyu-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tenkyu-ball/cover.jpg)

《TENKUI BALL》是一款3D休闲滚球益智游戏，玩家需要引导小球穿过倾斜的关卡到达终点。游戏画面简洁，挑战在于如何平衡控制与风险。随着关卡倾斜角度的增加，小球滚动速度加快，但同时也存在风险：如果倾斜角度过大，小球可能会掉落，导致关卡失败。

## 怎么玩

倾斜舞台/滑动手指：

在屏幕上滑动（或拖动）即可倾斜球所在的表面。

倾斜方向决定球的滚动方向。

谨慎控制：

倾斜角度过大，球会加速并可能掉落边缘。

只需倾斜到足以转弯、避开缝隙和完成复杂操作的程度即可。

到达终点：

每个关卡都有一个终点或出口，您必须将球成功送达，且不能掉落。

失败和重试：

如果球掉落，关卡结束（您失败），您需要重新开始该关卡。
