# 快速颜色

<a href="https://inkwengame.com/zh/games/fast-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fast-color/cover.jpg)

欢迎来到《颜色快速点击》——一款简单有趣的颜色游戏！游戏中有4个彩色方块和一个较大的彩色矩形。游戏的目标是点击与矩形颜色相同的方块。如果颜色匹配正确，颜色会改变，游戏继续进行。如果匹配错误，游戏结束！单人游玩，打破个人最佳成绩；或挑战朋友，争夺最高分和炫耀的资本！

## 怎么玩
