# 滚动平衡球

<a href="https://inkwengame.com/zh/games/rolling-balancer-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rolling-balancer-ball/cover.jpg)

《滚动平衡球3D》是一款简单却极具挑战性的平衡游戏，你的主要目标是引导一个滚动的球穿过被水环绕的狭窄木桥。你必须保持球的稳定，避开陷阱，并安全抵达每个关卡终点的船只。游戏玩法基于物理引擎，因此任何细微的操作都至关重要——一次错误的滑动就可能导致球落入水中。

## 怎么玩

左右滑动 → 控制球向左或向右移动。

向前拖动 → 控制球向前滚动（拖动速度可快可慢）。

遇到陷阱时，减速并调整球的位置使其笔直通过。

保持平衡直至到达终点。

到达船边即可完成关卡。
