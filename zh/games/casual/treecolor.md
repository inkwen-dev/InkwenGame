# TreeColor

<a href="https://inkwengame.com/zh/games/treecolor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/treecolor/cover.png)

TreeColor 提供了一场令人兴奋的旅程，玩家需要匹配从上方倾泻而下的鲜艳球体，在迷人的色彩舞蹈中体验乐趣。随着动态的色调变化和不断升级的挑战，游戏以其简单与复杂的巧妙平衡吸引着玩家，让你在沉浸于迷人的万花筒般视觉效果的同时，磨练自己的反应能力。
