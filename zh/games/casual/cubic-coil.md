# 立方线圈

<a href="https://inkwengame.com/zh/games/cubic-coil" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cubic-coil/cover.jpg)

引导一条绿黑相间的体素蛇在一个可旋转的立方体内移动。旋转蛇和立方体来调整移动路线，收集体素水果方块和稀有的大水果以获得奖励分数。经典贪吃蛇规则，以清新的绿色背景，用 3D 技术重新演绎。

## 怎么玩

PC：使用 WASD 键旋转立方体。使用方向键控制蛇的方向。

移动端：向左滑动旋转立方体；向右滑动控制蛇的方向。
