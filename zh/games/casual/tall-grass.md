# 高草

<a href="https://inkwengame.com/zh/games/tall-grass" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tall-grass/cover.jpg)

每一根高高的草叶都藏着秘密：碎片、爱心或怪物。

## 怎么玩

移动：方向键或 WASD 键。在移动设备上，点击方向键或滑动屏幕。

进入高草丛即可割草。

进入苏醒的怪物身边即可攻击它。

数字显示周围八个方格内隐藏的怪物数量。

选择增益：1 或 2，或左或右

暂停：P

静音：M

开始或重新开始：回车键或空格键

## 介绍

每一根高高的草叶都藏着秘密：碎片、爱心或怪物。

踩踏它，一探究竟。清理过的方格会显示周围八个方格中潜伏着多少怪物，

所以每一步都既是一次冒险，也是一次考验。

大门会在田野被清理干净之前开启：带着你已有的东西离开，或者继续深入，
寻找南瓜王醒来时你需要的碎片和升级道具。

每天的游戏体验都截然不同。天气每天早晨都会变化——雨水会延缓
怪物的苏醒，雾气会缩短你的阅读时间，霜冻会减缓整个田野的移动速度，
黄昏会遮蔽光线——而且每个田野里都隐藏着一些东西，只有
细心的观察者才能发现。

单指操作，单次移动，完全回合制：在你移动之前什么都不会发生，所以
没有反应会出错。
