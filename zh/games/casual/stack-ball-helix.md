# 堆叠球螺旋

<a href="https://inkwengame.com/zh/games/stack-ball-helix" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stack-ball-helix/cover.jpg)

《堆叠球螺旋》是一款3D街机游戏，玩家需要在旋转的螺旋平台上撞击、碰撞和弹跳，以到达终点。你的小球像砖块一样撞碎五彩缤纷的平台来阻止其下落，但如果你碰到黑色平台，游戏就结束了！如果加速，即使黑暗的堆叠也不会阻碍你，小球将能够克服它们。

## 怎么玩

- 只需按住手指以增加小球下落速度 - 不要撞碎或触碰黑色堆叠
