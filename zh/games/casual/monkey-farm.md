# 猴子农场

<a href="https://inkwengame.com/zh/games/monkey-farm" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monkey-farm/cover.jpg)

猴子农场是由TinyDobbins制作的一款闲置/管理游戏。你控制一个可爱的猴子角色，刚刚开了一家超市。种植水果，从一个站台移动到另一个站台，为摊位摆放香蕉或玉米等物品。顾客会前来取货，并在收银台处等待你。你可以升级你的角色，解锁新的工作站点，甚至招募其他员工来帮你管理商店！
