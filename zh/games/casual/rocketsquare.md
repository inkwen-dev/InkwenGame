# RocketSquare

<a href="https://inkwengame.com/zh/games/rocketsquare" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rocketsquare/cover.jpg)

RocketSquare 是一款专为儿童设计的趣味游戏，玩家控制一枚火箭，避免与不断出现的致命物体以及墙壁发生碰撞。每次点击，火箭都会向左转90度，你需要熟练掌握这一操作。尽情享受游戏乐趣吧！

## 怎么玩

点击以使火箭旋转90度
