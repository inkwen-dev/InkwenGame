# 踢幸运方块，防止脑腐

投掷幸运方块，锻炼力量，收集所有脑洞大开的生物！迎接奶酪天气，尽情享受奶酪脑洞大开的乐趣吧！

## 怎么玩

使用屏幕上的按钮。

手机操作：左摇杆移动角色。右摇杆旋转视角。

电脑操作：WASD 键移动角色。按住鼠标右键旋转视角。空格键跳跃。鼠标左键攻击。Q 键投掷脑腐。E 键拾取或偷取脑腐。

## 介绍

投掷幸运方块，锻炼力量，收集所有脑洞大开的生物！迎接奶酪天气，尽情享受奶酪脑洞大开的乐趣吧！

击碎稀有方块，收集滑稽的脑洞生物，并将它们带回你的基地。但要小心——每一次强力踢击都可能引发巨大的海啸！奔跑、跳跃，在被海水吞没之前生存下来。

提升你的力量，锻炼你的腿部力量，购买新的负重，变得足够强大，将方块踢得更远。踢得越远，你就能发现越丰厚的奖励！

游戏特色：

- 踢击神秘方块，发现稀有奖励

- 在巨大的海啸中生存下来

- 收集脑洞生物，并将它们放置在你的基地

- 升级你的力量、速度和训练装备

- 解锁更强力的踢击，探索新的区域
