# 魔法桥

<a href="https://inkwengame.com/zh/games/magic-bridge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magic-bridge/cover.jpg)

《魔法桥》是由Neutronized制作的一款技巧类游戏。操控众多猫咪角色之一，努力在不断向上移动的桥上生存下去。桥会根据你的站立位置向下倾斜，因此你必须迅速反应，保持平衡。避开所有敌人，收集所有硬币，并解锁拥有不同能力的更多角色。跃上桥面，体验无尽乐趣！

## 怎么玩

在平台上移动，避免触碰敌人；操控猫咪——使用A、D键或左、右方向键
