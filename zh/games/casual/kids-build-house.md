# 儿童建房

<a href="https://inkwengame.com/zh/games/kids-build-house" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kids-build-house/cover.jpg)

《儿童建房》是一款教育类游戏。在游戏中，你可以帮助小动物们建造适合它们的房屋。你可以帮助猴子在雨林风格下建造香蕉树屋，帮助企鹅建造白色冰屋，帮助兔子建造温室来种植胡萝卜，并使用树干为小熊建造一座木屋。
