# 圣诞之战

<a href="https://inkwengame.com/zh/games/christmas-wars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-wars/cover.jpg)

在充满姜饼人和精灵的神秘森林中战斗，圣诞老人不会把你的礼物送给你，因此你必须通过魔法森林与他战斗，亲自取得自己的礼物。

## 怎么玩

使用 WASD 或方向键，鼠标点击朝你面对的方向投掷雪球

## 介绍

在充满姜饼人和精灵的神秘森林中战斗，圣诞老人不会把你的礼物送给你，因此你必须通过魔法森林与他战斗，亲自取得自己的礼物。
