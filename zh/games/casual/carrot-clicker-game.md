# 胡萝卜点击游戏

<a href="https://inkwengame.com/zh/games/carrot-clicker-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

在这个游戏中，玩家使用鼠标左键点击胡萝卜来获得分数，这些分数用于收集兔子并提高得分速度。在胡萝卜点击游戏中，玩家通过反复点击屏幕上的元素来取得进展，并解锁新功能。

## 怎么玩

使用鼠标左键或在移动屏幕上轻触以收集胡萝卜分数
