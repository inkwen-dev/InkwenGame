# 忍者坠落

<a href="https://inkwengame.com/zh/games/ninja-drop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ninja-drop/cover.jpg)

忍者坠落是一款游戏，你需要投掷你的忍者飞镖（手里剑）来击破来袭的球。注意！一旦炸弹出现，它将在3回合后爆炸。所以你必须在看到它时立即消灭，否则游戏结束。你能打破最高分吗？

## 怎么玩

点击屏幕以投掷你著名的手里剑
