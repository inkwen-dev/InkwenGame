# 果汁机

<a href="https://inkwengame.com/zh/games/juice-machine" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/juice-machine/cover.jpg)

果汁机是一款轻松的休闲游戏，你将操作一台色彩缤纷的搅拌机。水果会不断出现，你需要等待刀片将它们搅成美味的果汁。你可以直接点击水果以加快搅拌过程并获得额外资源。使用奖励升级搅拌机至最高等级，提高速度和效率。简单、有趣且极具上瘾性！
