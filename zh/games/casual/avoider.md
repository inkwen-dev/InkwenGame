# 躲避者

<a href="https://inkwengame.com/zh/games/avoider" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

一款有趣且富有挑战性的街机游戏，你需要避开下落的物体、怪物甚至激光！避开从左边、右边以及上方掉落的箱子和球体！收集沿途出现的所有宝石。别忘了你可以跳跃。尽可能坚持更长时间！

## 怎么玩

桌面端 按键盘左右箭头键移动 按上箭头键跳跃 移动端 使用触摸屏按钮
