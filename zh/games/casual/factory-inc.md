# 工厂公司

<a href="https://inkwengame.com/zh/games/factory-inc" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/factory-inc/cover.jpg)

工厂公司是一款街机游戏。你的工厂生产了一些不合格的产品，作为操作员，你必须用液压机将它们压碎。点击并按住，机器就会将它们压碎，我得说这是一种很好的减压方式。但要注意避开炸弹和调制管。快来玩这个游戏吧！

## 怎么玩

点击并按住以移动，松开以停止
