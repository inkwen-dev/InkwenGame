# Snake YO

<a href="https://inkwengame.com/zh/games/snake-yo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-yo/cover.jpg)

“Snake YO” 是一款俯视角游戏，你将扮演一条蛇，需要吃魔法食物来成长并变强。尽可能长时间地存活，并尽可能多地摧毁敌方蛇以积累分数并保存你的最高分。使用冲刺技能完成更困难和更具风险的动作。一款随时随地都能玩的非常有趣的游戏。祝你玩得愉快！

## 怎么玩

桌面端 - 使用鼠标光标控制蛇的转向 - 按住左键进行冲刺
移动端 - 触摸屏幕上的按钮来转向蛇并使用冲刺
