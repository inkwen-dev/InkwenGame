# 我的简单生存点击游戏

<a href="https://inkwengame.com/zh/games/my-simple-surviving-clicking-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/my-simple-surviving-clicking-game/cover.jpg)

通过击打树木来尽可能长时间地生存。努力生存得越久越好。除非你补充生命值，否则你的生命值会自然减少至零。

## 怎么玩

点击或轻触地面的某个位置以移动。通过点击或轻触树木三次来恢复生命值
