# 猫喝牛奶

<a href="https://inkwengame.com/zh/games/the-cat-drink-milk" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-cat-drink-milk/cover.jpg)

像猫这样的宠物喜欢喝牛奶。在游戏《猫喝牛奶》中，你将用牛奶喂养各种猫咪。你会以一种相当独特的方式进行。屏幕上会出现一个游戏区域，底部会有一只坐着的猫。一袋牛奶会悬挂在绳子上，位于某个高度，它会像钟摆一样左右摆动。你会有剪刀可用。你需要判断时机，在牛奶袋正上方猫的位置时剪断绳子。这样牛奶袋就会落入猫的手中，你将获得分数。
