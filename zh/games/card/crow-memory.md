# 乌鸦记忆

<a href="https://inkwengame.com/zh/games/crow-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crow-memory/cover.jpg)

乌鸦记忆是一款以乌鸦为主题的记忆配对游戏，包含8个独特角色和总共16张卡片。游戏开始时，使用Fisher-Yates算法对卡片进行洗牌，以确保随机分布。计时器在玩家首次点击时启动，每成功匹配一对卡片，玩家得分增加1分。完成一局后，只需点击“开始/重新开始”即可再次洗牌并开启新的一轮。
