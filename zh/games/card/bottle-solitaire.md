# 瓶中接龙

<a href="https://inkwengame.com/zh/games/bottle-solitaire" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bottle-solitaire/cover.jpg)

游戏目标：尽可能多地消除瓶子。最好最后只剩下一个瓶子，并且它位于最中心的位置。点击选择想要移动的瓶子，它可以跳到的位置会自动显示出来，只需点击目标位置即可。
