# Stacklands

<a href="https://inkwengame.com/zh/games/stacklands" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stacklands/cover.jpg)

Stacklands 是一款具有创新玩法的卡牌游戏。它融合了城市管理和堆叠卡牌游戏的元素，各种实体均以卡牌形式呈现，是一款新颖的游戏。例如，将村民卡放置在浆果灌木卡上时，村民会自动采集浆果，然后将浆果卡拖到村民卡上，以恢复村民的饱腹度。数十个任务和新颖的游戏机制等待着你的挑战与探索，你准备好了吗？
