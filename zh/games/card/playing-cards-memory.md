# 扑克牌记忆

<a href="https://inkwengame.com/zh/games/playing-cards-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/playing-cards-memory/cover.jpg)

我们与你一同在游戏《扑克牌记忆》中，将帮助他完成这项挑战。与他一起，你将玩最简单的纸牌游戏，你的专注力将对你大有帮助。屏幕上会显示铺在桌布上的卡片。你需要同时翻开两张卡片，并尝试记住它们。一旦找到两张相同的卡片，就将它们同时翻开，从而获得这一回合的分数。请记住，任务有特定的时间限制。

## 怎么玩

使用鼠标或触摸屏幕
