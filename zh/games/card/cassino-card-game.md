# 卡西诺纸牌游戏

<a href="https://inkwengame.com/zh/games/cassino-card-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cassino-card-game/cover.jpg)

目标是通过从手中打出一张与桌面上的牌数字相同，或与多张桌面上的牌数字之和相同的牌，来从桌面上的牌堆中捕获牌。

## 怎么玩

此应用程序仅用于娱乐目的，游戏积分不具有实际货币价值，您需要一点耐心和放松，现在就开始享受吧
