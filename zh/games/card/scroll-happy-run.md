# 滚动快乐跑

<a href="https://inkwengame.com/zh/games/scroll-happy-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scroll-happy-run/cover.jpg)

这是一款有趣且令人上瘾的技巧游戏，你需要控制一个小小角色，在充满障碍物和间隙的小路上滚动，并与其他角色汇合以到达终点。开始滚动，通过每一关的终点，并收集其他小角色来组成更大的轮子。加入的角色越多，你就能越过越大的障碍物和间隙，但当然也会失去一些落后的小小角色。尽量在每一关中保留尽可能多的角色…

## 怎么玩

这款游戏操作简单，采用幽默风格的鼠标控制方向，以避开障碍物。玩家需要更多小人物滚入更大的轮子，以帮助自己顺利通关。
