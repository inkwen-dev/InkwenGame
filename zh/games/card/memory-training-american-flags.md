# 记忆训练。美国国旗

<a href="https://inkwengame.com/zh/games/memory-training-american-flags" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/memory-training-american-flags/cover.jpg)

记忆训练。美国国旗包含3个不同的类别，每个类别有4个等级。游戏开始后，点击卡片以揭示某个美洲国家的国旗。记住它，以便与另一张相同的国旗配对。在时间耗尽前找到棋盘上每张国旗的配对，即可完成当前关卡。
