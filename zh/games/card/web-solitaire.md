# 网页纸牌

<a href="https://inkwengame.com/zh/games/web-solitaire" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/web-solitaire/cover.jpg)

一款有趣的纸牌游戏，包含所有可解的谜题。将每种类型的四堆牌按顺序整理好。在上层堆中，您可以按照交替颜色的规则排列卡片。

## 怎么玩

点击任意一张闭合的牌将其翻开。拖动并放下已翻开的牌，按照交替颜色规则排序
