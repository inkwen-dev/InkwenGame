# 数字方块接龙

<a href="https://inkwengame.com/zh/games/numblocks-solitaire" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/numblocks-solitaire/cover.jpg)

这是一款基于技巧的益智游戏，你需要匹配并收集数字方块。通过配对来收集所有数字方块。你可以将方块从一个堆移动到另一个堆来进行配对。关卡进度一定会增强游戏的乐趣和挑战性。完成全部60个关卡即可赢得本游戏。
