# 接龙：卡片分类

<a href="https://inkwengame.com/zh/games/solitaire-card-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/solitaire-card-sorting/cover.jpg)

一款融合经典接龙机制与主题分类逻辑的智力卡片谜题。在每一关中，你需要将卡片归类到不同的类别中：植物、珠宝、玩具、工具、花朵等。运用观察力和策略，在有限的步数内清理场地并完成关卡。

## 怎么玩

每轮开始时，桌面部分已填满。从牌堆中抽取一张牌，并将其放置在正确的类别中。要开始构建，需先放置一个类别牌，然后添加相关卡片。仔细排序——如果布局错误，你将耗尽步数
