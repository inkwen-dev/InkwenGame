# 多拉记忆卡片

<a href="https://inkwengame.com/zh/games/dora-memory-cards" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dora-memory-cards/cover.jpg)

多拉记忆卡片是一款专为儿童设计的益智游戏。游戏的目标是配对所有相同的卡片。因此，请点击任意一张卡片并记住它，当你点击第二张卡片时，如果与第一张相同，这两张卡片就会变为空白。将所有卡片都配对成功即可完成该关卡。

## 怎么玩

鼠标点击或轻触屏幕进行游戏
