Sprunki Memory 让您同时训练和测试您的视觉记忆。选择一种模式：单人模式，通过关卡并进行双人对战。这两种模式本质上是相同的，您必须快速找到一对相同的图片并将其从游戏区域移除。这是一款有趣的双人游戏版本，您将与一位真实对手竞争，看谁能够最快地将所有卡片从场地上移除。
