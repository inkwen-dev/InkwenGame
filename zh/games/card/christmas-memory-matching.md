# 圣诞记忆配对

![cover](https://img.inkwengame.com/games/christmas-memory-matching/cover.jpg)

这是一款记忆配对游戏，专为圣诞节设计。您有30个关卡需要通过记忆力完成。记住您第一次触摸的卡片，然后选择相同的卡片来完成。享受游戏吧！

## 怎么玩

点击或轻触卡片并选择相同的卡片
