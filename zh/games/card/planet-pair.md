# 行星配对

<a href="https://inkwengame.com/zh/games/planet-pair" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/planet-pair/cover.jpg)

行星配对是一款配对行星的记忆游戏。每一轮分为三个难度递增的阶段：第一阶段有3对，第二阶段有6对，最后一阶段有9对。每个阶段的配对及其位置都会随机化，确保每次游戏体验独特且具有很高的重玩价值。计时器会挑战你更快地完成每一轮。
