# 动物卡片配对

<a href="https://inkwengame.com/zh/games/animals-cards-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animals-cards-match/cover.jpg)

这是一款教育类记忆游戏。在游戏中，你需要打开棋盘上的所有卡片。当你连续点击或触摸两张相同的卡片时，它们就会打开。如果卡片不匹配，它们会再次关闭。因此，一旦你打开一张卡片，就要记住它。在时间结束前完成一个关卡。

## 怎么玩

点击或触摸卡片以打开它。观察并记住卡片上的动物。你的目标是连续打开两张相同的卡片。打开所有卡片以完成一关。
