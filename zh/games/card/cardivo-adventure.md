# 卡迪沃冒险

<a href="https://inkwengame.com/zh/games/cardivo-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cardivo-adventure/cover.jpg)

《卡迪沃冒险》是一款轻松的卡牌分类益智游戏，每张卡牌都属于一个主题系列。在卡牌堆之间移动卡牌，发现隐藏的匹配项，并在步数用完之前整理出色彩缤纷的卡组。精心设计的关卡布局、赏心悦目的动画、实用的道具以及不断提升的挑战，让每一局游戏都充满新鲜感，如同一次小小的冒险。

## 怎么玩

目标：在步数用完之前，将所有卡片分类到与其主题匹配的牌堆中，完成关卡。

玩法：

- 在电脑上，使用鼠标左键选择并移动卡片。

- 在手机和平板电脑上，用一根手指点击或拖动卡片。

- 将卡片与正确的类别匹配，并清除棋盘上所有需要的卡片。

- 如果遇到难以处理的布局，可以使用道具。

- 完成关卡即可解锁下一个挑战。如果步数用完，可以重试关卡并重新规划顺序。
