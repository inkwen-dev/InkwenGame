# 快乐万圣节记忆

<a href="https://inkwengame.com/zh/games/happy-halloween-memory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-halloween-memory/cover.jpg)

年轻的女巫在万圣节前夜，举行特殊的魔法仪式，以保护她村庄里居民的家园。为此，她使用特殊的魔法卡片。在屏幕上，卡片正面朝下摆放。你可以一次翻转两张卡片，并仔细观察上面的图案。努力记住它们的位置。你需要找到两张相同的图片，并同时翻开它们。随后，这些卡片将从屏幕上消失，并为你赢得分数。
