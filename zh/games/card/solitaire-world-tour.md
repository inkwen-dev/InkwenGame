# 纸牌世界之旅

<a href="https://inkwengame.com/zh/games/solitaire-world-tour" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/solitaire-world-tour/cover.jpg)

这款游戏包含令人惊叹的100个关卡。连续翻开4张牌以激活组合，并从牌堆中获得额外1张牌。每张翻起的牌有30%的概率生成一枚硬币图标。如果立即翻开该牌，即可赢得硬币。此外，部分牌一开始是锁定状态，增加了挑战性，让游戏更加刺激和引人入胜。
