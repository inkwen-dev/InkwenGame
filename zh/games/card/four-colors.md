# 四色

<a href="https://inkwengame.com/zh/games/four-colors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/four-colors/cover.jpg)

四色是一款HTML5纸牌游戏。面对最多三名电脑控制的对手。通过颜色或数字匹配卡片，使用行动卡来改变游戏局势，并成为第一个甩掉所有卡片的人。最后但同样重要的是：当你只剩一张卡片时，别忘了按1键！

## 怎么玩

用鼠标或手指选择卡片
