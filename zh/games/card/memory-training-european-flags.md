# 记忆训练。欧洲旗帜

<a href="https://inkwengame.com/zh/games/memory-training-european-flags" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/memory-training-european-flags/cover.jpg)

记忆训练 欧洲旗帜 包含3个不同类别，每个类别有4个等级。游戏开始后，点击卡片以揭示一个欧洲国家的旗帜。记住它，以便与另一个相同的旗帜配对。在时间耗尽前找到棋盘上每面旗帜的配对，完成当前等级。
