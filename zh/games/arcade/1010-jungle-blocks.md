# 1010 热带方块

<a href="https://inkwengame.com/zh/games/1010-jungle-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/1010-jungle-blocks/cover.jpg)

1010 热带方块是一款非常有趣的方块益智游戏。在这款游戏中，你需要选择并放置一组方块到棋盘上。放置完成后，如果形成了一条由10个方块组成的水平或垂直线，这些方块就会从棋盘上消除。一次消除的方块越多，得分就越高。不要让棋盘被方块填满。你可以持续游戏，直到无法再放入现有的方块组合为止。

## 怎么玩

使用鼠标或触摸板来玩这款游戏
