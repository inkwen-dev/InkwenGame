# 数学向上

<a href="https://inkwengame.com/zh/games/math-up" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-up/cover.jpg)

Math Up 是一款专为儿童和幼儿设计的脑力游戏。你需要掌握数学知识才能玩这个游戏。在圆圈中会给出数学题目，你需要知道答案，并在圆圈中正确数字的位置用球通过。完成所有任务以获得更高的分数。圆圈会一直旋转。因此，你需要确保答案正确，并等待合适的时机，在正确的时间通过圆圈中的正确数字。

## 怎么玩

点击屏幕来控制球
