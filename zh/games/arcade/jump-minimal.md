# 跳跃极简

<a href="https://inkwengame.com/zh/games/jump-minimal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/jump-minimal/cover.jpg)

跳跃极简是一款适合所有玩家的益智街机游戏。游戏的目标是让在横梁上滚动的球跳过前方的方块。有时你需要从障碍物下方通过，有时则需要完成一次艰难的跳跃来越过它们。随着游戏进行，或者你玩得越久，游戏速度会越来越快。无论如何，这都是一款非常有趣的玩法。

## 怎么玩
