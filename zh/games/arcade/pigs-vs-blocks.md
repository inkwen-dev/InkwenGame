# 小猪对积木

<a href="https://inkwengame.com/zh/games/pigs-vs-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pigs-vs-blocks/cover.jpg)

小猪对积木是一款街机游戏，你需要借助一只小猪来击碎积木。每一关中的每个积木都有一个数字，表示小猪需要击打该积木多少次才能将其击碎。这款游戏共有30个有趣且富有挑战性的关卡。尽情享受游戏乐趣吧！！！
