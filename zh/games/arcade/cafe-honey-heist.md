# 咖啡馆蜂蜜劫案

<a href="https://inkwengame.com/zh/games/cafe-honey-heist" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cafe-honey-heist/cover.jpg)

穿梭于温暖而繁忙的咖啡馆中，从咖啡杯和桌上的点心上啜饮美味的花蜜，并将你的战利品运送到外面的蜂巢。但要保持警惕——巨大的咖啡馆老板始终在倾听！嗡嗡声太大就会惊动他，他会追捕你，把你从空中拍飞。降落在桌面以休息，降低噪音水平，并规划下一步行动。收集足够的花蜜，解锁强大的能力，并完成5次蜂巢存入即可获胜！

## 怎么玩

桌面键盘操作 W 或 上箭头 向上爬升 S 或 下箭头 向下下降 A 或 左箭头 向左转向 D 或 右箭头 向右转向 空格键 按住向前飞行 —— 松开则停留在原地 1 Q 或 Shift 激活
