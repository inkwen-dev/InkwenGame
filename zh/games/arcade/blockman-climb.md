# Blockman Climb

<a href="https://inkwengame.com/zh/games/blockman-climb" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockman-climb/cover.jpg)

在方块世界中，让方块人到达终点线的旗帜。尽你所能在这个方块世界中生存下来，并一起抵达终点，不要独自前往终点线！这是一款团队游戏，与你的朋友一起完成关卡。旋转锤子，攀爬墙壁，赢得游戏。克服所有挑战才能获胜，注意避开尖刺，永远不要从深渊中掉落，否则你会输掉游戏。

## 怎么玩

使用WASD键操作玩家1，使用方向键操作玩家2，该游戏可在移动设备上进行
