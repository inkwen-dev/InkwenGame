# 鱿鱼逃脱但块世界

<a href="https://inkwengame.com/zh/games/squid-escape-but-blockworld" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-escape-but-blockworld/cover.jpg)

你需要逃离鱿鱼比赛，但在逃跑过程中，你掉进了方块世界。从方块世界逃脱有点困难，但不要停下，继续奔跑。直到到达紫色传送门之前，永远不要停止奔跑。别忘了在路上收集你看到的钱币。小心身后追赶的大怪物；它们想要抓住你，如果被抓住，你就会失败。

## 怎么玩

使用WASD和方向键移动。为了生存，跑到关卡尽头的传送门，并注意障碍物
