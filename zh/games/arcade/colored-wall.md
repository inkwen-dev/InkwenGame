# 彩色墙壁

<a href="https://inkwengame.com/zh/games/colored-wall" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colored-wall/cover.jpg)

彩色墙壁是一款带有小球的益智游戏。你的任务是控制小球穿过彩色墙壁。每次需要穿过墙壁时，小球的颜色都会改变。你可以通过与小球颜色相同的墙壁部分。因此你需要快速反应，并将墙壁移动到与小球颜色相同的位置。

## 怎么玩

点击屏幕开始游戏
