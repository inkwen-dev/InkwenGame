# 箭矢小子

<a href="https://inkwengame.com/zh/games/arrow-kid" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrow-kid/cover.jpg)

箭矢小子是一款复古风格的像素游戏，使用触摸按钮或Ctrl键来射箭，空格键跳跃，射出箭矢并跳到箭矢上以跳得更高，获取钥匙打开门以进入下一关卡。

## 怎么玩

PC端：Ctrl键射击箭矢，空格键跳跃，方向键移动；移动端：使用屏幕上的控制按钮
