# 超速跃迁3D

<a href="https://inkwengame.com/zh/games/hyper-jump-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hyper-jump-3d/cover.jpg)

超速跃迁3D是一款3D街机游戏，玩家需要在旋转的螺旋平台间撞击、碰撞和弹跳，以到达终点。听起来很简单？你太天真了！！你的球像砖块一样撞碎色彩斑斓的平台，阻挡它的下落，但如果你撞上黑色平台，一切就结束了！你的球会四分五裂，必须重新开始下落。
