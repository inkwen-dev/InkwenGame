# 弓箭颜色圆圈

<a href="https://inkwengame.com/zh/games/bow-color-circle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bow-color-circle/cover.jpg)

你的任务是快速点击鼠标，将箭射向与当前箭头相同颜色的目标。如果你选择的颜色一致，就会获得一分，随后你需瞄准相同或更多的颜色。圆圈会越来越快地移动，颜色也会逐渐缩小。

## 怎么玩
