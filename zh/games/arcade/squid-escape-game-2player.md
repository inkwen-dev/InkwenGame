# 鱿鱼逃脱游戏 2人版

<a href="https://inkwengame.com/zh/games/squid-escape-game-2player" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-escape-game-2player/cover.jpg)

你必须从这个铁皮覆盖的迷宫监狱中逃脱。两位蓝色玩家都需要逃离监狱。你必须收集所有的几何形状。收集所有形状并找到两把钥匙。找到钥匙后，迅速跑向门口。务必小心，地面上有带刺的障碍物。不要离你的朋友太远；如果彼此走散，你将输掉游戏。

## 怎么玩

使用 WASD 键和方向键移动。两位玩家都必须安全抵达门口并完成关卡。你必须收集关卡中的所有形状
