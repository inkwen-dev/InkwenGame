# 胡萝卜攀爬者

<a href="https://inkwengame.com/zh/games/carrot-climber" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/carrot-climber/cover.jpg)

胡萝卜攀爬者是一款可爱又有趣的游戏，一只饥饿的兔子需要在墙上攀爬以收集胡萝卜！每一关墙上都放置了钩子，你需要帮助兔子从一个钩子跳到另一个钩子。瞄准要准确——如果失误，兔子就会掉落！沿途收集胡萝卜和硬币，解锁下一关。这是一款适合所有年龄段的挑战与乐趣相结合的精彩游戏。

## 怎么玩

桌面 鼠标 点击并拖动以瞄准 释放以跳跃 移动端 触摸 拖动以瞄准 用手指释放以跳跃
