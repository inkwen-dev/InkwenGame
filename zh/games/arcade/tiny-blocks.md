# 小方块

<a href="https://inkwengame.com/zh/games/tiny-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tiny-blocks/cover.jpg)

通过触摸或点击来收集相同颜色的方块。更大的组合将为你带来令人兴奋的道具，这些道具能提升游戏进度并为游戏增添乐趣。如果你弄塌了一个方块，将扣除200分作为惩罚。
