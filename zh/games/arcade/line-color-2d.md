# 线条颜色 2D

<a href="https://inkwengame.com/zh/games/line-color-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/line-color-2d/cover.jpg)

《线条颜色 2D》是一款令人上瘾的益智游戏，你需要按住屏幕来滑动彩色线条在平面电路中移动。规划好每一步动作，避开移动的障碍物，并在二维空间中完整涂绘路径，最终抵达终点。这是一款既放松又充满挑战的趣味游戏。
