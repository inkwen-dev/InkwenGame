# 超级彩线

<a href="https://inkwengame.com/zh/games/super-color-line" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/super-color-line/cover.jpg)

这款超级彩线游戏将为你带来每日的色彩享受，美丽的宝石正等待着被撞击在一起，获得巨额分数！这款令人兴奋的益智游戏要求你同时关注游戏中宝石的颜色和数量。只有当五颗宝石连成一线时，才能享受到分数爆炸的快感。但可不是任意五个，而是必须是相同颜色的五个。你能否在为时已晚之前，将这些闪耀的宝石滑动到一起？

## 怎么玩

方向键 单击鼠标
