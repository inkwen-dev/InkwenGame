# 正确射击游戏

<a href="https://inkwengame.com/zh/games/right-shot-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/right-shot-game/cover.jpg)

《正确射击》是一款非常有趣的休闲游戏，将考验你的技巧和逻辑思维。通过「拖拽投放」系统，你可以拉伸弹力带，让球弹跳并击倒目标。尽量用最少的球完成每一关，以获得更高的分数。你可以引爆装有TNT炸药的箱子，一次性击倒多个目标，节省球的数量。游戏设计精美且色彩丰富。

## 怎么玩

桌面鼠标 拖拽投放 移动端 触屏按钮
