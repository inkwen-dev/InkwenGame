# 抓住那只猫

<a href="https://inkwengame.com/zh/games/catch-that-cat" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/catch-that-cat/cover.jpg)

这是一款基于技巧的益智游戏。你将看到一个充满不同猫咪的棋盘。你需要在棋盘上找到与左侧面板中显示的完全相同的猫咪。在每个区块中找出对应的猫咪以完成游戏。

## 怎么玩
