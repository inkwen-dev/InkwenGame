# 自走棋

<a href="https://inkwengame.com/zh/games/auto-chess" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/auto-chess/cover.jpg)

每回合玩家获得5金币，可以花费3金币放置冠军，花费2金币刷新商店，花费4金币升级。收集同类型的足够数量的冠军以获得加成。赢得回合，存活下来。
