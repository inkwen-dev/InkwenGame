# 单词搜索 昆虫

<a href="https://inkwengame.com/zh/games/word-search-insects" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/word-search-insects/cover.jpg)

在方块的直线中找到单词（水平、垂直或对角线，任何方向），点击显示单词首字母的方块，然后移动到单词末尾的字母。找出左侧面板中显示的所有单词以完成一个关卡。完成所有关卡即可赢得游戏。
