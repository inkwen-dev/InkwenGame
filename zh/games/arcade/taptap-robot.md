# Taptap Robot

<a href="https://inkwengame.com/zh/games/taptap-robot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/taptap-robot/cover.jpg)

Taptap Robot 是一款关于机器人收集钻石的街机游戏。充分发挥你的反应能力，点击屏幕来控制方向。收集所有钻石并完成关卡。

## 怎么玩

开始游戏后等待一秒让机器人行走，然后点击屏幕改变玩家移动方向
