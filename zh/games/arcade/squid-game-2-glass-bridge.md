# 鱿鱼游戏2 玻璃桥

这是一款全新的鱿鱼游戏主题游戏。你必须在充满挑战的玻璃桥上找到正确的玻璃，顺利通过。你需要按照玩家456显示的绿色路径来选择正确的玻璃块。此外，如果你在规定时间内无法到达对岸，游戏就结束了。你可以通过玩50个不同关卡来提升记忆力。集中注意力，现在就开始游戏，确保不打破玻璃，成功抵达对岸！
