# 抓住猫咪

<a href="https://inkwengame.com/zh/games/catch-the-cats" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/catch-the-cats/cover.jpg)

《抓住猫咪》是一款游戏，你需要击打从洞里探出头来的猫咪。但只有当猫咪从洞里冒出来时才能击打它们。如果你错过了击打某只猫咪，你就会失去一条生命。猫咪会从不同的位置出现，有时还会同时从多个洞里冒出来。动作要快，在生命耗尽前尽可能多地击中猫咪。

## 怎么玩

点击游戏屏幕即可开始游戏
