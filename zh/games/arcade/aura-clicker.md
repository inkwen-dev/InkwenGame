# 灵气点击器

<a href="https://inkwengame.com/zh/games/aura-clicker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/aura-clicker/cover.jpg)

你能刷到多少灵气？在《灵气点击器》这款色彩缤纷的放置点击游戏中，从新手一路晋升为顶级高手。游戏充满炫酷的变身、可收集的宠物和令人满意的升级系统。

## 怎么玩

1. 选择你的初始英雄，然后点击或轻触英雄周围区域即可获得光环。

2. 使用光环升级点击威力、自动点击、光环倍率和暴击率。长按购买按钮可购买多个等级。自动点击会在游戏运行时持续生成光环。

3. 不断积累光环，即可晋升至新手、大佬、西格玛、光环领主、传奇和终极王者。等级提升基于当前游戏进程中获得的光环，因此购买升级不会降低你的等级。

4. 打开商店标签页，召唤带有光环的宠物。每次召唤都会获得一只你当前区域尚未拥有的宠物。所有已拥有的宠物都会提供永久加成；选择一只宠物陪伴你的英雄。

5. 点击出现的宝箱，领取每日奖励，完成成就即可获得额外奖励。

6. 在一次游戏中获得 3 亿光环即可解锁你的首次重生。重生会提升你的声望，并重置你的光环、等级和升级，但会保留你的宠物、已解锁的英雄和声望。后续重生需要更多光环；请查看重生按钮上的需求。声望会提供永久加成，并解锁地图上的新区域。前往这些区域可以收集更多宠物，并持续提升你的光环。

## 介绍

你能刷到多少灵气？在《灵气点击器》这款色彩缤纷的放置点击游戏中，从新手一路晋升为顶级高手。游戏充满炫酷的变身、可收集的宠物和令人满意的升级系统。

点击屏幕即可获得灵气，提升点击威力，解锁自动收益，并打出强力暴击。随着英雄外观和灵气的进化，你将晋升至六个等级。六位英雄任你选择，五个区域共 52 只宠物等你收集。你拥有的每只宠物都能提供永久加成，即使它不是你的活跃伙伴。

准备好重新开始了？重生即可获得声望和永久灵气加成。保留你的英雄和宠物，解锁新区域，并在下次游戏中更快地发展壮大。探索宝箱，领取每日奖励，并在通往灵气巅峰的旅程中追逐成就。

使用鼠标或触摸屏即可畅玩。游戏开启期间，灵气自动收益将持续发放。
