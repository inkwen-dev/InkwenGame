# 蛇色突破

<a href="https://inkwengame.com/zh/games/snake-color-break" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-color-break/cover.jpg)

蛇色突破是一款蛇类益智游戏。滚动中会有五个目标。你需要控制蛇，通过与蛇圈颜色相同的靶标。目标之间会有不同颜色的边界。当你穿过边界时，蛇的颜色会改变，你需要前往与当前颜色相同的靶标。如果你未能匹配目标与蛇的颜色，游戏将结束。这是一款有趣且令人上瘾的儿童游戏。尽可能长时间地玩下去吧。

## 怎么玩

使用鼠标控制蛇或在屏幕上滑动
