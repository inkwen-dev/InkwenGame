# 武士刀水果

<a href="https://inkwengame.com/zh/games/katana-fruits" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/katana-fruits/cover.jpg)

武士刀水果是一款动作游戏。在这款游戏中，目标是切掉屏幕上出现的所有水果，同时不要让水果掉落，并避开炸弹。获得最高分数，不要碰到炸弹。每切一个水果可得30分。玩得开心！
