# 拯救飞行员

<a href="https://inkwengame.com/zh/games/save-the-pilot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-pilot/cover.jpg)

这是一款动作游戏，你必须击落敌方飞机并消灭它们以获得分数。你可以通过收集页面上的物品来获得分数。你还必须避开火箭，否则你会失败。游戏速度逐渐加快，让你感到困惑。飞机也会升级。这款游戏非常有趣。

## 怎么玩

使用鼠标操作游戏，或点击屏幕
