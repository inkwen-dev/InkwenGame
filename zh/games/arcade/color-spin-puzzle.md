# 色彩旋转谜题

<a href="https://inkwengame.com/zh/games/color-spin-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-spin-puzzle/cover.jpg)

COLOR SPIN 是一款超级街机游戏，规则简单：将球弹跳到圆圈中相同颜色的位置。只需向左或向右旋转右侧的轮盘，使圆圈底部的颜色与球的颜色匹配即可。上手容易，但要精通并获得高分却极具挑战性！游戏特色：- 无限玩法 - 操作简单 - 在排行榜上与朋友竞争，争夺最高分

## 怎么玩

仅用一根或两根手指操作，旋转颜色轮盘。尽可能多地让球弹跳
