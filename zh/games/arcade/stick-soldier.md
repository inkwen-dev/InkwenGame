# 棍子士兵

<a href="https://inkwengame.com/zh/games/stick-soldier" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stick-soldier/cover.jpg)

棍子士兵是一款街机游戏，用手指按住屏幕使棍子生长。拉长棍子以到达并走在平台上。如果棍子不够长，你就会掉下去！

## 怎么玩

点击或触摸屏幕开始游戏
