# 金属钻探者

<a href="https://inkwengame.com/zh/games/metal-driller" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/metal-driller/cover.jpg)

金属钻探者是一款休闲采矿冒险游戏，您将操控一个基于布娃娃物理引擎的钻头角色，深入矿井，解锁新关卡和升级内容。通过独特的技能树自定义您的游戏体验，每章结束后技能树将重置。随着进度推进，收集酷炫的钻头服装，并为您的角色及其钻头伙伴换上各种装扮。

## 怎么玩

使用 WASD 方向键和鼠标左键控制角色
