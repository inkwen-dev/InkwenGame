# 尺寸方块

<a href="https://inkwengame.com/zh/games/size-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/size-box/cover.jpg)

尺寸方块是一款带有方块的解谜游戏。游戏的目标是将方块放置在方块位置上。但方块需要放置的位置总是大小不同，而方块本身总是比位置小。你需要长按屏幕，方块会随之变大。当你认为方块已经足够大时，松开手指。方块必须与方块位置完全一致，如果方块太小或太大，游戏就会结束，你需要从头开始。

## 怎么玩

点击屏幕即可开始游戏
