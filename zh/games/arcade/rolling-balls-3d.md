# 滚动球 3D

<a href="https://inkwengame.com/zh/games/rolling-balls-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rolling-balls-3d/cover.jpg)

《滚球3D》是一款休闲游戏，考验你的反应速度和灵巧度。游戏的目标是引导小球穿过一个充满障碍物的无尽迷宫，沿途收集小球来获得更多！关键在于，每次收集到小球，都会生成一个克隆球并添加到迷宫中，随着游戏的进行，难度也会不断增加！

## 怎么玩

滑动手指或鼠标来左右移动小球，避开障碍物。

收集尽可能多的小球，到达终点线即可通关。
