# 寻找圣诞物品

<a href="https://inkwengame.com/zh/games/find-christmas-items" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-christmas-items/cover.jpg)

这是一款基于技巧的棋盘益智游戏。您将看到一个充满各种圣诞物品的棋盘。您需要在棋盘上找到与左侧面板中显示的完全相同的物品。点击每个方块中的物品以完成关卡。完成所有关卡即可赢得此游戏。

## 怎么玩

使用鼠标或触摸板来玩此游戏
