# 数字方块猎手

<a href="https://inkwengame.com/zh/games/numblocks-hunter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/numblocks-hunter/cover.jpg)

数字方块猎手是一款街机动作数学游戏。在本游戏中，你需要通过消除方块行来阻止方块接近基地。一次只能消除一行。要消除一行，你需要点击前线的一个方块，该方块显示的是基地方块上数学问题的答案。

## 怎么玩

使用鼠标或触摸板来玩此游戏
