# 圣诞方块

<a href="https://inkwengame.com/zh/games/christmas-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-blocks/cover.jpg)

一款以圣诞节为主题的类似俄罗斯方块的方块游戏。玩法类似于俄罗斯方块，但在此游戏中，你可以将当前方块与下一个方块互换，帮助你完全填满方块行。

## 怎么玩

键盘控制 - 左右箭头键左右移动，向下箭头键加快形状下落速度，空格键立即落下并锁定形状，上箭头键或X键顺时针旋转形状，Z键逆时针旋转形状
