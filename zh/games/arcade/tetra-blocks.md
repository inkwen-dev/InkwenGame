# 四连方块

<a href="https://inkwengame.com/zh/games/tetra-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tetra-blocks/cover.jpg)

将方块拖放到拼图板上，匹配9个水平行、9个垂直列或9个3x3的方块区域，以收集挑战模式中的所有目标星星方块！或者在高分模式中游玩，看看你能获得多少分！

## 怎么玩

直接将下落的方块向左或向右移动，以形成无瑕的行

## 介绍
