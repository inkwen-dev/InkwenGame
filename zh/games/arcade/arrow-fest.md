# 箭头节

<a href="https://inkwengame.com/zh/games/arrow-fest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrow-fest/cover.jpg)

箭头节实际上并不是一个弓箭发射模拟游戏，而是一款需要技巧躲避的3D箭矢和小人敌人组成的街机游戏。为了击败每一关的最终Boss，你需要收集正确的物品来增加当前箭矢的数量。只有当你的箭矢数量超过Boss的生命值时，才能完成该关！

## 怎么玩
