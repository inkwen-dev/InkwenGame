# 特里丝粉碎

<a href="https://inkwengame.com/zh/games/teris-crush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/teris-crush/cover.jpg)

特里丝粉碎是一款适合所有人的上瘾、放松且离线的益智游戏。将方块落下，创建垂直或水平方向上无间隙的方块线。当这样的线条形成时，它就会被消除。保持你的棋盘整洁，在这款简单但极具吸引力的益智游戏中保持冷静！

## 怎么玩

拖动木块移动它们。在垂直或水平线上填满方块以清除它们。方块不能旋转
