# Panellka：建造一座塔

起重机用钢索吊起楼层——在合适的时机松开，使其稳稳地落在塔身上。楼层不能进行修整：任何一次失误都会改变塔的重心，导致塔身倾斜摇晃。每一次建造都是一次全新的组合：选择能力卡牌，解锁混凝土、磁铁和配重等特殊部件，在塔倒塌之前将其建造到天际。

## 怎么玩

点击屏幕或按空格键或回车键即可将地板从起重机上释放。

地板会保持缆绳的动量，因此在地板悬于塔顶上方之前稍稍松开即可。如果地板悬空超过塔顶边缘的一半，它就会掉落，你会失去一条生命。如果塔倾斜角度过大，它会倒塌——将下一层地板向相反方向移动即可将其扶正。

地板可提供经验值：每升一级，即可从三张技能卡中选择一张。每次建造获得的金币都可以在工坊中用于永久升级。
