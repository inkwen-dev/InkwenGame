# 夏洛特过桥游戏

<a href="https://inkwengame.com/zh/games/charlotte-crossing-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/charlotte-crossing-game/cover.jpg)

夏洛特过桥是一款简单而令人上瘾的休闲游戏，精准和时机至关重要。你控制着一只可爱的小猫夏洛特，她会自动向前穿越平台。当她到达边缘时，会停止并等待你的操作。按住屏幕使一根棍子生长，松开以创建一座桥梁。目标是让桥梁的长度恰好合适，以便抵达下一个平台。

## 怎么玩

鼠标点击或轻触开始游戏
