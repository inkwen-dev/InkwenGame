## 怎么玩

使用上箭头进行跳跃，下箭头进行向下移动，左箭头进行向左移动，右箭头进行向右移动

## 介绍

宠物奔跑冒险是一款精彩的动物竞速游戏，拥有疯狂的宠物奔跑模拟器，适用于WebGL。在这个宠物奔跑游戏中，你将能够模拟商店里最可爱的宠物。宠物奔跑冒险旨在让你沉浸在一场激动人心的游戏体验中，与可爱的宠物伙伴一起享受这场萌宠狂奔。在这个无尽的宠物奔跑游戏中，你的任务是在宠物冲浪游戏的冒险跑动赛道上收集带有特殊骨头标志的金币。
