# 克隆球冲刺

<a href="https://inkwengame.com/zh/games/clone-ball-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/clone-ball-rush/cover.jpg)

克隆球冲刺是一款兼具技巧性躲避与收集球体的3D模型平台轨道街机游戏。绿色墙壁会扩大或增加你当前的球体数量。红色墙壁会缩小或减少你的球体数量。通过帮助至少一个球体抵达终点旗，完成关卡挑战。祝你好运，玩得开心！

## 怎么玩

滑动操作进行游戏
