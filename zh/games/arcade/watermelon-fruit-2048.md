# 西瓜水果2048

<a href="https://inkwengame.com/zh/games/watermelon-fruit-2048" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/watermelon-fruit-2048/cover.jpg)

这是一款非常简单但极具上瘾性的游戏，你需要触摸两个相同的物体使其爆炸并进入下一关。点击或拖拽水果到屏幕任意位置，将它们放在相同类型的水果上方以获得分数。相同类型的两个水果会合并并变成一个更大的水果，位于它们碰撞的位置，因此你可以引爆最大的水果——西瓜，获得1000分

## 怎么玩

使用鼠标来放置水果
