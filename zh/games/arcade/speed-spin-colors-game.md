# 极速旋转：颜色游戏

<a href="https://inkwengame.com/zh/games/speed-spin-colors-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/speed-spin-colors-game/cover.jpg)

你的目标是尽可能长时间地生存！你的彩色光点会在不同轨道之间跳跃。避开所有其他颜色形态，小心！你不能进入中心区域，也不能离你的轨道太远，否则就会失败。这是一款令人着迷的游戏，将考验你的反应力、注意力和速度。

## 怎么玩
