# 菜鸟 vs 黑客

<a href="https://inkwengame.com/zh/games/noob-vs-hacker" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noob-vs-hacker/cover.jpg)

可爱的笨拙菜鸟必须在黑客之前拿到钥匙并到达门口，才能在沙漠中生存。在被黑客的诡计绊倒之前，避开障碍物，躲避怪物，小心一点，你不会游泳，可能会溺水。
