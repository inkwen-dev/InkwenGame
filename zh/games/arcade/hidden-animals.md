# 隐藏动物

<a href="https://inkwengame.com/zh/games/hidden-animals" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hidden-animals/cover.jpg)

隐藏动物是一款基于技巧的解谜游戏，你需要在森林中找到所有隐藏的动物。你需要完成全部8个具有挑战性的关卡才能赢得这款游戏。
