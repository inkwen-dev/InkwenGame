# 再转一圈

点击屏幕以跳到下一个圆圈。在正确的时间点击，否则就会失败。如果点击太晚，你会到达中心圆圈并失败。如果点击次数过多，你会到达外部圆圈并失败。如果碰到红色圆点，你也会失败。你能连续完成多少圈而不失败？
