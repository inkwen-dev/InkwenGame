# VoxelBomb

<a href="https://inkwengame.com/zh/games/voxelbomb" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/voxelbomb/cover.jpg)

在体素建筑上粘贴炸药，引发壮观的连锁反应，将所有建筑夷为平地。使用更少的炸药即可获得星星，解锁并升级十种爆破工具，并在完成每个关卡后进入沙盒模式继续破坏。

## 怎么玩

桌面端：WASD 移动，鼠标视角，左键放置炸药或使用工具，E 引爆，右键回收炸药，数字键或鼠标滚轮切换工具，空格键跳跃，Shift 冲刺，C 切换视角，R 重建。移动端：拖动旋转，双指捏合缩放，点击墙壁放置炸药，点击“BOOM”引爆。切换到“WALK”模式使用摇杆移动。
