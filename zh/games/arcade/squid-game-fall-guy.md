# 鱿鱼游戏坠落者

<a href="https://inkwengame.com/zh/games/squid-game-fall-guy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-game-fall-guy/cover.jpg)

鱿鱼游戏坠落者是一款令人兴奋且充满动作的技巧游戏，适合想要寻找新方式逃离岛屿的玩家。选择你的角色，展示你的技能，逃离可怕的游乐岛。小心谨慎，避开障碍物，确保角色安全着陆。通过55个以上不同的关卡设计，享受乐趣并提升技能。尽情玩耍吧！

## 怎么玩

使用鼠标左键或触摸屏打开角色的栏杆，尝试以平衡的方式降落在地面上
