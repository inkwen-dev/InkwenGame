# Block It！

<a href="https://inkwengame.com/zh/games/block-it" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/block-it/cover.jpg)

Block It 是一款非常有趣的方块益智游戏。在这款游戏中，你需要选择一组方块并将其放置在棋盘上。放置完成后，如果形成一条由 10 个方块组成的水平或垂直线，这些方块将从棋盘上移除。一次消除的方块越多，得分就越高。不要让棋盘被方块填满。你可以一直玩下去，直到无法再放置现有的方块组合为止。

## 怎么玩

使用鼠标或触控板来游玩此游戏
