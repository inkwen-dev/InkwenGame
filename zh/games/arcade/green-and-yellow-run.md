# 绿色与黄色奔跑

<a href="https://inkwengame.com/zh/games/green-and-yellow-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/green-and-yellow-run/cover.jpg)

你准备好迎接这个充满绿色和黄色胖乎乎男人冒险的世界了吗？你必须帮助他们完成这次冒险，因为他们只能不停地奔跑。只有你能阻止他们奔跑并让他们跳跃。小心，怪物无处不在，它们会吃掉你。但别担心，你需要踩碎怪物才能杀死它。跳跃并踩碎。如果你没有拿到金币和箱子，门就不会打开，但请不要忘记这一点。

## 怎么玩

使用W和D键进行操作，用W键跳跃，用D键停止；也可以使用上箭头和右箭头键，用上箭头跳跃，用右箭头停止。收集金币和箱子，然后打开门
