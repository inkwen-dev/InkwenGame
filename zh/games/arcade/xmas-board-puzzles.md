# 圣诞拼图

<a href="https://inkwengame.com/zh/games/xmas-board-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/xmas-board-puzzles/cover.jpg)

这是一款限时游戏，玩家需要在两张外观相同的棋盘中找出一个不同之处。一旦找到差异，两个棋盘将刷新以生成新的差异。在规定时间内找出尽可能多的差异，以获得更高的分数。

## 怎么玩

使用鼠标或触控板来玩这款游戏
