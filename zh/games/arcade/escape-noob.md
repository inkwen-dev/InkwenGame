# 逃离菜鸟

<a href="https://inkwengame.com/zh/games/escape-noob" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/escape-noob/cover.jpg)

在这个冒险中，菜鸟正在逃离自己的克隆体。克隆体是一个非常邪恶的角色，想要杀死真正的菜鸟。他驯服了一只熊，并试图让熊杀死菜鸟。你必须避开克隆体和熊，沿途收集所有的金币。记得拿到钥匙。一旦拿到钥匙，就用它来降下终点线的铁栏。降低铁栏将阻止熊和邪恶的菜鸟攻击你，让你能够随心所欲地逃脱。不要回头——只管奔跑和逃逸。

## 怎么玩

使用WASD键移动，收集金币和钥匙，确保不要回头，收集所有硬币，在关卡末尾激活铁栏
