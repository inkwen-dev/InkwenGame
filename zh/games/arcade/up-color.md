# 向上颜色

<a href="https://inkwengame.com/zh/games/up-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/up-color/cover.jpg)

这是一款儿童街机游戏，你的任务是控制玩家通过不同颜色的砖块。有三种不同颜色的砖块。当你穿过一块砖时，玩家的颜色会改变，而在下一道有砖块的墙中，你需要只穿过与玩家颜色相同的砖块。这款游戏非常有趣且好玩。使用鼠标或在屏幕上滑动来控制玩家进行游戏。

## 怎么玩

在屏幕上滑动来玩游戏，或使用电脑上的鼠标
