# 绳索人

<a href="https://inkwengame.com/zh/games/ropeman" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ropeman/cover.jpg)

绳索人是一款街机风格的复古游戏，你将尝试攀爬从天空落下的绳索。游戏中有两种玩法模式：滑动和点击。你可以选择滑动来实现连续攀爬，也可以选择点击模式并拥有生命条。任选一种模式，邀请朋友一起挑战，乐趣就此开始！

## 怎么玩

向左移动 左箭头 向右移动 右箭头 重新开始 空格键
