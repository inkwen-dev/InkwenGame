# 怪物粉碎者

<a href="https://inkwengame.com/zh/games/monster-stomper" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/monster-stomper/cover.jpg)

潜入一款充满动作与节奏的街机平台游戏，由激烈的音乐驱动。考验你的反应能力，跳跃于漂浮的平台之间，并利用强力踩踏机制精准下落。掌握慢动作功能，计算好你的下落时机，以在混乱中生存下来。共有10个截然不同的关卡等待征服，一切取决于速度、时机和纯粹的动量。保持专注，用踩踏一路冲向巅峰。

## 怎么玩

你的目标是通过在平台间跳跃并运用踩踏能力精准落地，尽可能获得最高分数。没有终点线，你需要完成特定任务以解锁新关卡，并持续挑战更高分数。
