# 厕所冲刺跑

![cover](https://img.inkwengame.com/games/toilet-dash-run/cover.jpg)

《厕所冲刺跑》是一款轻松有趣的路径绘制益智游戏。你需要引导每个角色避开栅栏、障碍物和移动的敌人，绘制安全路线，最终到达对应的厕所。在冲刺开始前规划好每一条路线：路线规划完毕后，所有角色将同时行动。精心设计的关卡、可解锁的角色外观以及快速的鼠标或触控操作，让每一次逃脱都充满新鲜挑战。

## 怎么玩

目标：让每个角色安全到达与其对应的洗手间。

点击或触摸角色，然后拖动绘制通往正确洗手间的路线。在目的地松开鼠标，并规划剩余路线。避开墙壁、障碍物、敌人以及可能导致角色碰撞的路径。当所有角色都安全到达正确的洗手间时，游戏结束。

操作方式：

- 鼠标：按住鼠标左键并拖动。

- 触摸屏：用一根手指点击并拖动。

- 重新开始：点击圆形箭头按钮重新绘制关卡。

- 提示或跳过：点击视频按钮，观看奖励视频（如有）。
