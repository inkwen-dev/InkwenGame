# 惊人的建筑堆叠

<a href="https://inkwengame.com/zh/games/amazing-building-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/amazing-building-stack/cover.jpg)

你的任务是堆叠建筑。一台起重机将从一侧移动到另一侧，你必须确定释放建筑的时机，使其与其他建筑完美地组合成一座平衡的塔。显然，你积累得越多，堆得越高，得分就越高。
