# ArrowGami：箭矢拼图

<a href="https://inkwengame.com/zh/games/arrowgami-arrow-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/arrowgami-arrow-puzzle/cover.jpg)

ArrowGami 是一款益智游戏，你的目标是通过解开缠绕的彩色箭头来清除屏幕上的所有障碍物。点击箭头即可让它沿着指向的方向滑出屏幕，确保路径上没有障碍物。仔细规划你的移动顺序，避免碰撞，完成关卡。完成关卡后，屏幕上会显示一个完整的像素艺术剪影，例如热气球。你可以赚取金币来解锁不同的视觉主题，或者在遇到难题时使用提示。

## 怎么玩

左键单击/轻点：选择并射出一支箭。

只需轻点即可射出箭。

横屏和竖屏模式均适用。
