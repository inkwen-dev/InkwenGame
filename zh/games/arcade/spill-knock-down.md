# 倾倒和撞倒

<a href="https://inkwengame.com/zh/games/spill-knock-down" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spill-knock-down/cover.jpg)

在《Spill It!》这款游戏中，你需要投掷小球来击倒玻璃杯，让里面的东西洒出来。它结合了简单的操作机制和基于物理的谜题——为了达成目标，你必须精准地瞄准、投掷小球，并利用重力/动量让小球从玻璃杯中倾泻而出。

## 怎么玩

你可以从特定位置投放小球。

在很多情况下，你可以瞄准或选择投放点。

小球会与周围环境互动：玻璃器皿、支撑物、可能移动的平台或障碍物。

物理原理至关重要：时机、角度、力度、越障能力。

你的目标是让杯子里的液体全部倾倒。你可以利用小球来实现这个目标：投放、投掷或调整小球的位置，使它们撞击杯子（直接撞击、反弹或滚动撞击），从而使杯子里的液体溢出。
