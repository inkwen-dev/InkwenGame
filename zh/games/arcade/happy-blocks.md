# 快乐方块

<a href="https://inkwengame.com/zh/games/happy-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-blocks/cover.jpg)

要赢得这个游戏，你必须将所有黄色方块变为绿色。为此，将绿色方块拖动到黄色方块上。记住，你不能穿过红色方块。如果你指定紫色方块，它们会在黄色方块上变为绿色。
