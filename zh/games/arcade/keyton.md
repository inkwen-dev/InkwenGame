# Keyton

![cover](https://img.inkwengame.com/games/keyton/cover.jpg)

Keyton 是一款 2D 科幻主题的平台游戏，你的任务是寻找并收集钥匙卡以解锁大门，同时避开敌对机器人和尖刺。共有 8 个关卡可供挑战，难度会随着游戏进程逐渐增加。

## 怎么玩

使用 WASD 或方向键进行移动，连续按两次 W 键或上箭头键可实现双跳
