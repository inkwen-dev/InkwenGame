# 飞机涂色书

<a href="https://inkwengame.com/zh/games/airplanes-coloring-book" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/airplanes-coloring-book/cover.jpg)

飞机涂色书包含16种不同的飞机图片，孩子们可以选择并随意涂色。您有24种不同的颜色和9种铅笔粗细可供使用。完成绘画后，他们可以使用打印按钮保存涂色后的图像，并展示给朋友看！

## 怎么玩

使用鼠标或触摸屏幕
