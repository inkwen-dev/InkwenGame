# AnimalCraft 朋友

<a href="https://inkwengame.com/zh/games/animalcraft-friends" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animalcraft-friends/cover.jpg)

在这个冒险中，两只可爱的动物需要生存。帮助小猪和小羊到达谷仓。小猪和小羊必须逃离非常危险的森林。引导小猪和小羊逃离森林并躲进谷仓。小猪和小羊都很饿；你应该给它们胡萝卜和干草来填饱肚子。小心并留意农夫；如果他抓住它们，他会吃掉小猪和小羊。

## 怎么玩

使用 WASD 方向键进行操作 移动设备触摸控制可用 收集所有的干草和胡萝卜 到达谷仓
