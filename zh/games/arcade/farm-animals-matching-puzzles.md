# 农场动物配对拼图

<a href="https://inkwengame.com/zh/games/farm-animals-matching-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/farm-animals-matching-puzzles/cover.jpg)

将方块滑动到另一个相同的方块上以消除两者。尽量用最少的步数完成此操作。消除一个方块可获得100分，但如果一个方块被滑动超过一次，每次移动将扣除10分。消除所有方块即可完成关卡。本游戏共有24个具有挑战性的关卡。
