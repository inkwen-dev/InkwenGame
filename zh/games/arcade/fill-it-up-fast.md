# 快速填满

<a href="https://inkwengame.com/zh/games/fill-it-up-fast" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fill-it-up-fast/cover.jpg)

用合适的形状填满空白区域。按回车键发射当前形状。确保所选形状与旋转底座的空白部分方向一致。
