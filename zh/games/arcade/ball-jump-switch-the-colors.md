# 球跳跃切换颜色

<a href="https://inkwengame.com/zh/games/ball-jump-switch-the-colors" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ball-jump-switch-the-colors/cover.jpg)

点击屏幕，小球就会弹得越来越高。小球只有一种颜色，可以穿过同色障碍物，也可以从不同颜色障碍物之间穿过。

## 怎么玩

掌握色彩！在这款令人上瘾的色彩匹配挑战游戏中，弹跳穿梭于无尽的缤纷障碍之间。引导你的彩色小球向上弹跳，精准把握跳跃时机，穿过旋转障碍，收集星星，随时切换颜色！

在这款快节奏的街机游戏中，你需要点击屏幕让小球越弹越高，收集星星与障碍物颜色匹配，从而改变小球的颜色。安全地穿过颜色匹配的障碍物（或从不匹配颜色之间的缝隙穿过），同时避开致命的碰撞，尽可能地攀升到最高点，创造难以超越的高分！

电脑端操作：

点击鼠标或空格键 → 让小球弹得更高。

移动端操作：

点击屏幕 → 让小球弹得更高。
