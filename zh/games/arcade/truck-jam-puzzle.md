# 卡车拼图

<a href="https://inkwengame.com/zh/games/truck-jam-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/truck-jam-puzzle/cover.jpg)

在这款 3D 分类益智游戏中，解开五彩缤纷的卡车交通堵塞！按正确顺序派出卡车，将它们与相同颜色的货物匹配，并保持有限的装载空间畅通。随着关卡难度增加，你会发现被锁定、冻结、隐藏和过热的卡车。使用各种道具，争取在每个关卡都获得三星评价。

## 怎么玩

用鼠标左键点击或轻触一辆路线畅通的卡车，然后点击或轻触一个空置的装货位即可停车。卡车颜色需与待装货物颜色相匹配。满载的卡车会离开，腾出空间供你下一步操作。在倒计时结束前清空卡车，并避免让无法装货的卡车占据所有装货位。需要帮助时，可以使用屏幕上的加速按钮。快速完成关卡即可获得更多星星并解锁下一个谜题。所有菜单均使用鼠标点击或触摸操作，无需键盘按键。
