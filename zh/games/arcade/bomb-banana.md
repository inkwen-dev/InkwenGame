# 炸弹香蕉

<a href="https://inkwengame.com/zh/games/bomb-banana" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/bomb-banana/cover.jpg)

《炸弹香蕉》是一款3D解谜冒险游戏，主角是三只猴子：一只聋子、一只瞎子和一只哑巴！在它们各自独特的能力之间切换，搜索房子，解开谜题，并在时间耗尽之前拆除炸弹。

## 怎么玩

使用盲猴寻找炸弹，使用聋猴阅读说明书，使用哑猴处理炸弹。在三只猴子之间切换，按照说明操作，解开所有炸弹谜题即可获胜。

桌面版操作：

- WASD / 方向键：移动。

- 鼠标：点击游戏后环顾四周。

- 鼠标左键 / E：互动；必要时按住。

- 1 / 2 / 3：切换至盲猴/聋猴/哑猴。

- M：打开或关闭说明书。

- A / D 或左右方向键：翻阅说明书。

- Z：缩放。

- P：暂停；点击“继续”按钮继续游戏。

移动版操作：

- 摇杆：拖动移动和转向。

- 猴子头像：点击切换角色。

- 使用：点击或按住进行互动，或直接点击炸弹的控制按钮。

- 说明书：打开说明书；点击方向键翻页。

- 缩放：放大查看。 - 暂停：暂停游戏。
