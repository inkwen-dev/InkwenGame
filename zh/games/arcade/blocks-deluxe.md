# 方块豪华版

<a href="https://inkwengame.com/zh/games/blocks-deluxe" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocks-deluxe/cover.jpg)

将方块堆叠放入棋盘，以形成完整的水平或垂直行。单次放置形成的行数越多，得分越高。本游戏没有道具，没有时间限制，但有空间限制。你将拥有一个100个方块的棋盘，必须为即将出现的方块留出空间。
