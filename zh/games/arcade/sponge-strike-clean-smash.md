# 海绵冲击：清洁与粉碎

<a href="https://inkwengame.com/zh/games/sponge-strike-clean-smash" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sponge-strike-clean-smash/cover.jpg)

《海绵冲击：清洁与粉碎》是一款趣味十足的物理益智游戏，每次发射都能让隐藏的图案跃然纸上。拉动、瞄准，让你的海绵在棋盘上滑动，清除下方的黑色涂层。你可以利用墙壁反弹，粉碎色彩缤纷的方块塔，旋转移动障碍物，触发炸弹和按钮，并沿途收集金币。完成所有目标，揭开完整的图案，并用奖励解锁全新的海绵皮肤。

## 怎么玩

操作方式

鼠标：按住鼠标左键并向后拖动以瞄准并设置发射力度。松开鼠标左键即可发射海绵。当海绵减速时再次点击即可停止海绵并准备下一次发射。

手机：触摸并向后拖动以瞄准，然后松开鼠标左键即可发射海绵。当海绵减速时再次点击即可停止海绵并重新瞄准。
