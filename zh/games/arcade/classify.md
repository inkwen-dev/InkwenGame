# 分类

<a href="https://inkwengame.com/zh/games/classify" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/classify/cover.jpg)

按照指示对糖果进行分类。在游戏中，糖果会进入分类器，分类器两侧会出现糖果类别，糖果将通过分类器开关根据类别进行分类。来试试看你能得到多少分吧。
