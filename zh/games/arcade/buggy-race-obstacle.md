# 故障赛车障碍

<a href="https://inkwengame.com/zh/games/buggy-race-obstacle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/buggy-race-obstacle/cover.jpg)

这是一款简单的赛车游戏，你控制一辆越野车在沙滩赛道上行驶，尽可能地前进。但你必须避开赛道上的其他越野车和障碍物，一旦撞上，就会失去一颗心。如果失去全部4颗心，游戏就结束了！你的得分取决于你前进的距离，所以尽你最大努力，尽可能长时间地保持在赛道上！
