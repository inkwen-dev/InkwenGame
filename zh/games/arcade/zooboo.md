# Zooboo

<a href="https://inkwengame.com/zh/games/zooboo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/zooboo/cover.jpg)

Zooboo 是一款 2D 冒险游戏，你将扮演 Zooboo，任务是收集所有橙色水果，同时避开有毒水果（紫色）、敌人和尖刺。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键移动。按两次 W 键或上箭头键可进行二段跳
