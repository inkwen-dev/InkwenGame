# 兔子武士

<a href="https://inkwengame.com/zh/games/rabbit-samurai" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/rabbit-samurai/cover.jpg)

兔子武士是由Mini Duck Games开发的一款技巧游戏。挥舞、收集胡萝卜并拯救你的朋友们！你的目标是找到并从绿野中狼的巢穴里的捕鼠器中救出小老鼠。踏上一段史诗般的冒险，借助你的钩爪和敏捷的动作展示你的忍者技能。从忍者火箭炮发射出去，收集胡萝卜和水晶，避开危险的尖刺，拯救你所有的老鼠朋友！

## 怎么玩
