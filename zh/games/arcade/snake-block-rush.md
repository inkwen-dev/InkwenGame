# Snake Block Rush

<a href="https://inkwengame.com/zh/games/snake-block-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snake-block-rush/cover.jpg)

Snake Block Rush 是一款快速的超休闲街机游戏！引导你的霓虹珠蛇，收集白色奖励球以增长身体，并击碎数字方块。获得星星以解锁 9 种独特的蛇皮肤，并使用复活道具来创造高分！

## 怎么玩

桌面端 使用鼠标左右拖动来控制蛇 移动端 使用触摸和左右滑动来控制蛇
