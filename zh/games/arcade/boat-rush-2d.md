# 船速2D

<a href="https://inkwengame.com/zh/games/boat-rush-2d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/boat-rush-2d/cover.jpg)

你准备好驾驶你的船，投身于冒险了吗？小心一点，虽然船坚固且速度快，但也有脆弱的时候，随时可能沉没。为了避免沉船，你必须始终避免撞击障碍物，直到终点线。障碍物可能会炸毁你并让船沉没。用船收集黄金，购买更漂亮的船，争取拥有最昂贵的那一艘。

## 怎么玩

你可以通过点击或轻触鼠标来左右移动。也可以使用方向键通过键盘左右移动
