# 极限平衡3D

<a href="https://inkwengame.com/zh/games/extreme-balancer-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/extreme-balancer-3d/cover.jpg)

极限平衡3D是由CoolMathGamesKids.com团队开发的一款新的球类冒险游戏。引导小球穿越各种陷阱，到达最终平台。环境被水和冰包围，整个平台就位于它们上方。你必须将小球移动到由不同狭窄路径组成的木制桥上。当小球从桥上掉落时，关卡将失败。

## 怎么玩

- 方向键或ASWD控制小球移动 - 鼠标改变视角
