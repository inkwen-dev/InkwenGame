# Roll Classic

<a href="https://inkwengame.com/zh/games/roll-classic" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roll-classic/cover.jpg)

Roll Classic 是一款经典骰子游戏，融合了策略与运气。玩家轮流掷骰子收集分数，目标是在对手之前达到指定分数。每次掷骰时，玩家必须决定是冒险争取更多分数，还是保守以确保领先优势。游戏中充满惊险转折，意外情况可能彻底改变局势。规则简单易学，却令人欲罢不能，非常适合家人和朋友一起游玩。
