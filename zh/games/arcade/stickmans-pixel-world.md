# Stickmans 像素世界

<a href="https://inkwengame.com/zh/games/stickmans-pixel-world" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickmans-pixel-world/cover.jpg)

我们之前见过 Stickmans 的表现，这次他们需要在像素世界中帮助自己生存。他必须通过像素世界的全部关卡并到达终点线。否则，最终将面临非常糟糕的结果。与你的朋友一起抵达终点线并完成所有关卡。小心，各个区域充满惊喜，要做好应对意外的准备。

## 怎么玩

使用 WASD 方向键移动 双跳功能可用 移动触摸控制 与你的朋友同时抵达传送门
