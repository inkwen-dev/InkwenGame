# Blumgi城堡游戏

<a href="https://inkwengame.com/zh/games/blumgi-castle-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blumgi-castle-game/cover.jpg)

Blumgi城堡是一款技巧类游戏，你可以在游戏中装备各种爆炸物和特殊武器，将敌人击入水中。炸飞你的敌人，或者摧毁他们站立的地面！使用角色周围的指示器进行瞄准，按住行动按钮来设定强度，然后释放以向怪物倾泻炸弹。如果关卡中的每个生物都被击败，你就成功通关了。每几关就会解锁一个全新的酷炫角色，所以一定要尝试每一个角色！

## 怎么玩

瞄准 - A D 或 左右箭头 发射 - 按住并释放 空格键
