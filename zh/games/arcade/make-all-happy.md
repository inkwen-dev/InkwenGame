# 让所有都快乐

<a href="https://inkwengame.com/zh/games/make-all-happy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/make-all-happy/cover.jpg)

让所有都快乐是一款美丽的益智游戏，你需要让所有的方块都变得快乐。点击一个方块以切换其状态以及其水平和垂直相邻的方块。通过切换方块，使所有方块都处于快乐状态。

## 怎么玩

使用鼠标或触摸板来玩这个游戏
