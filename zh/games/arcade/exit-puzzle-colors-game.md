# 退出谜题：颜色游戏

<a href="https://inkwengame.com/zh/games/exit-puzzle-colors-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/exit-puzzle-colors-game/cover.jpg)

一款简单而上瘾的动作解谜游戏。你需要引导一个或多个绿色光点在棋盘上移动，进入一个或多个目标区域，同时避开其他几何形状。光点和形状都会按照可预测的路径移动：碰到墙壁时总是向右转，沿着拐角行进，或在死胡同时掉头。

## 怎么玩

光点在碰到箭头时会沿箭头方向前进，碰到墙壁时会向右转。你需要放置箭头，使所有光点都能到达出口
