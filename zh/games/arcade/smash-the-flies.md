# 打飞虫

<a href="https://inkwengame.com/zh/games/smash-the-flies" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/smash-the-flies/cover.jpg)

这是一款酷炫、简单又好玩的无尽游戏。用手指轻触或点击屏幕上的苍蝇，将其拍碎，以免它们飞出屏幕。但千万不要点击红色的苍蝇，否则游戏结束！动作要快，迅速拍碎所有苍蝇，争取高分。
