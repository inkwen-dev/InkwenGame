# 使全部相等

<a href="https://inkwengame.com/zh/games/make-all-equal" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/make-all-equal/cover.jpg)

每一关都有带有数字的盒子。顶部列出了目标数字。将数字从一个盒子移动到另一个盒子，使得每个盒子中数字的总和等于该关卡的目标数字。通过点击一个盒子中的一个数字，然后点击另一个盒子中的另一个数字来交换数字。

## 怎么玩

使用鼠标或触控板来玩这个游戏
