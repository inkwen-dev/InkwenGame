# PullyWog

<a href="https://inkwengame.com/zh/games/pullywog" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pullywog/cover.jpg)

用你的舌头抓住苍蝇，把自己甩向空中。在不接触地面的情况下吃掉多个东西可以得到连击分数，所以尽量在空中停留得越久越好！计时器会持续倒数；你可以吃任何东西来稍微延长计时，但要注意幽灵一旦触碰就会致命！你可以在炸弹碰到水面之前吃掉它们，从而阻止它们爆炸。

## 怎么玩

控制 键盘方向键 WASD 移动并瞄准你的舌头左右或上下 按住 Z 空格 使用你的舌头，按得越久，舌头伸得越远 X Shift 激活你的泡泡（如果你有的话） ESC 暂停 Alt Enter 全屏切换
