# Blockivo

<a href="https://inkwengame.com/zh/games/blockivo" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockivo/cover.jpg)

Blockivo 是一款简单的方块益智游戏。在 8×8 的棋盘上放置彩色方块，填满行和列，尽可能获得高分。仔细规划你的每一步，遇到困难时使用道具，努力登上全球排行榜的顶端。

## 怎么玩

将一个可用形状拖到棋盘上的空白处。整行或整列消失，并获得分数。放置完三个形状后，会出现新的一组形状。

如果棋盘过于拥挤，可以使用“换行”功能移除选定的两行或两列。“撤销”功能可以让你撤销上一步操作。当所有可用形状都无法放置时，游戏结束。努力打破你的最高分，在排行榜上攀升。
