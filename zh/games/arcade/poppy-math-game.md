# 罂粟花数学游戏

<a href="https://inkwengame.com/zh/games/poppy-math-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/poppy-math-game/cover.jpg)

你擅长数学吗？那么就来试试回答所有关于隐藏有罂粟花图片的方块的问题吧！游戏玩法：将左侧的数字方块拖动到右侧对应的方块上，覆盖住图片。尽情享受乐趣，并尝试解锁所有图片！
