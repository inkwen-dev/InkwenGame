# 找到乐趣！

<a href="https://inkwengame.com/zh/games/find-the-fun" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-the-fun/cover.jpg)

《找到乐趣！》是一款寻找物品的游戏。游戏中有三个关卡，孩子们需要在给定的图片中找出指定的物品。如果成功，该物品上会出现一颗星星。在某些情况下，你可能需要点击多个位置才能成功。祝你玩得开心 :)

## 怎么玩

找到物品并点击它
