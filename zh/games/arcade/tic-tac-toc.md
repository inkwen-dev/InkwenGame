# 井字棋

![cover](https://img.inkwengame.com/games/tic-tac-toc/cover.jpg)

井字棋是一款多人游戏，玩家可以用 X 或 O 字母组成三格连线。在这个有趣的迷你游戏中，您可以与朋友一起玩，或与电脑对战。您可以在游戏顶部查看得分。您必须将三个相同的图案连成一行。
