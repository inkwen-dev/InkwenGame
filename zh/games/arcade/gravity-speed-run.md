# 重力速度跑

<a href="https://inkwengame.com/zh/games/gravity-speed-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gravity-speed-run/cover.jpg)

《重力竞速》是一款快节奏的平台游戏，你将操控一个迷你角色，通过切换重力来穿越充满障碍的关卡。点击屏幕即可在赛道顶部或底部奔跑，躲避致命的尖刺和陷阱——一旦被击中，游戏就会重新开始。每个关卡都会增加难度，障碍物更多，速度更快。完成关卡即可获得金币，解锁机器人角色的全新皮肤。考验你的反应速度，征服挑战吧！

## 怎么玩

点击鼠标或轻触屏幕即可上下移动
