# 狗地

<a href="https://inkwengame.com/zh/games/dogland" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dogland/cover.jpg)

在这个充满狗狗的世界里，通过触碰食盆来提升自己。你可以从狗之国获得一些新骨头，或者从睿智的紫色老巫师狗那里获得魔法镐。

## 怎么玩

点击屏幕以赚取金钱，点击按钮并旅行以获取升级，点击以获得改进
