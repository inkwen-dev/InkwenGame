# 最困难的游戏

<a href="https://inkwengame.com/zh/games/hardest-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hardest-game/cover.jpg)

玩这款几乎不可能通关的游戏，名为《最困难的游戏》。游戏开始时是简单的关卡，直到第5关，之后难度逐渐增加，需要完成剩下的13个关卡。游戏的目标是到达屏幕的另一侧，当你触碰到绿色区域时，该关卡即视为完成。

## 怎么玩

方向键。对于触摸屏设备，可以使用屏幕上出现的方向键
