# 像素蛇

![cover](https://img.inkwengame.com/games/pixel-snake/cover.jpg)

像素蛇是对经典蛇类游戏的现代演绎。引导你的发光像素蛇在网格上移动，吃掉红色苹果以变得更长，并在挑战逐渐增加的情况下考验你的反应速度。规则很简单：不要撞到墙壁或自己的尾巴，否则游戏结束！凭借其复古风格、霓虹视觉效果和令人上瘾的游戏玩法，像素蛇重现了最经典的街机体验之一的魅力。
