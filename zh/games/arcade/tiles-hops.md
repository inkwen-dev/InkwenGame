# 瓷砖跳跃

<a href="https://inkwengame.com/zh/games/tiles-hops" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tiles-hops/cover.jpg)

跟随节奏，运用你的音乐反应能力，引导小球从一个瓷砖跳到另一个瓷砖。触摸、按住并拖动小球，使其跳上瓷砖。不要失误，否则你将从头开始。
