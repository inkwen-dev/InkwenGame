# 洞穴工人史蒂夫

<a href="https://inkwengame.com/zh/games/cave-worker-steve" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cave-worker-steve/cover.jpg)

史蒂夫在洞穴中工作，以保护和发展他的村庄，通过破坏洞穴中的方块来赚取金钱。通过存下这些金钱，他可以将他的镐子升级到石制、铁制、金制、钻石和祖母绿级别。他可以从附魔台对镐子施加法术，使其达到最强状态。

## 怎么玩

点击屏幕以赚取金钱 使用标志前往村庄或附魔台 如果你买得起，就点击它
