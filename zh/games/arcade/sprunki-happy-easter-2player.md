# Sprunki 愉快复活节 2人游戏

<a href="https://inkwengame.com/zh/games/sprunki-happy-easter-2player" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sprunki-happy-easter-2player/cover.jpg)

Sprunki兄弟们在复活节期间互相竞争。收集最多复活节彩蛋的玩家将赢得比赛。向你的兄弟或朋友展示你才是更优秀的玩家。尽快收集彩蛋并将其带到箱子中。谁把最多的彩蛋送到箱子，谁就赢得比赛。

## 怎么玩

使用WASD和方向键移动。收集20个彩蛋的玩家获胜。从气球上取下彩蛋并带到箱子中。支持移动端触控操作
