# 窗户清洁工

<a href="https://inkwengame.com/zh/games/window-cleaners" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/window-cleaners/cover.jpg)

在这个游戏中，你是一名窗户清洁工。在高楼大厦中清洁窗户是一项危险的工作。但如果你有同事一起，这不仅危险，而且也很有趣。你们将竞争谁先到达目标。为此，你需要避开障碍物，可以收集旗帜，这些旗帜可以用作降落伞，让你快速下降。你也可以拿起水海绵，朝你的同事扔去。一款非常有趣的遊戲，你將努力成為第一。
