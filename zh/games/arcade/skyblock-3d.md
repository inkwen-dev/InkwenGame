# Skyblock 3D

<a href="https://inkwengame.com/zh/games/skyblock-3d" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/skyblock-3d/cover.jpg)

你准备好在高空中漂浮的小岛上生存了吗？从有限的资源开始你的冒险，收集方块，创建新的区域，并逐步扩展你的岛屿。明智地使用你的资源，发现不同的材料，并打造属于自己的世界。随着进度推进，解锁新的机会，改善你的岛屿，将其转变为巨大的空中家园。一场结合生存、探索和建造的激动人心的冒险正等待着你！

## 怎么玩

使用WASD移动，并用鼠标破坏方块。该游戏也支持在移动设备上玩，提供适合手机的控制方式
