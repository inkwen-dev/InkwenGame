# LimeKattana

<a href="https://inkwengame.com/zh/games/limekattana" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/limekattana/cover.jpg)

KattanaLime 是一款水果切割游戏，玩家使用虚拟武士刀将屏幕上出现的不同类型水果切开。游戏机制简单：玩家必须在屏幕上轻触并滑动手指，将水果切成更小的碎片，同时避免触碰出现在水果中间的炸弹或危险物品。在 KattanaLime 中，玩家必须提防与水果一同出现的炸弹。如果玩家触碰到炸弹，它会立即爆炸，游戏随即结束。

## 怎么玩

用手指滑动进行切割
