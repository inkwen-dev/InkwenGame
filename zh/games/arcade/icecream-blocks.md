# 冰淇淋方块

<a href="https://inkwengame.com/zh/games/icecream-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/icecream-blocks/cover.jpg)

通过点击水平或垂直方向上三个或更多相同颜色的方块来收集冰淇淋。每次消除都会增加你的分数，消除的方块越多，得分越高。投影框显示了本次消除将获得的分数。运用逻辑思维创建更大的组合，同时防止方块到达顶部。使用道具可以移除更多的方块。

## 怎么玩

使用鼠标或触摸板来玩游戏
