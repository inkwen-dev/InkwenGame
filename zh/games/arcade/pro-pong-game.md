# 专业乒乓球游戏

<a href="https://inkwengame.com/zh/games/pro-pong-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pro-pong-game/cover.jpg)

专业乒乓球游戏是一款节奏快速的复古街机经典，带有现代元素。控制你的球拍，反弹球体，并在激烈的1对1对决中击败对手。精准和反应是胜利的关键！

## 怎么玩

玩家1 使用 W S 键或拖动左侧球拍；玩家2 使用 上下箭头键或拖动右侧球拍；暂停使用 ESC 键；移动设备上触摸并拖动任意球拍
