# 小蝶飞行

<a href="https://inkwengame.com/zh/games/fluttershy-fly" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/fluttershy-fly/cover.jpg)

小蝶飞行是一款横向卷轴游戏，玩家控制小蝶。尽可能远地飞行，避免撞上障碍物和敌人。你有3点生命值。收集金币和生命值以维持游戏进程。按空格键或鼠标左键来飞行。按F12键可切换至全屏模式。

## 怎么玩

点击鼠标或使用空格键开始并让小蝶飞行
