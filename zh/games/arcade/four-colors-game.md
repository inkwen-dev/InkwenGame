# 四色游戏

<a href="https://inkwengame.com/zh/games/four-colors-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/four-colors-game/cover.jpg)

四色是一款益智游戏。游戏中间会有一个大的彩色方块。从游戏的各个方向，会有一些小方块向大方块移动。大方块和小方块的颜色需要匹配才能得分。如果颜色不同，游戏就会结束。因此，你需要点击屏幕来改变大方块的颜色。方块有四种不同的颜色。观察小方块，并调整大方块的颜色以匹配它们的颜色。

## 怎么玩

点击屏幕即可开始游戏
