# 星际打击 2.0

<a href="https://inkwengame.com/zh/games/cosmic-strike-2-0" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cosmic-strike-2-0/cover.jpg)

一款你可以探索太空并战斗飞船的游戏。来吧，进入太空，与极其强大的Boss作战。怎么了，你害怕了吗？游戏中有三个长关卡，每个关卡都有一个具有不同玩法的Boss。当你摧毁敌人和Boss时，你会获得金钱，可以购买新飞船。每艘飞船不同的伤害和射击风格让游戏体验各不相同。最后的Boss并非无敌，它有一个弱点。

## 怎么玩

W键加速，S键减速，左键射击，用鼠标移动。如果飞船撞毁，你就死了
