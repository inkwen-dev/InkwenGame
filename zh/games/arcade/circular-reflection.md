# 圆形反射

<a href="https://inkwengame.com/zh/games/circular-reflection" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/circular-reflection/cover.jpg)

在《圆形反射》这款游戏中，你需要用盾牌接住球。你必须迅速且准确地接住球。球会从盾牌上反弹并朝另一个方向前进。围绕圆圈旋转盾牌，不要让球离开圆圈。如果球离开了圆圈，游戏就结束了。

## 怎么玩

点击屏幕即可开始游戏
