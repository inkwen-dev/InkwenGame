# 动物盒

<a href="https://inkwengame.com/zh/games/animals-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/animals-box/cover.jpg)

你必须捕捉动物。不要碰到炸弹和火焰。有奖励系统。收集钻石星以购买皮肤。你将沉浸于奇妙的余弦氛围中。有5种不同类型的动物需要捕捉。游戏内设有商店，共有7种盒子皮肤可供选择：标准、紫罗兰色、黑色、羊驼、熊、熊猫、独角兽。每次游戏速度都会增加。享受挑战，保持专注！
