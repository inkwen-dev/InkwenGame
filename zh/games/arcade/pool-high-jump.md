# 泳池高跳

<a href="https://inkwengame.com/zh/games/pool-high-jump" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pool-high-jump/cover.jpg)

在这个游戏中，你的任务是控制跳水运动员，从跳台跳入泳池。如果你觉得这很容易，那可就大错特错了，因为泳池会开始左右移动，同时还会变得越来越小，而跳水者也会从更高的地方跳下。所以，尽量每次都跳进泳池，如果错过了泳池，跳水员就会被撞碎，你将失去一条生命。当你失去三条生命时，游戏就结束了。

## 怎么玩

当你认为时机合适时，点击游戏屏幕
