# 快乐糖果

<a href="https://inkwengame.com/zh/games/happy-candy" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/happy-candy/cover.jpg)

你见过吃糖果的怪物吗？这些怪物非常喜欢糖果。它们最喜欢的东西就是糖果。收集糖果并获得金币。小心，即使你是怪物，刺也会杀死你。移动的尖刺也会杀死你。收集金币，拥有大量快乐的怪物。它们都是非常快乐又甜蜜的怪物。

## 怎么玩

及时点击糖果以吃掉糖果，注意避开障碍物，收集金币，购买其他服装
