# 新手帮助绵羊

<a href="https://inkwengame.com/zh/games/noob-help-sheep" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noob-help-sheep/cover.jpg)

在一个充满冒险的游戏里，新手必须保护绵羊。你必须非常小心地保护绵羊。绵羊并不聪明，无法分辨朋友与敌人。作为新手，你必须帮助绵羊。拿起你的剑，攻击所有敌人。消灭敌人以清除绵羊的前进道路。帮助绵羊安全抵达谷仓。绵羊必须完好无损地到达谷仓。你需要为绵羊清理道路。它的路上不应有任何敌人或障碍物。

## 怎么玩

按 W、A、S、D 键移动 按空格键用剑攻击 可进行双跳 移动端触摸控制 击杀所有怪物并安全护送它们到谷仓
