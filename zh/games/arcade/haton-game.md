# Haton 游戏

<a href="https://inkwengame.com/zh/games/haton-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/haton-game/cover.jpg)

Haton 是一款 2D 平台游戏，你需要收集橙子，避开尖刺和戴着蓝色帽子的敌人，抵达红色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制玩家移动；连续按两次 W 键或上箭头键可进行二段跳
