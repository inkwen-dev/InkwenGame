# 纸杯塔建造者

<a href="https://inkwengame.com/zh/games/cups-tower-builder" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cups-tower-builder/cover.jpg)

纸杯塔建造者是一款益智游戏，你需要用纸杯搭建一座塔。纸杯会在屏幕上水平移动，当你点击屏幕时，纸杯就会掉落到地面上。将所有纸杯都这样掉落，并尝试让它们一个叠在另一个上面。当有纸杯从塔上掉落时，游戏就结束了。尽可能长时间地玩下去，建造最长的纸杯塔。

## 怎么玩

点击屏幕开始游戏
