# 万圣节连线

<a href="https://inkwengame.com/zh/games/halloween-link" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-link/cover.jpg)

万圣节连线是一款经典的方块消除游戏。在游戏中，你可以一次消除两个相同的方块。规则是，这两个方块必须通过最多两段转折的直线相连。要完成一个关卡，你需要消除棋盘上的所有方块。完成全部21个关卡即可赢得本游戏。

## 怎么玩

使用鼠标或触摸板寻找可以通过最多两段转折的直线连接的相同方块，然后持续点击或轻触这两个物品
