# 颜色旋转

<a href="https://inkwengame.com/zh/games/color-spin" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/color-spin/cover.jpg)

COLOR SPIN 是一款超级街机游戏，规则简单：将球弹跳到圆圈中相同颜色的位置。你只需用一只手或两只手在右侧或左侧旋转轮盘，使圆圈底部的颜色与球的颜色匹配。

## 怎么玩

仅使用一只手或两只手来操作，旋转颜色轮盘。让旋转方向向左或向右。尽可能多地弹跳球
