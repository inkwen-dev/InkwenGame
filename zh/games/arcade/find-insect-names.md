# 找出昆虫名称

<a href="https://inkwengame.com/zh/games/find-insect-names" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-insect-names/cover.jpg)

这是一款教育类单词拼图游戏，你需要根据右侧面板中给出的昆虫图像，找出该昆虫的正确拼写。只需点击所需的字母按钮来完成拼写。如果点击了错误的字母，将会损失一条生命（总共五条生命）

## 怎么玩

轻触字母按钮进行选择
