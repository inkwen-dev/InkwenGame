# 小虫子

<a href="https://inkwengame.com/zh/games/little-bugs" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/little-bugs/cover.jpg)

甲虫们靠近两张图片，然后需要选择走哪条路。一张图片是安全的，你可以穿过它；另一张是通向深渊的陷阱门，如果你误解了以蔬菜或动物形式呈现的提示，就无法到达终点。
