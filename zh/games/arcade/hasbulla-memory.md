## 介绍

Hasbulla Memory 是一款超级有趣的儿童在线记忆游戏。通过这款记忆游戏来测试你的记忆力。在游戏棋盘上，总是有两张相同的图片。开始游戏后，翻转一张卡片，然后尝试找到另一张与第一张图片相同的卡片。如果你找不到配对，翻转的卡片将再次翻回背面。尽量记住这些图片，随着游戏时间的延长，找到配对会变得越来越容易。当你找到一对时，它们将从棋盘上移除，当你找到这个记忆游戏中所有的配对时，你就完成了这一关。尽情享受游戏吧！
