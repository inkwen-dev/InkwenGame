# 塔楼宝藏

<a href="https://inkwengame.com/zh/games/tower-loot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tower-loot/cover.jpg)

作为一名拥有超能力的魔术师，你必须摧毁所有物体，并将保险箱带到黏性地板上。一旦到达黏性地板，箱子会立即打开。不要忘记，只要贴在地板上即可，因为地板本身具有黏性。你可以删除方块。点击方块并摧毁它们，吸引箱子。

## 怎么玩

点击物体以摧毁它们 点击引爆炸弹 只要箱子贴在地板上即可
