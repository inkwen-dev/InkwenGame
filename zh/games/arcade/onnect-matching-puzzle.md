# Onnect 匹配拼图

<a href="https://inkwengame.com/zh/games/onnect-matching-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/onnect-matching-puzzle/cover.jpg)

Onnect 匹配拼图是一款经典益智游戏！你的任务是成功匹配相同的水果方块并消除它们！匹配的对数越多，得分越高。每次只能有三条线匹配相同方块！同时，你还需要注意消除方块时是否有位移！快来试试吧！
