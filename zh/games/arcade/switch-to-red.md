# 切换至红色

<a href="https://inkwengame.com/zh/games/switch-to-red" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/switch-to-red/cover.jpg)

经典的休闲益智游戏。你只需要将所有方块变为红色。但当你点击一个方块以及所有与之接触的方块时，它们都会旋转并改变颜色。你需要动脑筋，让所有方块都变成红色！

## 怎么玩

点击开始游戏
