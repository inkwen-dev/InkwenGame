# 维京人酒馆

<a href="https://inkwengame.com/zh/games/vikings-tavern" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/vikings-tavern/cover.jpg)

饮料！！！饮料！！！一群强大的维京人入侵了你的酒馆！他们不想使用你的洗手间……他们的唯一目标就是喝光你所有的啤酒！在他们变得不耐烦之前，赶紧满足他们的口渴。给他们送上啤酒，并在他们喝完后收回酒杯。小心：有些维京人比其他人的渴更厉害。这么多啤酒，肯定会有很长的队伍去洗手间！

## 怎么玩

你的酒馆有4张大桌子，许多维京人正坐在桌旁等待他们的啤酒。你不能把啤酒送到空桌子上
