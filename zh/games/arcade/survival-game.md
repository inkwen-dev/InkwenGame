# 生存游戏

<a href="https://inkwengame.com/zh/games/survival-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/survival-game/cover.jpg)

移动鼠标，用线条拖动小球，避开白色圆点并获得分数。游戏规则：1. 避开白色斑点；2. 触碰绿色点时无敌；3. 保持在中心位置，不要触碰边缘；4. 利用不易受损的白色斑点；5. 移动可获得额外分数。

## 怎么玩
