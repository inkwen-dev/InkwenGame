# 鸟类链接

<a href="https://inkwengame.com/zh/games/birds-link" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/birds-link/cover.jpg)

将方块滑向另一个相同的方块以消除两者。尽可能少地移动来完成此操作。消除一个方块可获得100分，但如果方块被滑动超过一次，每次移动将扣除10分。消除所有方块以完成关卡。游戏中共有36个具有挑战性的关卡。

## 怎么玩
