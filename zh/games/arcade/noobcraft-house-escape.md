# 菜鸟屋逃脱

<a href="https://inkwengame.com/zh/games/noobcraft-house-escape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noobcraft-house-escape/cover.jpg)

你必须帮助那个人人都喜欢的菜鸟逃离房子。帮忙并逃离房子。菜鸟想要成为一个男人，拿起他的金色剑，逃离房子，但无法打破门。当他发现需要在房子里找到金色钥匙和硬币时，一旦他把硬币放进箱子，房子内的秘密传送门就会显现。传送门出现后，你将被送往下一个世界。

## 怎么玩

使用 WASD 和方向键移动，支持双跳。用钥匙收集硬币，创建传送门以获取箱中的硬币
