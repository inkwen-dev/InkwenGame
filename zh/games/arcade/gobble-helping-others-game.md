# Gobble 帮助他人游戏

<a href="https://inkwengame.com/zh/games/gobble-helping-others-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gobble-helping-others-game/cover.jpg)

Gobble 帮助他人是一款街机游戏，你扮演地面上的一张嘴，目标是吃掉除人类以外的所有东西！在地面上移动，吞下眼前的一切，从仙人掌和石头到树木和箱子！每个谜题都与前一个相关，但总会有新的技巧和问题需要解决！每个新章节都会带来更有趣的挑战，看看你能走多远，别忘了，不要吃人！

## 怎么玩

鼠标点击或轻触开始游戏
