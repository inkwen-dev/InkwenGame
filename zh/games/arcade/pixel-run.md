# 像素跑

<a href="https://inkwengame.com/zh/games/pixel-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-run/cover.jpg)

控制一个由像素方块组成的人，在这款有趣且节奏快速的跑步游戏中，穿越充满挑战的障碍赛道。小心：当像素男孩撞到障碍物时，他会失去像素！跳过障碍以确保他的生存，并完整抵达终点以获得完美跑酷成绩。在穿越各种障碍时收集像素，以恢复像素男孩丢失的身体部位并升级。但要小心！如果撞到太多障碍，你将失去所有像素，必须重新开始！

## 怎么玩

操作简单但游戏极具挑战性和动态性。只需点击并左右滑动，随着你在赛道上冲刺。练习造就完美跑酷
