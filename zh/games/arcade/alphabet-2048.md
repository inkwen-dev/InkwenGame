# 字母 2048

<a href="https://inkwengame.com/zh/games/alphabet-2048" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/alphabet-2048/cover.jpg)

通过使用方向键或在屏幕上滑动手指或滑动鼠标指针，将相同的字母方块合并到一起。每次合并两个方块后，你将获得下一个字母。快来试试看你能达到哪个等级？你可以有限次数地打乱棋盘或重组方块，或者通过观看奖励视频来实现。
