# LOF 水果拼图

<a href="https://inkwengame.com/zh/games/lof-fruits-puzzles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lof-fruits-puzzles/cover.jpg)

一款非常独特的益智游戏，将让你开动脑筋。通过消除所有水果来完成每一关。方法是触摸或点击同一行或同一列上两个相同的水果。请注意，两个水果之间的任何其他水果也会被移除，这可能会导致你无法完全清除某一关的所有水果。

## 怎么玩

触摸或点击同一行或同一列上的两个相同水果
