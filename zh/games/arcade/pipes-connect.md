# 管道连接

<a href="https://inkwengame.com/zh/games/pipes-connect" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pipes-connect/cover.jpg)

管道连接是一款逻辑游戏，你的任务是连接管道。在棋盘上只有圆圈，你需要连接两个相同的圆圈以形成管道。会有不同类型的管道，你需要将它们全部连接起来才能通过关卡。但管道不能相互交叉或碰撞。你需要为每条管道找到正确的路径。
