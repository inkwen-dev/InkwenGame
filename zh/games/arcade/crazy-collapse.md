# 疯狂坍塌

<a href="https://inkwengame.com/zh/games/crazy-collapse" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/crazy-collapse/cover.jpg)

疯狂坍塌是一款精彩的方块消除游戏。在这款游戏中，您可以消除水平或垂直相连且颜色相同的方块。底部的状态栏将显示所选组合的预估分数。利用这些信息创建更大的组合，以获得更高的分数。

## 怎么玩

点击一个与其相邻方块具有相同物品的方块
