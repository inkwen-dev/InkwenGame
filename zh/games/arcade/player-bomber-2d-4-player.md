# 玩家炸弹手 2D 4人版

这是一款4人炸弹手游戏，你需要用炸弹炸毁墙壁。每次只能放置一个炸弹，并且可以支持4名玩家一起游玩这款游戏。

## 怎么玩

使用WASD键控制玩家1移动，左Shift键放置炸弹
