# 井字游戏

<a href="https://inkwengame.com/zh/games/tic-tac-too" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tic-tac-too/cover.jpg)

井字游戏是一款多人游戏，玩家可以用X或O字母组成三格连线。在这个有趣的迷你游戏中，你可以和朋友一起玩，也可以挑战电脑。游戏顶部会显示得分情况。你必须将三个相同的图案连成一条水平线

## 怎么玩

鼠标或触摸
