# Bhoolu 游戏

Bhoolu 2 是一款 2D 平台游戏，你需要收集所有的糖果，同时避开敌人、锯子、尖刺，并抵达通往下一关的魔法洞穴。游戏中共有 8 个关卡，随着进程难度逐渐增加。这是原版 Bhoolu 系列的第二部作品。
