# 发光爆炸！

<a href="https://inkwengame.com/zh/games/glow-explosions" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/glow-explosions/cover.jpg)

这款游戏的目标非常简单：你必须摧毁屏幕上所有移动的发光点。只需点击屏幕上的任意位置来制造爆炸。所有接触到爆炸区域的其他点也会随之爆炸，从而引发连锁反应。你必须清除屏幕上所有的发光点才能获胜。你准备好引爆所有发光点了吗？

## 怎么玩
