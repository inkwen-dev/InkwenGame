# 翻转颜色方块

<a href="https://inkwengame.com/zh/games/flipping-color-box" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flipping-color-box/cover.jpg)

立方体翻转！让跳跃的立方体翻转，使其着陆时颜色匹配，并完成色彩冲刺关卡。每一次跳跃，你都将进入更难的关卡，需要集中全部注意力和专注力通过色彩冲刺，从而登上山顶，成为我们经典上瘾游戏中色彩立方体翻转大师。

## 怎么玩

使用方向键操作游戏，或点击屏幕进行操作
