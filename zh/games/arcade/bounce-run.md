# 弹跳跑

![cover](https://img.inkwengame.com/games/bounce-run/cover.jpg)

这款有趣又上瘾的游戏依赖你的鼠标点击。游戏的目标是让你的角色以高速向前奔跑，避开障碍物，尽可能跑得更远。你能跑得越远，获得的成就就越多！根据你的成就，可以解锁角色的新外观。这为游戏增添了个性化和竞争性元素，让你保持动力。要取得更大成功，你需要快速的反应、精准的时机把握以及敏锐的观察力。
