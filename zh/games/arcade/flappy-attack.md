# Flappy Attack

<a href="https://inkwengame.com/zh/games/flappy-attack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flappy-attack/cover.png)

Flappy Attack 通过让你在充满不可预测方块的敌对天空中导航，考验你的精准度和反应能力。每次成功击中都能获得分数，挑战在于在随机性和破坏性中生存下来，依靠技巧而非速度来推进，而流畅的操作确保了跨设备的上瘾体验。
