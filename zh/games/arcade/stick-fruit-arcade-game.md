# Stick Fruit Arcade Game

<a href="https://inkwengame.com/zh/games/stick-fruit-arcade-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stick-fruit-arcade-game/cover.jpg)

Stick Fruit 是一款令人上瘾的 HTML5 休闲游戏，玩家需要通过延伸一根木棍桥来帮助自己的水果英雄跨越平台。简单却富有挑战性，这款游戏提供无尽乐趣，具有随机生成的平台、分数追踪、重新开始选项以及水果角色选择。

## 怎么玩

点击并按住以延伸木棍，松开以放下它，帮助英雄跨越间隙
