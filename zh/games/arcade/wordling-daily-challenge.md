# Wordling 每日挑战

<a href="https://inkwengame.com/zh/games/wordling-daily-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wordling-daily-challenge/cover.jpg)

你如何用五次机会猜出一个五个字母的单词？这是一款硬核的五字母单词猜测谜题游戏，配有2D键盘。键盘上的每个字母块和按钮的颜色将告诉你与正确答案的接近程度。如果你看到绿色，意味着该字母出现在正确的位置。如果你看到黄色，意味着该字母是正确的，但位置错误。如果你看到灰色，意味着正确答案中不包含这个字母。祝你好运，展现你的智慧！

## 怎么玩

轻触屏幕上的按钮
