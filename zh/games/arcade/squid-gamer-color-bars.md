# 鱿鱼玩家彩色条

<a href="https://inkwengame.com/zh/games/squid-gamer-color-bars" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/squid-gamer-color-bars/cover.jpg)

要获得分数，您必须击中与屏幕上玩家颜色相同的条形。相反，如果您击中了与自己颜色不同的条形，您将死亡。

## 怎么玩

点击鼠标左键以跳跃 在移动设备上跳跃只需轻触屏幕 在桌面或网页浏览器上，只需点击显示区域的任意位置即可跳跃
