# 猫咪坠落

<a href="https://inkwengame.com/zh/games/cat-drop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cat-drop/cover.jpg)

帮助可怜的小猫安全降落到正确的平台！游戏玩法：点击方块、积木等，将它们从屏幕上移除。除了草地外，所有方块都必须被清除，才能进入下一关。利用提供的方块和道具，让小猫安全降落在草地区域。如果走错步，可以重置当前关卡。尝试完成全部28个不同的关卡，体验这款有趣的物理益智游戏！

## 怎么玩
