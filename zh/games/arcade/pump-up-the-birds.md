# 给小鸟充气

<a href="https://inkwengame.com/zh/games/pump-up-the-birds" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pump-up-the-birds/cover.jpg)

城市鸟类战斗非常激烈，所以要保护好你的地盘！规则很简单：两只鸟相撞时，体型较大的一方会将另一方转化，所以快给你的小鸟充气吧！但要注意，在吸气时不要撞到其他小鸟，否则你的小鸟会失去空气。

## 怎么玩

触摸小鸟为它们充气 用你的小鸟撞击其他小鸟以将其转化为己方 不要让你的小鸟撞上比它们更大的小鸟
