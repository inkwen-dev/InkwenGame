# 拼字挑战

<a href="https://inkwengame.com/zh/games/scrabble-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/scrabble-challenge/cover.jpg)

拼字挑战是指由两个或更多单词组成的词。例如，单词‘灯塔’由‘光’和‘房子’两个词组成。同样，这个游戏包含许多常见的复合词例子。你需要根据每张图片猜出一个单词，并思考如何将其组合成复合词。简单的英语词汇列表。根据不同难度猜测流行词汇。通过逐一完成每个单词来解锁每一关。-2-图片1词活动。

## 怎么玩

游戏玩法 - 单词中的字母以横线形式显示，表示缺失的字母 - 从下方提供的字母中选择正确的字母 - 如果选择了错误的字母，则会再次提示选择字母
