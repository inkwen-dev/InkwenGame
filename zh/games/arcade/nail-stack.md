# 指甲堆叠！

<a href="https://inkwengame.com/zh/games/nail-stack" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/nail-stack/cover.jpg)

说实话，我从未想过有人能用指甲元素制作出一款3D收集类街机游戏。采用卡通艺术风格，玩家需要收集白色指甲，以增加手指的最终长度。同时，游戏中还包含一些色彩缤纷的画笔和装饰操作。事实上，即使你没有收集更多的指甲也无关紧要，因为游戏中并没有惩罚机制。不过，我还是建议你尽可能多地收集彩色指甲，完成所有关卡！

## 怎么玩

滑动屏幕进行移动
