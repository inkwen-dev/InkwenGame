# 霓虹方块

<a href="https://inkwengame.com/zh/games/neon-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/neon-block/cover.jpg)

一款充满霓虹主题的休闲游戏。尝试以最少的死亡次数通过所有关卡。挑战你的朋友。共15个关卡，可在所有平台（PC、移动设备、Android、iOS）上游玩。支持移动设备控制和PC控制。

## 怎么玩

使用鼠标进行跳跃，使用A和D键或方向键进行移动。在移动设备上，点击游戏屏幕上的箭头来移动
