# Meme Tiles

<a href="https://inkwengame.com/zh/games/meme-tiles" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/meme-tiles/cover.jpg)

Meme Tiles 是一款快节奏的节奏游戏，每一次跳跃都必须与节拍同步。左右移动以落在正确的方块上，避免坠落，并享受在奔跑过程中出现的搞笑表情包。测试你的反应速度，保持节奏，看看你能走多远！

## 怎么玩

桌面端 使用左右方向键 移动设备 点击屏幕左右两侧
