# 森林之翼

<a href="https://inkwengame.com/zh/games/forest-wing" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/forest-wing/cover.jpg)

《森林之翼》是一款超休闲的蝴蝶飞行游戏。引导你的蝴蝶穿越古老的森林树干，收集金色种子，并尽可能长时间地生存下去！游戏特色包括5种可解锁的蝴蝶皮肤、经典模式和闪电模式（30秒冲刺），11级经验进度系统，7天每日连签奖励，8项成就，季节性视觉主题（万圣节、冬季、春季、夏季、森林），以及为新手玩家设计的互动教程。

## 怎么玩

点击或轻按以拍打蝴蝶翅膀向上飞行，松开以滑翔下降。穿过树干之间的空隙，切勿触碰。收集金色种子以获得额外分数和连击倍数。通过积累种子来解锁新的蝴蝶皮肤
