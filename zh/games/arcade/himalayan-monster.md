# 喜马拉雅怪物

<a href="https://inkwengame.com/zh/games/himalayan-monster" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/himalayan-monster/cover.jpg)

使用方向键移动怪物。跳到车辆上将其摧毁。跳到飞行的人身上并按空格键咬住他。开到最底部，然后按向上键跳得更高。注意障碍物并避开它们。红色箭头表示障碍物，绿色箭头表示生命补给。
