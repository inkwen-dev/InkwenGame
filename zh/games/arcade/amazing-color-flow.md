# 神奇色彩流动

<a href="https://inkwengame.com/zh/games/amazing-color-flow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/amazing-color-flow/cover.jpg)

神奇色彩流动是一款有趣的街机游戏，你需要将一个空的水箱填满。你必须帮助水流向正确的方向。为此，你可以移除木棍。有足够的水来填充带有正确颜色的水箱，但要小心不要让颜色坍塌。共有20个具有挑战性的关卡等待完成。祝你好运！

## 怎么玩

点击金色的木棍以移除
