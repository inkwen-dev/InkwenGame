# Stickman Collect Run

Stickman Collect Run 是一款令人兴奋的跑酷冒险游戏，你将快速奔跑、跳跃和滑行穿越一个色彩斑斓的世界。控制一个木偶人，在充满活力且动作激烈的平台上奔跑。你的目标是持续奔跑，尽可能多地收集其他颜色的人物，并抵达终点线。
