# 万圣节填字游戏 HTML5

<a href="https://inkwengame.com/zh/games/halloween-crosswords-html5" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/halloween-crosswords-html5/cover.jpg)

万圣节填字游戏是一款文字与提示相结合的游戏。请先阅读提示，然后点击您想要填写的数字方块。横向填写时，点击一次方块编号；纵向填写时，点击两次。请留意提示旁边的绿色箭头位置，以确保您没有出错。游戏包含三个关卡，其中两个关于万圣节，最后一个关于电影惊悚片。该游戏可在移动设备和平板电脑上运行，但您必须使用方向键来导航填字方块。
