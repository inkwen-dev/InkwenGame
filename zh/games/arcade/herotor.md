# 英雄者

<a href="https://inkwengame.com/zh/games/herotor" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/herotor/cover.jpg)

你是一名超级英雄，可以飞行并到处穿梭。作为英雄者，投掷网绳并从一栋建筑飞到另一栋建筑。收集3颗星星，前往传送门。从传送门跳入新关卡，每种模式都是不同的冒险。

## 怎么玩

点击以飞行，点击并拖动。移动设备控制可用
