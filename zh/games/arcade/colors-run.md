# 颜色奔跑

<a href="https://inkwengame.com/zh/games/colors-run" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/colors-run/cover.jpg)

颜色奔跑是一款适合所有年龄段的街机益智游戏，非常适合家庭一起享受。游戏的目标是用位于屏幕底部的圆环捕捉不断出现的彩色球。你需要将圆环的颜色与即将出现的球的颜色匹配。为此，你有不同颜色的按钮。点击相应颜色的按钮，即可将圆环颜色更改为该颜色。反应迅速，尽可能多地摧毁更多球。

## 怎么玩

点击彩色按钮来玩这个游戏
