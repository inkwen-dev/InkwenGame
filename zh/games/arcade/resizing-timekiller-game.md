# ReSizing - 休闲游戏

<a href="https://inkwengame.com/zh/games/resizing-timekiller-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/resizing-timekiller-game/cover.jpg)

ReSizing - 一款简单却有趣的消磨时间游戏。通过鼠标展示你的敏捷性，避开障碍物。要避开障碍物，请改变自己的大小，穿过洞穴以增大体型，穿过岩石则缩小体型。

## 怎么玩

控制 左键点击玩家左侧 - 延伸 左键点击玩家右侧 - 收缩 Q - 关闭音乐
