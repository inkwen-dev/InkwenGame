# 贴纸球

<a href="https://inkwengame.com/zh/games/stickerball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/stickerball/cover.jpg)

贴纸球是一款快节奏的游戏，你将操控一个拥有独特能力的球来收集贴纸！你的目标是在9个关卡中收集180张色彩缤纷的贴纸，完成挑战并激活改变游戏规则的触发器。每回合，10张贴纸会从购买的贴纸包中飞入场内，但任何未被收集的贴纸都会消失——所以要行动迅速且精准！

## 怎么玩

玩法：

1. 瞄准：

移动光标瞄准——球上的箭头指示击球方向。

2. 蓄力：

按住鼠标左键（LMB）为箭头蓄力。松开鼠标左键即可发射球！过早击球会取消射击。

3. 收集贴纸：

击球后，球会反弹，收集贴纸、金币和水晶。一回合内收集的越多，连击数和奖励就越高！

4. 触发器：

收集特殊图标（磁铁、双倍、冰冻等）来强化球或改变贴纸的行为。例如，“幽灵”可以让球穿过触发器，“双倍移动”可以让球进行第二次击球，而不会出现新的贴纸。

5. 购买卡包：

在第一回合开始前，选择一个免费的1级卡包。每个卡包包含100张贴纸，每回合出现10张。

6. 策略提示：

使用“冻结”或“奖励”来增加场上的贴纸数量。

组合使用“磁铁”+“x2”等触发器可获得双倍奖励。

优先使用全息贴纸——它们可获得双倍金币！

贴纸球是一款快节奏的游戏，你将操控一个拥有独特能力的球来收集贴纸！你的目标是在9个关卡中收集180张色彩缤纷的贴纸，完成挑战并激活改变游戏规则的触发器。每回合，10张贴纸会从购买的贴纸包中飞入场内，但任何未被收集的贴纸都会消失——所以要行动迅速且精准！

游戏亮点在于14种动态触发器：冻结贴纸、使用“x2”获得双倍奖励、将球变成磁铁或幽灵、激活“迪斯科”模式，甚至操控双球！单回合收集的贴纸越多，你的连击数就越高，获得的金币也就越多。全息贴纸拥有独特的设计，还能获得双倍金币！

在12个色彩鲜艳、随机变化的场地中畅玩。购买贴纸包，升级你的收藏，并在最佳时机激活触发器，制定策略，最大化你的奖励。
