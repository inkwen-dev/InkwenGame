# 花朵排序

<a href="https://inkwengame.com/zh/games/flower-sorting" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/flower-sorting/cover.jpg)

在这个游戏中，你需要将五彩缤纷的花朵按列排序，直到同一列中的花朵都相同。这是一次愉快的大脑锻炼！你可以从一列中弹出一朵花，并将其放入一个空列，或放入顶部有相同花朵的列中。

## 怎么玩

使用鼠标或触摸屏来玩这个游戏
