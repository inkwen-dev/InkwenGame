# 像素猫飞不起来

<a href="https://inkwengame.com/zh/games/pixel-cat-cant-fly" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-cat-cant-fly/cover.jpg)

像素猫飞不起来是一款反应速度游戏，你需要尽可能长时间地让你的小像素猫保持在空中。当你触摸屏幕时，你的猫就会跳跃。你需要让它穿过墙壁上的洞。如果你不够精准，猫碰到表面，你就输了。

## 怎么玩

掌控一只可爱的小猫，在一个足够可爱的宇宙中尽情体验，并尽可能长时间地坚持下去。点击以让猫飞起来
