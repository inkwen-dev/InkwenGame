# 恐龙趣味冒险

<a href="https://inkwengame.com/zh/games/dino-fun-adventure" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/dino-fun-adventure/cover.jpg)

平台游戏，恐龙在三个关卡中行走，尽可能多地收集小蛋来得分。每个关卡有三个大金蛋，你需要收集这三个才能通关。跳到敌人身上以获得分数，并消灭所有敌人。

## 怎么玩

使用鼠标操作游戏，或在屏幕上轻触
