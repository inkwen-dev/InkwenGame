# 新手赛跑计时

<a href="https://inkwengame.com/zh/games/noob-race-against-time" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/noob-race-against-time/cover.jpg)

在这个冒险中，你需要收集所有的金币并获得箱子的钥匙。你必须非常小心才能在这片危险的森林中生存下来。你需要收集散布在整个森林中的所有金币。收集全部金币并获得金色钥匙。获得钥匙后，你必须到达箱子。到达箱子并打开它。你必须迅速行动以打开箱子。逃离森林的唯一方法就是到达箱子并打开它。

## 怎么玩

你可以通过按住 WASD 键来移动。注意障碍物并收集所有金币。收集全部金币并获得钥匙。
