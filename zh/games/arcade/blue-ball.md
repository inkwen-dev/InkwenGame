# 蓝球

<a href="https://inkwengame.com/zh/games/blue-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blue-ball/cover.jpg)

蓝球是一款由玩家控制的解谜游戏。你需要操控蓝色小球，越过旋转的方块。这些方块大小不一，遍布整个游戏屏幕。因此，你需要避开它们，顺利通过。在方块之间上下移动小球，尽可能走得更远。

## 怎么玩

使用鼠标控制小球，或直接在屏幕上滑动
