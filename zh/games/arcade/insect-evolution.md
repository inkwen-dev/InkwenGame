# 昆虫进化

<a href="https://inkwengame.com/zh/games/insect-evolution" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/insect-evolution/cover.jpg)

《昆虫进化》是一款轻松的移动游戏，通过关卡；你是一只迷路在沙漠中的小蚂蚁，回家的路还很遥远。你需要通过所有关卡才能找到家人，但这并不容易。在旅途中，你需要吃比你小的昆虫来成长，但同时也要小心不要被比你大、更强壮的昆虫吃掉。
