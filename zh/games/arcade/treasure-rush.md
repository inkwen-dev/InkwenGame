# 宝藏冲刺

<a href="https://inkwengame.com/zh/games/treasure-rush" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/treasure-rush/cover.jpg)

将宝石移动到空白位置，以形成一条水平或垂直的五个相同物品的行列。只需点击宝石，然后点击想要移动到的位置即可移动。如果宝石与其目的地之间有空路径，它就会移动到新位置。每次移动宝石后，如果没有发生匹配，则会在棋盘上新增三个宝石。不要让棋盘过于拥挤，否则可能会填满所有位置，你的魔法也将结束。

## 怎么玩
