# 猫井字棋

<a href="https://inkwengame.com/zh/games/cat-tic-tac-toe" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/cat-tic-tac-toe/cover.jpg)

猫井字棋是一款有趣的休闲策略游戏，玩家可以相互对战或与人工智能对抗，在3x3的网格上形成一条三格连线——横向、纵向或对角线。游戏不使用传统的X和O，而是采用可爱的猫咪主题符号，使所有年龄段的玩家都能感受到趣味性和视觉吸引力。

## 怎么玩

点击放置猫咪——只需点击3x3网格中的任意空格即可放置你的猫咪符号。撤销（可选）——如果启用，点击“撤销”按钮可移除你上一步的操作。重新开始游戏——点击“重新开始”或“新游戏”
