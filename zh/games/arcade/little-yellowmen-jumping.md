# 小黄人跳跃

<a href="https://inkwengame.com/zh/games/little-yellowmen-jumping" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/little-yellowmen-jumping/cover.jpg)

在这个冒险中，你需要逃离正在上升并试图杀死你的粉红色毒液。你可以独自游戏，也可以和朋友一起，避开毒液。尽可能地往上爬，永远不要回头。不断跳跃，不要回头看，逃离实验室。如果你无法逃离实验室，可能会被粉红色毒液淹死。

## 怎么玩

使用 WASD 键来移动和跳跃 游戏 使用方向键来移动和跳跃 移动设备控制可用
