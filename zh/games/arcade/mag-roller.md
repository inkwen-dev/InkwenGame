# 磁力滚轮

<a href="https://inkwengame.com/zh/games/mag-roller" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

掌控磁力滚轮，一个高速的磁性球体，能将附近的方块拉入其轨道。在混乱的关卡中滚动，即时构建巨大的方块护甲，碾压障碍物，并利用电磁力，以令人满足的毁灭之路通过每一关！Web 开发 <a href='https://www.poki.org.es/'>https://www.poki.org.es/</a>
