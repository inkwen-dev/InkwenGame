# 雪时滑动

<a href="https://inkwengame.com/zh/games/snow-time-swipe" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/snow-time-swipe/cover.jpg)

这是一款快节奏的视频游戏。玩法很简单：在躲避雪崩的同时，你需要将角色移动到每一屏的开放门口。随着游戏进行，定时陷阱被加入游戏的视觉元素中，使挑战逐渐增加。尽管游戏复杂度较高，但一旦你适应了节奏，就能轻松应对。金币用于扩展可玩角色的阵容。当遇到特别困难的情况时，可以使用道具暂时停止降雪。

## 怎么玩

使用 WASD 或 方向键 移动角色
