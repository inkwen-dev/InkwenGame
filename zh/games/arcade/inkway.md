# 墨路

<a href="https://inkwengame.com/zh/games/inkway" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/inkway/cover.jpg)

在这款趣味十足又极具挑战性的益智游戏中，你的目标是绘制一条道路，安全地引导小车到达终点。发挥你的创造力和规划能力，打造一条完美的路线，同时避开沿途的障碍物和危险区域。只需在屏幕上画一条线，就能为小车铺设道路。道路铺设完成后，小车就会沿着它驶向目的地。务必谨慎规划路线，因为设计不当的道路可能会导致小车撞车或陷车。

## 怎么玩

画一条线：从起点到终点画一条路，引导汽车安全到达目的地。
