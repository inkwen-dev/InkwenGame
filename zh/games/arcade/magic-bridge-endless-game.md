# 魔法桥！：无尽游戏

<a href="https://inkwengame.com/zh/games/magic-bridge-endless-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/magic-bridge-endless-game/cover.jpg)

魔法桥是一款技巧类游戏。控制众多猫角色中的一个，尝试在不断向上移动的桥上生存下去。桥会根据你站立的位置向下倾斜，因此你必须迅速反应，保持平衡。避开所有敌人，收集所有硬币，并解锁拥有不同能力的角色。跃上桥面，体验这场无尽的乐趣吧！操作方法：在平台上移动，避免触碰敌人。

## 怎么玩

移动猫咪 - A D 或 左右方向键
