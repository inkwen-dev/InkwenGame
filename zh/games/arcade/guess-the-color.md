# 猜颜色

<a href="https://inkwengame.com/zh/games/guess-the-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/guess-the-color/cover.jpg)

猜颜色是一款专为儿童设计的教育游戏，帮助孩子们了解各种颜色。它还能测试孩子们的反应速度。屏幕上会出现一支彩色铅笔，孩子们只需选择是或否作为回答。在时间耗尽前尽可能多地回答问题。这是一款有趣且令人愉快的游戏，孩子们一定会喜欢。
