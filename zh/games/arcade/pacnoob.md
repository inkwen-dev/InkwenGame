# PacNoob

<a href="https://inkwengame.com/zh/games/pacnoob" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pacnoob/cover.jpg)

PacNoob 是一款像素风格的街机冒险游戏，你将引导 Noob 穿越充满敌人的迷宫式关卡。收集金币，避开追捕者，并使用道具来通关每一关。游戏采用复古风格的画面和快节奏的玩法，融合了经典街机乐趣与 Noob 的标志性幽默感。解锁皮肤，穿越复杂的路径，智胜追捕者，在这款令人上瘾的迷宫逃脱挑战中展现你的技巧。
