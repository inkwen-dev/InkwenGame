# Reco Ball

<a href="https://inkwengame.com/zh/games/reco-ball" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/reco-ball/cover.jpg)

Reco Ball 是一款 2D 可爱的小型平台游戏，你将扮演一个球，需要收集所有铜币，同时避开敌对的球、旋转刀片、尖刺，并抵达黄色旗帜以进入下一关。共有 8 个关卡可供挑战，难度会随着进程逐渐增加。

## 怎么玩

使用 WASD 或方向键控制角色移动；连续按两次 W 键或上箭头键可进行二段跳
