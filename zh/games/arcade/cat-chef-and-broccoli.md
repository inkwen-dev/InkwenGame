# 猫厨师与西兰花

<a href="https://inkwengame.com/zh/games/cat-chef-and-broccoli" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

可爱的西兰花需要逃离厨师猫，否则它会被抓住并做成晚餐。帮助西兰花在甜美的厨师猫追捕下抵达冰箱。西兰花要小心，饼干不是你的朋友，它们是敌人。路上有障碍物，请小心盐瓶和磨碎器等障碍物。
