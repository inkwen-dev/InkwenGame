# 太空人迷宫

<a href="https://inkwengame.com/zh/games/astronaut-in-maze" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/astronaut-in-maze/cover.jpg)

这是一款简单但富有挑战性的益智游戏。你需要将太空人的飞船安全地送到他的空间站。为他找到回家的路可能很棘手，因为需要避开障碍物，并且有很多容易迷失的方向。用最少的移动次数将飞船送达空间站将获得更高的分数。小心一点，如果飞船飞出屏幕，他就永远迷失了，你将不得不重新开始这一关。看看你能否完成全部24个关卡以赢得游戏。
