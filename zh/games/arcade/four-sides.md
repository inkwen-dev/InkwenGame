# 四面

<a href="https://inkwengame.com/zh/games/four-sides" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/four-sides/cover.jpg)

这是一款游戏中有四个位于中间的球，它们颜色各不相同。当你点击屏幕时，它们会旋转。从屏幕顶部、左侧、右侧以及底部会出现与中间球颜色相同的较小球。你需要旋转这四个球，使其与相同颜色的小球匹配。请准备好快速反应，否则游戏一开始就会失败。

## 怎么玩

点击屏幕开始游戏
