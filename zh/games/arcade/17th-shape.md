# 第17个形状

<a href="https://inkwengame.com/zh/games/17th-shape" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/17th-shape/cover.jpg)

通过方向键或在屏幕上滑动手指或滑动鼠标指针，将相同的形状向任何方向移动并合并。每次合并两个形状后，你将获得一个新形状。不妨试一试，看看你能否达到第17个形状？你可以有限次地打乱棋盘或重新分组物品。
