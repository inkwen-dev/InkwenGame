# 超菜鸟监狱复活节

<a href="https://inkwengame.com/zh/games/supernoob-prison-easter" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/supernoob-prison-easter/cover.jpg)

你需要帮助超菜鸟在复活节从监狱里收集所有的蛋。他必须在每个章节的复活节收集全部12个蛋，并且用超菜鸟收集那个蛋。小心炸弹正在落下，箭矢正从墙里射出。在不死亡的情况下收集蛋并到达宝箱。
