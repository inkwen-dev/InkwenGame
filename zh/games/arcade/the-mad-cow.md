# 疯牛病

<a href="https://inkwengame.com/zh/games/the-mad-cow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-mad-cow/cover.jpg)

有一天，母牛达莎突然发疯，离家出走。她跑到城里，开始大肆破坏。这头母牛的任务就是摧毁一切。用牛角和武器摧毁建筑物，获得积分，驾驶直升机，开汽车。记住，警察会追捕你。

## 怎么玩

移动 - 使用 AWSD 键，跳跃 - 空格键，用角攻击 - A 键，射击 - A 键，加速 - Shift 键，拾取物品 - T 键。手机版采用摇杆 + 弹出式按钮。
