# 斯巴达水果

<a href="https://inkwengame.com/zh/games/spartan-fruits" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/spartan-fruits/cover.jpg)

斯巴达水果们必须克服重重障碍，找到装有金币的宝箱，才能解锁奖励并进入下一关。他们还必须收集宝石来解锁新的水果种类。

## 怎么玩

使用 A 或 D 键或左/右方向键移动角色。

使用 W 键或上方向键跳跃。

按住 F 键投掷剑，使其悬挂并挥舞。

按 G 键攻击，或按住 G 键向前投掷剑。

悬挂时：

使用 A 或 D 键或左/右方向键挥剑。

使用 W 键或上方向键向上移动。

使用 S 键或下方向键向下移动。
