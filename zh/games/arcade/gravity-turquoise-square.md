# 重力青绿色方块

<a href="https://inkwengame.com/zh/games/gravity-turquoise-square" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/gravity-turquoise-square/cover.jpg)

你是一个违背重力的方块。你需要跳跃才能到达门口，别忘了，无论你点击哪里，它都会向相反方向跳跃！到达大门以生存并完成20种不同的模式。

## 怎么玩

要玩这个游戏，必须用鼠标点击或触摸点击，而不是指定方向来移动，它会自动跳跃
