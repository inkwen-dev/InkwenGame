# 拯救动物：森林火灾

<a href="https://inkwengame.com/zh/games/save-animals-forest-fire" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-animals-forest-fire/cover.jpg)

从森林火灾中拯救动物。找到逃离燃烧森林的正确路径。脆弱的桥梁将承载猫、兔子、乌龟以及其他许多动物，穿越河流、沼泽、有鲨鱼出没的海洋和深渊等危险水域。从非洲到北极圈的不同区域拯救动物。所有被救出的动物都可以安置在你的农场上。通过关卡后，会有越来越多的宠物加入。

## 怎么玩

桌面 点击鼠标，在需要旋转时点击屏幕下方 移动端 点击屏幕可使动物转向 尝试在转弯瞬间保持角色重心位于桥面之上，否则可能失去平衡
