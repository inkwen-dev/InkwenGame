# 方块对战

<a href="https://inkwengame.com/zh/games/blocks-vs-blocks" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blocks-vs-blocks/cover.jpg)

方块对战是一款放松的益智游戏。你只需要放置第一个方块，这个方块会向各个方向扩散，所有你扩散出的方块区域面积将会被计算。面积越大，胜败的差距就越明显！快来挑战吧！

## 怎么玩

点击开始游戏
