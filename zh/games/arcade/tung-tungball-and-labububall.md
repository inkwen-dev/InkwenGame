# Tung TungBall 和 Labububall

<a href="https://inkwengame.com/zh/games/tung-tungball-and-labububall" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/tung-tungball-and-labububall/cover.jpg)

你必须在这个球的世界中生存下来。两位朋友，Tungball 和 Labububall，需要你的帮助。他们必须收集所有的硬币，逃离森林，找到钥匙，并打开城堡大门。两位朋友都必须安全抵达城堡。安全抵达城堡后，你将获得进入下一关的资格。小心——如果被壳状怪物抓住，你就会失败。

## 怎么玩

使用 WASD 方向键移动 双重跳跃可用 移动触摸控制 收集所有硬币和金色钥匙，然后到达大门
