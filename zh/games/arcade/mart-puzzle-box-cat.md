# Mart Puzzle Box Cat

![cover](https://img.inkwengame.com/games/mart-puzzle-box-cat/cover.jpg)

在 Mart Puzzle - Box Cat 中开启一段可爱的解谜冒险。这是一款休闲游戏，你将装载许多动物，如猫、兔子、龙等。点击它们，让它们进入相同种类的汽车中。收集3个玩偶即可启动汽车。
