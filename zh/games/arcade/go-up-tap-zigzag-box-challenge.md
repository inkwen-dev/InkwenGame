# 向上点击 zigzag 方块挑战

<a href="https://inkwengame.com/zh/games/go-up-tap-zigzag-box-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/go-up-tap-zigzag-box-challenge/cover.jpg)

《向上》是一款简单但富有挑战性的超休闲街机游戏，时机与专注是获胜的关键。控制一个小方块，引导它向上朝胜利线前进。每次点击都会改变方块的方向。第一次点击使方块向左移动，第二次点击则向右移动，形成锯齿状的移动模式。路径两侧布满障碍物，玩家必须精准地把握每次点击的时机，以避免碰撞。到达胜利线即可完成当前关卡，进入下一个挑战。

## 怎么玩

点击屏幕来移动方块
