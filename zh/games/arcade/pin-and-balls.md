# 钉子与小球

<a href="https://inkwengame.com/zh/games/pin-and-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pin-and-balls/cover.jpg)

一款轻松简单的益智游戏，你只需拔掉钉子，疏通彩色小球的管道，让彩色小球顺利落入底部的桶中并达到数量标准即可。但管道中有很多障碍需要留意，它们可能会让你失去小球。
