# 青蛙跳

<a href="https://inkwengame.com/zh/games/froggy-hop" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/froggy-hop/cover.jpg)

《青蛙跳》是一款趣味十足、令人上瘾的街机平台游戏，你将操控你的青蛙飞向天空！在睡莲叶、弹簧片、乌龟和鲸鱼身上弹跳，躲避棘手的陷阱，一路收集金币和宝石。升级青蛙的能力，跳得更高、弹得更远，解锁炫酷的新皮肤。你能跳多远呢？

## 怎么玩

把握时机点击，即可让青蛙弹跳越过睡莲、乌龟和弹簧垫，并通过弹跳躲避障碍物。

桌面端操作：

使用鼠标左键发射青蛙。

移动端操作：

点击屏幕即可发射并弹跳青蛙。
