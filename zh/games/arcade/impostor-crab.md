# 冒牌蟹

<a href="https://inkwengame.com/zh/games/impostor-crab" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/impostor-crab/cover.jpg)

帮助一只爱吃汉堡的螃蟹克服充满危险的生活中的种种危机。帮助螃蟹战胜危险，收集汉堡，每关得分越高，挑战越大，敌人也越多。消灭敌人，抵达终点旗帜。

## 怎么玩

使用WASD键进行操作。注意躲避敌人以求生存。你可以爬到怪物头顶并杀死它们。游戏中可进行二段跳。
