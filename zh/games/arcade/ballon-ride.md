# 气球飞行

<a href="https://inkwengame.com/zh/games/ballon-ride" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/ballon-ride/cover.jpg)

你必须尽最大努力防止飞行中的气球掉落。通过将障碍物扔向气球的两侧来防止气球爆炸。如果气球爆炸，珍贵物品会掉落，你将失败。尽情享受吧。
