# 方块拼图魔法

<a href="https://inkwengame.com/zh/games/blockpuzzlemagic" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/blockpuzzlemagic/cover.jpg)

组装并消除方块。各种形状的方块会随机出现在底部。将方块拖动到上方的盒子中。当一行或一列被填满时，方块就会被消除。快来试试吧。
