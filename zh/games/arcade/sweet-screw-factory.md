# 甜蜜螺栓工厂

<a href="https://inkwengame.com/zh/games/sweet-screw-factory" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/sweet-screw-factory/cover.jpg)

甜蜜螺栓工厂是一款基于物理的解谜游戏，你需要拧下五颜六色的糖果螺栓，让糖果方块掉落并引导它们进入匹配的收集罐！通过按正确的顺序移除螺栓，来控制平台的下落、旋转和滑动。6个糖果工厂世界，共120个关卡，包含锁定螺栓、连锁反应、弹簧床、传送门以及Boss谜题。提供简单、中等和困难三种难度，并支持完整进度保存！

## 怎么玩

点击糖果螺栓将其移除，让物理效果接管一切。将下落的糖果方块引导至颜色匹配的罐子中以获胜
