# 滚动王国

<a href="https://inkwengame.com/zh/games/roll-kingdoms" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/roll-kingdoms/cover.jpg)

《Roll Kingdoms》是一款色彩缤纷的3D骰子王国冒险游戏。掷骰子，探索三个漂浮王国，收集金币和皇冠，将18座建筑从废墟升级为皇家地标，解锁角色和骰子，完成任务，并精通六款互动小游戏。建造阳光要塞、海盗湾和余烬王国，然后完成皇家庆典。

## 怎么玩

按下或轻触“滚动”按钮掷两颗骰子并在棋盘上移动。停留在金币、皇冠、神秘、升级和小游戏格子上即可获得奖励。花费金币可将每个建筑从 0 级升级到 4 级。在电脑上，使用鼠标并按照小游戏期间显示的键盘提示操作。在移动设备上，使用触控操作并按照屏幕提示操作。完成阳光要塞、海盗湾和余烬王国中的所有建筑和目标，然后完成皇家庆典即可完成战役。
