# 波浪奔跑

<a href="https://inkwengame.com/zh/games/wave-runs" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/wave-runs/cover.jpg)

波浪奔跑是一款街机益智游戏，目标是让您的火箭尽可能跑得更远。这并不像您想象的那么容易。在太空中，关卡将充满障碍物或几何图形。在它们之间穿行，并尽量不要撞到障碍物。障碍物会移动，它们不是静止的，因此穿过它们会更加困难。点击屏幕时，火箭会移动，松开则停止。火箭将水平左右移动，点击屏幕以向前推进。

## 怎么玩

点击屏幕来玩这个游戏
