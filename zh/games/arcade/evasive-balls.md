# 躲避球

<a href="https://inkwengame.com/zh/games/evasive-balls" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/evasive-balls/cover.jpg)

这是一款你需要控制两个在无形圆圈中旋转的球的游戏。每次点击屏幕，你就能改变球的移动方向。当面前出现障碍物时，请及时改变方向以避开它们。收集圆形物体，并努力取得最佳成绩。这是一款有趣且轻松的儿童游戏。
