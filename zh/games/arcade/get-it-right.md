# 答对它

<a href="https://inkwengame.com/zh/games/get-it-right" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/get-it-right/cover.jpg)

球上的代码！你能破解吗？盲目猜测需要添加球的颜色和位置。每次放置一个位置后，每个位置的答案都会给出。绿色表示完全正确，红色表示完全错误，黄色表示颜色位置错误。请在有限次数内猜出正确答案！
