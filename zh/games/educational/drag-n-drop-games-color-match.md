# 拖拽游戏 色彩匹配

<a href="https://inkwengame.com/zh/games/drag-n-drop-games-color-match" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/drag-n-drop-games-color-match/cover.jpg)

欢迎来到色彩匹配！这是一款专为儿童设计的终极互动学习体验！本游戏旨在以有趣且引人入胜的方式帮助年幼的学习者识别和区分颜色。目标很简单：观察目标中的黑白物体，从源盒中找到对应的彩色卡片。将红色卡片拖到苹果上，蓝色卡片拖到鲸鱼上，看着物体瞬间被赋予色彩！

## 怎么玩

桌面 使用鼠标点击并拖动彩色卡片，在匹配的物体上释放鼠标按钮以涂色 移动设备 平板电脑 用手指按住彩色卡片，拖动并放置到对应的物体图标上
