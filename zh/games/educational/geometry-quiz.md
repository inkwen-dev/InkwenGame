# 几何测验

<a href="https://inkwengame.com/zh/games/geometry-quiz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/geometry-quiz/cover.jpg)

通过回答有趣的问题来检验你的几何技能。每个问题你将有4个选项。首次正确回答可获得更高分数。努力取得最高分，并挑战你的朋友，看他们能否超越你的分数。
