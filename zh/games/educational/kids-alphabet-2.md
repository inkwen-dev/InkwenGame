# 儿童字母表

<a href="https://inkwengame.com/zh/games/kids-alphabet-2" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/kids-alphabet-2/cover.png)

《儿童字母表》为小学习者带来一场色彩缤纷的教育之旅。通过生动的声音和视觉效果，孩子们可以描画并识别字母，将它们变成单词。趣味十足且直观的游戏玩法鼓励孩子练习词汇和书写技能，同时跟踪进步，让学习变成一次字母冒险。
