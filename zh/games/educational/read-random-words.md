# 阅读随机单词

<a href="https://inkwengame.com/zh/games/read-random-words" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/read-random-words/cover.png)

在《阅读随机单词》中，每次点击都能轻松发现新词汇。这款简单的工具每次都会提供一个新单词，让学习和阅读变得有趣。凭借其简洁的设计和即时洗牌功能，探索语言从未如此引人入胜、令人愉悦。
