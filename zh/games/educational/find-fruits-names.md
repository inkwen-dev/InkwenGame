# 找出水果名称

<a href="https://inkwengame.com/zh/games/find-fruits-names" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-fruits-names/cover.jpg)

这是一款教育类单词拼图游戏，你需要识别右侧面板中给出的水果图片，并找出其拼写。只需点击所需的字母来完成拼写。错误点击的字母将导致失去一条生命（总共五条生命）

## 怎么玩
