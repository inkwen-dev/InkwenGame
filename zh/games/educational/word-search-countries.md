# 单词搜索国家

<a href="https://inkwengame.com/zh/games/word-search-countries" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/word-search-countries/cover.jpg)

在方块的直线中找到单词（水平、垂直或对角线方向任意），点击显示单词首字母的方块，然后移动到单词末尾的字母。找出左侧面板上显示的所有单词以完成关卡。完成所有关卡即可赢得游戏。
