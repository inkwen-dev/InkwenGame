# 圣诞树加法

<a href="https://inkwengame.com/zh/games/christmas-tree-addition" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/christmas-tree-addition/cover.jpg)

通过创建与圣诞树上数字匹配的装饰品来装饰圣诞树。点击发射雪人手中的装饰品。当相同类型的装饰品相互碰撞时，它们的数字会相加；而不同类型装饰品碰撞则会导致相减。看看你能否装饰完所有的10棵树！

## 怎么玩

使用鼠标或触摸操作让雪人投掷装饰品
