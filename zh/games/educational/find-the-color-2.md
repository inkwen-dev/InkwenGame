# 找出颜色

![cover](https://img.inkwengame.com/games/find-the-color-2/cover.png)

沉浸在多彩的冒险中，体验《找出颜色》这款引人入胜的游戏，专为锻炼年轻大脑而设计。在九个难度逐渐提升的关卡中，将鲜艳的物体与其对应的色彩进行匹配，从而提升颜色识别能力和手眼协调能力。非常适合在有趣且富有教育意义的环境中培养好奇心和快速反应能力。
