# 天才乌鸦

<a href="https://inkwengame.com/zh/games/the-genius-crow" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/the-genius-crow/cover.jpg)

《天才乌鸦》是一款有趣且富有教育意义的益智游戏，灵感源自经典寓言。帮助聪明的乌鸦将石头投入罐中，提升水位并完成每一关。享受色彩缤纷的图形、流畅的触控操作以及考验大脑的挑战，锻炼逻辑思维与解决问题的能力。适合儿童、学生和解谜爱好者，这款HTML5游戏可在移动设备和桌面端运行，带来数小时的沉浸式乐趣。

## 怎么玩

移动端：点击并拖动以将石头投入罐中，与物体互动并导航菜单；桌面端：使用鼠标左键与物体和菜单进行互动
