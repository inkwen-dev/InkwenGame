# 数字方块

<a href="https://inkwengame.com/zh/games/number-block" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/number-block/cover.jpg)

这款数学谜题游戏中的加减法并不难。真正具有挑战性的是，找出哪些方块组合起来能使最终的方块变为零。如果卡住了，只需点击主屏幕上的视频按钮，查看每关的解法。
