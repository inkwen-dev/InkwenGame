# 世界国旗：彩色拼图

<a href="https://inkwengame.com/zh/games/world-flags-color-puzzle" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

一款独特的国旗涂色益智游戏，融合了世界探索元素。通过正确涂绘国旗来测试你的地理知识，然后驾驶飞机环游世界，发现并解锁新的国家。

## 怎么玩

点击颜色即可根据国家名称绘制国旗。使用飞机按钮飞越世界地图，探索未知领域，并在旅途中解锁更多国旗挑战。
