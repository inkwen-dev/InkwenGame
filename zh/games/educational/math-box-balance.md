# 数学盒平衡

<a href="https://inkwengame.com/zh/games/math-box-balance" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-box-balance/cover.jpg)

数学盒平衡是一款数字益智游戏。早期关卡有2个盒子，随着进度推进，最多可达到8个盒子。每个盒子包含4个数字方块，这些数字的总和会显示在盒子内部。你的目标是让所有盒子的总和相等。你可以交换盒子之间的数字方块，以实现总和相等。这是一款无尽游戏，难度会随着时间增加，你的得分也会提升，乐趣也随之增长。

## 怎么玩

使用鼠标或触控板来玩游戏
