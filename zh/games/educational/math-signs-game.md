# 数学符号游戏

<a href="https://inkwengame.com/zh/games/math-signs-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/math-signs-game/cover.jpg)

“数学符号游戏”是一款教育类数学游戏，鼓励人们快速思考以解决数学运算。通过四种主要的数学运算，在这款游戏中尽情享受乐趣，并尽可能迅速地在数学符号之间做出选择。可以和朋友一起玩，或挑战自己的最高得分！游戏画面精美且色彩丰富。祝你好运，玩得开心！

## 怎么玩

在桌面端使用鼠标，或在移动设备上使用触摸按钮
