# 放松数学加法

<a href="https://inkwengame.com/zh/games/chill-math-addition" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chill-math-addition/cover.jpg)

在这个游戏中，一幅冬日景象隐藏在加法表达式瓷砖之下。玩家必须将正确的数字彩球拖放到匹配的瓷砖上以解决表达式。每解决一个表达式，冬日景象就会逐渐显现。目标是通过正确完成所有数学问题来揭示整个图像。
