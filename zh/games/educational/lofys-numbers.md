# Lofys 数字

<a href="https://inkwengame.com/zh/games/lofys-numbers" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lofys-numbers/cover.jpg)

Lofys - 数字是一款专为儿童设计的教育游戏，包含40多个练习，通过手机、平板或电脑以有趣的方式教授数字名称、形状、书写和数量。使用Lofys学习乐趣无穷！游戏由 Nau.kids 开发

## 怎么玩

名称 点击对应你名字的数字 形状 拖动正确的数字 书写 跟随桥梁来书写数字 数量 点击所需的数量
