# 我的第一个机器人

<a href="https://inkwengame.com/zh/games/my-first-robot" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/my-first-robot/cover.jpg)

这是一款专为儿童设计的教育类游戏，旨在帮助孩子们组装机器人。实验室里的所有机器人都不完整，让我们一起将它们修复吧。游戏中有6个独特的机器人，每个都有自己的动作姿势。从零开始搭建机器人将会非常有趣。你需要将各个部件组合成一个完整的机器，并绘制电路元件。
