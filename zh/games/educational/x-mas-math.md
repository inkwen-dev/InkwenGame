# 圣诞数学

![cover](https://img.inkwengame.com/games/x-mas-math/cover.jpg)

XMAS 数学是一款简单但有趣的益智数学游戏。单词 XMAS 被用来表示方框中的数字。X 代表千位，M 代表百位，A 代表十位，S 代表个位。利用这一点来解决所有谜题。例如，在数字 3489 中，X 是 3，M 是 4，A 是 8，S 是 9。
