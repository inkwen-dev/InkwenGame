# 乘法轮盘

<a href="https://inkwengame.com/zh/games/multiplication-roulette" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/multiplication-roulette/cover.jpg)

点击旋转按钮，然后点击轮盘以停止它们。你将有10次机会。每次都会指向一个数字，你需要在最短时间内正确回答这两个数字相乘的结果。
