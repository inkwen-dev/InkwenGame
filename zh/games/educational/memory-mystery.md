# 记忆之谜

<a href="https://inkwengame.com/zh/games/memory-mystery" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/memory-mystery/cover.jpg)

记忆之谜是一款引人入胜且富有挑战性的记忆游戏，旨在测试并提升你的记忆力。游戏中会展示一系列带有独特图像的卡片，这些卡片最初会短暂显示，然后被翻面朝下。你的任务是通过记住它们的位置，逐一翻开卡片来配对相同的卡片。游戏设有多个难度逐渐增加的关卡，为所有年龄段的玩家提供无尽的乐趣和大脑刺激。

## 怎么玩

鼠标点击 使用鼠标左键选择并翻转一张卡片 触摸屏 移动设备 平板电脑 点按卡片以翻转它
