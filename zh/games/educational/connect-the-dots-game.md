# 连线游戏

<a href="https://inkwengame.com/zh/games/connect-the-dots-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/connect-the-dots-game/cover.jpg)

一款专为数字学习和描线设计的教育类游戏，通过有趣的活动帮助孩子学习。每完成一幅图画，孩子们将听到其英文发音。这些活动没有时间限制，因此鼓励孩子按照自己的节奏学习。

## 怎么玩

从数字1开始，按顺序连接每个点
