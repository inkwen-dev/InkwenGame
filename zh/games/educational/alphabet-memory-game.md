# 字母记忆游戏

![cover](https://img.inkwengame.com/games/alphabet-memory-game/cover.jpg)

教孩子学习的一种最佳方式就是通过某种游戏。这款记忆游戏旨在通过记忆游戏的方式帮助孩子学习英语字母。本游戏包含四种模式：学习、简单、普通和困难。在学习模式中，您可以看到所有字母，并可以选择每个字母来听其发音。在其他模式中，您可以玩记忆游戏，需要匹配所有卡片才能完成关卡。
