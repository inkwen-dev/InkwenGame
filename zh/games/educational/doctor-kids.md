# 医生小孩

<a href="https://inkwengame.com/zh/games/doctor-kids" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/doctor-kids/cover.jpg)

孩子们来到诊所，需要你的帮助让他们恢复健康。一旦你将小病人安排到正确的医生办公室，就可以尽情玩互动小游戏，迅速为孩子们治疗。游戏中有各种类型的医生和治疗方法，还有许多色彩缤纷的物品来匹配病人的特征。每个医生办公室都包含一个独特的迷你游戏，让治疗过程更加有趣。
