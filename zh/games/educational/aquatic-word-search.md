# 水中单词搜索

<a href="https://inkwengame.com/zh/games/aquatic-word-search" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/aquatic-word-search/cover.jpg)

在方块的直线中找到单词（水平、垂直或对角线方向，任意方向），点击显示单词首字母的方块，然后移动到单词末尾字母的方块。找出左侧面板中显示的所有单词以完成一关。完成所有关卡即可赢得游戏。
