# 2048 方块

<a href="https://inkwengame.com/zh/games/2048-cubes" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/2048-cubes/cover.jpg)

无限模式的2048游戏，带有物理效果。方块碰撞后会反弹。下落并合并相同数字以获得更高的数字。

## 怎么玩

向右和向左滑动以移动方块，松开以放下。合并相同数字的方块以得到更大的方块。通过更多方块来提高分数。当棋盘填满到虚线位置时，游戏结束
