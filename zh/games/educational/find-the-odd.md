# 找出不同

<a href="https://inkwengame.com/zh/games/find-the-odd" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/find-the-odd/cover.jpg)

这是一款色彩缤纷的益智游戏，你需要从一组4个物品中找出1个不同的物品。为了准确找出不同的物品，你必须遵循屏幕上显示的提示。如果你在25秒内找到不同的物品，将获得时间奖励。完成全部30个关卡即可赢得游戏。

## 怎么玩

使用鼠标点击物品
