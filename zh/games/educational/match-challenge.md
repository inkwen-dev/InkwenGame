# 比赛挑战

<a href="https://inkwengame.com/zh/games/match-challenge" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/match-challenge/cover.jpg)

一个简单却有趣的配对挑战！看看屏幕底部的各种物品，点击四个属于同一类别的物品，类别可以是水果、工具、动物或家居用品。快速思考，但也要谨慎选择！

## 怎么玩

观察一组不同的物品

点击选择四个属于同一类别的物品

提交你的匹配结果以确认是否正确

在后面的关卡中与时间赛跑
