# 图像测验

<a href="https://inkwengame.com/zh/games/image-quiz" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/image-quiz/cover.png)

用图像测验挑战你的大脑，这是一款引人入胜的游戏，玩家需识别超过100张色彩鲜艳的图像，涵盖多种类别。在享受趣味教育体验的同时，提升你的观察力和记忆力。仔细分析每张图像，提交答案，并逐步解锁更复杂的视觉内容。准备好测试你的知识了吗？
