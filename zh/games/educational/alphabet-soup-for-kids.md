# 儿童字母汤

<a href="https://inkwengame.com/zh/games/alphabet-soup-for-kids" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/alphabet-soup-for-kids/cover.jpg)

儿童字母汤是一款适合所有年龄段的趣味教育游戏。在乐趣中学习能更好地吸引孩子的注意力并激发他们的兴趣。让我们通过这个游戏来学习吧。在游戏中，我们会看到一锅汤，里面充满了带有字母的零食，你只需要按顺序从A到Z收集这些字母（大小写字母均可）。尽快完成所有字母的收集，即可通关游戏。

## 怎么玩

使用鼠标进行操作
