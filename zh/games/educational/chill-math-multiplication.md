# 轻松数学乘法

<a href="https://inkwengame.com/zh/games/chill-math-multiplication" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/chill-math-multiplication/cover.jpg)

在这个游戏中，乘法表达式瓷砖下隐藏着一幅冬日景象。玩家必须将正确的数字彩球拖放到匹配的瓷砖上以解决表达式。每解决一个表达式，冬日景象就会逐渐显现。目标是通过正确完成所有数学问题来揭示整个图像。

## 怎么玩

使用鼠标或触控板将正确的数字彩球拖放到匹配的瓷砖上以解决表达式
