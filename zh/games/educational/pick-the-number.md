# 选择数字

<a href="https://inkwengame.com/zh/games/pick-the-number" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pick-the-number/cover.jpg)

选择数字是一款旨在提升大脑能力的教育类且令人上瘾的益智游戏！在有趣、色彩丰富的环境中，锻炼你的数字识别能力，提高记忆力，并测试你的反应速度。你的任务很简单：在时间耗尽前根据提示选出正确的数字！适合儿童和成人，这款游戏将快速思考与教育价值完美结合。

## 怎么玩

桌面 点击鼠标左键以按顺序选择正确数字 移动设备 点击按顺序选择正确数字
