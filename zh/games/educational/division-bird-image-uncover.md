# 除法鸟图像揭示

<a href="https://inkwengame.com/zh/games/division-bird-image-uncover" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/division-bird-image-uncover/cover.jpg)

在这个游戏中，一只鸟的图像被隐藏在除法表达式方块之下。玩家必须将正确的数字气泡拖放到匹配的方块上以解决表达式。每解决一个表达式，鸟的图像就会逐渐显现出来。目标是通过正确完成所有数学问题来完全揭示图像。

## 怎么玩

使用鼠标或触控板将正确的数字气泡拖放到匹配的方块上以解决表达式
