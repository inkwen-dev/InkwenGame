# 涂色鱿鱼游戏

<a href="https://inkwengame.com/zh/games/coloring-squid-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/coloring-squid-game/cover.jpg)

玩这款以热门鱿鱼游戏图片为主题的涂色游戏。游戏中将出现许多来自鱿鱼游戏的热门角色。从十二张图片中选择一张你想要涂色的，然后开始游戏。选择你认为适合描绘这张图片的最佳颜色。如果需要绘制图片的较小部分，可以选择画笔大小；如果出错，可以使用橡皮擦工具。尽可能多地涂色更多图片。打印它们或保存图片，以证明你的绘画成果。
