# 难题：彩色线条

<a href="https://inkwengame.com/zh/games/hard-puzzle-color-lines" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/hard-puzzle-color-lines/cover.jpg)

《Hard Puzzle: Color Lines》是一款逻辑游戏，玩家需要连接相同颜色的元素，在棋盘上绘制路径，并仔细规划每一步。游戏难度会逐渐增加：出现的颜色更多，可用空间更少，出错的几率也更高。这款游戏非常适合放松身心，同时又能锻炼大脑——关卡短小精悍，规则清晰明了，而且越到最后阶段越具有挑战性。

## 怎么玩

在每个关卡中，用线条连接相同颜色的元素对，并整齐地填满棋盘，同时避免阻挡其他颜色。

• 点击一个彩色元素，然后画线连接到与其颜色相同的元素对。

• 线条不能交叉，通常也不能留下额外的空隙。

• 如果操作失败，可以使用撤销/重做功能或重新开始关卡。

• 你的目标是连接所有颜色对，完成关卡。
