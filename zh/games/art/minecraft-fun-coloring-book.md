# 我的世界趣味涂色书

<a href="https://inkwengame.com/zh/games/minecraft-fun-coloring-book" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/minecraft-fun-coloring-book/cover.jpg)

《我的世界趣味涂色书》是一款出色的教育类游戏。在这款游戏中，你将找到六幅不同的图片，需要尽可能快地为它们上色，以在游戏结束时获得高分。你有24种不同的颜色可供选择。你还可以保存已上色的图像或将其打印出来。尽情享受吧！

## 怎么玩
