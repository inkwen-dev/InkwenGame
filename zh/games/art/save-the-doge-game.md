# 拯救Doge游戏

<a href="https://inkwengame.com/zh/games/save-the-doge-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/save-the-doge-game/cover.jpg)

《拯救Doge》是一款专为儿童设计的在线益智游戏。在游戏中，Doge将受到许多蜜蜂的攻击。你需要绘制一条蜡笔墙，帮助Doge避开蜜蜂，并保持10秒钟。你玩的关卡越多，难度就越大。石头和有毒的水也会试图伤害Doge。快来帮助Doge吧！

## 怎么玩

如果你在电脑上玩游戏，请用鼠标移动；如果你在手机上玩游戏，请点击按钮来移动
