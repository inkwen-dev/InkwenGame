# LOL 总统脸

<a href="https://inkwengame.com/zh/games/lol-presidential-face" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/lol-presidential-face/cover.jpg)

LOL 总统脸是一款有趣且轻松的面部编辑游戏，你可以以滑稽的方式混合、拉伸和交换总统特征。从不同的总统中挑选，拖动并扭曲他们的脸部，添加搞笑的配饰，并创造出你所能想象出的最搞笑的组合。无论你是让他们看起来傻乎乎、一本正经，还是纯粹荒谬可笑，目标都很简单：为你的总统杰作开怀大笑，并与朋友分享。
