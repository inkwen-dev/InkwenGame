# 像素绘制排序

<a href="https://inkwengame.com/zh/games/pixel-paint-sort" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-paint-sort/cover.jpg)

《像素涂色排序》是一款引人入胜的益智游戏，它将像素涂色和图块排序完美融合，带来轻松愉悦的体验。重新排列色彩缤纷的图块，将它们与正确的图钉匹配，逐步展现美丽的像素艺术。看着画面随着你的每一次移动而逐渐鲜活起来，将杂乱的图块变成一幅令人惊叹的杰作！

## 怎么玩

点击方块即可选中与其相连的同色方块组。

将选中的方块移动到对应的空位上。

使用托盘暂时存放方块，并规划下一步操作。

完成所有颜色，即可展现完整的像素图案。

将所有方块放置在对应的空位上，即可完成此关卡。
