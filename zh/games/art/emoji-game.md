# 表情符号游戏

<a href="https://inkwengame.com/zh/games/emoji-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/emoji-game/cover.jpg)

一款全新的想象力游戏，你需要通过联想将情绪配对。思考并找出每个谜题的创意。只需依次点击不同列中的元素，用线条连接它们。或者拖动以画线，连接来自不同列的元素。如果正确连接所有元素，即可通过关卡。比你想象的更难！

## 怎么玩

拖动以画线并连接来自不同列的元素
