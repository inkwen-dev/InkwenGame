# 像素色彩探索

<a href="https://inkwengame.com/zh/games/pixel-color-quest" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/pixel-color-quest/cover.jpg)

选择一张你喜欢的图片，将空白区域变成一幅色彩鲜艳的像素画。选择所需的颜色，并按照编号仔细填充单元格。

## 怎么玩

目标：为选定的图片完全着色。找到单元格中的数字，选择与数字对应的颜色，并填充所有匹配的单元格。当图片的每个部分都涂上正确的颜色时，图片就完成了。

电脑：

- 左键单击鼠标左键 — 选择图片或颜色。

- 左键单击单元格 — 用选定的颜色填充该单元格。

手机和平板电脑：

- 点击图片或颜色进行选择。

- 点击所需的单元格进行填充。
