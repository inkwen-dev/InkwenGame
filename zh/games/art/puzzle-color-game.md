# 拼图颜色游戏

<a href="https://inkwengame.com/zh/games/puzzle-color-game" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/puzzle-color-game/cover.jpg)

在这个游戏中，你的目标是用你的大脑摧毁所有的方块。将相同颜色的方块移动成一行，以摧毁它们并进入下一关。每一关都越来越难。享受游戏吧！

## 怎么玩

电脑 - 鼠标控制 智能手机 平板 - 触控控制
