# 色彩迷宫谜题 2D

色彩迷宫谜题 2D 是一款包含 80 个挑战关卡的迷宫游戏。滑动以移动小球并为所有方块着色。通过一些关卡后，会解锁新的小球，帮助你到达终点。玩得开心！

## 怎么玩

单触控操作 键盘方向键 按 R 重新开始 布局
