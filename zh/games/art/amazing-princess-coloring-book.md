# 神奇公主涂色书

<a href="https://inkwengame.com/zh/games/amazing-princess-coloring-book" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/amazing-princess-coloring-book/cover.jpg)

所有孩子都喜欢画画和涂色！不如来发现全新的涂色乐趣，用可爱的不可思议的公主们开启你的创作之旅。选择你最喜欢的公主角色，并用传统风格为她上色。或者，你可以为公主创造一幅全新的独特多彩图像。使用右侧的可移动面板来选择所需颜色。用鼠标左键拖动调色板面板。尽情享受这款新游戏《神奇公主涂色书》吧！
