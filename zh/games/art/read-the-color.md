# 读取颜色

<a href="https://inkwengame.com/zh/games/read-the-color" target="_blank" rel="noopener noreferrer">在 InkwenGame 玩</a>

![cover](https://img.inkwengame.com/games/read-the-color/cover.jpg)

读取圆圈内的颜色，并点击对应颜色的按钮！你有20秒的时间来得分。但要小心，不要混淆！颜色，或称色彩，是视觉感知的一种特征，通过颜色类别来描述，如红色、橙色、黄色、绿色、蓝色或紫色。这种颜色感知源于光感受器细胞受到电磁辐射的刺激。本游戏由Trezegames和Kutty Company制作

## 怎么玩

点击正确的颜色以获得分数
