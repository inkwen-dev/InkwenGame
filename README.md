## What is InkwenGame

InkwenGame is a free online games site. Browse by category or search, open a title, read a short guide, and play right in your browser — no download.

Each game page has its own short description and how-to so you know what you are opening before you start. New games are added over time. Visit <a href="https://inkwengame.com/" target="_blank" rel="noopener noreferrer">inkwengame.com</a>.

## What this repository is

This repo is a **public Markdown catalog** of games published on InkwenGame. Content is split by language:

- [`en/`](en/README.md) — English categories and game pages
- [`zh/`](zh/README.md) — Chinese categories and game pages

Play links point to the live site. Cover images use our CDN (`img.inkwengame.com`). The catalog is meant for people and tools that prefer reading structured docs on GitHub, then jumping to the site to play.

## Who it helps

- **Players** — discover games by category, skim intros and controls, then open the play page.
- **Directory and content sites** — stable pages and deep links to cite or list without scraping the live HTML.
- **Search and AI tools** — plain Markdown with game names, short copy, and links to `inkwengame.com`.

## How to browse

1. Open [English](en/README.md) or [中文](zh/README.md).
2. Pick a category.
3. Open a game page for the intro and how-to.
4. Use the play link to start on InkwenGame.

## Not in this repository

- No playable game packages or embeds
- No admin tools, API keys, or private config
- No supplier / source attribution fields
