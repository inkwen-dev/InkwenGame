## How to play

Build the missing parts of the level. 

PC/Desktop
Q to build a platform
W to build a ramp
E to build a slope
R to use weapons

Mobile

Use on screen buttons

## About

Build And Run is an exciting arcade game where you navigate, construct, and triumph! Play instantly on various devices without downloads or sign-ups. Race through levels while building ramps and defeating foes with diverse weapons. Customize your character with stylish gear and enjoy endless fun in both modes!
