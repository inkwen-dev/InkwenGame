## About

Project VOID is a fast-paced sci-fi roguelike survival game set on a mysterious alien world. Fight off waves of hostile drones, survive as long as you can, collect Void Skulls, and upgrade your abilities between waves. Each wave gets more intense as enemies become stronger and spawn more frequently. How long can you survive?
