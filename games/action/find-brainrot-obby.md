## About

This is an obby game about exploration, strange places, and unexpected discoveries.
Brainrots are hidden everywhere — on rooftops, under platforms, behind walls, and in the most unexpected spots.

There is no right path here.
If something looks strange, it probably hides something.

Explore the world, beat the obbies, discover secrets, and collect all Brainrots.
Can you see all the absurdity this world has to offer?
