## About

In Prison Escape Plan, 3 prisoners decide to escape from prison. A plan is required for this. But 3 prisoners cannot create a plan. They ask for help from this professor. Your task is to kidnap these 3 prisoners from prison as professors. Remember, you shouldn't be caught by cops and detectors. A fluent game awaits you with +50 different levels.
