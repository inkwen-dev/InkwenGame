## About

You need to collect all the coins at every level. There are two modes in game: the platforming mode, in which you can run and jump, and the sokoban mode, in which you can move blocks, coins, etc. In sokoban mode chests monsters wake up, attack and chase the main character. In platforming mode chests sleep and can be used as platforms.
