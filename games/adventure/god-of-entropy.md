## How to play

Story Mode – Complete each level’s goal using the available elements to progress the story
Sandbox Mode – Experiment without limits, create your own scenes, and unlock achievements

Controls:
Select element – Click an icon in the left toolbar
Draw element – Left Click + drag
Draw straight line – Shift + Left Click + drag
Adjust brush size – Mouse wheel or on‑screen slider
Pause / Menu – ESC key
