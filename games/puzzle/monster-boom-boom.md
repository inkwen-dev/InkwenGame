## About

Monster Boom Boom is a fun and challenging puzzle game where you use special vials created from green monsters to eliminate all the monsters on the arena. Each move is precious because the number of actions is limited. You need to carefully calculate the position, shooting direction, and timing to create an optimal chain explosion, clearing all enemies in just a few steps. With exciting explosion effects, the gameplay is both simple and strategic, offering thrilling and satisfying puzzle experiences.
