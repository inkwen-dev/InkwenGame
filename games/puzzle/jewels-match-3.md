## About

Jewels Match 3 is a match-3 games with the jewels. In each level, you need to clear the dirty cells. Make a column or row of three or more jewels of the same type to make them disappears. You can't swap the locked jewels. If you match 3 or more jewels with a specific shape you will get special symbol, such as bomb symbol, crump symbol, flash symbol and time symbol. Break all the dirty cells in time to complete the level.
