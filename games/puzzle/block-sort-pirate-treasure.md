## How to play

Objective 🎯
Sort all the mixed pirate treasures so that every column contains only one matching type of loot! 🏆

Controls 🕹️
💻 Desktop (Mouse): Click on a stack to pick up the top treasure item, then click on an empty space or a stack with the same top item to drop it.

📱 Mobile / Touchscreen: Tap a stack to select the top block, then tap your target destination to move it.
