## About

It's no secret that players love matching three or more objects together in order to complete a task. And now, they can do so with animals in an online game called Animals Pairs Match 3. This game is based on the popular matching games you may have played on mobile devices or computers, but with animals as the main focus. The object of the game is to match up two of the same animals and then move on to the next level. Levels get harder and faster as you go, and if you can't complete a level within a certain time limit, the game will end and you'll have to start over. The game is simple to play but hard to master, so be sure to try it out today!
