## How to play

Select the appropriate emoji by clicking or touching it.
Each puzzle may seem nonsensical, but there is only one correct answer!

## About

Emoji Sort is a pattern recognition puzzle game where players must fill in empty cells with the correct emojis. Each puzzle presents a grid with missing emojis that follow specific patterns - such as categories, sequences, or associations. Players analyze the existing emojis to identify the pattern (animals, food chains, transportation types, etc.) and select the appropriate emojis to complete the grid. The game features 80 increasingly challenging levels with various pattern types, and includes a hint system to help when players get stuck. Perfect for puzzle enthusiasts who enjoy discovering logical connections between visual elements!
