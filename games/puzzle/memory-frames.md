## About

Memory Frames tests your brain memory. The Elements, Water, Earth, Wind, Fire, creates patterns by pushing Frames. You must repeat this Elements pattern using your memory ability. Each Frames is associated with a color, Blu for water, Yellow for Earth, Green for Wind and Red for Fire! These Elements help you to remember as the correct pattern; sign your best scores and enjoy playing anywhere!
