## How to play

Keyboard & Mouse Controls
1 - Select Ambulance
2 - Select Crane
3 - Select Dump Truck
W / S - Drive
Q / E - Rotate crane cabin
Mouse Up / Down - Move crane arm
Left Mouse - Close claw
Right Mouse - Open claw
Esc - Pause / Back

Gamepad Controls
RT / R2 - Drive forward
LT / L2 - Reverse / Brake
LB / L1 - Rotate crane cabin left
RB / R1 - Rotate crane cabin right
Left Stick Up / Down - Move crane arm
A / Cross - Close claw / Confirm
B / Circle - Back / Cancel / Pause
X / Square - Switch vehicle

## About

Bucket Brigade
Bucket Brigade is a cozy toy-themed puzzle game where you guide a rescue convoy across a sunny beach.

Children have left toys and sandcastles behind, and the beach needs to be cleared before the summer heat melts your plastic vehicles.

### 介绍

救生桶大作战

《救生桶大作战》是一款轻松愉快的玩具主题益智游戏，你将带领一支救援队穿越阳光明媚的海滩。

孩子们把玩具和沙堡都留在了沙滩上，你需要在夏日的酷暑融化你的塑料小车之前，把沙滩清理干净。
