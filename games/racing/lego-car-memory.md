## About

Lego Car Memory is a free online game from genre of memory and car games. This game offers different cars, but in the picture and you have to use your memory to remember and guess two same car signs. Flip the tiles and try to match them up in pairs. Pair up all the tiles to win. Try to complete the game in as few moves as possible! There are is 4 levels. Use mouse to click or tap to screen on the squares. Concentrate yourself and start to play. Good luck!
