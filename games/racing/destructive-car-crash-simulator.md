## How to play

TAB - pause menu (or Escape)
WASD - moving.
Spacebar - handbrake.
Shift - nitro.
C - change camera.
R - reset car.
K - restore car.
N - switch car.
For mobile devices, use the game interface.

## About

Different maps and cars.
