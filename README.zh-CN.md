## InkwenGame 是什么

InkwenGame 是免费在线小游戏站。可按分类浏览或搜索，打开一款游戏，先看简短介绍和玩法，再在浏览器里直接玩——不用下载。

每款详情页都有自己的短介绍和玩法说明，方便你先了解再开玩。游戏会陆续增加。地址：<a href="https://inkwengame.com/zh" target="_blank" rel="noopener noreferrer">inkwengame.com</a>。

## 本仓库是什么

本仓库是 InkwenGame 已上架游戏的**公开 Markdown 目录**，按语言分树：

- [`zh/`](zh/README.md) — 中文分类与游戏页
- [`en/`](en/README.md) — 英文分类与游戏页

游玩链接指向官网。封面使用自有 CDN（`img.inkwengame.com`）。适合在 GitHub 上阅读结构化文案，再点进网站游玩。

## 对谁有用

- **玩家** — 按分类发现游戏，浏览介绍与操作说明，再打开游玩页。
- **目录站与内容站** — 可引用稳定页面与深链，不必抓取线上 HTML。
- **搜索与 AI 工具** — 纯 Markdown，含游戏名、短文案与指向 `inkwengame.com` 的链接。

## 怎么浏览

1. 打开 [中文目录](zh/README.md) 或 [English](en/README.md)。
2. 选择一个分类。
3. 打开游戏页查看介绍与玩法。
4. 点击游玩链接，在 InkwenGame 开始。

## 本仓库不含

- 可玩的游戏包或嵌入页
- 后台工具、密钥或私密配置
- 供应商 / 出处字段
